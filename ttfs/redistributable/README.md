# ttfs/redistributable — 재배포 승인 원본 SFNT

OFL은 아니지만 권리자가 무료 사용·배포한 exact 원본 SFNT를 라이선스·출처와 함께 추적한다. 수정 가능한
오픈소스 폰트만 두는 `../opensource/`와 혼합하지 않는다. 각 하위 디렉터리는 공식 source URL, archive/member
hash, 동봉 라이선스와 변형 금지 경계를 기록해야 한다.

이 경로의 폰트는 fixture·exact-source 검증 입력이다. 별도 제품 결정 없이 WASM이나 배포 bundle에 자동
포함하지 않는다.
