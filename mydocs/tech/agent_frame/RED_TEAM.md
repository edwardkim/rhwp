# 경쟁자 시각 — 우리 틀을 공격한다 (외부 검증 축)

> 스스로를 경쟁자로 가정하고 우리 시스템(표준·gym·조직·프레임)을 친다. 그 공격을
> **축으로 세워** 계측기로 삼는다 — 비판을 지우는 게 아니라 흡수한다. 계측 도구는
> [`tools/reality_check.py`](../../../tools/reality_check.py), 신호 스냅샷은
> [`external_signals.json`](external_signals.json).

## 왜 이 축인가

우리는 표준·gym·조직·프레임을 정합하게 세웠다. 그런데 여러 축이 있어야 어느
방향으로 공격이 들어와도 결국 우리 축에서 막힌다. 지금까지의 축은 전부 **내부
정합**(가드가 통과)을 향한다. 빠진 축은 하나 — **외부 검증**: 밖에서 봐도 진짜인가.

## 경쟁자의 여섯 공격 — 그리고 정직한 답

| # | 공격 | 정직한 인정 | 어느 축이 막나 |
|---|---|---|---|
| 1 | **"다 self-graded 다"** — gym 이 gym 을 채점, 표준 만든 자가 표준 준수, 리더보드가 스스로 봉인 | 맞다. 내부 정합은 self-graded 다 | **이 축(외부 검증)** — 내부/외부를 분리 계측해 스스로 속이지 않는다 |
| 2 | **"문서·가드일 뿐 능력이 아니다"** — 코어(HWP 파싱·편집)는 안 늘었다 | 이 세션 산출은 대부분 메타-스캐폴딩이다 | 능력 축(gym pack·코어 PR)이 별도로 코어를 실측·확장 |
| 3 | **"표준에 준수자가 하나뿐"** — AWS 를 오직 rhwp 만 구현 | 맞다. 준수자 1 = 표준이 아니라 명세 | 이 축이 **외부 준수자 수를 정직하게 0 으로 보고** — 채울 격차를 드러낸다 |
| 4 | **"정합 ≠ 가치"** — 서로 가리키는 건 맞는데 사용자 가치는 안 잰다 | 맞다. 지도를 최적화했지 영토가 아니다 | 이 축이 외부 채택(=실사용 가치)을 계측 대상으로 못박는다 |
| 5 | **"메인테이너 종속"** — 전부 남의 저장소에서 그의 승인에 달렸다 | 맞다. 단일 실패점이다 | 이 축의 판정 기준 "제3자 독립 재현"이 저장소 밖 재현성을 요구 → 종속 완화 |
| 6 | **"채택을 안 잰다"** — '더 들어온다'는데 외부 사용 지표가 0 | 맞다. dominance 지표는 내가 얼마나 썼나이지 남이 얼마나 쓰나가 아니다 | 이 축이 **메타-시스템 외부 채택을 별도 계측**(프로젝트 견인과 뭉뚱그리지 않음) |

## 정직한 현실 채점 (실측)

`reality_check.py` 는 **절대 뭉뚱그리지 않는다**:

- **프로젝트 견인(코어, 실재)** — ★3691 · fork 672 · 기여자 50 · npm @rhwp/editor 13,089/월.
  이건 진짜다. 그러나 **코어 제품**의 견인이지 이 세션 메타-시스템의 것이 아니다.
- **메타-시스템 외부 채택** — 준수자·참조·제3자 재현 = **0**. 프로젝트 견인에 얹혀
  있을 뿐 스스로 번 채택은 없다.
- **내부 정합** — 가드 통과. 단 self-graded.

→ **결론: 내부 정합은 높고 외부 채택은 0.** 이 격차를 지우지 않고 드러낸다.

## 외부 검증으로 인정하는 것 (다음 목표)

내부 가드가 아무리 초록이어도 외부 검증은 아니다. 다음만 외부 검증으로 친다:

1. 외부 저장소/도구가 AWS 표준을 준수 선언하거나 검증 사다리 캡슐을 생성한다.
2. 제3자가 gym scorecard·리더보드를 **저장소만으로 독립 재현**한다.
3. 외부 에이전트가 리더보드에 **자기 키로** 등재한다(초대 메커니즘 실사용).
4. MCP 레지스트리(glama·smithery·pulsemcp 등)에 rhwp 가 등재된다.
5. 붙이기 킷을 쓴 외부 호스트 설정이 관측된다.

## 여러 축 = 어느 방향이든 우리 축

각 공격은 서로 다른 방향에서 온다. 하지만 축을 여럿 세워 두면 — 능력(gym)·검증
(사다리)·채택(표면)·조직(운영체제)·정합(프레임)·**현실(외부 검증)** — 어느
방향으로 공격이 들어와도 그 방향에 대응하는 축이 있다. 특히 가장 아픈 공격
("self-graded")조차 **이 축이 정직하게 계측**하므로, 경쟁자가 그걸로 우리를
놀래킬 수 없다 — 우리가 먼저 숫자로 인정하고 있으니까.

## 합법성

이 축의 힘은 **정직**에서 온다. 외부 채택을 0 으로 부풀리지 않고 그대로 보고한다.
자기 견인(프로젝트)과 남의 채택(메타)을 뭉뚱그리면 그 순간 이 축은 self-graded 로
전락한다 — 그래서 계측기가 둘을 강제로 분리한다. 준거는 재현 가능성이지 자기
선언이 아니다.
