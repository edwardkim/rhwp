# 트랙 E — 실물 편집 능력 (R41~R50)

**질문**: 실물 한글 문서를 실제로 다루는가(구경이 아니라).

읽고 들여다보는 것과 실물 바이트를 바꾸는 것은 다른 문제다. 이 트랙의 증거
기준은 말이 아니라 **실물 서식의 픽셀 diff** 다 — set-cell 은 13×13px 외과수술로
(R43), render-diff 는 bbox 로(R50 근거) 무엇이 바뀌고 무엇이 그대로인지를
이미지로 증명한다. R41~R47 이 세션 편집·보호 문서·표 셀·batch 추출까지 실물로
짚은 실적이고, R48~R50 은 오탐률·등급 기준·회귀 임계 같은 **측정·합의가
선행돼야** 여는 표면이다.

## R41 세션 편집·검색·치환·저장 `[완료]`

- **한 줄** — 문서를 열고 채우고 형식 보존해 저장하는 세션 편집이 선다.
- **지금** — #3599 · #3602. `hwp_doc_fill_fields` 누적 + `hwp_doc_save` 형식 보존,
  세션 단위 검색·치환.
- **설계(보장)** — 채우기는 누적이고 저장은 원본 형식을 보존한다 — 편집이 파일을
  다른 포맷으로 눕히지 않는다. 세션이 상태를 들고 있어 검색·치환·채우기가 한 문서
  위에서 이어진다.
- **DoD** — 달성: 열기 → 채우기(누적) → 검색·치환 → 형식 보존 저장이 한 세션에서
  완결된다.
- **의존** — 없음(편집 표면의 바닥).

## R42 보호 문서 password 전 표면 배선 + 전수 가드 `[완료]`

- **한 줄** — `--password` 를 선언하고도 암호 문서를 못 열던 명령 7건을 고쳤다.
- **지금** — #3604 · #3839. `--password` 를 선언하고도 암호 문서를 못 열던 명령
  7건 — 내부에서 `from_bytes` 를 직접 호출해 **암호를 무시**했고, 사용자는
  "HWP 파싱 실패"를 보고 **파일이 깨진 줄 알았다.** 전부 `load_document` 로 통일.
- **설계(보장)** — 전 명령이 `from_bytes` 직접 호출 대신 `load_document` 한 곳을
  지난다 + **실행 기반 회귀 가드** — 새 명령이 다시 `from_bytes` 로 새면 가드가
  잡는다(선언과 실물의 괴리를 실행으로 대조).
- **DoD** — 달성: 7건 배선 + 실행 기반 회귀 가드.
- **의존** — R41.

## R43 set-cell·checkbox 실물 `[완료]`

- **한 줄** — 표 셀 값과 체크박스를 실물 서식에 그대로 쓴다.
- **지금** — #3613 · #3620. 실물 서식 **픽셀 diff 증적**(13×13px 외과수술).
- **설계(보장)** — 편집 증적이 픽셀 diff 다 — 바뀐 것은 대상 13×13px 뿐이고
  나머지 서식은 불변임을 이미지로 증명한다. "고쳤다"가 주장이 아니라 관측이 된다.
- **DoD** — 달성: set-cell·checkbox 편집 전후 픽셀 diff 로 대상 외 불변 증명.
- **의존** — R41.

## R44 도장 insert-image 실물 킬러 `[완료]`

- **한 줄** — 도장 이미지를 실제 문서에 실물로 얹는다(킬러 앱).
- **지금** — #3395 계열. `batch_fill` · 도장 삽입.
- **설계(보장)** — insert-image 가 도장 이미지를 실제 좌표에 얹고, `batch_fill` 과
  묶여 여러 문서에 일괄 날인한다 — "실물을 다루는가"의 가장 직접적인 증명이라
  킬러 앱으로 부른다.
- **DoD** — 달성: 도장 삽입 + batch 일괄 채우기가 실물 문서에 반영된다.
- **의존** — R41.

## R45 batch extract-data `[완료]`

- **한 줄** — 폴더 전체에서 날짜·금액·수량을 일괄 추출한다.
- **지금** — #3871. 폴더 전체를 돌며 날짜·금액·수량을 한 호출로 수확한다.
- **설계(보장)** — extract-data 가 폴더 단위로 날짜·금액·수량을 뽑는다 — 한 건씩
  열지 않고 다건을 한 호출로 처리하는 것이 batch 의 값이다(R44 의 batch 날인과
  같은 축의 읽기 방향).
- **DoD** — 달성: 폴더 입력에서 날짜·금액·수량이 일괄 추출된다.
- **의존** — R41.

## R46 렌더 견고성 연속 `[이슈]`

- **한 줄** — 기형 입력이 렌더러를 패닉시키던 결함을 연속 발굴한다.
- **지금** — PR #3875. WMF POLYLINE/POLYGON 의 **음수 NumberOfPoints** 가 capacity
  overflow 패닉을 냈다(red→green 실증). 이런 파서 견고성 결함의 연속 발굴 축이다.
- **설계** — 기형 입력(음수 NumberOfPoints)을 capacity 할당 전에 거른다. 이런
  결함은 하나 고치고 끝이 아니라 코퍼스·퍼즈로 연속 발굴되는 축이라, 발견 1건마다
  red→green 회귀를 스위트에 남긴다(트랙 B 악성 코퍼스와 같은 방법).
- **착수 게이트** — 없음(PR 존재). 다음 행동은 머지 유도·리뷰 대응.
- **DoD** — PR #3875 머지. 음수 NumberOfPoints WMF 가 패닉 대신 정직한 오류로
  처리되고, red→green 회귀가 스위트에 남는다.
- **의존** — 트랙 B(악성·기형 코퍼스 회귀와 짝).

## R47 표 셀 내 검색 경계 `[완료]`

- **한 줄** — 표 셀 안 텍스트가 찾기에서 안 잡히던 경계를 닫았다.
- **지금** — #3865 → #3870(통합 반영). 표 셀 안 텍스트가 찾기에서 안 잡히던 것.
- **설계(보장)** — 검색이 표 셀 내부 텍스트까지 훑는다 — 셀 경계가 더는 검색
  사각이 아니다(세션 검색·치환의 도달 범위를 실물 표까지 넓힌 것).
- **DoD** — 달성: 표 셀 내부 텍스트가 검색에 잡힌다.
- **의존** — R41(세션 검색).

## R48 폼 오토파일럿 `[가설]`

- **한 줄** — 서식을 인식해 채우기 계획 초안을 자동 생성한다.
- **지금** — 미착수. #3719 §6.6 2호(`hwp_form_autopilot`).
- **설계** — 서식 인식 → 계획 초안 자동 생성. **주의**: 잘못된 계획 초안은 R22
  CAS 로도 못 막는다(CAS 는 "이 계획이 이 문서에 적용됐음"을 고정할 뿐, 계획 자체의
  옳고 그름은 검증하지 않는다) — 그래서 **사람 확인 게이트가 설계에 필수**다.
- **착수 게이트** — 서식 인식의 **오탐률 실측**. 오탐률이 사람 확인 게이트의 강도를
  정한다 — 근거 없이 게이트를 설계할 수 없다.
- **DoD** — 서식에서 계획 초안을 생성하고, 초안은 사람 확인 게이트를 통과해야
  실행에 들어간다. 오탐률이 게이트 설계 기준을 만족한다.
- **의존** — R41(편집 표면), R22(CAS, 트랙 C).

## R49 한컴 호환성 등급표 공표 `[가설]`

- **한 줄** — 기능별 한컴 라운드트립 등급을 공표한다.
- **지금** — 미착수. 기능별 라운드트립 등급(#3676 계열).
- **설계** — 기능별로 한컴 실물 왕복 등급을 매겨 표로 공표한다. **주의**: 한컴
  동작에 의존하는 판정이라 메인테이너 재검증 영역이다 — 우리 관측만으로 등급을
  확정하지 않는다.
- **착수 게이트** — ① 한컴 실물 대조 코퍼스(트랙 B R18). ② 등급 기준 정의(무엇을
  어느 등급으로 볼지).
- **DoD** — 기능별 등급표가 공표되고, 각 등급이 대조 코퍼스의 재현 가능한 왕복
  결과에 근거한다.
- **의존** — 트랙 B R18(대조 코퍼스).

## R50 render-diff 임계 정책 상시 게이트화 `[가설]`

- **한 줄** — render-diff 를 편집 전후 회귀 게이트로 상시화한다.
- **지금** — render-diff 자체는 **이미 있다**(#3618 픽셀 diff bbox 증명). 없는 것은
  "무엇을 레이아웃 회귀로 볼지"의 임계 정책이다.
- **설계** — 이미 있는 render-diff 를 편집 전후 회귀 게이트로 배선한다. 판단
  지점은 임계값 하나 — 어느 픽셀 차이부터 "회귀"로 볼지다(너무 엄하면 정상 편집도
  막고, 너무 느슨하면 회귀를 흘린다).
- **착수 게이트** — 임계값 기준(무엇을 "레이아웃 회귀"로 볼지) **실측 합의**.
- **DoD** — 편집 전후 render-diff 가 임계 초과 시 CI 를 막고, 임계값이 실측
  합의로 고정된다.
- **의존** — R41(편집 대상), render-diff(#3618).
