# 차기 지평 R101~R200 — 트랙 L~U 제안 (#4362)

R1~R100(#3907)의 다음 백 단계 **제안** 세트다. 세 가지가 이 문서의 지위를
정한다:

1. **전 항목이 `[지평]` 이다** — `[가설]`보다 먼 등급으로, *착수 게이트 자체를
   아직 서술할 수 없는* 단계라는 뜻이다. 가설은 "근거를 확보하면 시작"이고,
   지평은 "게이트를 쓸 수 있게 되면 가설로 강등"이다. 이 구분을 뭉개면 지도가
   소설이 된다.
2. **번호는 예약이지 부여가 아니다.** 채택·트랙 승격(`track_*.md` 신설과 그때의
   등급 재판정)은 전부 메인테이너 몫이다. 파일명이 `horizon_` 인 이유: 진행률
   기계 집계(`tools/roadmap_progress.py`)는 `track_*.md` 만 파싱하고 1~100 밖
   번호를 오류로 잡는다 — 이 문서는 의도적으로 집계 밖이다.
3. **R100 판정 전 구현 착수 금지.** 단, 각 트랙이 인용하는 "씨앗 실측"(이미
   저장소에 존재하는 실물)은 예외가 아니라 근거다 — 지평은 무에서 세우지 않고
   연장선으로 세운다.

## 승격 규약 — 지평이 가설이 되는 길

`[지평] → [가설]` 강등(지도 관점에선 승격) 조건은 각 트랙 표의 "승격 조건"
열이다. 공통 절차: ① 승격 조건의 실측이 생기면 개별 이슈로 게이트를 서술하고
② 메인테이너 채택 시 해당 구간을 `track_*.md` 로 옮겨 집계에 편입한다(그때
결번 검사 상한 100→200 확장이 같은 PR 에 포함되어야 한다 — 스크립트 V1 규칙).
