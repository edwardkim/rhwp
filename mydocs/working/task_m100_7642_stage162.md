# #7642 Stage 162 — 그림 회피 뒤 TAC 표의 실제 줄 프레임 공유

Issue: #7642

## 구현 전 근거

실패한 #6812 관계 검사는 `samples/issue6797/156160455-social-pig-farm-income.hwp`의
첫 그림을 같은 문단에 복제하고 세로 오프셋을 4500HU 늘린다. 이 상태를 보존한
HWPX를 한컴 2020 MCP Print로 출력했다. 독립 기준은 11쪽이며 PrintMethod 0,
`hancom2020_pdf_driver_one_up`, 한컴 11.0.0.9136, 작업
`ea1ea3c7-4173-47df-8663-32ecd2afbe1d`다. Native는 동일한 3.6px 본문 하단
초과를 재현했다. 첫 두 쪽 일치율은 95.60806 / 45.35332%다. Print의 다음 쪽
첫 줄이 Native에서는 앞 쪽에 남으므로 첫 쪽 점수만으로 완료 판정하지 않는다.

`stage162-square-table-cap.log`에서 앞 두 TAC 줄의 `line_height`는 각각
표 선언 높이와 위·아래 바깥 여백의 합이다. 실제 paint는 연속된 다음 저장 줄
원점에 따라 뒤 간격 900HU를 전량 소비한다. 반면 높이 cap은 그 간격을 절반만
예약하고 이미 줄 높이에 포함된 위 여백을 다시 더한다. 첫 두 표 뒤 측정 커서와
paint 커서는 약 8.25px 갈라진다. 그 뒤 일반 본문 높이들은 같으므로 앞 표의
확정 흐름 끝을 고쳐야 한다. 실패한 줄의 수용은 saved-tail 특례가 아니다.

## 생산·소비와 수정 계획

그림의 옆 회피 공간 확정 → 현재 단의 실제 TAC 원점 → 원본 표 소유 줄 높이와
독립 다음 줄 연결로 검증한 뒤 간격 → 단 예산 → inline placement의 같은 원점과
advance_end → paint의 기존 공통 끝 소비 → 후속 문단 예산으로 연결한다.
단일 표 줄이 선언 본체와 바깥 여백을 정확히 담고 실측 본체도 같은 높이일 때만
이 결과를 사용한다. 편집·합성 줄, 실제 성장 표, 캡션·각주, 본문 혼재·다중 개체
줄은 각각 기존 소유 경로에 남긴다. 저장 페이지 좌표로 그림 회피 뒤 원점을
되감거나 문서 ID·절대 px로 출력 위치를 맞추지 않는다.

정확한 기존 관계 검사는 유지한다. 같은 원본·독립 Print의 전체 Native/fresh WASM
90%와 확대 판독 전에는 새 회귀·fixture 또는 golden 기대값 변경을 추가하지 않는다.
다중 그림과 원본 그림, 독립 재저장 표 및 PrEP 영향 페이지를 함께 검증한다.

## 1차 구현과 Native 실행

`controls/physical_tac.rs`의 조회 결과를 그림 회피 확정 뒤에 소비하고 같은
inline `advance_end`를 기존 paint 소비 지점에 전달했다. 뒤 문단의 cap도 이
확정 끝점을 되감지 않도록 했다. Native 빌드는 exit 0, 280.004초이며 소스
해시 유지 true다. immutable binary SHA-256은
`b62cb20bbc962457c29df3888820c3247deca7778231f3d0725045a3b3c4fee1`이다.

다중 그림 입력에서 pi8 앞의 측정 커서는 893.84에서 902.08로 바뀌어 실제
paint 원점과 일치한다. 기존의 두 번째 줄 하단 초과 대신 첫 줄만 앞 쪽에 남는다.
다만 직접 좌표 추적에서 새 metadata의 `y`에 위 바깥 여백이 들어 있고 기존
paint 소비 지점이 그 여백을 다시 더하는 문제도 확인했다. 표 테두리가 종전보다
위 여백만큼 아래로 이동하므로 이 1차 상태를 완료 판정하지 않는다. 해당 실행과
검사 결과를 보존한 뒤 pen 원점 계약을 바로 보정한다.

기존 #6812 관계 검사와 다중 그림·원본 그림 전체 11쪽씩, PrEP 영향 네 쪽,
독립 재저장 표 두 쪽의 Native 비교가 실행 중이다. 전체 fresh WASM과 최종
Rust 검증은 아직 미완료다. 테스트와 golden 기대값은 바꾸지 않았다.

독립 다중 그림 HWPX/Print 및 기존 수식 카탈로그 HWP/Print는 각각
`pdf/issue6812-multiple-square-pictures-print/`,
`pdf/issue7642-equation-catalog-print/`에 보존했다. 미달한 진단 자료이며 신규
회귀 fixture로 승인한 것이 아니다. 각 README에 원본 대응·Print 출처·SHA와
미달 상태를 기록했다.

## 1차 검증 종료와 보정 대상

Native 선행 비교는 소스 해시 유지 true로 종료했다. 다중 그림 전체 11쪽의
최저는 65.10121%이며 2·4쪽이 미달이다. 원본 그림 전체 11쪽은 4쪽
82.97181%로 미달이다. 같은 수정 전 바이너리·원본·PDF의 전쪽 최저는
95.76069%이고 4쪽은 97.54161%였으므로 원본의 하락은 이번 변경의 회귀다.
PrEP 영향 네 쪽은 앞 단계와 같은 결과이며 독립 재저장 표 두 쪽은 100%다.

기존 #6812 검사 20건은 19 PASS / 1 FAIL, 실행 exit 100, 소스 해시 유지 true다.
다중 그림 뒤 본문 하단 관계 검사는 PASS로 바뀌었지만, 뒤에서 등장하는 그림이
이미 놓인 표 위치를 바꾸지 않는 검사가 FAIL이다. 두 결과를 전체 검증 통과로
합치지 않는다. 위 여백을 중복 가산한 metadata 원점 계약을 다음 단계에서 보정한다.
