### #826 — PUA substitution 위치 확정

**기존 패턴 발견**: [src/renderer/layout/paragraph_layout.rs:3005](../../src/renderer/layout/paragraph_layout.rs#L3005) `map_pua_bullet_char(ch: char) -> char` 함수가 이미 한컴 PUA → 표준 Unicode substitution 패턴을 구현 중. Task #509 / Task #528 / Task #588 등이 같은 함수에 케이스를 점진 추가해온 패턴.

→ **단일 함수에 두 케이스 추가만으로 측정/렌더링 양쪽 자동 적용**. 별도 substitution 모듈 신설 불필요.

### #825 — header/footer 그림 lookup 위치 확정

**WASM API**: [src/wasm_api.rs:2267](../../src/wasm_api.rs#L2267) `getPictureProperties(section_idx, parent_para_idx, control_idx)`
**Native impl**: [src/document_core/commands/object_ops.rs:18](../../src/document_core/commands/object_ops.rs#L18) `get_picture_properties_native`

**현행 동작**: `section.paragraphs[parent_para_idx].controls[control_idx]` 만 lookup. 머리말 그림은 `section.paragraphs[bi].controls[Header(h)].paragraphs[ipi].controls[Picture]` 안에 위치하므로 도달 불가.

**IR 구조 확인**:
- `Section.paragraphs[bi].controls[hi] = Control::Header(Box<Header>)` ✓
- `Header.paragraphs: Vec<Paragraph>` ✓ ([src/model/header_footer.rs:11](../../src/model/header_footer.rs#L11))
- 머리말 picture 위치 = 5-tuple `(sec, body_para_idx, header_ctrl_idx, inner_para_idx, inner_ctrl_idx)`

**Stage 3 정정 방향 확정**:
1. WASM API 에 optional 파라미터 추가:
   - `header_para_idx: Option<u32>` + `header_ctrl_idx: Option<u32>` (footer 도 별도)
   - 또는 단순화: `parent_kind: Option<u32>` (0=body, 1=header, 2=footer) + `inner_para_idx, inner_ctrl_idx`
2. Native impl 분기 — 본문 lookup (현행) vs header/footer lookup
3. rhwp-studio 측 ref 구조 확장 + WASM 호출 전달
