# 단계 868 원본 프레임과 글꼴 공급의 배치 보정 계획

검토 후보 95a956ecd, 기준 a5e88ad682c805e1d845502ddc9521b94ea8eccd.

- 독립 Print 38쪽의 첫 행(오프셋 72)이 Native에서 이전 쪽에 들어갔다. 원본 첫 조각 높이 26568HU는 처음 18행의 정확한 합이다. 나머지 8232HU, 아래 캡션 1802HU, 바깥 여백 276HU의 합은 다음 문단의 원본 vpos 10310HU다. 두 프레임의 내용 경계를 함께 인증하는 경우에만 scanner의 행 소유 상한으로 전달한다. 문서명·행 번호·관측 px를 분기 조건으로 쓰지 않는다.
- 명시 공급 H2GTRE.TTF는 Print 제목 글꼴과 원본 contour가 같지만 Native 출력은 바뀌지 않았다. strace에서 파일 적재 뒤 설치 HYGTRE.TTF를 다시 읽는 것을 확인했다. Skia의 대표 영문 family만 map에 넣고 한국어 요청을 조회한 경로가 원인 후보다. 같은 Typeface의 localized family를 모두 등록하고 명시 공급의 원본 face를 소비하도록 한다. 글꼴 바이너리는 비공개 ignored 진단 경로에만 둔다.
- HWPML 57쪽의 저장 TAC 수용은 첫 표 뒤 기준축을 보존하지 못한다. measured/declared/caption 잔차를 기존 진단 옵션에서 기록하여 수용 조건 실패를 먼저 확인한다. 미달 회귀의 기대값을 바꾸지 않는다.
- 장평의 세로 축 설명을 실제 Tf/CTM/Tz 계약으로 정정한다. 출력 메트릭은 단계 855의 구현을 유지한다.

단계 863의 실제 그룹 회귀 4건은 통과했다. fresh WASM 빌드 동안 source 변경은 적용하지 않고 patch를 output에 준비했다. 빌드가 종료되고 source 해시를 고정한 뒤 함께 적용·커밋하고 Native 하나를 빌드하여 동일한 선택 페이지를 확인한다. 신규 렌더링 회귀 추가와 #5821 기대값 변경은 Native/fresh WASM 선행 조건을 충족한 뒤 진행한다.
