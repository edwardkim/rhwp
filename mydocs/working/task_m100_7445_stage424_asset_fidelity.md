# 자산관리규정의 저장 제목·서명 기호·굵은 글자 간격 보정

Issue: #7445. 브랜치는 `fix/7445-completed-20261009`이며 보정 전 head는 `41562a703`다. 고정 devel은 `21ed64071f81f35f37618717693bd30f727392c9`다.

## 사전 분석과 수정

대상은 `samples/issue6031/3249937_asset_management_rules.hwpx`, 독립 기준은 `pdf/3249937_asset_management_rules-2020.pdf`의 전 60쪽이다.

1. 정상 저장 제목의 줄 높이 2000HU와 텍스트 부분 높이 2198HU는 서로 다른 필드다. 텍스트 부분 높이가 글자 크기보다 크다는 이유만으로 로더가 원본 한 줄을 두 줄로 재조판했다. 옛 크기가 줄·텍스트 높이에 함께 남은 단일 일반 글자모양만 재구성하고 유효한 글꼴 테두리는 보존한다. 원본이나 PDF는 수정하지 않았다.
2. 사용자께서 50·53·54쪽 서명란과 수신인의 미세 차이를 지적하셨다. 원문 U+F00E1 사각 인(印) 기호는 Print PDF의 한컴바탕 CID에서 1000/1000 전진폭을 갖는데, 결측 휴리스틱은 반각을 썼다. 전각 기호로 측정해 가운데 정렬 전체의 약 3.25pt 밀림을 제거했다.
3. HFT 굵은 한양신명조는 일반체 메트릭과 전진 간격이 다르다. 독립 PDF 54쪽 Type3는 `Tf 133`, `TJ -52.6`, 50쪽은 `Tf 117`, `TJ -51.3`이며 원본 em에 상대적인 추가 전진과 대응한다. 원본 HFT·같은 한양신명조 메트릭·굵은 한글 음절에만 5% 추가 전진을 적용했다. 공백·기호·실제 TrueType 선택·별도 Bold 메트릭을 보존한다. 읽기 전용 글꼴 trace도 이 결정을 실제와 같은 이유로 기록한다.

값의 경로는 `원본 저장 줄 → 로더의 재조판 필요 판정 → 한 줄 제목`, `기호 전진폭·굵은 글자 상대 전진 → 공용 글자 위치 측정 → 줄 정렬 → SVG/fresh WASM paint`다. 비교 알고리즘·관용 반경·점수 계산은 바꾸지 않았다.

## 전쪽 시각 검증

| 범위 | Native | 실제 Chrome fresh WASM | 쪽수 |
| --- | ---: | ---: | --- |
| 자산관리규정 전체 최저 | 91.83989% | 91.83989% | 60 = PDF 60 |
| 50쪽 | 96.79432% | 96.79432% | 미달 없음 |
| 53쪽 | 97.95201% | 97.95201% | 미달 없음 |
| 54쪽 | 97.06910% | 97.06910% | 미달 없음 |
| TAC 대조군 전체 최저 | 92.54967% | 92.54967% | 3 = PDF 3 |

두 백엔드의 자산관리 전쪽 PNG는 byte-identical이다. 독립 PDF와 엄격 픽셀 동일하다는 뜻은 아니다. 50·53·54쪽 review PNG를 직접 판독했다. 54쪽 서명 시작은 PDF 220.201pt / Native 220.250pt, 수신인 귀하 시작은 PDF 213.484pt / Native 213.600pt로 미세 출력 반올림 차이가 남는다. 이를 100% 픽셀 일치로 보고하지 않는다.

법원 서식의 현재 Native 두 쪽 SVG는 stage422에서 전쪽 Native/fresh를 검증한 결과와 byte-identical이다. 현재 법원 fresh를 재캡처한 것으로 쓰지 않는다. 현재 TAC는 두 백엔드 전쪽을 새로 비교했다. Mac locked no-opt WASM이며 Docker 최적화 빌드 통과로 기록하지 않는다. 실제 캡처는 최대 8개 병렬이다.

## 기존 회귀와 판정

전 60쪽 Native/fresh 90% 이상·독립 쪽수 일치·확대 판독을 먼저 확인한 후 기존 `saved_auction_frame_is_owned_by_both_measurement_and_painted_cell` 함수 하나를 보완했다. 새 테스트 함수는 추가하지 않았다. 기존 경매 칸의 측정·paint 프레임 소유를 유지하며, 정상 제목의 단일 글줄/칸 포함, 서명 기호와 한글의 같은 전각, 굵은 한글과 일반체의 전진 관계, 공백 보존을 검사한다. 절대 x/y와 고정 픽셀은 회귀 기대값으로 쓰지 않는다. 원본 HU 격자의 양자화 오차만 포함한다.

기존 자산관리·TAC·법원 회귀 3개를 threads 8 nextest로 실행해 3 PASS / 0 FAIL / 필터 제외 643, 0.088초, exit 0을 확인했다. 이는 전체 회귀 완료가 아니다. Native Clippy `-D warnings`도 37.69초, exit 0으로 통과했다. WASM32·all-target lint와 원래 대상 27건의 새 최종 검증·전체 nextest는 아직 완료되지 않았다.

요약과 직접 판독 PNG는 `mydocs/pr/assets/issue7445/completed-20261009/asset-fidelity/`에 보존한다. TSV 원본·빌드 출처·로그는 ignored `output/pr-review/7445-completed-20261009/stage424-asset-signature-spacing/`에 있으며 커밋하지 않는다. 전체 검증 보고 후 사용자 승인을 받아 PR을 진행한다.
