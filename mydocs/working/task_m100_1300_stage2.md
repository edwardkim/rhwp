## 보정 방식 변경 (작업지시자 피드백 반영)

1차(`base_y`를 sup 높이로 상한)는 여전히 위첨자가 괄호 위로 떠(baseline 위 26.0px) "아직 높다"는 피드백.
→ **상단 정렬**로 재설계: base 를 아래로 밀지 않고, 위첨자 상단을 base 상단에 맞춘다.

```rust
// layout_superscript, sup_shift >= 0 분기
base_y = (s.height - b.height).max(0.0);   // base가 sup보다 낮을 때만 내림
```
- 키 큰 base(`(1/6)`): base_y=0 → 합성 baseline = base 자연 baseline. 위첨자 상단 = 괄호 상단.
- 짧은 base(`x`,`6`): base_y=0 → 위첨자가 base 상단에 정렬(우상단 첨자).
