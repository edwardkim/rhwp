# Issue #7642 단계 135 — 분할 표 종료 뒤 저장 호스트 줄의 전진량

## 독립 근거와 원인

- 시작 소스 `5d0ff690ca4af9eacb719087e653e9babcdc319f`의 KTX 원본 전체 27쪽 중
  26쪽만 70.17973%다. 2쪽은 99.72705%로 개선됐다. 양쪽 쪽수는 27이다.
- 26쪽의 보정 전 소스 `4ed009b6027dba8ac9373c7006a74a073811a669`를 별도로 재출력했다.
  PNG SHA-256이 새 출력과 동일하고 일치율도 70.17973%다. 이번 셀 끝 줄간격 보정의 회귀가 아니다.
- 원본 문단 406의 비-TAC RowBreak 표는 25·26쪽으로 나뉜다. 표 이후 첫 본문인 문단 407은
  저장 위치 37878 HU이고 표 호스트 줄은 35478 HU다. 차이 2400 HU는 호스트 줄의
  높이 1500 HU + 줄간격 900 HU와 일치한다. 독립 MCP Print도 표 아래 이 줄 공간을 보존한다.
- 현재 26쪽의 표 외곽·내부 내용은 맞지만 그 뒤 본문 전체가 한 호스트 줄만큼 위에 있다.
  공백 호스트가 글자로 보이지 않는 상태와 줄 공간을 점유하지 않는 상태를 혼동하면 안 된다.

## 실제 경로와 보정 계획

| 단계 | 소비 경로 |
|---|---|
| 근거 생산 | `native_empty_host_rowbreak_line_advance_hu`: 저장 호스트·후속 줄의 사다리, 비-TAC·단일 양수 문단 오프셋 RowBreak |
| 통째 배치 | `typeset/table/host_spacing.rs`의 기존 호스트 예약, full table의 paint lane 종료 |
| 분할 요구·예약 | `typeset/table/block/prepare.rs`의 terminal_host_spacing → continuation budget·emit의 종료 예약 |
| 분할 실제 배치 | `layout_partial_table_item`의 마지막 조각 → content bottom 기록 후 다음 문단의 흐름 원점 |

저장 줄이 실제로 다음 흐름을 전진시킨 근거를 공통 helper로 확인해 분할의 종료 예약과
실제 흐름에 적용한다. 표 자체의 테두리·높이에는 더하지 않는다. 이미 호스트 줄을 소비한
경로는 중복 가산하지 않으며, 편집으로 무효화된 저장 위치도 증거로 사용하지 않는다.
문서 이름·문단 번호·2400 HU를 구현 조건이나 기대 좌표로 고정하지 않는다.
중간 조각, 실제 호스트 텍스트, 일반 물리 사다리와 통째 배치는 기존 계약을 보존한다.

## 검증

- 수정 후 실제 원본 KTX 전쪽, AIFT 영향 쪽, 셀 분할 대조군과 관련 줄 계약을 같은 새 빌드로 확인한다.
- Native/fresh WASM 관련 전쪽 90% 이상과 수식·간격 확대 판독 뒤 새 이름의 관계형 검사를 추가한다.
- 기존 골든을 새 SVG 해시로 덮거나 절대 픽셀 기대값을 옮겨 통과시키지 않는다.
- 현재는 원인 분석 및 보정 단계다. 전체 시험지·필수 lint·전체 회귀·WASM 검증 완료가 아니다.

증거는 ignored `stage134-terminal-cell-native`, `stage134-terminal-cell-review`,
`stage135-ktx-before-p026`, `stage135-ktx-p406-dump.txt`와 `stage135-ktx-dump-pages.json`에 보존했다.

## 비렌더링 분류 검사 보정

밑줄의 paint-only 분류 검사에 호출돼 있던 converted-HWP5 흐름 서식 helper는
HWP5 저장 컨테이너를 HWP3 전용 레이아웃으로 단정하는 잘못된 선행 assertion에서
실패했다. 이 helper를 분류 검사에서 제거하고 새 이름
`underline_changes_preserve_text_flow_classification`으로 원래 밑줄 분류 계약을 유지한다.
새 물리 배치 검사를 추가하거나 HWP3 플래그를 되돌리는 변경이 아니다. 실제 서식 편집
출력의 독립 Print 대조와 관계형 검사는 여전히 미검증 범위로 남긴다.

셀 분할·paint 소비 경로 보정의 Native Clippy는 종료 코드 0(1분 43초)이며
밑줄 검사 정리 후 source-side unit tier와 전체 target 검사도 다시 확인한다.
