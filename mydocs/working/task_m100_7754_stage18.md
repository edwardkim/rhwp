PR 준비까지만 진행하고 대기하는 범위와 #9316의 Windows 직접 PDF 기능 검사 제외는 유지한다.

완료했다. 뒤에 추가한 `a883a52521ee9640856c11b00e132de3ed0bfed0`는 검토·오늘할일·CI 기록
3파일만 바꿨다. 새 head의 성공 12개·skip 24개와 이전 전체 CI 성공을 확인했다.
2026-11-22 10:52:33 UTC에 실제 병합됐으며 merge SHA는
`622af208ee12c4cb16357d465e4802e7fd4726bc`다. 최신 `upstream/devel`도 이 SHA다.

리베이스 전 완료한 제품 후보는 `8f9fd0414ffcfb720fa4a601c79c4590480de0e8`이다.
Native 보호 23조건·2,023쪽은 고정 정본 표시값 대비 하락 0쪽이다. 정본 SHA는
`b2ea68f97a242d111522132b6c733f15a65b29b56e227943fd9c15f9c8d35597`로 유지했다.
화학·outline의 qualified 전쪽 실행과 sample10의 같은 producer 재개 결과를 문서 단위로
사용했으며 페이지별 최댓값을 골라 합치지 않았다. WASM은 완료된 22문서 1,260쪽에
sample16 세 저장본의 18·35쪽 미달 총 6쪽이 남았다. sample10은 진행 중이었으므로
전쪽 통과로 판정하지 않는다. 새 base와 후보에서 이 경계를 먼저 대조한 뒤 전쪽을 재검증한다.

새 #9318 기반 후보의 완료 근거로 사용하지 않는다.

root의 입력·검증 스크립트가 바뀌기 전에 이 작업 소유 controller 6개와 자식 등 18개
프로세스의 소유·시작 시각·그룹을 확인해 종료했다. 진행 중인 검사를 무응답 때문에
중단한 것이 아니라 실제 병합에 따른 새 base 검증으로 전환한 것이다. 중단한 실행은
