## Native 결과와 증적

Source255의 code SHA는 `b0d4bb102a2a4717a220da5002d660430d4e850f`이며 분리 후보
`local/7642-stage255`에서 실제로 빌드했다. 같은 `samples/exam_math_8.hwp`와
독립 Print PDF의 전체 1쪽 Native는 90.14556%다. 이전 후보의
89.22901%에서 올라 정확히 90% 이상 조건을 통과했다. 쪽수와 측정 범위가
일치한다. 입력 SHA-256은 `f29e0d92c45c51306a482c9304e70820a18f55ec8c44b6cdffc26db0e54645ff`,
PDF SHA-256은 `a4aab7757207e2cc4838afd739641d5ea1546f3b0a57944a5dbca3e7bf3e2d6f`이며 바이너리 SHA-256은
`3e351986a4fa56540657f88fd3d598e93ad3dff9228a561a9f89a6bb8748330e`다.

독립 한컴에서 정상 저장·Print한 구분자 진단 24개도 전체 1쪽 Native
98.17793%였다. math8의 원본·PDF를 진단 입력으로 바꾸지 않았다.
정상 둥근 괄호 슬롯, 작은 확장 괄호의 가로·세로 em 분리, 절댓값 슬롯을
각각 독립 입력과 Print에 연결한 후보다. 큰 괄호 조립·일반 글리프·
미측정 크기의 기존 경로는 해당 범위의 별도 검증이 필요하다.
