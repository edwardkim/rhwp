## 원인에 따라 보정한 실제 소비 경로

자세한 독립 관측값·반례·검증 계획은
[호스트 프레임과 #7969 보존 계획](../plans/task_m100_7642_host_frame_and_7969_preservation_20261017.md)에 기록했다.

- `layout_table_item`은 표 배치 전의 앞 간격 소비 상태를 사용하고, 표 배치 안에서
  실제 호스트 글줄을 그린 뒤에는 갱신된 뒤 간격·마지막 줄간격 소비 상태를 읽는다.
  실제 배치가 소비한 마지막 간격을 과거 사본 때문에 다시 더하지 않는다.
- 프레임 채움은 물리 행의 첫 구간에서만 들여쓰기·내어쓰기를 차감한다. 확정한
  실제 `RowSegment`에도 같은 소유 플래그를 남긴다. 평탄화 뒤의 구간 번호로
  첫 줄·후속 줄을 다시 판정하던 중복 처리를 제거했다. 배치는 그 플래그를 읽어
  들여쓰기와 가용 폭을 한 번 적용하고, 목록 마커도 같은 행의 뒤 구간에 다시 얹지 않는다.
- Native 이미지의 전체 원본 축소 분기는 최종 sampling이 nearest이면 mipmap을
  만들지 않는다. #7969의 원본 픽셀 흑백·디더링 및 빠른 미리보기 정책을 보존한다.
  일반 선형 그림의 축소와 crop의 strict 경계는 기존대로 처리한다.

원본 #1440의 47쪽 대 Print 46쪽 문제와 법령 미달 쪽은 아직 해결 완료가 아니다.
빈 문단 삭제·문서 ID 예외·고정 좌표로 화면을 맞추거나 기대값을 완화하지 않았다.
새 실물 회귀는 관련 전쪽 Native/fresh WASM 90% 및 직접 판독 전에는 추가하지 않았다.

## Canvas metrics 경고의 실제 출처

전체 단위 로그의 `Canvas2D measurement context unavailable`은
`canvas-metric-session.test.ts`가 의도적으로 null context를 반환한 음성 대조다.
해당 테스트도 통과했지만 예상 경고가 전체 로그에 실제 장애처럼 출력됐다.

접두어, Error 타입과 정확한 메시지, stale 상태 해제를 함께 검사하도록 보완했다.
