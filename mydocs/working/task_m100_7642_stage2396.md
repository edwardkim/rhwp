Issue: #7642. 도구 보정의 실행 기록이며 PR 준비 완료 판정은 아니다.

## 수정 전 실패와 수정 후 통과

`test_visual_sweep_pdf_tiled_fill.py`는 PDF 단위로 같은 색의 단일 사각형과
빈틈없이 인접한 200개 띠를 정의한다. 한컴 문서나 RHWP 구현을 정답으로
복사하지 않는다. 단일 면의 내부 RGB는 (64,128,191)이다. 기본 Cairo에서
같은 띠 면은 96 DPI의 (120,165,210), 144 DPI의 (111,159,207)로 바뀌었다.
정확한 RGB 반올림을 확인한 뒤, 의도한 띠 면 assertion에서 두 배율 모두
실패하는 것을 확인했다. 초기의 잘못된 192 기대값은 실패 증거로 사용하지 않는다.

공통 Cairo 명령에 `-antialias none`을 명시하고 정책 신원을
`poppler_cairo_tiled_rgb_v2`로 바꿨다. 전체/선택 쪽의 설정이 같으며 manifest에
antialias를 기록한다. 같은 테스트는 수정 후 통과했다. 균일 RGB·실제 한컴
Print의 파랑 채우기·쪽 선택·raw gate·문서 쪽수와 기존 Visual Sweep 검사를
함께 실행해 **101개 통과**, exit 0을 확인했다. 실행 명령은 다음과 같다.

```bash
PYTHONPATH=scripts/tests venv/bin/python -m unittest \
  scripts.tests.test_visual_sweep_pdf_tiled_fill \
  scripts.tests.test_visual_sweep_pdf_uniform_color \
  scripts.tests.test_visual_sweep_pdf_print_raster \
  scripts.tests.test_visual_sweep_raw_gate \
  scripts.tests.test_visual_sweep_document_pages \
  scripts.tests.test_visual_sweep
```

## 실제 미달 문서의 교차 진단

고정 producer 056d370f89의 동일 Native PNG를 사용한 진단이다. 원본 PDF는
바꾸지 않았으며 기본 Cairo 결과를 덮어쓰지 않았다.

| 입력 | 이전 Cairo raw 최저 | 새 설정 raw 최저 |
| --- | ---: | ---: |
| cell-background-layers | 82.81513% | 99.35383% |
| connected-backgrounds | 85.01286% | 99.34588% |
| continued-paragraph, 전체 3쪽 | 82.37321% | 99.95735% |
| flow-band-ownership | 84.74949% | 97.98758% |

이는 독립 렌더러 교차 진단이며 새 source의 Native/fresh WASM 제출 TSV가 아니다.
raw 식·내용 임계값·2px 허용 거리·90%·98%·0.01%p 기준은 바꾸지 않았다.
낮은 점수를 색상 경계 보정값으로 상쇄하지 않는다. 문자와 바깥 외곽의 antialias
변화도 영향 범위이므로 같은 설정으로 base/head의 필수 전쪽 검증과 직접 판독을
다시 수행해야 한다. 기존 raster policy와 다른 결과를 같은 baseline으로 섞지 않는다.

실행 로그·독립 PDF 재현·교차 진단은 ignored stage2390~2393에 있다.
이미 끝난 stage2380 Native 진단은 이전 정책의 결과로 보존하고, 대기 중이던
후속 sweep dispatcher만 종료했다. 실행 중인 빌드와 독립 Print는 중단하지 않았다.
새 코드·정책을 고정한 후 원본들의 검증과 남은 회귀 보정을 이어간다.
