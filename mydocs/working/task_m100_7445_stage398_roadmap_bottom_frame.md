# 단계 398: 로드맵 44쪽 표 하단 빈 공간 보정

## 사전 분석

- 사용자가 보정 후 44쪽 review PNG의 하단 차이를 확인했다. 내용 소속은 PDF와 같지만 현재 표 아래 경계가 위에 있다.
- 현재 부분 표는 시작 4행 컷 `[2,1,7]`, 종료 6행 컷 `[2,1,30]`이다. 마지막 ‘비정규직 모니터링 센터’ 문단 뒤 남는 물리 공간을 내용 높이로만 닫고 있다.
- 원본의 빈 표 앵커, 선언 첫 개체 높이, 바깥 여백과 본문 바닥이 일치하는 certificate는 존재한다. 하지만 `native_stored_multirow_closes_body_frame`은 문단 내부 reset 위주로 확인하여 원본 문단 사이의 물리 쪽 경계를 놓친다.
- 6행의 p26 저장 원점 59520 다음 p27 원점 0은 실제 CellUnit의 쪽 경계다. 이후 p28 줄은 1980으로 전진한다. 반복 원점이나 일반 문단 로컬 reset만으로 임의로 확장하지 않는다.
- 동일 본문 프레임 certificate와 실제 끝 컷의 비편집 원본 경계를 예약과 paint가 함께 사용하도록 보완한다. 새로운 컷이나 여백 숫자를 하드코딩하지 않으며 기존 내용 소속을 유지한다.

## 검증 계획

기존 partition 4와 로드맵 소속 대조군을 재실행하고, 43~45쪽 review PNG와 302쪽 TSV를 Native/fresh WASM에서 확인한다. 원본과 PDF는 동일하며 캡처는 8개씩 수행한다. 기존 302쪽 검증과 무암호 문서 비교의 frozen package를 보존한다.
