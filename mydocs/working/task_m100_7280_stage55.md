## 소유와 흐름

`state`가 private 데이터를 소유하고 불변 관측면만 외부에 제공한다. `DerefMut`·가변 필드
접근자를 제공하지 않는다. 기존 페이지/단 전이와 각주 예약은 state 내부로 옮기고, 도메인
조정자는 확정 항목 추가·흐름 전진·커서 기록·예약 명령을 호출한다. 읽기 전용 관측면은
기존 Query의 조회 시점을 보존하기 위한 것이며 새로운 IR이나 snapshot 복제본이 아니다.

구역의 공개 진입점은 유지하고 `section`에서 원본 문단 순회를 조정한다. 명시적 경계,
저장 좌표 경계, 빈 꼬리 흡수, 어울림, 제목 보호, 본문/표 배치, 앵커 후처리, 컨트롤 순회를
기존 순서에 연결한다. 조기 continue와 내부 탐색 루프의 continue를 구별한다.
각주·미주·지연 표 종료 순서와 WASM 재개 API는 유지한다.

모든 기존 조건·상수·테스트 기대값·baseline·ignore는 보존한다. 불명확한 기존 예외의
타당성을 새로 승인하거나 조판 결함을 수정하는 범위가 아니다.
