같은 설치 글꼴을 그대로 복사해 공급한 Native 대조군은 기존 캡처와 픽셀이

이 결과는 힌팅 소비의 영향 증거이며 최종 출력이나 글꼴 대체 계약이 아니다.
진단 글꼴은 private ignored output(stage2795)에만 보존했다. 실제 입력·
설치 글꼴·독립 기준 PDF·기준 점수는 변경하지 않았다.

## 코드와 소비 범위

기존 regular 프로그램 합성 굵기 분기에서 실제 선택한 glyph의 원 path를
받아 같은 TextRun 원점에서 fill+stroke한다. 장평·원본 폭·기울임은 같은 Font
기하를 사용하고 획의 사용자 좌표 폭을 유지한다. PDFium의 stroked text와
Skia getPaths의 실제 소비 경로를 독립 근거로 연결했다. 확인한 main 소스가
설치 binary와 같은 revision이라는 주장은 하지 않는다.

모든 glyph path를 먼저 확인한 뒤 그리며, path가 없는 경우에는 원래 폰트와
그리기로 fallback한다. 힌팅/기준선 설정은 path용 복사본에만 적용한다.
실제 bold face와 명시 outline pass는 기존 분기를 사용한다. shaping span은
별도 경로이므로 이번 cluster 경로의 결과로 그 범위까지 충족했다고 쓰지 않는다.

수정한 `text_replay.rs`를 1000줄 이하로 유지하기 위해 기존 face→Font 설정과
편집 부호 그리기 closure를 각각 `text_replay/fonts.rs`, `text_replay/marks.rs`로
분리했다. 기존 선택 조건·옵션·원점 인자는 그대로 전달한다. 세 파일은 각각
975/48/102줄이고 synthetic helper는 99줄이다.

## 검증 상태

변경 파일의 rustfmt와 증분 `git diff --check`는 통과했다. 새 source의 컴파일·
시각 개선·전체 회귀·반례 보존은 아직 미검증이다. 실물 회귀나 baseline을
추가/완화하지 않았다. 줄 무효화 보정과 함께 한 source에서 새 Native/fresh
WASM·전체 102개 문서·기준 대비 하락·#7969/#7970 기능 보존·필수 검증을
실행한다. 진행 중인 747 source의 고정 worktree와 공유 target 빌드를 변경하지 않는다.
