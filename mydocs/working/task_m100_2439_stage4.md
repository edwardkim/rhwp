## 1. 유효한 기준 파일 정보

사용자가 한컴 2024에서 가로 방향으로 인쇄한 Microsoft Print to PDF 결과를 기준으로
사용했다.

- Producer: `Microsoft: Print To PDF`
- 페이지: 10쪽
- 크기: A4 landscape 841.92×595.32pt
- 오른쪽 `31`·`비고` 열까지 잘림 없이 출력됨

Stage 4 당시 rhwp 중간 결과는 A4 landscape 841.88×595.28pt, 9쪽이었다. 이 9쪽 값은
최종 결과가 아니다.

## 2. 철회한 판정

최초에는 1~9쪽에 양식 코드가 같은 순서로 나타난다는 사실만으로 내용 페이지가 모두
대응한다고 판단하고, 10쪽을 trailing blank page로 분류했다. 이 판단은 페이지별
continuation과 10쪽 텍스트를 끝까지 확인하지 않아 생긴 오류다.

PDF 10쪽의 마지막 문장이 존재하므로 다음 결론은 모두 무효다.

- rhwp 9쪽과 PDF 10쪽의 내용 페이지 수가 일치한다.
- 10쪽 차이는 양식 누락이 아닌 blank-page 처리 차이다.
- 4쪽 이후의 안내문·제목 귀속은 #2439와 독립적이다.
- 기존 수정과 회귀 테스트만 유지하면 완료된다.

## 3. 당시 유효했던 부분

1차 수정으로 문제 표의 하단 37.3px 조각과 3.8px `LAYOUT_OVERFLOW`는 제거됐다. 그러나
표 전체와 서명란이 한 번씩 나타난다는 사실만으로 문서 전체 pagination이 정답지와
일치한다고 판정할 수는 없었다.

## 4. 후속 조치

- Stage 5에서 PDF 1~10쪽을 다시 매핑하고 표 분할, 표 하단과 서명문, 번호 줄글
  들여쓰기를 잔여 차이로 특정했다.
- Stage 6에서 저장 표·LineSeg flow를 복원하고 10쪽 출력, focused 회귀, WASM,
  페이지별 visual sweep과 사람 직접 review를 완료했다.
