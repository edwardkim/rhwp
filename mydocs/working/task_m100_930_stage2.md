# Task #930 Stage 2 완료보고서 — shortcut 자동번호 축소 계수 재유도

## 1. 측정 방법

`shortcut.hwp` 1페이지를 96dpi PNG로 렌더(`pdftoppm`, `rsvg-convert`)하고, 자동번호 "1" 글리프를 **flood-fill 연결성분 추출**로 측정했다. "1"은 단색 회색(`#aeaeae`) 연결 영역이므로, 내부 시드에서 회색 픽셀(110<v<218)을 BFS 확장하면 주변 검정 단축키 텍스트·점선 구분선 오염 없이 글리프만 분리된다.

## 2. 측정 결과

| 대상 | "1" 글리프 bbox | 폭 | 높이 |
|------|----------------|-----|------|
| PDF (한글 2022) | x 962–1056, y 540–726 | 95px | **187px** |
| 현재 렌더 | x 1040–1084, y 650–742 | 45px | **93px** |

PDF "1"이 현재 렌더의 **약 2.01배** (높이 187/93=2.01, 폭 95/45=2.11).

## 3. 목표 축소 계수 산출

- 자동번호 char 글꼴: 254pt = **338.67px** (96dpi)
- 현재 #874 축소: `inv = 1/max_ratio = 1/2.6775 = 0.3735` → 렌더 글꼴 **126.5px** → 글리프 93px
- 목표: 글리프 187px = 현재의 2.01배 → 목표 글꼴 = 126.5 × 2.01 = **254px**
- 목표 inv = 254 / 338.67 = **0.750**

> 글리프 높이 대 글꼴 크기 비율은 글꼴마다 다르므로 PDF 글꼴로 역산하지 않고, **동일 렌더러·동일 글꼴**의 현재 출력(93px @ 126.5px)을 기준으로 환산했다. 즉 "현재 글리프 93px → 목표 187px" 에는 우리 렌더러 글꼴 그대로 2.01배가 필요하다.

## 4. 공식 검토

목표 inv ≈ 0.750. 도형 스케일(sx=2.6775, sy=2.5130)에서 유도 가능한 후보:

| 후보 공식 | 값 | 글꼴(px) | 글리프(px) | PDF(187) 대비 |
|----------|-----|---------|-----------|--------------|
| `1/max_ratio` (현행 #874) | 0.3735 | 126.5 | 93 | −50% |
| `1/min_ratio` | 0.3979 | 134.8 | 99 | −47% |
| `1/min + 1/max` | 0.7714 | 261.3 | 192 | +2.7% |
| **`2/max_ratio`** | **0.7470** | **253.0** | **186.6** | **−0.2%** |
| flat `0.75` | 0.7500 | 254.0 | 187.4 | +0.2% |

도형 스케일에서 1차 원리로 깔끔히 유도되는 공식은 없다. `2/max_ratio`가 PDF 측정값과 가장 정합(−0.2%)하며, "현행 #874 계수의 2배"라는 단순 관계로 표현된다.

## 5. 확정

**축소 계수: `inv = (2.0 / max_ratio).min(1.0)`** 채택.

- 근거: PDF(한글 2022) 정합 측정값. `2/max_ratio`가 오차 −0.2%로 최적.
- 성격: **단일 샘플(`shortcut.hwp`) 기반 경험적 보정 계수**. #874 의 `1/max_ratio` 역시 문서화되지 않은 경험 휴리스틱이었고, PDF 측정으로 약 2배 과축소가 확인되었다.
- 한계: 등방 확대 글상자 샘플이 `shortcut.hwp` 1건뿐이다. 다른 등방 스케일 글상자 샘플이 확보되면 재검증이 필요하다 (구현 주석에 명시).
- `.min(1.0)` 으로 확대 방지 (`max_ratio < 2.0` 인 경우에도 글꼴을 키우지 않음).

## 6. 회귀 교차 점검

- `table-in-tbox.hwp` 2p (min_ratio=1.068): 판별자 (B) `min_ratio>1.5` 미충족 → 축소 자체가 비발동 → 계수 변경 영향 없음.
- `table-in-tbox.hwp` 1p 표 (max_ratio=1.079): 비발동 → 영향 없음.
- 계수 변경은 `min_ratio>1.5` 인 등방 확대 글상자에만 영향하며, 현재 코퍼스에서 `shortcut.hwp` 자동번호가 유일.

## 7. Stage 3 반영 사항

- 발동 조건: `max_ratio > 1.5` → `min_ratio > 1.5` (판별자 B)
- 축소 계수: `1.0 / max_ratio` → `(2.0 / max_ratio).min(1.0)`
- 주석 갱신 + 임시 디버그 출력 제거
