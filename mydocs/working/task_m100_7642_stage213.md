# 배경 그림과 같은 문단의 저장 표 줄 소유

Issue: #7642

## 근거와 실제 소비 경로

Source207 영어 원본 `samples/exam_eng.hwp`의 2쪽은 60.27373%다.
독립 기준은 `pdf/issue7642-exam-print/exam-02-exam_eng-hwp-print-2020.pdf`다.
새 review와 네 문서의 원점 trace는 ignored `stage210-source207-english-p002-review`,
`stage211-batch-flow.json`에 보존한다. 입력 SHA-256은
`7a5755a2f773fce4d295cbfeb1c5d722edb02c7f920bb067fa56940e8cd6a05b`다.

문단 103은 저장 원점 0의 명시적 단 시작 제목이다. 문단 104는 글 뒤 배경 그림
두 개와 TAC 표 하나를 소유한다. 표 본체와 바깥 여백을 합한 22207HU가
저장 줄 높이와 일치하며 다음 문단 원점은 `2254 + 22207 + 344 = 24805`HU로
같은 줄 상자를 닫는다. 배경 그림은 자체 문단 앵커를 소유하며 줄을 전진시키지 않는다.

`stored_first_tac_line`은 이 소유를 인증하지만 `prepare_coanchored_first_line`의
형제 개체 분류는 그림을 거절한다. `flow_table::place`가 일반 TAC로 돌아가면
실제 저장 표 원점 대신 제목 직후 누적 높이가 inline metadata에 기록된다.
`layout.rs`는 복원한 문단 원점보다 이 inline 위치를 우선하며 표 내용과 후속
문항이 위로 이동한다. 그림의 앵커 자체는 별도로 보존해야 한다.

## 보정과 반례

단 첫 원본 글줄과 물리 앵커가 모두 원점 0이고 편집·dirty·미주 경로가 아닐 때만
이 추가 경로의 단 좌표축을 인증한다. 글 앞/뒤 비인라인 그림·도형은 독립 장식으로
분류하되, 저장된 표의 완전한 줄 높이와 다음 줄의 정확한 연결이 유지되어야 한다.
확정된 표 원점과 줄 끝을 기존 commit 경로로 fit와 paint에 함께 전달한다.
그림을 생략하거나 원점을 표에 맞춰 이동하지 않는다.

자리차지 그림, 인라인 그림, 재조판·편집·양수 단 시작 원점, 저장 연결이 끊긴
입력은 새 경로로 수용하지 않는다. 기존 float/고정 장식 경계는 유지한다.
검증은 영어 전체, 국어 HWP/HWPX, 과학·사회·10월 실패 및 정상 대조군을 한
빌드로 비교한다. 아직 실행 결과는 미검증이며 90% 통과 전 새 회귀를 추가하지 않는다.
