## 축소 원인과 변경

10월 그래프를 BinData·실제 SVG image까지 추적했다. 원본은 WMF가 아니라
1126×1094·983×868 PNG이고 약 1/6 크기로 그린다. 독립 PDF는 같은 폭의 bitmap을
보존하며 가는 축이 보인다. Native의 mipmap 없는 표본과 Canvas의 기본 낮은 품질은
가는 선을 놓친다. 좌표를 유지하고 그림만 면적을 반영해 축소한 진단은 1쪽 raw를
88.52370%에서 BOX 90.27979%, bilinear 90.71427%, Lanczos 91.64466%로 바꿨다.
이 raster 변형은 제품 통과 증거가 아니다.

Native Skia·CanvasKit·Rust Web Canvas2D의 실제 소비 지점을 함께 고쳤다.
원본 전체의 축소에서만 mipmap 또는 high quality 저역 통과를 사용한다.
실제 canvas 변환·원본 픽셀 크기가 조건이며 문서명·쪽·좌표 핀은 없다.
잘린 source는 기존 경계를 유지한다. Canvas2D의 quality는 조기 반환에도 복원하고,
CanvasKit의 임시 mipmap은 draw 뒤 해제한다. 원본·배치·Print PDF·시각 지표를 바꾸지 않는다.
새 코드의 Native/fresh WASM 재출력과 lint·전체 Rust는 아직 실행 전이므로 미검증이다.
새 렌더링 회귀와 기존 기대값·golden·허용치는 이번 단계에서 바꾸지 않았다.

## 실제 검증 중 발견한 Node loader 오류

`npx tsc --noEmit`는 exit 0이다. 첫 `npm test`는 2029건 중 2018통과·9실패·2skip이며,
세 자식 러너가 제품의 `boxed-digit-metrics.json`을 `.json.ts`로 바꾸어 로드를 실패했다.
각 러너의 JSON import는 Node의 실제 JSON loader로 전달하도록 고쳤다.
기존 검사·음성 대조를 그대로 재실행한 결과 2029건 중 2027통과·0실패·2skip이다.
명령 실행 이전에 실패를 검출했고, 검사 기대값을 약하게 바꾸지 않았다.

## WMF 독립 Print 대조와 남은 범위

stage2044~2049의 작은 authored HWPX와 2020/2024 Print를 보존한다.
이는 한컴에서 저장한 정상 원본이라고 주장하지 않는 제품 세대 진단이다.
256색 vector/DIB는 2024에서 128·240을 유지하고, 눈에 보이는 257번째 색이 있는
vector/DIB는 131·246 등으로 확장된다. 2020의 bitmap 자원은 128·240을 유지한다.
따라서 모든 WMF를 일괄 밝게 만들거나 BMP 형식만으로 판단하는 가정은 부적절하다.

전체 합성 뒤의 전달 조건을 해결한 제품 출력이 아니므로 미검증으로 남긴다.
