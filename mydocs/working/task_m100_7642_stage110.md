## 분수 본체의 기준선 간격

분수 위첨자 확대에서 분자/분모의 간격도 공개 MATH 값과 독립 한컴 frame 사이에
차이가 남는 것을 확인했다. 글자 줄 분수는 이미 독립 font frame의 전체 높이와
기준선을 측정에서 사용하지만, 내부 분자/분모의 실제 배치는 공개 MATH shift를
사용한다. 같은 원본의 잉크와 전체 점유를 함께 바꾸도록 소스 font frame을 내부
배치에도 공급한다. 22pt의 기본 분수 frame은 기존 표에 없으므로 15개 크기의
보통 분수를 추가로 정상 한컴 저장/Print해 확인한 뒤 채운다. 임의 비율이나
문서 좌표로 누락된 값을 추정하지 않는다.

15개 기본 분수의 추가 저장/Print가 완료됐다. 기존 14개 크기의 높이·기준선은
모두 기존 font frame 표와 일치하고, 빠졌던 22pt는 5010 HWPUNIT·66%였다.
`font_frame_metrics::fraction_at_dpi`에 같은 출처를 기록했다.
`layout_fraction`은 일반 글줄의 분자·분모에서 첫/마지막 글줄의 독립 기준선을
소비하고, `logical_font_frame`도 같은 높이·기준선을 반환한다. prime·한글·복합
본체는 해당 일반 글자 분수의 자료로 추정하지 않는다. 기존 공개 MATH 경로는
그 밖의 구조에 남아 있으며 시각 미검증을 통과로 바꾸지 않는다.
