# #7642 내용 높이가 결정한 재조판 행의 병합 물리 띠

Issue: #7642. 수정 전 소스는 `63c14b3538815c30aafa52d234d2230b730b315b`다.

## 독립 관측과 반례

원본 #7028의 관측된 Print 글꼴에서 Native 6쪽은 41.08081%에서
98.83256%로 개선됐고, 5쪽은 97.60364%에서 98.23171%로 개선됐다.
1·2·4쪽은 유지됐으며 3쪽 75.99855%가 남아 있다. 기존 보정 53쪽과
#7969의 13쪽 Native 대조도 통과했다. fresh WASM과 최종 회귀는 미완료다.

3쪽의 빈 문단 17.1px는 Native와 독립 Print 양쪽에 존재한다. 이를 제거하지
않는다. 2쪽의 부분 20행은 내용 컷 뒤 물리 띠를 예약하지 않고 끝난다.
이어받은 병합 칸의 종료 24행은 실제 앞 조각의 작은 상자를 차감한 나머지
48.9px를 요구한다. Print의 해당 행은 약 43.79px다. 뒤 행을 줄이거나 위치를
옮기기 전에 앞 조각의 수용 상자를 확인한다.

작은 독립 대조군 네 개는 같은 글꼴·표에서 끝 빈 문단 0/3개와 전체/분할
쪽 예산만 바꿨다. 수동 저장 LineSeg는 넣지 않았다. `stage3096`의 각 입력
SHA와 MCP job·Print 경로는 ignored output 영수증에 고정했다. 실제 한컴
11.0.0.9136, engine 2020, PrintMethod 0, one-up, 입력 전처리 없음이다.
두 전체 출력은 Native 100%다. 빈 문단 3개 분할본은 다음 쪽의 13.3px 빈
문단을 양쪽 모두 보존하지만 앞쪽에서 Native의 물리 띠가 짧다. 빈 문단이
없는 분할본의 블록 이월 차이도 남아 있으며 통과 대조군으로 분류하지 않는다.

## 공통 규칙과 실제 소비 경로

재조판 일반 글줄 행의 내용 컷이 선택되고 같은 병합 칸이 뒤 행까지 이어지면
현재 쪽의 남은 물리 띠도 그 병합 칸이 소유한다. 선언 최소가 내용보다 클
때만 이 띠를 예약한다는 가정을 제거한다. 다른 칸의 단독 행, 저장 줄 프레임,
중첩 표·개체 유닛을 이 계약으로 재분류하지 않는다.

`reflow_row_physical_minimum`의 별도 최소 유무와 실제 재조판·병합 소유를
구분한다. `row_step`은 기존 실제 프레임 예산으로 같은 내용 컷을 선택하고
물리 상자를 예약한다. 수용한 높이와 `end_row_height_override`를 함께 반환해
emit의 PageItem·paint와 `accepted_straddle_fragment_units`가 같은 상자를 쓴다.
뒤 조각의 `straddle_page_band_relief`는 그 실제 수용 합을 차감한다. 내용 컷,
빈 문단·글줄 수, 저장 문단 유지 지시와 실제 페이지 예산은 완화하지 않는다.

## 검증 순서

현재 실행 중인 `stage3094`의 Cargo가 종료된 뒤 고정 `target/pr-review`에서
빌드 잡 8개로 빌드한다. 원본 6쪽, 작은 전체/분할 병합·빈 문단 대조군,
기존 53쪽과 #7969 13쪽을 같은 PDFium 153 조건에서 비교한다. 해당 범위의
후퇴를 보정하고 Native/fresh WASM·확대 판독 조건을 충족하기 전에는 새 회귀
기대값을 추가하지 않는다. 이전 Native 통과를 이 변경의 통과로 재사용하지 않는다.
