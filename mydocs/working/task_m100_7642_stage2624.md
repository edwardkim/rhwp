## 실제 소비 경로 보정

layout_partial_paragraph → layout_wrap_around_paras에서 실제 반환 끝점을
버리는 경로를 확인했다. 소비 장부는 마지막 간격까지 완료로 표시했지만,
호출자는 composed 줄의 마지막 간격을 빼고 커서를 재계산했다. 실제 그림과
후속 흐름의 생산 결과가 분리돼 간격이 사라졌다.

어울림 배치 함수를326줄의square_host_flow 모듈로 옮기고 실제 호스트를
그린 경우 반환한 끝점을 통째/분할 표 호출자에게 전달한다. 각 호출자는 표의
점유 끝과 이 결과의 최댓값을 소비한다. 실제 반환값이 있는 경우 composed
높이를 재계산하지 않으며 간격을 다시 더하지 않는다. 호스트를 그리지 않은
기존 경로와 별도 소유의 후속 어울림 문단의 처리는 보존했다.

새 source의 rustfmt·diff 확인은 통과했다. 빌드·시각·정식 회귀는 아직
미완료다. 현재 실행 중인ddb Native/WASM과 새base의 결과는 별도 producer로
보존한다. 새 실물 회귀나 기존 baseline 변경은 전쪽90%·쪽수·직접 판독 뒤에
수행한다. PR 준비·CI·머지·옵션2 기록·후속 처리는 아직 완료하지 않았다.
