# Task M100 #4969 W10-Q2-D2 — final emitted-run mapping

## 판정

Q2-D2는 **qualified**다. D1이 `ComposedParagraph`에 보존한 Q2-C outcome에서 final emitted run 전체와
정확히 같은 target 하나만 골라 scalar·UTF-8·UTF-16 범위를 대사하고, line width·bbox width·다음 run
origin을 동일 measurement advance에서 한 번만 산출하는 dormant mapper를 만들었다.

기계 판독 결과는
[`w10_q2_d2_emitted_run_mapping.json`](../tech/investigations/issue-4969/w10_q2_d2_emitted_run_mapping.json)이다.

## D2의 제품 경계

- 실행계획의 `productOutputChange=false`를 지키기 위해 mapper와 D0 table attach helper만 준비했다.
- `paragraph_layout`, `PageRenderTree` 조립, LayerBuilder, paint에는 D2 helper 호출을 연결하지 않았다.
- 실제 bbox·다음 origin 변경과 sidecar 제품 게시를 먼저 열면 D3 glyph-run lowerer 없이 layout owner만 바뀌므로,
  D4의 동일-boundary 원자적 activation까지 보류한다.
- 따라서 기존 render-tree·layer-tree·JSON 및 화면 출력 변화는 0이다.

## final emitted-run 대사

1. 문단은 최대 4,096 scalar까지만 스캔하며 UTF-8·UTF-16 offset vector도 같은 상한 안에서 만든다.
2. emitted `char_start + scalar count`로 절대 scalar 범위를 만들고, 문단의 UTF-8 slice가 실제 emitted text와
   byte-for-byte 같은지 확인한다.
3. emitted UTF-8 byte 수와 UTF-16 code-unit 수도 계산된 절대 범위와 각각 대사한다.
4. Q2-C final line 전체가 target 하나이고 emitted run 전체도 바로 그 target일 때만 채택한다. mixed
   prefix/suffix, target 일부, target 여러 개는 run을 분할하지 않고 거부한다.
5. final line width와 target measurement advance가 허용오차 안에서 같을 때만 measurement advance 하나를
   `line_width_px`, `bbox_width_px`, `next_origin_x_px`의 공통 owner로 쓴다.
6. Q2-C attempt ledger에서 measurement identity의 settings digest·font digest·glyph count와 같은 applied trace를
   찾아 D0 decision을 만든다. decision은 Q2-C final target measurement와 동일한 `Arc`를 보존한다.
7. attach helper는 대사한 range와 동일 `NodeId`를 D0 bounded page table에 원자적으로 전달한다.

## fail-closed와 보호 불변식

- outcome이 `DormantQualified`가 아니거나 이미 게시된 경우 거부한다.
- 빈 run, 4,096 scalar 상한 초과, scalar overflow, 문단 slice 불일치, 세 좌표계 불일치는 거부한다.
- W9 `layout_positions`가 이미 있으면 common sidecar와의 상호 배타를 위해 거부한다.
- display projection, RTL/bidi, field·note split, CharOverlap, border/background, decoration은 거부한다.
- exact target 없음, mixed/partial target, measurement scalar·width 불일치, applied trace identity 부재,
  유한하지 않거나 양수가 아닌 기하는 모두 typed reason으로 닫는다.
- 실패한 mapping은 decision이나 table entry를 만들지 않으므로 partial range publication은 0이다.
- trace에는 raw text·font bytes·host path를 새로 기록하지 않는다.
