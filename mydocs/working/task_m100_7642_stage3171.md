# #7642 단일 글줄의 물리 최소와 문단 종료 경계

Issue: #7642. 앞 단계 Native 후보는 `9a02ef911f`, 저장 줄 출처 보정은
`e28c1d2c3d`다. 앞 단계의 #7226 실패와 #7518 7쪽 하락을 그대로 보존한다.

## 실제 호출 경로에서 검출한 누락

`stage3166`에서 일반 80px·480px 행은 `CUT_BASE`에 도달하지 않는다.
`MeasuredTable::is_row_splittable`이 글줄 수만 보아 단일 글줄 행을 거절하므로
앞 단계에 마련한 물리 최소 분할 분기는 실행되지 않았다. 내용이 원자적이라는
사실은 빈 최소 공간까지 한 쪽에 들어간다는 뜻이 아니다. RowBreak 정책과
일반 재조판 유닛의 독립 최소를 함께 확인해 같은 분할 적격성을 사용한다.
그 판정을 rowspan 행의 먼저 실행되는 분기와 일반 행의 `split_gate`에 전달한다.
셀 단위·나누지 않음 정책의 기존 `intra_row_cut_here` 조건은 유지한다.

최소 공간의 소유는 칸별로 확인한다. 다른 열에 저장 줄이 있다는 이유로
일반 재조판 칸의 독립 최소를 지우지 않는다. 그 칸의 선언 최소가 행 전체의
실제 내용보다 클 때만 빈 최소 공간으로 인정한다. 이웃 칸의 저장 줄을
재조판 줄로 분류하거나 저장 정보 수용 조건을 완화하지 않는다. 같은 최소가
scan·paint의 상자 소유와 이어받기의 정확한 잔여 계산에 사용된다.

긴 종료 병합 대조군은 앞쪽 3줄과 뒤쪽 5줄을 보존했으나 뒤쪽 마지막 행이
20px 과대였다. 선언만으로 미지 행을 푼 뒤 앞 병합 칸의 재조판 내용이 커져도
뒤 제약의 옛 배분을 다시 사용한 것이 원인이다. 기존 실제 내용 요구를 한 번
모아, 일반 재조판 요구가 선언을 넘을 때만 초기 일반 행 하한에서 같은 제약을
다시 푼다. 측정과 배치는 같은 재계산을 사용한다. 저장 프레임의 제약·선언
축소·내용 하한과 기존 순서의 요구 보존을 유지한다. 별도 텍스트 측정을 추가하거나
마지막 행을 목표 좌표로 줄이지 않는다. #7685의 저장 줄 경로는 이 재계산의
대상으로 바꾸지 않는다.

## 회귀 보정의 독립 근거

#7518 7쪽은 빈 띠를 13px 늘리면서 가운데 정렬 글자가 6.5px 이동했다.
단순 세로 정렬 조건으로 대상을 숨기지 않도록 두 반대 대조군을 Print했다.
같은 문서를 위 정렬로 바꿔도 7쪽 종료선은 426.381px로 유지되고, #7028의
40행을 가운데 정렬로 바꿔도 3쪽 종료선은 1043.977px로 유지된다. 따라서
세로 정렬 자체가 종료 프레임 차이의 근거가 아니다. `stage3172`의 여러 문단과
`stage3173`의 올바른 `hp:t/hp:lineBreak` 한 문단 대조군은 모두 한컴 Print에서
앞쪽 5줄과 같은 137.683px 경계로 닫힌다. 처음의 run 직속 lineBreak 대조군은
한컴이 무시했으므로 문단 내부 컷의 증거에서 제외한다. 문단 수로 대상을
분리하지 않는다.

#7028의 40행은 선언 164.067px가 그 쪽에서 선택한 내용 점유 152.7px보다 크며, #7518의
7행은 선언 80.72px보다 내용이 크다. 일반 칸의 전체 내용 점유는 선언 프레임을
포함하지 않는 `row_complete_cut_content_height`에서 조회한다. 이웃의 병합 칸이
현재 행을 넘어 계속되면서 선언이 그 칸의 전체 내용보다 큰 경우도 독립 최소의
소유자로 인정한다. scan과 paint가 같은 판정을 소비하며 단순 NoLS 출처만으로
빈 띠를 확대하던 분기를 제거한다. 재조판 원자 줄의 분할 적격성 누락과 긴
종료 병합의 제약 재계산도 같은 후보에 포함해 묶어서 검증한다.

현재는 구현 보정이며 이 후보의 실행 결과는 아직 없다. 기존 29건 중 #7226
1건 실패와 #7518 7쪽 95.54841%는 이전 `9a02ef911f`의 결과로 유지하며,
독립 기대값·기존 검사·허용치를 변경하지 않았다.

현재 단계는 원본·대조군의 전체 Native/fresh WASM, 새 회귀 추가와 최종 PR
준비가 완료되지 않았다. 빌드·로그·일치율·직접 판독은 source SHA별로 구분한다.
