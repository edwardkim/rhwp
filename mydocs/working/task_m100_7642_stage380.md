# Stage 380 — 빈 본체 첨자의 기준선과 실제 Print 대조

Issue: #7642
수정 전 코드: `1098dc0dc414ad889fd4cdd9f188b6050a633c93`
검증 base: `22317614b03722e95349a1d3d71c86923363c6f5`

## 근거와 남은 차이

2023년 9월 HWP의 전20쪽 Native 최저값은 96.74020%이고 15·16쪽은
97.04759%와 98.36188%다. 수식 누락을 해결했으나 15쪽의 순열·조합 식을
같은 배율로 확대하면 빈 본체에 붙은 첨자의 세로 위치가 독립 Print와 다르다.
페이지 점수 통과로 이 차이를 면제하지 않는다. HWPX와 fresh WASM도 같은
원본·기준 출력으로 확인한다.

`it _{7} rm P it _{4}`의 두 첨자는 글꼴 전환 뒤 빈 본체에 붙는다.
현재 `Empty`는 높이와 기준선이 0이고, 첨자 배치는 그 값을 일반 글줄의
기준선 대신 사용한다. 뒤 P의 Row 정렬에 의해 빈 본체 첨자의 기준선도
0에서 정렬되어 정상 글자 뒤 첨자와 다른 세로 축이 생긴다.

## 생산·소비와 보정

`parser_terms::parse_element` → `try_parse_scripts(Empty)` →
`layout_subscript/superscript/subsup` → Row 기준선 정렬 →
수식의 흐름 메트릭·paint가 같은 배치 상자를 소비한다.

한컴 문서의 **첨자 본체로 사용되는 명시적인 Empty**만 기존 빈 글줄 상자로
측정한다. 폭과 잉크는 0이고 글자 크기의 기준선 프레임만 가진다.
일반 Empty의 출력·오류 입력 처리·공개 LaTeX 경로를 바꾸지 않는다.
오른쪽·왼쪽 첨자는 같은 본체 프레임을 소비하며 수식 문자열·문서 ID·
화면 px 위치를 조건으로 사용하지 않는다.

## 검증 범위

- 원본 2023년 9월 HWP/HWPX 전40쪽의 Native/fresh WASM TSV와 쪽수.
- 순열·조합·이항 확률식의 첨자, 본문 기준선, 앞뒤 간격을 확대 대조.
- 명시적인 빈 본체/빈 첨자와 일반 본체, 글꼴 전환, 구조 명령 오류의
  기존 독립 한컴 진단 문서. 미달 진단을 통과 fixture로 보고하지 않는다.
- 새 관계 회귀는 관련 문서의 양쪽 전쪽 90% 이상과 직접 판독 뒤 등록.
- public LaTeX 호환 검사와 이미 등록한 내용/소유 관계의 무회귀.

독립 Print와 기존 정상 저장 진단을 사용한다. 로그·TSV·중간 산출물은
