### 결함

`samples/hwp3-sample14.hwp` (및 HWP5/HWPX 변환본) 의 그림 (bin_id=2, 149.9×41.9mm, tac=true) 내부 콘텐츠 누락. 한컴 한글 2022 PDF (권위 자료) 와 시각 다름.

### 본질 진단 (Stage A/B/C)

#### 1차 본질 — BMP MIME 미지원

rhwp 가 HWP 의 WMF/EMF image 를 SVG 로 변환할 때 inner BMP image 의 data URI 가 `data:image/bmp;base64,...`. **rsvg-convert (SVG renderer) 가 BMP MIME 미지원** → image 누락.

**증거**:
- BMP 자체는 정상 (sips 로 직접 변환 시 terminal screenshot 표시)
- inner SVG 만 별도 rsvg-convert: BMP image 누락

#### 2차 본질 — WMF SVG converter 의 viewBox 부족

WMF binary 의 SetWindowExt 가 actual element bbox 보다 작은 경우, `convert_wmf_to_svg` 의 결과 SVG 의 viewBox 가 image element 의 bbox 를 cover 못 함. rsvg-convert 가 viewBox 밖의 element 를 잘라냄 → image 누락.

**증거**:
- inner SVG viewBox = `0 0 4231 1189`
- image 위치: `x=329 y=1536 width=2119 height=768`
- **image y=1536 > viewBox height=1189** → 영역 밖
- viewBox 를 1189 → 3000 으로 확장 시 image 정상 표시 (검증 완료)

### 정정

#### Fix 1: BMP → PNG 변환

`src/emf/converter/player.rs:368` `dib_to_bmp_data_url`:
```rust
if let Some(png) = crate::renderer::svg::bmp_bytes_to_png_bytes(&bmp) {
    format!("data:image/png;base64,{}", base64::encode(&png))
} else {
    // fallback BMP
}
```

`src/wmf/converter/svg/util.rs:20` `Bitmap::as_data_url`:
```rust
if let Some(png) = crate::renderer::svg::bmp_bytes_to_png_bytes(self.as_slice()) {
    format!("data:image/png;base64,{}", STANDARD.encode(&png))
} else {
    format!("data:image/bmp;base64,{}", STANDARD.encode(self.as_slice()))
}
```
