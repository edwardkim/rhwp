# Stage 324 — 기존 검사 위치 보존과 파서 책임 분리 보정

Issue: #7642

Stage 323의 기존 검사 파일 이동이 base 고정 unit-tier 검사에서 신규 cfg(test)
module/support item으로 검출되어, 모든 기존 검사를 `parser.rs`의 원래 namespace와
위치로 복원했다. 정책·허용 기준선을 완화하지 않았다.

대신 기존 production atom/group 함수를 자식 모듈로 옮겼다. 공통 parser 상태와
입력 소유 계약은 그대로 사용한다. 함수 이동의 역변환으로 코드 보존을 확인했으며
증거는 ignored `stage324-parser-move-proof.json`에 있다.
`parser.rs`는 992줄, atom/group 모듈은 각각 144/167줄이며 모두 1000줄 이하다.

- `cargo fmt --all`: 통과.
- `rust-unit-test-tiers --check --base-ref 22317614b03722e95349a1d3d71c86923363c6f5`:
  통과. 4106 tests / 296 modules / 28 cfg support items.
- Native/fresh WASM 정식 빌드·정식 파서 검사·세 Clippy gate: 아직 미검증.

Stage 323의 Native 시각 결과는 해당 source SHA의 진단 증거로 유지한다.
추가 분리 뒤 head의 최종 전쪽 TSV·확대 판독을 대신하지 않는다.
현재 미해결 범위와 PR 보류 판정은 유지하며 다음 검증을 진행한다.
