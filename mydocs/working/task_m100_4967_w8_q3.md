## 4. LineSeg feature detection의 한계

W3에서 target 위험량 43,374자는 모두 stored lane이고 fresh 위험량은 0이다. 그러나 stored LineSeg의 존재는
validity가 아니다. 현재 읽기 전용 query는 다음 두 관측을 한 snapshot에 제공하지 않는다.

1. Font Decision Trace·text layout이 사용한 정확한 TextLine frame과 context
2. 그 frame이 stored-row cache를 admit/reject/unmodelled 중 무엇으로 판정했는지

독립 `export-render-tree`와 `rhwp-q-text-layout`의 run set이 다른 2문서에서 target 4,397자를 frame에 조인할
수 없었다. 이 문서는 악화·무변화로 추정하지 않고 `unmodelled`로 분류했다. 공개 결과의
`cacheAdmissionObserved=false`, `validityClaim=false`는 이 한계를 숨기지 않는 보호 불변식이다.
