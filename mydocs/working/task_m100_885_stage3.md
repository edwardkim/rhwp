## 2. 주 측정 — `samples/table-in-tbox.hwp` p1

| 항목 | RMSE (%) |
|------|---------|
| PDF vs Before SVG | 26.863 |
| PDF vs After SVG  | 26.797 |
| **개선폭 (Before − After)** | **+0.066 %p** |
| Before vs After [SVG 변화량] | 3.904 |

### 2.1 해석

- **SVG 자체는 의미 있게 변화**(3.9% RMSE) — 텍스트 좌표/폭 메트릭이 별칭 매핑으로 보정됨.
- **PDF 와의 차이는 거의 동일**(26.86% → 26.80%) — 별칭 추가만으로는 PDF 픽셀 RMSE 가 거의 줄지 않는다.
- 근본 원인: `rsvg-convert` 는 HY 폰트가 시스템에 없으면 `Noto Serif/Sans CJK KR` 글리프로 렌더한다. 메트릭 별칭은 폭/베이스라인 계산에만 영향을 주고, **글리프 모양 차이는 변하지 않는다**. 따라서 픽셀 RMSE 중 글리프 모양 기여분 (대부분)은 보정되지 않는다.

### 2.2 개선이 일어난 영역 (정량)

- 텍스트 요소 개수: 변경 없음 (102 개)
- 텍스트 x 좌표 분포: unique 100 개 유지, 미세 위치 조정
- 표 셀 안 글자 사이 간격 / 줄바꿈 폭 분포가 메트릭에 맞춰 재계산됨
- IR(`rhwp dump`) 출력 완전 동일 — 레이아웃 IR 단계 변경 없음 확인
