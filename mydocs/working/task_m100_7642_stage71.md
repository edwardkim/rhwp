# #7642 Stage 71 — 분할 진입 예산 공유와 수식 논리 프레임 보정

Issue: #7642

## 독립 근거와 원인

sample16 한컴 Print의 23쪽 마지막 본문은 세 줄이다. Stage 69의 Native는
92.45337%이지만 두 줄만 소유하고, 이월된 한 줄 때문에 24쪽은 55.60151%다.
흐름 끝은 본문 안에 들어가므로 점수만으로 완료 판정하지 않는다.

`paragraph::prepare_fit_budget`는 `state::take_paragraph_safety_margin`이 반환한
실제 여백으로 전체 fit 예산을 만든다. 그러나 분할에는 소비 전 기본 여백만
전달해 저장 앵커·부분 표·한 번만 적용하는 면제 결과를 잃는다. 실제 여백을
진입 조각에 전달하고, 분할 전·후 쪽 전환에서는 기존 기본 여백으로 돌아간다.
예약 수치 자체를 줄이거나 문서별 예외를 추가하지 않는다.

MCP 2024가 저장하고 Print한 36개 CJK/숫자 분수 대조는 800/1200/1600HU에서
확장 둥근 괄호의 한쪽 예약 폭 3/8 em, 대괄호 1/2 em의 논리 격자를 확인했다.
기존 분수 프레임이 바깥 괄호에서 끊어져 흐름 높이도 달라진다. 논리 프레임이
확인된 확장 구분자의 폭을 공유하고 괄호를 통해 같은 분수 프레임을 전달한다.
기존 작은 구분자와 근거 없는 다른 구분자의 경로는 별도로 검증한다.

## 검증 계획

두 원인의 변경을 함께 Native 빌드·포맷·Clippy하고, sample16 영향 쪽과
36개 독립 수식 대조를 출력한다. 진입 여백·분할 컷·소유 줄과 다음 쪽 내용,
수식 폭·높이 및 확대 PNG를 대조한다. 관측 전에는 개선 완료로 기록하지 않는다.
전체 55개 원본·853쪽의 Stage 69 Native/fresh WASM 측정은 고정된 이전
코드로 계속하며 새 코드 결과와 구분한다. 관련 관계형 회귀와 최종 전체 게이트는
90% 이상 및 직접 판독 이후 진행한다. HML 제외 범위를 유지한다.

## 첫 관측과 lint 보정

9832413f5 Native 빌드는 exit 0, 441.54초이고 fmt 검사도 exit 0이다.
CJK 대조 두 쪽의 최저 점수는 98.14749%다. 새 1쪽 review PNG를 직접
표시했으며 수식 확대 판독과 원본 문서 전체 결과로 승격하지 않는다.

진입 여백 0, 이월 뒤 기본 여백 4가 실제 로그에 확인된다. 이전 0..2,
2..6에서 세 번째 줄의 이월이 해소됐고 전체 쪽수는 64로 유지됐다.
원본 Print와 최종 시각 대조는 진행 중이다.

exit 101이었다. 계산된 값은 유지하고 `unwrap_or`로 수정한다. 새 source의
빌드·lint·시각 결과를 별도로 기록하며 실패한 lint를 통과로 보고하지 않는다.
