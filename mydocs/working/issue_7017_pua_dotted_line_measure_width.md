# #7017 — 한컴 PUA 점선 `U+F081C` 를 측정만 0폭으로 봐서 절취선이 208.8px 밀린다

## 무엇

`2528375`([별지 2] 전국학생과학발명품경진대회 출품작품 접수(반출)증) 1쪽의 절취선 줄
`┈┈…┈ 절 ┈┈┈┈ 취 ┈┈┈┈ 선 ┈┈…┈` 이 오른쪽으로 **208.8px** 밀려, 글자 `절 취 선` 이
줄 중앙이 아니라 오른쪽에 놓이고 뒤쪽 점선이 용지 우단(793.3px)을 63.2px 넘어
잘려 나간다.

## 왜 — 같은 코드 포인트에 정책이 셋이었다

| 위치 | 정책 |
| --- | --- |
| `src/renderer/layout/text_measurement.rs` | 폭 **0** (`U+FFFC` 오브젝트 자리표시자와 같은 갈래) |
| `src/renderer/composer.rs` `expand_pua_display_text` | `continue` — 아예 안 그린다 |
| `src/renderer/hancom_pua.rs:88` | `(0xF081C, "┈")` — 반각 점선으로 그린다 |

실제 렌더는 셋째를 탄다. SVG 는 글자마다 `0.5em × 장평 0.95 = 6.9668px` 만큼 전진해
`354.85 → 856.5` 까지 그리고, 한컴의 글자별 전진(평균 6.987px)과 0.3% 안에서 같다.

그런데 정렬에 쓰인 줄 폭은 `6 × 6.9668 + 3 × 13.9336 = 83.60`, 즉 **PUA 60자를 전부
0으로 센 84.0px** 이다. 가운데 정렬이 이 폭으로 잡은 시작 x 는
`75.6 + (642.5 − 84.0) / 2 = 354.85` 로 관측값과 소수점까지 같고, 밀림량도
`(501.6 − 84.0) / 2 = 208.8px` 로 정확히 맞는다.

`hancom_pua.rs:14` 의 모듈 계약은

> 원문 IR은 이 표로 바꾸지 않고, SVG/Canvas/HTML paint **및 폭 측정**에만 투영한다.

인데 지켜지지 않는 상태였다. 같은 표의 다른 괘선 조각(`F0806` `F0807` `F0810`
`F0832` `F0848`)은 0폭 분기에 걸리지 않아 폴백 0.5em 으로 떨어지고, 그 값이 마침
렌더 폭과 같아 우연히 맞는다. **`F081C` 만 어긋났다.**

## 어떻게

0폭 분기에서 `U+F081C` 를 뺀다. 오브젝트 자리표시자(`U+FFFC`)만 남는다.

```rust
if c == '\u{FFFC}' {
    return CharWidthDecision {
        width_source: "inlineObjectPlaceholder",
        base_width_px: 0.0,
        final_width_px: 0.0,
        …
    };
}
```

새 분기·새 상수를 만들지 않는다. 다른 `hancom_pua` 괘선 조각과 같은 경로로
떨어질 뿐이다.

```text
             줄 시작 x   마지막 글리프 우단 x
  한컴 2020    145.4       647.7
  결함         354.9       856.5      ← 용지 우단 793.3 을 63.2 넘는다
  수정 후      145.9       647.9      ← 오차 0.5 / 0.2px
```

## `#677` 잠금이 정본과 어긋나 있었다

`tests/svg_snapshot.rs` 의 `issue_677_bokhakwonseo_page1` 주석은

> 2. U+F081C HWP PUA 채움 문자 폭 (0) … 폭을 0 으로 처리하는 동작을 잠가둔다.

라고 그 규칙을 명시적으로 잠그고 있었다. 그런데 저장소에 있는 그 문서의 한/글 2020
정본(`pdf/복학원서-hwp-2020.pdf`)을 재면 **폭 0 쪽이 틀렸다**.

```text
  '복학원서접수증' 줄 시작 x     정본 286.27px
                               폭 0  291.42px   (+5.15)
                               정정  286.29px   (+0.02)

  'Filing Receipt'             정본 332.27px
                               폭 0  337.92px   (+5.65)
                               정정  332.79px   (+0.52)
```

쪽 전체 29줄로 대조해도 x 오차 **중앙값 0.44 → 0.28px**. 최대 오차 25.74px 는 전후
동일하다(별개 축). golden 을 정본 값으로 갱신했다.

`hancom_pua.rs:86` 이 같은 문서에 대해 "한글 2022 PDF 실측: 작은 사각 점 ~9개가
이어진 대시 조각" 이라고 적어 둔 것과도 맞는다 — 한컴은 이 문서에서도 그 글자를
보이게 그리고 폭을 준다.

## 사실과 달라진 주석 셋을 정정했다 (계약은 유지)

  지우므로(`continue`) `display_text` 로 재면 글자 수가 줄어 폭이 모자란다" 로

  시험 자체는 바뀌지 않고 그대로 통과한다.
