# #7642 새 적격 회귀의 후속 본문 소유 검사 정정

`stage3416`의 source `32c55333996d36f1abcd712614c7030d9c6a38c3` 집중 실행은
컴파일 완료 뒤 새 검사 1건이 실패했다. 모든 TextRun이 셀 안에 있어야 한다는
새 검사 자체의 가정이 잘못됐다. `stage3438`의 불변 CLI 실제 출력에서 마지막
8쪽에 원본의 `AFTER TABLE FOLLOWER`가 표 밖 본문으로 존재함을 확인했다.
빈 문자열이나 렌더 결함으로 분류하지 않는다.

원본·독립 PDF·전쪽 100% 증적은 그대로 보존한다. 행 표식 12개의 순서·셀 소유·
포함·누락·중복·쪽 소유를 유지하고, 후속 본문은 별도로 정확히 한 번, PDF의
8쪽 본문에 있으며 표의 끝 조각 뒤에 놓이는지 검사한다. 중요한 기준선 ±2px는
기존 독립 PDF 글자 행렬과 양쪽 raw 100% 선행 조건을 유지한다.

이 정정의 실행과 수정 전 CLI의 원래 소유 실패 증명은 아직 다시 실행하기 전이다.
`stage3416`의 실패를 PASS로 바꾸지 않으며, 대기하던 진단·후속 빌드가 그 오류로
종료된 사실도 보존한다. 정정 소스에서 같은 새 검사와 나머지 집중 검사를 함께
실행하고, 불변 CLI를 바꿔 원래 소유 결함 검출을 다시 확인한다.
