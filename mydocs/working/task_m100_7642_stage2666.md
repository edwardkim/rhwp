## 생산 결과와 소비 경로

`stored_lines::stored_frame_prefix_consumed_before_page`는 앞 실제 쪽 끝과
현재 첫 항목의 소유를 읽는다. `section::stored_reset`과 함께 다음 지점에 전달한다.

- `whole_decision::decide_whole_fit` → `whole_fit::inspect`의 자동 되감김·넘침 판단
- `place_after_failed_fit` → `split_entry::inspect_entry`의 저장 전체 문단 이월 판단
- `prepare_forced_page_boundary`의 자동 anchored/internal reset 후보

명시적 page-start 후보와 독립 표·각주 경계의 소유는 변경하지 않았다.
줄 스캔의 다단·전면 TAC 개체 경계는 이 본문 prefix 규칙과 적용 범위가 다르다.
선택한 강제 경계를 소비하는 기존 스캔·실제 부분 문단 배치 흐름은 유지했다.

1019줄이었던 paragraph 모듈에서 전체 수용 조정 함수를
`paragraph/whole_decision.rs`로 옮겼다. 공개 조정 경로 이름과 상태 변경 순서는
유지하고, 원 모듈을 1000줄 아래로 줄였다.
