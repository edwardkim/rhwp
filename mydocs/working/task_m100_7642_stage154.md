# #7642 Stage 154 — 재조판 줄의 실제 fit과 누락 글리프 공급

Issue: #7642

## 구현 근거

Stage 153에서 문단 439는 원본 저장 줄이 없는 일반 본문이다. 앞 간격과 글줄을
합친 실제 점유는 본문 안에 들어가지만 일반 4px drift 여유가 쪽 소속을 바꾼다.
별도 개체·Square 배제 띠가 없고 구성된 줄의 높이·간격이 format 결과와 같을 때는
paint가 소비하는 실제 재조판 상자로 fit한다. 기존 저장 사다리와 개체 높이 경로를
이 조건의 증거로 추측하지 않는다. 바깥 float의 명시적 점유·각주 예약은 계속 예산에서 소비한다.

경로: `format_paragraph_for_flow`의 실제 composed 줄 → `FormattedParagraph`의 줄
메트릭/앞뒤 간격 → `prepare_fit_budget`의 여유 → `insert_fitted_paragraph`와
`apply_full_paragraph_flow`의 소비 → `layout_composed_paragraph_in_frame`의 같은
composed 줄 메트릭. 줄 수·메트릭이 다른 경로는 면제 대상에서 제외한다.

휴먼명조에는 U+2024가 없으며 독립 Print는 Haansoft Batang으로 이 문자를 그린다.
공식 설치 파일 HBATANG.TTF의 잘못된 cmap U+FFFF 종료 매핑은 실제 Chrome OTS가
거부한다. 원본/시스템 파일은 바꾸지 않고 기존 `svg_outline_font_data`가 사용하는
종료 매핑 보정과 윤곽선 내장 경로를 적용한다. 특정 문자를 바꾸거나 좌표를 더하지 않는다.
일반 serif fallback에 정식 family를 연결하고, 실제 주 글꼴에 없는 사용 문자만 그
대체 글꼴이 제공하는지 확인해 CSS를 공급한다. 주 글꼴에 있는 글자는 그대로 유지한다.

## 검증 범위

한 번의 Native 빌드 뒤 대조군 9쪽과 sample16 전체 64쪽을 검증한다. 페이지 21~27의
쪽 소속 및 점 리더를 새 review PNG로 직접 확인한다. 줄 수가 바뀌거나 물리 개체를
포함하는 경로는 여유 면제 조건을 만족하지 않아야 한다. 최종 전체 55문서/853쪽의
Native·fresh WASM, 실패한 회귀와 필수 lint는 별도 최종 검증으로 남는다.
전쪽 90% 및 확대 판독 전에는 새 배치 회귀/기대값 변경·PR 생성을 보류한다.

설치 파일은 Git에 포함하지 않는다. 증거는 ignored output의
`stage154-font-sentinel-proof.json`과 `stage154-font-exact-result.json`에 보존한다.

새 43쪽 review에서는 Footer 컨트롤을 소유한 본문 691 진입에서 원본 앞 간격
568HU가 소실되는 것을 확인했다. Footer의 별도 프레임 소유와 본문 줄의 흐름을

이 기록은 두 경로의 보정 완료나 전체 검증 통과를 뜻하지 않는다.
