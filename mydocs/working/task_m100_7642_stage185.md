# #7642 Stage 185 — 정렬 칸과 첨자 인자의 소속 계약

Issue: #7642

## 출발점과 근거

현재 head는 `b39fd3579e8da64d5e11c2bd91bcc5a790c85e21`, 검증한 구현 source는 `c49fe2f9fae0fc4f2e823a216dbcdff3bb3e5e65`다. base는 `552f5228d2dbfd6046c838f14241704f1bcb8a05`다. Native 구조 30쪽은 최저 99.20409%로 통과했지만 프레임의 EQALIGN 9–11쪽, 카탈로그 14·17쪽, 오른쪽 SUB/SUP 경계는 미달이다. 왼쪽 첨자 5개 확대는 100%이나 근호 인자의 소속과 오류 구문은 미검증/미충족이다. 전체 검증·PR 완료를 뜻하지 않는다.

공식 수식 형식 1.3의 EQALIGN은 & 기준 칸 맞춤이며, 단어·분수·근호·괄호·첨자의 새 독립 Print와 원 카탈로그의 열 소속이 이를 뒷받침한다. Stage 182 구조 Print는 같은 수식 레코드의 두 행 원점을 다르게 출력해 충돌한다. 이 자료는 보존하고 출처 문제를 계속 확인한다. 특정 파일·AST 종류·크기로 분기해 충돌하는 출력을 모두 흉내 내지 않는다. 공통 칸 원점 계약을 바로잡고 각 대조군의 실제 결과와 남은 차이를 구분한다.

## 구현 경로와 반례

- `EqAlign.rows → layout_aligned_rows의 칸 최대 폭/연산자 경계 → left/right LayoutBox 원점 → SVG/Canvas/paint의 EqAlign 자식 배치`를 추적한다. &는 전 행이 공유하는 칸 경계이며 개별 행의 폭으로 오른쪽 열을 전진시키지 않는다. 줄바꿈만 있는 Row는 별도 칸 맞춤이 없는 기존 빈 왼쪽 항으로 표현한다.
- 중위 SUB/SUP과 LSUB/LSUP은 앞 원자/명시 그룹의 첨자 소속이다. 근호의 인자 파싱 중 뒤 첨자가 그 인자에 붙는지, 바깥 그룹 전체에 붙는지를 추가 Print로 대조한다. 단순 원자·분수·명시 그룹·앞뒤 본문·양쪽 슬롯·순서 역전·누락 인자·적분을 포함한다.
- prefix 오류를 뒤 내용을 삭제해 맞추지 않는다. 독립 Print의 실패 범위와 정상 남은 그룹/행을 확인하고 문서 문법의 오류 복구를 정한다. 공개 legacy parser의 호환 동작과 문서 생성 구문은 구분한다.
- 기대값은 사양·독립 Print에서 정하며 90% 미만의 카탈로그 golden을 새 출력으로 갱신하지 않는다. 새 관계형 회귀는 Native/fresh WASM 전쪽과 확대 선행 조건 뒤에 추가한다.

## 구현·독립 근거와 사전 검사

추가 Print 21·6·8쪽은 `pdf/issue7642-script-ownership-diagnostic/README.md`의 파일/명령별 job·SHA·관측에 보존했다. 한컴 2020 정상 저장 뒤 PrintMethod=0으로 출력했다.

- EqAlign AST는 각 행에 & 표시가 있는지 보존한다. 표시가 하나라도 있으면 첫 칸도 공유 열에 맞추며, &가 전혀 없는 묶음은 원 행 원점을 유지한다. 빈 오른쪽 칸으로 표시 유무를 추정하지 않는다.
- 칸 경계의 연산자 여유는 일반 행의 분수/근호 뒤 여유 억제와 구분한다. 공통 첫 칸 폭과 열 여유로 오른쪽 원점을 생산하며 모든 출력 backend가 같은 자식 LayoutBox를 소비한다.
- 명령형 첨자 결합을 요소 수집 뒤의 항 종료 경로에 두어 현재 함수 인자/명시 그룹의 소속을 보존한다. x LSUB y^2는 왼쪽 아래 y와 본체 오른쪽 위 2를 보존하며, 인자의 명시 그룹 안 첨자는 그 그룹에 남는다.
- 양쪽 첨자는 실제 본체의 공통 기준선에서 계산한다. 오른쪽 첨자로 커진 점유 상자를 왼쪽 첨자의 본체 글줄로 재인용하지 않는다.
- bare 큰 연산자 이름 뒤 marker는 템플릿 인자로 소비한다. SUM/PROD/INT와 바깥 그룹의 독립 Print를 대조했으며 바깥 그룹은 일반 첨자 본체다. 원본 스크립트는 모델에서 보존한다.
- 선행 항이 없는 명령형 첨자 오류는 독립 Print에서 중첩 그룹/PILE를 포함한 수식 전체의 표시를 무효로 한다. 파서의 문법 오류 상태로 이 계약을 표현하며 정상 내용의 좌표나 표시를 clamp하지 않는다. 공개 legacy parser의 prefix 호환 동작은 유지한다.
- 인자 누락은 닫힘·행·칸 경계를 소비하지 않는다. 앞뒤 본문·다음 행 소속은 원 토큰에 남긴다.

첫 전체 test target 사전 컴파일은 `tests/issue_505.rs`의 EqAlign 패턴이 새 필드를 포함하지 않아 E0027로 실패했다. helper 패턴만 `rows, ..`로 보완했으며 assertion·기대값·test 이름은 바꾸지 않았다. 최종 묶음의 `cargo check --locked --profile release-test --tests --target-dir /home/tsjang/rhwp/target/pr-review`는 exit 0, 90초로 통과했다. fmt와 source-side tier base 검사도 통과했다(4106 tests/296 modules). 실제 회귀 실행·시각 통과를 뜻하지 않는다.

원 구조 대조군의 정렬 Print 충돌은 그대로 보존하며, 이번 실제 Native/fresh WASM 재출력 뒤 미달과 확대 차이를 별도로 기록한다. 새 회귀 추가/기대값 갱신은 아직 수행하지 않았다.

## 정렬 충돌 진단·공간 정리

기존 HWP 정상 재저장→Print, 첫 equation ID 한 개 변경, 첫 식 고정/뒤 식만 & 있음·없음·빈 식·중첩 행렬로 변경한 대조는 충돌 원인을 설명하지 못했다. 모든 입력 HWPX·정상 HWP·Print PDF·job·SHA와 반증 관측은 `pdf/issue7642-alignment-reference-investigation/README.md`에 보존했다. 이 결과로 기존 기준을 덮어쓰거나 원본이 통과했다고 보고하지 않는다.

종료된 stage163/stage164 검증의 중간 SVG 205개를 사용 중 아님·Git ignored·명시 경로·SHA를 확인해 제거했고 3.17GiB를 확보했다. 입력/Print PDF/TSV/PNG/tree/실행 기록과 공용 target은 보존했다. 감사 JSON은 ignored `stage185-svg-cache-cleanup.json`이다.

현재 Cargo·WASM 빌드·MCP·전쪽 비교는 모두 terminal이다. 전체 55개/853쪽의 최신 source 검증, 전체 Rust 실행·lint, 새로운 이름의 관계형 회귀와 실제 Studio 확인은 미완료다. 이번 단계에서 새 회귀·golden 기대값 갱신·PR 생성·remote push는 수행하지 않았다. 다음 작업과 미달 목록은 ignored nextrun에만 기록한다.
