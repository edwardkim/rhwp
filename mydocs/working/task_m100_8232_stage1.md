## 최근 확인 결과

- WMF: 원 Native 12개는 PASS지만 문자열만 확인하는 분기는 실제 칠이 사라진 진단 출력도 수용합니다. 유효한 비트 연산 검사는 유지합니다.
- 셀 영역 대각선: 원 Native 8개는 PASS입니다. 80셀의 중심선 중 가로 80개·세로 70개를 제거한 진단 사본도 세로선 10개 조건을 만족합니다. 변환을 무시한 선택은 첫 셀 밖으로 옮긴 선도 놓칩니다.
- 추출 쪽수: 현재 CD06/CD10의 실제 추출 결과는 1쪽/2쪽입니다. 그러나 추출기는 걸친 문단 전체를 남겨 재조판하므로 이 숫자를 보장하지 않습니다. 정적 예외에 CD10=999를 주입한 원 Python 검사는 PASS했고, 비예외 LR01=999는 예상대로 FAIL했습니다. 현재 제품이 999쪽을 만든 회귀가 아닙니다.
- 234–236차 원 Python 검사 140개는 모두 PASS입니다. 논리 편집 주소·스키마·정적 과제·누름틀 Python 모델을 화면 px와 구분했습니다. 누름틀 모델의 PASS는 실제 HWP 저장·재파싱·렌더링의 수용 근거가 아닙니다.
