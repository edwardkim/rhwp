# #7642 Stage 147 — HWP3 줄 흐름의 fresh WASM 대조

Issue: #7642

## 실행 전 범위

Stage146의 Native 원본 전9쪽은 모두 90% 이상이며 영월은 원본/Print 모두 4쪽이다.
같은 source를 루트 WASM wrapper와 공유 `target/pr-review`로 빌드하고 Studio에 자동
동기화한다. JS/WASM의 package·Studio·고정 검증 복사본 SHA-256 일치를 확인한다.
그 뒤 같은 입력·독립 Print·글꼴 공급·인쇄 프로필로 fresh WASM 전9쪽 TSV와 대표
review/overlay를 산출한다. 실행 중 Rust source를 바꾸지 않는다.

페이지별 gate와 직접 확대 판독을 구분한다. 첫 표 뒤 흐름, 조건9·안전 안내의 줄 소속,
서식별 쪽 소속, 탭 글자 원점·셀 본문·괘선 잉크의 남은 차이를 확인한다. 복수 inline
표의 재정렬 경계는 이 단일 TAC 원본의 대조로 대체하지 않고 별도 실제 입력을 찾는다.
Native/fresh WASM의 해당 범위 90% 및 확대 판독 전에는 새 관계형 회귀를 추가하지 않는다.

전체 55문서·853쪽과 실패 회귀 48건의 최신 검증은 별도 남은 범위다. 전9쪽 성공으로
전체 완료를 선언하지 않는다. TSV/log/JSON/nextrun은 ignored output에 보존한다.

## sample16 실패 원본의 독립 Print 재산출

#6706 실패는 원본 제목이 없어졌다는 assertion이지만 현재 Native18쪽에서는 같은 제목이
한 줄의 여섯 TextRun으로 보존되어 있다. 소속·포함·순서는 새 출력으로 재판정하며 문자열
전체가 한 TextRun에 남아야 한다는 전제를 그대로 유지하지 않는다. 테스트 수정은 전체 시각
선행 조건을 확인한 뒤 새 이름으로 진행한다.

#7722 최신 기록에는 독립 Print와 전64쪽 복원 기록이 있으나 이 브랜치의 기준 PDF 해시는
그 새 출력과 다르다. 과거 job은 조회되지 않아 동일 원본을 새 MCP2024 Print로 출력했다.
새 기준은 `pdf/issue7642-sample16-print-refresh-20261012/`이며 입력은 바꾸지 않았다.
원본64쪽/새 Print64쪽과 Print0/1-up 계약을 확인했으므로 같은 source Native 전64쪽 TSV,
fresh WASM 전64쪽 TSV 및6·18쪽 수식/표·그림의 확대 판독을 추가 검증한다.
이관 기록만으로 복원된 정상 검사를 일괄 삭제하거나 현재 코드의 통과를 선언하지 않는다.

## 실제 결과와 남은 결함

fresh WASM 빌드 exit 0, 860.50초이며 source는 `fe5ad4db922e03f38665a6c1fb7ba34627e13596`다.
package/Studio의 JS와 WASM 해시는 각각 같은 것으로 확인했다. 전9쪽 Native/fresh WASM
점수는 대응 쪽별로 같고 최저98.39623%다. 영월 전4쪽은 99.26310 / 100.00000 /
99.19799 / 100.00000%다. 형식적 점수 통과와 직접 판독은 구분한다.

직접 새 WASM3쪽을 확인해 `월별/누계`의 두 줄이 셀 하단에 걸리는 결함을 찾았다.
원본은 저장 LineSeg 한 줄, 정상 저장본은 두 줄이다. 렌더는 두 줄로 재구성하지만
`table_layout.rs`의 저장 셀 흐름 신뢰 분기가 작은 저장 extent로 정렬 높이를 덮는다.
이 경로는 다음 보정 대상이며 99% 점수로 완료·새 회귀의 근거로 삼지 않는다.
독립 Print의 기본 셀 괘선은0.36pt이며 정상 저장 HWPX의 기본 실선은0.12mm다.
Native HWP3 셀 기본 실선은0.1mm로 매핑되어 잉크 두께도 재검토 대상이다.

sample16 새 MCP2024 Print는 전64쪽, Print0/1-up·13.0.0.3901의 실제 결과다.
원본은49e3e809 해시를 유지했고 기준 PDF는 별도 새 경로에 보존했다. Native 전64쪽
최저27.23722%, 미달17쪽으로 미충족이다. 미달 쪽은
1, 6, 8, 19, 21, 22, 23, 24, 35, 43, 45, 47, 48, 49, 52, 53, 57다. Native64 / PDF64로 쪽수만 같고 내용 소속은 다르다.
6·23쪽 대표 review/overlay를 직접 확인하고 안정 asset에 보존했다. fresh WASM64쪽은
진행 중이며 결과를 추정하지 않는다. #7722의 다른 로컬 브랜치 완료 기록을 이 브랜치의
완료로 바꾸지 않는다. 새 회귀·기존 기대값 교정은 해당 전체 시각 선행 조건 뒤에 진행한다.

`bfa28a77a2714482f647ee6a7b9aa7f7876d8404`의 manifest/unit-tier 검사는 모두 exit0이다.
Native Clippy와 fmt는 Stage146에서 완료했다. lint의 source 해시도 실행 전후 일치했다.
