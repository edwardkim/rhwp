# 첫 저장 조각의 행 높이 인증 범위 보정

## 원인과 독립 근거

전체 Rust 검사 3991의 정책연구 원본 겹침 실패를 고정 base
`238de6de41a208648f4ade6b494fe433a81c1fce`와 같은 입력·Print로 대조했다.
대상은 기존 `samples/issue4599/1790387_policy_progress.hwpx`와
`pdf/issue4599/1790387_policy_progress-hwpx-2020.pdf`다. 범위를 새 문서로 넓히지 않는다.
원 이슈 #4599와 실제 반영 PR #8185·통합 #8228의 개별 검토 기록을 확인했다.
#4599의 다른 축인 저장 사다리 일치를 이번 결함의 기대값으로 사용하지 않는다.

양쪽 전체 쪽수는 64쪽이다. 18쪽 raw는 base Native247 99.92932%, 이전 후보
Native248 49.85191%다. base의 글자 겹침은 0건, 후보는 같은 쪽 55건이다.
공유 차트 의존성을 실제 재컴파일한 Native249에서도 55건이므로 오래된 차트 캐시와
별개의 현재 회귀다. 기존 겹침 기준값을 늘리거나 문서를 이관하지 않는다.

원본 Section1/p8 표는 21행이며 개체 높이 36610HU는 첫 8행의 물리 조각이다.
`stored_plain_opening_row_frame`은 첫 8행의 내용·여백만 인증했지만 전체 21행의
선언 높이를 반환했다. 측정·배치·컷 소비자가 인증되지 않은 뒤 행까지 이 값으로
덮어써 9행의 실제 내용 84px와 상하 여백 3.76px를 30.5333px 상자에 그렸다.
공개 `HeightMeasurer::measure_section` 진단 4010에서도 이를 재현했다.

## 공통 결과와 소비 경로

첫 조각 결과는 실제 인증한 접두 행만 반환한다. 공통 `apply_to`가 이 접두만 현재
측정 행 벡터에 적용하며, 이후 행은 내용·여백으로 측정한 원래 높이를 보존한다.

| 경로 | 보정 |
| --- | --- |
| source helper | 인증하지 않은 행을 결과 벡터에서 제외 |
| HeightMeasurer | 전체 표 프레임만 전량 대체; 첫 조각은 접두만 적용 |
| LayoutEngine 측정 캐시 경로 | 접두 뒤의 실제 측정 유지; 첫 조각 높이를 표 전체로 맞추지 않음 |
| LayoutEngine 캐시 없는 경로 | 같은 공통 접두를 최종 행 벡터에 적용 |
| 완결 행 컷 | 인증 범위 밖의 행 조회는 실패하여 기존 내용 측정 경로 사용 |
| 첫 조각 종료 행 | 기존 종료 행 소유 계약 유지 |

편집·재조판·부모 폭 변경의 무효화 조건과 완결 표 전체 프레임은 유지한다.
문서 ID·특정 좌표·점수 임계값으로 분기하지 않는다. 삭제된 제외 대상의 원본·검사·
파생 참조는 재생성하지 않으며, 해당 문서의 과거 증적을 새 검증으로 보고하지 않는다.
