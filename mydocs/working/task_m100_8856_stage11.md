# #8856 설날 문서의 원본 공백과 캡션 그림 글머리표

이전 stage10을 `8e7867c442`로 커밋한 뒤 시작한다. 원 PR #8611은 경로 글꼴 적재 예산의
보정이며 설날 문서의 기존 잔여를 해결했다고 주장하지 않는다. 현재 차이를 원본·독립 Print로 다시 확인했다.

제목의 한양해서는 원본 TTF 선언이며 `useFontSpace=1`이다. 독립 PDF의 HYhaeseo 서브셋과
설치된 UNI_HSR.TTF의 제목의 네 음절과 공백 윤곽과 hmtx가 모두 같다. 공백은 341/1024em이다.
기존 메트릭 표 HYhaeseo는 있으나 한국어 이름의 별칭이 없어, 공통 조회가 반각 공백으로 내려간다.
독립 PDF의 차·례·상 원점과 원본 프로그램의 공백을 같은 장평 90%로 대조했다.
새 폭을 추정하거나 표시 대체 폰트의 폭으로 바꾸지 않고 검증된 기존 표를 이름에 연결한다.

2쪽의 마름모는 캡션 문단의 그림 글머리표다. 원본 Bullet은 useImage와 BinData 참조를 보존하고
독립 PDF도 60×60 원본 그림을 별도 자원으로 출력한다. 현재 트리에는 본문 그림만 있고
마커는 없다. 캡션은 문단을 구성한 뒤 공통 번호/글머리표 적용을 건너뛰고 바로 배치한다.
공통 마커 문자열·점유 칸·그림 소비 경로를 캡션에도 연결해 본문 원점까지 함께 복구한다.
원본 본문에 문자 마커를 삽입하거나 개별 쪽 좌표를 옮기지 않는다.

수정 전 최소 글꼴 전3쪽 Native98.42814% / fresh WASM98.42806%이며 조건은 고정한다.
원본 글꼴 대조는 별도 조건으로 보존한다. 공통 보정 후 새 관계 검사2PASS와 완료 페이지의 독립±2CSSpx1PASS를 확인했다.
기존 관련14건·Node55건도 통과했다. 같은 최소 글꼴 조건 전3쪽에서90% 미만·누락은 없다.
실제 Native/fresh WASM 확대 판독으로 제목과 마름모·뒤 본문 위치가 복구됐음을 확인했다.
최종 PR 전체 게이트는 아직 완료하지 않았다.
