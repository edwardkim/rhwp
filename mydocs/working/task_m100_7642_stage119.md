# Stage 119 — 새 이름의 관계형 회귀 등록

Issue: #7642. 작업지시자는 기존 시험지 회귀 검사를 다른 PR에서 전체 삭제할 예정이므로,
2026-10-11부터 관계형 검사를 기존 이름으로 변경하지 말고 새 이름으로 생성하도록 지시했다.
전체 입력·시각 검증 범위는 유지하며, 기존 목록 복원 자체를 관계형 전환 완료로 세지 않는다.

## 리사이즈 검사 분리

`tests/cases/issue_6806_shape_resize_original_scale.rs`는 원래 `463794a8a` 내용과
바이트 단위로 일치하도록 복원했다. 새 검사 파일은
`tests/cases/issue_7642_shape_resize_relations.rs`다.

- `issue7642_resize_keeps_owned_line_length_ratio`
- `issue7642_resize_undo_restores_owned_line_endpoints`
- `issue7642_resize_updates_size_without_changing_creation_frame`

새 검사는 화면 고정 영역이 아니라 개체 소유로 선을 선택하고, 길이의 비율·생성 프레임
보존·Undo 끝점 복원을 검사한다. 이전 이름의 같은 assertion은 보정 전 2 PASS·1 FAIL,
source `95daed4d5`에서 3 PASS였다. 새 이름으로 파생 suite를 준비하고 실제 실행한
결과는 아직 없다. 이름만 바꾼 소스의 이전 통과를 새 검사 실행 완료로 기록하지 않는다.

동일 source의 실제 편집 전·절반 폭·Undo는 Native 45쪽과 fresh WASM 45쪽 모두
최저 95.17139%다. 각 상태 저장본은 MCP Print 입력과 바이트 단위로 대응했다.
대표 Native 1쪽 비교를 직접 열었으며, 새 코드 후보의 영향 재검증과 추가 확대 판독은
계속한다. TSV·로그는 ignored output에 보존한다.

## 나머지 검사

#1139 전체와 복원 목록의 필요한 관계형 검사도 새 파일·새 이름으로 추가한다.
같은 원본의 Native/fresh WASM 관련 모든 쪽 90% 이상과 확대 판독을 먼저 확인한다.
삭제 예정인 기존 검사와 신규 검사 목록을 구분해 기록하며, 기존 실패를 기대값 완화로
통과시키지 않는다. 다른 PR의 실제 삭제·병합 여부는 최종 base 통합 전에 확인한다.
