# Issue #7642: 정상 저장 본문의 관계 회귀와 fresh WASM 검증

## Native와 fresh WASM

`stage1425-current-native.json`의 보존 Native 라이브러리·실행 파일은 보정 소스와 해시가 같다.

고정 `target/pr-review`, release codegen-units 16으로 빌드한 기록이다.
컴파일·wasm-opt가 exit 0으로 끝났고, 생산 중 source hash가 바뀌지 않았으며,
`pkg/`와 Studio의 JS·WASM SHA가 같다.

WASM SHA-256은 `f9400120aac661318845c25563aa300246e708e77f95569a1852489ef7ee55c1`다.
Native와 WASM의 각 생산 receipt는 실제 빌드 시점 부모와 작업 트리 상태를 보존하고,
`committed_source_sha`와 소스 해시 일치 여부로 위 commit에 연결한다.

## 새 이름의 정식 관계 회귀

`verified_language_print_preserves_clean_body_rows_and_neighbor_ownership`를 추가한다.

원문 내용으로 문단을 유일하게 찾고, 앞·대상·뒤 문단을 같은 본문 소유 범위에서 조회한다.

본문의 증거로 세지 않는다. 좌표를 고정하거나 특정 px 영역으로 대상을 선택하지 않는다.

## 이번 브랜치에서 추가한 글꼴 검사의 기대값 오류 교정

`legacy_hwp3_font_declaration_preserves_its_source_program_kind`는 이번 브랜치에서
새로 추가한 검사이며 고정 devel에는 없다. 조합형 원본 `신명조`가 기존 파서의
정규화 규칙으로 `한양신명조`가 되는데 기대 이름을 `HY신명조`로 잘못 적었다.

렌더러나 원문·PDF를 이 테스트에 맞춰 바꾸지 않았다.

`stage1436-stored-body-focused-nextest.json`과 로그에서 위 파일의 7건 및
기존 `verified_language_print_column_fragments`의 1건, 합계 8건이 모두 통과했다.

## 남은 검증

이 결과는 언어 15쪽의 전쪽 90% 선행 조건과 이번 줄 분할 관계의 검증이다.

국어 2·10·14쪽과 사회 1쪽에도 devel 대비 하락이 남는다. 평균이나 90% 통과로 면제하지 않는다.

`stage1440-social-independent-print-top.json`에 보존했으며 아직 구현 보정 전이다.
