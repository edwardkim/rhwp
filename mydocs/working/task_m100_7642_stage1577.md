# #7642 완료 페이지의 새 회귀와 독립 Print 기준 보존

Issue: #7642

## 자격과 범위

제품 소스 `057a584e9eafc9f8ec12f7557326ca6a6c010b15`에서 PrEP 140쪽의 Native/fresh WASM
최저값은 각각 91.54965%와 92.43307%다. 전체 쪽수 140, 90% 미만·누락 0쪽을 확인했다.
물리 70쪽은 양쪽 100%이며 같은 배율로 반복 머리행·표 끝·후속 본문을 직접 판독했다.

새 회귀·독립 PDF·대표 PNG·쪽수 원장 행을 추가한다. 기존 회귀 파일의 이름이나 검사 함수를
재사용하지 않고 `verified_prep_completed_table_page.rs`를 만들었다. 다른 PrEP 페이지의
위치나 SVG 해시를 이 완료 페이지의 자격으로 고정하지 않았다.

원본·PDF SHA와 실제 출력 계약, 전체 TSV SHA, 대표 PNG는
[시각 증적](../pr/assets/issue7642_prep_completed_table_page/README.md)에 모았다.
기준 PDF는 원본을 실제 Print한 12,228,923바이트 파일이며, 실행 경로의 바이트를
`pdf/issue2006/1790387_prep_final_report-hwpx-2024.pdf`로 보존했다. 기존 PDF는 덮어쓰지 않았다.

기대값을 정했으며 현재 출력 좌표를 복사하지 않았다.

## 본문 차이의 추가 분석

별도 진단은 원본의 시각 완료나 새 회귀 자격으로 세지 않았다.

- `stage1574-prep-independent-font-metrics.json`: 67쪽 문제 문단의 고유 문자 120종에
  대해 실제 PDF glyph ID와 시스템 KoPub TTF의 전진폭·외곽선이 모두 일치했다.
  PDF subset 전체 파일의 SHA 차이를 글꼴 불일치라고 해석하지 않았다.
- `stage1575-ratio-spacing-measurement.json`: 로컬에서 생성한 HWPX 3개를 MCP2024로
  실제 Print PDF로 산출했다. 장평 50/100/150 × 자간 -20/0/+20 × KoPub·맑은 고딕·굴림
  27사례는 현재 장평을 반영한 자간 모형을 지지한다. 장평을 자간에서 제거하는 가설은
  반례와 맞지 않아 구현하지 않았다. 이 입력은 한컴 저장 원본으로 주장하지 않는다.
