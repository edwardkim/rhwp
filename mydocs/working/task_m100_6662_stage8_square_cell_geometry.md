# 열린 이슈 재검증 8단계: 셀 어울림의 좌표와 본문 소유

Issue: #6712. 시작 HEAD: `a503ec6e0`.

## 남은 재현과 계획

- 한국어 1쪽 제목/본문의 세로 위치, 2쪽 그림과 제목의 겹침이 남는다.
- 중국어 1쪽 예방수칙 첫 두 줄이 겹친다. 2쪽 마지막 `儿童之家婴幼儿健康管理访问项目团`
  16자가 SVG에 없다. 단순 overflow=0 또는 쪽수 2만으로는 해결되지 않았다.
- 실제 저장 LINE_SEG의 문단/줄 좌표와 조각 원점을 대조한다. 같은 문단의 Square와
  다른 문단의 anchor를 구분하고, 한 물리 줄의 마지막 빈 가로 조각이 전진량을 없애는지 확인한다.
- 증상별 red 계약을 먼저 만들고, 일반 셀/분할 셀의 공통 배치 규약으로 수정한다.
- 범위를 파일명/문구로 제한하거나 baseline을 올리지 않는다. 실물 2종, 합성 음성,
  overlap/overflow/off-canvas 및 기준 PDF를 검증하고 이 단계 결과를 별도 커밋한다.

임시 파일은 `/tmp`에 둔다. 최종 코멘트용으로 선정하지 않은 PNG/SVG/JSON과 로그는 커밋하지 않는다.

## 원인과 보정

1. 같은 저장 vpos의 앞 가로 조각이 줄 전진을 마지막 조각에 위임했지만, 마지막 조각이
   공백이면 Square guide 규칙도 전진을 생략했다. 앞 조각에 실제 글자가 있으면 마지막
   조각이 해당 행의 전진량을 부담하도록 수정했다.
2. 같은 문단의 Square 그림은 wrap anchor 검색에서 빠졌다. 검색 범위에 현재 문단을
   포함하고, 분할 셀 그림의 세로 anchor는 조판 후 cursor가 아닌 문단 시작점을 사용한다.
3. 중국어 마지막 문구는 렌더 트리에 있었지만 clip의 3px만 걸친다는 이유로 다음 페이지
   잔여물로 숨겨졌다. `end_unit == usize::MAX`인 마지막 조각에는 다음 페이지 소유자가
   없으므로 일부만 잘린 마지막 글줄을 중복 억제 전에 복원한다. 중간 조각의 중복 억제와
   기존 복원 범위는 그대로 유지한다.

## 중간 검증

- red: 예방수칙 행 전진 및 마지막 문구 가시성 테스트 2개 모두 실패.
- 첫 보정: #6712와 #5862 14개 중 13개 통과. 마지막 문구는 clip 확장보다 앞서 숨겨져 실패.
- 소유권 보정 후: 동일 14개 모두 통과(0.180초, exit 0).
- 이 결과는 본문 누락/중복 계약의 통과이며 PDF와의 전체 좌표 정합 통과가 아니다.
  CLI 재빌드는 exit 0(2분 37초)이다.
- 전체 nextest: 9,082개 중 9,081 통과, 1 실패, 46 skipped, 497.037초, exit 100.
  실패는 `text_overlap_baseline` partition 14이며
  `task2287/1342000_edu_curriculum_map.hwp` 겹침이 94건에서 97건으로 늘었다.
  대형 표 성능 테스트도 230.526초에 정상 종료했다.
- 앞 후보는 모든 직접 분할 셀을 중복 억제에서 제외해 범위가 넓었다. 다음 조각이 없는
  마지막 셀의 clip만 미리 복원하도록 좁혔다. 위 전체 결과를 이 재보정의 통과로 재사용하지
  않고, 관련 clip/중첩 표 및 overlap·overflow·off-canvas 분할 검사를 다시 수행한다.
- 재보정 결과: 80개 중 79 통과, 1 실패, 89.090초, exit 100. #6712의 마지막 문구와
  #5862/#5863/#2007, overflow/off-canvas는 통과했지만 겹침 partition 14는 여전히
  94 -> 97건이다. 마지막 조각 판정만으로 충분하다는 가설은 기각한다.
- 별도 `layout-anomaly --json` 진단에서 해당 코퍼스의 표 글줄/페이지 Footer 겹침을
  확인했다. 쪽 하단까지 clip을 복원하면 본문 밖의 꼬리말 영역까지 허용할 수 있다.
  다음 단계에서 본문 paint 경계와 복원 글줄의 전체 높이를 함께 제한해 확인한다.
- 이 단계는 분석과 국소 수정의 **체크포인트**다. 실패가 남은 후보를 PR 또는 push하지 않는다.
  전체 해결 완료 또는 회귀 통과라는 뜻으로 `completed` 상태를 해석하지 않는다.

## 기준 PDF와 직접 비교한 잔여 사항

- 두 원본 모두 2쪽이다. 한국어 2쪽 첫 그림의 세로 오차는 +32px에서 0px로 줄었다.
  그러나 그림 옆 다음 문단의 소제목은 여전히 겹친다. 글자가 있는 anchor 문단의
  어울림 연결을 같은 문단으로만 제한한 나머지 후속 문단이 빠지는지 확인해야 한다.
- 한국어 1쪽 글줄 y 차 중앙값 -21.9px, 중국어 1쪽 -25.6px가 남는다.
  빈 그림 anchor의 저장 `line_height + line_spacing` 전진량과 그림 높이의 중복 제거는
  서로 다른 계약이다. 다음 단계에서 저장 다음 vpos가 증명하는 전진량을 검토한다.
- 중국어 1쪽 예방수칙 네 줄은 겹치지 않고, 2쪽 마지막 문구 16자가 다시 보인다.
  하지만 마지막 문구와 아래 테두리가 겹친다. 한국어 2쪽의 footer 로고도 아직 없다.
- 한국어·중국어 각각 1·2쪽 review PNG 네 장을 직접 열었다. 한국어 sweep 첫 실행은
  Chrome exit 0 직후 파일 확인 경쟁으로 실패했고 같은 입력의 resume은 exit 0이었다.
  중국어 sweep은 exit 0이다. 이 중간 실패 화면은 최종 코멘트용 증적으로 커밋하지 않는다.
- **#6712는 해결 완료가 아니다.** page count와 누락 계약 통과를 시각적 정합으로 대체하지 않는다.
