## #1440의 일반 경로 근거

원본 HWPX는 한컴13.0.0.3622의 정상 저장본이다. 진단본은102문단의 저장
줄만 제거했으며 같은ZIP의 다른멤버는 동일하다.115문단의 네 저장 줄·일반
reset도 원본과 같다. 이 진단본을 원본 수용 입력으로 대체하지 않았다.

Print는102문단179자를 네 줄로 출력한다. 현재 원본은 저장 다섯 줄을 쓰고,
진단은 공통 실제 표 배제 프레임의 네 줄을 쓴다. 기존 계획 함수는 NO_LS만
수용해 같은 원본 호스트의 저장 key는 현재 실제 배제 영역과 대조하지 않았다.

단일 Square 표·기존 좌표/캡션/컨트롤 조건을 보존한다. 정상 가시 저장 호스트도
실측 표 배제 영역으로 행 수·column_start·segment_width를 계산한다. 저장
key가 같으면 기존 소유자에게 남기고 다르면 그 공통 줄·끝점을 fmt/fit/paint에
전달한다. 실제 쪽/단 횡단과 원점 계약이 다른 HWP3 계보는 기존 저장 경로를
유지한다. 기존 composer의 물리 프레임 횡단 helper를 재사용하도록 공개했다.
문서ID·글꼴명·행 수 상수로 입력을 분류하지 않았다.

115문단의 진단 관측은 fit85.33px/잔여93.83px인데 anchored/internal reset3을
강제했다. 실제 원본은 수용 예산도 부족하므로 이 reset만 없애면 해결된다고
판정하지 않았다. 같은 흐름 helper가 ladder dirty=true를 무시했고, 앞 호스트의
재조판 뒤 새 흐름과 맞춘 좌표를 원래 쪽 소유로 재사용했다. 재조판된 사다리는
자동 reset의 증거로 거절한다. 명시적 page-start는 별도 경계 소유를 유지한다.
