# 작업 2464-2511 단계 4 - E2E 검증 근거 반영

## 범위

- HML, HWP/HWPX 저장 왕복, undo/텍스트 플로우와 직접 연결되는 원 PR 검토 문서에 browser E2E 결과를 보완한다.
- 최종 통합 PR 본문에 기록할 E2E 범위와 한계를 정리한다.

## 반영 대상

- [#2464](https://github.com/edwardkim/rhwp/pull/2464)~[#2487](https://github.com/edwardkim/rhwp/pull/2487): HWP/HWPX 저장·재열기 E2E.
- [#2472](https://github.com/edwardkim/rhwp/pull/2472), [#2493](https://github.com/edwardkim/rhwp/pull/2493), [#2511](https://github.com/edwardkim/rhwp/pull/2511): HML 실제 열기·저장·재열기 E2E.
- [#2480](https://github.com/edwardkim/rhwp/pull/2480): undo 및 텍스트 플로우 E2E.

## 경계

- E2E runner 보정은 `690734270`에 고정돼 있으며, 이 단계에서는 코드·test script를 추가 변경하지 않는다.
- Safari 서명과 실기기 확장 설치는 인증서 환경 제약 때문에 이번 headless browser E2E 범위 밖으로 남긴다.

## 결과

- HWP/HWPX 저장 보존 PR 12건에 저장 UI·MIME·매직·재열기 E2E smoke 근거와 속성별 focused Rust oracle의 역할을 구분해 기록했다.
- HML 관련 [#2472](https://github.com/edwardkim/rhwp/pull/2472), [#2493](https://github.com/edwardkim/rhwp/pull/2493), [#2511](https://github.com/edwardkim/rhwp/pull/2511)에
  실제 HML 열기·저장·재열기 E2E 결과를 기록했다.
- [#2480](https://github.com/edwardkim/rhwp/pull/2480)에 실제 입력·Ctrl+Z undo와 text-flow E2E 결과를 기록했다.
- E2E는 Studio 브라우저 경로의 근거다. VS Code selector와 각 확장 URL 식별은 package/shared-security test와 production build 결과로 별도 검증한다.
