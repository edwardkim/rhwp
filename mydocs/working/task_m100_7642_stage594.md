# Issue #7642 단계 594: text 윤곽과 소유 상자의 좌표계 일치

- stage584의 fmt·세 Clippy·workspace 빌드와 글꼴 공급/리터럴/그리스 문자/근 지수 검사는 통과했다. 아래첨자와 dyad의 최종 잉크 3건은 여전히 실패했다. Text 순회 추가만으로 통과했다고 보고하지 않는다.
- 설치된 usvg 0.45.1의 `text::flatten::commit_span`은 글리프 path를 `Transform::default()`로 만든다. `text::convert`는 text 자체의 절대 상자에만 `text.abs_transform`을 적용한다. `Text::flattened()` 내부 path의 절대 상자는 text 로컬 공간의 상자다.
- 두 helper가 flattened 윤곽의 상자에도 text의 실제 절대 변환을 적용하도록 보완했다. 일반 SVG path에는 항등 변환을 유지한다. 기대 좌표·영역·허용치를 추가하지 않고 실제 소유 상자와 표시 윤곽을 동일한 페이지 좌표에서 비교한다.
- 내용·순서·정체, 첨자/분모 기준선, 장식 폭, 뒤 본문 비겹침 검사는 유지한다. 임시 진단용 전체 path 출력은 제거했다. 새 집중 검사 결과는 아직 미검증이다.
- 원본 수식의 기존 Native/fresh WASM 시각 증거는 stage563/564이며, 최신 parser의 새 시각 검증은 stage585와 후속 fresh WASM에서 별도로 확인한다. 테스트 helper 변경을 실제 출력 개선으로 보고하지 않는다.
