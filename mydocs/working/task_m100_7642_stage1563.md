새 devel의 `apply_resolved_field_tokens`는 기존 브랜치에서 스타일과 DPI를 받도록 바뀐
`inline_width_px_at` 호출에 스타일 인자를 전달하지 않았다. 첫 Native 빌드의 `E0061`로
확인하고 같은 `ResolvedStyleSet`을 전달하도록 보정했다. 기대값이나 메트릭 정책을 바꾸지 않았다.

호출 연결은 `layout_field_values → apply_resolved_field_tokens → token_width +
inline_width_px_at(styles) → BreakToken → 줄 수용`이다. 저장 표시 경로의
`resolved_fields::apply`와 실제 paint의 표시 구간 소비도 함께 유지했다.
