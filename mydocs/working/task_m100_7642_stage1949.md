## 충돌 해소와 소비 경로

upstream의 `composer.rs` 본문은 현재 브랜치에서 include 파일로 나뉘어 있다.
분리 과정과 새 중첩 표 소유권 변경이 충돌했으므로, 모듈 export만 남기는 데 그치지 않고
`reflow_helpers.inc.rs`의 기본 호출과 `stored_cell_reflow.inc.rs`의 실측 높이 인자,
프레임 수용 조건, `FrameGeometry.inline_table_heights`를 원래 변경과 대응시켰다.
새 모듈 `nested_table_frames.rs`는 기존 bool 호출도 수용하는 `Into<StoredGeometryPolicy>`를
받아 현재 브랜치의 전체 저장 정보 정책을 두 하위 조판 호출에 그대로 전달한다.
HWP3 원점 보존 조건도 같은 정책 필드를 사용한다.

측정·온전한 표 배치·지연 조각 배치는 upstream의 `compose_cell_unit_paragraph`와
`recompose_cell_lines_with_nested_tables` 연결을 유지한다. 이전 브랜치의 정책 전파 변경을
낡은 개별 지연 배치 구현으로 되돌리지 않았다. 새 입력·회귀 함수·독립 쪽수 항목도 보존했다.
upstream 문서를 다시 확인했고 변경된 두 지침 파일은 upstream과 차이가 없다.
