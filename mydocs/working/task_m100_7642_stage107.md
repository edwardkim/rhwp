# Stage 107 — 소비 경로와 회귀 실패의 독립 대조

Issue: #7642. 55개 원본·853쪽, 복원한 회귀 292개와 #1139 전체 관계형 전환 범위를 유지한다.

## 현재 단계의 근거

Stage 106에서 Native SVG/fresh WASM 반례 16개·19쪽의 최저 92.57667%와 RGB 동등성을
확인했다. 전체 nextest와 원본 전쪽 대조는 실행 중이며 종료 결과를 먼저 확인한다.
실패한 검사는 원본·독립 Print PDF·현재 출력의 대응을 확인한 뒤 보정한다.

실제 23쪽 시험지의 CanvasKit document preflight는 10쪽에서 50,000 work-unit 제한에
걸린다. 앞쪽에도 semantic layout/shaping 경계가 있다. 전체 자원 목록을 얻지 못한
출력을 CanvasKit 성공으로 기록하거나 제한을 키워 통과시키지 않는다.

작은 정상 한컴 저장본을 실제 Studio의 Canvas2D/CanvasKit 소비 경로에 전달해
장식·첨자 공통 결과가 어떻게 재생되는지 확인한다. 입력 바이트·SHA·출력 backend·
프로필·안정화 상태·독립 Print를 기록한다. 큰 원본의 fallback을 작은 대조군 성공으로
해결됐다고 보고하지 않는다. 진단은 ignored output에 보존하며 새 회귀 기대값의
추가·변경은 해당 원본의 전쪽 90% 및 확대 판독 선행 조건을 유지한다.

전체 회귀에서 발견한 실패는 현재 branch에서 원인을 보정한다. 정확한 기대값을
유지하고, 고정 px 기대값을 교정할 때는 같은 원본의 독립 출력과 관계를 먼저 정한다.
전체 원본과 관계형 전환, 최종 검증·새 PR·CI·trailing commit·merge/후속은 미완료다.

## 제품 보정과 검증 결과

- 실제 Studio의 `FontGlyph`에 outline이 없으면 이전 CanvasKit 소비는 실패했다.
  읽기 전용 추적에서 `∙`/`⋅` leaf 실패가 부모 수식 전체 누락으로 전파됨을 확인했다.
- 선언된 준비 글꼴 후보만 순서대로 검사하고 실제 glyph가 있는 face로 자연 폭·생산 기준선을
  보존해 그린다. 글꼴 파일의 실제 family를 읽어 다른 수학 글꼴을 LMM으로 가장하지 않는다.
  선언하지 않은 기본 글꼴을 추가하거나 glyph 부재를 성공으로 보고하지 않는다.
- 새 글꼴 선택·기준선 보존 계약 5개 통과. 전체 Studio `npm test`는 1,830개 통과,
  2개 건너뜀, 0개 실패. `tsc --noEmit` 종료 코드 0. 세 실행 로그와 source hash는
  `output/pr-review/issue7642/failed-inputs-20261008/stage15-current-validation/`의
  `stage107-studio-validation-evidence.json`에 연결했다.
- runtime 보정이 없는 실제 제품 캡처에서 CanvasKit 기본/compat의 5쪽 모두 backend
  검증 통과. vector-bullet 95.50152%/93.10142%, vector-body 98.82140%,
  roman-context 91.53203%/93.74425%. Native/fresh WASM SVG는 Stage 106의
  같은 원본 전체 페이지 검증과 구분하며 Studio 점수로 대체하지 않는다.
- 확대 판독에서 누락된 수식의 복원은 확인했지만 점 기호의 크기 차이가 남는다.
  Canvas2D roman-context는 87.87447%/87.57062%로 미달이다. 90%를 통과한
  CanvasKit도 이 미세 차이를 면제받지 않으며 본 단계는 최종 시각 승인 판정이 아니다.
- 증적은 `stage107-studio-decoration/`의 `receipt.json`,
  `product-print-comparison-scores.json`, `vector-bullet-product-before-after-print-review.png`,
  `roman-context-canvas2d-canvaskit-print-detail-review.png`에 보존했다. 이전 화면은
  별도 `stage107-studio-decoration-trace/`에서 가져왔다. 기존 점수 파일에 경로가
  같다는 이유로 덮어쓴 화면을 수정 전 증거로 쓰지 않는다.
- Rust capability policy의 outline 없는 leaf 판정과 실제 큰 시험지의 preflight 제한은
  아직 해결되지 않았다. 전체 Rust nextest·55개 원본 전쪽 대조는 실행 중이고,
  기존 고정 px 검사의 전체 관계형 전환과 최종 PR 절차도 남아 있다.
