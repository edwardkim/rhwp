## 진행 중 검증과 판단

새 package를 실제로 사용하는 전쪽 WASM queue와 같은 source의 Rust lint를 시작했다.
Native queue는 먼저 완료한 새 CLI로 계속 실행 중이다. dispatcher는 실제 빌드
process group과 완료 receipt·동결 artifact를 확인하고 시작하며 출력 공백을 이유로
같은 빌드를 재시작하지 않는다. Native 빌드와 마스크 2건의 성공을 전체 Rust
회귀·전체 lint·전쪽 시각 승인으로 대신하지 않는다.

본문 굵기는 source HWPX와 실제 layer JSON 모두 bold=true다. PDF stroke도
물리 0.02em으로 확인됐다. 같은 Print PDF의 glyph raster는 Cairo·Splash·MuPDF·
PDFium 사이에 차이가 있어 원인을 분리하는 독립 진단을 진행한다. 좌표 동치의
새 PDF는 진단 복사본이며 한컴 Print 기준으로 사용하지 않는다. 기존 원본 PDF·
raw 식·90%·98%·0.01%p gate를 변경하지 않았다. 임의 굵기 조절이나 renderer별
점수 선택으로 차이를 숨기지 않는다. 이 진단은 아직 원인 확정·검증기 변경 근거가 아니다.
