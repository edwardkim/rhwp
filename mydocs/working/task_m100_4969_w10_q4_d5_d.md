## 결론

D5-C에서 유일하게 남았던 same-tree causal WASM size hard gate를 완화하지 않고 충족했다. B exact head의
detached worktree에서 Q4-D와 D5 제품 Rust source commit 일곱 개의 `src/**` diff만 최신순으로 역적용해 A를
만들었다. 문서·test-only·Studio-only commit은 역적용하지 않았고, A의 tracked diff는 계획한 13개 Rust 파일
allowlist와 정확히 일치했다. 수동 conflict resolution, reject, 과거 절대값 대체는 모두 0이다.

A와 B를 같은 Docker image ID와 서로 분리된 빈 cargo·wasm-pack·target volume에서 표준 WASM 절차로 각각
완전 빌드했다. 최적화된 `rhwp_bg.wasm`은 A 9,858,318 bytes, B 9,894,929 bytes였고, 인과 delta는
**+36,611 bytes, A 대비 +0.371371668%**다. 이 양의 delta를 사후 크기 SLA로 pass/fail하지 않고 그대로
공개한다.

D5-C가 이미 correctness·runtime parity·성능 정정을 qualified로 판정했고, D5-D가 마지막 causal size
영수증을 완성했으므로 Q4-D 최종 분류는 `blocked`에서 `qualified-bounded-subset`으로 갱신한다. D5-C의
blocked 기록은 당시 전체 commit reverse 방식이 충돌한 역사적 결과로 보존하며, D5-D가 baseline 구성 방법만
교정해 그 blocker를 해소했다.
