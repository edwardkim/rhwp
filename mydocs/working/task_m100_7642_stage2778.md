# #7642 저장 자동 줄의 무효화 근거 보정

Issue: #7642.

## 확인한 반례

`stage2774-common-soft-wrap-counterexample/`의 정상 언어 시험지에서 저장
0.132 문단은 두 줄이며 독립 Print도 `다.`를 둘째 줄에 둔다. 직전 공통
정규화는 현재 측정으로 더 적은 줄에 들어간다는 이유로 이 문단을 합치고
뒤 문단을 한 줄 위로 당겼다. 줄 감소 자체를 캐시 무효화 사유로 삼은
가정을 제거해야 한다. 특정 문서·페이지에 정규화를 끄는 방식은 사용하지 않았다.

## 변경한 공통 경로

본문 정규화는 원문 문자에 없는 목록 마커가 실제로 해소되어 그려지는지
`list_marker_geometry`로 확인한다. 현재 마커의 기하가 필요한 경우에 같은
frame으로 줄·공백·후속 원점을 발행한다. 유효한 일반 본문은 기존 저장 줄
수용을 유지한다. 원문 편집이나 별도 폭/개체 변화가 무효화한 경로는 유지한다.

`project_stored_soft_wraps`는 저장 줄을 비운 복사본 대신 원본 입력을 fresh
줄 채움에 전달한다. 이 함수는 저장 줄을 배치 결과로 반환하지 않으며,
`reflow_indentation_pattern`이 원본의 줄별 들여쓰기 적용 기록을 읽도록 한다.
생산한 줄·공백을 파생 문단에 게시하고, 측정·pagination·paint가 그 문단을
공유하는 소비 경로는 유지한다. 원본 document의 저장 캐시는 변경하지 않는다.

## 진단 근거와 실행 상태

`stage2777-soft-wrap-font-observation/`에서 기존 af71 진단 producer의 글꼴
관측을 다시 실행해 두 문서 모두 exit 0을 확인했다. 관측에 사용한 글꼴
측정·style resolver 모듈은 747 source와 byte-identical임을 기록했다. 이 자료는
옛 producer의 측정 진단이며 새 head의 실제 paint 선택·최종 시각 통과로
승격하지 않는다. 글꼴 이름이나 Type3 분류만으로 다른 프로그램을 같은
프로그램이라고 단정하지 않았다.

수정 파일의 rustfmt와 증분 `git diff --check`는 통과했다. 새 코드의 컴파일·
전체 Native/fresh WASM·정상 대조군 보존은 아직 미검증이다. 747 source의
실행 중인 WASM 빌드·대기 중인 Native 계약/전체 Rust를 중단하거나 고정
worktree의 source에 이번 변경을 섞지 않았다. 새 source도 같은
`target/pr-review`에서 빌드 잡 8개로 순차 검증한다.

747 Native의 온새미로 HWP/HWPX 전쪽 90% 이상은 이전 source의 관측으로
유지하며 이 수정의 통과 증거로 재사용하지 않는다. 새 실물 회귀·baseline은
추가하거나 완화하지 않았다. 공통 수정 완료·PR 준비 완료는 아직 아니다.
