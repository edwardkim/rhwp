# Stage 330 — fit·flow 뒤 간격과 수식 명령·첨자 경계 묶음 보정

Issue: #7642
Base: `22317614b03722e95349a1d3d71c86923363c6f5`

## 구현 근거와 소비 경로

독립 Print와 Stage 328의 실제 출력 추적에서 과학 문서의 문단 뒤 간격이 다단 흐름에서
사라지는 것을 확인했다. `format_paragraph_for_flow`의 fit은 마지막 점유까지이고,
`flow_advance_height` → `place_fitted_paragraph` → `apply_full_paragraph_flow`는 다음
내용의 원점을 전진시킨다. 다단 전진량에 뒤 간격을 한 번 보존했다. 같은 계약의 Square
host fit 재설정에서 뒤 간격을 제외하고, inline-equation fit에서 중복 차감도 제거했다.
출력 원점을 숫자로 보정하거나 특정 문서 조건을 추가하지 않았다.

Stage 325/327/329의 한컴 Print 자료에 맞춰 저장 문서용 tokenizer에 최장 명령 우선순위를
적용했다. OVERLINE/UNDERLINE을 먼저 읽고 OVER/UNDER/ATOP과 붙은 피연산자를 분리한다.
UNDER 별칭과 백슬래시 뒤 문자도 공개 LaTeX API와 구분한다. 기저 없는 첨자·누락 첨자
피연산자는 이미 읽은 앞 항을 유지하고 뒤 입력을 중단한다. 명시적 빈 그룹은 유효한 인자다.
공통 상태를 사용하며, 첨자 결합 함수를 분리해 parser를 1000줄 이하로 유지했다.

## 현재 실행 증거

- 같은 production parser와 독립 Print 기대값의 51개 진단: 수정 전 42건 실패 → 수정 후 51/51 통과.
  수정 전 소스는 ignored output에 동결했다. 컴파일 실패를 결함 재현으로 세지 않았다.
- `cargo fmt --all`, `git diff --check`: 통과.
- base 고정 unit-tier 정책: 4106 tests / 296 modules / 28 cfg support items, 통과.
- 정식 파서·tokenizer 검사, Native/fresh WASM 빌드, 과학 문서 전체 4쪽 및 정상 대조군의
  재출력은 다음 단계이며 아직 미검증이다. 이전 source의 전체 queue는 고정 산출물로 계속 실행한다.

probe는 입력 해석의 진단이며 최종 시각 증거나 정식 회귀를 대신하지 않는다. 관련 전쪽의
Native/fresh WASM 90% 이상과 확대 판독 후 새로운 이름의 관계형 회귀를 추가한다.
전체 회귀·lint·시각 gate가 남아 있으므로 PR 준비 완료로 판정하지 않는다.
