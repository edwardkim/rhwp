# 임의 바탕쪽 대상 번호의 보존과 선택

Issue: #7642

## 독립 저장본과 생성 방식

과학 원본의 첫 쪽에는 독립 Print의 `1` 대신 `2`가 보인다. 원본 HWP와
기준 PDF는 변경하지 않았다. 한컴 MCP 2020으로 원본을 HWPX로 저장한
결과는 바탕쪽 4개를 `OPTIONAL_PAGE`, 대상 번호 1·2·3·4로 선언했다.
원본 HWP 구역 끝 LIST_HEADER의 대응 값은 4·5·6·7이다.

대상 번호와 배열 순서를 분리하기 위해 빈 모델로 4쪽 문서와 3쪽 전용
바탕쪽 하나를 새로 만들었다. 한컴 저장 HWP는 바탕쪽이 하나뿐인데도
값 6을 기록했다. 이 독립 대조군은 원본의 대체물이 아니며 배열 위치를
쪽 번호로 추측할 수 없음을 확인하는 진단이다. 입력·MCP start/status/download와
원본 구조는 ignored `stage220-science-hancom-master-source`,
`stage225-clean-master-source`에 보존한다. 원본 HWPX에서 번호만 바꾼 별도
대조군은 서비스의 매크로 검사에 거절되어 변환하지 않았다. 매크로 제거·실행으로
우회하지 않았고 새 빈 문서의 진단과 구분했다.

## 원인과 구현 경로

구역 끝 확장 목록을 파싱하는 경로가 값 4·5·6·7을 확장/겹침 비트와
양쪽/홀수/짝수 배열 순서로 해석했다. 그 결과 임의 쪽 1·2가 기본 바탕쪽이
되고 나머지는 마지막 쪽에 적용됐다. 한컴 저장본과 단일 3쪽 대조군은
해당 값이 지정 대상 쪽 번호 + 3이라는 독립 근거다.

HWP 구역 끝 목록의 임의 쪽 범위를 모델의 별도 대상 번호로 보존한다.
HWPX OPTIONAL_PAGE도 같은 번호 계약을 사용한다. 기본 Both/Odd/Even,
LAST_PAGE, 페이지 안의 숫자 표시 힌트는 지정 쪽 범위와 구분한다.
선택은 구역 안 실제 쪽 위치로 판단하며 같은 범위의 대체/겹침 계약을 소비한다.
HWPX와 HWP 저장에도 지정 범위를 보존한다. 원본 raw LIST_HEADER는 유지한다.

과학·국어·사회와 기본/마지막 바탕쪽 대조군을 직접 확인한다. 임의 대상이
현재 쪽과 다르면 적용하지 않고, 단일 바탕쪽이라도 전체 쪽으로 확장하지 않는다.
전체 Native/fresh WASM·확대 판독·새 이름 회귀·최종 lint는 아직 미검증이다.

## 단일 지정 쪽 대조군의 PDF 한계

빈 모델 대조군의 한컴 Print는 4쪽이고 `pdf_print_method=0`,
`pdf_output_mode=hancom2020_pdf_driver_one_up`을 확인했다. 그러나
독립 PDF의 텍스트 추출에서 바탕쪽 문구 `MASTER3`는 어느 쪽에도 없다.
이 대조군은 지정 번호 3의 HWP 저장 값 6을 확인하는 메타데이터 증거이며
바탕쪽 문구의 실제 3쪽 표시·시각 일치·회귀 통과 증거로 사용하지 않는다.
실제 표시 보정은 원본 과학·국어·사회와 독립 Print로 검증한다.
새 합성 렌더링 회귀를 추가하지 않았다.

## 빌드 복구와 실제 바탕쪽 내용

Source `9dde0ca97591f3e7265b381881c357fe4a68f601`의 실제 컴파일은
6분 13초에 완료됐지만 기록 프로세스가 SIGTERM으로 종료됐다. 원 Cargo의
최종 exit code는 미확인이다. 소스 해시 불변과 프로세스 종료를 확인한 뒤
동일 Cargo 명령을 실행해 exit 0을 확인했다. 재확인 Cargo는 캐시를 재사용해
0.33초에 끝났으며 원래 실제 컴파일과 구분했다. 재확인 뒤 실행 파일의
SHA-256은 `89cf137f689bf2fdf23cb67f9a85bb44f17427d2321c2f3ee701abb28e70a8e3`다.
소스 해시가 같은 복구 산출물로 비교 큐를 다시 시작했다. 최초 큐는 빌드
결과 파일 생성 전 시작한 순서 오류로 종료됐고 `stage226-queue-initial-error.json`에 보존했다.

복구 바이너리로 과학 원본 4쪽을 각각 실제 render-tree로 출력했다. 바탕쪽의
내용은 1쪽 `1/32`, 2쪽 `2/32`, 3쪽 `31/32`, 4쪽 `32/32`와 확인 사항이다.
독립 한컴 저장본의 지정 대상과 대응한다. 쪽 번호의 누락·잘못된 반복을
정정했지만 본문 시각 점수의 통과 증거로 쓰지 않는다. 전쪽 Native 비교는
진행 중이며 fresh WASM·최종 회귀·lint도 남아 있다. 원본과 명령·실행 결과는
ignored `stage228-science-master-pages/receipt.json`에 있다.
