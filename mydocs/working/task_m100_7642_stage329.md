# Stage 329 — 명령 우선순위의 독립 Print 반례와 다음 보정 범위

Issue: #7642

한컴 2020 일반 저장과 별도 Print 출력으로 24개 수식의 명령 우선순위를 확인했다.
저장 전후 script가 같고 PDF는 전체 1쪽이다. 입력·전송본·한컴 저장본·Print PDF를
`pdf/issue7642-structure-argument-boundary-diagnostic/`에 보존한다. job과 파일 해시는
그 폴더의 README에 기록했다. raw trace·실행 로그는 ignored output에 둔다.

- `OVERLINE`은 `OVER`보다 긴 실제 장식 명령이며 먼저 인식해야 한다.
- `OVERSET`·`ATOPSET`은 각각 중위 명령과 뒤 문자로 분리된다.
- `UNDER`는 밑줄 명령의 별칭이다. 혼합 대소문자의 긴 명령을 임의로 합치지 않는다.
- Print의 `\sqrt`, `\frac`, `\matrix`, `\sin`은 공개 LaTeX API와 달리 문서의 문자다.
- Stage 327의 기저 없는 첨자·누락 피연산자는 읽은 앞 항을 보존하고 뒤 입력을 중단한다.
  명시적 빈 첨자 `{}`는 같은 오류로 분류하지 않는다.
