## 검증 계획

AST로 제거 대상 함수와 남은 함수 집합을 대조한다. 전용 파일은 하위 이슈와 보존 경로를 가리키는 문서 주석만 유지하여 실행 대상에서 분리한다. 원장 재생성기가 #7821의 oracle 행을 다시 포함하지 않는지 확인한다. 공유 target의 Cargo 작업이 실제 종료된 뒤 변경을 적용하고, 파생 suite 준비·fmt·필수 lint와 고정 base 정책 검사 및 남은 혼합 검사를 순차 실행한다. 원시 로그·TSV·중간 JSON은 ignored output에 둔다.

이전 stage136 집중 실행은 22개 중 21 PASS / 1 FAIL로 종료했다. 남은 실패는 `svg_snapshot::table_text_page_0`의 기존 가운데 정렬 검사이며, 이번 이관 대상이 아니다. 해당 검사는 보존하고 별도의 출력·독립 Print 비교를 통한 보정 범위로 남긴다. 이 결과를 전체 회귀 통과로 기록하지 않는다.
