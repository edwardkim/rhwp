# #7642 한양중고딕 프로그램 대조와 대체 선택 후보 폐기

Issue: #7642. 새 Native/fresh WASM 검증과 PR 준비는 진행 중이다.

## 확인한 프로그램과 보존한 고유 폭

한양중고딕의 ASCII95자·크기·자간·굵기 대조군을 정상 저장·Print했다.
정상 저장 job은 `0eef0abb-2997-4264-b6c7-c5ac7dd141a6`, Print job은
`beda1681-6c6e-4d10-bcbf-4fd1949e5d1d`다. 정체·굵게 Type3의 intrinsic
ASCII95자 폭은 모두 같다. 숫자는500/1000em, 괄호는288/281/1000em이다.
굵기 전진과 고유 폭을 구별하여 검증된 HFT 표의 마지막 항목으로 추가했다.
원본이 HFT로 해소되는 경로에서만 사용하며 기존 항목 순서는 유지한다.

## 반례와 폐기한 가정

법령 입력 `samples/issue6776/78494-virtual-convergence-industry-decree.hwpx`는
실제 HWP5 바이트다. 원본 FACE_NAME은 TTF 선언과 HY 대체 이름을 저장한다.
기존 독립 PDF는 H2gtrM TrueType이며 괄호 전진이 약0.416em이다. 설치된
H2GTRM.TTF의 괄호도426/1024em이다. 현재 한양 HFT 폭의 괄호는 더 좁아
표의 첫 셀이 한 줄에 들어가고 행 높이·후속 위치가 달라진다.

그러나 같은 TTF 선언만 넣은 대조군은 한컴에서 Type3 HFT로 Print됐다.
명시적 HY중고딕 substFont도 추가해 정상 저장·Print했으며 결과는 역시 Type3다.
후자의 정상 저장 job은 `0333e715-349a-458c-ad49-1e84a5aa646a`, Print job은
`00ccea07-6f12-4543-9f95-ab75ad85f90b`다. HWP로 저장된 실제 대체 정보도
별도로 읽어 확인했다. 따라서 이름·TTF 플래그·대체 이름만으로 실제 프로그램을
선택하는 후보는 충분하지 않다. 조건을 더 좁혀 유지하지 않고 후보를 폐기했다.
그 후보의 helper·스타일 선택·paint 체인 변경은 실제 소스에 남기지 않았다.

폐기한 diff와 원본 레코드·설치 hmtx·PDF 프로그램·교차 Print는 ignored
stage2398~2408에 보존한다. 기존 원본과 PDF는 바꾸지 않았다. 같은 원본 바이트를
확장자만 `.hwp`로 복사한 진단 입력의 Print가 진행 중이며, 프로그램 선택을
확인하기 전까지 실제 표 높이 보정이나 회귀 기대값 변경은 보류한다.
