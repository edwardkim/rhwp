## 새로 출력한 원본의 확대 판독

`eq-002.hwp`와 그 HWPX는 Native/fresh WASM 모두 97.30842%, `exam_math_8.hwp`는
모두 96.47709%다. 각 원본의 새 review와 같은 물리 영역 확대 패널을 만들고 직접 열었다.
전체 점수는 통과하지만 분수가 들어간 첨자의 세로 배치와 중괄호 옆 간격을 추가 확인한다.

가로 원점 차이는 작으며 분수 첨자의 세로 배치 차이가 더 크다. PDF span의 대표 origin만
보면 분자와 뒤 `f(n)`이 같은 기준선처럼 보이지만, 같은 span 안 글자들의 실제 origin은
다르다. span을 하나의 글자 행으로 가정하지 않는다. 원본의 script와 명시 공백을 보존한다.

## 독립 49개 메트릭 대조

일반 글자·보통 분수·분수 뒤 함수·보통 첨자·분수 첨자·분수/함수 첨자·명시 공백 뒤
분수 첨자를 600/612/900/1020/1496/1500/2200HU에서 한 묶음으로 만들었다.
612/1020/1496은 실제 9/15/22pt의 첨자 크기다. 수식 크기와 기준선을 비운 입력에서
한컴이 저장한 control 메트릭을 원시 파싱하며 현재 layout 계산이나 로드 정규화를 사용하지 않는다.

Print job `97ef7c4e-7a3f-4806-b189-b87b65b0551f`으로 출력했다. 실제 11.0.0.9136·PrintMethod 0·1-up·PDF 2쪽이다.

기준값을 갱신하지 않고 일반 분수·첨자·줄 소속의 공통 결과와 실제 표시 원점까지 추적한다.
