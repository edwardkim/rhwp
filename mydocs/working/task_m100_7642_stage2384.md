Issue: #7642. 이번 단계는 PR 준비 중간 기록이며 승인·통합 완료를 뜻하지 않는다.

## 기준과 이력 보존

`upstream/devel`이 `b7a5388034`에서 `9415b920c8dec299e8ada69b01dbd1c3c044f1f1`로
38개 커밋 전진해 작업 브랜치를 리베이스했다. 완료 HEAD는
`056d370f89e940f0404d649bc1c52886f2469dc8`이다. 원래 856개 커밋을 유지했다.
846개 패치는 동일하며, 9개는 충돌 해소 또는 문맥 변화가 있다. raw 판정 변경의
중복 구현은 새 devel에서 받아들이고 같은 커밋의 작업 기록은 보존했다.

충돌은 이미지 색조·캐시, paint 설정, 셀 도형 기준 좌표와 모듈 등록에서 발생했다.
문단 기준 도형은 새 devel의 문단 좌우 여백을 소비하고, 종이·본문·단 기준은
각 기준 프레임을 유지하도록 합쳤다. 원본색 2024 bitmap과 효과가 있는 일반
raster/WMF의 조건을 보존하고 캐시 신원의 선택 함수를 공유했다.
추적 파일의 미커밋 변경은 없으며 기존 미추적 입력 183개는 해시가 모두 일치한다.
충돌 파일의 rustfmt와 리베이스로 추가된 차이의 공백 검사는 통과했다.

왕복본 Print job은 `5edce303-b214-439a-bfc8-a55f1cee3e6b`다. engine 2020의

새 이름의 정식 회귀와 기존 실패 기대값의 교체는 아직 보류했다.

## 다음 보정의 독립 근거

표지 날짜의 원본 속성은 한양신명조 HFT, 28pt, 굵게, 장평 100%, 자간 0이다.
독립 Print의 Type3 T1 /Widths는 숫자 500/1000em이며 실제 TJ는 추가 전진을
갖는다. 현재 bbox 폭과 PDF span의 단순 차이를 새 상수로 복사하지 않는다.
정체·굵게, 크기·자간과 TTF 대조군을 독립 한컴에서 정상 저장·Print하여 원본
프로그램의 전진과 표시 glyph 폭을 분리한다. 확인되지 않은 HFT 전체로 확대하지 않는다.
