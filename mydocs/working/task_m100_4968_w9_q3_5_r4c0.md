## 1. 결론

R4B의 개별 run 측정을 한 layout/reflow transaction에서 재사용하고, 여러 run의 결과를 문단의 `N+1`
position map 하나로 원자적으로 합치는 계약을 추가했다. slot binding의 registry generation, exact source handle
해소, per-face source cache가 이제 같은 `KerningLayoutSession` 수명에 고정된다.

문단 측정은 실제 pair 적용 segment가 하나라도 있을 때만 adjusted position map을 만든다. K0 또는 모든
segment가 기존 positions를 유지하는 경우에는 base map을 복제하지 않는다. range·상한·수치 검증이 하나라도
실패하면 일부 segment 결과를 게시하지 않고 문단 전체를 base positions로 되돌린다.

이 절편은 paragraph segmentation이나 제품 line breaker에 연결하지 않았다. 따라서 layout 결과를 바꾸는
R4C-1 이후 작업에 앞서 owner·수명·원자적 commit/rollback 계약만 출력 무변화 상태로 고정한 것이다.

## 2. 구현 계약

### 2.1 layout transaction

`KerningLayoutSession`은 `LayoutEngine`의 exact-font registry를 transaction 동안 빌린다.

- 생성 시 registry generation을 고정한다.
- slot에서 payload-free source handle을 해소한다.
- 기존 R2 `KerningSourceSession`을 소유해 동일 face의 parse·capability cache를 재사용한다.
- K0에서는 slot lookup을 생략하고 R4B의 source-미접근 fast path를 사용한다.
- source bytes·경로·family 이름은 session 결과나 trace로 복제하지 않는다.

`LayoutEngine::exact_font_layout_session`은 이 transaction의 단일 owner 진입점이다.

### 2.2 owned paragraph measurement

`KerningParagraphMeasurement`는 다음을 소유한다.

- 문단의 기존 `N+1` base positions
- 실제 pair 적용이 있을 때만 존재하는 adjusted positions
- Unicode scalar half-open 범위와 exact slot을 갖는 segment measurement
- 문단 disposition과 구조화된 rollback 이유
- 최대 256개 segment의 bounded 회계

`positions()`는 adjusted map이 없으면 base map을 그대로 반환하고, `range_width(start, end)`는 token·긴 단어·
line boundary가 앞으로 같은 owned map을 소비할 수 있는 공통 범위 API다.

### 2.3 원자적 commit과 rollback

문단 합성은 각 R4B segment의 advance delta만 해당 scalar 범위에 더한다. 다음 조건은 문단 전체 rollback이다.

- 4,096 code point 또는 256 segment 상한 초과
- base position 수·finite·monotonic 불일치
- segment 범위 오류·겹침
- 문단 base와 segment base의 상대 위치 불일치
- segment code point·advance 수 불일치
- 합성된 position의 non-finite·non-monotonic 결과

개별 segment가 R4B에서 fail-closed된 것은 zero delta segment로 취급한다. 따라서 그 실패가 검증된 다른
segment의 적용을 임의로 막지는 않지만, 문단 구조 검증 실패는 언제나 전부 rollback한다.

## 4. 보호 불변식 확인

1. K0는 registry slot 조회와 source parse 없이 기존 positions를 그대로 반환한다.
2. exact slot과 segment 범위를 명시하고 서로 다른 slot 사이에 pair delta를 합치지 않는다.
3. adjusted map은 검증이 전부 끝난 뒤 한 번만 commit된다.
4. 상한·구조·수치 실패 시 일부 K1 결과를 남기지 않고 문단 전체를 K0 positions로 되돌린다.
5. font payload·private path·family 이름·원문은 measurement와 trace에 남기지 않는다.
6. 제품 line break·page tree·backend는 아직 이 계약을 소비하지 않는다.
