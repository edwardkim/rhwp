## 충돌 해소의 의미

- CanvasKit의 WebGPU 초기화와 수학 기호 폴백을 함께 보존했다. 정적 레이블은
  준비된 Paragraph 글꼴을 사용한다. 수식의 일반 문자에는 기존 자연 폭 표시를,
  문자 조합이 필요한 입력에는 준비된 Paragraph 경로를 연결했다.
- upstream의 극한 이름 글리프 상자와 기존 이름·하한 크기를 함께 전달했다.
  생산자가 이름의 실제 폭·글리프·기준선을 정하고 JSON과 각 painter가 소비한다.
  추출된 limit_geometry와 box_types에도 같은 필드를 보존했다. 변경된 실제 출력은
  독립 Print와 다시 대조해야 하며, 이전 수식 통과 결과로 승인하지 않는다.
- 새 Native 글꼴 카탈로그와 설치 글꼴 별칭·HFT 해소를 함께 유지했다.
  옮겨진 글자 크기 helper에 크기0과 미지정 값의 구분을 적용해 중복 정의를 피했다.
- 그라데이션은 upstream의 공통 shape_fill 경로가 원본 색상·축·패턴·opacity를
  소비한다. stop 수와 f32 출력 경계, 유한 opacity 검사를 유지했다. 중복 wrapper는
  제거했다.
- 이미지의 실제 장치 축소 여부를 공통 predicate로 조회해 기존 mipmap cache에
  연결했다. 이때 기존 profile·원본 픽셀 효과·nearest 선택과 자원 소유는 유지했다.

## 이번 선행 검사

`tsc --noEmit --pretty false`는 exit0이다. Rust 형식 검사에서 충돌 해소 부분
3개 파일의 차이를 확인해 rustfmt로 정리했고, `cargo fmt --all -- --check`를
다시 실행해 exit0을 확인했다. `git diff --check`도 통과했다.

CanvasKit 계약 검사는 새 stroke cap 조회와 숫자 상자의 scale을 테스트 대역이
제공하지 않아 먼저 실패했다. Paint getter/setter와 Canvas scale을 보완했다.
점선 구현의 if 문 모양을 찾던 중복 정규식은 제거했다. 실제 실행에서 네 점선의

assertion은 유지했다. 숫자1과 상자 표시 검사도 유지했다. 최종 실행은

픽셀 기대값·golden·시각 문턱을 변경하지 않았다.
