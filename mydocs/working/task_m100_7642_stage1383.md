# Issue #7642: 언어 원본의 두 단 경계와 독립 Print 위치 회귀

## 수용 범위와 선행 증거

원본 HWP5 `samples/21_언어_기출_편집가능본.hwp`와 독립 한컴 Print `pdf/issue7642-exam-print/exam-01-21_언어_기출_편집가능본-hwp-print-2020.pdf`는 이미 Git에 있다. 새 사본이나 baseline을 추가하지 않는다. 인쇄 프로필·compat2022·96dpi·동일 시스템 글꼴을 사용했다.

- 검증 생산 source: `ee09c2d7c`. Native는 커밋 전 같은 작업 트리로 빌드했고 커밋 후 전체 source hash를 재대조했다. `stage1360-current-native.json`의 `committed_source_sha`와 `commit_source_hashes_equal`에 연결했다. fresh WASM은 이 커밋으로 최적화 빌드한 `stage1368-fresh-wasm-build.json`이다.
- Native 전 15쪽 최저 94.96332%, fresh WASM 전 15쪽 최저 94.93966%. 양쪽 모두 독립 PDF 15쪽과 같고 누락·90% 미달 쪽이 없다.
- 변경한 핵심 동작은 같은 문단이 왼쪽 단에서 오른쪽 단으로 이어받는 10쪽이다. 같은 결함의 원본 17개 저장 줄과 후속 문단이 함께 있는 이 쪽을 선정했다. Native 99.46707%, fresh WASM 99.50862%다. 다른 내용의 더 높은 쪽을 대신 고르지 않았다.
- Native와 fresh WASM의 전쪽 TSV, 정상 review와 확대 대조를 별도로 직접 열었다. 같은 쪽의 첫 원문 줄, 오른쪽 단 이어받기 2줄, 후속 문단과 「낙론계 유학자들」을 확인했다. 원문 17줄의 누락·중복·단 소속과 앞뒤 순서를 검사한다. 글꼴 외곽·명암의 미세 차이는 자동 점수와 구분하며 픽셀 완전 일치로 쓰지 않는다.

## 새 검사와 독립 좌표

새 파일은 `tests/cases/verified_language_print_column_fragments.rs`, 함수는 `verified_language_print_keeps_source_column_fragments_and_following_paragraph`다. 기존 시험지 검사와 이름을 공유하지 않으며 기존 파일을 이 단계에서 변경하지 않았다. 이미 관계형이었던 검사를 교체했다고 세지 않는다. 새 검사는 원본 내용으로 문단을 찾고 원본 저장 줄의 문자 시작, 실제 전체 페이지의 쪽·단 소속, 내용 보존과 후속 문단 비겹침을 확인한다.

완료된 10쪽에만 독립 Print의 문자 원점(pt)을 96/72로 변환한 다음 값을 ±2 CSS px로 추가했다. 좌표로 노드를 검색하지 않는다. 원본 소유와 줄 순서로 찾은 노드를 검사한다.

Native 라이브러리를 직접 연결한 단계 1384에서 기존 HCI 독립 메트릭 2개와 이 새 검사 1개는 통과했다. 이때 HWP3 parser만 추가 보정한 source의 Native 라이브러리를 썼고 HWP5 경로는 그대로다. 최종 전체 nextest·lint·현재 head의 시각 검증을 완료한 것으로 쓰지 않는다. 언어 7·8·15쪽 등 devel 대비 하락과 다른 문서 미달의 재검토도 남아 있다. PR 준비 완료·승인 판정이 아니다.
