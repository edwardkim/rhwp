# 이어받기 물리 위 띠의 정렬 소유

## 독립 근거와 원인

기존 #7518 valid_orientation/nested-split 5쪽과 #8060 원본 20쪽의 실패를
독립 Print·원본 속성·현재 Native251의 최종 렌더 트리로 대조했다. 원 PR #7518의
NO_LS 흐름·실제 메인터너 보정 기록과 #8060·원 PR #8059의 마지막 atom 꼬리
회계도 확인했다. atom의 보이지 않는 뒤 간격은 기존대로 쪽 밖으로 흐른다.

4014의 두 소유 셀은 모두 가운데 정렬, 위·아래 안 여백 각각 141HU이며,
자식의 위 바깥여백은 283HU다. 예산은 이어받기 위 띠를 포함하지만 정렬의 내용
높이는 raw CellUnit 합만 사용했다. 따라서 빈 공간으로 오해한 283HU의 절반인
약 1.8867px만큼 내용과 자식이 함께 내려갔다. 독립 Print 대비 약 2.11px 차이의
원인은 허용 오차 부족이 아니라 서로 다른 점유 회계다.

- #7518: 셀 y=58.573333, h=131.306667, 내용=123.773333, 안 여백 합=3.76px.
  현재 text_y=62.34이고 위 띠 3.773333px 뒤 자식 y=66.113333이다.
- #8060: 셀 y=77.48, h=61.733333, 내용=54.2, 안 여백 합=3.76px.
  현재 text_y=81.246667이며 자식 y=85.02다.

측정·컷 예산이 이미 사용하는 `nested_continuation_header_height`를 해당 정렬
분기도 소비한다. 새 좌표 상수·문서별 조건·오차 완화는 추가하지 않는다. 첫 조각과
중첩 이어받기가 없는 컷의 기존 0값, 반복 제목행·위 바깥여백 및 atom 꼬리 계약을
그대로 사용한다. 실제 원점 계산에서 위 띠를 다시 더하지 않도록 숨기는 보정이 아니다.

## 검증 범위

기존 독립 ±2px 검사와 소유·순서·누락·중복·부모 포함 검사를 유지한다. 현재 실패한
세 검사·정상 프레임 대조군을 먼저 실행한 뒤 해당 기존 원본의 전쪽 Native/fresh
WASM과 review·overlay를 검증한다. 최종 전체 Rust·lint는 새 소스에서 다시 실행한다.
이 문서는 원인과 보정 계획이며 실행 전의 성공으로 기록하지 않는다. 삭제된 제외
대상의 검사·입력·파생 참조는 새로 생성하지 않는다.

## 4015 실행과 최종 소비 지점의 추가 보정

Native252 빌드는 256.29초·exit 0·source_unchanged=true다. 기존 집중 99건은
95 PASS / 4 FAIL이다. #7518 두 건과 #8060 한 건의 위치 차이가 그대로 남았고,
#5846은 기존의 실제 기호 공급자 선택 조건에서 실패했다. 통과로 기록하지 않는다.

원점 차이의 원인은 맞지만 첫 수정은 우선순위가 뒤인 정렬 분기에만 적용했다.
앞에서 선택한 `total_content_height`는 `nested_cell_cut_content_height`가
raw 유닛 합과 물리 보정 차이만 더하고 시작 띠를 빠뜨린 결과다. 물리 보정 함수의
`reserved`에는 그 띠가 이미 포함돼 있으므로, 그 차이만 더해도 시작 띠는 복원되지
않는다. 이 공통 내용 질의에도 같은 `nested_continuation_header_height`를 적용한다.
기존 opt-in 정렬 진단에는 실제 선택 분기를 식별할 수 있는 소유 플래그를 보완했다.
새 Native producer에서 기존 검사와 같은 경계를 다시 검증한다.

## 최종 소비 지점 보정 뒤 실행 결과

`11dc162752ebcd30084757a4f9e20d18d0d8189a`의 Native253에서 #7518 두 검사와
#8060 한 검사는 기존 ±2px 기대값을 바꾸지 않고 통과했다. 집중 99건 중 남은
#5846의 실제 기호 공급자 선택 조건을 독립 Print에 맞게 교정한 뒤 99건 모두 통과했다.

#7518 6쪽의 Native/fresh WASM072 최저 raw는 99.96132/99.95693%,
#8060 48쪽은 96.73952/96.69927%다. 독립 Print와 전체 쪽수가 일치하며,
#7518 5쪽과 #8060 20쪽의 canonical review·standalone overlay를 직접 판독했다.
고정 base와 대조한 해당 전체 페이지의 0.1%p 초과 하락은 양쪽 모두 0쪽이다.
최종 전체 Rust·lint는 별도 종료 결과가 필요하며 이 집중 실행으로 대체하지 않는다.
