# #7642 일반 재조판 행의 실제 내용·물리 밴드 계약

Issue: #7642. 앞 단계 후보 `7b7645f297`의 Native·기존 회귀 검증은 실행 중이다.

## 직접 판독과 독립 기준

`7606228e9e`의 원본 #7028은 전쪽 Native 90%를 넘었지만, 같은 SHA의
`stage3117` review·overlay 확대 판독에서 3쪽 하단선 차이가 남았다.
그 행은 다른 행까지 이어지는 병합 칸이 없이 자기 내용 컷으로 계속된다.
선언 최소가 따로 크거나 병합 칸이 있을 때만 물리 띠를 예약하는 가정은
이 일반 행에서도 성립하지 않는다. 빈 문단·내용 유닛을 제거하지 않는다.

작은 독립 Print의 일반 6행·2열·80px 최소 상자도 같은 경계다. 남은 68px에
13.333333px의 한 줄이 온전히 들어간다. Print는 그 줄을 현재 쪽에 두고
남은 빈 최소 상자만 다음 쪽에 둔다. Native는 고정 25px 조건 때문에 행을
전부 이월한다. 가운데·아래 정렬의 실제 글자가 예산 밖에 있는 경우까지
허용하지 않으며, 개체·중첩 유닛·저장 줄의 계약은 기존 경로로 남긴다.

기존 전체/분할·빈 문단 대조군에서 빈 문단이 다음 쪽에 남는 것은 정상이다.
작은 블록 경로의 별도 미달도 보존하며 이 일반 행 보정의 통과로 보고하지 않는다.

종료 병합 칸에 긴 여덟 문단을 둔 독립 Print 반례도 확보했다. 일반 컷이 비어
있어도 `end_row_height_override`로 실제 마지막 행을 나눈 경우는 원본 내용의
부분 종료다. 기존 mapper가 행 소속만 보고 그 칸의 끝을 무조건 `usize::MAX`로
정해 뒤쪽 내용을 앞쪽에 소비한 것으로 만들었다. 측정과 paint의 종료 경계는
같은 실제 부분 상자를 인식하고, 그 높이에 들어간 유닛만 수용하도록 고친다.
앞 단계의 Native 최저 43.98726%를 통과 증거로 쓰지 않는다.

## 공통 결과와 소비 경로

일반 글줄로 재조판한 행은 내용 높이와 선언 최소의 대소에 관계없이 실제
쪽 프레임을 사용한다. 같은 `owns_plain_row_frame` 판정이 whole-row 허용,
완전 소비 내용의 밴드 적격성, 부분 컷의 실제 예산과 최종 수용 상자를 잇는다.
유닛이 모두 들어간 짧은 일반 글줄에는 고정 고아 조각 하한을 적용하지 않는다.
정렬된 내용 끝·패딩·페이지 예산 검사는 유지한다. `end_row_height_override`와
수용 높이를 함께 전달해 PageItem·paint·다음 조각 원장이 같은 상자를 사용한다.
배치 뒤 마지막 행을 접는 `fold_last_row`의 소유 판정도 같은 재조판 일반 행을
인식한다. 스캔에서 예약한 빈 띠를 paint에서 내용 높이로 다시 접지 않는다.
병합 칸도 행 끝의 실제 부분 상자를 같은 유닛 종료 판정에 사용한다. 종료 행
소속과 실제 유닛 소비를 구분해 뒤 조각에 남은 글줄을 앞쪽에서 소비하지 않는다.

쪽 맨 위에서도 내용 완료가 선언 최소 완료는 아니다. 실제 내용과 정렬이
현재 프레임에 들어가면 큰 선언 최소를 같은 실제 상자로 나누고 정확한
나머지를 이어받는다. 내용이 이미 완료된 뒤의 빈 최소 공간도 양의 물리
전진으로 소비하며, 마지막 유닛을 다시 표시하지 않는다. 기존 480px 최소
대조군의 Native 7쪽/Print 10쪽 불일치가 이 경계를 직접 검증한다.

본문 전체를 선언한 개체 프레임은 기존 하단을 유지한다. 그 밖의 일반
프레임은 다른 위치의 rowspan 존재만으로 기존 100HU 하단 inset을 버리지 않는다.
이 값은 새로 만든 px 보정이 아니다. 같은 helper를 쓰는 예산·paint의 원래
원본 단위 계약을 복원한다. 새 PDF는 MediaBox가 595×841pt이고 입력은
595.28×841.89pt이므로 Print 드라이버 용지 반올림과 행 배치 결함도 구분한다.
이 반올림을 문서별 좌표 보정으로 상쇄하지 않는다.

## 검증과 보류

현재 Cargo가 끝난 뒤 고정 `target/pr-review`와 빌드 잡 8개를 사용한다.
원본 6쪽의 하단선과 앞뒤 내용, 작은 병합·비병합·짧은 글줄·빈 문단·전체/분할
대조군, 기존 53쪽과 #7969 13쪽을 먼저 확인한다. #7226의 실제 소유 회귀도
유지한다. 알려진 차이가 남은 이전 후보의 대기 WASM은 빌드 전에 중지했으며
시작·통과로 기록하지 않는다. Native/fresh WASM과 직접 판독을 마치기 전에는
새 fixture·golden·회귀 기대값을 추가하지 않는다. 기존 실패 기준도 완화하지 않는다.

`6eda1805d2`의 첫 Native 빌드는 새 종료 상자 인자를 mapper 선언에 전달하지
못한 E0425로 실패했다. 실제 물리 컷을 가진 수용·paint 호출은 종료 상자를
전달하고, 온전한 종료를 질의하는 저장/이어받기 측정 호출은 `None`을 전달하도록
보정한다. 실패한 빌드와 그에 의존한 미실행 검증을 통과로 기록하지 않는다.

## 선행 검증에서 검출한 회귀

`9a02ef911f`의 Native 원본 6쪽은 최저 98.83256%지만, 기존 #7518 7쪽의
100%가 95.54841%로 내려갔다. 29개 기존 Rust 중 #7226의 인접 예산 -75에서
마지막 줄이 사라져 28 PASS / 1 FAIL이다. 문단·블록 대조군도 미달이 남아
fresh WASM은 시작하지 않았다. 새 기대값이나 허용치로 통과시키지 않는다.

저장 줄의 원본 종료와 재조판 일반 글줄의 물리 종료는 서로 다른 계약이다.
끝 행의 물리 상자가 있다는 이유만으로 저장 줄의 끝을 높이로 다시 선택한
가정을 제거한다. 실제 재조판 일반 문단일 때만 높이 컷을 적용하며, 저장 줄은
명시 원본 컷과 기존 프레임 소유를 유지한다. 같은 출처 판정을 수용과 paint가
공유한다. #7518의 불필요한 빈 띠 확장은 별도의 문단 경계 판독으로 보정한다.
