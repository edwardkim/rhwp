# Stage 116 — 관계형 검사 실행 실패와 검증 자원 복구

Issue: #7642. 기존 전체 입력·회귀 전환·필수 검증 범위는 유지한다.

## 실제 실패와 다음 보정 범위

Stage 114의 원본 형식 HWP 저장본은 Native/fresh WASM 전쪽 최저 95.16239%다.
그러나 저장본 재열기와 실제 편집 인스턴스의 Undo는 다르다. 정식 세 검사 중
배치 복원 검사가 실패했으며, 좌표 허용치 변경으로 통과시키지 않는다.

관측 경로는 `set_shape_properties_native`의 모델 크기 변경 → `section.raw_stream = None`
→ `Document::layout_profile`의 문서 전체 `session_edited` → 재조판·측정·최종 배치다.
저장 줄 자체가 바뀌지 않은 문단까지 편집 상태로 분류되어 원점/간격 수용 조건이 바뀌는지
확인한다. 같은 결과를 공유해야 할 측정·배치 양쪽의 소비 분기를 찾고, 실제 입력의
실패를 보정한 뒤 관계형 검사를 다시 실행한다.

생산·소비 경로를 좁혀 `typeset::controls::paragraph_flow`의 전폭 표 호스트 계획에서
문서 전체 편집 플래그에 의한 거절을 제거했다. `inline_flow::stored_host`는 현재
`MeasuredTable.total_height`가 선언 프레임 안에 있는지 확인한다. 측정 누락·비정상 값·
내용 증가로 프레임을 넘는 경우는 거절한다. 기존 저장 줄의 dirty 상태·합성 태그·
앞뒤 줄 원점·현재 표 배제 하단 대조도 유지한다. 문서 ID나 관측한 좌표로 분기하지 않는다.
셀 편집으로 표가 자라는 반례와 일반 저장본의 무회귀는 추가 검증해야 한다.

확정한 계획은 `commit_stored_body_wide_host`에서 실제 수용한 줄 소유와 예산을 확인한 뒤
`inline_flow_plans`에 보존된다. 부분 본문 paint가 그 계획의 앞 간격 0과 줄 원점을
소비한다. 단순 원점 clamp로 Undo 실패를 가리지 않는다. 보정 뒤 세 관계형 검사는
공용 `target/pr-review`에서 실행 중이며 최종 결과 확인 전 통과로 기록하지 않는다.

HWP3의 저장 PGY를 HWPX 진단에 대입한 3·8쪽은 각각 66.00676%와 51.16980%다.
동일 좌표를 적용했다는 사실로 원본 개선을 선언하지 않는다. 해당 진단은 원본 HWP3의
정상 출력 증거가 아니며, 저장본 프로필·그림 앵커·캡션·후속 본문을 구분해 분석한다.
비교와 overlay/review PNG를 `stage115-hwp3-stored-frame-selected`에 보존하고 직접 열었다.

## 디스크 복구와 전체 스윕 상태

전체 스윕의 `all-24/native`, `all-23/native`, `all-15/wasm`은 실제 실행 종료와
ENOSPC 기록이 있어 자원 실패로 분류한다. 미달/통과로 집계하지 않고 자원 복구 뒤
동일 원본·고정 소스에서 다시 검증해야 한다. 나머지 실행 중인 프로세스는 중단·재시작하지
않고 PID 시작 시각을 확인해 SIGSTOP/SIGCONT로 잠시 멈췄다가 같은 controller를 재개했다.

종료된 Print 진단과 이전 focused sweep의 중간 SVG를 경로·SHA-256 원장으로 정리했다.
입력·Print PDF·PNG·tree·TSV·로그·실패 기록과 공유 `target/pr-review`은 보존했다.
정확한 제거 내역은 ignored `stage116-completed-diagnostic-svg-cleanup.json`과
`stage116-terminal-sweep-svg-cleanup.json`, 프로세스 상태는
`stage116-whole-resource-pause.json`에 있다.

이번 정리는 종료된 진단 SVG 412개 5,353,952,896바이트와 종료된 sweep SVG
177개 7,488,836,776바이트를 제거했다. 추가 이전 완료 실행의 중간 SVG도 완료
summary와 현재 프로세스의 출력 경로 부재를 확인한 뒤 별도 원장에 정리 중이다.

현재 전체 스윕은 고정 소스 `a4454ac384f12bffe95eaec8356cefe2a63dda4c`의 증거다.
후속 코드 소스의 전체 시각 검증 완료로 승격하지 않는다. 새 PR·CI·오늘할일 trailing·merge는
전체 범위의 필수 검증 뒤 진행한다.
