# Stage 334 — 문자 글꼴 전환과 기호의 독립 Print 반례

Issue: #7642

Stage 330의 Native/fresh WASM 빌드와 소스 해시 보존·Studio 동기화가 완료됐다.
같은 source에서 science 전체 4쪽은 양쪽 모두 최저 92.77516%다. 추가 64쪽은
Native 최저 56.63767%, 8쪽 미달이며 여전히 보정 대상이다. 전체 검증 완료가 아니다.

새 독립 한컴 저장·Print 대조군 30개는 기존 문제의 해석 경계를 분리한다.
입력/전송 HWP/한컴 저장 HWP/Print PDF와 job·해시는 진단 폴더 README에 연결한다.
모든 script의 저장 전후 보존을 확인했다. 기준은 한컴 2020의 실제 Print 출력이며
문자 추출을 넘어 원시 glyph codepoint·font·bbox를 확인했다.

- LEFTARROW/RIGHTARROW는 이중 화살표이고 lowercase leftarrow는 단일 화살표다.
- LINE/line/Line은 같은 세로 기호다.
- 백슬래시 뒤 일반 문자는 ASCII 글리프다. 중괄호 종료로 변수 PUA에 복귀하지 않는다.
  명시적 it 뒤 글자는 PUA 변수로 복귀한다. 기존 rm/it 그룹 계약과 구분한다.
- escaped UNDERLINE은 인자의 첫 여는 중괄호를 표시한다. 중첩 내부 그룹을 전부
  문자로 펼치거나 다른 escaped 명령에 같은 규칙을 적용하지 않는다.

## 다음 묶음 보정

문서 tokenizer의 기호 별칭과 문자 전환 상태를 실제 Print에 맞추고, 원래 token의
위치·공백·항 소유는 유지한다. 현재 그룹 범위와 구분되는 문자 상태를 일반 글자의
측정·SVG·Canvas가 소비하는 공통 AST 글꼴 노드로 전달한다. escaped UNDERLINE의
표시용 첫 괄호와 원래 인자 닫힘을 함께 처리해 바깥 그룹 소유를 훼손하지 않는다.
공개 LaTeX tokenizer/parser에는 적용하지 않는다. 원본 소스를 동결한 before/after
probe와 기존 정식 검사, 영향을 받는 전체 Native/fresh WASM 대조군을 확인한다.
90% 이상·확대 판독 전에는 새 렌더링 회귀/golden을 추가하지 않는다.
