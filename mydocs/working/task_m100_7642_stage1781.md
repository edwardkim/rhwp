# #7642 글자 기준선·문단 테두리·인라인 도형의 공통 배치 보정

Issue: #7642

## 독립 기대와 원인

기준 제품은 `e4b59c9c4`다. `samples/exam_kor.hwp` 14쪽의 원본 글자 위치는 -10%다.
한컴 Print의 같은 본문 첫 줄 기준선은 약 315.04 CSS px, 다음 줄은 339.52 CSS px다.
TextStyle의 줄 기준선은 각각 316.5333·341.04, 글꼴 크기는 15.3333 CSS px다.
원본 속성의 이동만 적용하면 315.00·339.5067로 독립 Print와 일치한다.

현재 `script_draw_metrics`는 원본 -10%와 과거 `HY신명조` 이름의 -0.1em 보정을
둘 다 적용해 313.4667·337.9733으로 올린다. 같은 줄의 한양신명조 쉼표·물음표에는
이름 보정이 없어 315.00으로 남는다. 독립 Print에서는 같은 기준선이다.
기준 devel은 원본 위치를 소비하지 않고 이 글꼴 이름 보정만 사용했던 상태라,
새 원본 위치 지원 뒤의 이중 이동이 기존 후보의 국어 14쪽 하락에 기여한다.

원점과 속성은 1775단계 typed 페이지 트리, 독립 Print 원점은 1774단계에 보존했다.
조판 기대값은 현재 좌표에서 추정하지 않고 같은 원본의 Print와 원본 속성에서 정한다.

## 생산과 소비 경로

원본 언어 슬롯 글자 위치 → style resolver의 해소 속성 → text_measurement의
TextStyle.font_position → script_draw_metrics → Native/Canvas/SVG·paint의 실제 기준선이다.
줄 기준선·점유 높이와 표시 글리프 이동을 구분한다. helper 내부의 글꼴 이름 분기를
제거하고 선언된 글자 위치를 한 번만 소비한다. 조건을 더 붙여 특정 문서나 수치에만
제한하지 않는다. 위첨자·아래첨자의 별도 크기·기준선 계약은 그대로 소비한다.

## 검증 계획

수정한 source에서 Native/fresh WASM을 같은 공용 target에 순차 빌드한다.
국어 HWP/HWPX 전체 20쪽과 기존 정상 글자 위치·첨자 대조군의 전쪽 TSV를 먼저 산출하고,
영향 본문·구두점·대표 변경 영역을 독립 Print와 같은 배율로 직접 확인한다.
0·양수·음수·글꼴 이름이 다른 경우와 위/아래첨자의 조합도 필요한 범위에서 확인한다.
전쪽 90% 및 직접 판독 뒤 새 이름의 관계 회귀를 추가한다. 완료 페이지 양쪽 98% 이상이면
중요 위치는 독립 Print ±2 CSS px와 내용 관계로 함께 보호한다.

이 수정은 수학 콜론의 별도 글리프·간격 결함을 해결한 것으로 보고하지 않는다.
정상 한컴 저장 콜론 대조군의 12pt 페이지에는 별도 줄 간격 차이도 관측돼 추가 분석한다.
전체 회귀·시각 gate 완료 전 PR은 만들지 않는다.

## 사용자 지적 영역의 추가 추적

국어 14쪽은 기준선 보정 뒤 Native 97.15305%지만 완료 판정하지 않는다.
본문 오른쪽 테두리와 바탕쪽 `홀수형` 상자의 차이가 직접 판독에서 남았다.

- 문단 단의 오른쪽 끝은 540.4533 CSS px다. 실제 출력한 인용 표의 끝은 531.0133인데,
  별도 `compute_square_wrap_tbl_x_right`가 오른쪽 오프셋 708 HU를 반대 부호로 더해
  549.8933으로 추정했다. 이 값이 어울림 호스트 테두리 override에 들어가 연결 그룹
  전체를 넓힌다. 부분 표 경로도 같은 추정 함수를 사용한다.
- 가로 보정은 표의 정렬 식을 다시 복사하지 않고, 같은 단에 이미 배치된 동일 원본
  소유자의 Table 노드 최종 오른쪽 끝을 테두리 확장 판단에서 소비한다. 실제 외부 표를
  둘러싸는 기존 동작은 유지하며, 출력 위치의 근거가 없는 추정값은 사용하지 않는다.
- `홀수형` 독립 Print 외곽은 CSS 좌표 (922.9906, 148.7347)–(1002.1040, 188.3973),
  현재 Rectangle은 (924.0000, 137.4933)–(1003.3067, 177.1600)이다.
  셀의 빈 TAC 도형에서 paragraph가 등록한 inline 위치 없이 이전 문단 y로 돌아가는
  별도 경로를 추적 중이다. 공통 기준선 계약의 근거를 더 확인하며 임의 상수 이동은 넣지 않는다.

독립 PDF의 도형·소스 속성·최종 typed 트리는 1794·1796단계에 보존했다.
이 지적을 90% 점수나 글꼴 차이로 면제하지 않는다. 수정 뒤 같은 페이지의
Native/fresh WASM review와 standalone overlay를 함께 제시한다.

### 도형의 공통 글줄 정렬 결과

그림은 이미 `inline_picture_top`에서 문단 세로 정렬의 글꼴/위/가운데/아래 정렬점과
같은 줄 기준선을 소비한다. 도형은 이 결과 대신 상자 하단을 기준선에 붙여 clamp하거나,
빈 셀에서 아예 등록을 건너뛰고 `para_y_before_compose`로 돌아갔다.
독립 Print의 `홀수형` 위쪽 148.7347은 실제 TextLine top 145.0667, 기준선 거리 37.4와
도형 높이 39.6667을 기존 글꼴 정렬점으로 맞춘 148.75와 일치한다.

그림·도형의 상자 정렬 helper를 공통화하고, 빈 셀의 도형도 자기 TextLine에서 원점을
등록하도록 수정한다. 셀의 그림·표 출력 소유 경로와 별도 수식 기준선은 유지한다.
위/아래 캡션·바깥여백은 같은 개체 상자에 포함한다. 수정 전에 해당 도형의 실제 줄과
부모 셀을 추적했으며, 텍스트가 없다는 이유로 줄 상자의 기준선을 무시하지 않는다.
기존 #5789의 높이 1 HU 선도 저장 기준선을 보존하는 대조군으로 확인한다.

1798단계 Native는 기준선+괘선 보정만 빌드했다. 1801단계 WASM은 이 도형 원인 확인 후
여러 보정을 묶기 위해 중단했으며 완료 증거로 사용하지 않는다. 다음 Native/fresh WASM

### 새 이름의 회귀와 기존 대조군

[새 회귀 파일](../../tests/cases/verified_hancom_paragraph_frames.rs)에 4개 검사를 추가했다.
기존 시험지 회귀 이름을 바꾸거나 기대값을 완화하지 않았다.

1. 문단 외곽과 단 경계가 일치하고 인용 표가 보존되어 그 안에 포함되는 관계.
2. `홀수형` 도형이 같은 셀 문단의 자기 글줄 안에 포함되는 관계.
3. 같은 원본 글자 위치를 가진 본문과 구두점의 그리기 기준선이 일치하는 관계.
4. 위 관계를 유지하며 완료한 14쪽의 중요한 상자·괘선을 독립 Print ±2 CSS px로 보호.

w=79.1134, h=39.6626이며, 괘선은 Print 래스터의 x=539·1004 열을 기준으로 했다.
