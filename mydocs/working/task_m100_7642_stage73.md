## 검증 기준과 범위

현재 검증 source는 `b6a1269b3dfaa146e5eccfb9598c2471c1422cae`다.
55개 원본과 독립 한컴 Print 853쪽의 범위는 유지한다. 이전 source
`1266e0302a5c16cd09c0b931119d642b0cee17f8`의 전체 측정은 실패 쪽을 찾는
진단 자료이며 현재 source의 완료 증거로 사용하지 않는다.

기존 36개 및 추가 42개 산식의 저장 폭·높이와 현재 Native 계산을
독립적으로 대조했다. 페이지 점수와 수식·간격의 확대 판독은 별도로
확인한다. CASES 세로 높이 복원이 실제 13→14쪽의 내용 소속과 배치까지
복원했는지 Native/fresh WASM의 같은 원본과 Print에서 확인한다.

## 남은 미달 문서

이전 source의 `samples/3-10월_교육_통합_2022.hwpx`는 9쪽 83.94872%,
10쪽 45.27286%다. HWP 쌍과 혼동하지 않는다. 같은 입력·Print·호환 설정의
최신 출력과 대조하고 처음 달라지는 문단·개체의 소유와 줄 구성을 추적한다.
현재 변경으로 생긴 회귀를 테스트 제거·기준 완화로 처리하지 않는다.

`samples/task1768/distribution_doc.hwpx`는 실제 HWP 5 바이너리이며
기존 독립 Print의 3쪽 표 위치 차이가 최신 source에서도 남아 있다.
원본의 저장 줄 부재와 TAC 앞 공백의 줄 소속을 구분한다. 원본의 표·속성을
보존한 공백 0/1/3/6개 대조군을 한컴 2024에서 저장·Print했다. 그 저장 줄과
표 원점, 현재 줄 구성 및 실제 배치 소비를 연결한다. 대조군 통과를 원본
일치로 보고하거나 관측된 차이만큼 상수 offset을 추가하지 않는다.

## 공간 정리와 실행

종료 증거와 실행 중 프로세스의 경로를 확인한 이전 검증의 SVG만 정리한다.
삭제 전에 파일별 SHA와 바이트 수를 ignored output에 기록한다. 원본,
Print PDF, PNG, TSV, JSON, 로그, 고정 바이너리 및 공유 Cargo target은 보존한다.
현재 진행 중인 검증은 관찰 timeout 때문에 재시작하지 않는다.

최신 Native의 영향 쪽과 fresh WASM을 확인한 뒤 전체 55개 입력을 최신
고정 산출물로 검증한다. 관련 원본의 모든 쪽이 90% 이상이고 확대 판독을
통과한 뒤 고정 px 검사를 관계형으로 전환한다. #1139 전체 77개 검사와
제거 후 복원한 검사 목록을 포함하며 전체 회귀·필수 lint 검증을 남긴다.

Native 빌드·fmt·Native Clippy는 exit 0이다. fresh WASM 빌드도 exit 0이며

나머지 집중·전체 WASM 및 Studio 브라우저 실행은 완료로 판정하지 않는다.

한글 분수는 같은 source의 `stage73-current-cjk-fraction-selected-detail-review.png`에서
접두식·곱셈·분수·중첩 괄호·퍼센트를 같은 좌표와 배율로 확대 대조했다.
저장 폭·높이 일치와 페이지 점수, 글리프의 래스터 차이를 구분한다.
이 대조를 원본 시험지 전체 수식 판독의 대용으로 사용하지 않는다.

공백 대조군의 한컴 Print PDF 벡터 괘선과 Native Table 원점을 직접 비교했다.
0/1/6개 공백 사례의 Print 좌단은 83.15467px이고 3개 사례는 91.47066px다.
Native는 모두 83.2px다. 이 px 값은 진단 좌표이며 회귀 기대값이 아니다.
3개 사례의 저장 줄은 문자 93에서 시작하고 표는 94에 있어, 표 앞 공백
한 글자가 같은 줄을 소유한다. 공백 6개 사례에는 별도 공백 줄 뒤에
표의 자기 줄이 있다. 따라서 공백 수에 비례한 offset을 추가할 수 없다.

저장 줄 경로는 `layout_table_item`의 첫 줄 가시 본문 조건이 표 소유 줄의
공백 전진을 0으로 덮어쓰는 분기를 확인했다. 저장 줄 없는 원본의 프레임은
`flow_inline_controls_with_tac_tables`에서 문단 끝의 표를 제외하고,
`absorb_whitespace_only_rows`는 개체 소유 없이 글자 범위만 판단한다.
소유 줄·종단 개체·공백 점유를 함께 보정해야 하며 두 경로의 출력을
독립적으로 확인하기 전에는 기대값을 변경하지 않는다.

공백 대조의 첫 실행은 Chrome 시작 제한으로 종료됐다. 실제 종료를 확인한
뒤 기존 export를 180초 제한으로 이어받았다. 최종 출력·측정은 완료됐고
3쪽 미달로 gate가 `re_review_required`, exit 1을 반환했다. 이를 실행 장애로
분류해 반복 시작하지 않는다.

정리 원장 `stage73-terminal-svg-cleanup.json`은 종료 증거와 파일 SHA를
보존하며 172개 SVG, 17,340,115,313바이트(약 16.15GiB) 정리 완료를 기록한다.
원본·독립 Print·최신 비교 PNG와 검증 로그는 보존했다. 관계형 검사 전환과
전체 회귀·나머지 필수 gate는 미완료다.
