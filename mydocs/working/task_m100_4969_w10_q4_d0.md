## 결론

Q4-D0는 계획과 일치하는 `qualified-red-baseline` 후보이다. Q4-C dormant 계약 27건과 D0 target policy
1건은 모두 통과했고, product activation에 필요한 다섯 source contract만 0/5로 실패했다. 실패는
제품 module 등록, exact-source-bound owner, atomic table-cell layout commit, vertical GlyphRun publication,
CanvasKit feature detection 부재와 정확히 일치한다.

test-only target policy는 HWP5 semantic provenance, `text_direction=2`, one cell·paragraph·line·run·column,
pure CJK, exact source 등록, variation 없음이 모두 참일 때만 후보로 판정한다. 같은 `한글` 입력은 Q4-C
dormant owner에서 exact transaction을 만들지만 `product_published=false`를 유지한다. HWPX provenance,
code 1, mixed `한A`, multi paragraph, exact source 부재는 각각 독립적으로 거부된다.
