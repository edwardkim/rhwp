## 판정

Q3-E1은 **qualified-dormant-reversible**이다. exact slot 단위 set/update/clear를 strict native command로 열고,
실제 snapshot 변화가 있을 때만 request generation과 composition·pagination invalidation이 발생하도록 했다. 잘못된
요청은 snapshot을 바꾸기 전에 거절되고, 없는 slot clear와 canonical axis 재등록은 멱등이다.

이번 절편은 요청 owner만 가역적으로 만들었다. 공개 WASM adapter, modern Hangul·Latin explicit composer session,
`GlyphOutline` 제품 게시를 추가하지 않았으므로 default 출력은 그대로이고 Q3-E2~E4 red 계약 세 건이 남아 있다.

## 구현 범위

1. `HorizontalShapingInstanceRequestRegistry`에 per-slot remove와 read-only canonical request 조회를 추가했다.
2. native `set_exact_font_instance_native`·`clear_exact_font_instance_native`에 strict JSON DTO를 연결했다.
3. JSON 16 KiB, axis 16개, language index 0..6, unknown field/mode, 중복·잘못된 axis tag, 비유한 값,
   `fvar` 범위 밖 값과 source가 없는 slot을 mutation 전에 거절한다.
4. set/update/clear의 effective mutation만 request generation을 올리고 measurement context·composition·pagination·
   page tree를 무효화한다. 동일 canonical request와 이미 비어 있는 slot clear는 generation을 유지한다.
5. 응답은 상태·slot·canonical axis·source/request generation·request count만 포함한다. font bytes, text, path,
   corpus identity는 포함하지 않는다.
