## 적용한 정정 (Stage D)

### Fix 1: viewBox origin 적용

`src/wmf/converter/svg/device_context.rs:as_view_box()`:
```rust
pub fn as_view_box(&self) -> (i16, i16, i16, i16) {
    (self.origin_x, self.origin_y, self.x.abs(), self.y.abs())
}
```

종전 `(0, 0, ...)` → `(origin_x, origin_y, ...)`. SetWindowOrg 의 origin 을 viewBox 시작점으로 사용.

### Fix 2: viewBox min/max 양방향 자동 확장

`src/wmf/converter/svg/mod.rs:generate()`:
- element 의 max(x+width, y+height) 까지 viewBox 우/하 확장
- element 의 min(x, y) 까지 viewBox 좌/상 확장
- helper: `element_min_x`, `element_min_y`, `element_max_x`, `element_max_y`, `parse_attr_i32`

### Fix 3 (framework): y-flip transform

`Window::ext()` 에서 y < 0 (Cartesian) 감지 + `y_inverted` flag. `generate()` 에서 `<g transform="translate(0,vb_h) scale(1,-1)">` 적용.

**현재 sample14 는 y_inverted=false** (Window ext y > 0). 다른 sample (bottom-up Cartesian) 에서 작동 예정.
