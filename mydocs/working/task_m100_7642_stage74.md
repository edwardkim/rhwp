# #7642 Stage 74 — CASES의 한글 조건과 종단 TAC의 물리 줄 소유

Issue: #7642

검증 source는 `b6a1269b3dfaa146e5eccfb9598c2471c1422cae`이며 Stage 73 기록은
`bf12381a9fc2`로 커밋했다. 전체 55개 원본·853쪽과 관계형 회귀 전환의
범위는 유지한다. 현재 미달 원본의 검사나 기준 파일을 제거하지 않는다.

## 10월 HWPX의 차이 시작점

최신 Native의 `samples/3-10월_교육_통합_2022.hwpx`는 8쪽 91.43010%,
9쪽 83.94033%, 10쪽 45.29901%다. 동일 Print와 18쪽 수를 보존하지만
문8 이후 미주의 위치와 단·쪽 이월이 어긋난다. 원본 문단 70의 미주
문단 2에 한글 조건 CASES가 있다. 저장 높이는 2385HU이고 현재 자연
높이는 약 1933HU다. 원본 문단·미주·개체 소속으로 선택하며 고정 px
범위를 회귀 검사로 사용하지 않는다.

먼저 원본 산식과 조건을 분리한 독립 대조를 한컴 2024에서 저장·Print한다.
8/9/12/16pt의 한글/숫자 조건, 단독/접두/괄호 표현과 세로 행 대조를
같이 확인한다. 단일 문서의 저장 높이를 상수로 복사하지 않고 자식 줄의
글꼴 프레임·세로 간격·기준선이 부모 프레임과 실제 paint에서 어떻게
소비되는지 추적한다. 저장 폭·높이와 독립 Print를 같은 근거로 연결한다.

## TAC 공백 소유의 반례

공백 0/1/3/6개 대조 중 3개 사례만 표 앞 공백 한 글자를 같은 저장 줄에
남긴다. 공백 6개 사례는 별도 공백 줄을 먼저 소비하고 다음 줄에 표를
놓는다. 단순 공백 수 offset 또는 종단 표를 마지막 공백에 합치는 토큰은
이 반례를 보존하지 못한다.

저장 줄의 표 소유 범위를 재사용하는 경로와 NO_LS 프레임이 종단 개체의
폭·높이·줄 소속을 구성하는 경로를 각각 보정해야 한다. 공통 줄 결과가
측정과 배치에 소비된 뒤 첫 줄 가시 본문 조건이나 공백 흡수 분기가
그 결과를 덮어쓰는지도 확인한다. 실제 반례와 정상 대조의 시각 검증을
확인하기 전에는 기대값·baseline을 바꾸지 않는다.

## 실행 기록

진단 입력·MCP job·Print 계약·SHA·Native/fresh WASM 산출물은 ignored
output에 남긴다. 이전 코드의 전체 측정은 실패 탐색 자료이고 최신 head
완료의 증거가 아니다. 대표 review PNG를 직접 보여 주고 점수와 확대
판독 결과를 구분한다. 필요한 보정을 모아 빌드·검증하며 같은 실패의
관찰 timeout만으로 작업을 반복 시작하지 않는다.

## 독립 재생성에서 확인한 구분

32개 대조의 한컴 2024 저장·Print가 완료됐다. Save job은
`d14816f2-8319-4d2a-a7cd-1b49f70d8ec8`, Print job은
`06b27eb8-fcaa-4898-b585-4b53bac30aae`다. 실제 한컴 버전은
13.0.0.3901이고 Print는 method 0의 `frame_print_to_pdf_ex_one_up`이다.
HWP SHA는 `539e8c9743db6d8442c111bccce7cce81d4fc494411a3420d8aaf6436c29b0ef`,
PDF SHA는 `4ec378777699947a3d0826272ae524fdb2d875c39746529af3d4d7819f408166`이다.
정식 fixture가 아닌 진단 입력이며 ignored output의 `stage74-cases-frame-probe`에 있다.

900HU의 한글 조건 CASES 재생성본은 한컴도 높이를 1935HU로 저장했다.
Native는 약 1933HU이며 숫자 조건 CASES·matrix·pile의 flow 높이는 1935HU로
맞는다. 한글 조건 재생성본의 폭은 Native와 279~360HU 차이가 남는다.
원본의 2385HU와 새로 생성한 1935HU가 다르므로 원본 수치 하나를 모든
CASES의 높이 상수로 적용할 수 없다. 원본 저장 프레임 재사용과 독립
재생성의 계약을 분리하고, 원본의 같은 산식·글자 모양·출처를 추가 대조한다.
이 차이만으로 원본 저장 정보가 무효라고 판정하거나 원본을 재생성본으로
대체해 목표 통과로 보고하지 않는다.

32개 메트릭은 `stage74-cases-frame-geometry-comparison.json`에 기록했다.
현재 같은 고정 Native/fresh WASM의 페이지 비교가 진행 중이다. 페이지
점수·직접 확대 판독·원본 9~10쪽 복원은 아직 완료하지 않았다.
