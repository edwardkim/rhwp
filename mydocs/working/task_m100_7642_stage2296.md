# #7642 유효한 본문 분수 입력의 Print 대조와 검사 교정

Issue: #7642

## 실제 완료

최신 `upstream/devel` b7a5388034를 fetch·ls-remote로 확인했다. 현재 브랜치에
이미 포함되어 있어 불필요한 리베이스를 반복하지 않았다. 기존 파일과 공용
target을 보존했다. 최신 devel의 Native·fresh WASM 빌드도 각각 exit 0으로
끝났고, source 해시 불변을 확인했다.

기존 #5583 합성 검사의 0×0 용지·미지정 face/version·임의 크기 때문에 Print
기준을 만들 수 없었다. 원본 실패 자료를 보존하고, 유효한 용지와 한컴 정상
저장에서 확인한 수식/줄 메트릭을 반영한 별도 대조군 두 개를 생성했다.
column_start 0/6000은 유지했다. 각각 engine 2020의 실제 Print로 독립 PDF를
얻었다. 두 PDF는 같은 위치에 같은 분수를 출력한다. 양수 column_start만으로
비가운데를 요구한 기존 기대가 이 경계의 독립 출력과 맞지 않음을 확인했다.

code cc4255a58d8112c07013e89eda1b1a065c824fea의 stage2291 Native와
stage2292 fresh WASM에서 두 입력은 전쪽 raw 100%, 각각 1쪽 일치다.
stage2294의 전체 및 확대 review·standalone overlay를 대조했다. 분자/분모와
가운데 관계는 일치하고 작은 래스터 경계 차이는 증거 문서에 남겼다.
판정에 쓰는 raw와 엄격 내용 픽셀 보조값 63.75%/71.25%를 구별했다.

## 검사 변경

실패 검사를 삭제·skip해서 결과를 숨기지 않는다. 기존 무효 합성 builder 대신
새 이름 `verified_printed_body_equation_alignment.rs`에서 검증한 두 fixture를
읽는다. 원본 소유·내용·누락/중복·본문 포함·양쪽 여백의 대칭 관계를 보호하고,
양쪽 raw 100%인 1쪽의 독립 PDF 숫자 원점을 ±2px로 함께 검사한다.
입력 HWPX와 실제 Print PDF, 생성 차이·SHA·Print job·검증 경로를 담은
PRINTED_EQUATION_ALIGNMENT.md를 함께 보존한다. renderer 수용 조건을
완화하거나 유효한 다른 저장 LineSeg 계약을 바꾸지 않았다.

rustfmt와 git diff --check는 통과했다. **새 검사 두 개의 실행은 아직 대기**다.
stage2282의 논리 기호 수정 전/후 검사가 공용 target을 사용한다. 그 검사의
종료를 확인한 뒤 현재 후보의 정렬 검사를 같은 target에서 순차 실행한다.
이는 기대값 교정이며 엔진 결함의 수정 전 FAIL 증거라고 주장하지 않는다.

## 전체 검증의 남은 범위

후보의 97문서 Native 전쪽 측정은 끝났다. 수치 통과 90문서, 쪽수 차이 2문서,
90% 미만 5문서다. 미달 문서에는 법령 1개와 배경 합성 대조군 4개가 포함된다.
fresh WASM과 최신 devel 대비 같은 쪽 비교는 아직 실행 중이다. stage2264의
부분 비교에서 0.01%p 이상 하락도 남아 있다. 이를 평균 개선으로 상쇄하지 않는다.
기존 12개 Rust 실패의 나머지 원인, 최종 lint/전체 회귀와 실제 Studio/backend
소비 경로도 미완료다. PR 준비 완료로 판정하거나 원격 PR을 생성하지 않았다.
