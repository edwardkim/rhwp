## 원인과 보정

새 HFT 표는 확인한 ASCII95자의 부분 표다. 미수집 문자의 기존 표시 face 폭을
보존하는 경로가 ASCII에만 적용돼 전각 괄호는 일반 반각 휴리스틱에 빠졌다.
확인된 부분 HFT 표의 미수집 문자도 기존 표시 face의 폭을 사용하도록 한다.
확인한 원본 ASCII 폭을 덮어쓰거나 일반 TTF의 cmap 결측 조건을 완화하지 않는다.

HFT 굵기 전진은 보충 표의 이름과 구별하여 원래 선택된 측정 프로그램에서
판단한다. 공통 문자 측정 walk → 줄 폭/줄 구성 → 실제 글자 원점과 glyph-fit
소비 경로를 유지한다. glyph-fit에는 굵기 추가 전진을 넣지 않는다.
