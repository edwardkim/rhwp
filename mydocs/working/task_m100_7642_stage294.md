## 수정 근거와 범위

Source269 전체 회귀에서 `test_latex_binom`이 과거 `Paren(Atop)` AST를 기대해
실패했다. 현재 구문 계약은 `CHOOSE`와 `\binom`이 위·아래 피연산자를 소유하는
`EqNode::Binomial`이다. 실제 수식 배치와 글리프 프레임은 변경하지 않는다.

LaTeX 호환 검사를 별도 867줄 모듈로 옮겼다. 기존 검사와 깊이 제한 검사를
유지했고, 실패한 검사만 새 이름 `latex_binomial_preserves_the_owned_choose_operands`로
교체했다. 단일 글자와 그룹화된 다항식의 LaTeX/한컴 입력 동치, 위·아래 피연산자의
정확한 소유와 내용을 검사한다. 물리 위치·px·SVG hash를 기대값으로 사용하지 않는다.
이 변경은 입력 AST 계약이며 시각 일치 검증 완료의 증거로 사용하지 않는다.
