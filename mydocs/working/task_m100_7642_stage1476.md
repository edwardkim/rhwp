## 독립 기대값과 직접 판독

문단 번호나 고정 영역으로 대상을 고르지 않고 원문 질문 내용과 그 앞뒤 TAC 표 소유로
대상을 찾는다. 질문 1의 본문→첫 표, 질문 2의 앞 표→두 본문 줄→뒤 표,
질문 3의 앞 표→질문·이어지는 본문→뒤 표 순서·비겹침을 검사한다.
원본 저장 줄 시작은 컨트롤 슬롯을 포함한 UTF-16 축이므로 원본 `char_offsets`로
가시 문자 축에 투영해 런의 시작과 비교한다. 전쪽 일반 본문의 원문 소유·내용과
두 대상 표의 중첩 셀 내용도 비교해 누락·중복을 막는다. 쪽수 단독 검사가 아니다.

완료한 1쪽의 표 경계는 독립 PDF 벡터를 96dpi CSS 좌상단 좌표로 환산한 값이다.
`stage1468-social-independent-page1-pins.json`에 입력별 PDF 해시와 측정을 기록했다.
첫 표 x=85.599996, y=324.555990, 폭=412.480001px, 후속 표 x=85.599996,
폭=408.639994px를 ±2px로 보호한다. 후속 표 y는 원본 1083.663981px,
분할본 1080.946615px로 각각 자기 PDF를 사용한다. 둘의 2.717367px 차이를
같은 값으로 덮어쓰지 않는다. 관계 검사도 함께 유지한다.

`stage1474-social-direct-read.json`은 Native/fresh WASM/Print를 같은 배율로 직접
읽은 영역과 관측을 기록한다. `stage1474-social-{full,split}-detail-{1,2,3}-review.png`는
첫 신문 표·둘째 질문·셋째 질문과 후속 표의 새 대조다. 원본·분할본 각각에서 HWP와
HWPX의 1쪽 RGB 출력 및 Print 래스터가 같은 것도 픽셀 차이로 확인했다.
본문/표 겹침, 내용 누락, 줄바꿈 차이는 관찰되지 않았다. 글자 래스터의 농도와
앤티앨리어싱 차이는 남으며 완전한 픽셀 일치로 보고하지 않는다.
