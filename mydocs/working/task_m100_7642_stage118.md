# Stage 118 — 행렬 프레임과 근호 괄호 소속 보정

Issue: #7642. 전체 55개 원본·853쪽과 복원한 회귀 검사의 관계형 전환 범위를 유지한다.

## 독립 기준과 원인

259종 전체 카탈로그는 Native와 fresh WASM의 18쪽 모두 90% 미만이다. 골든을
현재 구현에 맞춰 일괄 갱신하지 않는다. 첫쪽에서 확인한 괄호 행렬과 근 지수의
차이를 먼저 독립 반례로 분리했다.

한컴 2020 정상 저장 job `52604762-7e03-4966-8dba-ce5748ea0821`, Print job
`6c36a396-840e-42a7-8e86-f25180b7582f`는 900·1500·2200HU의 네 행렬 스타일과
문자·숫자·분수·첨자 열, 네 근호 구문을 포함한다. 60개 수식의 정상 저장 프레임은
ignored `stage118-matrix-root-counterexamples/independent-frames.json`에 보존한다.

괄호 행렬은 일반 행렬과 셀의 폭·높이·기준선이 같고 양쪽 구분자 폭만 더한다.
둥근 괄호는 한쪽 0.4em, 대괄호·세로줄은 0.5em의 75HU 논리 격자로 확인했다.
현재 괄호 행렬은 일반 행렬과 다른 열 간격·행 높이·전체 기준선을 계산한다.
`SQRT(3) of x`의 괄호는 Print에서도 지수에 표시되는데 현재 파서가 제거한다.
`SQRT (x+1)`은 OF가 없으므로 괄호 안 내용이 본체다.

## 구현 소비 경로

행렬 AST → `layout_matrix` → 일반 행렬의 공통 셀 프레임과 열 폭 → 구분자 슬롯을
포함한 Paren 배치 상자 → SVG·Canvas의 Paren 소비 경로다. 기존 Matrix paint의
`fs * 0.3` 재계산에 새 슬롯 값을 넘긴 것처럼 보고하지 않는다. 일반 글꼴의 기존
행렬 경로와 LADDER는 적용 대상에서 제외한다.

근호 파서는 사전 계산한 괄호 짝을 이용해 OF 유무를 판정한다. 괄호 묶음을
지수 또는 본체로 한 번 소비하고 측정·그리기는 같은 AST를 사용한다. LaTeX 대괄호
지수 구문은 기존 계약으로 유지한다.

## 검증 순서와 남은 범위

원래 60개 입력의 보정 전후 Native/fresh WASM과 독립 Print를 전쪽 대조하고
행렬·근호를 확대 판독한다. 90% 미만이면 회귀·골든 갱신을 보류한다. 전폭 표
호스트의 성장 반례, HWP3 그림과 후속 본문, #1139 전체 관계형 전환, 전체 원본과
Rust·lint·Skia·Studio 검증은 별도로 남아 있다. PR review·오늘할일은 code head CI
성공 뒤 trailing commit으로 작성한다.
