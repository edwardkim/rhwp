raster ledger: what is still compared, how one page is isolated, and
which classes are layout defects versus font environment.

own open PRs. This work does not rewrite those font-chain or subsetter

## Residual classes

| Class | Layout defect? | Gate |
| --- | --- | --- |
| `none` | no | within ink/hist/bbox budget |
| `wrap_flow` | yes | left-strip PDF density ≥ 0.025 and rhwp/PDF ≤ 0.15 |
| `glyph` | yes | histogram shift, bbox stable |
| `paint` | yes | ink ppm jump |
| `table_place` | yes | bbox / top-edge move |
| `font_width` | no (font surface) | advance-only, owners match |
| `font_weight` | no (font surface) | dark-bin shift, owners match |
| `font_env` | **no** | face substitution + matching boxes/owners |

`FontEnv` is the Stage 169 contract: missing HCR Dotum is not a
justification to change pagination or table split.

## Page isolation

`compare_document_pages` compares each page independently.

- Decode / raster failure on page *k* becomes `IsolatedWarning` (or
  `Skipped` under `DocumentIfAllSkipped`).
- Neighbors still produce a document report.
- The document fails only when every page is skipped, or a page is
  marked fatal.
- This is the **raster** analog of page isolation. It does not call
  `svg2pdf::to_chunk` and does not classify `SubsetError`.

Isolation fixtures: `tests/fixtures/issue_4764/isolation_cases.tsv`
(every catalog page × eight injects). `pdf_pages.tsv` drives
`build_multipage_pdf` / `extract_isolated_page`.

## How to remesure a real HWP 2020 PDF

When the large samples and MCP PDFs are present:

1. Keep page totals 383 / 82 / 17.
2. Raster one page at a time (`extract_isolated_page` or
   `fidelity_compare.py` with a single index).
3. Classify with `classify_page_residual`. Promote a catalog row only
   when the class is not `font_env`.
4. A single page decode failure must not drop the rest of the ledger.
