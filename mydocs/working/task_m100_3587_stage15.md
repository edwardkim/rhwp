## 확인 결과

1. #3587은 OPEN, 담당 edwardkim이며 조회 시 기여자 추가 답변은 없다. 기존 기본 구현 재개 결정을 유지한다.
2. 기존 외부 붙여넣기는 `src/document_core/commands/foreign_paste.rs`에 있다.
   Stage 1의 일부 축약 경로 `src/document_core/foreign_paste.rs`와 구분한다.
3. 이 경로는 전체 구역 평탄화·구역 컨트롤 제거·커서 경계 merge·빈 문서 용지 복사를 수행한다.
   독립 블록 자동화는 해당 명령 자체가 아닌 자원 매핑 구성요소를 재사용해야 한다.
4. `ForeignIdMap`은 누락 참조를 원래 번호로, `BinPool`은 누락 바이트를 0으로 대체한다.
   스타일 범위 초과도 0 fallback이다. 기존 대화형 호환 정책과 D strict 실패 정책을 분리할 필요가 있다.
5. B의 `validation/resources.rs`에는 도달 자원 검사와 스타일 순환 방문 처리가 이미 있다.
   `repeat.rs`에는 detached 준비 후 단일 commit이 있다. 같은 기능을 별도 엔진으로 다시 만들지 않는다.
6. 서식/자원 mapping은 서로 다른 문서의 번호 공간 사이 변환이고, A의 instance ID 재발급과 다른 책임이다.
   두 경로를 함께 검증해야 HWP/HWPX 저장 시 엉뚱한 서식이나 그림 참조를 막을 수 있다.

위는 코드 읽기로 확인한 사실이며 신규 런타임 실패 재현이나 테스트 통과 주장과 구별한다.
