# PR #8319 후속 증적의 원본·주장 대응 정정

## 작업 범위와 원인

원 PR 45건의 본문·원 작성자 댓글·diff와 게시한 기존 통합 댓글을 다시 대조한다.
기존 대표 이미지에는 실제 보고 문서 대신 합성 경계 입력을 사용한 사례가 있다.
같은 코드 경로의 회귀 PASS와 원 PR이 지목한 실물 문서의 시각 검증 완료는 별개다.
원본 파일과 편집 상태가 다른 이미지는 원 문서의 대표 증거로 사용하지 않는다.

작업지시자는 증적이 없으면 증적만 재산출해 별도 PR로 처리하고, 개별 review 문서도
수정하도록 지시했다. 원 PR과 통합 PR에는 새 정정 댓글을 추가하지 않고 기존 댓글을
직접 수정한다. 엔진·테스트·baseline·Visual Sweep 정책 변경은 이번 범위가 아니다.

## 확인 기준

1. 원 PR 본문과 원 작성자 댓글에 기재된 실제 파일·페이지·실패 영역을 먼저 확정한다.
2. API 생성 입력이면 원 PR의 생성·편집 순서와 저장 형식 및 편집 전후 상태를 대조한다.
   비슷한 표나 다른 개체를 넣은 합성 대조군을 같은 입력으로 취급하지 않는다.
3. 실제 파일·입력 SHA·독립 Print PDF SHA·실행 source와 producer·backend·DPI·페이지를
   연결한 뒤 해당 경계의 review와 standalone overlay를 직접 판독한다.
4. 같은 입력의 기존 증적만 재사용한다. 원 작성자의 과거 before/after는 원 보고 자료로
   명시하며 현재 통합 source의 새 출력이나 독립 한컴 Print 증거로 승격하지 않는다.
5. 빠진 증적은 동일 원본·동일 조작 상태로 재산출한다. 전쪽 Native/fresh WASM TSV와
   대표 PNG를 제출하며 점수와 실제 결함의 확인을 구분한다.
6. 개별 review/review_impl, 통합 리뷰와 증적 색인 및 PR 본문의 잘못된 대응을 함께 고친다.
   정식 증적 PR 반영 후 기존 댓글의 이미지·수치·설명을 교체하고 API로 재조회한다.

## 공식 게시처에서 원본 재확보

작업지시자는 원본 미확보 시 대체 입력임을 표시하도록 승인한 뒤, 인터넷의 공식 게시처를
최대한 검색하고 원 PR의 문서 내용과 같은지 확인해 사용하도록 추가 지시했다.
이번에 새로 찾은 문서에는 전 페이지를 90% 이상으로 보정할 의무를 부여하지 않았다.
원본 식별·해당 문제 영역의 증적 재산출 범위로 진행하며 엔진·회귀·지침은 변경하지 않는다.

- 기존 미확보 21건 중 16개 PR에 대응하는 14개 HWP/HWPX를 공식 게시처에서 확보했다.
  #8027, #8031, #8036, #8039, #8045, #8049, #8050, #8051, #8052, #8053,
  #8055, #8056, #8057, #8061, #8062, #8065다. 앞서 확보한 #8014는 별도다.
- #8036은 미리내집의 정책 문구·표와 저장 줄 시작 4480HU·끝 69616HU가 원 PR과 일치한다.
  #8039는 표지와 저장 줄 textpos 8·높이 4700HU·간격 2352HU가 일치한다.
  #8062는 요약 쪽의 수치와 높이 3403HU·vpos 500/600 저장 줄이 모두 일치한다.
- #8056은 원 PR의 11쪽 숫자열 전체, #8057은 11쪽 제목·347/122 및 U+2024를 대조했다.
  #8065는 2025-07-31 개정 서식을 확보하고 다른 사이트의 2021년 판본을 제외했다.
- 아직 원본 확보 또는 판본 확정이 되지 않은 PR은 #8029, #8030, #8033, #8054, #8066이다.
  #8030의 공식 표준계약서 후보, #8033의 동일 모집 프로그램 안내, #8066의 다른 입사지원서는
  원 PR 원본 검증 완료로 기록하지 않는다.
- 로컬 HWP/HWPX 10,000개의 본문·미리보기 텍스트에서도 미확보 사례를 추가 검색했으나
  일치 원본을 찾지 못했다. 단순 파일명 검색과 구분한다.
- 상세 출처·입력 SHA-256·내용 대조·제외 후보는
  `output/pr-review/pr8319-comment-correction/internet-originals/search-results.md`와

공식 배포처 PDF의 일부는 2쪽 모아찍기이므로 원문 식별에만 사용한다. 새 시각 증적의 기준
PDF는 버전에 맞는 한컴 Print로 별도 확보한다. 내용 대응 확인과 작성자 원본의 바이트 동일성,
현재 제품의 정상 동작 판정은 구분한다. 원 PR의 실제 문서를 찾은 경우에는 기존 대체 입력의
높은 점수를 그 문서의 검증 결과로 사용하지 않는다.

## 원 PR HWP/HWPX 미첨부 시 대체 표시

작업지시자 지시: “원 pr 에 hwp 파일이 없어서 유사 문서로 대체해서 표시”. 보고 실물 문서가 언급된 22건의 원장·개별 review/review_impl에 대체 여부를 기록했다. 공식 배포 문서의 내용 대응이 확인된 경우도 작성자 파일과 바이트 동일성을 뜻하지 않는다.

39개 유효 재현 입력의 실제 캡처는 입력·Print·페이지를 연결해 사용한다. 5개 파일 없는 단위 계약과 #8033의 추가 진단 실패를 구분한다. 기존 댓글을 직접 수정하며 새 정정 댓글을 추가하지 않는다. 새로 찾은 공식 문서의 전 페이지 90% 보정은 범위에 포함하지 않는다. 엔진·회귀·baseline·지침 변경은 없다.

파일 없는 단위 계약인 #8027·#8029·#8030은 실제 대체 문서의 시각 검증이 없는 상태에서 대체가 완료됐다고 쓰지 않는다. 보고 문서 사례 22건은 대체 입력 19건(유효 시각 증거 18건·추가 진단 1건)과 단위 계약 3건으로 구분한다.
