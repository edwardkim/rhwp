# Issue #7642 단계 746: 직접 PNG 수식 색상 경로의 컴파일 보정

## 확인한 원인과 적용 범위

- 기준 `upstream/devel`: `c0d330737fabae77ca2bf1706cba8514d0e8f1df`. 단계 737의 소스 `0d31cfff33`은 이 기준을 포함한다. 재 fetch 결과 기준이 동일해 추가 리베이스하지 않았다.
- 단계 738에서 포맷, Native/WASM/전체 타깃 Clippy와 기본 CLI 빌드는 통과했다. Native Skia feature Clippy는 `equation_conv.rs`가 `LayoutKind::Color`를 처리하지 않아 E0004로 실패했다. 이를 시각 통과나 완료로 기록하지 않는다.
- SVG와 Canvas는 색상 노드의 자식만 지정 RGB로 렌더링하고 같은 위치·글자 크기·스타일을 전달한다. Skia에도 같은 재귀 계약을 적용한다. 형제 노드에는 기존 색상을 유지하며 좌표·줄 구성·수식 메트릭은 변경하지 않는다.
- 집중 회귀의 기존 실패는 #1892의 자식 행렬 identity·왕복 1px 검사와 #1880의 노드 수 동일 검사 세 건이다. 최신 원본·독립 Print의 시각 확인 이후 적절성을 판단하며 실패를 숨기기 위해 허용치를 넓히지 않는다.
