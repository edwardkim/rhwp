# #7642 TAC 줄 상자의 기준선과 텍스트 표시 기준선 분리

Issue: #7642

## 독립 근거와 잘못된 가정

`26eccce4f2`에 전쪽 범위 감사와 실패 PNG를 보존했다. 원본 HWP3와 한컴 저장 HWPX의
표지·18·19쪽에서 큰 TAC 사각형이 위로 이동한다. 표지 원본 줄은 높이 7948HU·
기준선 6755HU이고, 19쪽 원본 줄은 높이 28560HU·기준선 24276HU다. 각각 원본 도형을
포함한 줄 상자의 높이·기준선이며 독립 Print는 그 줄 상단에서 도형을 표시한다.

`paragraph_layout.rs`는 본문 TAC 도형 줄에서 텍스트 표시용 높이·기준선을 글꼴 크기로
줄이고, 문단의 실제 흐름 점유는 기존 TAC 점유 경로에서 보존한다. 최근 추가한
`inline_shape_top`이 텍스트용 기준선을 원래 큰 도형의 어센트와 비교해 원점을 위로
이동시켰다. 잘못된 가정은 두 기준선이 같다는 것이다. 음수 좌표를 clamp하거나 문서별
조건을 추가하지 않고 원래 줄 상자의 기준선을 도형 정렬에 전달한다.

## 생산·소비 경로

`ComposedLine.baseline_distance`와 원본 줄 메트릭 → 현재 source 수용·재조판 규칙으로
확정한 줄 상자 기준선 → inline 개체 정렬과 공통 `inline_object_top`의 원점으로
전달한다. 텍스트 표시용 축소는 별도 소비값으로 유지한다. 같은 줄의 그림·도형은 같은
개체 기준선을 소비하며 텍스트에 줄 상자 어센트를 다시 가산하지 않는다.

run 안의 inline 개체, 빈 run 줄, 뒤에서 보완하는 TAC 그림의 세 경로를 확인한다.
빈 줄 fallback과 저장 source의 수용 조건은 유지한다. 표 셀처럼 기준선을 축소하지 않는
경로와 기존 그림·국어 도형 대조군의 원점을 함께 확인한다. 다른 줄의 개체를 현재 줄의
기준선 증거로 새로 사용하지 않는다.

## 검증

한 번의 수정·Native 빌드로 원본 HWP3/HWPX의 1·18·19쪽, 국어 14쪽과 정상 TAC 도형·
그림 대조군을 확인한다. 실제 수정 전후의 값·반례를 확인한 뒤 fresh WASM을 같은
공유 target에서 순차 빌드하고 원본 전쪽을 다시 측정한다. 최저 90%와 직접 판독 전에는
새 렌더링 회귀나 baseline을 추가·갱신하지 않는다. 그 뒤 같은 원본 소유·줄 포함·순서의
새 이름 회귀를 추가하며 완료된 양쪽 98% 페이지의 중요한 위치만 ±2px로 보완한다.

이미 실행 중인 48e8593054의 전쪽 큐는 해시 고정 producer를 읽으므로 해당 source의
증거로 보존한다. 새 코드의 완료 증거로 사용하지 않는다. 큰 배치 차이를 확인했으므로
새 source의 전체 Rust 반복보다 영향 페이지의 원인 보정·직접 확인을 먼저 한다.

## 최신 devel 동기화 요청

사용자 요청으로 `upstream/devel`을 fetch하여 기준이 `0953598d8e`에서
`552514f423ec91f1b7171f6e6b0882a4efe034f2`로 바뀐 것을 확인했다. 리베이스 중
입력·스크립트가 바뀌지 않도록 이전 기준의 시각 검증 큐 7개와 자식 프로세스를 중단했다.
완료된 TSV와 중단 기록은 ignored `output/`에 보존하며 미완료 큐를 통과로 판정하지 않는다.

새 지침은 검토·필수 후속 처리가 끝난 뒤 필요한 입력·Print PDF·TSV·대표 PNG·공유 캐시를
`output/` 밖으로 보존하고 참조·해시를 확인한 다음, 저장소 루트 `output/` 자체를 전부
제거하도록 변경됐다. 활성 자료를 지금 삭제하는 절차가 아니며 공유 `target/pr-review`는 보존한다.

이 기준선 보정은 검증 중인 구현으로 커밋해 보존한다. 기존 head의 빌드·진단 결과를
리베이스 이후 head의 전체 검증 완료로 재사용하지 않는다. Native 영향 페이지 확인,
fresh WASM·전쪽 TSV·회귀 검사는 리베이스 뒤 새 코드와 기준 SHA에 연결한다.

리베이스 전 Native 빌드는 exit 0(5분 18초)으로 끝났고 빌드 전후 소스 해시 일치도
확인했다. `stage1946-current-native.json`과 `stage1946-current-native-build.jsonl`에
명령·8개 빌드 잡·고정 실행 파일 해시를 보존했다. 이는 컴파일 확인이며 시각·회귀 통과가 아니다.
