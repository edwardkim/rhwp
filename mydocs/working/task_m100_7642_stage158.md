# #7642 Stage 158 — Print 선 굵기와 반복 주기의 독립 진단

Issue: #7642

## 확인할 계약

Stage 157은 도형의 DASH/DOT 해석과 선 굵기에 비례하는 패턴을 바로잡았다.
원본 5쪽의 확대 비교에는 Print의 선 농도와 반복 주기가 여전히 다르게 보인다.
이미 높은 페이지 점수로 이 차이를 완료 처리하지 않는다.

독립 한컴 2024 Print 벡터에서는 점선의 채움 굵기가 선언 굵기와 다르고
작은 외곽 stroke도 함께 출력된다. 28·56·112·224HU만으로 규칙을 확정하지 않고,
얇은 선과 경계 전후 굵기·실선 대조군을 한 문서로 구성해 같은 MCP Print로 측정한다.
문서 재배치가 다른 합성 진단의 전체 점수를 원본 시각 증거로 사용하지 않는다.
선 굵기·주기는 pt/HWPUNIT으로 측정하며 특정 화면 px나 문서 ID로 보정하지 않는다.

## 병행 검증

Stage 157의 원본 64쪽 진단과 이전 실패 48건·직렬화 계약 1건 재실행은 유지한다.
새 출력 보정은 독립 진단과 실제 소비 지점을 확인한 뒤 한 번에 적용한다.
코드가 바뀌면 최종 Native/fresh WASM·전체 회귀·lint를 다시 수행하며,
두 경로의 관련 모든 페이지 90% 이상과 미세 판독 전에는 새 배치 회귀를 추가하지 않는다.

## 독립 측정 결과

33개 굵기 사례의 3쪽 Print PDF와 18개 경계·원형 점 사례의 2쪽 Print PDF를 확보했다.
두 출력은 한컴 2024 13.0.0.3901, PrintMethod=0이었다. 입력과 PDF는
`pdf/issue7642-line-width-probe-20261012/`에 함께 보존하며 README에 SHA·job을 기록한다.

0·1·6·11·12·13·17HU의 점선 채움 굵기는 모두 12HU였다. 18HU는 24HU,
30HU는 36HU, 42HU는 48HU, 54HU는 60HU, 66HU는 72HU였다. 나머지 구간도
12HU 단위의 가장 가까운 양수 굵기와 일치하며 절반 경계는 올림이었다.
실선은 같은 굵기의 stroke이고, 점선은 그 굵기의 채움과 추가 12HU 외곽 stroke를
함께 출력했다. 원형 점도 같은 채움 지름과 외곽 stroke를 가졌다.
이는 600dpi 인쇄 장치의 물리 pen 단위와 일치하는 관측이다. 화면 1px 최소값으로
설명하지 않는다. 버전·다른 출력 경로까지의 적용은 추가 검증 대상이다.

실제 원본 5쪽 SVG의 선언 굵기 56HU를 이 규칙으로 바꾼 별도 prototype에서,
채움 60HU와 외곽 12HU를 반영한 선 농도·반복 주기가 Print에 가까워졌다.
prototype은 렌더러 수정이 아닌 진단이며 native 통과 증거로 승격하지 않는다.
`stage158-line-width-prototype/page005-before-prototype-print-detail.png`에 이전 Native,
prototype, Print를 같은 배율로 나란히 보존했다. 페이지 보조값은 99.48958%이며
원본 5쪽의 프레임 원점 차이도 남아 있어 점수만으로 완료하지 않는다.

Stage 157의 64쪽 진단은 exit 0, 최저 25쪽 90.27013%, 90% 미만 0쪽이었다.
빌드 이후 cfg(test) 생성기를 보정해 source 해시 유지가 false이므로 최종 head의
완료 증거로 사용하지 않는다. 49건 재실행은 컴파일 중이며 실제 Rust 프로세스가 살아 있다.
