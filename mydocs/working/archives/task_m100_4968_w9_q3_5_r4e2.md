## 2. 장평·자간 수치 gate

R4E-1의 등록 후 body 18행에서 같은 ratio·spacing의 kerning-off와 kerning-on total width를 직접 뺐다.
layer tree가 0.001px 단위로 직렬화하므로 부동소수점 허용 오차 대신 정수 milli-px로 비교했다.

| 장평 | 자간 0 | 자간 -5 | 자간 -10 | 기대 |
|---:|---:|---:|---:|---:|
| 100% | 1,600 | 1,600 | 1,600 | 1,600 milli-px |
| 90% | 1,440 | 1,440 | 1,440 | 1,440 milli-px |
| 80% | 1,280 | 1,280 | 1,280 | 1,280 milli-px |

따라서 pair delta는 글꼴의 `AV=-80`, `To=-40`, 13.333px 크기에 장평을 한 번 적용한 값이다. 자간은
glyph별 기존 advance에 남고 pair delta에 다시 곱해지지 않는다. target별 상수나 허용 오차를 추가하지 않았다.

## 3. public registration failure matrix

각 case는 새 `HwpDocument`/`DocumentCore`에서 실행했다. 시도 직전과 직후의 page count, normalized render
tree, normalized layer tree, SVG bytes/hash, Canvas command count, CanvasKit plan을 비교했다.

| case | registration | 기대 disposition | render 결과 |
|---|---|---|---:|
| malformed SFNT | 등록 허용 | measurement에서 malformed fail-closed | 무변화 |
| pair table unsupported | 등록 허용 | capability unsupported | 무변화 |
| unavailable face index | 등록 허용 | face parse fail-closed | 무변화 |
| invalid language index | `invalid-language-index` 거부 | registry 불변 | 무변화 |
| 32MiB + 1 byte | `font-byte-limit-exceeded` 거부 | 해시·parse 전 거부 | 무변화 |
| 같은 slot의 다른 source | `slot-conflict` 거부 | 기존 exact state 보존 | 무변화 |

앞의 세 case는 source identity 등록과 글꼴 capability 판정을 의도적으로 분리한 구조다. 즉 “등록 성공”을
“커닝 적용 성공”으로 해석하지 않는다. capability가 증명되지 않으면 기존 positions를 그대로 쓴다.

`wrong digest`는 public registration API에서 호출자가 전달할 수 있는 값이 아니다. digest는 받은 bytes에서
core가 직접 계산하므로 public API에 가짜 digest를 추가하는 검사는 계약을 왜곡한다. provider가 selection
handle과 실제 source를 다시 대사하는 내부 경계는 기존
`issue_4968_exact_source_handle_resolves_without_carrying_font_payload`가 SHA mismatch, byte-length mismatch,
face mismatch를 모두 검증하며 이번 29/29 실행에서 통과했다.
