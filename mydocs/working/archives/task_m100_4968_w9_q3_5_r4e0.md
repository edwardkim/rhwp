## 2. smoke face와 가시 텍스트 경계

`RHWPExactKerningSmoke.ttf`는 `space, A, V, T, o, W, H`만 지원한다. Q2 fixture의 `BODY R…` 라벨이나
한글 control을 그대로 재사용하면 exact shaping의 nominal glyph identity가 깨져 run 전체가 fail-closed한다.
그 상태에서는 WASM 등록 API가 정상이어도 K1 pair adjustment가 생기지 않아 R4E의 목적을 검증할 수 없다.

따라서 R4E의 모든 가시 run은 지원 글립만으로 된 `AV To WA HH`이고, 다음 식별 정보는 본문이 아닌 manifest에
둔다.

- context와 paragraph ID
- char shape ID 7~24
- ratio 100/90/80, spacing 0/-5/-10, kerning K0/K1
- stored/fresh lane
- Latin `languageIndex=1`, `faceIndex=0`

이 분리는 원문 없는 projection 불변식과 exact face의 fail-closed 계약을 동시에 지킨다.

## 3. Q2 정본 보호

기존 `generate_kerning_pair_fixture.py`는 `KerningFixtureSpec`을 받는 공통 helper로 확장했지만 기본값은 이전
Q2 계약 그대로다. Q2 HWPX와 manifest를 새 임시 디렉터리에 재생성해 추적 정본과 각각 byte-for-byte
대조했다. 두 파일 모두 동일했다.

신규 테스트도 이 대조를 영구 계약으로 둔다. 앞으로 runtime fixture를 바꾸더라도 Q2 font identity,
가시 라벨, paragraph ID, semantic manifest는 소급 변경할 수 없다.

## 4. canonical projection 계약

projection은 다음 값만 허용한다.

- case identity: context, char shape, language, lane, ratio, spacing, kerning request
- decision: registration, capability, disposition, fallback reason
- layout: measurement total, line starts/boundaries, final positions, bbox width, page count
- consumer: Canvas positions, CanvasKit positions, SVG SHA-256

원문, font bytes, source path, source document hash, 파일명, 절대 경로, private identity는 금지한다. native64와
WASM32가 synthetic paragraph sentinel을 서로 다른 최대 정수로 직렬화하는 경우만 `para:MAX`로 정규화한다.
그 밖의 수치에는 target별 상수나 허용 오차를 두지 않고 canonical JSON byte identity로 비교한다.
