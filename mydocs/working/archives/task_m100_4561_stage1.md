## 1. 무엇을 만들었나

검증 사다리(1~10년, #4463)의 채택 병목을 푸는 **표면 배선**: LLM 코딩 도구들이
저장소에서 자동으로 읽는 지침 파일 전판에 "작업 증빙 기본 경로"를 깔았다.
포크·클론·다운로드가 이 파일들을 같이 실어 나르므로, 어떤 도구로 기여하든
같은 길(지식 지도 → 봉투 계약 → 캡슐 증빙 → PR 체크리스트)에 도착한다.

**방침(이슈 명시)**: 유도는 전부 공개·투명 규약 파일 — 숨김 지시·기만 유도 없음.
에이전트가 읽는 파일은 사람도 그대로 읽는다.

## 3. 내용 원칙 (이슈 잠금 그대로)

1. **단일 정본** — 도구별 파일은 AGENTS.md 를 가리키는 얇은 포인터(중복 표류 방지).
2. **devel 병합분만 규약으로** — 증빙 경로는 `replay --capsule`(영수증)·
   `lineage`(계보)·`audit`(재현율)만 안내. 확장 축(서명~감사 표준)은 #4463
   좌표 링크로만 — 병합 전 기능은 규약이 아니라 로드맵(정직).
3. **권장이지 강제 아님** — 체크리스트 문구는 "에이전트 보조 작업 권장".
