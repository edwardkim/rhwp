# #4823 Stage 4: KoPubWorld 공개 라이선스 판정

## 공식 이용 조건

KoPubWorld 서체는 모든 사용자에게 무료로 제공된다. 사용 등록으로 정보만 입력하면 종이책, 전자책, 인쇄물, 광고물, 온라인을 포함한 상업적 목적으로 자유롭게 사용할 수 있다.

`font-kopubworld@1.0.3`의 패키지 메타데이터도 한국출판인회의(KOPUS) 배포 글꼴과 `KOPUS-Custom` 라이선스를 명시한다.

## 변경

- `KoPubWorld돋움체`·`KoPubWorld바탕체`의 Light/Medium/Bold를 정확한 `font-kopubworld` OTF로 직접 매핑한다.
- 고정 라이선스 근거를 `KOPUS-Custom (사용 등록 후 상업적·온라인 사용 가능)`으로 기록해 웹폰트 사용 가능으로 판정한다.
- `KoPubWorld ... _Pro` 계열은 패키지에 동일 face가 없으므로 기존처럼 미발견으로 남긴다.

## 재수집 기준

stage 3 산출물에서 `라이선스 검토 필요`였던 KoPubWorld 기본 6개 행은 재수집 후 `웹폰트 사용 가능`으로 바뀌어야 한다.
