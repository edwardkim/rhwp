# Task M100 #4969 W10-Q2-D4-B — one-line/one-run atomic activation

## 판정

Q2-D4-B는 **qualified**다. 제품 layout과 `LayerBuilder` 사이에 최초의 엄격한 one-line/one-run lane을 연결했고,
모든 기능 탐지·mapping·exact source 인증·page sidecar attach가 성공한 뒤에만 measurement advance를
TextRun 폭과 다음 x에 게시한다. 성공 제품 fixture는 TextRun fallback 1개와 common GlyphRun 1개를 남기며,
같은 text source의 nominal GlyphRun은 0개다.

거부 lane에서는 기존 TextRun·geometry를 유지하고 sidecar·font resource를 만들지 않는다. 기계 판독 결과는
[`w10_q2_d4_b_atomic_activation.json`](../../tech/investigations/issue-4969/w10_q2_d4_b_atomic_activation.json)이다.

## 제품 activation 경계

최초 lane은 파일 확장자나 한컴 버전이 아니라 최종 문단 surface의 기능을 탐지한다.

- 문단 전체가 composed line 1개·emitted text run 1개이고, Q2 final target range가 전체 model text와 같다.
- direct old-Hangul target이며 display projection·`layout_positions`·tab/control·TAC·note·field·CharOverlap이 없다.
- left alignment, 압축 장평 `0 < ratio < 0.999`, 자간·분배·문단 condense·장식·효과·합성 bold/italic이 없다.
- raw shaping glyph의 y offset·advance가 모두 0이고 exact source registry generation이 현재 값과 같다.
- run·문단 border/background와 numbering/prefix가 없다.

저장된 tab definition의 존재만으로는 거부하지 않는다. 실제 text/tab control이 없고 tab layout을 사용하지 않는지가
기능 탐지의 기준이다. 이것은 문서 버전이나 작성기 상태를 추정하는 분기가 아니다.

## 원자 게시와 fallback

activation 후보는 최종 TextRun의 `NodeId`를 먼저 예약한다. D2 final-run mapping, 현재 registry source certificate,
page sidecar attach가 모두 성공한 경우에만 다음 세 값을 같은 measurement advance로 바꾼다.

```text
TextRun bbox width = common GlyphRun bbox width = replay local advance × affine scale-x
```

attach가 실패하면 예약한 같은 `NodeId`로 legacy TextRun을 만들고 K1/K0 width path를 그대로 실행한다. 따라서 실패가
NodeId hole, K1 억제, 부분 geometry 변경을 남기지 않는다. `LayerBuilder`는 기존 public entrypoint를 보존한 채
common shaping lowerer를 먼저 실행한다. 성공 report가 claim한 `text_source_id`만 nominal portable GlyphRun에서
제외하며 TextRun과 bitmap/SVG font sidecar 경로는 보존한다.

## 제품 source integration 결과

저장소의 embedded Source Han fixture와 public `DocumentCore` page build 경로로 검증했다. 양성 text는
`ᄒᆞᆫ말`이다. `ᄒᆞᆫ글`은 기존 제품명 display projection 대상이므로 direct-text 양성 fixture로 쓰지 않고
음성 행렬에 포함했다.

| 항목 | 결과 |
| --- | ---: |
| TextRun fallback | 1 |
| common shaping GlyphRun | 1 |
| nominal duplicate GlyphRun | 0 |
| page text source | 1 |
| portable font blob / face | 1 / 1 |
| `layout_positions` | 없음 |
| TextRun·GlyphRun bbox 불일치 | 0 |
| bbox width·affine page advance 불일치 | 0, 허용 오차 1e-9px |

음성 행렬은 center alignment, legacy 제품명 display projection `ᄒᆞᆫ글`, char border fill 세 경우다. 세 경우 모두
legacy TextRun을 유지하고 common GlyphRun 0, font blob 0으로 닫혔다.

cross-backend 선택 검증은 승인 전 D4-C 범위로 남긴다.

## 남은 한계와 다음 승인 게이트

D4-B는 최초 strict lane만 열었다. multi-line/run, mixed target, center/right/justify/distribute, ratio 항등·확대,
nonzero GPOS y positioning, RTL/vertical/variation, native Skia blob typeface replay는 계속 fail-closed 또는 기존
TextRun fallback이다.

D4-C에서는 Rust native/WASM, studio selector/draw matrix, 실제 CanvasKit glyph width·height·cluster 오라클,
#5821 회귀와 sidecar/resource/JSON 성능을 함께 판정한다. 별도 승인 전에는 D4-C, push, PR, GitHub comment를
진행하지 않는다.
