## 판정

Q3-E3는 **qualified-bounded-explicit-geometry**다. default transaction은 instance request를 암묵적으로 읽지 않고,
composer가 exact slot request의 존재를 확인한 뒤에만 별도 explicit transaction을 연다. 활성 범위는 전체가 modern
Hangul syllable이거나 ASCII Latin letter인 한 줄·한 run·한 slot 문단이다.

Happiness Sans VF Title 요청에서 같은 measurement provenance가 line width·TextRun bbox·다음 origin·page sidecar에
이어져 폭이 `21.0px`에서 `19.840000000000003px`로 변했다. 요청 해제 뒤 layer JSON은 baseline과 완전히 같았다.
mixed script와 가운데 정렬은 요청이 있어도 문단 전체가 baseline JSON과 같았다.

Q3-E4가 소유할 variable `GlyphRun + GlyphOutline` 원자 게이트는 아직 열지 않았다. explicit sidecar는 paint lowerer에서
prepared-source cache나 resource를 건드리기 전에 거절되므로 제품에는 legacy TextRun만 남는다. 따라서 E3의 제품 변화는
조판 geometry뿐이고 부분 portable publication은 0이다.

## 구현 경계

- default/explicit transaction이 공통 paragraph 알고리즘을 호출하는 measurement session 계약을 추가했다.
- Q2 `is_bounded_horizontal_shaping_candidate_text`와 old-Hangul segment selector는 수정하지 않았다.
- 별도 `is_bounded_explicit_instance_candidate_text`는 request 확인 뒤에만 호출된다.
- modern Hangul과 ASCII Latin을 섞지 않고, Latin ligature cluster가 두 scalar 이상을 합치면 전체 rollback한다.
- style·hard boundary·bidi·display projection·condense·control·tab·overlap·scale 중 하나라도 불일치하면 전체 rollback한다.
- layout preflight는 request slot·request generation·source generation을 현재 context와 다시 대조한다.
- E4 전 explicit paint lowering은 `explicitInstancePublicationPending`으로 resource mutation 전에 fail-closed한다.
