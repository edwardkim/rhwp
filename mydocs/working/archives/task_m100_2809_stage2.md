# Task #2809 Stage 2 — 위·아래 문단 속성 차이 보존

- 브랜치: `task/2809-distribute-align`
- 선행: [`task_m100_2809_stage1.md`](task_m100_2809_stage1.md)
- 상태: 완료(최종 화면 불일치 확인, Stage 3로 이관)

## 정정된 문제 정의

문제는 glyph 잘림이 아니다. 이슈 문서의 위쪽 나눔정렬 문단과 아래쪽 나눔정렬
문단은 원문 속성이 다르므로 PDF처럼 서로 다른 폭으로 보여야 한다.

- 위쪽: `charPrIDRef=4`, 자간 `-50%`, `LineSeg.horzsize=6972HU`.
- 아래쪽: `charPrIDRef=11`, 자간 `0%`, `LineSeg.horzsize=6872HU`.

Stage 1 후속 검토에서 추가한 마지막 glyph ink overhang 보정은 위쪽의 음수 자간
차이를 상쇄해 두 문단의 결과를 거의 같게 만들었다. 해당 보정은 제거한다.

## 검증 계약

1. `Split` 마지막 줄 분배는 유지한다.
2. 위쪽 `다/같/이`의 분배 span이 아래쪽보다 유의미하게 넓어야 한다.
3. WASM 빌드 후 사용자 화면과 같은 rhwp 페이지 보기 100%를 직접 캡처한다.
4. E2E는 별도 Canvas뿐 아니라 실제 편집기 화면 증적을 남긴다.

## 단계 결론

- 잘못 추가한 마지막 glyph ink overhang 보정을 제거하고 관련 golden을 원래
  나눔정렬 분배 좌표로 복원했다.
- native SVG, WASM SVG와 페이지 레이어 트리에는 위 `85.44px`, 아래
  `76.693px`의 span 차이가 존재한다.
- 그러나 실제 rhwp 편집기 캡처에서는 두 문단이 여전히 같게 보인다. 따라서 이
  단계의 좌표 검증만으로는 해결로 판정하지 않는다.
- 최종 렌더 백엔드가 페이지 레이어 트리의 문자별 위치를 래스터에 반영하는 경로를
  다음 단계에서 분석하고, 실제 화면 픽셀 회귀 검증을 추가한다.
