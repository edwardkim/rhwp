## 결론

Q4-D3-A는 D2의 한 vertical line sidecar를 문자별 fallback leaf와 일대일로 연결하는 읽기 전용 DTO를
구현했다. target `한글`은 line node 1개, 순차 child node 2개, 순차 `TextSourceId` 2개, Q4-C glyph·cluster·
bbox 2개로 손실 없이 대응한다. DTO는 raw text와 font bytes를 소유하지 않으며 render tree, layer tree,
resource arena를 변경할 수 없다.

`src/paint/shaping_glyph_vertical.rs`는 실제 line subtree를 같은 입력 DTO로 바꾸는 shadow bridge를 제공하지만
`LayerBuilder` caller는 연결하지 않았다. 따라서 target layer에는 여전히 문자별 `TextRun` 두 개만 있고
`GlyphRun`, portable font blob/face와 nominal claim은 0이다.

## 1. 재검토 중 발견한 identity gap

D2 sidecar는 glyph cluster의 UTF-8 범위와 exact source certificate를 보존하지만 원문은 보존하지 않는다.
그 상태로는 `한`을 같은 3-byte·1 UTF-16 unit인 `가`로 바꾼 fallback leaf를 cluster 길이만으로 거부할 수 없다.
paint 단계에서 다시 shaping하거나 raw text를 sidecar에 저장하는 두 방법은 각각 geometry 단일 권위와 원문
비보존 원칙을 깨뜨린다.

따라서 D2 sidecar에 다음 비직렬화 값만 추가했다.

- source text SHA-256 32 bytes
- source UTF-8 byte count
- source UTF-16 unit count

custom `Debug`는 text digest를 출력하지 않는다. D3-A preparation은 leaf text를 순서대로 hash하고 길이와 함께
대사한다. 같은 길이의 다른 문자 한 건은 `ClusterTextMismatch`로 line 전체가 거부된다. raw text 보존·재-shape·
public JSON 변경은 0이다.

## 2. mapping 계약

1. certified transaction의 line/bbox/next-origin은 같은 geometry `Arc`여야 한다.
2. certificate digest·byte length·face index는 applied identity와 공개 Noto source identity에 일치해야 한다.
3. leaf 수는 glyph 수와 같고 node id는 `line+1..`, text source id는 최초 id부터 연속이어야 한다.
4. 각 leaf는 vertical 한 문자이며 결합 UTF-8 범위가 Q4-C cluster와 일치해야 한다.
5. leaf bbox는 glyph bbox와 일치하고 glyph는 nonzero·upright·finite origin/advance여야 한다.
6. 반환 DTO의 source range는 각 leaf의 local UTF-8·UTF-16 범위다.
7. 어떤 실패도 product publication으로 전환되지 않는다.
