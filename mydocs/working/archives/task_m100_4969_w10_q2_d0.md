# Task M100 #4969 W10-Q2-D0 — page-local shaping sidecar ABI

## 판정

Q2-D0는 **qualified**다. `HorizontalShapingRunDecision`이 applied measurement 또는 rejected trace를
terminal 상태로 보존하고, 페이지별 `NodeId -> Arc<decision>` table이 이를 최대 4,096건만 소유하도록
구현했다. composer·layout·paint가 새 결정을 읽는 제품 소비자는 아직 0이며 출력 변화도 0이다.

기계 판독 결과는
[`w10_q2_d0_page_sidecar.json`](../../tech/investigations/issue-4969/w10_q2_d0_page_sidecar.json)이다.

## owner와 수명

- table은 `PageRenderTree`가 직렬화에서 제외하는 `PageLayoutContext.frame` 안에 있다. 따라서 페이지와 함께
  생성·clone·폐기되지만 render-tree JSON에는 나타나지 않는다.
- applied decision은 Q2-B의 `Arc<HorizontalShapingMeasurement>`를 다시 감싸 소유한다. table과 clone은
  measurement를 복사하지 않고 같은 `Arc`를 공유한다.
- rejected decision은 raw text·font bytes·host path 없이 기존 bounded `ShapingAttemptTrace`만 보존한다.
- UTF scalar·UTF-8·UTF-16 범위를 한 객체에 함께 두어 D2가 final emitted run과 세 좌표계를 한 번에 대사할
  수 있게 했다.

## fail-closed 규칙

attach는 다음 조건을 typed reason으로 거부하고 기존 table을 바꾸지 않는다.

| reason | 거부 조건 |
| --- | --- |
| `MalformedRange` | scalar·UTF-8·UTF-16 범위가 비어 있거나 역전됨 |
| `RangeMismatch` | caller가 대사한 emitted range와 decision range가 다름 |
| `DispositionMismatch` | applied payload의 trace가 applied가 아니거나 그 반대임 |
| `AttemptIdentityMismatch` | trace digest·glyph count와 measurement identity/source handle이 다름 |
| `MeasurementRangeMismatch` | registry generation 또는 scalar count가 measurement와 다름 |
| `StaleRegistryGeneration` | 한 페이지 안에서 다른 registry generation을 섞으려 함 |
| `DuplicateNode` | 같은 NodeId에 두 번째 결정을 붙이려 함 |
| `EntryLimitExceeded` | 페이지별 4,096개 상한을 넘음 |

첫 성공 attach가 해당 페이지의 registry generation을 고정한다. 실패 attach는 entry count와 generation을
변경하지 않으므로 부분 게시가 없다.

## serialization·성능 경계

- `PageRenderTree.frame`의 기존 `#[serde(skip)]` 경계 안에 table을 배치했으므로 serde JSON field 증가는 0이다.
- legacy `RenderNode::to_json()`은 `root`만 순회하므로 sidecar와 독립이며 기존 bytes를 유지한다.
- 빈 table은 `HashMap::new()` 상태라 entry heap allocation과 retained measurement `Arc`가 0이다.
- 현재 제품 attach/read callsite는 0이므로 페이지 layout·paint 실행 횟수와 제품 출력에는 영향이 없다.
- 활성화 후 entry 수·retained payload·lowering 시간은 D4/D5와 Q2-F에서 별도로 계측한다.
