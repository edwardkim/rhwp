# Task M100 #4969 W10-Q2-D4-A — replay projection·source certificate shadow

## 판정

Q2-D4-A는 **qualified**다. 같은 `Arc<HorizontalShapingMeasurement>`의 raw design-unit glyph를
[#5821 draw 계약을 반영한 수정 계획](../../plans/archives/task_m100_4969_w10_q2_d4_revised.md)의 SSOT로 replay-local 좌표에 투영하고,
affine을 적용한 page-space position·advance가 D3 measurement와 허용 오차 안에서 일치함을 확인했다.
exact registry가 소유한 font `Arc<[u8]>`는 복사 없이 page-local certificate로 연결된다.

제품 layout·LayerBuilder caller는 여전히 0이다. 따라서 이 결과는 replay 가능한 shadow payload를
검증했을 뿐 render tree·layer tree·JSON·화면 출력을 바꾸지 않는다. 기계 판독 결과는
[`w10_q2_d4_a_replay_projection.json`](../../tech/investigations/issue-4969/w10_q2_d4_a_replay_projection.json)이다.

## exact source certificate

`HorizontalShapingContext::certify_replay_source`는 measurement와 현재 registry generation을 먼저 대사하고,
handle의 SHA-256·byte length·face index를 다시 검증한다. face parse와 units-per-em까지 맞은 경우에만 registry의
동일 `Arc<[u8]>`를 certificate에 복제 소유시킨다.

- source: `SourceHanSerifK-OldHangul-subset.otf`, 456,688 bytes, face index 0
- SHA-256: `2f86ef9a52acb6d1dad9d915843239123b635d97edd88fd0573a88ffcb4e16f1`
- 두 번 발급한 certificate의 source `Arc::ptr_eq=true`; font byte copy 0
- Debug에는 generation·handle·byte length·units-per-em만 나오며 raw bytes는 나오지 않음
- certificate가 없는 기존 D0/D2 sidecar는 계속 유효하지만 D4 lowerer는
  `missingReplaySourceCertificate`로 닫고 resource를 만들지 않음
- stale generation·source identity·face·units-per-em 불일치는 typed rejection
- certificate와 sidecar는 page-local이며 직렬화되지 않음

D3의 embedded font 목록 재탐색은 제거했다. font family 문자열은 portable `FontFaceResource`의 표시용 metadata로만
사용하며 replay source 선택에는 관여하지 않는다.

## 새 보호 불변식: nonzero y positioning 보류

D3 page measurement의 y 환산은 `font_size / unitsPerEm`, #5821 replay-local y 환산은
`draw_fs / unitsPerEm`이다. 두 의미를 연결할 한컴 오라클이 아직 없으므로 raw glyph의 `y_offset` 또는
`y_advance`가 0이 아니면 `verticalPositioningAuthorityPending`으로 거부한다.

이 음성 fixture는 measurement 자체는 내부적으로 일치하도록 구성한 뒤 lowerer에서 typed rejection되고 font
resource mutation이 0임을 native·WASM 양쪽에서 확인했다. mark positioning을 임의 보정하거나 유실하지 않는
fail-closed 경계이며 D4-B 최초 lane도 이 조건을 그대로 기능 탐지해야 한다.

## fallback·한계·제품 영향

- 원래 `PaintOp::TextRun`은 그대로 남고 성공 shadow report만 `claims_glyph_run_slot=true`다.
- 개별 font 32 MiB, page unique font payload 64 MiB, glyph·cluster 각 4,096 상한을 유지한다.
- 모든 certificate·measurement·projection·cluster·resource budget 검증 뒤에만 resource를 등록한다.
- ratio `0 < r < 0.999`, horizontal LTR, rotation 0, 효과·자간·display projection·layout positions 없음만 허용한다.
- 제품 source에서 lowerer 정의 외 호출은 0건이며 generated integration suite·manifest·Cargo target도 만들거나
  stage하지 않았다.
