## 판정

Q3-E4는 **qualified-atomic-portable-publication**이다. canonical non-default instance가 완전한
`GlyphRun`과 producer-resolved monochrome `GlyphOutline`을 만들었을 때만 같은 text source, equivalence group,
anchor에 두 variant를 한 번에 게시한다. outline 생성과 resource 상한 검사는 resource mutation보다 먼저 끝나며,
둘 중 하나라도 없으면 nominal claim을 얻지 않고 기존 `TextRun`만 남는다.

CanvasKit policy와 Browser/Studio selector는 완전하고 재생 가능한 `GlyphOutline`만 선택한다. 빈 path 또는 multipart
불완전 outline은 variable `GlyphRun`도 선택하지 않고 `TextRun`으로 되돌아간다. Native Skia, SVG, Canvas2D는 Q3
non-default outline을 capability 미지원으로 거절하고 같은 fallback을 선택한다.

## 구현 결과

- explicit measurement의 `GlyphRun` diagnostics를 `q3ExplicitInstanceGlyphRunProjectionV1`로 분리했다.
- variable outline 생성 실패는 font resource 등록 전에 `variableOutlineUnavailable` 또는 구체 실패 사유로 닫힌다.
- page lowerer는 explicit instance에서 `GlyphRun`과 `GlyphOutline`이 모두 있을 때만 두 op와 claim을 함께 게시한다.
- Q3 variable outline은 CanvasKit·CanvasKit Browser에서만 선택 가능하며 다른 backend에는 영향이 없다.
- Studio selector는 outline 우선순위를 유지하되 재생 실패·구조 불완전 시 `TextRun` fallback을 선택한다.
- explicit default 요청은 registry·cache provenance에서는 독립 상태로 남지만 제품 composer activation에는 진입하지 않는다.
  최초 검사에서 explicit default가 no-request 폭 `21.0px`을 `19.6267px`로 바꾸는 결함을 발견했고, 검사를 약화하지
  않고 canonical axis가 빈 transaction을 기존 Q2 composer로 돌려 layer JSON과 bbox를 정확히 복원했다.
