# #4823 Stage 16 - 웹폰트 콘솔 진단 테스트 범위 보정

## 배경

Stage 15에서 추가한 `console.debug` mock의 선언은 첫 번째 오프라인 모드 테스트에,
복원 코드는 두 번째 조건부 등록 테스트에 배치되어 전체 Studio 테스트가 실패했다.

## 보정

- 디버그 로그 mock과 원래 `console.debug` 복원을 모두 조건부 웹폰트 등록 테스트에 둔다.
- 시스템 글꼴 건너뜀과 KoPubWorld CDN 로드 성공 로그 검증을 해당 테스트의 지역 상태로 유지한다.

## 기대 결과

`npm test`가 콘솔 진단 계약을 포함해 통과하며, 전역 콘솔 상태가 각 테스트 뒤에 원복된다.
