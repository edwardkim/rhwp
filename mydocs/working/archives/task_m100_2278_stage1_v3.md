rhwp 누적 막대가 한컴 대비 눈에 띄게 두꺼움.

## 2. 원인 실측

`pdf/chart/가로막대형/3차원누적가로막대형-2022.pdf` 재판독:

| 항목 | 한컴 2022 | rhwp (v2) |
|---|---|---|
| 막대 두께/슬롯 | **~0.4** (슬롯 40px, 막대 ~15px) | **0.7** (2D 누적 비율 상속) |
| 깊이/두께 비 | ~0.33 | 0.29 — 문제 아님 |

- 한컴 3D 누적 두께 0.4 = XML `gapWidth=150` → `1/(1+1.5)`와 정확 일치 —
  한컴 3D는 gapWidth 규칙대로 얇게 그림. rhwp는 2D의 0.7을 상속해 1.75배 두꺼웠음.
- 묶은형이 정합인 이유: 0.7을 3계열로 나눠 막대당 0.233 슬롯 — 한컴 묶은형 개별
  막대와 유사해 갭이 드러나지 않음.
- 세로 누적 정답지도 동일 비율(~0.4) 확인.

## 3. 보정 내용

`render_bars`: 슬롯 점유 비율 분기 — **`is_3d && stacked`일 때만 0.7 → 0.4**.

```rust
let bar_frac = if chart.is_3d && stacked { 0.4 } else { 0.7 };
```

- `cat_span`/`bar_span_total` 계산을 방(room) 방출 앞으로 이동, `bar_thickness`를
  `bar_span_total`에서 파생하도록 통합 (순수 계산 재배치 — 방출 바이트 무영향)
- 깊이는 두께 연동이라 자동 축소 (슬롯 45px 기준 5.4px — 한컴 ~5px 정합)
- 중앙 정렬은 기존 `(cat_span - bar_span_total)/2`가 자동 처리
- 2D(0.7)·3D 묶은형·축·라벨 무접촉
