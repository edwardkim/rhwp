## 2. 보정 내용

`src/ooxml_chart/renderer.rs`만 변경.

1. **깊이 공식**: `(두께 * 0.45).clamp(3.0, 9.0)` → **`(두께 * 0.30).clamp(2.5, 9.0)`**
   - 두께 정의를 명시화: 누적 = 슬롯 막대폭(`bar_span_total`), 묶음 = 계열별
     막대폭(`bar_w`) — 기존 4개소 인자와 동일값, `d3` 단일 계산으로 통합
   - 예: 시각판정 차트(두께 11px) 깊이 5.3 → 3.3px / 누적세로(두께 ~40px) 클램프 9 유지
2. **3D 방 (`render_value_grid_3d` 신설)**: `is_3d` 막대 차트에서 기존
   "배경 rect + render_value_grid"를 대체 —
   - 뒷벽: `(px+d, py-d)` 오프셋 흰 면 + 테두리, 격자선은 뒷벽 위에
   - 눈금 사선 커넥터: 앞면 눈금 → 뒷벽 (`#cccccc`)
   - 바닥: 평행사변형 (`#f2f2f2` + 테두리)
   - 앞면 좌측 축선 유지
   - 전체를 `<g class="hwp-bar3d-room">` 단일 그룹으로 방출 (계수 테스트용)
   - **라벨 문자열·위치·축 계산은 `render_value_grid`와 동일** — #1882 앵커 무접촉.
     막대 뒷면(front+d)이 뒷벽과 정확히 일치하도록 방 깊이 = 막대 깊이(`d3`) 공유
3. 2D 경로는 기존 코드 그대로 (`else` 분기) — 출력 바이트 불변.
