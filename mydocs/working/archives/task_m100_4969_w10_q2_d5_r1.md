# Task M100 #4969 W10-Q2-D5-R1 — unique-source prepared identity cache 결과

## 판정

Q2-D5-R1은 **qualified**다. R0이 고정한 `1/2/8 run` red는 모두 green으로 전환됐고, 기존 D4 replay와
page-local blob·face dedup은 유지됐다. cache는 page-local이며 font-by-key transport, layer JSON option,
WASM/Studio API와 NO_LS boundary는 변경하지 않았다.

기계 판독 결과는
[`w10_q2_d5_r1_prepared_source_cache.json`](../../tech/investigations/issue-4969/w10_q2_d5_r1_prepared_source_cache.json)에
고정한다.

## 구현 owner

`HorizontalShapingPreparedSourceCache`가 다음 exact source key를 page traversal 동안 소유한다.

```text
registry generation
+ font source SHA-256
+ byte length
+ face index
```

최초 miss에서만 registry-owned certificate `Arc<[u8]>`를 대사하고 face를 parse한다. BLAKE3 resource digest,
blob/face key, glyph count, weight·width·italic metadata를 immutable prepared source로 만든다. 이후 같은 key는
certificate의 `Arc` owner가 같은지 다시 확인한 뒤 prepared identity를 공유한다.

cache는 raw bytes를 복사하지 않고 registry `Arc` 하나를 더 보유한다. Debug에는 entry 수·논리적 source byte
합계·상한만 나타나며 font bytes·family·host path는 나오지 않는다. page JSON에 필요한 `ResourceArena` blob copy는
최초 unique source 등록 한 번만 기존 경로로 수행된다.

## bounded gate

- 개별 source: 기존 portable font 상한 32 MiB
- prepared entry: page당 최대 256개
- prepared logical source bytes: page당 최대 64 MiB
- key hit: 동일 registry generation과 exact handle뿐
- 같은 key라도 certificate `Arc` owner가 다르면 `replaySourceIdentityMismatch`
- entry/byte 상한은 face parse·digest·arena mutation 전에 `resourceLimitExceeded`

`with_limits(0, 0)` 음성 fixture에서 prepared entry 0, blob 0, face 0, GlyphRun 0과 TextRun claim 0을 확인했다.

## 보호 불변식

1. source handle/generation/certificate 대사는 cache lookup보다 먼저 수행한다.
2. cache hit도 같은 registry-owned `Arc`인지 확인한다.
3. face parse·digest가 성공하기 전에는 cache entry를 넣지 않는다.
4. glyph geometry·projection·cluster 검증이 끝나기 전에는 `ResourceArena`를 변경하지 않는다.
5. cache limit 실패는 prepared entry와 page resource를 모두 0으로 남긴다.
6. TextRun fallback과 D4 strict selector 조건은 바뀌지 않는다.
7. cross-page payload 재사용을 cache가 해결했다고 주장하지 않는다. 이는 R2의 transport 책임이다.

## 다음 절편

Q2-D5-R2는 opt-in font-by-key transport만 연다. default inline JSON은 그대로 두고, metadata/resource key를 유지한
채 font bytes만 생략하는 option과 exact resolver를 연결해야 한다. Studio의 현재 expected red를 green으로 만들고
missing·wrong·stale·oversized 응답에서 verified cache mutation 0과 TextRun fallback을 증명해야 한다.
