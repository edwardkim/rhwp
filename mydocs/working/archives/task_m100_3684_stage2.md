# Task #3684 Stage 2 보고 — 해법 결정과 구현

## 해법 후보 검증 — 실측으로 3개 중 2개 기각

Stage 1 이 제시한 후보를 데이터로 검증했다.

### ① `save-if` 를 Cargo.lock 변경 시로 좁히기 — **기각**

같은 lock 해시로 캐시가 중복 생성되는지 확인한 결과, **해시당 캐시 수 = 그 해시로
돌아간 job 수**였다(중복 저장 없음).

| lock 해시 | 캐시 수 | job 수 |
|---|---:|---:|
| `2ff177b0` | 7 | 5 |
| `2538decb` | 3 | 3 |
| `efef7f89` | 3 | 3 |

즉 rust-cache 는 이미 "같은 키면 재저장하지 않는" 동작을 한다. devel push 가 7일간
498회였지만 세대는 7개뿐이고, 이는 같은 기간 `Cargo.lock` 커밋 9회와 정합한다.
**`save-if` 를 좁혀도 줄어들 것이 없다.**

### ② 세대 상한 — **채택**

문제는 생성이 아니라 **구 세대가 GitHub 의 7일 미사용 만료까지 살아 있는 것**이다.
`v0-rust-lint` 는 7세대가 동시 생존하며, 각 세대는 하루 이틀만 쓰이고 죽는다.

### ③ CodeQL·frontend-wasm 별도 처리 — **불요, ②로 흡수**

두 성분도 **같은 세대 누적 패턴**임을 확인했다.

| 성분 | 세대 수 | 크기 |
|---|---:|---:|
| `Linux-codeql-rust` | 6 (05-31 ~ 08-01) | 3,035MB |
| `Linux-frontend-wasm` | 5 (07-26 ~ 08-01) | 1,977MB |
| `node-cache`(npm) | 5 (중복 2쌍 포함) | 278MB |

성분별 대책이 아니라 **전역 세대 정리 하나로 전부 해소**된다.

## 정량 근거

논리 그룹(키에서 후행 해시를 뗀 단위)별로 최신 세대만 남길 때:

| 유지 세대 | 정리 대상 | 정리 후 총량 | 한도 대비 |
|---:|---|---:|---:|
| 1 | 29개 / 7.60GB | **2.53GB** | 25% |
| **2 (채택)** | 18개 / 5.40GB | **4.73GB** | **47%** |

**KEEP=2 를 택했다.** 1세대만 남기면 진행 중인 job 이 방금 만든 캐시를 스윕이 지울
수 있고, 직전 세대가 사라져 lock 변경 직후 PR 이 전부 cold 가 된다. 2세대는 그
경계를 흡수하면서도 한도의 절반 아래를 유지한다.

## 구현 — `.github/workflows/cache-generation-sweep.yml`

- **트리거**: 매일 1회(cron) + 수동(`workflow_dispatch`, `dry_run` 기본 true).
  devel push 마다 돌 필요가 없다 — 세대는 `Cargo.lock` 변경 시에만 는다.
- **그룹핑**: `key.replace(/[-_][0-9a-f]{8,}$/, '')` + `ref` 로 묶는다. ref 를 함께
  묶는 이유는 devel 캐시와 PR 캐시가 같은 그룹으로 섞이면 안 되기 때문이다.
- **안전 경계**:
  - `permissions: actions: write` 하나뿐. checkout 없음, PR 코드 실행 없음.
  - **열린 PR 의 ref 캐시는 제외** — 머지 전에 재사용된다.
  - 그룹별 최신 2세대 유지.
  - 삭제 실패는 `core.warning` 으로 흘린다(다른 run 이 이미 지웠을 수 있다).
- **관측 가능성**: 정리 전/후 총량, 대상 목록, 보호한 PR 수를 job summary 표로 남긴다.
  (#2431 판정에서 요청된 "정리 후 잔여 총량 출력" 요건.)

로직은 실제 캐시 스냅샷(42개 10.13GB)으로 검증했다 — KEEP=2 에서 18개 5.40GB 정리,
잔여 4.73GB.

## Blacksmith·sticky disk (과제 1·2) — 불요 판정

이 해법으로 한도의 47% 로 내려가므로 **유료 서비스 도입도, 7/25 self-hosted 종료
판정 재검토도 불필요**하다. 이슈 본문의 과제 1·2 는 이 해법이 실패했을 때의 대안으로
남긴다.
