# 작업 2464-2511 단계 8 - FieldRange 분할 회귀 보정

## 문제

- 누적 통합 PR #2521 CI shard 1·3에서 ClickHere 복사/붙여넣기 회귀 세 건이 실패했다.
- `Paragraph::split_at()`이 `Field`를 일반 이동형 컨트롤로 분류해, 보이는 문자 기준의 split offset 계산에 보이지 않는 필드 control까지 포함했다.

## 수정

- `Field`는 일반 이동형 문자 컨트롤에서 제외한다.
- 새 문단으로 이관되는 `FieldRange`가 참조하는 `Field` control만 범위와 함께 이동한다.

## 검증 계획

- 병합 undo 뒤 ClickHere 복원과 분할 offset 단위 테스트를 확인한다.
- `issue_258_clickhere_form_mode` 전체와 `cargo test --profile release-test --tests`를 현재 HEAD에서 재실행한다.

## 검증 결과

- 최초 CI에서 `issue_258_clickhere_form_mode`의 ClickHere 복사/붙여넣기 회귀 세 건이 실패해, 기존 전체 회귀 성공 기록만으로는 현재 통합 HEAD를 증명하지 못함을 확인했다.
- 수정 뒤 `CARGO_INCREMENTAL=0 cargo test --profile release-test --test issue_258_clickhere_form_mode`는 13건 모두 통과했다.
- 기존 병합 undo 회귀와 새 visible-offset 분할 회귀도 각각 통과했다.
- 최종 merge 조건은 이 보정을 포함한 최신 PR head CI 전체 성공이다.
