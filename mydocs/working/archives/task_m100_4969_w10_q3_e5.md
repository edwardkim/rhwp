## 판정

Q3-E5는 **qualified 후보**다. 명시 요청이 없는 기존 출력과 explicit default 출력은 결정적으로 보존되고,
interior/max variable instance만 bounded `GlyphRun`·`GlyphOutline`을 게시한다. 반복 layer build의 병목은 variable
outline 자체가 아니라 매 호출마다 1.5MB font bytes를 복사하고 source digest·face preparation을 되풀이한 데 있었다.
font bytes를 `Arc<[u8]>`로 공유하고 기존 page render tree·JSON과 같은 generation에서 무효화되는 page-local,
profile-keyed `PageLayerTree` cache를 최대 4개 variant로 제한해 원인을 제거했다.

성능, WASM 크기, cache/resource 선형성, Studio·CanvasKit, native full, Native Skia와 lint gate가 모두 승인된
hard gate 안이다. cold first build는 과거 동등 기준이 없어 이번 값을 최초 baseline으로 공개하며 사후 ceiling을
적용하지 않았다.

## 출력·resource 불변식

- exact-default와 explicit-default: TextRun 1, GlyphRun 0, GlyphOutline 0, font blob/face 0이며 layer·CanvasKit hash가 같다.
- interior/max: TextRun·GlyphRun·GlyphOutline 각 1, unique font blob/face 각 1이다.
- `1/2/8 instance × 1/2/8 run` 전 조합에서 digest pass·source face parse·arena intern은 unique source당 1회다.
- parsed instance face와 cached result는 instance 수 1/2/8에만 선형이고, 추가 run은 0/1/7, 0/2/14,
  0/8/56 cache hit로 흡수된다.
- 최대 8 instance × 8 run에서도 source bytes 1,503,064, font blob/face 1, payload 2,613,391 bytes이며
  glyph run/outline 각 64로 bounded하다.
- cache hit은 기존 output/profile fingerprint를 key로 사용하고, page tree·JSON cache와 같은 편집 generation에서
  함께 무효화된다. page당 variant 상한은 4다.

## 검증 중 발견·정정한 절차 문제

1. 최초 matrix fixture가 run마다 독립 registry/context를 만들어 source identity 보호 불변식에 거절됐다. 한
   registry/context/transaction으로 고쳐 실제 cache ownership을 측정했다.
2. generated suite 재배치 후 atomic test를 이전 suite 022로 호출해 0건을 실행했다. 현재 manifest를 조회해 suite
   024로 정정했고, 이후에는 공식 router를 사용했다.
3. all-target Clippy가 고정 8개 instance fixture의 불필요한 `Vec`를 검출했다. 배열로 최소 정정해 재통과했다.
4. 첫 full nextest에서 exact-font instance set/clear API가 미분류 문서 뮤테이터로 탐지됐다. 두 API는 문서 IR이
   아니라 request·layout cache만 바꾸므로 기존 #4968 registry API와 같이 `SessionState` 근거로 등재했다. focused
   5/5 뒤 최종 full 8,757/8,757을 다시 통과했다.
5. EXEMPT 추가로 source weight가 바뀐 직후 stale generated suite를 한 번 호출해 0건을 얻었다. 이를 성공으로
   기록하지 않고 prepare/check 후 재실행했다.
6. 기존 warm aggregate를 cold ceiling으로 재사용하려던 초안은 단위·측정 조건이 달라 철회했다. cold는 이번
   최초 baseline으로 공개하고 비교 가능한 warm gate만 hard 판정했다.
7. 최종 diff 감사에서 빈 문서 교체와 머리글·바닥글 숨김이 기존 page tree만 직접 비우고 새 `PageLayerTree`
   cache까지 무효화하지 않는 경로를 발견했다. 전체·단일-page 공통 헬퍼로 세 캐시를 함께 비우고 실제 cache를
   채운 보호 테스트 2건을 추가한 뒤 전체 회귀·Native Skia·WASM을 최종 소스에서 재실행했다.
8. 신규 보호 테스트의 첫 focused 호출은 짧은 이름에 `--exact`를 써 0건을 선택했다. 이를 통과로 기록하지 않고
   `--list`로 전체 경로를 확인한 뒤 각 테스트 1/1과 full suite 포함 실행으로 고정했다.
