# planet6897 통합 검토 Stage 2 - 개별 판정과 통합 PR 기록 계획

## 목표

`planet6897`의 열린 PR #4041, #4047, #4053, #4057, #4060, #4066, #4067, #4077을 최신
`upstream/devel` 위 누적 검토본에서 개별 판정한다. 중복 선행 commit은 한 번만 적용하고,
Stage 1 메인터너 보정을 포함한 통합 PR에 review 기록과 오늘할일을 함께 넣는다.

## 구현 계획

1. 원 PR의 최신 head·base·변경 범위·CI 상태를 다시 읽고, 각 review 문서에 source SHA와 누적
   적용 SHA, 의존 PR과 충돌 해소를 분리해 기록한다.
2. #4067의 실제 HWP fixture를 HWP 2020 MCP로 PDF 변환한다. 서버 경로나 token은 기록하지 않고,
   원본·PDF SHA-256, 페이지 수, validation, 생성된 기준 PDF 경로만 증적으로 남긴다.
3. 같은 fixture를 rhwp SVG로 렌더링해 HWP 2020 PDF의 대표 첫 페이지와 비교한다. 기준 PDF, 임시
   output, 대표 PNG asset, 판정 범위를 review 문서에 남긴다.
4. #4041, #4077의 같은 `typeset.rs` 수정은 Stage 1의 순수 경계 테스트로 보강됐음을 두 review에
   명시한다. #4057/#4060/#4066의 이미지 PR은 선행 commit이 중복 적용되지 않았음을 명시한다.
5. archive review 문서 8개와 `mydocs/orders/20260806.md` 갱신을 같은 최종 review 묶음 commit으로
   만든다. 통합 PR 생성 전 최신 `upstream/devel`과 모든 원 PR head를 다시 확인한다.

## 검증 계획

- `git diff --check`와 문서 링크·SHA 검토
- HWP 2020 MCP PDF 생성 결과의 status, validation, `pdfinfo`, SHA-256 확인
- rhwp SVG export와 대표 PNG 시각 검토
- Stage 1의 `release-test --tests`, Native Skia 3종, clippy, WASM 결과를 원 PR별 관련 범위에
  재사용하되 결과를 미래형으로 표현하지 않는다.
