## 목표

`integrate/kevin9327-open-prs-20260816`에 누적한 공개 PR의 정적 검토에서 확인한
출력 계약 불일치를, 소비자가 잘못된 렌더 결과나 잘못 해석한 측정값을 받기 전에

## 변경

- `SvgBackend`가 `ClipRect`를 전달하지 않는 실제 구현에 맞춰 `clipping: false`를
  선언했다.
- 페이지별 독립 SVG를 하나의 문자열로 이어 유효하지 않은 SVG를 만들지 않도록
  두 번째 페이지를 명시적으로 거절하고 `multi_page: false`를 선언했다.
- `export_text`의 문자 오프셋은 표시용 페이지 줄바꿈이 아닌 문서 본문 글자 좌표임을
  코드 주석으로 고정했다.
- 대형 문서 사다리의 RSS 표기는 Windows 전용 계측값임을 보고서 제목과 도구 설명에
  명시했다.

## 검증 계획

- SVG 능력 선언과 두 번째 페이지 거절을 단위 테스트로 고정한다.

  Rust·Python 변경 범위의 검증 게이트를 수행한다.
