# Task M100 #4969 W10-Q2-A — terminal attempt owner

## 판정

Q1의 `shape_bounded_request`를 layout·paint와 무관한 terminal attempt owner로 승격했다. 성공·실패 모두
`ShapingAttemptTrace`를 가지며, pre-shaping 중간 상태인 `requested`는 terminal vocabulary에서 제외했다.
applied 결과만 `Arc<AppliedShapingRun>`으로 canonical identity와 glyph vector를 한 번 소유한다.

기계 판독 결과는
[`w10_q2_a_terminal_attempt.json`](../../tech/investigations/issue-4969/w10_q2_a_terminal_attempt.json)이다.

## attempt 계약

trace는 다음 값만 직렬화한다.

- bounded `attemptId`
- terminal `disposition`과 typed `reason`
- canonicalization에 도달한 경우의 settings·font source SHA-256
- glyph count

source unavailable·font byte limit처럼 canonicalization 전에 닫힌 attempt의 hash는 `None`이다. 빈 문자열이나
가짜 identity를 발급하지 않는다. 원문·font payload·로컬 경로와 glyph vector는 trace에 없다.

applied payload는 trace ledger와 분리했다. 향후 layout·paint가 동일 `Arc`를 소비할 수 있지만 Q2-A에서는 어느
제품 경로에도 연결하지 않았다.

## bounded ledger

`BoundedShapingAttemptLedger`는 최대 4,096개 trace만 보존한다. limit 필드는 외부에서 변경할 수 없으며, 이후
record는 vector를 키우지 않고 status를 `truncated`로 바꾸고 saturating omitted count만 증가시킨다. applied
glyph payload는 ledger에 보관하지 않는다.
