# Task #3681 Stage 3 중간 보고 — 지배 갭 분해 (진행)

대표 4종: 3차원묶은가로막대형(8.83) · 누적꺽은선형(18.49) · 묶은세로막대형(32.62) ·
2차원원형(55.20).

## 확정된 사실

1. **쪽 수준 기하는 정합** — 잉크 bbox 정렬 실험: 스케일 1.002, 오프셋 0px (4종 공통).
   bbox 정렬 후 ink 개선 +0.9 이하 = **"차트 박스 크기·여백" 가설은 쪽/프레임
   수준에서 기각**.
2. **색·구조 정합** — review 시트 육안: 계열 색(파랑/주황/회색)·범례·데이터 구조 일치.
   색상 팔레트 가설 기각.
3. **하니스 ink_match 는 색 민감 diff** (`ink_diff/ink_union`) — 이진 IoU 로 재면
   같은 문서가 8.83→29.4 로 뛴다. 지표 정의를 보고에 명시해야 오독을 막는다.
4. 지배 갭은 **차트 내부 콘텐츠 기하**(플롯 영역 배치·막대 두께/길이·폰트 스케일)로
   좁혀짐 — overlay 육안: PDF 는 프레임을 채우고 rhwp 는 내부 여백이 큼
   (3차원묶은가로 review_003.png).

## 미해결 — 성분 정량화 방법의 함정 2건 (정직 기록)

- 콘택트 시트 패널은 배율이 달라 육안 크기 비교가 **착시**일 수 있다.
- 잉크 분산(σ) 프록시는 방향 혼재(0.82~1.09)로 판별력이 없다 — 굵기·밀도 변화가
  분산에 역방향으로 섞임(누적꺽은선형: pdf 잉크량 1.57배인데 σy 0.88).
