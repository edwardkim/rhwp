# planet6897 통합 검토 Stage 1 - 조판 충돌 회귀 보정 계획

## 목표

`#4041`의 저장 사다리 꼬리줄 연쇄 상한과 `#4077`의 각주 안전영역 조건부 예외를 최신
`devel` 위 통합 검토본에서 함께 유지한다. 두 PR은 같은 줄 분할 루프를 수정하지만 적용
조건이 다르므로, 충돌 해소가 한쪽의 안전 조건을 제거하지 않았음을 코드 수준에서 검증한다.

## 구현 계획

1. 저장 꼬리줄 연쇄의 상태 전이를 순수 판정 함수로 분리한다. 적용 대상에서는 처음 두 줄을
   허용하고 세 번째에서 분할하며, HWP 권위 경계와 native HWP5 각주 경계 예외에는 상태를
   변경하지 않는다.
2. 저장 줄의 각주 영역 상단 통과 판정을 순수 함수로 분리한다. 각주 존재, 단일 단, 안전
   마진 이하 초과, 저장 좌표의 본문 한계, 흐름 커서 허용오차를 모두 만족할 때만 허용한다.
3. 위 두 판정의 경계값 회귀 테스트를 `typeset.rs`의 기존 단위 테스트에 추가한다.

## 검증 계획

- `cargo fmt --check`
- `cargo test --lib saved_tail_fit_chain -- --nocapture`
- `cargo test --lib saved_line_clears_footnote_area -- --nocapture`
- `cargo test --lib emitted_as_svg_not_raw -- --nocapture`
- `cargo test --lib test_embedded_measurer -- --nocapture`
- Native Skia 공식 3종과 `wasm-pack build --target web`을 전용 target에서 순차 실행한다.
- `git diff --check`

작업지시자가 루트 파일시스템 용량을 확보한 뒤 전체 `release-test` gate도 전용 target에서 재실행한다.
Cargo 계열 명령은 같은 target을 공유하므로 동시에 실행하지 않는다.
