# #7642 PDF 기준 raster의 균일색 보존 보정

## 구현 근거와 변경

[상수 면 독립 재현](task_m100_7642_stage2071.md)의 손실 없는 RGB/Flate PDF를
정식 검사로 작성했다. 균일색의 내부는 분수 좌표에서 축소해도 같은 색이어야 한다.
수정 전 `pdftoppm`의 96DPI 출력은 RGB 64→63으로 실패했고, 144DPI와 선택 쪽
계약은 통과했다. 특정 문서나 raw 마스크의 경계를 골라 색을 바꾸지 않았다.

전체·선택 페이지의 PDF 출력은 공통 `pdftocairo` 경로로 옮겼다. 같은 poppler-utils에
포함된 Cairo backend이며 새 Python PDF dependency는 없다.
`scripts/visual_sweep_pdf.py`가 명령·도구 버전·실행 파일 해시·정책·helper 해시를
제공한다. 기존 source PDF·페이지·DPI와 내용 이진화·raw 수식·90%·98%·0.01%p는
유지했다. `shape`/`solid`로 실제 채우기를 지우거나 문서마다 backend를 고르지 않는다.
새 reference는 이전 Splash PNG·TSV에 덮어쓰지 않으며 같은 base/head에 적용한다.
