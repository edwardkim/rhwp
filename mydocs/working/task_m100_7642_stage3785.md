## 잔여 설명 정렬

상위 판정 절은 이미 0.1%p였으나 이 브랜치가 추가한 Visual Sweep PDFium 설명에
0.01%p가 남았다. 해당 한 곳을 PR #8016의 정본과 같은 **0.1%p**로 맞춘다.
정확히 0.1%p인 하락도 재검토한다. 전쪽 90%, 완료 페이지 98%, 내용·쪽수 보존,
직접 확대 판독, RGB 내용 마스크와 2px 관용 거리는 바꾸지 않는다.
앞 단계에서 당시 기준으로 계산한 0.01%p 목록은 과거 결과로 보존한다.

후속 diff 검사에서 예전 단계 124 보고서의 줄 끝 공백과 선 굵기 진단 README의
불필요한 마지막 빈 줄도 확인했다. 두 곳은 공백만 정리하며 기록의 수치·입력·판정은 유지한다.

## 기존 검증의 출처

범례 보정 후보 `21bfc5b559`의 Native 14문서 301쪽은 전쪽 raw 90% 이상과 쪽수 일치를
확인했고, 기존 차트 검사 165개도 통과했다. PrEP 26/27쪽은 각각
94.40431% / 91.56789%다. 세부 범례의 남은 차이는 완료로 처리하지 않았다.

같은 후보의 fresh WASM은 별도 worktree에서 빌드·Studio 파일 동기화를 마쳤다.
리베이스 중 변하는 원문을 읽지 않도록 대기 중인 캡처 시작만 일시 정지했다.
리베이스와 문서 감사 후 같은 대기를 재개한다. 빌드·캡처의 실제 source SHA를
리베이스 후 새 SHA로 덮어쓰지 않는다. 전후 코드가 같다는 근거와 실행 출처를 구분한다.

ignored `stage3779-rebase-224a326063`에 리베이스 로그·새 PR 원문·두 base의 트리 비교를,
`stage3782-post-rebase-audit`에 후보 트리·지침·링크 감사 결과를 보존한다.
전체 Rust·원래 전체 시험지 범위·새 기준의 최종 Native/fresh WASM 비교와 PR 준비는
아직 완료되지 않았다. 이번 문서 정렬은 렌더링 결함 해결이나 PR gate 통과가 아니다.
