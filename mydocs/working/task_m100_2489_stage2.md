# 작업 2489 단계 2 - 현재 작업 문서 한국어 통일

## 범위

- 현재 통합 브랜치에서 새로 만든 `mydocs/working` 문서 가운데 영어 본문으로 작성된 단계 문서를
  한국어로 번역한다.
- 영어로 남은 `Task`·`Stage` 제목도 한국어 제목으로 통일한다.
- 코드 식별자, 파일 경로, 명령, 제품명, HWP/HWPX/HML 같은 형식명은 정확성을 위해 원문을 유지한다.

## 검증 계획

1. 현재 브랜치가 추가·수정한 작업 문서만 대상으로 삼아 과거 archive 문서를 변경하지 않는다.
2. 번역 뒤 문서의 Markdown 구조와 링크, 명령 블록이 보존됐는지 확인한다.

## 경계

- 과거 archive의 대규모 번역은 이 통합 변경의 범위가 아니며, 별도 문서 정비 작업에서 다룬다.

## 결과

- 현재 통합 task에서 추가한 영어 본문 단계 문서 9개를 한국어로 번역했다.
- 현재 통합 task에서 추가한 작업 문서 15개의 제목을 한국어로 통일했다.
- 코드 식별자, 명령, 파일 경로, 형식명은 기술적 정확성을 위해 원문 표기를 유지했다.
