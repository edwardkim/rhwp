# Task M100 #4967 Stage W8-R7-Q3 — bounded same-snapshot qualification

- **계획**: [`task_m100_4967_v3.md`](../plans/archives/task_m100_4967_v3.md)
- **공개 결과**:
  [`rank7_private_qualification.json`](../tech/investigations/issue-4967/rank7_private_qualification.json)
- **실행 정책**: Q0 동결 5문서만 read-only, 전수 10k·Hyper-V·제품 변경 없음

## 1. 계측 경계

Q0 local-only 원장에 봉인한 5문서(HWP 3, HWPX 2)만 사용했다. 쪽마다
`rhwp-q-font-layout-evidence`가 `PageRenderTree`를 한 번 만들고 Font Decision Trace, 실제 TextLine frame,
run membership와 stored-row cache disposition을 같은 snapshot에서 반환했다.

Q3 projector는 current heuristic base를 px 정밀도로 재생하고 base만 exact KoPubWorld Dotum Light TTF의
`hmtx`로 바꾼다. ratio, letter spacing, justification, clamp 순서는 current와 동일하며 replay mismatch는
0이다. font bytes, private 경로·문서명·hash·본문과 상세 line 좌표는 tracked 결과에 넣지 않았다.

CharShape style은 기존 read-only `rhwp dump`의 ID·ratio·spacing·bold·italic만 메모리에서 추출해 trace의
`charShapeId`와 조인했다. dump 본문은 저장하거나 공개하지 않았다. nested table-cell의 일부 ID는 이
경로로 조인되지 않아 style 판정은 fail-closed로 남겼다.

## 2. 회계

| 항목 | 수치 |
| --- | ---: |
| 동결 문서 | 5 (HWP 3 / HWPX 2) |
| Q0 source usage | 63,858자 |
| Q3 render observation | 74,969자 |
| render 반복 관찰 delta | +11,111자 |
| exact metric 적용 | 74,132자 |
| cmap miss 보존 / special 보존 | 251 / 586자 |
| current transform replay mismatch | 0 |
| trace truncated page | 0 |
| unframed / invalid-frame target | 0 / 0자 |

source usage와 render observation은 반복 story 때문에 다른 회계다. 74,969자를 새로운 corpus usage 수치로
해석하거나 Q0 63,858자와 중복 제거 없이 합산하지 않는다.

cache disposition은 admitted 19,182자, rejected 326자, unmodelled 55,461자다. style 조인은 11,504자를
설명했고 63,465자는 미조인이다. 따라서 전체 evidence는 complete가 아니며 stored LineSeg 전체의 유효성을
주장하지 않는다.

## 3. 개선과 회귀

전체 render line 관찰은 다음과 같다.

| disposition | line observations |
| --- | ---: |
| overflow removed / reduced | 289 / 12 |
| overflow introduced / increased | 140 / 31 |
| slack increased | 208 |
| unchanged | 12,089 |

평균적으로 좁아지고 overflow를 제거하는 line도 있지만, 회귀 171건은 모두 table-cell이다. 이 가운데
cache admission으로 modelled된 51건은 모두 다음 한 boundary signature의 반복 관찰이다.

```text
format=HWPX
context=table-cell
stored-row=admitted
current overflow=0px
candidate overflow=0.707px
line advance delta=+162 HWPUNIT
disposition=overflow-introduced
bold=false
```

나머지 regression 관찰 120건은 cache-unmodelled이므로 제품 변경의 근거로 승격하지 않는다. 반대로
modelled 51건은 같은 signature가 반복됐다는 이유로 서로 다른 51개 원본 결함이라고 부르지 않지만,
실제 렌더 line에서 재현된 한 종류의 결정적 회귀로는 충분하다. 최대 전체 관찰 overflow 증가는 4.22px,
modelled signature는 0.707px다.

## 4. format·context·style 판정

- HWP regression 관찰은 1건이며 cache-unmodelled이다.
- HWPX regression 관찰은 170건이고, modelled 51건은 전부 HWPX table-cell admitted row다.
- body·header·footer에는 신규·증가 overflow가 없다.
- bold render observation은 1,269자이며 bold line은 overflow removed 2, slack increased 2, unchanged 22다.
- modelled regression의 bold line은 0이다.
- italic source usage와 render observation은 모두 0이다.

bold 후보가 advance를 바꾸지 않는다는 Q2 source 불변식과 관찰된 1,269자는 모순되지 않는다. 그러나
nested style 미조인 때문에 Q0 bold 4,468자 전체를 동적으로 닫지는 못했다. 이 미완전성은 후보를
`qualified`로 올릴 수 없게 하지만, 이미 확인된 non-bold modelled 회귀를 무효화하지 않는다.

Q3 종료 게이트는 평균 개선으로 신규 overflow를 상쇄하지 않는다. 따라서 rank 7 일괄 exact

진입하지 않는다.
