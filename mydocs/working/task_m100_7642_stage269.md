# 논리 괄호와 자연 글리프가 섞인 일반 줄의 분류

Issue: #7642

## 실제 회귀와 독립 근거

Source255의 9월 2022 원본 HWP 20쪽은 91.34687%, Source261은 76.59445%다.
같은 HWPX 20쪽도 76.57746%다. 원본·독립 Print·명령을 유지했으며 현재
변경의 회귀로 판정한다. 파일 제거·이관·기대값 변경으로 숨기지 않는다.
Source261 math8 및 24/64/32개 진단의 Native/fresh WASM 전쪽은 각각
99.59499/98.51842/98.48803/99.29034%이며 이 성공을 9월 실패의 면제로 쓰지 않는다.

새 `layout_paren`은 논리 기준선과 본체 원점을 발행한다. 일반 Row는
자연 글리프와 논리 괄호를 그 기준선으로 정렬하므로 임시 합집합 높이가 명목
글자 크기와 다를 수 있다. `font_line`은 모든 상자의 높이가 명목 크기와 같아야
한다고 가정해 일반 분수·글줄의 논리 프레임을 거절했다.

동일 페이지의 표시 트리 240개를 대조했다. 첫 변경 수식의 높이가
27.6에서 30.6으로 증가하고 다음 문단부터 이동이 누적된다. 수치는 진단이며
화면 핀이나 허용치로 사용하지 않는다. 일반 글줄 분류는 리프의 글자 크기와
가로 소속을 소비해야 하며 자연/논리 상자의 임시 합집합을 글줄 종류로 쓰지 않는다.

## 생산·소비와 반례

`layout_paren` 논리 기준선/본체 원점 → `layout_row` 가로 기준선 정렬 →
`logical_font_frame::font_line` 의미 분류 → `fraction_sup_frame`와 논리 분수
프레임 → 실제 분수 배치 및 문단 측정/전진의 호출 경로를 추적했다.
가로 Row의 소속 확인과 리프 크기 확인을 보존하고 컨테이너 높이 비교를 제거한다.
세로 Row, 분수·첨자·장식 본체, 실제 글자 크기 변경을 일반 줄로 접지 않는다.

원본 9월 전체 HWP/HWPX, 첫 변경 분수와 뒤 문단, math8 및 정상화 대조군을
한 빌드로 확인한다. 소스는 별도 후보 `local/7642-stage269`에서 준비하여
현재 Source261의 실행 증거를 보존한다. 모든 컴파일은 공용 target/pr-review를
순차 사용한다. 새 소스의 Native/fresh WASM·확대 판독은 아직 미검증이다.
정식 회귀·전체 검증·PR 완료로 판정하지 않는다.
