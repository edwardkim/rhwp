## 직접 판독과 초기 추정 정정

stage2302에서 review와 standalone overlay를 직접 열었다. WMF 기본 펜의
선 농도·두께가 다르고 마지막 anisotropic EMF의 물리 범위도 다르다.
수치가 90%를 넘더라도 이 상태로 golden/mapper 기대값을 갱신하지 않는다.
WMF의 선택 기본 pen은 width=1을 논리 Stroke로, EMF의 기본 pen은 장치 폭
정규화 경로로 소비한다. 코드상 경로 차이는 확인했지만 올바른 변경량이나
모든 문서에 적용할 일반 규칙은 아직 독립 출력으로 입증하지 못했다.

처음에는 EMF 3종이 누락되고 글꼴도 다르다고 추정했다. 실제 캡션은 양쪽
HCR Batang이며, 그림에는 매우 옅은 선이 있다. 따라서 누락/글꼴 차이를 확정
원인으로 쓴 stage2281 문구를 정정한다. MIME만 바꾼 이전 Print도 도형 출력을
복구했다는 근거가 없었으며, MIME 별칭을 무효 형식이라고 주장하지 않는다.

정상화 대조군 수치는 원본 바이트 의미·기존 SVG 문자열 golden의 정확성을
입증하지 않는다. 명시적 펜과 물리적으로 일관된 frame 대조를 독립 Print로
확인한 후, 실제 도형의 변환 의미를 보호하는 검사와 필요한 구현을 판단한다.
현재 9개 golden과 #7266 mapper 검사는 변경하지 않았다.
