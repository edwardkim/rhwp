# Stage 323 — 문서 구조 인자의 중단 상태 공유

Issue: #7642

Stage 322의 독립 Print에 따라 문서 파서의 구조 인자 시작 경로를 공유했다.
필수 몸체가 없는 MATRIX/PMATRIX/PILE/EQALIGN/CASES와 빈 MATRIX 몸체는
이후 입력을 중단한다. 유효한 빈 PILE/EQALIGN/CASES와 행·셀 구분자는 유지한다.
이미 읽은 앞 항과 바깥 수식 구조를 비우지 않는다.

생산 지점은 `parser_structures::begin_structure_body`다. 같은 parser가 가진
중단 상태를 `current`·`current_type`·`at_end`에서 읽으므로 표현식·그룹·행·첨자가
각자 다음 토큰을 다시 해석하지 않는다. 전체 수식을 비우는 기존 명령형 첨자
오류와 구분하며 공개 `EqParser::new` 경로에서는 중단 상태를 만들지 않는다.

기존 긴 parser는 명령, 분수·LaTeX 호환 문법, 구조 몸체, 기존 검사로 분리했다.
수정·신규 파일은 모두 1000줄 이하다. 기존 검사는 `include!`로 같은 namespace에
유지했다. 기계적인 소스 이동의 역변환 검증은 ignored
`stage323-parser-source-move-proof.json`에 보존했다.

## 사전 계약 검사

동일 생산 parser source를 사용하는 별도 진단 executable에서 독립 Print의
30개 문서 계약과 공개 호환 경로 30개 대조를 실행했다. 수정 전은 의도한 원인인
뒤 항의 잔존으로 9건 실패했고, 수정 후는 60건 모두 통과했다. 컴파일·환경 오류를
수정 전 실패로 세지 않았다. executable은 공용 `target/pr-review/release-test`에 있다.

진단은 정식 회귀 추가나 실제 출력의 시각 통과를 대신하지 않는다.
전체 Native/fresh WASM TSV와 확대 판독 후에 새 이름의 관계형 회귀를 추가한다.
현재 Native CLI 빌드, 기존 정식 파서 검사, fresh WASM 빌드·재출력은 아직 미검증이다.
OVERSET/UNDERSET의 차이와 다른 원본·진단 문서의 미달 범위도 남아 있다.

## Native 재출력과 정책 보정

Source `91fca5830c7cef16c23678ec415e93ded4e98768`의 Native CLI 빌드가 종료 코드 0으로
완료되었고 빌드 중 source hash가 유지되었다. 컴파일 잡 8개, 공용 target을 사용했다.
동일 한컴 저장본·Print PDF의 전체 1쪽 비교에서 24개 진단은 90.64429%,
30개 대조군은 93.47702%였다. 쪽수와 TSV 범위는 각각 1쪽으로 일치했다.
`stage323-structure-native-scores.json`에 source·binary·입력/PDF SHA와 명령을 보존했다.

새 review의 OVERSET/UNDERSET에 여전히 출력 차이가 보인다. 90% 통과를 완료로
판정하지 않으며, fresh WASM과 세부 영역의 보정·재검증이 필요하다.
기존 cfg(test) 항목의 파일 이동은 unit-tier 정책에서 신규 항목으로 검출되었다.
Stage 324에서 원래 위치를 복원하고 production 함수의 분리를 추가했다.
