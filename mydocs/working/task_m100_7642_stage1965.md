# #7642 원격 raw 판정 변경 적용과 이전 판정 구분

Issue: #7642

## 확인한 출처

사용자가 제공한 예시는 `ubuntu-ted3:~/rhwp`의 PR 전 변경이다.
해당 호스트의 head는 `4246468203100a0bd2a7c9f4523c281ac962f521`이며,
Visual Sweep 판정 변경은 `737d2cea2eeb6fa7eb5afda393eb0f96c1df12fb`다.
해당 파일의 원격 작업 트리는 clean이었다. 원격 파일·브랜치는 수정하지 않았다.
최신 공개 upstream `552514f423`에는 이 커밋이 없었으며, 기존 리베이스의 누락과 구별한다.

## 적용 범위

원본 커밋의 script·test·지침을 직접 적용한다. 별도로 작성했던 제안 patch와 검사는
ignored output에 보존하고 원본 커밋의 필드 의미와 검사로 맞췄다.
`silhouette_raw_match_percent`를 90% gate·devel 하락·98% px 조건에 사용한다.
`tolerant_content_match_percent`는 경계 보정 진단값으로 유지하며 raw 미달을 면제하지 않는다.
TSV의 기존 열을 바꾸지 않고 `below_90`과 review/overlay 하단을 raw 판정에 연결한다.
기존의 독립 PDF 그라데이션 보존용 `thinlinemode=none` 보정은 유지한다.

이 브랜치에 없는 타 작업 #7751의 stage5 문서만 modify/delete 충돌이 발생했다.
해당 원문은 `stage1965-ted3-task_m100_7751_stage5.md`와 가져온 원본 Git commit에
보존하고, 그 작업의 도형 구현 기록을 이 브랜치에 새로 복원하지 않는다.
현재 작업의 적용 기록은 이 문서로 남긴다.

## 이전 검증의 구분

새 head의 Native 빌드는 stage1954에서 exit0, fresh WASM 빌드는 stage1956에서 exit0이다.
Native 7개 입력·17쪽의 영향 진단과 원본 sample16 계열 전64쪽 산출을 확보했다.
이는 당시 경계 보정 판정이며 새 raw 전체 통과가 아니다.
현재 산출된 raw 전쪽 최저는 원본 HWP3 89.03816%, HWPX75.43041%,
HWP5 저장본76.16824%이므로 모두 재검토 대상이다. 원래 CSV·이미지·당시 판정은 덮어쓰지 않는다.
기준 변경 중 구·신 결과가 혼합되지 않도록 전쪽 Native/WASM 큐를 중단했다.

## 계속할 검증

원본 커밋의 전체 Visual Sweep Python 검사를 실행하고, 새 source에서 대표 review와
standalone overlay·raw TSV를 다시 산출한다. 원본 PNG 재분류와 새 head 재출력은 구분한다.
원본 HWP3의35쪽, HWPX/HWP5의18쪽을 우선 판독하고 실제 출력을 먼저 보정한다.
새 테스트·px 좌표 추가 또는 기존 기대값 갱신 전에는 새 raw 조건으로 전쪽 자격을 확인한다.
전체 회귀·필수 lint·89개 항목의 전쪽 Native/fresh WASM·고정 devel 비교는 미완료이며,
PR 준비 완료로 보고하지 않는다.
