## 원문·Print·출력 대조와 변경

### 온새미로 쪽수3건

정확히 `samples/[2027] 온새미로 1 본교재.{hwp,hwpx}`의 독립 전체 Print는
각각46쪽이다. stage2869의 같은 원본·Print 전쪽 Native/fresh WASM 결과는
HWP 최저90.17559/90.10782%, HWPX90.16447/90.11795%다. 쪽수와 쪽 범위는 같다.
stage2903의6쪽과 마지막46쪽 review·standalone overlay를 양쪽에서 직접
읽었다. 마지막 쪽의 바탕쪽과 빈 본문도 Print와 같다.

원장 두 행과 #2158의 과거47쪽 핀을 실제 Print46쪽으로 교정한다. 쪽수만
바꾸지 않고 #2158에서 구역1/문단32의6쪽 소속과 원문 전체의 순서·누락·중복을
검사한다. 같은 이름이어도 내용이 다른 `samples/hwpx/` 및 다른 변환본의
원장 행은 바꾸지 않는다. 원본·기준 PDF는 이미 추적된 파일을 재사용한다.

### 점선 검사1건

원본 지문 박스의 네 면은 `BorderLineType::Dot`이다. 실제 출력은 네 Line에
짧은 선/공백을 명시한 `StrokeDash::Explicit`을 사용한다. 옛 `Dot` 열거형과의
직접 비교 때문에 선이 있어도 실패했다. 독립 Print에도 짧은 선과 더 긴
공백이 있다. 비실선 여부만 검사하지 않고 두 구간의 순서·나머지 구간의
부재·원문 색상을 확인한다. 고정된 ±80px 탐색 영역은 제거하고 실제 지문
줄 상자를 둘러싼 가장 가까운 네 변의 포함·끝점 연결 관계를 검사한다.

stage2902의 원본 SVG 진단은 실제 네 면의 점선 방출을 확인한다. 독립 Print의
개별 선분과 현재 패턴에는 미세 반복 간격 차이가 있어 추가 분석 대상으로
남긴다. 이번 관계 검사의 통과를 그 차이의 해결로 보고하지 않는다.

### 페이지 테두리 검사2건

`PagePaintContext`의 Print 출력 종이는 정수 point 크기이고, 벡터·Studio 정보는
원문 논리 용지 좌표를 쓴다. 테스트가 물리 viewport 크기로 논리 좌표를 나눠
원문 spacing 비율과 달라졌다. 원문 HU를96dpi로 환산한 논리 용지로 정규화하고,
물리 종이가 원문 point의 정수부인지 별도로 검사한다. 원래 비율 허용치,
독립 Print 선 굵기와 이중선 간격·네 면 누락/중복 검사는 유지한다.

stage2876의 동일한12입력은 Native/fresh WASM 모두 각 한 쪽, raw100%다.
stage2907에서 본문 기준 이중선 w10의 두 review·standalone overlay를 직접
열어 선 두 줄·내부 간격·본문 기준 위치를 판독했다. 엄격 내용 픽셀 보조값은
37.08798/37.72671%이며 raw100%와 구분한다. 논리/물리 좌표 혼동 때문에
허용 오차를 늘리거나 원본 spacing을 변경하지 않는다.
