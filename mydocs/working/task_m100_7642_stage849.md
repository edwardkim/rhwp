# Issue #7642 단계 849: 실제 중첩 묶음과 첫 표 조각의 호스트

## 실행 결과와 입력 확인

단계 846에서 `a51a72429`의 최적화 Native 빌드를 release-test 프로필로 통과했다. 준비된 integration suite는 027이었으며 실행 전에 원본 파일을 포함한 suite를 조회해 선택했다. 검사 4건 중 내용·표·그룹 프레임 왕복과 탭 2건은 통과했고 IR의 빈 묶음 필수 존재 검사만 실패했다.

원본 전체 조판부호 덤프에서 최상위 묶음은 자식 3개 또는 2개이며 중첩 묶음도 자식 2개다. 이 원본에 빈 묶음이 있다는 기존 검사 설명은 실제 입력과 다르다. 새 계약은 실제 중첩 묶음의 구조·깊이·원본 상대 오프셋·크기 보존을 검사한다. 표·그리기 글상자·머리말·꼬리말·주석 안의 묶음도 같은 입력의 소속을 따라 수집한다. 없는 빈 묶음을 검사했다고 기록하지 않으며, 별도 합성 원본을 실물 Print 증거로 대신하지 않는다.

## 첫 부동 조각의 실제 호스트

단계 847은 같은 Native 산출물로 전체 122쪽 진단을 수행했다. 37쪽의 첫 부동 조각은 아직 19행에서 끝나고, 공동 앵커 계획의 호스트 원점은 None이었다. 전역 저장 축을 복구할 수 없더라도 단 중간에서 실제 앞 TAC와 같은 원본 줄·동일 물리 frame으로 수용한 문단은 앞 간격을 소비한 호스트를 갖는다. 캡처한 문단 시작과 원본 앞 간격의 합을 이 물리 호스트로 전달하고 기존 budget이 원본 선언 높이·행 끝과 대조하도록 한다. 단 맨 위의 간격은 별도 수용 계약이므로 이 경로에서 추정하지 않는다. 관측 행 번호·px에 맞춘 분할 조건을 추가하지 않는다.

## 남은 검증

변경을 커밋하고 같은 공용 target, 빌드 잡 8개에서 빌드·그룹 검사·선택 쪽 Native와 fresh WASM을 다시 확인한다. 현재 Native 37쪽 98% 결과에도 행 차이가 남아 완료·승인을 보류한다. HWPML 미달 쪽, 전체 55개 원본·대조 문서, base 대비 하락과 전체 회귀·lint의 완료가 필요하다. PR·CI·별도 review/오늘할일 PR·머지와 후속 처리 순서는 유지한다.
