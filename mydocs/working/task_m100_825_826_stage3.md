# Task #825 Stage 3 (GREEN) 보고서

## 발견 — 예상 범위 확장

Stage 1 사전 조사에서 식별한 단순 "WASM API 확장" 으로는 부족. 추가 조사 결과:
- `layout_picture` 가 머리말/꼬리말 호출 시 인덱스 정보 None 전달
- `RenderNode::ImageNode` 가 인덱스 None → `getPageControlLayout` JSON 에 secIdx 부재
- `findPictureAtClick` 가 `ctrl.secIdx === undefined` 필터로 제거 → 클릭/우클릭 자체 도달 불가

→ Stage 3 를 3 substage 로 분할 진행.
