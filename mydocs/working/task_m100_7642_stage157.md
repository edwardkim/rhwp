# #7642 Stage 157 — 도형 선 종류와 굵기에 비례하는 반복 패턴

Issue: #7642

## 독립 근거와 범위

Stage 155의 `pdf/issue7642-line-pattern-probe-20261012/` 진단 HWPX를 한컴 2024
13.0.0.3901 MCP의 PrintMethod=0으로 출력했다. Print 벡터에서 uppercase `DASH`는
짧은 사각 점, `DOT`는 긴 파선이다. 기존 borderFill 파서는 같은 이름을 이미 올바르게
해석하지만 도형 lineShape 파서·직렬화기는 반대의 HWP5 코드로 매핑했다.

Print의 `DASH` 굵기 28·56·112·224HU 모두에서 사각 점 길이는 선 굵기의 약 1.5배,
시작 간격은 약 3.75배였다. `DOT`는 길이 7.5배와 공백 4.5배, `LONG_DASH`는
길이 15배와 공백 4.5배였다. 쇄선은 긴 구간 15배, 짧은 구간 1.5배, 공백 4.5배이며
원형 점은 지름 1배·중심 간격 2.25배였다. PDF의 장치 단위 반올림은 렌더 좌표의
고정 px 보정으로 복제하지 않는다.

도형에 한컴 패턴을 부여하고 기존 범용 Dash/Dot와 구분한다. SVG·Canvas2D·Native Skia·
Studio CanvasKit은 선언 선 굵기에 같은 비율을 곱한다. 원형 점은 round cap을 사용한다.
문서 번호를 근거로 한 점선 최소 1px 보강을 제거한다. 조판 높이·글꼴·기준 PDF는 바꾸지 않는다.

소비 경로는 `parse_line_shape_attr → ShapeBorderLine → drawing_to_shape_style / drawing_to_line_style
→ StrokeDash 한컴 종류 → 각 backend의 실제 stroke`이며 직렬화는 HWP5 코드의 역매핑을 쓴다.
noteLine·colLine·글자 외곽선은 이번 독립 Print 진단과 다른 속성이므로 매핑을 추정해 바꾸지 않는다.

## 검증 계약

진단 페이지 전체는 저장 LineSeg를 제거한 합성 입력의 재조판 위치 차이가 있어 현재 13.34657%다.
선 종류의 벡터 측정 근거로 사용하며, 이 결과를 원본의 시각 통과나 신규 fixture 승인으로 바꾸지 않는다.
원본 sample16 5쪽의 점선 외곽과 글리프를 직접 확대 판독하고 전체 64쪽을 다시 비교한다.
Stage 156의 완전한 앞 개체 소유 보정도 같은 빌드의 35~38쪽에서 확인한다.
대조군 4문서 9쪽, 전체 55문서 853쪽, fresh WASM, 전체 회귀·lint는 최종 코드로 별도 확인한다.
새 관계형 렌더링 회귀는 관련 Native/fresh WASM 전체 페이지 90% 이상 확인 전 추가하지 않는다.

수정 전후 측정·로그·TSV는 ignored output에 보존한다. Native 및 fresh WASM 검증 전이므로
이 단계의 구현을 완료·PR 제출 가능으로 판정하지 않는다.

## 첫 실행과 테스트 생성기 보정

Native 빌드는 338.490초, exit 0였다. 쪽 배정에서 37쪽은 제목 610, 표 611,
뒤 문단 612·613을 함께 소유했다. Studio `npx tsc --noEmit`과 기존 CanvasKit
테스트 35건은 통과했다. 최종 head 전체 Sweep의 대용으로 사용하지 않는다.

기존 실패 48건과 선 종류 단위 계약 1건의 실행은 컴파일 단계에서 E0063으로
중단됐다. 이전 단계에서 추가한 `exact_reflow_text_box`가 `#[cfg(test)]`의
줄 전진 경계용 생성기에서 누락되어 false로 초기화한다. HWP5 code 2를 HWPX
DASH로 요구하던 직렬화 단위 검사는 독립 Print·기존 borderFill의 계약에 따라 DOT로
교정한다. 실제 배치의 좌표·baseline을 변경하는 검사가 아니다.

이 두 테스트 내부 보정은 이미 캡처한 Native 빌드 이후다. 실행 중인 Native 64쪽과
대조군은 그 빌드의 진단 결과로 기록하며, 테스트 보정 이후의 최종 코드 검증과
fresh WASM을 완료한 것으로 보고하지 않는다. 컴파일 오류 수정 후 같은 필터를 재실행한다.

반복 주기는 아직 완전히 같지 않으므로 미세 판독 완료로 처리하지 않는다.

`stage157-priority-review/page005-dotted-frame-detail.png`, `stage157-priority-review/metrics.json`이다.
