## 자동 수집과 검사 확인

- `tests/fixtures/deferred_visual_regression_inputs.tsv`에 원본 경로·이관한 검사 축·하위 이슈를 기록했다. body/off-canvas/text-overlap/overflow-cell의 입력 수집은 이 원장을 읽는다. oracle/render-page의 지정 행은 실제 제거했다. IR·parser·serializer 원장은 적용 대상이 아니다.
- 쪽수 원장 재생성기도 이관된 oracle 축과 이전 시험지 제거 목록을 읽는다. 실제 수집 호출에서 제거 입력 61개가 다시 포함되지 않으며, KTX 노선도·AIFT HWPX·별도 거대 셀 HWP·pic-in-table의 정상 oracle 대조군은 남는 것을 확인했다. 활성 입력은 1,166개다.
- AST 확인: 제거한 test 함수 28개가 활성 원문에서 모두 사라졌고, 혼합 파일의 나머지 test 함수 339개는 남아 있다. 신규 test 함수는 추가하지 않았다.
- 원장에 기록한 12개 원본은 제거 전 head와 바이트가 같다. 동일 파일의 HWP/HWPX를 이름만으로 함께 제외하지 않았다.
- 두 경로 helper는 입력과 저장소 루트의 구분자를 같이 정규화한다. Linux·Windows 형태의 저장소 루트에서 상대/절대 입력과 검사 축을 직접 확인해 각각 통과했다. Windows 절대 경로의 역슬래시 때문에 제거 대상이 다시 선택되는 문제를 방지한다.
- `output/pr-review/issue7642/failed-inputs-20261008/stage15-current-validation/stage136-removal-audit.json`에 함수·원본 해시와 제거 수를 기록했다. 실행 로그·중간 JSON은 Git에 포함하지 않는다.

## 검증 상태

파생 suite 준비 뒤 fmt를 다시 실행한다. 최초 fmt는 제거 전 generated module의 사라진 경로를 읽어 실패했으며, suite 재생성 후 결과로 판정한다. Native/WASM/workspace all-target Clippy, workspace build, 고정 base 대비 manifest/unit 정책과 남은 혼합 검사를 동일 `target/pr-review`에서 순차 실행 중이다. 실제 종료 결과를 확인한 뒤 이 절을 갱신한다.

Native Clippy는 exit0(155.2초), WASM Clippy는 exit0(119.4초)다. 이후 workspace 빌드는 종료 코드 없이 controller와 Cargo 프로세스가 실제 사라진 상태로 확인됐다. 이를 빌드 통과로 세지 않고 `interrupted_process_absent`로 기록하여 동일 공유 target에서 미완료 단계부터 재개했다. 두 path helper 보완 후의 fmt도 다시 확인한다. 도구 관측 시간 만료를 작업 종료 근거로 쓰지 않았다.

재개한 workspace build와 첫 전체 target Clippy도 exit0이다. 이어진 manifest 정책에서 fmt 이후의 소스 byte weight와 이전 파생 suite 배정이 달라 `generated harness drift`가 검출됐다. fmt를 유지하고 suite를 재준비했다(1,446 sources·6,195 static attrs·28 suites·20 exceptions). 파생 파일은 커밋하지 않으며, 최종 배정에 대한 전체 target Clippy와 정책·집중 검사를 다시 실행한다.

최종 필수 게이트는 fmt, Native/WASM/workspace all-target Clippy, workspace build,
manifest/unit 정책의 7단계가 모두 exit0인 것을 확인했다. 정책 base는
`790a6f8f388445e7bff2bcb165aa7b384f9ece80`으로 고정했다. 남은 혼합 검사는
nextest는 컴파일 30분 11초 후 실행 36.485초로 종료했다. **22개 중 21 PASS / 1 FAIL**이며,
실패는 이관 대상이 아닌 `svg_snapshot::table_text_page_0`의 가운데 정렬 검사다.
해당 검사는 유지하며 출력·독립 Print 대조를 통한 별도 보정 대상으로 남긴다.
전체 회귀 PASS로 기록하지 않는다. controller의 종료 코드는 100이다.

현재 변경은 검사 이관이며 조판 구현을 변경하지 않는다. 진행 중이던 이전 head의 검증과 새 검사 head의 검증은 구분한다. 제거 전 head에서 빌드한 Native KTX 대조는 전27쪽을 끝까지 완료했고 **최저 93.45384%**, 2쪽 **99.72705%**, 26쪽 **94.68177%**다. 기준·쪽수는 원본/Print 각각27쪽으로 일치한다. 이 결과는 `592a7a889`의 Native 결과이며 fresh WASM 또는 전체 필수 회귀의 완료 증거가 아니다.
