## PDF span 크기와 실제 세로 Tf 구분

양자 기술 보도자료의 독립 Print 8쪽 제목 `9대 중점기술`에 대해 PyMuPDF가
보고한 span size는 CSS 96dpi 약20.47058다. 이를 실제 세로 글자 크기라고
보고 예전 √장평 축소를 복원하면 안 된다. PDF 원문의 실제 상태를 확인했다.

```text
0.120 0 0 -0.120 0 841 cm
/F19 133.000 Tf
92.537315 Tz
1 0 0 -1 ... 1071 Tm
```

실제 세로 크기는 133×0.120×96/72 = **21.28px**다. Tz는 가로에만 적용된다.
보고된 span size의 행렬 합성값과 세로 크기를 구별한다. 현재 SVG의 세로
21.33333px는 이 독립 값과 가깝고, base의20.57312px를 단순히 복원할 근거가
아니다. 이 사실만으로 페이지 하락이 해소되거나 모든 글자 paint가 정확하다고
판정하지 않는다. 실제 face·원점·굵기·장평과 나머지 그리기 차이를 계속 대조한다.

stage2312는 보고 크기의 한계를 명시했고, stage2313에는 해당 PDF 페이지의
원문 text state를 ignored output에 보존했다. 위 값은 현재 렌더러의 계산값이
아니라 독립 PDF 연산자에서 확인했다. 점수를 올리려고 잘못된 세로 축소를
복원하거나 원인이 확인되지 않은 golden을 갱신하지 않는다.
