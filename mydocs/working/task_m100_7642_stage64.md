## 생산과 소비 경로

저장 글줄의 권위·좌표축 범위 → HeightCursor의 page/lazy 기준 유효성 →
이미 수용한 물리 흐름 원점에서 새 저장 축 연결 → typeset의 fit/누적과
layout의 실제 문단 원점. 두 경로에서 같은 커서 결과를 사용한다.
정상 축 안의 되감김, 미주의 허용된 되감김, 편집·합성 줄·개체 경로는
현재 가정의 반례로 구분한다. 그 경계가 구현 결과의 검증 대상이다.
