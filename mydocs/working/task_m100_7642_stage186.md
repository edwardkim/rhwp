## 근거와 범위

## 함께 분석할 소비 경로

1. 적분은 `IntegralNolimits → finish_command_atom`으로 가며 `parse_big_op`의 명령형 marker 인자 소비를 우회한다. 같은 템플릿 소속 계약을 적용하고 일반 적분의 오른쪽 첨자·그룹 바깥 첨자를 보존한다.
2. 왼쪽 첨자는 `layout_left_scripts → script_*_geometry → 실제 body/첨자 baseline → Row 자식 → SVG/Canvas/paint`를 공유한다. 복합 본체에 단순 `base.baseline * 0.4`를 적용해 아래첨자가 올라가는 가정을 제거하고, 원본 글꼴의 논리 프레임/기준선 거리와 점유 깊이를 대조한다. 근호·분수·큰 연산자·중첩 첨자·네 슬롯을 반례로 확인한다.
3. 같은 명령/크기라도 중첩에서 0.68배 크기의 독립 폰트 프레임이 없으면 일반 MATH fallback으로 돌아가는 경로를 확인한다. 지원하지 않은 크기를 픽셀 수치로 보간해 맞추지 않는다. 독립 재생성 자료에서 필요한 축과 논리 프레임을 확인한다.
4. 현재 변경으로 생긴 카탈로그 13·18쪽의 정렬 회귀와 기존 Print/새 Print 충돌은 같은 원본의 저장 정보·측정·paint를 대조해 원인을 확인한다. 부적합한 타입/문서/수치 분기를 추가하지 않으며 기대값 완화·파일 제거·이관으로 숨기지 않는다.

## 적용한 보정과 독립 근거

- `upstream/devel`을 다시 fetch하고 `git rebase --autostash upstream/devel`을 실행했다. base `552f5228d2dbfd6046c838f14241704f1bcb8a05`가 유지되어 이미 최신이며 기존 커밋과 작업 변경을 보존했다.
- 적분의 문서 parser가 `parse_operator_scripts`를 합계 기호와 공유한다. bare `INT LSUB/LSUP i`는 템플릿 인자로 소비하며, `INT SUB i`와 그룹 바깥 `{INT} LSUB i`의 소속을 구분한다. 공개 legacy parser는 기존 경로를 유지한다.
- 새 30쪽 대조군에서 612/1020/1496HU의 일반/왼쪽 위첨자 프레임이 일치했다. 이 축의 위/아래 첨자 프레임을 공급하며 미측정 크기를 보간하지 않는다. 원본·정상 HWP·Print PDF·job·논리 프레임은 [독립 대조군](../../pdf/issue7642-script-frame-diagnostic/README.md)에 보존했다.
- 일반 글줄과 그 줄을 감싼 근호의 아래첨자는 본체 기준선에 독립 아래첨자의 하강 거리를 연결한다. 근호 상단 밴드도 예약 프레임의 높이·기준선에 포함한다. 복합 본체에 `base.baseline * 0.4`를 적용해 아래첨자가 올라가던 경로를 이 범위에서 제거했다. 분수는 기존 독립 분수 프레임을 먼저 소비하며 다른 복합 본체·복합 첨자는 미검증이다.
- 공용 target의 첫 사전 컴파일에서 분리 모듈 helper의 접근 제한 오류를 확인했다. 접근 범위를 바로잡았다. 종료를 확인하기 전에 예약한 재실행은 실제 빌드 없이 lock 대기 중 중단했으며 최종 검사는 이전 Cargo 종료 뒤 별도로 시작했다. 실패 로그를 보존한다.

## 언어 문서의 base/head 회귀 판정

같은 입력·독립 Print PDF·명령·DPI·글꼴 공급으로 고정 base `552f5228d2dbfd6046c838f14241704f1bcb8a05`를 별도 worktree에서 비교했다. 공용 target을 순차 사용했으며 base 바이너리 SHA `046c84c20840c0595c6faaac1e29fad0fd4fc660e724f9787da573922499d427`를 별도 보존했다. base는 15쪽 중 1쪽만 미달(60.85712%)이며 3쪽 99.36976%다. 현재 source는 1쪽 96.95558%로 개선했지만 다른 8쪽에 회귀가 생겼고 3쪽 72.27333%다. base의 미달을 근거로 현재 8쪽의 회귀 검사·입력을 제거하거나 이관하지 않는다.
