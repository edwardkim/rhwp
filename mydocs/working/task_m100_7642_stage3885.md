# #7642 저장 버전에 맞는 독립 Print와 #5961 축 검사의 기대값

Issue: #7642

## 원 이슈·PR과 앞 단계의 한계

원 PR #5970과 후속 #7220의 읽는 쪽 투영·파일 값 불변·문단 전체 슬롯 경계 판정을
다시 확인했다. #5970의 캐럿 관측은 한컴 2024에서 수집한 값이다. 원본 저장 제품이
2020인 문서의 정식 2020 Print 결과와 동일하다고 단정하지 않는다. `stage3740`은
이미 이 구분을 기록했지만, 그때 정식 2020 기준의 재출력·판독을 완료하지 못했다.
이 단계에서는 해당 출력을 실제로 확보했다.

## 독립 Print의 실제 실행

공식 client의 `start → status → download`, 명시적 `engine: 2020`, `target: pdf`를
사용했다. 두 원본 모두 재저장·내용 변경 없이 인쇄했다. 실제 한컴은 `11.0.0.9136`,
`pdf_print_method: 0`, `hancom2020_pdf_driver_one_up`다. 인증·비공개 원본 자료는
공개 문서나 PR asset에 포함하지 않는다. 실행 원문은 ignored `stage3881-original-axis-print/`다.

| 입력 | 원본 SHA-256 | Print PDF SHA-256 | 전체 쪽수 |
| --- | --- | --- | ---: |
| 공개 `samples/hwpx/aift.hwpx` | `5e27ee51825d10f0f51bd04935f0f9f8fc24f930a010367d822638964fefd491` | `cccf1955714f60faf17eefee2f75dad184cbb6861b2c2cdba4c8c44308ab8794` | 74 |
| 원 PR의 비공개 캐럿 대조 원본 | `d387bea66341c343c60bfed7bd2fa009b3c4d8173a36022a8977be55b6918c82` | `6fd9c0d0535cc290e7dee197fc4f78a2267b2de1b9b632da76199a819859a4f5` | 1 |

비공개 대조 원본의 첫 본문 문단은 저장 `textpos: 0/78`, 본문 시작 위치 32다.
2020 Print의 둘째 줄은 원본 본문 인덱스 46에서 시작하며, 원 PR의 2024 관측에 따른
54와 다르다. 이 결과는 원본 저장값을 8 올리지 않는 현재 경로와 일치한다.

`stage3884-caret-axis-head-{native,wasm}/`에서 생산자
`f2157e2772c1594427bc7051a300e61a66a6f9a7`와 위 독립 2020 PDF를 같은 96dpi 조건으로
비교했다. Native/fresh WASM 각각 전체 1쪽·raw 100.00000%이며 쪽수도 일치한다.
원본·PDF·글꼴 조건·metrics source는 각 receipt에 해시로 보존했다.
첫 본문 두 줄의 Native/fresh WASM review와 standalone overlay를
`stage3886-caret-axis-panels/`에서 직접 열어 줄 끝·다음 줄 시작·앞뒤 간격을 대조했다.
해당 확대 raw는 Native 99.94682%, WASM 100%다. 이 판독은 첫 본문 두 줄에 대한 것이며
비공개 문서 전체의 모든 세부 요소를 검토 완료했다고 주장하지 않는다.

## 검사 변경의 범위

일반 한컴 원본의 명시적 구역 정의는 합성 슬롯을 생략했다는 증거가 아니다.
`aift`의 raw 24는 컨트롤 슬롯이며 본문은 32부터 시작한다. raw 24와 8 올린 32가
같은 첫 표시 글자로 투영된다는 사실만으로 보정폭 8을 강제할 수 없다. 별도 원본의
2020 Print와 정확히 일치하는 경로를 과거의 버전 혼합 기대값에 맞춰 되돌리지 않는다.

두 실패 검사는 새 이름으로, 명시적 생산자 축 마커가 없는 원본의 구역 슬롯 축을 보존하고
저장 줄 시작이 같은 첫 표시 글자를 소유하는지 검사하도록 바꾼다. 원본 `text_start` 불변,
문단 시작 0, 명시적으로 기록한 투영폭, 문단 끝·제어 슬롯 경계 및 왕복 고정점 계약은
그대로 유지한다. 숫자 오프셋을 모두 금지하는 규칙이 아니라, 독립 근거 없이 특정 축을
강제하던 가정을 제거하는 변경이다.

이는 `aift` 74쪽의 시각 개선 완료를 주장하지 않는다. 독립 Print 전체는 확보했으며 원래
범위의 검증은 계속 유지한다. 캐럿 대조 원본의 1쪽 통과를 다른 원본의 전쪽 검증으로
대신하지 않는다. 새 테스트·전체 회귀·최종 PR 게이트는 변경 후 실제 실행으로 확인한다.

## 검사 실행 결과

변경 후 source `87c50d2bef`에서 `stage3889-native-marker-and-axis-focused-rust/nextest.log`를
실행했다. #5961 8개를 포함한 집중 검사 12개가 모두 통과했고 종료 코드는 0이다.
기존 파일 값·문단 끝·기록한 투영폭 계약도 함께 통과했다. 원래 전체 Rust 회귀의 최종 통과로
보고하지 않으며 후속 제품 소스 변경의 결과는 새 source에서 다시 판정한다.
