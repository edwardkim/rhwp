## 발견 사항

### A. 즉시 수정 (이번 e2e에서 fix)

#### A-1. `pdf_to_pngs.sh` octal 해석 버그 (severity: high)

**현상**: `pdftoppm`이 31페이지 PDF에서 `page-08.png`, `page-09.png` 등 leading-zero 파일명을 출력. 빌더 측 sed 추출 후 `printf -v new "page_%03d.png" "$n"` 호출 시 `08` / `09`가 8진수로 해석되어 `printf: 08: invalid number` 발생, 8페이지 이후 변환 실패.

**수정**: `printf -v new "page_%03d.png" "$((10#$n))"` (10진수 강제).

**검증**: 재변환 후 31페이지 모두 정상 (`page_001.png` ~ `page_031.png`).

#### A-2. 빌더 자동 prefix 중복 (severity: medium)

**현상**: `build_exam_paper`가 첫 stem_block에 무조건 `{number}. ` prefix를 추가. 사용자(Skill)가 stem 첫 블록에 이미 `2. ㉠에 해당하는...`라고 작성했을 때 `2. 2. ㉠에 해당하는...` 중복 출력. 또한 `[1~3] 다음 글을 읽고...` 같은 그룹 지시문 앞에 무관한 `1. `이 붙음.

**수정**: `apply_number_prefix()` 헬퍼 추가. 첫 stem 텍스트가 이미 `{n}. ` 또는 `[`로 시작하면 prefix skip.

**회귀 테스트 추가**:
- `test_build_stem_with_explicit_number_prefix_no_duplication`
- `test_build_stem_with_group_directive_no_prefix`

**검증**: 동일 ingest.json 재빌드 시 `[1~3] 다음 글을...`(prefix 없음), `1. 윗글의...`(이미 명시), `2. ㉠에...`(중복 제거) 모두 정상.

### C. 스키마 진화 권고 (신규 발견)

#### C-1. 공유 지문 (group passage) 표현 부재

수능/모의고사는 `[1~3] 다음 글을 읽고 물음에 답하시오.` 형식으로 **여러 문제가 한 지문을 공유**한다. 본 e2e는 *문제 1번에 본문 전체 + 문제 2~3번에는 짧은 stem만* 형태로 우회했지만, 본문이 문제 1번에 종속되어 있어 의미적으로 어색하다.

**권고**: 후속 이슈에서 schema에 `passage_groups` 또는 `shared_passage_ref` 필드 추가:

```jsonc
{
  "passages": [
    {"id": "p1-3", "blocks": [...]}
  ],
  "questions": [
    {"number": 1, "passage_ref": "p1-3", "stem": "...", ...},
    {"number": 2, "passage_ref": "p1-3", "stem": "...", ...},
    {"number": 3, "passage_ref": "p1-3", "stem": "...", ...}
  ]
}
```

#### C-2. <보기> 박스 (page 2 문제 3번에서 발견)

문제 3번은 본문 외에 `<보기>` 라는 별도 박스 (테두리 + 배경) 안에 보조 자료를 둔다. 현재 stem_blocks의 `text` / `image` 두 종류로는 표현 불가.

**권고**: schema에 `boxed` 블록 타입 추가, 또는 boilerplate 텍스트로 우회 (기본). 본격 처리는 Table/Frame IR 빌드와 함께 후속 마일스톤.

#### C-3. 페이지 footer (1/20, 홀수형 등)

시험지는 페이지 하단·상단에 `1/20`, `홀수형`, `국어 영역` 등을 반복 표시한다. 이는 `page_size` 외에 `header_text` / `footer_text` / `form_label` 필드로 정형화 가능.

**권고**: 후속 이슈로 추적, 본 단계는 무시 (시험지 본문 e2e의 핵심 가치 영역 아님).
