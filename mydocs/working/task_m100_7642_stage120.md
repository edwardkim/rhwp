- `issue_6806_objectprops_getset_identity.rs`의 함수 내부 `SAMPLE`을 파일 공통 상수로
  해석하면 다른 문서의 검사까지 선택된다. 시험지의 크기 0 보정 함수 1개만 제거하고
  다른 입력의 get/set·Undo 3개는 보존한다.
- `integration_tests.rs`의 혼합 문서 소유 정보 사전 검사는 목록의 시험지 전용
  25개 함수에 포함하지 않는다. 나머지 문서·합성 계약 검사도 보존한다.
- `ruler-resize.test.mjs`는 시험지를 여는 실행 진입점만 제거한다. 재사용하는
  DOM·스크린샷 검사와 resize driver 함수는 유지한다.
- 새 `issue_7642_shape_resize_relations.rs`, `issue_7642_oct_endnote_relations.rs`,
  `issue_7642_forced_break_relations.rs`의 20개 새 이름 검사는 보존한다.

  기존 검사 삭제를 해당 문서의 90% 이상 검증 완료로 세지 않는다.
