# #6665 도형 전용 줄 뒤 저장 줄간격 보정

## 범위와 원인

`fix/6699-6662-residual-image-layout-20260906`에서 #6699 보정을 유지하며 진행한다.
`layout_column_item`의 TAC 도형 높이 보정은 `lh`로 문단 하단을 확보하지만, 도형 전용
줄의 `ls`를 반환 커서에서 누락했다. 첫 보정은 HWP3 계보를 일괄 제외해 대상 문서에서도
발동하지 않았다. 한컴 2024 저장본이라도 내부 프로필이 HWP3 계보일 수 있으므로, 저장
줄 정보가 꼬리 줄간격의 소유권을 증명하는 문단으로 보정 범위를 좁힌다.

바닥값이 기존 문단 커서보다 큰지 판정하는 식은 바꾸지 않는다. 판정에 줄간격까지 더하면
기존에 발동하지 않던 위치에서도 보정이 발동할 수 있으므로, 발동 후 커서에만 적용한다.

적용 조건은 빈 TAC 도형 문단, 단일 저장 줄, 양수 `lh`와 `ls`, `도형 높이 < lh`,
`다음 문단 vpos - 현재 vpos == lh + ls`이다. 원본 HWP3와 원본 HWPX 저장 레이아웃은
제외한다. 다음 문단이 없거나 저장 위치가 새 단·쪽에서 초기화되어 이 관계를 증명하지
못하면 기존 전진량을 유지한다. 파일명, 쪽 번호, 특정 좌표 또는 고정 보정량은 사용하지 않는다.

## 2026-09-06 실패 추적과 재보정

- 직전 focused 실행은 28개 중 26개 통과, #6665 신규 2개 실패였다. 첫 대조 위치는
  실제 652.533px, 한컴 기준 659.249px로 수정 전과 같았다.
- 현재 라이브러리로 원본을 읽은 임시 계측에서 `hwp5_stored_pagination_layout=false`,
  `legacy_hwp3_stored_geometry=true`를 확인했다. 대상 도형 문단의 빈 문단 조건은 참이었다.
  따라서 보정을 막은 원인은 빈 문단 판정이 아니라 제가 추가한 계보 배제 조건이다.
- 예를 들어 원본 문단 203은 `vpos=0`, `lh=2551`, `ls=452`, 다음 `vpos=3003`이며,
  문단 273은 `vpos=61696`, `lh=4454`, `ls=452`, 다음 `vpos=66602`이다.
  두 경우 모두 저장 위치 차이가 `lh + ls`이고, 누락된 452 HWPUNIT는 96dpi에서 약 6.027px다.
- 계보 배제 대신 위 저장 관계를 확인하도록 제품 코드를 보정했다. 기존 테스트의 기대 좌표와
  1px 미만 허용치는 변경하지 않았다. 후속 focused 실행에서 #6665는 통과했지만 #1116 회귀가
  발생했으므로 현재 보정은 수용 불가다. 아래 실행 결과를 최종 판정으로 사용한다.
- 추가 비교용 임시 탐침은 `LineSeg` 필드명 오류로 컴파일되지 않아 사용하지 않았다.
  위 원인과 수치는 별도로 정상 실행된 원본 계측 결과에 근거한다.

## 후속 재보정: 순수 개체 프레임과 확장된 저장 줄 상자 구분

위 26/28 결과는 `도형 높이 <= lh`였던 이전 후보의 실패 기록이다. 사용자 지시로 재추적했고,
이번 수정에서는 등호를 제외한다. 아래는 보정 근거이며, 수정 후 실행 결과를 미리 선언하지 않는다.

- #1116의 HWP5 및 2022 재저장본은 문단 71에서 `도형 높이 = lh = 9764HU`,
  `ls = 780HU`다. 기존 `paragraph_layout` 주석과 한컴 좌표 계약은 이 순수 개체 줄에서
  높이 접힘과 꼬리 간격 없는 바닥값이 짝을 이룬다고 명시한다. 바닥값에 ls를 다시 더하면
  10.4px 내려가며, 이번 실패량과 일치한다.
- #6665는 문단 203에서 `도형 높이 = 1984HU < lh = 2551HU`, 문단 273에서
  `도형 높이 = 1249HU < lh = 4454HU`다. 프레임보다 큰 저장 줄 상자를 복원하면서
  다음 문단의 저장 위치가 `lh + ls` 전진을 증명하는 경우만 꼬리 간격을 추가한다.
- 형식 계보에 예외 파일명이나 쪽 번호를 추가하지 않는다. 기존 #1116/#6665 테스트와
  허용치는 변경하지 않고 동일한 28개 focused 계약을 다시 실행한다.
- 현재 CLI는 이 재보정 전 산출물이므로 테스트 통과 후 최신 CLI를 빌드해 시각 대조한다.
  기존 PDF와 수정 전 트리를 재사용하며 새 한컴 변환은 요청하지 않는다.
