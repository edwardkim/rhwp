## 이번 보정의 독립 근거와 소비 경로

### 짧아진 본문 뒤의 자동 쪽 경계

`body-single-symbol.hwpx`는 독립 한컴 2020 Print 1쪽인데 기존 출력은 2쪽이었다.
재조판 문단은 3줄이고, 뒤 빈 문단의 원본 vpos는 67200/68800HU다. 로드 정규화는
이를 6400/8000HU로 재기준한다. 다시 쓴 좌표가 실제 흐름 끝과 같다는 이유로
예전 자동 쪽 경계를 유효하다고 판단하는 순환을 제거한다.

`Paragraph.source_line_seg_vertical_pos`의 원본 스냅샷 →
`stored_tail_end_and_advance_hu` → `stored_rewind_boundary_matches_current_flow` →
공통 `stored_page_boundary_invalidated_by_reflow` → 구역 진입·whole fit·split entry의
실제 경계 선택으로 연결한다. 편집으로 무효가 된 저장 텍스트 분할은 근거에서 제외한다.
원본 저장 좌표가 없으면 기존 줄 좌표를 사용한다. 명시적 pageBreak는 기존 entry가 처리한다.
대조군은 `body-original`, `body-reflow`, `body-explicit`와 저장 셀 프레임이다.

### 빈 그림 호스트의 진행량과 콘텐츠 하단

원본 `hwp3-sample.hwp` 9쪽은 그림 하단 약 973.1, 캡션 하단 약 997.7이며 독립
Print의 잉크 위치와 정합한다. 후행 빈 호스트 줄을 포함한 흐름 끝 1030.5를 콘텐츠
하단으로 읽어 본문 하단 1009.1보다 21.3px 넘쳤다는 경고가 발생했다.
이 좌표는 진단 관측값이며 회귀 테스트의 절대 기대값으로 사용하지 않는다.

`hwp3_caption_host::line_advance_hwp` → 그림·캡션 배치 결과와 후행 호스트 줄의
진행량 분리 → `last_item_content_bottom` → 기존 항목별 overflow 판정으로 연결한다.
다음 흐름의 `result_y`와 조판 예약은 그대로 전진하며, 그림·캡션을 이동하거나 경고를
숨기는 분기를 추가하지 않는다. caption 없는 그림, 비흐름 그림과 변환 HWP5/HWPX에는
기존 helper의 비적용 조건이 유지된다.
