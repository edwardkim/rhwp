# #7642 남은 합성 EMF 좌표 검사 보정

## 독립 근거와 기존 실패

MS-EMF의 [Header Object](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-emf/e4a35c41-e8e3-43f9-bc07-a18e99bb866d)는
Bounds를 장치 픽셀, Frame을 0.01mm, Device와 Millimeters를 참조 장치의 크기로 정의한다.
기존 합성 입력은 10mm Frame에 참조 장치 1920px/527mm를 기록하면서 100px viewport와
같은 크기라고 가정했다. 두 크기는 일치하지 않는다. 검사 helper도 `<rect>`의 x/y 속성을
검색해 장치 펜의 `<path>` 출력에서 먼저 실패했다.

이는 실문서 출력의 회귀를 허용하거나 golden을 갱신할 근거가 아니다. 이번 변경은
합성 좌표 계약만 바로잡으며 조판·그리기 구현과 기존 0.5 허용 오차는 바꾸지 않는다.

## 변경한 검사

새 이름은 `anisotropic_geometry_respects_physical_frame_and_target`다.
참조 장치를 10mm당 viewport 픽셀로 명시하고, 서로 다른 window/viewport 배율과
목표 크기를 검사한다. 물리 Frame이 두 배인 대조군은 도형이 목표 영역의 절반을
차지해야 하므로 잉크 Bounds를 원본 viewport로 잘못 쓰는 경로도 검출한다.

SVG는 usvg로 해석해 경로의 최종 기하 경계를 확인한다. 태그나 행렬 문자열의
출력 형태를 기대값으로 쓰지 않고, 도형의 누락·중복도 함께 검사한다.
실물 문서의 절대 화면 좌표를 고정하는 검사는 아니다.
