## 실행 결과와 새 검토 대상

fresh WASM wrapper는 1,043.93초, exit 0으로 종료했다. 고정 package와 Studio public의
JS·WASM SHA-256이 각각 일치한다. 같은 Rust 소스의 workspace build와
workspace/all-targets Clippy도 exit 0이다. 전체 nextest는 컴파일·실행 중이며 최종
summary가 나오기 전에는 통과로 기록하지 않는다. 시작 당시 controller의 바이트를
별도로 보존했다. 최종 검사 변경 후 실행에는 `--locked`를 사용하고 Skia 3종까지
순차로 확인한다. 현재 source의 Studio Node 검사는 1,825 PASS, 2 SKIP, 0 FAIL이며
전체 명령 exit 0이다.

장식·첨자 반례 16개, 각각 19쪽의 Native SVG/fresh WASM TSV는 모두 90% 이상이며
각 경로의 최저는 92.57667%다. TSV 해시도 재확인했다. 이는 전체 원본 55개의 완료
증거가 아니다. 같은 19쪽의 Native/fresh WASM RGB 픽셀도 모두 동일했다. 이는 SVG
소비 경로의 동등성이며 Studio Canvas의 동등성으로 확대하지 않는다. 실행 중 글꼴
전송 대상이 없는 outline-only SVG를 임시 helper가
거부한 오류는 별도 helper에서 원본 SVG를 그대로 처리하도록 보정했다. 원본과
전송본의 해시·바이트 수가 동일하며 글꼴 없는 text는 이 예외를 허용하지 않는다.
Chrome 시작 오류로 exit 1인 검사도 기록을 보존하고 실제 실행한 Chrome 경로를
고정해 미완료 항목부터 재개했다. 완료 TSV를 새 실패로 덮어쓰지 않았다.
