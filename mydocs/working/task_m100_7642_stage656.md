## run 분리 실패

- 네모 숫자: 같은 원본 줄이 합성 숫자 `200`, `□`, `-`, `□□□`로 분리된다. 기존 `□-□□□` 단일 run 선택은 출력 내용 존재를 검사하지 못한다. 프레임을 고정 `19.20px` 문자열로 찾는 검사도 기존 근사값을 고정한다.
- 끝 탭: 원본 줄은 공백, 하이픈, ` \t`, 뒤 본문으로 분리된다. 세 실패 검사의 `  - \t` 단일 run 선택을 같은 TextLine의 내용과 원본 section/paragraph/char 주소로 바꾸는 후보를 ignored output에 준비했다. 캐럿·문자 경계·다음 본문의 같은 확정 끝점 계약은 유지한다.
- 후보는 정식 검사에 아직 적용하지 않았다. 원본 기호 차이를 보정하고 Native/fresh WASM 및 직접 판독을 완료한 뒤 적용·실행한다.
