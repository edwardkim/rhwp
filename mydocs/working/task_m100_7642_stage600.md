# Issue #7642 단계 600: 무브레이스 첨자 뒤 새 그룹의 본체 소유

- stage585의 명시적 공간·첨자 18식 대조군 Native 전체 1쪽은 89.22042%다. 미달이므로 새 회귀·baseline으로 추가하지 않았다. stage599 review를 직접 표시해 원인을 확인했다.
- 독립 한컴 2024 Print의 900HU/1800HU에서 `` `_3{rmC}_1= ``는 왼쪽 3이 0.68배 첨자 크기이고 C는 본래 글자 크기다. 뒤 `1=`은 함께 아래첨자 크기다. `3^2=81`의 `2=81`도 함께 위첨자 크기다. 관계 기호를 임의의 인자 종료점으로 바꾸지 않는다.
- 기존 `parse_script_span`은 첫 첨자 숫자 뒤 새 `{rmC}` 그룹까지 첨자 인자로 소비했다. 공간 기저의 전체 내용 누락을 보정한 뒤에도 C/P 본체를 0.68배로 축소하는 두 번째 소유 결함이 남아 있었다. 명시적 빈 그룹 기저도 같은 새 그룹 경계에 영향을 받는다.
- 문서 경로에서 이미 인자를 읽은 뒤의 LBrace는 다음 본체의 시작으로 남긴다. 처음부터 braced인 첨자는 기존 `parse_group`이 끝까지 소유하며, 공개 LaTeX 해석과 붙은 숫자·연산·관계 기호 범위는 유지한다. 특정 수식·문서·글자 크기나 좌표로 분기하지 않는다.
- 기대 결과는 committed `pdf/issue7642-leading-space-script-diagnostic/`의 독립 정상 저장/Print와 stage579 입력 manifest에서 확인했다. parser → intrinsic/flow 측정과 표시 layout → 공통 renderer에 같은 AST를 공급한다. 새 Native/fresh WASM과 원본 시험지·대조군은 아직 미검증이다.
- stage595는 별도의 최종 잉크 helper 좌표 보정 검증이며 현재 실행 중이다. 미달 원인이 남은 source의 예정 WASM 빌드는 시작 전에 중단했고, 새 parser의 Native 진단 후 같은 source로 fresh WASM을 준비한다. 실행 중인 Cargo는 중단하지 않았다.
