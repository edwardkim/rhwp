# Issue #7642 단계 571: 빈 후속 슬롯의 저장 사다리 질의 복원

- stage557의 fresh WASM은 source `4533d1c95f`에서 exit 0으로 종료했다. source 해시 유지와 Studio JS/WASM 동기화가 모두 확인됐으며 패키지 원본을 output에 보존했다. 해당 빌드 이후 이번 source 보정을 적용했다. 이전 패키지를 새 source의 빌드로 표시하지 않는다.
- 현재 바뀐 부분은 `layout.rs`의 textless float host 조기 반환이다. 다음 문단에 가시 글자가 있다는 조건을 제거하고 Square 호스트를 기존 `textless_host_ladder_line_advance`에 질의한다. 빈 저장 줄의 점유는 글자의 가시성과 다르다. 공통 질의의 저장 줄 규모·문단 간격·합성 태그·되감김·과도한 델타 거절을 유지한다.
- 원본의 host vpos 0과 후속 빈 줄 vpos 3200은 host 높이 2000과 간격 1200의 합이다. 측정은 42.7을 예약했지만 stage566 cursor 로그의 실제 FullParagraph는 0을 소비했다. 이제 조기 반환도 같은 원본 사다리가 증언하는 전진을 소비하게 한다. 개체 자체의 float 점유 높이를 더하는 수정이 아니다.
- stage555의 폭 필터 변경은 실제 호출 경로에서 비해당으로 확인해 철회했다. 해당 필터는 단일 단에서 실행되지 않았다. 효과가 없는 새 분기를 유지하거나 추가 좌표 보정으로 덮지 않는다.
- 새 코드의 HWP3 전64쪽 Native/fresh WASM과 영향 반례는 아직 미검증이다. 기존 실패 검사·입력·PDF를 제거하거나 기대값을 수정하지 않았다. 두 backend의 전쪽 90% 이상과 확대 판독 이후 정식 관계 회귀를 추가한다.
- `rhwp-studio/public/rhwp.js`는 완료한 fresh WASM wrapper가 최신 devel의 페이지 셀 조회 API를 반영해 만든 산출물이다. 사용자 요청에 따라 source 보정과 함께 포함한다. 파일 SHA와 패키지 동기화 증거는 stage557 receipt에 연결한다.
