## Native 출력의 추가 결함

`stage3879-issue1950-corrected-panels/native-head/`의 full·제목 확대 review와 standalone
overlay를 직접 열었다. 제목 뒤 U+FFFC 개체 마커가 Native에서 검은 기호로 그려진다.
제목 확대 raw는 88.96296%다. 전쪽 점수로 이 결함을 면제하지 않고 보정을 계속한다.
본문 `2 - 48`은 같은 첫 쪽에 돌아왔고 꼬리말 `- 581-35 -`와 별개로 보존됐다.

모델의 U+FFFC는 8유닛 개체·설정 컨트롤 자리표시자다. 원문에서 제거하면 탭·글자모양·컨트롤
오프셋 계약을 훼손하므로 파서 문자열과 위치를 보존한다. 기존 `text_measurement`는 마커 전진폭을
0으로 계산하며 SVG·WebCanvas는 마커를 글리프로 그리지 않는다. Native `SkiaTextReplay`는
공백만 건너뛰어, 존재하지 않아야 할 마커 글리프를 그린다.

## 수정할 경로와 반례

생산: 원본의 자리표시자와 `TextRunNode` → 공통 측정의 전진폭 0 및 replay positions →
Native `SkiaTextReplay::draw_text`의 cluster/complex span 소비 → 실제 글리프 draw 순서다.
마커 cluster의 글리프만 방출하지 않고 원문 인덱스·앞뒤 글자 위치·개체 배치와 장식은 보존한다.
complex shaping span에도 마커를 포함하지 않아, 결합 문자 앞에 있는 마커가 blob으로 다시
그려지지 않게 한다. 문서명·포맷·특정 글자열에 따른 분기는 만들지 않는다.

일반 텍스트, 마커가 맨 앞·중간·끝에 있는 텍스트, 마커 다음 결합 문자와 독립 개체의 보존을
확인한다. 새 소스에서 Native 직접 출력과 fresh WASM·SVG를 같은 영역으로 대조하고,
#1950 원래 탭 계약과 독립 1쪽 원장 및 표의 본문 안/밖 경계도 재검증한다.
이전 source의 fresh WASM은 완료했으며 집중 회귀가 종료된 뒤 소스 변경을 적용한다.
필수 검증과 원래 전체 범위를 완료하기 전에는 PR을 제출하지 않는다.

## Native 구현 반영

이전 source의 집중 Rust 실행 `stage3882-paper-outside-body-focused-rust/nextest.log`가
종료 코드 0으로 끝났다. #1950 탭의 8유닛·왕복 계약과 쪽수 원장 partition 13의 기존 검사
**2개 모두 통과**했다. 원래 1쪽 기준선은 변경하지 않았다.

그 뒤 Native `text_replay`는 U+FFFC cluster의 글리프를 건너뛰고, `text_shaping`은
해당 마커를 complex span에 넣지 않도록 수정했다. 원문·layout positions·개체의 paint op는
그대로 유지한다. 마커를 문자열에서 삭제하거나 뒤 글자의 인덱스를 당기지 않는다.
Native 코드 두 파일의 변경이며 `cargo fmt --all`·`git diff --check`는 통과했다.
수정 후 빌드·제목 직접 판독·대조군·정식 회귀는 다음 실행에서 완료한다. 이 항목은 아직
Native 출력의 검증 완료 보고가 아니며 해당 보정까지 끝낸 뒤 최종 판정을 갱신한다.
