# #8856 명시 대체 기호의 잉크와 전진 칸

## 선행 구현과 동일 조건 복구

그림 효과 읽기·저장·자르기 보정을 `df4b5916a2`에 커밋한 뒤 이 단계를 시작한다.
일반 기호의 음수 자간 보존과 실제 결측 기호의 반각 정렬을 구분한 기존 보정
`92b52a793d` 및 `issue_8153_symbol_fallback`을 먼저 확인했다. 원본 TTF에 실제 있는
글리프의 자연 프로그램을 임의로 바꾸지 않는 기존 반례는 유지한다.

과거 issue1994 Print 설정은 저장소의
`mydocs/pr/assets/issue1994/print-frame-20261107/reference-font-environment.json`이다.
같은 canonical 웹폰트 준비기를 적용하자 과거 환경 JSON SHA-256
`81705de8fef321b10e64247a4023e7a3c88a97ce2762654f907e180c3e6e43c9`가 재현됐다.
기존 글꼴 공급 기록의 1,210개 파일도 누락·해시 차이 없이 확인했다.
이는 원본 산돌 글꼴을 복원한 것이 아니라, 독립 Print가 사용한 Haansoft Batang에
대응하도록 이미 선택했던 비교 조건을 복구한 것이다. 최소 글꼴 검증과 구분한다.

이 조건에서 이전 고정 Native CLI의 전 4쪽은 99.96356/99.72650/98.69196/99.80186%다.
다른 글꼴 조건의 약 91~92%와 직접 비교하지 않는다. 이전 보호 4쪽 99.94357%와의
0.14171%p 차이는 남아 있으므로 기준을 낮추거나 통과로 처리하지 않는다.

## 독립 원점과 현재 경로

4쪽의 2px 실루엣 미일치 190화소 중 대부분이 왼쪽 열의 리터럴 U+2219에 모인다.
자동 문단 번호나 원 PUA F09F가 아니므로 그 들여쓰기·암묵적 기호 프로그램을 변경하지 않는다.
독립 PDF의 해당 glyph 전진은 512/1024em, 설치 TTF의 U+2219는 1024/1024em이다.
두 잉크 경계는 수평 -256 단위, 수직 -1 단위 차이지만 윤곽점 수는 16/17로 달라
윤곽 전체가 완전히 같다고 주장하지 않는다.

현재 공개 trace는 같은 기호를 embeddedMetric 550HU(11pt의 반각)로 측정하고 장평·자간을
별도로 적용한다. 그러나 명시 대체 프로그램의 잉크 보존 경로는 음수 자간에서 glyph-fit을
생략하므로 전각 표시 프로그램의 여백을 반각 측정 칸으로 옮기지 않는다.
자간을 없애거나 본문 원점을 움직이는 방식 대신 측정 칸과 잉크 원점을 분리해 검증한다.

새 관계 검사는 MIT 합성 CFF를 메모리에 공급한다. 반각 측정 칸의 같은 기호가 음수 자간을
달리해도 잉크 위치를 보존하는지, 실제 원본 TTF의 자연 프로그램은 그대로 유지하는지 확인한다.
처음 실행은 공유 helper 수집 누락으로 컴파일 실패했으며 결함 재현으로 세지 않는다.
helper 소비 경로를 등록하고 다시 prepare한 실제 실행부터 수정 전후 증거로 사용한다.

## 실제 보정과 재검증

명시 대체의 음수 자간에서 실제 embeddedMetric hit의 자간 적용 전 폭을 소비한다.
표시 프로그램의 잉크가 그 칸에 들어가면 크기는 바꾸지 않고 여백만 중앙에 놓는다.
실제 원본 TTF/HFT·고정 전진·미확인 폭은 기존 경로를 유지한다. 문서명·쪽 번호·글꼴명으로
생산 코드를 분기하지 않는다. 기존 결측 기호의 정렬도 먼저 처리해 그대로 보존한다.

새 합성 검사는 실제 1 FAIL → 1 PASS였다. 기존 관련 29건도 최소 글꼴 macOS Native에서
PASS이며 전체 회귀 완료로 표시하지 않는다. 테스트 헤더 갱신 시각 추가 외에 검사 본문은 동일하다.

현재 보정 CLI로 같은 명시 환경의 전 4쪽을 재산출했다. 1·2쪽은 99.96356/99.72650%로
같고 3쪽은 98.69196 → 98.75608%, 4쪽은 99.80186 → 99.94357%다.
4쪽의 엄격 하락은 0.00000%p로 복원됐다. 전 4쪽의 렌더 트리와 PDF raster 해시는 전후 같다.
3·4쪽 review·overlay를 직접 판독해 기호 위치와 본문·표 배치를 확인했다.
사진 효과 도색, 새 후보의 전쪽 fresh WASM 및 최종 전체 게이트는 아직 남아 있다.
증적은 `mydocs/pr/assets/issue8856/stage6-replacement-symbol-cell/`에 보존한다.
