## 묶어서 분석할 경계

1. ATOP/CHOOSE/BINOM: 현재 ATOP은 자식의 자연 표시 높이와 분수용 여백을 합산한다. 독립 Print의 상하 글줄 기준선·43 CSS px에 대응하는 3225 HWPUNIT 논리 높이·67% 기준선과 비교한다. 픽셀 상수를 추가하지 않고 원본 BaseUnit/독립 글줄 프레임으로 상하 행을 발행한다. 이어서 Paren이 본체 프레임·구분자 슬롯·원점을 어떻게 소비하는지 추적한다. ATOP 안의 분수·문자 폭이 다른 CHOOSE와 정상 BINOM도 확인한다.
2. EQALIGN 분수: 독립 Print의 분수 프레임과 실제 행 피치·첫 기준선을 대조한다. helper 뒤의 재계산·실제 SVG/Canvas 원점까지 추적하며 평균 점수나 일부 행의 통과로 긴 정렬 묶음을 면제하지 않는다.
3. 누락 PILE: 표시 개체의 0 점유와 호스트의 유효한 빈 글줄은 다르다. Native 후속 문단이 Print보다 위에 있다. 실제 charPr은 1100 HWPUNIT이다. 저장 줄/생성 줄/무효 수식 캐시에서 `flow_metrics → composition → 측정 → 배치`를 추적해 호스트 줄이 사라진 지점을 고친다. 캐시를 clamp하지 않는다.
4. 불균등 MATRIX: 독립 정상 저장/Print는 `MATRIX{a # b & c # d & e & f}`의 a·b·c를 첫 표시 행, d·e·f를 둘째 표시 행에 두면서 세 행의 논리 높이를 예약한다. 원본과 독립 출력의 구문·셀 소속 및 정상 직사각형/명시적 빈 셀 대조를 확인한 뒤 규칙을 정한다. 수동 입력만으로 줄 정보를 수용하는 조건을 완화하지 않는다.
5. 원 카탈로그의 남은 누락 인자/외부 확장 구문: Native와 동일 원문 Print의 실제 표시·폭·후속 수식 소속을 연결한다. 공개 호환 parser와 문서 생성 문법을 구분하고 기능을 일괄 삭제하거나 기대값을 갱신하지 않는다.

## 독립 Print 추가 관측과 적용 내용

새 MCP 정상 저장 job `5119fdd6-748e-4ca2-bdad-ab551a923878`, Print job `fd38ef32-47da-481f-acbd-d5a1b047d27a`의 26쪽을 대조했다. 인증/응답 원문은 보존하지 않는다. `CHOOSE/BINOM`은 두 글줄 사이 0.15em을 예약하지만 일반 ATOP은 0.1em이다. `LEFT ( n ATOP k RIGHT )`의 저장 폭·높이는 2850×3150 HWPUNIT이며 `n CHOOSE k`의 2100×3225와 다르다. 두 구조를 같은 AST로 만들던 가정을 제거한다.

- AST의 Binomial은 CHOOSE/BINOM 두 항을 소유한다. 일반 호환 layout은 기존 괄호/ATOP 표현을 소비하고 한컴 layout은 독립 두 행·반복 템플릿 슬롯·구분자 프레임을 발행한다. top/bottom의 자체 기준선은 각 행 안에 유지한다.
- 일반 ATOP은 독립 빈 항/단어/분수 자료의 중앙 최소 템플릿 폭과 1/4em 좌우 예약, 첫 항에서 기준선을 정하는 계약을 소비한다. 분수 항의 큰 프레임도 동일한 행 결과에서 예약한다. 괄호는 이 결과를 소비하며 단순 글자 캐시 정규화 범위를 넓히지 않는다.
- EQALIGN의 & 경계는 일반 row의 연산자 앞 간격 helper를 공유한다. 분수·근호·닫는 괄호의 예약 여백을 중복하지 않고 일반 항·첨자·인접 연산자의 경계도 같은 helper로 정한다.
- 불균등 MATRIX는 추가 2열/3열·직사각형·명시적 빈 칸 Print 대조에서 확인한 원문 순서로 칸을 채운다. 선언한 물리 행 수와 마지막 빈 예약 행은 유지한다. 원문 칸을 버리거나 중복하지 않는다.
- 누락 PILE의 0 개체 점유 뒤, 가시 텍스트 없는 생성 줄은 실제 run/원본 charPr과 문단 줄간격의 `frame_metrics_for_line` 결과를 소비한다. 기존 유효 저장 줄은 덮어쓰지 않는다. 생산자 `flow_metrics_hwp` → composition `refresh_rows` → 저장/일반 문단 측정 → 같은 composed line을 사용하는 실제 배치로 이어진다.
- CASES의 누락 인자와 명시적 빈 템플릿은 독립 1500×1500 HWPUNIT 저장 결과에 맞는 한 빈 행/몸체 슬롯을 소유한다.

`cargo check --locked --profile release-test --tests --target-dir /home/tsjang/rhwp/target/pr-review`는 첫 묶음에서 89초에 exit 0이었다. 그 뒤 괄호의 ATOP 프레임 인식과 빈 CASES 슬롯을 대조해 추가 반영했다. 새 Native 빌드/전쪽·확대 검증에서 최종 소스를 판정하며 사전 컴파일을 전체 회귀 실행으로 보고하지 않는다. source-side eq_depth helper는 새 Binomial의 두 항을 순회하도록 보완했으며 테스트 수/기대값은 바꾸지 않았다.
