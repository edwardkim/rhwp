# Stage 130 — 공통 수식 줄과 분수 첨자의 배치 보정

Issue: #7642. Stage 123 전체 nextest는 두 번째 신호로 종료됐다. 실제 assertion 실패는
20개이며 종료된 검사 12개와 미실행 4,731개를 별도로 기록한다. 부분 실행을 전체 통과로
보고하지 않는다. 고정 source의 시각 전수도 controller가 종료돼 완료한 43건만 보존했다.
정확한 종료·원본 목록은 ignored `stage129-nextest-terminal-failure-inventory.json`에 있다.

## 이번 구현의 근거와 소비 경로

- 큰 둥근 괄호는 공개 cap의 전체 폭을 유지하면서 직선 부품의 폭을 원 face의
  49/1024em에 맞춘다. 공개 outline만 소비하며 특정 문서·좌표를 분기 키로 사용하지 않는다.
- 분수 첨자의 본체 크기와 실제 축소 크기 프레임을 따로 확인했다. 49개 부모 구조에 더해
  408/416/612/694/1017/1020/1496HU의 일반 글자·분수·분수 뒤 함수 21개를 한컴에서
  저장·Print했다. 저장 job `f0a37aee-9f15-4305-8f81-38bd6419c4c5`, Print job
  `1c26f3fb-2c6e-4543-b4cd-40db98f0851a`, 실제 2020 11.0.0.9136·PrintMethod 0·1-up다.
  지원 범위의 글자 크기는 폰트 메트릭 축이며, 입력 문자열이나 화면 좌표를 기대값으로 삼지 않는다.
  알려지지 않은 크기·장식·중첩 구조·다른 face는 기존 경로로 남기고 검증 범위를 구분한다.
- 없는 줄의 단일 TAC 수식 호스트는 빈 문단이 아니다. 같은 구성 결과에 수식 어센트와
  하강부·문단 글자 크기에서 계산한 줄간격을 공급한다. 다른 개체나 여러 수식의 줄 나눔을
  단일 수식의 증거로 대신하지 않는다.
- 합성 줄과 재조판 줄의 85% 기준선을 수식 기준선으로 간주하지 않는다. 실제 줄 소속의
  수식 상자·텍스트 합집합을 기존 `equation_line_metrics`에서 한 번 계산하고, 저장 줄 생성과
  composition을 통한 typeset·측정·최종 paint가 같은 결과를 소비하도록 연결한다.
  유효한 원 저장 줄을 무조건 다시 쓰지 않는다.

## 검증 순서와 남은 실패

소스 보정을 한 묶음으로 적용한 뒤 작은 독립 대조군과 원본 `eq-002`, 수학 최소본,
행렬/근호, 원본 HWP3 및 줄 캐시 없는 카탈로그를 먼저 확인한다. 90% 미만·쪽수 불일치가
남으면 출력을 보정하며 golden·baseline을 갱신하지 않는다. 90%를 통과해도 같은 영역의
첨자·기호·간격을 직접 확대 판독한다. 정식 관계형 검사 추가는 해당 원본의 Native/fresh
WASM 전쪽 검증 뒤 수행한다. 이어 실패 검사 보정과 최종 전수·전체 회귀·lint를 완료한다.

기존 쪽 테두리·HWP3 출처·머리말 기준점 검사의 전제와 실제 실행 결함을 구분한다.
WMF 도해·PUA 전진·저장/재조판 경계·CLI 진단·남은 golden 실패도 현재 브랜치에서
원본/독립 Print를 대조해 해결한다. 원인 미상의 snapshot 교체나 경고 은폐로 통과시키지 않는다.

## 적용 후 선행 확인

공통 수식 줄의 소비자와 네 재조판 진입점에 같은 메트릭 게시를 연결했다. 없는 줄의
단일 수식은 composition에 줄 하나를 만들며, 실제 줄 소속에 따른 어센트·하강부 합집합을
측정·typeset·paint와 공유한다. 생성된 수식 전용 줄의 저장 기준선도 같은 결과를 소비한다.
`line_breaking.rs`의 변경은 기존 진입점에 게시 호출을 연결하는 최소 변경이며 새 로직은
1000줄 이하 모듈에 둔다. 유효한 원 저장 줄은 기존 수용 조건을 유지한다.

`cargo fmt --all`, `git diff --check`, Native `cargo clippy --locked --target-dir
/home/tsjang/rhwp/target/pr-review -- -D warnings`는 종료 코드 0이다. Native build·
fresh WASM·시각 대조 및 나머지 lint/회귀는 이 source에서 다시 수행한다.
