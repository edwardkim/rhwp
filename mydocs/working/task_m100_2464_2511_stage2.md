# 작업 2464-2511 단계 2 - 최종 통합 PR 준비

## 범위

- 최신 `upstream/devel`을 기준으로 누적 통합 브랜치의 base 관계를 확인한다.
- PR review archive 39건의 필수 항목과 통합/중복 흡수 관계를 확인한다.
- 최종 원격 push 직전에만 최신 오늘할일을 생성·갱신해 첫 PR diff에 포함한다.

## 사전 검증 결과

- `CARGO_INCREMENTAL=0 cargo test --profile release-test --tests` 통과.
- `CARGO_INCREMENTAL=0 cargo clippy --all-targets -- -D warnings` 통과.
- `cargo fmt --all -- --check` 통과.
- `wasm-pack build --target web --out-dir pkg` 통과.

## 경계

- 이 스테이지에서는 원격 push, PR 생성, 원 PR close/코멘트, merge를 수행하지 않는다.
- 오늘할일은 PR 생성 승인과 최초 push가 임박한 시점에만 작성하며, PR 번호가 필요한 문서 때문에 사후 재작성하지 않는다.

## E2E 점검 결과

- `python3 scripts/check_e2e_manifest.py`는 tracked 72개와 MANIFEST 72개가 일치해 통과했다.
- `hml-open.check.mjs --mode=headless`는 HML 열기, 의미 보존 저장, 재열기, 기존 HWP 재열기까지 모두 통과했다.
- `undo-contracts.test.mjs --mode=headless`는 실제 입력과 Ctrl+Z를 포함한 5개 undo 계약을 통과했다.
- `save-as-format.test.mjs`는 HWP→HWPX와 HWPX→HWP의 blob 매직·재열기 assertion을 모두 통과했으나,
  두 `runTest()`를 동시 시작해 공용 reporter가 `null`이 되는 하니스 오류로 종료했다.
- `text-flow.test.mjs`는 페이지 넘김 단계에서 top-level `runTest()` Promise를 기다리지 않아 완료/리포트를
  보장하지 못했다. 두 스크립트의 E2E runner 수정을 다음 스테이지에서 수행한다.
