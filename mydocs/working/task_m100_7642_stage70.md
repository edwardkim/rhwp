정한다. 실제 예산 밖의 줄·표/각주/float 경계가 들어오지 않는 반례도 확인해야 한다.
현재 코드는 이전 단계의 중복 차감만 제거했으며 이 계약의 보정 완료를 주장하지 않는다.

## CJK 산식의 독립 Print 대조

원본 155·158은 HYhwpEQ, 1200HU이고 각각 한글 가격 산식·중첩 괄호 분수다.
원본 Print의 CJK face는 Haansoft Batang이며 수학 기호는 별도 Type3 프로그램이다.
PDF의 큰 font-size 값은 텍스트 행렬을 반영하지 않은 원값이므로 pt 값으로 쓰지 않는다.
PDF glyph 원점·분자/분모 기준선과 원본 속성을 ignored JSON에 기록했다.

원본 산식 두 개와 CJK/숫자/연산자/중첩 괄호 대조 12종을 800/1200/1600HU로
묶은 36개 진단 입력을 만들었다. MCP 2024의 저장 → Print로 한컴이 실제 생성한
크기·기준선·glyph 원점을 확보한다. 합성 입력의 0 크기나 현재 구현의 계산을
기대값으로 사용하지 않는다. 이는 원본 55개 TSV의 대체 자료가 아니며 정식 회귀는
시각 선행 조건 이후에 변경한다.
