## 배경

`local/task660`(v1) 머지 직전 클로드 서브에이전트(Codex 차단 대체)의 코드 리뷰에서 다음 권고 도출:

- **[Major]** 휴리스틱 (`text.starts_with("{n}. ")` 또는 `text.starts_with('[')`) 의존 → 명시 필드(`auto_number: bool`)가 더 깔끔하고 안전
- **[Minor]** `[`로 시작하는 모든 텍스트를 그룹 지시문으로 간주하면 `[보기]`, `[참고]` 같은 인용 블록도 prefix가 누락됨
- **[Minor]** 회귀 테스트 누락 — multi-digit 문제 번호, `[보기]` 시작, stem-only same-prefix

작업지시자 결정: **전면 재설계 진행** (`auto_number` 도입).

## 변경 요약

```jsonc

  "type": "boolean",
  "default": true,
  "description": "true면 빌더가 첫 stem 텍스트 앞에 '{number}. '를 자동 prepend. ..."
}
```

### 2. serde 모델 (`src/parser/ingest/schema.rs`)

```rust
pub struct Question {
    /// ...
    #[serde(default = "default_auto_number")]
    pub auto_number: bool,
}

fn default_auto_number() -> bool { true }
```

기존 v1 sample_minimal.json은 `auto_number` 미지정 → 기본 true → 동일 동작 유지 (회귀 0).

### 3. 빌더 (`src/document_core/builders/exam_paper.rs`)

휴리스틱 제거, 명시 필드만 참조:

```rust
fn apply_number_prefix(q: &Question, text: &str) -> String {
    if q.auto_number {
        format!("{}. {}", q.number, text)
    } else {
        text.to_string()
    }
}
```
