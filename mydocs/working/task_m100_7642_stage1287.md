# Issue #7642: rebase 뒤 호출 연결과 회귀 계약 재검증

## 기준과 범위

- rebase 뒤 source: `68d8aa8bae4616a2d5b9119fd89d0d2bb3aa7b6c`.
- upstream 비교 기준: `2efefc6a1f9812a188e32c1cb283e9ef7962ea3e`.
- 이전 단계의 TSV와 PNG는 이전 source의 증거이며 현재 source의 검증 완료로 재사용하지 않는다.
- 원래 55문서와 대조군 16문서, 남은 회귀 실패와 변경 영역의 확대 판독 범위를 유지한다.

## 원인과 보정 계획

재생 데이터에 추가한 `OutputDevice`의 CanvasKit 진단 이름이 exhaustive match에서 빠져 이전 빌드가 E0004로 끝났다. 이를 명시적으로 처리한다.

upstream의 composer 변경 일부가 이 브랜치에서 이미 분리한 include 파일로 이동하지 못했다. 기호 표시 투영 후의 실제 글꼴 소유 분할, 빈 캡션의 원본 글자 크기, 재조판한 저장 어절 꼬리의 줄 좌표·공백 메트릭을 실제 소비자에 연결한다. 실제 저장 줄을 합성 사다리와 구분하는 인수도 동일 호출 경로에 전달한다. 문서 ID나 새 수치 예외는 추가하지 않는다.

생산·소비 연결은 `composition.inc.rs`의 줄 투영 → `mapped_symbol_fonts`의 소유 분할 → `ComposedTextRun::text_style`, `stored_cell_reflow.inc.rs`의 프레임 재조판 → `FrameGeometry` → 기존 `paragraph_with_frame_geometry` 소비자다. 캡션은 `caption_height_px_in_context`가 원본 글자 크기를 읽고 기존 측정 호출자가 소비한다. 마지막 소비 경로·컴파일·실제 출력은 아래 실행 기록으로 확인한다.

## 회귀 테스트 변경 기준

변경된 정본 지침을 신규 검사와 이 작업의 기존 대상 검사에 함께 적용한다. 관계 검사를 유지하며, 완료된 후보 페이지 중 Native/fresh WASM 양쪽 점수의 최솟값이 100% → 99%대 → 98%대인 순서로 같은 핵심 동작의 페이지를 우선 선정한다. 표 시작·이어받기·종료·후속 본문·수식·각주 등 실제 변경 경계를 보호한다. 좌표는 독립 Print와 직접 확대 판독을 마친 페이지에만 ±2px로 추가하고 DPI·source·입력/PDF SHA·양쪽 TSV·PNG를 연결한다. 관련 전쪽 90%와 쪽수 일치가 먼저다.

현재 source의 선행 시각 검증 전에는 기존 회귀의 기대값이나 golden을 갱신하지 않는다. 전체 회귀·lint·Native/fresh WASM 검증·PR·CI·통합·옵션 2 문서 PR과 후속 처리는 아직 미완료다.

## 실행 결과

Cargo는 기본 작업공간의 `target/pr-review`를 순차 재사용하고 빌드 잡 8, 테스트 스레드 12를 구분한다. TSV·JSON·로그·nextest 기록은 ignored output에만 남긴다.


`stage1290-native-check.jsonl`의 Native Skia library check는 exit 0이다. 앞선 두 실행에서 인수 누락·제거된 구두점 API 호출을 검출했고 실제 현재 API와 언어 슬롯을 사용하도록 보정했다. `OutputDevice` match도 이제 컴파일된다. 이는 CLI 실행·전쪽 시각·회귀 통과 증거가 아니다.

upstream의 선두 공백 계획이 런을 분리한 뒤 실제 출력만 원래 런 인덱스의 공백 목록을 읽을 수 있던 연결도 수정했다. 측정에서 선택한 줄의 분할을 실제 출력에 넘긴 뒤 같은 분할에서 공백 소유를 읽는다. 문단 테두리는 채움 유무로 흐름 끝을 제외하지 않고 `ignoreMargin` 계약과 실제 점유·문단 뒤 간격을 공유한다. 이 경계의 최종 출력은 아직 재검증 대상이다.

`stage1293-unit-policy.log`는 새 base SHA와 비교해 4,101 tests / 296 modules로 성공했다. rebase 충돌 해소에서 남은 다섯 파일의 포맷 차이를 review worktree에서 정리하고 같은 파일 SHA를 확인한 뒤 기본 작업공간에 적용했다.

글꼴 고지 검사는 새 upstream의 공개 파일 전수 목록에서 이 브랜치의 Noto Sans Math, RHWP LMM Variable Outline 파생본, RHWP Host Fixture 부분 cmap 대조군의 등록 누락을 검출했다. 실제 바이트 SHA·name 저작권과 기존 전문을 등록했다. 부분 cmap 대조군은 Regular와 glyph 윤곽·hmtx가 같고 `A`만 cmap에서 빠진 것을 확인했다. `stage1292-font-source-notices-tests.log`는 원본 목록·고지 2/2 PASS다. 기존 dist의 오래된 폰트와 고지 누락으로 실패한 전체 배포 검사는 실제 재빌드 뒤 별도 실행한다.

이 브랜치의 활성 추가·수정 회귀 파일 56개와 `#[test]` 202개를 `stage1289-regression-guideline-audit.tsv`에 열거했다. 35개 파일의 좌표·크기 검색 후보는 관계 검사도 포함하므로 위반 또는 변경 완료 수가 아니다. 원본 속성의 크기 계약·소유 관계·실제 절대 좌표 핀을 구분하며 현재 Native/fresh WASM·쪽수·직접 판독 뒤 필요한 기존 검사를 변경한다. `issue_7642_page12_print_coordinates.rs`의 기존 독립 ±2px 검사도 현재 source의 해당 페이지 양쪽 98% 유지 여부를 다시 확인할 대상이다.
