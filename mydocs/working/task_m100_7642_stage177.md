# #7642 Stage 177 — 문서 수식과 LaTeX 확장 명령의 경계

Issue: #7642

## 독립 근거와 원인

한컴 2020이 정상 저장한 `pdf/issue7642-equation-catalog-print/equation-catalog-hancom-2020.hwp`의 독립 Print PDF에서 3쪽 FRAC/DFRAC/TFRAC, 17쪽 BEGIN/END/QUAD/OPERATORNAME/TEXT/STACKREL은 명령 이름을 문자로 출력한다. 현재 공개 파서의 LaTeX 호환 분류가 문서 수식에도 적용돼 이름을 없애거나 인자를 재구성한다. 문서 ID나 점수로 분기하지 않고 명령의 생성 문법을 구분한다.

`원본 script → 문서 tokenizer → EqParser AST → flow_metrics/인라인·떠 있는 수식·표·OLE 배치 → 공통 LayoutBox → Native/WASM paint`의 실제 소비 위치를 함께 변경한다. 공개 `tokenizer::tokenize`와 `parser::parse`의 LaTeX 호환 계약은 유지한다. 문서 경로의 bare LaTeX 분수·본문·간격·환경 명령 및 STACKREL 이름만 Text로 보존하고, 한컴 OVER/SQRT/MATRIX/PILE 등과 명시적 백슬래시 확장 경로는 유지한다. 후자의 한컴 대응을 이번 수정의 검증 주장에 포함하지 않는다.

## 메타파일 진단과 구분

Stage 176 헤더 경계 보완 후 Native 빌드는 exit 0, 322.858초이며 공용 `target/pr-review`를 사용했다. 이전 device-unit 진단 스크립트는 SVG 기본 네임스페이스를 ns0로 직렬화해 raster driver가 크기를 읽지 못했다. 기본 네임스페이스를 등록해 수정했다. 실제 그림 크기·관측 Print 600dpi로 변환한 진단 SVG 8쪽에서 WMF 4쪽은 100%, EMF 3쪽은 79.62963/83.09598/84.90196%, WMF 선 1쪽은 84.00447%다. 변형 진단이며 생산 출력·최종 검증이나 600dpi 공통 기본값의 근거로 승격하지 않는다. 구현 반영 전 장치 단위·crop·source image resource key의 소비 계약이 더 필요하다.

## 검증 계획

기존 카탈로그의 모든 18쪽을 Native로 재출력하고 동일 독립 PDF와 전체 TSV를 비교한다. bare 확장 명령의 내용 보존과 원래 한컴 구조 명령 및 공개 LaTeX API를 함께 사전 확인한다. 사전 Rust 컴파일도 공용 `target/pr-review`를 사용한다. Native/fresh WASM 90% 이상과 확대 판독을 충족하기 전에 golden을 갱신하거나 정식 렌더링 회귀를 추가하지 않는다. 전체 회귀·55개 입력·lint·fresh WASM·PR/CI/후속 처리는 아직 완료되지 않았다.

독립 저장 프레임도 함께 확인했다. PHANTOM{x}는 폭 825 HU를 예약하고 Print에 글자가 없으므로 한컴의 기존 명령이다. OVERSET/UNDERSET도 문자 이름 전부를 그대로 표시하지 않는다. 이 세 가족은 문서 tokenizer에서 변경하지 않으며 원래 공개 파서와 동일한 토큰을 소비한다. 분류표의 LaTeX 설명만으로 한컴에서 미지원이라고 추정하지 않았다.

## 문법 사전 확인

실제 AST·tokenizer·parser·문법 보조 모듈을 함께 컴파일했다. 기존 문서 호출 경로에서는 bare FRAC의 문자 분류 검사에 실패했고, 보정 후 bare 이름 11개·명시적 확장 11개·한컴 구조/인용/레거시 대조군 10개 및 공개 LaTeX 분수 파서가 모두 통과했다. 첫 사전 harness의 brace_recovery 모듈 누락은 harness 구성 오류이며 결함 재현으로 세지 않았다. source/컴파일/실행 원문은 `output/pr-review/issue7642/failed-inputs-20261008/stage15-current-validation/stage177-document-token-preflight.json`에 있다. 두 실행 파일 모두 `target/pr-review/release-test/stage177-document-token-preflight-{before,after}`를 사용했다. 이 검사는 시각 완료나 정식 렌더링 회귀를 대신하지 않는다.

[대표 review/overlay](../pr/assets/issue7642-document-script-20261013/README.md)를 보존했다. 3쪽이 90%를 넘더라도 `a+b OVER c+d`의 분자·분모 소속과 괄호 경계의 차이가 직접 보여 완료로 판정하지 않는다. 17쪽도 미달이다. 새 정식 회귀·golden 갱신을 보류한다. fresh WASM 빌드는 동일 공용 target에서 진행 중이며 완료 결과로 기록하지 않았다. 다음 분석에서는 공백이 있는/없는 피연산자와 한컴 저장 PILE/EQALIGN의 행 프레임을 묶어 검토한다.
