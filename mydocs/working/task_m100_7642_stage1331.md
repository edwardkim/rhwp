# Issue #7642: 변경된 지침에 따른 기존 회귀 검사 재검토

## 검증 기준과 범위

- 생산 코드: `810654da2af51c727bf639c3c6ecec8595d3c5f2`. 고정 upstream 기준: `2efefc6a1f9812a188e32c1cb283e9ef7962ea3e`.
- `CLAUDE.md`와 `visual_fixture_evidence.md`의 전쪽 90% 선행 조건, 완료 페이지의 양쪽 98% 조건, 같은 핵심 동작의 100% → 99%대 → 98%대 선정 순서를 적용했다. 96dpi, Native Skia와 새 release WASM Canvas2D를 사용했다.
- 이 단계는 테스트와 증거 설명을 변경한다. 생산 코드는 변경하지 않는다. 문서 전체가 98% 이상이어야 한다고 해석하거나, 90% 미만 페이지를 평균으로 상쇄하지 않는다.
- 초기 검색은 변경된 검사 파일 56개·테스트 202개에서 좌표 관련 후보 35개를 찾았다. 이는 위반 또는 변환 완료 수가 아니다. 직접 읽으며 검색에서 빠진 정렬 대조군의 절대 원점 검사도 확인했다. 원본 단위 환산·셀 포함·순서·비겹침 검사와 화면 위치 핀을 구분했다. 전체 회귀의 감사 완료를 뜻하지 않는다.

### 양쪽 정렬의 선두 공백

`verified_justification_edge_spaces.rs`의 원점 검사를 새 이름 `print_verified_completed_pages_keep_leading_space_origins_within_two_pixels`로 보강했다. 전체 6쪽의 문자 소유·순서·자연 전진 관계는 그대로 유지한다.

- 선두 공백이 있는 완료 페이지 중 100% 후보는 없다. 5쪽의 양쪽 최솟값은 99.55817%, 6쪽은 99.55804%다. 두 쪽을 먼저 선정해 자간 −12%와 공백 1·3개의 경계를 보호한다.
- 자간 0% 경계는 기존 2쪽을 함께 유지한다. 양쪽 최솟값은 98.63130%다. 4쪽은 선두 공백이 없으므로 같은 동작의 대체 증거로 쓰지 않는다.
- 좌표는 PDF 내용 스트림의 CTM과 텍스트 행렬에서 독립적으로 추출했다. 기대값을 현재 출력에서 복사하지 않았고 ±2px를 넓히지 않았다. 1쪽에는 px 핀을 추가하지 않는다.
- 원본·PDF SHA, 쪽별 양쪽 점수, 원점과 선정 이유는 `tests/fixtures/justified_edge_spaces/README.md`에 연결했다.

### 위첨자와 본문의 셀 내부 전진

기존 `issue_5756_superscript_advance_scale.rs`의 한 검사를 `verified_superscript_cell_advance.rs`의 새 이름 `print_verified_superscript_advance_preserves_cell_ownership_content_and_non_overlap`로 교체했다. 원본과 PDF는 보존한다.

- 기존 검사는 화면 x<714.5와 SVG의 `font-size="10.0`·`font-size="14.2` 문자열을 요구했다. 현재 독립 Print와 전쪽 대조가 끝난 같은 생산 코드에서도 과거 글꼴 문자열 조건으로 실패함을 확인했다.
- 새 검사는 원문의 `39.3`·`78.8%`로 해당 줄을 찾는다. 원본 표·셀·문단 경로, 문자 범위·순서·누락·중복, 원본 위첨자 속성, 본문과 위첨자의 공존, 셀 내부 포함과 런 비겹침을 확인한다. 전체 쪽에서 찾아 Print의 3쪽에 한 번만 소속하는지도 확인한다.
- 같은 생산 코드에서 기존 검사 FAIL / 관계 검사 PASS다. 이는 독립 근거에 따른 검사 기대값 교정이며, 이 단계에서 새 생산 코드 결함을 고쳤다는 주장이 아니다.
