# Stage 287 — 사전 Clippy 경고 보정

Issue: #7642

## 검출과 수정

고정 소스 `6c172496124874247fe4ebb3c7b26961a0c0658e`에서 사전 fmt check는 통과했다.
Native Clippy는 `src/renderer/typeset/controls/stored_tac.rs`의
`clippy::question_mark` 한 건으로 실패했다. 이 결과를 lint 통과로 보고하지 않는다.
후속 WASM Clippy·workspace build·all-targets Clippy·정책 검사는 아직 실행하지 않았다.

저장 글줄의 진입 밴드를 판정하는 `Option` closure에서 `last()`가 `None`이면
`None`을 반환하던 `let ... else`를 같은 의미의 `?`로 고쳤다. 저장 줄의 유효성·
예약 높이·원점 선택·배치 조건은 변경하지 않았다. lint를 우회하는 allow는 추가하지 않았다.

## 검증 상태

`cargo fmt --all -- --check`와 `git diff --check`로 형식과 patch 공백을 확인한다.
Rust 전체·세 Clippy 경로와 관련 시각 검증은 남은 실패 분석·수정을 모은 후보에서
다시 실행한다. 이 문서만으로 경고 재검증 완료나 PR 준비 완료를 선언하지 않는다.

현재 실행 중인 Source269 Native/fresh WASM 전체 queue는 수정하지 않은 고정 worktree와
해시로 고정한 binary/package를 계속 사용한다. 따라서 그 결과의 생산 소스는 Source269이며,
이번 lint 보정을 포함한 새 Main head의 실행 결과로 바꾸어 기록하지 않는다.

사전 실패 로그는 ignored
`output/pr-review/issue7642/failed-inputs-20261008/stage15-current-validation/stage285-source269-lint-policy/`
에 보존한다. 다음 실행 기록도 ignored output에만 저장한다.
