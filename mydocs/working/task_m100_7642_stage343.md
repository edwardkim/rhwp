## 세대 설정 오류의 정정

한컴 2024 Print 대조군에 compat 2022를 지정한 이전 큐의 설정 오류를 검출했다.
Source 335의 아직 내보내기 전이던 두 제어 프로세스를 정확한 PID·argv로 확인한 뒤
종료하고, 추가 대조군의 compat를 2024로 정정한 새 큐를 실행했다. 이전 receipt와
결과는 덮어쓰지 않았다. 55개 원본의 저장 제품과 기준 PDF 이름의 엔진 표기도 전수
감사했다. 55개 모두 저장 제품의 engine 분류와 파일명 표기가 같고, 29개는 2024 표기다.
이 감사는 Print 경로 자체를 파일명으로 입증하는 작업이 아니며, 실제 engine·
Print job 근거는 기존 독립 출력 기록과 함께 사용한다. 잘못된 세대의 기존 결과는
최종 대상의 승인 근거로 재사용하지 않는다.
