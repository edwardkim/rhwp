# #7642 Stage 159 — 도형 pen의 물리 굵기와 패턴 외곽 보존

Issue: #7642

## 근거와 실제 소비 경로

Stage 158의 독립 51개 한컴 2024 Print 사례에서 도형 pen은 600dpi 물리 단위로
반올림되며 최소 1단위를 소비했다. 점선·원형 점은 그 굵기의 채움과 1단위 외곽을
함께 출력했다. 이 계약을 선언 HWPUNIT에서 계산하고 도형의 공유 선 스타일에 저장한다.
화면 해상도·문서 ID로 선을 강제로 키우지 않는다. 0·얇은 값·반올림 경계도 같은 규칙이다.

`DrawingObjAttr.border_line → drawing_to_shape_style / drawing_to_line_style → stroke_width
→ SVG / Canvas2D / Skia / CanvasKit`을 대조한다. 패턴의 주기는 채움 굵기를 소비하고,
사각 점의 각 구간은 외곽만큼 길어지며 공백은 그만큼 짧아진다. 원형 점의 지름은
외곽을 포함한 pen이고 중심 주기는 채움 굵기로 정한다. 기존 범용 Dash/Dot는 유지한다.
이번 측정에 없는 이중·삼중선은 별도 굵기 계약을 추정하지 않는다.

프레임 원점의 작은 차이는 근거 없는 좌표 배율이나 clamp로 덮지 않는다.
선 농도·주기의 실제 보정 이후 독립 Print와 새 출력에서 남은 차이를 다시 판독한다.

통과는 보정한 선 종류 단위 계약이며 기존 48건은 아직 해결되지 않았다.

같은 소스의 fresh WASM도 재산출한다. 55문서 전체 Native/WASM, 실패 원본들의 시각 확인,
새 이름의 관계형 회귀, 전체 Rust·lint가 끝나기 전 PR을 생성하지 않는다.
