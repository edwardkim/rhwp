# #7642 셀별 원본 인라인 호스트와 후행 간격의 구분

Issue: #7642

## 독립 근거와 반례

`samples/issue1880_takeplace_host_before.hwpx`는 정부 행정규칙2780073의 저장본이다. 중첩 표5는 반복 머리행이 없으며, 독립 한컴 Print는2행 전체를6쪽에 둔다. RHWP는 첫 행을5쪽, 둘째 행을6쪽에 나눴다. 호스트는 바깥 표6행1열의 문단9이며 저장 줄은 `vpos=0, height=5021, spacing=600`; 앞 문단의 마지막 줄은 `vpos=29874, height=1000`, 다음 문단은 `vpos=5621`이다.

원본을 보존하고 해당 표 하나 또는 모든2행 표의 `pageBreak`만 `CELL→NONE`으로 바꾼 진단 대조군을 만들었다. 각 HWPX의 CRC와 변경 XML·SHA를 확인했다. 버전에 맞는 MCP engine2020의 `target=pdf`, Print method0으로 각각 출력했고 두 대조군 모두 원본과10쪽 전체 텍스트·글자 좌표가 동일했다. PDF 좌표 비교의 반올림은0.0001pt다. 이를 raster 동일성이나 원본 출력 개선으로 보고하지 않는다.

원본6쪽 Native raw61.01039%와 달리 `target-no-split` 대조군은97.38994%다. 대조군 전체에는1·5쪽 미달이 남아 정상 회귀 fixture로 추가하지 않는다. 원본을 대조군으로 교체하거나 파일 속성을 구현에서 바꾸지 않는다.

## 원인과 공통 규칙

실행 추적에서 원본 호스트의 첫 자식 행은 `hard_break=true, page_frame_reset=true`였지만, 다음 분할기는 첫 행 높이37.64px만 보고 저장 경계를 흡수했다. 기존 `stored_inline_owner_frame`은 첫 열·전 열 병합 셀만 허용해 오른쪽 셀의 독립된 줄 소유를 배제했다. 또한 자식 행 유닛 합74.946667px에는 다음 저장 줄의 등식으로 이미 계상한 후행 간격8px가 포함돼, 실제 호스트 상자66.946667px와의 비교가 실패했다.

셀의 열 번호·전 열 병합 여부는 한 줄의 인라인 표 소유 근거가 아니다. 해당 두 가정을 제거한다. 기존 저장 원본·단일 호스트 줄·개체 높이와 바깥여백의 등식·실제 행 유닛의 완전한 소유 검사는 유지한다. 명시적으로 계상한 호스트 후행 간격만 점유에서 제외하고, 실제 유닛 전진량과 컷은 변경하지 않는다. 허용 오차와 baseline도 유지한다.

## 생산 → 소비 → 배치

`cell_units_uncached`는 각 자식 행의 같은 호스트 소유·전진량과 `host_trailing_spacing_charged`를 발행한다. `stored_inline_row_frame_content_height`는 이 유닛 그룹에서 후행 간격을 분리하고 원본 줄 상자와 대조한다. ordinary row scanner는 전체 호스트의 점유로 경계 흡수를 판단하며, block scanner도 셀별 예산`cell_avail`에서 같은 결과를 소비한다. 컷 벡터를 바꾸는 것은 기존 분할기이고 paint는 그 컷을 그대로 받는다. 저장 조건을 충족하지 않는 로컬 reset·변경/합성 줄·성장한 표·큰 호스트의 분할 경로는 원본 프레임 인증을 받지 않는다. rowspan 제약의 일반화는 이번에 주장하지 않는다.

## 검증 상태

구현 후 검증 전이다. 진행 중인 이전 source `ace031f953`의 WASM·103문서 대조 결과를 이 수정의 통과 증거로 사용하지 않는다. Native의 원본10쪽·대조군과 영향 경계, 기존 전체 호스트·중첩 표·rowspan·편집 대조 검사를 묶어서 실행한 뒤 fresh WASM으로 확인한다. 원본 전쪽90%와 직접 판독 전에는 새 실물 회귀·golden을 추가하지 않는다.

진단·실행 명령·Print 메타데이터·입력/출력 해시는 ignored `output/pr-review/issue7642/failed-inputs-20261008/stage15-current-validation/`의 `stage3522-issue1880-source-unit-trace`, `stage3523-small-inline-table-controls`, `stage3524-small-inline-controls-print`, `stage3525-small-inline-controls-head-native`, `stage3526-small-inline-print-invariance.json`에 보존한다. 대조군 ZIP 생성 중 공유 ZipInfo 객체를 재사용한 오류는 수정하고 미완성 산출물을 따로 보존했으며, 원본의 CRC·SHA가 정상임을 다시 확인했다.
