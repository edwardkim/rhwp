## 독립 근거와 실패

원본 `samples/3-09월_교육_통합_2023.hwp`와 기존 독립 한컴 2020 Print의 전20쪽
Native 대조에서 15쪽 81.21964%, 16쪽 61.87094%를 확인했다. 같은 HWPX 원본도
15·16쪽이 미달이다. 평균값으로 면제하거나 기대값을 먼저 갱신하지 않는다.

최신 15·16쪽 review를 직접 표시했고, 15쪽 문27의 순열 식 네 개가 통째로 빠진 것을
확인했다. 실제 RenderTree에는 원본 수식과 미주 소유가 남아 있지만 내부 layout은
0×0이다. 예: 구역0/본문266/미주control0/미주문단2/수식0,
`it _{7} rm P it _{4}=7times6times5times4 =840`.
독립 Print는 왼쪽·오른쪽 첨자와 순열 및 등식 전체를 표시한다.

## 생산·소비 경로와 수정 범위

`document_script::tokenize` → `EqParser::for_document` →
`parser_terms::parse_element`의 빈 body 글꼴 전환 → 다음 첨자 →
`parser_atoms`의 기저 없는 첨자 중단 → 불완전/빈 AST →
`flow_metrics_hwp`와 `layout_for_paint` → 본문·미주의 줄 구성과 실제 출력으로 연결된다.
글꼴 전환은 보이는 글자가 없어도 뒤 글자의 표시 속성을 가진다.

현재 항 파서가 글꼴 전환을 반환하기 전에 뒤 첨자를 공통 첨자 인자 경로로 소비하고,
전환 marker와 첨자 결과를 같은 Row에 보존한다. 글꼴 전환을 지워 뒤 본문의
정체/이탤릭 범위를 바꾸지 않는다. 문서 ID나 순열 문자 P/C/H 전용 분기를 만들지 않는다.
수식의 선언 폭·높이 또는 화면 좌표로 빈 출력을 숨기지 않는다.

영향 경계는 앞·뒤 첨자 인자, 명시 그룹, 다음 글꼴 전환, 중첩 인자와 누락 인자다.
일반 문자 뒤 첨자와 공개 LaTeX 호환 파서, 글꼴 전환 없이 시작하는 오류 입력도
대조한다. 자료가 없는 조합은 미검증으로 남긴다.

## 함께 교정하는 검사의 근거

전64쪽 Native/fresh WASM 최저 91.99347%인 sample16의 쪽 테두리 검사는
중심 좌표를 과거 이중선 잉크 끝의 49.2px로 고정해 실패했다. 생산 코드는 바꾸지 않고
원본 간격/쪽 높이와 본문·선 묶음 중심의 관계, 공개 쪽 정보가 같은 중심을 표시하는지를
새 이름의 `issue_7642_page_border_center_relations.rs`로 검사한다.
다른 종이/쪽 기준 입력 네 개의 기존 관계·원본 기준 검사는 유지한다.
새 검사 초안은 보정 코드에서 통과했고 정식 suite와 관련 unit 검사를 함께 실행한다.
기존 대형 query 파일에는 그 unit assertion의 분리·이름 변경만 적용한다.
