# #7642 저장 문자 분할과 실제 페이지 prefix 소유 보정

Issue: #7642.

## 근거와 변경

[계획](../plans/task_m100_7642_saved_partition_frame_ownership_20261017.md)의
독립 Print 대조와 a80c33624a의 실제 출력에 근거한다.

`inline_flow::plan_square_table_host`의 저장 캐시 수용은 같은 현재 프레임이
확인한 줄별 textStart로 판정한다. hanging indent 적용 전후의 가로 구간을
같은 좌표 key로 취급하지 않는다. 문자 분할이 같은 저장 호스트의 원점을
누적 커서로 다시 고정하지 않으며, 분할이 바뀐 호스트는 기존 공통 plan을 쓴다.

`section::stored_reset`은 `stored_frame_prefix_consumed_before_page`로
이전 실제 쪽의 마지막 항목과 현재 첫 항목의 줄 소유를 확인한다.
다음 두 경우에만 옛 자동 저장 경계를 일반 예산 분할로 넘긴다.

- 현재 첫 문단 바로 앞 문단의 저장 내부 reset부터 끝까지 이전 실제 쪽이
  완전히 소비했고, 현재 첫 줄이 그 저장 끝의 다음 전진 위치다.
- 같은 문단의 연속된 부분 조각이며 이전 실제 쪽이 현재 시작 줄 직전까지
  소비했다. 현재 줄은 양수 저장 위치이며 저장 prefix에는 vpos=0 줄이 있다.

편집·합성 줄, 서로 다른 구역, 다단, HWP3의 별도 좌표 관례, 표·도형 소유,
명시적 쪽·단 나누기와 first-line-of-page는 이 판단에서 제외한다.
줄을 숨기거나 고정 페이지 수로 기대값을 바꾸지 않았다.
