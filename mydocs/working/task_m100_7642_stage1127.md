## 충돌 해소와 검사 범위

새 문단 배경의 줄 밴드와 기존 문단 테두리·간격 보정을 함께 유지했다. 문단 테두리 상자 수집을 뒤 간격 계산 뒤로 옮긴 기존 경로에도 `ParagraphFillBand`를 전달한다. 저장 TAC 후속 줄 거리는 분리된 `composer/composition.inc.rs`에서 새 devel의 거리 계약과 기존 재시작 줄 계약을 소비한다. 모듈 선언·미주 측정 함수도 양쪽을 보존했다.

Native 그라데이션은 중복 shader 구현 대신 devel의 공통 색상 stop·축 계산을 소비한다. 기존 함수 이름은 위임 경계로 유지하고 비정상 opacity·좌표를 거부하는 검증을 공통 helper에 남겼다. 합성 검사에서 세로 방향을 읽는 두 표본은 원본 angle 0과 맞춘다. 이는 독립적인 원본 축 계약을 유지하는 충돌 보정이며 실물 문서의 허용치 완화가 아니다.

`git diff --check`와 충돌 marker 검사는 통과했다. 원본·PDF의 미추적 디렉터리는 보존했다. 새 source의 컴파일·집중 회귀와 새 배경 처리 입력의 시각 검증은 다음 묶음에서 실행한다. 이전 source의 통과를 리베이스 후 통과로 보고하지 않는다. 실제 devel 대비 TSV도 새 기준으로 다시 산출해야 한다. 아직 전체 검증·PR·CI·merge 완료가 아니다.
