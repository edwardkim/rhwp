## 변경한 검사와 이유

기존 #6527은 HWP3 수식에 TextLine 조상이 없어야 한다고 고정했다. 실제 원본
상자의 ref_pos=0은 TAC이고, 원본 두 수식과 변환본은 문단155/158의 줄 흐름에
참여한다. 독립 Print는 제목·두 산식·설명·뒤 주의문의 순서와 표시를 보존한다.
출력 의미 대신 wrapper 부재를 요구한 전제를 교정했다.

사용자 지시에 따라 새 파일·새 함수 이름으로 대체했다. 원본 제어 소속·TAC,
본문 내 포함·같은 문단 줄의 점유, 두 수식의 순서·내용/길이·추출1회와 후속
주의문을 보호한다. 원본 HWP3/HWPX·독립 PDF는 기존 commit을 재사용했다.
원본 기록에 최신 전쪽 결과·직접 판독·검사 근거를 연결했다.

rustfmt/git diff --check는 통과했다. 새 검사 실행은 아직 대기 중이며, 기존
필수 lint가 사용하는 공용 target을 동시에 사용하지 않는다. 실제 결과를
확인하기 전에는 새 검사 통과나 전체 회귀 완료로 보고하지 않는다.
