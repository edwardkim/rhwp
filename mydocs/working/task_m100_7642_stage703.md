## 수정 경로와 반례

- HWP3 트리 구성 시 자식의 상대 위치를 최상위 묶음의 로컬 좌표로 누적한다. `offset_x/y`와 깊이는 보존한다. 최상위 페이지 위치는 기존 CommonObjAttr가 담당하므로 루트의 앵커를 중복 가산하지 않는다.
- `원본 상대 위치 → parser의 누적 render_tx/ty → 그룹 자식의 공통 배치 → 선 끝점/글상자 → SVG/paint`와 HWP/HWPX 왕복 저장이 같은 결과를 소비한다. HWP3 전용 렌더러 분기와 문서 ID 예외는 추가하지 않는다.
- 확인 대상은 서로 다른 원점의 형제, 부모 위치를 상속하는 중첩 자식, 루트의 페이지 앵커, 원본의 비가시 선이다. 회전/배율의 완전한 HWP3 변환 계약은 이번 이동 보정으로 입증하지 않는다.
- 독립 Print 기준의 전쪽 Native/fresh WASM 90% 이상과 확대 판독 전에 새 렌더링 회귀를 추가하거나 기존 기대값을 갱신하지 않는다. 이번 변경의 빌드·lint·시각 결과는 아직 미검증이다.
