## 독립 기준과 검증 범위

입력은 `pdf/issue7642-term-context-diagnostic/term-context-hancom-2020.hwp`,
기준은 같은 원본을 한컴 2020에서 정상 저장하고 Print로 출력한 같은 폴더의 PDF다.
원본 저장 기록의 9·11·16·22pt에서 `a _n -3`, `a _n - 3`, `a _n {-3}`,
`{a _n} -3`는 같은 본체·아래첨자·빼기·3을 보존한다.
공백을 제거한 `a _n-3`은 아래첨자 소유가 달라 대조 동치군에서 제외한다.

고정 Source269 `6c172496124874247fe4ebb3c7b26961a0c0658e`의 전쪽 3페이지를
같은 독립 PDF와 비교했다. Native/fresh WASM은 모두 최저 **98.48803%**이며,
전체 페이지 포함·쪽수 일치·90% 미만 없음이 실행 receipt에서 확인됐다.
이번 단계에서 fresh WASM 2쪽 review를 추가하고, 원본 수식 소유에서 고른 16개
대조식의 기준선·아래첨자·기호·앞뒤 간격을 확대 판독했다. 절대 px로 검사 영역을
등록하지 않았다. 확대 이미지의 crop은 표시용이며 회귀 선택 조건이 아니다.

## 새 검사

원본 section/paragraph/control 소유로 누락·중복을 확인하고, 같은 크기의 동치 식끼리
글리프 내용·순서·전진·상대 기준선·글자 크기를 비교한다. 정해진 화면 좌표나
고정 px 허용치를 쓰지 않는다. 같은 물리 값의 부동소수점 반올림만 허용한다.

이 검사는 정상 대조군의 소유·동치 계약이다. 수정 전 결함의 FAIL 검출을
이번 단계에서 새로 실행했다고 주장하지 않는다. 이전 시험지 검사의 이름을
재사용하거나 다른 PR의 제거 목록에 있는 기존 검사를 수정하지 않는다.
같은 생산 로직의 Main release-test library에 정식 파일을 직접 연결해 1/1 통과했다.
