## 새 fixture와 독립 기대값

새 HWPX 세 개와 각 원본을 독립 인쇄한 PDF를
`tests/fixtures/inline_flow/`에 바이트 그대로 복사했다.
생성 절차·case 순서·인쇄 engine/버전/방법/job·파일별 SHA-256은
[fixture 계약](../../tests/fixtures/inline_flow/PRINT_ROW_CONTRACTS.md)에 있다.
`stage1507-inline-regression-registration.json`은 전쪽·직접 판독 뒤의 복사 시점과
입력/PDF의 byte identity를 기록한다. PDF는 모두 50MiB 미만이다.
원래 배포 문서와 PDF는 기존 추적 파일을 재사용했다.

기대 표 경계는 독립 PDF 벡터를 CSS 96dpi 좌상단 좌표로 환산했다.
`stage1499-inline-independent-print-frames.json`에 35쪽의 PDF SHA와 측정을 보존했다.
배포 문서 3쪽의 독립 외곽 벡터는 x=90.830668, y=542.446655,
폭=630.381327, 높이=244.532023px다. 양쪽 98%와 직접 판독을 충족한 위 쪽에만
±2px를 사용한다. 그 외 페이지에 새 px 검사를 확장하지 않았다.

검사 대상을 고정 영역에서 찾지 않는다. 원본의 문단·컨트롤 소유로 한 번 배치된 표와
호스트 줄을 찾고, 원문 문자·작성 공백·셀 내용, 줄 순서·연속 개행의 공간을 검사한다.
배포 문서는 단위 표시와 표가 같은 3쪽에 있고 앞 제목과 뒤 주석이 올바른 순서로
남는지도 검사한다. 원점 배열은 문자 수+1이고 실제 원문 위치에 대응해야 한다.
좌표 핀만으로 내용 보존이나 편집 위치 계약을 대신하지 않는다.
