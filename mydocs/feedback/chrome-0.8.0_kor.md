rhwp는 브라우저에서 HWP/HWPX 문서를 바로 열고, 편집하고, 인쇄할 수 있는 무료 오픈소스 확장 프로그램입니다. 별도 프로그램 설치가 필요 없습니다.

주요 기능:

웹에서 HWP/HWPX 파일 다운로드 시 자동으로 뷰어에서 열기
문서 편집: 텍스트 입력/수정, 표 편집, 서식 변경
인쇄: Ctrl+P로 인쇄 미리보기, PDF 저장 또는 프린터 출력
편집한 문서를 HWP 파일로 저장
드래그 & 드롭으로 파일 열기 (확인 후 열기)
웹페이지의 HWP 링크를 자동 감지하여 아이콘(배지) 표시
마우스 호버 시 문서 정보 미리보기 카드 표시
우클릭 메뉴: "rhwp로 열기"

개인정보 보호:

모든 처리는 브라우저 내에서 WebAssembly(WASM)로 수행됩니다
파일이 외부 서버로 전송되지 않습니다
광고 없음, 추적 없음, 회원가입 불필요
어떠한 개인정보도 수집하지 않습니다

▣ v0.8.0 (2026-07-26) 주요 변경

이번 버전부터 확장 버전을 문서 엔진 버전과 동일하게 표기합니다 (0.2.8 다음이 0.8.0인 이유).

[문서 엔진 대규모 업데이트 (v0.8.0)]
• 저장 신뢰성 대폭 개선: 양식 값·책갈피·누름틀·스타일·표 테두리·수식 속성 등 편집 내용이 저장 시 사라지거나 되돌아가던 문제를 대량 수정했습니다.
• HWPX 저장 호환성: 세로쓰기, 표 겹침 허용, 테두리 입체/그림자, 화살표 모양, 체크박스 상태 등 수십 가지 속성이 저장 후에도 보존됩니다.
• 편집 취소(undo) 안정성: 각주/미주/수식 삽입, 머리말/꼬리말 조작, 표 셀 문단 병합 등이 정확하게 되돌려집니다.
• 문서 표시 정확도: 글꼴 처리 일원화, 표·각주·개체 배치 정합 개선. 1만 건 실문서 검증에서 쪽수 회귀 0을 확인했습니다.
• 손상되거나 악의적인 문서 파일에 대한 파서 방어를 강화했습니다.
• 편집 반응 속도와 한글 입력 지연을 개선했습니다.

[확장 자체 변경]
• 설정 저장·복구와 다운로드 자동 열기 방어를 강화했습니다.
• 새 권한 없음
• 새 외부 네트워크 엔드포인트 없음
