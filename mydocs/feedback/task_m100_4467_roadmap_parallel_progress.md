# #4467 피드백 — 조판과 협업의 병행 진행

- **Issue**: [#4467](https://github.com/edwardkim/rhwp/issues/4467)
- **일자**: 2026-08-10
- **작업지시자 피드백**: rhwp는 v1.0에 이르기 전에 이미 40명이 넘는 외부 기여자와 두 명의
  콜레보레이터를 확보했다. 따라서 v2.0의 협업 체계는 다음 단계에서 처음 시작되는 것이 아니라,
  현재 v1.0 조판 작업과 함께 빠르게 구성되고 있다.

## 반영 원칙

1. 버전 번호는 작업을 시작하는 엄격한 순서가 아니라 각 목표의 성숙도와 완료 기준으로 설명한다.
2. 현재 상태를 “v1.0 조판 집중 진행 + v2.0 협업 기반 병행 진행”으로 표시한다.
3. 참여 인원과 협업 절차가 이미 존재한다는 사실과 v2.0 전체의 완료를 구분한다.
4. v2.0의 남은 과제는 협업 시작이 아니라 지속 가능한 역할 분담, 호환성, 실패 복구와 유지 책임으로
   설명한다.
5. 공개 로드맵과 README의 요약이 서로 다른 상태를 말하지 않도록 함께 갱신한다.

## 현재 근거

- GitHub 공개 contributor 이력에서 메인테이너, 봇과 익명 항목을 제외한 이름 있는 외부 기여자는
  41명이다.
- 저장소 직접 권한 목록에서 `postmelee`, `jangster77` 두 계정이 `write` 역할의 콜레보레이터로
  확인된다. `edwardkim`은 `admin` 역할의 메인테이너다.
- 이 수치는 2026-08-10 현재 상태이며, 로드맵 본문에는 변동을 견딜 수 있도록 “40명이 넘는 외부
  기여자와 두 명의 콜레보레이터”로 표현한다.
