# Chrome Web Store 설명 — v0.8.7

rhwp는 브라우저에서 HWP/HWPX 문서를 열고 편집하는 무료 확장 프로그램입니다.
웹 다운로드 자동 열기, HWP/HWPX 링크 배지와 우클릭 메뉴, 로컬 파일 드래그 열기,
문서 편집·인쇄·저장을 지원합니다. 문서와 비밀번호는 서버에 업로드하지 않습니다.
문서 처리는 확장에 포함된 JavaScript와 WebAssembly로 브라우저 안에서 실행합니다.

## 이번 버전의 변경사항

- 문단 내 TAC 표의 줄 배치와 중첩 표·rowspan의 페이지 분할을 보정했습니다.
- 영어 UI, 하이퍼링크 편집·보존, 찾기 결과 개수 표시와 표 편집을 개선했습니다.
- 정상 썸네일의 압축 처리를 복구하고 문서 입력 경계의 방어를 보강했습니다.
- 다운로드 완료 이벤트와 저장본 자동 열기 처리를 보정했습니다.
- v0.8.6 대비 새 권한을 추가하지 않았습니다.
