# Chrome Web Store description — v0.8.7

rhwp is a free HWP/HWPX document viewer and editor in your browser. Open downloaded documents,
detect document links, use the context menu, or drag a local file into the viewer. Edit, print,
and save documents locally. Documents and passwords are not uploaded; parsing and editing run
inside the browser using bundled JavaScript and WebAssembly.

## Changes in this version

- Corrected inline table placement and page continuation of nested and rowspan tables.
- Improved English UI, hyperlink editing and preservation, search counts, and table editing.
- Restored compatible thumbnail decompression and strengthened document input boundaries.
- Corrected download-completion handling and automatic opening of saved documents.
- No new permissions compared with v0.8.6.
