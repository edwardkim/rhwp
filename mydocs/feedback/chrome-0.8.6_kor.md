rhwp는 브라우저에서 HWP/HWPX 문서를 바로 열고, 편집하고, 인쇄할 수 있는 무료
오픈소스 확장 프로그램입니다. 문서 처리는 외부 서버 전송 없이 브라우저 내 WebAssembly에서
실행됩니다.

## 주요 기능

- 웹의 HWP/HWPX 다운로드와 링크를 rhwp viewer로 열기
- 텍스트·표·서식 편집과 HWP 저장
- 인쇄 미리보기, PDF 저장 및 프린터 출력
- 확인 단계를 거친 로컬 파일 드래그 앤 드롭
- HWP/HWPX 링크 badge·미리보기 카드와 우클릭 메뉴

## 개인정보 보호

- 파일과 비밀번호를 외부 서버로 전송하지 않습니다.
- 광고, 사용자 추적, 회원가입과 개인정보 수집이 없습니다.

## v0.8.6 변경 사항 — 2026-09-02

- `.xlsx` 다운로드 URL이 `.hwp`로 끝나더라도 최종 파일명과 MIME을 확인해 HWP
  viewer로 잘못 여는 문제를 정정했습니다.
- 미리보기 이미지 압축 해제에 출력 크기 상한과 정확한 길이 검증을 추가했습니다.
- 조판·폰트·저장 정확도와 편집 기능을 보강한 v0.8.6 WebAssembly 문서
  엔진을 포함합니다.
- v0.8.4 대비 새 권한이 없고 새 외부 네트워크 endpoint를 추가하지 않았습니다.
