# #4467 피드백 — 프로젝트 로드맵의 독자와 문체

- **Issue**: [#4467](https://github.com/edwardkim/rhwp/issues/4467)
- **일자**: 2026-08-10
- **작업지시자 피드백**: 로드맵은 프로젝트에 관심을 갖는 사람, 특히 한국어를 모국어로 사용하는 독자를
  대상으로 한다. 어휘와 논리적 전개를 그 독자에게 맞게 개선해야 한다.

## 반영 원칙

1. 프로젝트 비전과 현재 위치를 운영 규칙보다 먼저 설명한다.
2. `canonical`, `DoD`, `gate`, `release`, `fixture`, `corpus`, `fallback`처럼 설명 없이 쓰인 외래어를
   자연스러운 한국어로 바꾼다.
3. `P1~P7` 같은 내부 식별자보다 독자가 이해할 수 있는 분야 이름을 사용한다.
4. 각 버전은 “무엇을 이루는가 → 무엇을 다듬는가 → 언제 완료로 보는가” 순서로 설명한다.
5. 세부 운영 규칙과 문서 권위 관계는 본문 뒤로 보내되, 근거 없이 완료를 선언하지 않는 원칙은 유지한다.
