# 선언 높이 보정의 실제 소비 경로

메인테이너 승인 뒤 제품 code `19de2f3b54`로 보정했다. 원 기여의 측정·그림 복원은 보존하며 `LayoutEngine::trust_declared_row_heights`의 저장 줄 없는 텍스트 격자 수용 조건만 고쳤다.

## 원인과 독립 기대값

원본의 그림 6장은 각각 높이 7087HU이고 칸 위·아래 안 여백은 각각 141HU다. 정확히 맞춘 선언은 42522HU다. 이 값은 그림 높이 합이며 안 여백을 없애는 상한이 아니다. 한컴 2024의 동일 입력 Print는 그림 묶음과 두 여백을 수용하도록 칸을 늘린다. 작은 원본·CENTER·겹침 허용·가로 비충돌·남은 공간 경계도 별도 실제 Print로 대조한다. 합성 입력 생성과 한컴의 독립 인쇄를 구분한다.

| 생산 → 소비 | 실제 경로와 확인 |
| --- | --- |
| 그림의 문단 내 점유 | `float_placement::cell_paragraph_no_overlap_square_stack` → `HeightMeasurer::calc_cell_wrap_objects_bottom_height`에서 566.96px |
| 내용·여백 → 요구 높이 | `HeightMeasurer::measure_table`: 위·아래 각 1.88px를 포함한 행 570.72px. 실제 캐시 라이브러리를 연결한 진단으로 확인 |
| 측정 → 최종 행 | `layout_table` → `resolve_row_heights` → `resolve_row_heights_with_common_fit` → `trust_declared_row_heights`. 종전에는 빈 문자열 그림 호스트를 빈 텍스트 칸으로 받아 566.96px 선언으로 덮음 |
| 보정 뒤 실제 높이 | 저장 줄 없는 그림·도형·표·수식·양식 호스트를 텍스트 격자 증거로 사용하지 않음. 실제 저장 줄의 기존 선언 계약과 순수 텍스트 격자 계약은 유지 |
| 실제 그리기·후속 내용 | render tree의 표/칸 h=567.0→570.7px, 그림 6개 원점 불변, END y=714.8→718.5px. 독립 Print 대비 Native raw 83.83→100.00%, 아래 괘선·END 확대 판독에서 정합 |

선행 수정은 #3386의 원 `81d208159`·후속 `a60ac3974d`, #7160을 포함한 통합 `505661360e9`, 측정 행합을 지키는 `08958748dec` 순으로 추적했다. 기존 #3386/7160의 올바른 기대값을 수정하지 않는다.

## 상대 점유와 최종 그림 좌표의 계약

측정은 문단 원점 기준 HU 상자와 여백으로 묶음의 점유 바닥을 만든다. 일반/partial 칸 높이와 세로 정렬이 동일한 `bottom`을 소비한다. `NoOverlapSquarePlacer`의 입력은 셀 정렬, 저장 프레임·fragment 원점 및 선행 개체 흐름을 적용한 실제 px 좌표다. 상대 이동량을 최종 y에 무조건 더하면 이미 소비한 전진을 중복 적용할 수 있어 `shifts`를 후단에서 일괄 더하지 않는다. 같은 eligible `members`만 물리 좌표에서 충돌을 해소하며 다른 개체에는 적용하지 않는다.

이는 별도 높이 추정이 아니라 최종 좌표계의 충돌 계약이다. 일반 TOP/CENTER 묶음, 성장한 칸과 후속 본문, partial 소유, 겹침 허용 및 가로 비충돌을 실제 출력으로 대조한다. CENTER의 전체 묶음 정렬·가로 비충돌에서 불필요한 세로 이동이 없는지 확인했으며, 별도 추정으로 측정 행 높이를 다시 덮는 처리는 추가하지 않았다.

## 실제 분할·이어받기와 남은 공간

`cell_units` → `cell_cut_contains_non_inline_control_units` / `cell_cut_starts_non_inline_control` → `layout_partial_table`의 빈 문단 소유 → 그림 배치 순서다. 문단 문자열이 빈 것과 개체 유닛이 없는 것을 구별한다. `control_owned_empty_paragraph_height`는 해당 조각이 소유한 개체 띠를 칸 정렬에 반영하며, 빈 줄 높이를 개체 높이와 세로로 중복 합산하지 않는다.

원 HWP의 실제 1쪽 컷은 시작 없음/끝 `[18,15]`, 2쪽은 시작 `[18,15]`/끝 없음이다. 표는 7행·2열이며 첫 조각 h=860px다. 그림 2개는 첫 조각에만 있고, 이어받은 2쪽에는 LINE 19–40과 END가 있다. 앞쪽 LINE 1–18 및 전체 ROW 1–6/LINE 1–40의 순서·누락·중복을 대조한다. 마지막 그림을 그렸다고 이어받을 본문을 종료하지 않는다.

`cell-square-stack-after-leading-lines.hwpx`는 큰 원본 앞에 BEFORE와 실제 공백 줄 12개를 추가한 경계다. 종전 선언 높이만 남은 공간에 들어가고, 그림 점유를 반영한 칸은 다음 쪽으로 이동해야 한다. 독립 Print와 보정 Native는 앞 문단을 1쪽에, 온전한 그림 6개·칸·END를 2쪽에 둔다. Native 2쪽 모두 raw 100%다. base는 1쪽으로 잘못 남아 쪽수도 다르다. 새 코드가 내용 유닛을 임의로 자르거나 높이를 clamp하여 얻은 결과가 아니다.

최종 WASM·회귀 결과와 원본/PDF 해시는 최종 검증 기록으로 연결한다. 진행 중 결과를 완료로 쓰지 않는다.
