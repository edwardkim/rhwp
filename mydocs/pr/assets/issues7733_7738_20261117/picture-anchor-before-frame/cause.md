# 문단 기준 그림 호스트의 앞 간격 중복 점유

시행령 70쪽 그림 자체의 위치·크기는 대체로 맞았지만, 표 하단만 약 3.6px 길었다.
원본 셀의 빈 그림 문단은 저장 줄이 없고 앞 간격 200 HU를 선언한다. 그림은 문단 기준이다.
표 선언 높이 37483 HU는 머리 행 1865 + 그림 35336 + 안 여백 282와 같다.
기존 회계는 그림 자리에 흡수된 빈 앵커 줄을 제거하면서 앞 간격 200 HU를 남겨
표를 2.67px 더 늘렸다. 실제 paint는 앞 간격 전 문단 원점에 그림을 그대로 놓았다.

원본을 HWPX로 직렬화한 baseline과 해당 그림 호스트만 앞 간격 0으로 바꾼 대조군을
한컴 2020 Hancom PDF Print로 독립 출력했다. 두 출력 모두 버전 11.0.0.9136,
Print method 0, hancom2020_pdf_driver_one_up, preprocess none, 74쪽이다.
canonical 원본 Print와 두 대조군 70쪽의 표선·그림 좌표는 같다. 두 대조군의
96 DPI PDFium PNG 해시도 동일하다. RHWP는 그림 위치는 같은데 표만 502.4→499.8px로
달라졌다. 공식 원본·기준 PDF를 대조군으로 바꾸지 않는다. 임시 생성기의 의존성·ZipInfo
재사용 오류는 수정했고 CRC 검증을 통과한 입력만 MCP에 보냈다.

선행 #8427(d534dc86a0)은 문단 기준 그림이 앞 간격 전 원점을 쓰고 그 간격을 그림 자리에
흡수함을 저장 줄 경로에 구현했다. #9008(010a29bb18)과 b06037c142는 저장 줄 없는
빈 그림 호스트의 합성 줄만 제거해 앞 제목을 보존했다. 다만 앞 간격은 남겨 두었다.
기존 문단 기준 개체 판별을 저장 줄 분기 앞에서 공유하고, 저장 줄 없는 경우도 그 앞 간격을
마지막 호스트의 점유와 함께 흡수한다. 앞 제목 문단 전체를 차감하거나 그림·괘선을 옮기지 않는다.
생산한 행 높이를 측정→표 배치→가운데 라벨과 괘선이 그대로 소비한다.
실제 그림은 table_layout의 문단/셀 앵커 원점을 유지한다. 문서·쪽 번호 분기는 없다.

새 고정형 검사는 독립 Print의 하단 y=870.728px·그림 원점 y=398.284px를 ±2px로 보호한다.
수정 전 기존 제목·사진·도장 9 PASS, 새 표 하단 1 FAIL(874.32px), 수정 후 10 PASS다.
기존 #8427과 관련 소유·여백·줄 간격을 포함한 최소 글꼴 199건도 199 PASS(13.737초)다.
전체 회귀 완료를 의미하지 않는다. 저장 줄 없는 순수 텍스트의 앞 간격 검사도 유지했다.

일반 원본 글꼴 환경의 Native 전 252쪽 재측정에서 시행령 70쪽만
98.75022→100.00000%(2px raw)로 상승하고 나머지 251쪽은 정밀 수치까지 동일하다.
다섯 문서 최저는 화학 99.38114%, 사양서 99.68651%, 시행령 99.16669%, 개요 두 문서 100%다.
review와 overlay를 직접 판독했다. 이는 모든 RGB 픽셀이 동일하다는 뜻이 아니다.
보정 직전 058acd32a1 fresh WASM의 같은 쪽은 98.75534%로 재확인했다.
최종 소스의 fresh WASM 전쪽·전체 회귀·정본 보호·실제 소비 경로는 아직 미완료다.
