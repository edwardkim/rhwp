# 구역의 늦은 쪽번호 선언 앞에서 이전 위치를 잃던 문제

원본 CFB를 직접 읽은 결과 Section4의 `pgnp`는 최상위 문단179에 있고 그 앞에는 새 위치 선언이 없다.
같은 독립 PDF의 물리79·80쪽은 쪽번호57·58을 인쇄하지만 이전 Native의 Footer는 비어 있었다.
구역 안 어디든 자체 위치가 있으면 이전 구역의 위치 상속을 전부 생략하던 공통 후처리가 원인이다.

첫 실제 위치 선언 전의 선행 None 쪽에만 이전 구역 설정을 이어 준다. Some(position=0)도 명시적
선언이므로 그 이후를 채우지 않으며, PageHide·새 번호·쪽수·본문 배치는 바꾸지 않는다.
파일명·쪽 번호 예외가 없다. 동일 Native 입력103쪽에서 하락0쪽,80쪽89.83308→100%를 확인했다.
전체 98% 목표와 fresh WASM·회귀·보호 검증은 아직 남아 있으며 이 Native 결과만으로 완료하지 않는다.
