# 고정폭 바탕체 큰따옴표의 전각 전진

원 해결 #7702의 `155bec27ee7`은 곡선 따옴표를 영문 슬롯에서 측정한다. 후속 #7092 검사는
고정폭 작은따옴표의 전각을 보호하지만 큰따옴표는 같은 예외에 포함되지 않았다.
TrueType 종류가 명시되지 않은 고정폭 글꼴에서 큰따옴표의 원본 1em 폭이 0.5em으로 바뀌었다.

화학 원본 44쪽의 독립 2020 Hancom PDF Print는 BatangChe 큰따옴표를 각각 16px로 전진한다.
같은 줄의 한글도 16px다. 마지막 설명 줄의 `“` x=168, `평` x=184, `”` x=256, `에` x=272다.
이전 측정은 따옴표마다 8px를 빼서 뒤 내용과 양쪽 정렬을 함께 앞당겼다.
생성된 원본 메트릭은 이미 1024/1024의 전각이므로 글꼴 폭 표나 기준 PDF를 바꾸지 않는다.

고정폭 프로그램의 곡선 큰따옴표도 작은따옴표와 같이 원본 전진을 유지하도록 공통 측정기를
보정했다. 비례 글꼴과 이미 신뢰한 TrueType 프로그램의 계약은 유지한다.
최소 글꼴 격리 환경에서 실제 2건 중 1건 실패를 재현한 뒤, 보정 후 두 검사 모두 통과했다.

정상 원본 글꼴 환경 Native 252쪽의 정밀 raw 비교에서 화학 문서 11쪽만 상승했고 하락은 없다.
44쪽 95.83356→99.96767%, 49쪽 97.63332→99.83873%, 68쪽 96.99945→99.49869%다.
44쪽 review·overlay에서 줄 소속과 따옴표 뒤 간격을 직접 판독했다.
이는 현재 Native 결과이며 새 따옴표 소스의 fresh WASM 전쪽·전체 회귀 완료는 아니다.
