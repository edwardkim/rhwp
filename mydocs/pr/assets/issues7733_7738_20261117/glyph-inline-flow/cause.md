# 원본 기호 폭과 인라인 목록·표 종료 흐름의 소유

이 단계는 화학 원본의 글리프·간격을 복구한다. 입력과 독립 한컴 2020 Hancom PDF Print는
그대로 사용한다. 공식 형식 문서 PDF도 재출력하거나 수정하지 않았다.

- 원 해결 CJK 폭 보정 `e2b8b95214`는 U+3001..303F만 처리했다. 원본 HY중고딕에 없는
  U+FE40의 독립 Print 공급자는 Haansoft Batang이며 원 프로그램의 hmtx는 1em이다.
  실제 폭이 결측인 Unicode 세로 호환기호도 같은 전각 분류를 따른다.
- 돋움 U+25AA의 원 프로그램은 384/1024em이며 독립 Print의 다음 괄호 원점도 확인했다.
  기존 해소 슬롯의 TTF/HFT 플래그만으로 원본 유형을 단정하지 않는다. 폭 표 전체를 신뢰하게 하지 않고 확인한 glyph
  하나의 측정 계약을 보완한다. 다만 이 단계의 실제 28쪽 paint 원점은 아직 바뀌지 않아
  완료로 수용하지 않는다. 명시적 HFT는 이 보완에서 제외한다. 두 설치 TTC의 원본 해시와 face는
  별도 JSON에 기록하며 글꼴 바이너리는 저장소에 넣지 않는다.
- 인라인 표 문단은 번호 적용 결과를 버려 일반 목록과 같은 머리·첫 본문·후속 내어쓰기를
  쓰지 않았다. 공통 목록 기하와 마커 발행기를 사용하고, 컨트롤 자신의 저장 줄이
  `Common + 위·아래 바깥여백`을 인증한 경우 그 줄의 원점에서 표를 그린다.
  일반 TAC 한 줄 판정을 넓혔을 때 #7018 원점이 후퇴한 첫 후보는 폐기했다. 수정한
  발행기 전용 질의는 실제 측정 높이와 선언 높이를 모두 확인하며 기존 #7018을 유지한다.
- 화학 40쪽의 조판은 이미 아래 여백 283HU를 예약했지만 paint 뒤 흐름은 이를 누락했다.
  독립 저장 후속 줄의 원점이 같은 단 축에서 정확히 그 여백을 증명할 때만 복원한다.
  표 선·잉크 하단·overflow 판정은 늘리지 않는다. 일반 종료 경로에 여백을 무조건 더한
  중간 후보는 공식 형식 문서 57·58·59쪽을 후퇴시켜 수용하지 않았다. 원본 여백 75HU
  변경에 후속 제목이 2px가 아닌 1px만 전진하는 음성 관계 검사를 추가했다.

최소 글꼴 격리의 확장 집중 회귀는 79건 통과다. 7,523건은 선택 밖으로 전체 회귀 결과가 아니다.
첫 보완의 이름 해소 컴파일 오류는 수정했으며, 오류 실행을 제품 회귀나 통과로 세지 않는다.
현재 Native 전쪽 결과와 생산자는 함께 보존한다. 이 단계는 최신 fresh WASM 전쪽·전체
nextest·필수 lint/build·보호 gate·실제 소비 검증을 완료한 최종 제출 결과가 아니다.

95쪽에는 인라인 표 뒤 설명 줄의 양쪽 정렬 공백 늘림이 빠진 잔여 차이가 확인됐다.
문자 폭은 맞고 공백을 지날 때 차이가 누적된다. 그림 차이로 제외하지 않고 후속 보정한다.
시행령 13·19·36쪽의 물리 프레임 잔여도 같은 현재 작업 범위에서 계속 확인한다.

최신 Native 전 252쪽에서는 화학 4쪽 상승·하락 0쪽이며, 공식 형식 문서 57·58·59쪽은
모두 100%로 복구됐다. 화학 28쪽은 97.56592% 그대로이며 원본 문자열의 선두 리터럴
작은 네모다. 자동 글머리표가 아니므로 목록 예약 칸을 변경할 근거는 없다.

40쪽의 최신 review·overlay를 직접 판독해 표 뒤 제목·본문 원점의 복구를 확인했다.
95쪽은 98.41818%에서 공백 정렬 잔여를 확인했고 계속 보정한다.
