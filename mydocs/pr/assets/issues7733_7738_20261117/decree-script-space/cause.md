# 첨자 뒤 공백의 본문 em과 실제 글꼴 공백 구분

## 실제 차이와 원 해결 경로

시행령 13쪽은 데스크톱 Print 첨자 계약의 공통 적용(`5498d80a8e`)으로 Native/fresh WASM 모두 100%가 됐다. 같은 소스 전쪽 비교에서 18쪽은 Native 99.95047→99.82190%, fresh WASM 99.84048%로 남았다. 평균이나 13쪽 개선으로 이 차이를 상쇄하지 않는다.

18쪽 원본은 문단 617의 ` ○ 가상융합 플랫폼 사업자 수` + 위첨자 `* ` + `(2018 ∼ 2023)`다. 독립 한컴 2020 Print는 별표 x=464.16px, 그 뒤 공백 x=470.72px, 다음 본문 x=479.36px다. 첨자 크기는 본문 12.96pt 대비 8.28pt지만 공백은 본문 반각 8.64px로 전진한다. 5498 출력은 `* `의 공백까지 줄여 뒤 본문이 x=476.2933px에서 시작했다. 그림이 아닌 문자 간격 차이다.

기존 `reflow_space_font_size`는 새 줄 구성의 반각 공백을 본문 em으로 측정했으나, `char_width_decision_with_hft_tracking`는 `layout_half_space=false` 경로에서 첨자 크기로 공백까지 줄였다. 또한 원본 `useFontSpace`가 명시한 실제 글꼴 공백과, `punctuation_slots::apply_space_origin`이 언어 간 반각을 환산해 임시 `font_space_em`에 담는 경우를 구별해야 한다. 후자는 `inherited_half_space_em=true`로 출처가 보존된다. Some 여부만으로 명시적 글꼴 공백이라고 해석하면 안 된다.

## 독립 대조와 공통 보정

같은 3글꼴(맑은 고딕·한컴바탕·굴림) ×3크기(9·11·18pt) ×useFontSpace 0/1의 18조건을 실제 한컴 2020과 2024에서 각각 Hancom PDF Print로 출력했다. 총 36조건이며 실제 엔진·경로 영수증과 입력 SHA를 함께 보관한다. 2024 실행은 같은 2020 저장 메타데이터의 소형 입력에 대한 버전 교차 대조이며, 시행령의 기존 기준 PDF를 바꾼 결과가 아니다.

`independent-space-observations.json`에서 일반 공백은 위·아래 첨자에 포함되어도 본문 약0.5em을 유지하고, 글꼴 공백 사용은 실제 글꼴의 공백 전진을 첨자 크기로 축소한다. 한컴 장치 격자·글꼴별 양자화를 그대로 기록했으며 표시용 반올림으로 기대값을 만들지 않았다. [2020 PDF](../../../../../pdf/issues7733_7738_20261117/script-space-2020-controls.pdf)와 [2024 PDF](../../../../../pdf/issues7733_7738_20261117/script-space-2024-controls.pdf)는 정식 경로에 보관한다.

공통 `space_metric_font_size`를 실제 문자 폭과 재조판 공백 보정에서 함께 사용한다. 일반 공백 및 상속한 반각 em은 본문 크기를 유지하고, 원본에서 명시한 실제 글꼴 공백만 첨자 크기를 소비한다. HWP3의 Legacy 계약·일반 본문·나머지 glyph의 크기와 기존 장평·자간·공백 최소값은 유지한다. 문서·쪽 번호·글꼴 이름 분기나 비교 문턱 변경은 추가하지 않는다.

## 검사와 현재 상태

기존 관계형 `issue_7737_decree_superscript_flow`에 공백 관계와 명시적 글꼴 공백·상속 반각의 반례를 보강한다. OS 글꼴 설치나 화면 좌표 핀을 요구하지 않는다. 처음의 일반 공백 검사는 수정 전 3건 중 2 PASS·1 FAIL(1.320초), 첫 보정 후 3 PASS(1.364초)다. 추가 상속 반각 반례는 첫 보정에서 2 PASS·1 FAIL(1.294초)로 실제 검출했다. 최종 보정 후 3 PASS(1.289초)이며 기존 #5756 위첨자·70쪽 그림 호스트까지 합친 관련 검사 5건도 PASS(1.418초)다. 최소 글꼴 sandbox에서 실제 실행했다.

이 자료는 코드·기대값이 다른 예전 검증을 새 소스의 통과로 바꾸어 보고하지 않는다. 5498의 Native/fresh WASM 252+252쪽 자료는 `output/pr-review/issues-7733-7738-20261117/script-print-final/`에 보존한다. 최종 소스의 전체 회귀와 보호 검증은 아직 미완료다.

## 실제 Native 집중 출력

최종 공백 소스의 Native 13쪽은 100.00000%를 유지했고 18쪽은 99.82190→99.99005%(미대응 6픽셀)로 개선됐다. 같은 페이지 review/overlay를 직접 판독해 첨자 뒤 날짜 위치가 PDF와 정합함을 확인했다. 남은 작은 획 차이를 WMF·그림 차이라고 부르거나 100%로 반올림하지 않는다. `native/`와 `before-native/`에 raw·PDF·review·overlay를 함께 보관한다.

생산자는 parent 5498과 기록된 dirty 소스로 실제 빌드했다. `native-producer.json`의 세 소스 파일 SHA와 같은 커밋 소스를 대조한다. 실행 당시 HEAD를 최종 커밋으로 다시 붙이지 않는다. 이 공백 소스의 fresh WASM·전체 회귀·전쪽·보호 검증은 아직 미완료다.

## de467 소스의 fresh WASM과 전쪽 재검증

`visual-de467/`에 같은 소스의 Native 252쪽·fresh WASM 252쪽 TSV 10개와 생산자를 보존한다. 13쪽은 양쪽 100.00000%·미대응 0픽셀이고, 18쪽은 Native 99.99005% / fresh WASM 99.99037%·각 6픽셀이다. fresh WASM의 같은 18쪽 review와 overlay를 직접 판독했다. Mac locked wrapper `--no-opt` 로컬 대체 빌드이며 Docker 최적화 통과가 아니다. 루트 pkg와 Studio public JS/WASM SHA가 각각 일치한다.

다섯 문서 각각의 전쪽 최저는 `precision-summary.json`에 원래 정밀도로 기록한다. 모든 쪽이 98% 이상이며, 화학·사양서·시행령의 잔여 문자 차이를 그림 차이로 면제하지 않는다. 이 실행 이후 화학 72쪽의 원본 기호 전진·명시 공급자 순서 보정이 진행 중이므로 de467 결과를 이후 소스의 최종 전체 회귀·보호 통과로 인용하지 않는다.
