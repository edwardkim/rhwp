# 원본 HFT 근호의 논리 전진과 대체 윤곽 전진 분리

현재 5개 이슈의 글꼴·첨자 공백 보정 후 전체 회귀는 13,769개 중 13,768개 통과, #4138 근호 E 원점 1개 실패였다. 기존 한컴 Print 기대 좌표와 허용폭을 유지한다.

원 해결 PR #8754의 `7f76cee60e`는 현대 근호의 1em 대신 공개 Latin Modern 윤곽의 hmtx 833/1000em을 원본 HFT의 논리 전진으로 사용했다. 이전의 첨자 뒤 공백 축소와 오차가 상쇄되었으나, 공백을 정상 본문 전진으로 복구하니 E가 약 3.10px 오른쪽으로 이동했다. 독립 원본 PDF의 `=`·`5.0` 각 문자 원점은 새 본문 배치와 일치하므로 공백 보정을 되돌리지 않는다.

## 독립 재현

공개 #4138 원본에서 같은 문단·수식 속성을 보존하여 7.5/10/15pt × `sqrt E`, `sqrt {E}`, `E`, `{E}`, `sqrt Q`, `sqrt {Q}` 18조건을 생성했다. 한컴 2024 `Hancom PDF` Print PDF와 독립 한컴 HWPX 재저장을 각각 확보했다. PDF 기준을 교체하거나 후보 SVG를 정답으로 삼지 않았다. [대조 PDF](../../../../../pdf/issues7733_7738_20261117/hft-radical-controls-2024.pdf)와 [재저장 fixture](../../../../../tests/fixtures/issue7733_hft_radical/original-radical-controls-2024.hwpx)를 보관한다.

생성 직후 단문자 E/{E}는 임의 저장 폭을 가지고 있었으므로 그 원점과 근호 원점의 차이를 직접 비율로 삼지 않았다. 실제 대조는 독립 Print의 근호 피연산자 원점 12개와 같은 문단의 생산 배치를 비교했다. 재저장 fixture의 저장 치수는 한컴이 정상화한 값이다.

공개 대체 윤곽의 0.833em을 소비한 기존 원점 오차는 최대 4.66875px였다. 원본 HFT 논리 전진 0.6em을 적용한 예측 오차는 최대 0.20125px이며 크기·그룹·E/Q에 공통이다. [독립 측정](independent-advance.json)에 PDF 원점, 크기와 인쇄 증거를 연결했다. 윤곽을 가로로 압축하거나 글자 크기를 바꾸지 않는다.

## 소비 경로와 반례

`EqLayout::layout_sqrt`의 원본 HFT 논리 전진 → 공통 `LayoutBox::Sqrt.body.x` → SVG·Native·Canvas 공통 인자 원점으로 연결한다. `radical_outline::geometry`는 기존 공개 윤곽의 실제 전진 끝을 몸체에 접속하며 833/1000em을 계속 사용한다. 논리 점유와 잉크 폭을 구분한다. 현대 공개 수식과 명시적 현대 HYhwpEQ 경로는 유지한다.

기존 6개 검사를 제거하지 않고 원본 197쪽의 E 고정형을 그대로 유지했다. 추가 관계형은 3크기·그룹 유무·E/Q의 원본 전진과 공개 현대 근호의 자연 전진을 분리한다. 회귀 검사는 개인 글꼴에 접근하지 않는 macOS 최소 글꼴 sandbox에서 실행한다. Visual Sweep은 설치 원본 글꼴이 있는 정상 환경에서 별도로 실행한다.

보정 전 실제 8개 검사: 6 PASS / 2 FAIL, 1.295초 → 보정 후 8 PASS / 0 FAIL, 1.325초. 기존 E·괄호 기대 좌표와 허용폭을 유지했다. 소스 커밋은 `c4ecf5b910a0ed62b4f3a93568133d3ed729bf8b`다. 최종 전쪽·fresh WASM·전체 게이트는 진행 중이며 전체 PR 완료를 주장하지 않는다.
