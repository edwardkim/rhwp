# 시행령 13쪽 첨자 뒤 본문의 줄 소속

## 원인과 독립 근거

원본은 `samples/issue6776/78494-virtual-convergence-industry-decree.hwpx`이며 실제 컨테이너는 HWP5다. 기준은 기존 `pdf/78494-virtual-convergence-industry-decree-2020.pdf`로 유지한다. 13쪽의 표 안 `(예외)` 문단은 본문 1100HU, 자간 −3%, `*` 위첨자를 저장한다. 독립 Print의 둘째 줄은 `… 이하인 경우에는 신고`, 셋째 줄은 `의무 면제`다. 기존 출력은 둘째 줄을 `신`에서 끝내고 `고`를 다음 줄에 밀었다. WMF·그림 문제가 아니다.

원 해결 PR #2771(`0a1e6bb294`)은 기존 0.7배 첨자를 공통 소비하도록 정리했다. #5756의 실제 통합 `d5f0f8dc96`은 본문 크기로 전진을 측정하는 오류를 고쳤지만, 0.7배가 모든 데스크톱 한컴의 정확한 배율이라는 독립 입증은 아니다. #8389(`c417310cab`)는 2024 Print 18조건에서 크기 0.64, 상향 0.44em, 하향 0.12em을 확인하고 `ScriptMetricsContract`로 측정·모든 paint를 연결했다. 다만 계약 선택을 2024 조판 옵션으로 제한해 2020/2022 HWP5·HWPX 경로에는 0.7배가 남았다.

이번 독립 대조는 맑은 고딕·한컴바탕·굴림 ×9·11·18pt의 9조건이다. 실제 한컴 2020 11.0.0.9136, Hancom PDF Print method 0, `hancom2020_pdf_driver_one_up`, 전처리 없음으로 1쪽을 출력했다. 9/18pt의 크기 비율은 0.64이며 11pt는 장치 양자화된 본문/첨자 Tf 92/59에 대응한다. 기준선도 같은 장치 격자에서 0.44em 상향·0.12em 하향과 맞는다. 사양은 위·아래 첨자 flag를 정의하며 이 수치를 규정하지 않으므로, 실제 검증 결과를 공식 사양의 상수라고 부르지 않는다.

`contract-summary.json`과 `pdf-script-observations.json`은 실제 PDF의 크기·원점을 기록한다. `script-size-2020-controls.hwpx`는 이 대조 입력이며, PDF는 [정식 보관본](../../../../../pdf/issues7733_7738_20261117/script-size-2020-controls.pdf)이다. 원본 시행령 PDF를 바꾼 자료가 아니다. 입력·PDF SHA와 실제 엔진 영수증을 함께 보관한다.

## 공통 보정과 검증 경계

`ScriptMetricsContract::for_profile`가 HWP3 계보를 제외한 HWP5·HWPX에서도 검증한 데스크톱 Print 계약을 선택하도록 보정한다. 기존 2024 계산식은 복제하지 않고 그대로 공유한다. HWP3 원본·호환 계보와 다른 입력은 기존 계약을 유지한다. 문서 ID·쪽 번호·글꼴 이름에 따른 분기나 폭 공차 변경은 추가하지 않는다.

생산자가 선택한 계약은 스타일 해소 → composer scalar 폭/kerning → 공통 text measurement → Native·Canvas·SVG·HTML·CanvasKit으로 전달된다. 마지막 문자나 좌표만 보정하지 않는다. 기존 저장 줄과 셀 소유·내용 보존 검사는 유지한다.

새 `issue_7737_decree_superscript_flow` 검사는 관계형이며 p13의 원문·줄 소속과 HWP3 계약 보존을 검사한다. 수정 전 실제 실행은 2건 중 1 PASS·1 FAIL(1.323초)이고, 실패 원인은 정확히 `신`/`신고`의 줄 경계 차이다. 수정 후 같은 최소 글꼴 검사는 2건 모두 PASS(1.298초)다. 최초 재실행은 suite 준비 파일이 이전 배정에 남아 0건 실행으로 종료했으며 통과로 세지 않았다. 준비 파일 재생성 후 위 2건의 실제 실행을 확인했다. 실제 Native/fresh WASM 출력과 보호 검증은 결과가 나온 뒤 추가한다. 이전 c895 전체 통과를 새 소스 통과로 인용하지 않는다.

## 5498 실제 출력의 확인 결과

보정 커밋 `5498d80a8e7e0b94c668a2aea48c20bb3bd214a5`의 Native/fresh WASM 각 252쪽 전체가 98% 이상이다. 13쪽은 양쪽 모두 100.00000%·미대응 0이며 같은 페이지 review/overlay를 직접 판독했다. `visual-5498/`에 10개 전쪽 TSV·producer·대표 PNG를 보관한다.

같은 source의 Native Skia 관련 검사 4 PASS(1.300초)도 확인했다. 다만 전쪽에서 18쪽 Native 99.95047→99.82190% 하락을 확인해 완료로 처리하지 않았다. 첨자 뒤 공백의 본문 em 계약이 별도로 누락된 원인을 `decree-script-space` 공백 보정 분석에서 검증한다. 이 5498 결과를 그 이후 소스의 전쪽 통과로 바꾸어 보고하지 않는다.
