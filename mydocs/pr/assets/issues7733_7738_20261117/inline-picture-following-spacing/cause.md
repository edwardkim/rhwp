# 저장 줄 없는 TAC 그림 뒤 간격의 예약·paint 정합

원본 시행령의 Section0 문단 193 → 6행 1열 → 중첩 1×1 표의 문단 12는 저장 줄이 없는
TAC 그림 호스트다. 그림 높이는 312.4px, 호스트 글자 크기는 13pt, 줄간격은 120%다.
기존 #6776 원 해결 b1127b3520·메인터너 보정 64f33cfc1c의 그림 상자와 TAC 표 간격 소유를 유지한다.

paint는 그림 뒤에 글자 크기×20%=3.46667px를 소비하지만 원자 CellUnit은 표 전용 질의로
그림의 그 간격을 0으로 기록했다. 뒤 본문은 맞는 위치에 그리면서 부모 하단선이 짧아졌다.

공통 호스트 글꼴 간격 계산을 재사용하고, 저장 줄 없는 원자 표·그림 유닛이 같은 결과를

실제 저장 줄·보이는 본문·다른 개체가 섞인 호스트는 새 질의에서 제외하고,
셀 마지막 문단은 기존처럼 뒤 간격을 예약하지 않는다. 문서·쪽번호 특례는 넣지 않았다.

변화량이 같음을 검사한다. 보정 전에는 본문 6.93333px / 표 0px로 실제 1 FAIL이었다.
보정 뒤에는 기존 TAC 표·그림과 앞선 보정까지 최소 글꼴 환경 117 PASS / 0 FAIL이다.
