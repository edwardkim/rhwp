# U+257A의 실제 공급 프로그램과 원점 보존

화학 원본 85·92쪽의 짧은 표식은 ASCII 하이픈이 아니라 `U+257A`다. 독립 한컴 2020
Hancom PDF Print의 92쪽 첫 두 표식은 Haansoft Batang, 1024 UPEM의 전진 1024와
오른쪽 사각 잉크를 사용한다. 실제 원문 BatangChe TTC 두 프로그램은 이 문자가 없다.
현재 검증용 HBATANG의 해당 hmtx와 기하 윤곽은 독립 PDF와 같지만, 중복된 길이 0 선
명령 때문에 원시 윤곽 명령 배열은 다르다. 전체 글꼴이나 PDF 파일 해시가 같다는 뜻도 아니다.

기존 공통 결측 글리프 측정·paint 공급 체인에 이 프로그램의 확인된 cmap/hmtx를 연결했다.
특정 문서·페이지나 보정 좌표는 추가하지 않았다. 실제 제공한 주 프로그램에 해당 글리프가
있으면 같은 family의 기준 파일 결측으로 대체하지 않는다. 첫 시도는 이 반례에서 실패했고,
현재 주 프로그램을 먼저 조회하도록 보완했다. 명시적 HFT 계약과 기존 공급자는 보존한다.

정식 검사는 `tests/cases/issue_7733_box_drawing_glyph_supplier.rs`의 관계 검사와
`issue_7733_box_drawing_marker_origin.rs`의 독립 좌표 고정 검사로 구분했다. 좌표 검사는
보정 전에도 Native/fresh WASM 각각 98% 이상인 92쪽의 독립 Print 원점과 뒤 본문을
±2px로 보호한다. 실제 프로그램 hit 반례는 자체 제작한 MIT 합성 글꼴을 명시적으로
공급하며 설치된 개인 글꼴을 읽지 않는다. private 글꼴은 Git에 포함하지 않는다.

최종 보정 전 6건 중 3 PASS·3 FAIL, 보정 후 6 PASS다. 관련 최소 글꼴 집중 검사
167건도 모두 PASS다. 전체 회귀·fresh WASM·보호 문서 gate 통과를 대신하지 않는다.

Native 전 252쪽은 58쪽 상승·194쪽 동일·하락 0쪽, 모두 98% 이상이다. 이 전쪽 비교는
휴먼모음T 원본 설치 전 결과와 설치 후 결과도 포함하므로 상승 전부를 이번 코드로 세지 않는다.
같은 새 글꼴 조건의 집중 대조에서 코드 변경으로 85쪽은 99.83880→99.90227%,
92쪽은 98.49337→98.55232%다. 휴먼모음T가 필요한 23쪽도 전쪽 실행에서 100.00000%다.

92쪽 review·overlay를 직접 열었다. 첫 두 표식은 같은 원점과 공급자의 잉크를 사용하고,
뒤 본문과 103쪽 쪽수가 유지된다. 아래 세 번째 표식은 PDF에서 별도의 Type3 프로그램과
18.96pt 크기를 사용한다. 이 차이와 다른 글리프·간격 차이가 남아 있으며 100% 완료로
판정하지 않는다. 해당 HFT 슬롯을 다음 보정에서 추적한다.

Native 생산 뒤 출처 주석 한 줄의 SHA를 현재 사용자 파일로 바로잡았다.
실행 코드 변경이 없다는 정확한 변경과 전후 파일 해시는 별도 영수증에 보존했다.
