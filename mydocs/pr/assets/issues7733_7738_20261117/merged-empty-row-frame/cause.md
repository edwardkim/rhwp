# 병합 행의 높이 0을 완성된 계산 결과로 보존

화학 원본 85쪽의 작은 `어린이보호포장` 표는 Native에서 독립 Print보다 약 4.47px 낮았다.
외곽 표의 위치와 본체 높이는 이미 같았다. 표의 기준선만 올리는 예외는 넣지 않는다.

한컴 2020의 동일 원본 HWPX 재저장에서 셀 선언·줄 높이·기준선이 원본과 같음을 확인했다.
그 저장본의 해당 셀 세로 정렬만 위/아래로 바꾼 독립 Hancom PDF Print 대조군은 각각
863.05599px와 945.20532px였다. 기존 기준 PDF의 가운데 정렬 904.13070px는 두 값의
중간과 0.00005px 이내로 일치한다. 같은 두 행 병합 칸의 시작과 작은 표를 담은 행의
시작은 한컴에서 일치한다. 이 대조군은 원인 진단용이며 기존 원본·기준 PDF를 대체하지 않는다.

현재 행 원장에서 r6은 8.33333px, r7은 108.01333px다. 앞의 병합 칸 내용이 자라기 전에
배정한 잔여 8.33333px가, 내용으로 다시 푼 원장 대신 남았다. 원 해결 #8755 통합 커밋
`5d3d8fcd5e`는 최장 경로로 요구 없는 행 높이를 0으로 허용했지만, helper의 반환값에는
과거 미지 행 검사인 `각 행 높이 != 0`이 남았다. 호출자는 이를 실패로 읽어 새 원장을 버렸다.

공통 solver의 성공 판정은 각 병합 높이 제약의 충족 여부로 바꾼다. 또한 #8641 통합 커밋 `5d5b386358`의 전체 높이 비교는 행 재배분의 합이 같으면
새 결과를 버렸다. 두 번째 가드는 요구 없는 행을 0으로 회수하고 전체 높이를 늘리지 않는
경우에만 새 행 원장을 보존하도록 보완한다. 일반 행의 기존 분배는 유지한다.

행별 최소 높이·
셀 선언·내용 하한·표 선언 높이를 바꾸거나 특정 문서의 px 오프셋을 추가하지 않는다.
측정과 배치는 기존 공통 solver를 그대로 공유한다.

새 관계형 검사는 원본의 같은 경계·쪽수·내용 소속을 검사하며 절대 PDF 좌표는 고정하지
않는다. 보정 전 실제 1 FAIL을 확인했다. 첫 성공 판정 보정만 적용한 집중 검사는 기존 160 PASS·새 경계 1 FAIL이었다.
총높이 비교까지 보완한 최종 집중 검사 161건은 모두 PASS였다. 선택 밖 8,993건을
전체 회귀 완료로 세지 않는다. 동일 소스 Native 전 252쪽에서 화학 85쪽만
98.46202→99.83880%로 상승했고 다른 251쪽은 동일했다. 전체 하락 0쪽, 98% 미만 0쪽이다.
전체 쪽수 103·71·3·74·1과 입력·PDF는 유지했다. 같은 85쪽 review·overlay에서
작은 표의 위끝·아래끝을 직접 대조했다. 남은 하이픈·가운뎃점 등의 미세 차이를
그림 차이라고 분류하지 않는다.
최신 fresh WASM·전체 회귀·보호 문서·실제 소비 경로 통과를 주장하지 않는다.
