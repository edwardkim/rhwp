# 첫 표 조각의 물리 상자와 병합 블록 행 목록 불일치

공식 형식 문서 Section3 문단 193의 번호 형식 표는 Common 첫 높이 27130HU를 저장한다.
원본 행 7의 설명 칸은 같은 문단의 줄 위치가 5180→0으로 되감기며 다음 쪽으로 이어진다.
조판은 이 저장 경계와 호스트 원점으로 첫 상자 361.73333px를 인증했다.

먼저 계산한 병합 블록 행 목록은 끝 행을 내용 높이 84.82667px로 기록했다. 이후 원본 첫
상자로 정규화하면서 끝 행 override는 95.69333px로 갱신했으나 행 목록은 그대로였다.
paint는 병합 블록에서 행 목록을 권위로 사용하므로 10.86667px가 유실됐다.
가운데 정렬과 표 아래 선이 함께 위로 당겨진 이유다.

인증한 첫 상자를 적용할 때 병합 블록의 같은 끝 행과 다음 조각의 실제 소비 원장을 함께
갱신한다. 내용 컷·글줄 소속·원본 PDF는 바꾸지 않는다. 문서명·쪽 번호 예외는 없다.
Native 공식 형식 문서 전 71쪽 비교에서 31쪽만 97.51239→100%로 상승했고 하락은 없다.
이어지는 32쪽도 100%다. fresh WASM은 31쪽 99.99919%, 32쪽 100%다. 새 관계형 회귀는 실제 물리 끝과 원문 소속을 검사한다.
테스트의 원문 비교에서 표시용 옛한글 정규화를 원문 PUA와 비교한 오류를 바로잡았다.
최소 글꼴 격리 환경의 3건 집중 검사에서 이 관계 검사와 따옴표 검사 2건 모두 통과했다.
Native 전체 252쪽에서도 이전 후보 대비 31쪽만 상승했으며 하락한 쪽은 없다.
전체 회귀·최종 fresh WASM 전쪽 검증 완료를 뜻하지 않는다.
