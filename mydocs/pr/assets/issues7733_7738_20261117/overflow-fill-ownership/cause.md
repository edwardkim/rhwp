# 소유 글줄의 후행 배경과 본문 넘침 진단

현재 제품 커밋 `211253376d20aa40c4cf223fdaabd87467e88240`의 최소 글꼴 전체 회귀는 13,773건 중 13,770 PASS·3 FAIL·45 skip, 실행 558.449초다. 세 실패는 기존 본문 넘침 원장의 partition 2·4·5다. 원장·문턱·대상은 수정하지 않았다.

[같은 최소 글꼴 조건의 base/head 직접 진단](base-head-comparison.json)에서 sample4 원본과 HWP5 저장본은 각각 0→13건, 연구계획서는 0→6건이다. 새 항목은 모두 본문에 수용된 줄의 후행 배경 Rect이며 글자·표·그림의 페이지 이동이 아니다. sample4의 독립 한컴 2020 Print는 해당 배경 끝을 실제로 본문 아래까지 그린다. [독립 PDF 벡터 좌표](independent-pdf-background-rects.json)는 sample4 26쪽의 배경 끝 약1014.571px와 연구계획서 11쪽의 흰 배경 끝 약1013.132px 등을 보존한다. 96DPI 환산 좌표는 원인 확인용이며 canonical PNG의 pdftoppm 판정을 대체하지 않는다.

원본 LH+LS 채움 복구를 되돌리거나 본문 넘침 상한을 올려 통과시키지 않는다. 배경의 실제 소유 글줄과 원본 후행 밴드를 진단 경로에도 연결하는 공통 계약을 검토한다. 본문에 수용된 줄이 소유한 선언 밴드와 독립 도형을 구분하되, 소유 줄 자체가 본문을 넘거나 채움이 선언 밴드를 넘으면 기존 넘침 진단을 유지해야 한다. 용지 밖(off-canvas), 글자·표·독립 도형의 실제 넘침을 감추지 않는 정상/반례 검사를 먼저 추가하고 보정한다. 이 문서는 원인 확인 단계이며 해결·전체 통과 판정이 아니다.

## 공통 소유권 보정과 반례 결과

본문 문단 배경에 소유 NodeId와 원본 밴드 끝을 내부 메타데이터로 연결했다. 진단은 같은 단의 실제 소유 글줄이 본문에 포함되고 채움이 선언 밴드를 넘지 않을 때만 후행 밴드를 허용한다. 비공개 필드는 JSON에 직렬화하지 않는다. 독립 도형·실제 글줄·밴드 초과는 기존 본문 기준을 사용하고 off-canvas는 여전히 실제 paint 범위를 검사한다.

새 관계형 검사는 실제 6 PASS·1 FAIL에서 7 PASS로 바뀌었다. 독립 도형, 넘친 소유 줄, 선언 밴드 초과, 용지 밖 채움이 계속 검출된다. 기존 본문 넘침 16분할 전체, CLI 기계 계약14건, off-canvas 13건, 기존 빈 글줄 4건, glyph/clip 12건과 함께 **집중 66 PASS·0 FAIL**다. [로그·원장 불변·검증 범위](validation.json)를 보존한다. derived suite 준비 전 0건 실행 두 개는 invalid로 분리해 통과나 red 근거로 쓰지 않았다.

원장·문턱·대상은 그대로이며 마지막 배경 paint 복구도 유지한다. 현재 결과는 집중 검증으로, 최종 커밋의 전쪽·전체 회귀·보호·실제 소비 경로 수용을 대신하지 않는다.
