# 첫 그림 줄의 뒤 간격과 저장 Common 상자

화학 원본 Section4 문단 129의 두 행 표는 Common 첫 높이 22873HU를 저장한다.
앞 행 2231HU + 첫 그림 줄 잉크 20360HU + 위·아래 안여백 282HU와 정수 단위에서 같다.
다음 그림 문단은 원점 0으로 다시 시작한다. 기존 측정은 닫는 첫 줄의 간격 720HU까지
더해 314.57333px를 예약했지만 독립 원본 상자는 304.97333px다.

원점 0만으로 물리 쪽 경계를 추정하지 않는다. 편집하지 않은 저장 그림 줄, TAC 그림의
원본 높이와 줄 높이 일치, 선행 행·안여백·Common의 정확한 닫힘, 동일한 실제 컷을
모두 인증할 때만 그 뒤 간격을 다음 소유자에 넘긴다. 그림 크기·내용 컷은 바꾸지 않는다.

최소 글꼴 환경의 실제 보정 전 검사에서 9.6px 차이로 실패했고, 보정 후 기존 반례를
포함한 집중 검사 26건이 통과했다. 다음 쪽 그림 두 개의 누락·중복을 확인하며, Common
높이가 1HU라도 맞지 않는 반례는 원점 0만으로 줄간격을 지우지 않는지 검사한다.
새 Native 전 252쪽의 정밀 비교에서 79쪽만 92.22271→99.98752%로 상승하고 하락은 없다.
80쪽은 100%를 유지했다. 79쪽 review·overlay의 실제 닫는 선과 세 그림의 소속을 판독했다.
