# 기존 글꼴 체인 회귀의 기대값 검토

## 검토와 결정

원 해결 [PR #6195](https://github.com/edwardkim/rhwp/pull/6195)는 한양견고딕·한양견명조가
바로 generic 글꼴로 떨어지는 것을 막았고, [PR #6305](https://github.com/edwardkim/rhwp/pull/6305)의
통합 `b489f8efc45fe109cf16ac553b61628a422f6e6d`는 그 우선순위와 호환 음절 전진을 검사했다.
기존 검사는 한양 이름과 별도 HY 이름이 바로 붙어 있어야 한다는 세 항목의 접두어를 고정했다.

[실제 설치 파일의 이름](font-name-inventory.json)을 대조하면 `HY Gyeongothic`과
`HY Gyeonmyeongjo`가 각각 현재 공급하는 한양 계열 OTF의 영문 이름이다. 문서의 HFT 선언과
실제 OTF(CFF) 파일은 구분한다. 이 이름을 요청 이름 다음에 보존하는
현재 코드는 적절하다. 따라서 제품 코드를 되돌리지 않고 기존 기대값 세 곳을 수정한다.

새 접두어는 한양 요청 이름 → 공급 OTF의 영문 이름 → 별도 HY 대체 → 그 대체의 영문 이름이다.
기존 HY 대체·generic보다 앞서는 우선순위와 bold 경로 검사는 유지하며, 허용 오차나 검사 수를
줄이지 않는다. 네 번째 메트릭 검사는 기존의 특정 음절 폭 비교를 그대로 유지하고,
그 사실이 두 파일·글리프 전체의 동일성을 뜻하지 않음을 주석에서 구분했다.
모두 문자열·메트릭 관계 검사이며 사설 글꼴과 실물 문서의 px 고정에 의존하지 않는다.

## 실제 검증

수정 전 전체 실행은 13,781건 중 13,778건 통과·3건 실패·45건 제외였다. 실패는 위 접두어 세 건뿐이다.
기대값을 수정하고 파생 suite를 새로 준비한 집중 실행은 기존 네 검사 모두 통과했다.
처음 집중 명령의 실행 0건은 suite 준비 누락이며 통과나 결함 재현으로 세지 않는다.
제품 소스·입력·기준 PDF·비교 문턱은 이 기대값 보정에서 변경하지 않는다.
수정한 검사까지 포함한 전체 회귀는 13,781건 통과·실패 0건·제외 45건이었다.
기대값을 보정한 세 검사와 기존 메트릭 검사까지 모두 통과했다.
