# 바탕 U+2027 결측의 실제 공급자와 뒤 본문 전진

화학 27쪽 '문자‧위치, 활자 크기‧색깔'의 원본 기호 슬롯은 TTF 바탕이다.
설치 Batang TTC의 실제 cmap에 U+2027이 없고, 독립 한컴 2020 Hancom PDF Print는
이 기호만 Haansoft Batang으로 출력한다. PDF xref28·glyph7과 HBATANG.TTF의
hmtx는 모두 178/1024em이다. 글리프 잉크 bbox에는 1~2 font unit 차이가 있으므로
원본 파일 전체·윤곽이 완전히 같다고 주장하지 않는다. 글꼴은 로컬 검증용이며 Git에 넣지 않는다.

선행 #8419의 6d81fb84ed는 바탕 U+2024의 결측·공급자를 확인했지만 U+2027은 근거가
없어 의도적으로 유지했다. 이번 원본·독립 Print 근거로 같은 공통 공급자 표와 원 프로그램의
cmap 결측 판정에 U+2027을 연결한다. 측정 결과를 기존 SVG·Native·Canvas의 낱글자
공급 경로가 소비하며, 특정 페이지의 본문 좌표를 당기지 않는다. 다른 weight·italic·HFT의
별개 계약과 실제로 제공된 원 프로그램의 cmap hit 우선순위는 유지한다.

수정 전 새 4검사는 1 PASS·3 FAIL이다. 공급자·최종 뒤 본문 원점도 실제로 실패했다.
첫 보정 뒤에는 정수 반올림 폭 API를 사용한 새 단위 검사 1개가 부적절하게 실패했다.
실제 글줄의 소수 글자 경계 API로 바로잡고 기존 4 HU 장치 격자의 반 칸(2 HU) 오차로
자연 폭을 검사한 결과 4 PASS다. 기존 독립 Print의 ±2px 뒤 본문 검사도 PASS다.
최소 글꼴 환경의 관련 기존·신규 185건은 185 PASS(28.215초)다. 전체 회귀는 아니다.

같은 일반 원본 글꼴 환경의 Native 전 252쪽을 다시 산출했다. 화학 27쪽은
99.25221→99.85809%, 미일치 422→79픽셀이다. 9쪽 상승·241쪽 동일이고,
정밀 raw는 45쪽 99.95394→99.95378%, 52쪽 99.98520→99.98516%다.
두 쪽의 미일치 수는 각각 44·15로 같으며 union이 줄어든 비율 차이다.
공식 두 자리 값은 각각 99.95·99.99로 유지한다. 정밀 하락 0이라고 숨기지 않는다.
전 252쪽 쪽수·98% 이상을 유지하며 네 다른 문서는 동일하다.
review와 overlay를 직접 판독했다. 아직 100%라고 보고하지 않는다.

보정 직전 058acd32a1의 fresh WASM 집중 결과는 27쪽 99.37167%, 92쪽 99.99451%다.
이것은 이번 U+2027 보정의 최종 WASM 결과가 아니다. 새 소스의 fresh WASM 전쪽·
전체 회귀·보호 문서·실제 소비 경로 검증은 이후 단계에서 완료한다.
