# 원본 HFT 기호의 전각 전진과 최종 잉크 폭

화학 92쪽 세 번째 U+257A 표식의 크기·상속은 앞 단계에서 복구했지만,
표시용 프로그램의 cmap 결측을 반각 추정으로 측정해 전각 fallback 잉크도 절반 폭에 눌렀다.
원본 SYMBOL 슬롯은 한양신명조 HFT다. 독립 한컴 2020 Hancom PDF Print의
Type3 T11은 /Widths=1000·FontMatrix=.001·CharProc d1=1000으로 전각 전진을 기록한다.
첫 두 표식의 Haansoft Batang과 세 번째 원본 HFT의 출처를 구분한다.

기존 원본 글리프 전진 조회에 이 검증된 HFT 폭을 추가했다. 원본 HFT 출처가 확인된
regular 한양신명조에만 적용하며, 다른 HFT·같은 이름의 TTF·bold·italic은 인증하지 않는다.
측정한 전진을 기존 목록 머리 배치와 최종 glyph-fit 칸이 함께 소비한다.
페이지별 좌표 보정·윤곽 하드코딩·기준 PDF 교체는 하지 않는다.

새 관계형 검사에서 수정 전 9건 중 8 PASS·전각 전진 1 FAIL, 수정 후 9 PASS다.
최종 paint 칸의 폭도 독립 Print 좌표로 검사한다. 관련 최소 글꼴 집중 180건은
180 PASS(20.274초)이며 전체 회귀 완료를 뜻하지 않는다. 첫 테스트 초안의 Arc 타입
컴파일 오류는 수정했으며 제품 결함의 수정 전 실패 근거에는 사용하지 않았다.

같은 원본·PDF·일반 원본 글꼴 환경의 Native 전 252쪽을 다시 산출했다.
화학 92쪽은 99.93984→99.99180%이며 미일치 44→6픽셀이다.
나머지 251쪽은 동일하고 이번 단계의 정밀 raw·공식 두 자리 값 하락은 모두 없다.
다섯 문서 최저는 화학 99.25221%, 사양서 99.68651%, 시행령 98.75022%,
개요 두 문서 100%다. review와 overlay를 직접 판독했다. 100%라고 보고하지 않는다.

잉크 공급자만 추가한 앞선 실험은 실제 점수가 변하지 않아 제출 후보에서 제거했다.

수용하지 않았다. 정상 측정의 글꼴 조건은 유지하며 페이지별 최고 점수를 섞지 않는다.
