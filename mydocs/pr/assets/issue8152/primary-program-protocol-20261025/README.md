# 주 글꼴 프로그램 선택 검사 정정

원본 프로그램이 실제 공급됐으면 조건부 공개 대체가 발동하지 않아야 한다는
PR #8191·#4966의 계약을 유지합니다. `f5d996e7034234bae17b0beece92a672d946c04d`가
동일 주 TrueType 프로그램의 신원을 조판 환경에 전달한 뒤에는 원본 face를 그대로
선택하는 환경도 생깁니다. 이 환경 자체를 공개 대체로 간주해 `null`만 요구하던
검사 2곳을 실제 선택·출처·원본 보존 검사로 정정했습니다.

- 제품 소스와 렌더링 기준은 변경하지 않았습니다.
- 공개 대상과 조건부 규칙이 선택되지 않으며 원본 이름·직렬화가 보존되는지 검사합니다.
- 존재만 확인한 source는 여전히 프로그램 공급으로 승격하지 않습니다.
- 집중 검사와 필수 lint/build 결과, 이전 전체 회귀의 정확한 실패 범위는
  [검증 원장](validation.json)에 있습니다. 새 head의 전체 통과를 주장하지 않습니다.
