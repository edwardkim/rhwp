# WMF 장치 클립과 실제 로고 보호

## 수정과 근거

WMF의 `INTERSECTCLIPRECT`가 DC의 기록에만 남고 실제 SVG 그림에는 적용되지 않았습니다.
같은 큰 비트맵으로 SVG의 내재 크기까지 늘어나 CBTA 표지에는 로고 외의 Windows 화면 조각이
작게 출력됐습니다. 클립을 지정한 시점의 창 원점·뒤집힌 축으로 장치 영역을 고정하고,
그림 출력과 표시 외곽 계산이 같은 영역을 소비하도록 공통 경로를 수정했습니다.
선택 영역과 교집합·DC 복원, 무클립 자동 확장, 반복 PNG 공유와 ROP 대조군을 확인했습니다.

## 독립 Print와 원문

원문은 한컴 2018 저장본입니다. 같은 원문의 새 한컴 2020 `11.0.0.9136` Print(method 0,
1-up)204쪽을 `pdf/issue6764/`의 형식·엔진이 명시된 정식 경로에 추가했습니다.
기존 PDF는 보존합니다. 두 PDF의 전 204쪽 추출 본문은 같고, 새 Print에는 원문 WMF의 로고가
보입니다. 32쪽은 같은 코드·같은 PNG에서 정답지 인쇄 차이를 확인한 것으로 코드 개선이 아닙니다.

## 실제 결과

- 같은 새 Print 대비 표지: Native 92.83705→99.99681%, fresh WASM 93.00110→99.99361%.
- 전 204쪽: Native 최저91.87422%, fresh WASM 91.82753%, 양쪽90% 미달 0쪽.
- 같은 기준으로 고정 devel·보정 직전 후보와 비교해 0.1%p 이상 하락 0쪽. 출력 PNG가 바뀐 쪽은 1쪽뿐입니다.
- 새 정식 검사 5건 PASS. 같은 검사 바이너리에서 CLI만 이전/현재로 바꿔 표지 2건이 2 FAIL→2 PASS입니다.
- WMF 정상 대조군27 PASS, 새 정답지 원장의 전체 partition 16건 PASS.
- 표지 로고 잉크 네 변은 독립 Print의 96 DPI 좌표 ±2 CSS px로 보호합니다. 생성 WMF의 수치는
  문서 화면 핀이 아닌 입력 레코드의 DC 계약입니다.

[검증 원장](validation.json)에 입력/정답지·producer·전후 실행과 직접 판독·잔여를 기록합니다.
원본 TSV와 대표 review/overlay는 같은 디렉터리에 있습니다. 48쪽의 기존 그림 획/대비 차이는
해결했다고 주장하지 않습니다. 현재 브랜치 전체의 최종 검증은 별도로 완료해야 합니다.
