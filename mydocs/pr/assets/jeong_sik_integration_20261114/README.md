# 그림 셀·본문 프레임 통합 검증

원 PR #7668 → #7675 → #7682의 누적 변경과 메인터너 댓글의 HWP/HWPX 대조군을 검증했다. 각 원 PR의 검토 기록은 `mydocs/pr/archives/pr_7668_review.md`, `pr_7675_review.md`, `pr_7682_review.md`다.

기준은 **한컴 2020 Desktop 11.0.0.9136 Print**이며 WebHwp 캔버스·PDF는 수용 기준이 아니다. [동일 입력·PDF 해시와 실제 Print 영수증](input-reference-pairs.json)을 보존한다. 저장 제품과 출력 제품을 구분한다.

공개 31종과 메인터너 대조군 2종은 각 1쪽이다. Native/fresh WASM 모두 최저 **99.97213%**, 90% 미만·누락·쪽수 불일치·고정 base 대비 하락 **0건**이다. 정상 설치 글꼴·compat2022·96DPI·색상 경계 보정 전 2px raw이며, PDF rasterizer는 pdftoppm이다. [전쪽 base/후보 대조](base-candidate-comparison.tsv) · [판정](base-candidate-comparison.json).

시각 producer는 `6f8d22ac95`의 실제 빌드다. 리베이스 후 head `728b368e35`에서는 HWP/HWPX 관련 10파일 해시가 같음을 확인해 기존 결과를 재사용했다. 이를 새 head 재출력으로 표기하지 않는다. 새 PDF CMap 변경은 집중 10건으로 확인했다. 새 head fresh WASM은 실제로 다시 빌드하고 Studio 초기화 응답까지 확인했다. [재사용 근거](rebase-reuse-audit.json) · [새 WASM](post-rebase-wasm-producer.json). Mac locked wrapper `--no-opt` 로컬 대체 빌드이며 Docker 최적화 결과가 아니다.

## 실제 출력 소비

5개 대표 입력의 Canvas2D·CanvasKit software screen/print 20건, Native SVG browser screen/print 10건, Native Skia screen 5건을 실제 캡처했다. CanvasKit 준비는 브라우저 Local Font Access의 실제 설치 글꼴을 사용했으며 fallback을 통과로 표시하지 않았다. 새 WASM 초기 응답 해시와 Vite의 한정된 URL 변환을 검증했다. HWP/HWPX 대조군 각각 밝기를 17로 편집한 뒤 HWP/HWPX 각 3회 반복 저장·재열기에서 편집값·2개체·전체 프레임 비겹침을 확인했다.
