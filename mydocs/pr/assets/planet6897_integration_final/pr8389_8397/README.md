# #8389·#8397 기존 TSV 대비 전쪽 비교

기존 PR에 보존된 정밀 TSV의 모든 기준 행을 입력과 쪽별로 현재 출력과 대조한다.
동일 문서·쪽이 두 기준에 있으면 각 기준을 별도 행으로 남긴다. 사용자가 지정한
Visual Sweep 소수 둘째 자리 표시값을 비교하며, 현재 표시값이 기준 표시값 이상일 때
통과로 판정한다. 본 표는 개별 PR 대상의 독립 Print 90% 게이트를 대신하지 않는다.

- 제품 코드: `d536455b4e`. 이후 커밋은 회귀 검사 이동·서식과 리뷰 문서 변경이다.
- Native 실행 파일 SHA-256: `d53e4dac28839e01f4c6bf19761c4bbc181ef70a7a38eb65abf6f6c4050b96fc`.
- 같은 입력과 독립 한컴 Print PDF를 96 DPI로 측정했다. 시스템 글꼴을 사용하고 기존
  Print 대체 글꼴 환경은 해당 원본에 적용했다. 글꼴 파일은 배포하지 않는다.
- 편람 HWP/HWPX에는 [대체 글꼴 설정](handbook-font-environment.json)을, sample16의
  2020/2024 기준에는 각각 [2020 설정](hwp3-2020-font-environment.json)과
  [2024 설정](hwp3-2024-font-environment.json)을 적용했다. 이 설정은 글꼴 프로그램을
  포함하지 않으며 나머지 입력은 별도 치환 없이 시스템 글꼴을 사용했다.
- [Native 전체 기준 행 대조](native-display-comparison.tsv): 2,153행, 중복 제거 후
  1,770쪽, 누락 0쪽, 표시값 하락 0행. 각 행에 원본 기준 TSV 경로를 남겼다.
- [fresh WASM 전체 기준 행 대조](wasm-display-comparison.tsv): 2,153행, 중복 제거 후
  1,770쪽, 누락 0쪽, 표시값 하락 0행. 동일 글꼴 설정의 편람과 나머지 입력의 완료된
  전쪽 결과를 대조했다. [sample10 전쪽 TSV](wasm-sample10.tsv)는 763쪽이고 최저 99.40%다.
- 동일 글꼴 설정의 [WASM 편람 HWP 전쪽 TSV](wasm-handbook-hwp.tsv)는 383쪽이며,
  두 기준 TSV의 총 766행과 대조한 결과 표시값 하락이 없다. 전체 최저는 99.96%다.
- 동일 글꼴 설정의 [WASM 편람 HWPX 전쪽 TSV](wasm-handbook-hwpx.tsv)는 383쪽이며,
  기존 기준과 대조한 결과 표시값 하락이 없다. 전체 최저는 99.96%다.

WASM 편람 145쪽은 대체 설정을 빠뜨린 실행에서 HWP와 HWPX 모두 99.99%로 표시돼
기존 기준 100.00%보다 낮았다. 같은 최종 제품 코드·독립 Print에 위 편람 설정을 적용해
해당 쪽을 별도로 재출력하니 HWP와 HWPX 모두 100.00%였다. 이 선택 쪽 결과는 동일한
설정의 전쪽 검증을 대체하지 않는다.
