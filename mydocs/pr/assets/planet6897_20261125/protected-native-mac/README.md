# 시행령·중첩 표 Native 보호값 조정 근거

동일한 입력, 한컴 Print PDF, 글꼴 파일 순서와 SHA-256을 사용해 수정 전
`049fd5ed2fa1`과 후보 `8355876d60cb`를 대조했다. Native Skia, 호환 세대
2022, 96 DPI, 2px 이웃 raw 실루엣으로 시행령 74쪽과 중첩 표 17쪽 전부를
측정했다. 두 실행의 PNG 바이트와 공식 소수 둘째 자리 점수가 91쪽 모두
일치했다. Mac 설치본 `pala.ttf` 공급 전후에도 이 두 문서의 Native 점수와
PNG가 동일했다. [입력과 실행 해시](validation.json)

표의 Native 14행을 각각 실측값으로 조정한다.

Native와 WASM 합계 392쪽에서 0쪽이었다.
