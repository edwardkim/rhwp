# #6844 보조 기대의 독립 검토 초안

## 유지할 원래 결함 검출

원 해결 커밋 `c1a1a5dcf3`은 글리프가 자기 bbox 밖에 그려지는 API 기하 결함을 고쳤다.
원 예시의 폭78.0과 실제 문자 경계98.3의 불일치는 첫 번째 기존 검사로 계속 거절한다.
이 검사는 변경하지 않는다. 특정 문서의 숫자를 강제로 옮겨 검사에 맞추지 않는다.

## 재검토할 가정

두 번째 기존 검사는 서로 다른 문자 스타일·저장 탭 전진을 가진 모든 목차 숫자의
bbox 우단이1px 안에 모여야 한다고 가정한다. 독립 Print에서 관측한 실제 숫자 원점과
저장 탭 폭의 변화를 대조해야 하며, 잉크 bbox를 문자 전진 bbox로 혼동해서는 안 된다.

정확한57a38 Native 출력에서 저장 폭만+20px로 바꾼 사본도 원본과 같은 PNG가 나왔다.
독립 한컴 Print에서는 같은 변경으로 숫자가+20px 이동했다. 새 공통 보정은 이 입력의
저장 전진 소유를 복구하며 Native2쪽98.11→98.52%, 권고안4쪽99.86→99.96%로 개선했다.
새 소스의 기본 문자 배치 API에서 숫자 우단의 편차는1.3px이며, 원래 bbox 포괄 검사는 통과한다.

## 수정 예정 관계

fresh WASM도 같은 쪽을98% 이상으로 검증하고 같은 쪽 review/overlay를 직접 판독한 뒤,
두 번째 검사를 각 숫자 런의 bbox 끝과 그 런의 실제 charX 끝이 일치하는 관계로 바꾼다.
이 관계는 원래처럼20.3px 짧은 bbox뿐 아니라 지나치게 넓어진 bbox도 거절한다.
첫 번째 검사·최소6개 숫자 수집·탭 뒤 가시 문자 존재 검사는 유지한다.
기존1px 문턱을2px 등으로 늘려 통과시키는 방식은 쓰지 않는다.
새0.2 차이 허용은1자리 소수 JSON의 두 경계 반올림만 흡수하며 실물 절대 좌표 핀이 아니다.

353989의 Native/fresh WASM 전쪽과 같은 쪽 직접 판독을 확인한 뒤 보조 검사를 교정했다.
원래 bbox 이탈 검사는 바꾸지 않았으며 교정한2개 검사 모두 통과했다.
짧은·넓은 출력 변이의 음성 대조는 각각2개·1개 실패했다.
최소 글꼴 정식 suite와 새 최종 소스의 전체 회귀는 별도로 실행한다.
