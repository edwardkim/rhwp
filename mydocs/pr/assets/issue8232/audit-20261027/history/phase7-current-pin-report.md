## #8232 추가 조사 — 원본 계약과 고정 위치의 분리, 8조건 전쪽 대조

전수 조사는 계속 진행 중입니다. 고정 head는 `238de6de41a208648f4ade6b494fe433a81c1fce`이며, 제품·테스트 수정과 이름 변경·PR 제출은 아직 없습니다.

앞선 추가 조사 이후 integration 140함수/helper의 전체 단언·호출 목록과 필요한 source/helper 문맥을 대조했습니다. 국소 수치 의미가 단위·원본·상대/동등 계약인 70그룹과 독립 근거를 더 연결해야 하는 70그룹을 구분했습니다. 이는 확정 위반 수나 전체 호출 경로의 적합 판정 수가 아닙니다.

예를 들어 원본 13pt·160%에서 유도한 상대 줄 전진, 밑줄 조각의 실제 접속, 원본 HU 여백과 셀 내부 포함, 글꼴 em/cluster advance와 같은 계약은 실물 페이지의 절대 좌표 고정과 다릅니다. 반대로 상대 비율이라는 이름만 붙인 경험적 배치 상수, 좌표·폭으로 대상을 고르는 selector, 과거 결함 좌표의 부재만 보는 검사도 근거를 확인합니다. 합성 차트나 합성 세로표의 최종 bbox를 소수점 이하까지 고정한 경우도 합성이라는 이유로 심사를 면제하지 않습니다.

### #1133은 허용폭만 바꾸면 검출력이 사라집니다

실제 대상 2·3쪽 Native review와 WASM overlay를 직접 대조하고, 독립 PDF의 stroke path에서 다음 좌표를 다시 읽었습니다.

- 2쪽 첫 조각 상단 440.478678 / 하단 1042.539998 CSS px
- 3쪽 이어받기 상단 77.356038 / 하단 296.156006 CSS px

HWP/HWPX 원본의 출력 PNG와 독립 PDF PNG는 각 backend 전 3쪽에서 hash가 동일했습니다. 판독 재사용은 이 동일 픽셀과 현재 producer를 근거로 연결합니다. 2쪽 순서도와 일부 글자의 미세한 차이는 남으며, raw 100%를 엄격한 RGB 일치로 해석하지 않습니다.

기존 함수는 이 좌표를 ±0.6/±1.3으로 검사합니다. 현행 ±2 CSS px로 공차만 넓히면, 원 보정 기록의 잘못된 상단 439.066667/75.573333도 독립 기준과 차이가 약 1.4/1.8px여서 통과합니다. 이 수학적 단언 대조는 과거 engine을 새로 실행한 결과와 구분했습니다.

따라서 원본 141HU 바깥 위여백의 첫/이어받기 프레임 소유와 실제 예약·배치 소비, 행·내용·후속 문단 보존을 관계로 보호하고, 자격을 확인한 독립 좌표만 ±2 CSS px로 대조해야 합니다. 원 해결 #7382와 실제 보정 `f07affc3607e858aa83909465fa453626be6acf9`, 후속 분리 `fff5310762b8642fa4ef39135274970e3616e9f1` 및 현재 원본·출력을 연결했습니다. 이 helper는 공차 보정 대상임을 확정했지만 아직 재작성하지 않았습니다.

새 진단 driver는 HWP3에 저장제품 메타데이터가 없다는 처리를 누락해 4조건 뒤 한 번 중단됐습니다. 같은 작업 범위에서 원본 format을 확인하는 분기를 수정했고, 완료한 source/build/input/PDF hash를 검증해 나머지만 재개했습니다. 실패 로그를 보존했으며 완료한 4조건을 중복 실행하지 않았습니다.

전수 판정과 간접 호출·조건부 경로의 대조는 미완료입니다. 필요한 검사 보정과 `issue_8232` 명명·실제 등록/검출력 재검증도 남아 있습니다. PR은 나중에 진행합니다.
