# #8232 전수 조사 177차 기록

기존 수식 6개·HF 편집 4개 검사와 helper 10개를 직접 검토하고 현재 Native 10 PASS/0 FAIL/0 ignore를 확인했다. 176차에서 준비한 현재 suite를 재사용했으며 이 단계의 추가 빌드·PNG 캡처는 없다. 사용자 제외 신규 두 수식 검사는 실행·판정하지 않았다.

원본 HU·논리 em·편집 전후 동일 원점·셀 포함·내용 소유·문자 event 좌표를 실제 페이지 px 핀과 구분했다. 독립 한컴 Print의 baseline 편집 3쌍은 drawing stream이 동일했고 HFT percent의 실제 Type3 논리 칸은 1000/1000이다. 설치 TTF 853/1024 자연 폭과 혼동하지 않았다. 이 독립 자료를 현재 head의 PNG/fresh WASM 통과로 재인용하지 않는다.

기존 완료 분수의 ±2px 핀은 별도 현재 시각 자격 대기 상태를 유지한다. 보정 필요 누계는 205개이고 제품/테스트 수정·개명·외부 게시가 없다. 전체 감사는 미완료다.
