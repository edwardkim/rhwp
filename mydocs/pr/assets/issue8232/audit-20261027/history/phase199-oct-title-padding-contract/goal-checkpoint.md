# #8232 전수 조사 199차 기록

보류 중인 제목 4px 검사를 원 설계·후속 기대값 변경·실제 통합·현재 Native 실행과 연결했다. 이는 합성 커서의 명시적 여유 정책에 대한 단위 산술이며 실물 문서의 절대 좌표 핀과 구분한다. 현재 독립 2022년 10월 HWP/HWPX 16쪽의 문30·첫 본문 줄은 같은 왼쪽 단에 순서대로 포함된다. Native 네 개 PASS이며 추가 빌드가 없다.

직접 관련된 실제 후속 반영은 PR #1292 로컬 통합 51a319b이다. 앞 release #1294에는 뒤의 4px 기대값 변경이 없음을 확인했다. 2023년 9월 19쪽은 관련 대조 사례일 뿐 이 명목 정책의 직접 출처로 쓰지 않는다.

보류 한 개를 해소해 전체 증거 보류는 546개, 이 커서의 잔여 보류는 11개다. 보정 필요 213개와 직접 점검 누계 15123개는 그대로다. 페이지의 모든 수식 정합 또는 새 실물 px 핀 자격 완료를 주장하지 않는다. 소스/검사 수정·개명·외부 게시가 없으며 전체 감사는 미완료다.
