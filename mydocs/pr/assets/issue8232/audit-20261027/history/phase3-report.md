아직 전수 의미 심사와 보정이 완료되지는 않았습니다. 현재 작업 브랜치는 `audit/8232-px-regressions-20261025`, 고정 source head는 `238de6de41a208648f4ade6b494fe433a81c1fce`입니다. 제품 코드·테스트의 변경과 PR 제출은 아직 없습니다.

### 숫자 검색에서 빠질 수 있는 검증 경로

1. 앞선 literal 우선 후보88그룹에 포함되지 않았던 **127파일**의 부동소수 상수와 기하 단언 문맥을 추가로 읽었습니다. 40파일에는 절대 페이지 좌표·고정 영역·고정 좌표 selector의 재검토 지점이 있고, 87파일의 검토 지점은 원본 HU·glyph metric·합성 입력·객체 간 관계입니다. **40은 확정 위반 파일 수가 아니며, 87도 파일 전체 적합 판정이 아닙니다.** helper의 기대값 출처와 실제 페이지 자격을 각각 연결하고 있습니다.
2. 지역 `let` 기대값도 별도로 수집했습니다. 상수 선언만으로는 놓치는 좌표 튜플·배열을 포함한 데이터 의존 후보2,133지점/397파일이며, 그중 literal·배열·튜플152지점을 우선 심사합니다. 이 숫자도 결함 수가 아닙니다.
3. Studio E2E의 기하 후보 **47그룹/131지점**을 읽었습니다. `embed-svg-profile.test.mjs`의 번호x86.673024±2, `tac-prefix-page-handoff-issue7491.test.mjs`의 표y69.844±0.5, repaint helper의 cellBounds.h945.9처럼 실제 문서의 좌표/프레임 크기를 간접 고정하는 경로도 심사 대상입니다. 커서 문자 offset, DOM 투영, 실제 셀 포함, 편집 전후 이동과 합성 PaintOp 수치는 별도로 구분합니다.
4. 숫자 기하 후보 목록 밖에서도 렌더 출력을 만드는399함수/257파일을 찾아 기대값의 문자열·helper 경로를 추가로 대조하고 있습니다. 최초2,707그룹만 조사하고 전수 완료로 처리하지 않습니다.

### 기존 검사 자체의 반례

`tests/issue_1105.rs::task1105_k_water_rfp_2024_cover_hides_first_page_footer`는 특정 좌표·stroke를 모두 포함한 `<line .../>` 문자열이 없는지만 검사합니다. 같은 선의 y를 **1CSSpx만 옮겨 보이게 한 구성 반례**에서도 기존 부재 조건은 참입니다. 따라서 이 조건만으로 꼬리말 비표시를 검증할 수 없습니다.

이것은 **단언 수준의 구성 반례**이며 Native 엔진에 결함을 재주입해 실행한 결과로 주장하지 않습니다. 원본 source SHA와 정확한 단언·반례를 로컬 감사 자료에 고정했습니다. 실제 보정에서는 독립 근거에 따른 첫 쪽 꼬리말의 소유·가시성 및 정상 대조군을 검사해야 합니다.

`tests/issue_501.rs::mel001_pi22_row0_height_matches_ir`도 행 높이를 확인하기 전에 `x="212.9333333333333"` 문자열로 셀을 찾고 y600~800을 요구합니다. 원본1980HU 행 높이 계약과 관계없는 위치 locator가 섞여 있으므로 원본 표·셀 소유 경로로 재검토합니다.
