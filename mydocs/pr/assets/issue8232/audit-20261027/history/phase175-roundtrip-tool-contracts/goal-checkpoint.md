# #8232 전수 조사 175차 기록

HWP5/HWPX roundtrip 도구 검사 19개와 helper 한 개를 기존 동일 소스 Native 산출물로 실행·검토해 19 PASS/0 FAIL/0 ignore를 확인했다. 실제 현재 컴파일 입력과 binary hash를 재확인했고 추가 빌드는 없다.

인자·경로·보고 문자열·작성 Option 쪽수·CFB 오류·확장자 수집의 계약을 실물 페이지 px 핀과 구분했다. 조건부 smoke는 현재 입력 존재를 확인했으며 빈 목록이나 조기 return을 실제 검사로 세지 않았다. blank HWPX는 현재 CLI 저장본과 독립 ZIP/XML의 section·문단·표·text를 대조했다. 구조 PASS를 한컴 Print·전쪽 시각 일치로 확대하지 않는다.

제품/테스트 수정·개명·외부 게시·추가 빌드가 없고 보정 필요 누계는 205개다. 전체 감사와 166차 전쪽 검증은 계속 진행 중이다.
