# 원 PR에 공개된 악화 사례의 독립 대조 입력

이 자료는 #9001·#8959 본문에 고지된 원본을 같은 통합 후보에서 확인하기 위한 근거다.
원 PR의 주요 해결 샘플과 구분하며, 이 자료 보존은 통과·해결·이슈 종료를 뜻하지 않는다.

- 원본 파일 식별자·SHA와 독립 Print 영수증: [inputs-and-print.json](inputs-and-print.json).
- PDF는 실제 한컴오피스 **2020, 11.0.0.9136**의 Print 경로, MCP `engine 2020`, `pdf_print_method 0`으로 산출했다.
- 웹한글기안기 PDF나 rhwp 출력물을 한컴 기준으로 사용하지 않았다.
- 식량 보고서: 독립 Print 141쪽, 고정 devel 143쪽, 보정 전 통합 후보 144쪽. 기존 #8997과 같은 원본이다. 추가 1쪽의 원인과 실제 조각 배치를 확인 중이다.
- 건강 보고서: 독립 Print와 두 코드 모두 7쪽. 원 PR이 고지한 6쪽 악화는 동일 PDF로 다시 확인한다.
- 원본·PDF는 유지한다. 진단 스크립트·SVG·로그와 비공개 글꼴 바이너리는 이 자산에 포함하지 않는다.
