2026-11-28 KST에 기준 `274ae9d4c8` 위의 Native 빌드를 최소 글꼴 환경에서
`rhwp export-render-tree --compat 2022`로 실행했다. 실행 파일 SHA-256은
`803f74fe4c8aae4b51798689ffb6398bab310cf7722df4d1ea41abccc9720b0f`이다.

- #7821. 앞 인라인 표의 뒤 여백 140HU, 저장 줄간격 840HU, 부동 표의 오프셋
  937HU와 위 여백 141HU의 합은 27.44px이다. 한컴 Print에서 두 괘선 사이 거리는
  27.49px이다. 뒤 인라인 표가 저장 줄을 독립적으로 차지하고 앞 부동 표가 셀 안에서
  원본 좌표를 새로 시작함을 확인해, 앞 인라인 줄의 간격 전량을 공통 배치에 남긴다.
  세 번째 표의 위끝은 976.9px에서 982.5px로 이동했다. 한컴 Print의 용지 높이에 비례해
  같은 좌표계를 적용하면 차이는 0.1px 이하이다.
- #7831. 앞 호스트의 저장 줄과 새 쪽의 자식 표는 다른 원점을 소유한다. 자식 본체
  63,896HU와 바깥여백 566HU가 종료 빈 줄의 저장 위치 64,462HU와 같다. 이 줄을
  자식 표가 있는 컷에 포함하고, 마지막 줄의 실제 하단 65,562HU를 수용과 가운데 정렬이
  함께 쓴다. 23쪽 자식 표 위끝은 127.3px이고 한컴 Print는 127.22px이다.
  22쪽과 25쪽은 앞 후보의 전쪽 측정에서 각각 100.00%였다.
- #7864. 번호 제어 하나가 남은 두 파일은 번호 줄 뒤에 첫 표가 있어도 두 표의 제어
  위치가 하나의 저장 슬롯에 모인다. 각 표의 본체와 여백 합이 순서대로 저장 줄 높이를
  닫으면 그 물리 줄의 가로·세로 원점을 사용한다. 두 파일 모두 첫 표는 x=81.2px,
  y=257.2px이고 둘째 표는 x=78.1px, y=433.1px이다. 같은 입력으로 저장한 독립
  한컴 Print 및 원본과 네 대조군의 실루엣은 이어서 측정한다.

정식 제출에는 이 페이지들의 전쪽 Native와 fresh WASM 증적을 사용한다.
