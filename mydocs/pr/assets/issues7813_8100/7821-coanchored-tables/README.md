# #7821 공동 앵커 표의 첫 조각과 인라인 표 순서

한컴 Print 1쪽에는 선행 인라인 표 두 개와 그 뒤 RowBreak 부동 표의 첫 두 행이 나온다.
같은 호스트의 뒤 인라인 표가 바로 소유한 저장 줄 높이를 먼저 수용하면, 새 쪽에서 시작할 그
인라인 표 때문에 앞 부동 표의 첫 두 행도 밀린다. 첫 행 수용 여부는 실제 부동 표의 원점과
선언 프레임으로 판단한다.

인라인 표의 사전 fit을 확인할 때는 실제로 앞선 부동 표가 남아 있는지 제어 순서로 판별한다.
부동 표의 첫 조각을 수용할 때는 공동 앵커 줄을 뒤 인라인 표가 소유하는지 확인하고, 조각의
이미 계산된 물리 원점을 사용한다.

이전 기준 `ca96e9f342`의 Native 전3쪽 최저는 33.99%였다. 2026-11-28 KST의
96dpi 진단 후보는 1쪽 85.91%, 2쪽 100.00%, 3쪽 98.16%였다. 1쪽에서 남은 차이는
세 번째 표의 위끝이다. 앞 인라인 줄의 후행 간격 전량과 실제 앞 표의 하단을 대조하고 있으며,
최신 기준 리베이스 뒤 원본 전체를 다시 측정한다.
