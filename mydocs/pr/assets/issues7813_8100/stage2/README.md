# 2단계 저장 줄이 없는 연속 표의 첫 조각

#8100의 #7677·#7678 HWPX에서 저장 줄이 없는 호스트 첫 표가 뒤 본문의 문단 앞 간격까지 차지했다.
한컴 Print의 5쪽은 표 첫 조각을 먼저 배치하고 호스트 본문은 마지막 표 조각 뒤에 놓는다.
`host_spacing::resolve`가 이 조건을 확인해 앞 예약에 표의 바깥 위 여백을 적용한다.
5쪽의 분할 예산에 뒤 본문의 앞 간격이 추가되지 않아 원본과 같은 첫 조각을 수용한다.

## #7677·#7678 첫 조각의 바깥 위 여백

두 형식의 원본에서 표 제어 위치는 호스트의 첫 글자 앞이다. 호스트 글줄은 마지막
조각 뒤에 배치된다. 앞 본문 뒤에서 시작하는 첫 조각은 스캔이 확보한 위 여백
140HU를 배치 원점에도 사용한다. 5쪽 표의 위끝이 755.8px에서 757.7px로 이동했다.
한컴 Print와 대조하면 빠졌던 가로 괘선 세 곳이 같은 높이에서 검출된다.

2026-11-28 18:19 KST에 기준 `274ae9d4c8` 위의 단계 후보를 앞 절과 같은 원본,
한컴 Print와 96dpi 조건으로 대조했다. Native 실행 파일의 SHA-256은
`7aeb7f7031cc303ab63d54465a83c728c3f48db7163eebf47be7d5f7fe23f5bc`이다.
