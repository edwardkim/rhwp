## 저장과 최신 devel의 동작

Studio에서 원본을 HWP와 HWPX로 두 세대씩 저장하고 다시 열었다. 양쪽 소스에서 나온 저장본 8개 모두 원래의 37쪽, JPEG 15개, 각각의 압축 바이트 SHA-256, 안내판 방향 값 6을 보존했다. 각 저장 보고의 손실 항목은 0개다. 한 쪽 대조군 세 가지에서 만든 보완본의 저장본 12개도 원래의 JPEG 바이트가 모두 같다. [37쪽 저장본 8개](full-source-roundtrip.tsv) · [한 쪽 저장본 12개](roundtrip-jpeg.tsv)

#9393에서 바뀐 법률 개정 이유서 52쪽과 동물복지 사육관리 지침 12쪽을 동일 입력·독립 한컴 PDF로 대조했다. 사육관리 지침은 기본 인쇄와 원본 BMP 색 보존 옵션을 각각 검사했다. Native 76쪽, WASM 76쪽 모두 기준·후보 PNG가 바이트 단위로 같다. [통합 전후 쪽별 수치와 해시](incoming-9393.tsv)
