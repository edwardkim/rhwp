## 원 PR별 변경 영역

- **#9352**의 흰 사각형 내부에서 표 오른쪽 괘선이 보이던 130개 가로줄이 0개로 줄어 한컴과 일치했다. 도형을 글 뒤로 보내면 130개 모두 다시 보인다. 사각형 위 65줄과 아래 60줄에서도 괘선을 확인했다. [괘선 측정](rule-visibility.tsv) · [확대 비교](9352-placement.png)
- **#9384**의 오른쪽 정렬 대조에서 두 번째 사진이 첫 사진과 같은 높이에 그려지던 80px 겹침이 사라졌다. 한컴·Native·브라우저 모두 앞 사진의 하단과 뒤 사진의 상단이 맞닿는다. 가로로 맞닿는 사진은 같은 높이에 남는다. [가로 겹침과 세로 간격](picture-spacing.tsv) · [확대 비교](9384-placement.png)
- **#9407**의 아래 여백 10mm 대조에서 두 번째 쪽은 한컴과 같은 26번 행으로 시작하고 35번 행과 뒤쪽 `TAIL ROW`를 표시한다. 긴 용지에서는 중첩 36행과 본문 `END`가 모두 첫 쪽에 들어가고, 다음 쪽에는 바깥 표의 뒤 행만 남는 경계도 확인했다. [쪽별 행과 후속 내용](row-ownership.tsv) · [확대 비교](9407-placement.png) · [측정·배치의 공통 경로](placement.md)

## 영문 글꼴과 인쇄 용지

제출된 분할 HWP의 영문 글꼴 표는 비어 있다. 한컴 2024는 한컴바탕, rhwp는 한글 슬롯의 함초롬바탕을 골랐다. 원본 두 쪽의 Native 값은 95.98%·96.21%, WASM은 96.56%·96.62%다. 영문 슬롯에 한컴바탕을 명시한 대조본과 한컴으로 다시 저장한 문서는 모두 100.00%였다. 작업지시자의 결정에 따라 HWP 5 기본 글꼴 선택은 별도 검토로 남겼다. [글꼴 하나를 바꾼 직접 인쇄와 쪽별 측정](hwp5-latin-slot.tsv)

용지 높이만 바꾼 8개 문서·15쪽에서 한컴과 두 렌더러의 중첩 행 번호와 순서, `TAIL ROW`·`END`의 쪽 소속이 모두 같았다. 원본이 1,033pt인 대조군 한 개는 한컴 2020과 2024의 Hancom PDF 프린터가 모두 1,031pt 용지로 출력했다. 첫 쪽 원래 좌표의 일치율은 Native 96.84%·WASM 97.12%이며 두 번째 쪽은 100.00%다. 인쇄 PDF를 원본 용지 좌표로 환산한 별도 비교에서는 두 경로 모두 100.00%였다. [Native 인쇄 좌표](paper-coordinates-native.tsv) · [WASM 인쇄 좌표](paper-coordinates-wasm.tsv) · [첫 쪽 아래 괘선 확대](paper-1033pt-print.png)
