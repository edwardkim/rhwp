# PR #7460 IR field sweep 입력 코퍼스 동일성

수집 규칙에 따라 열거했습니다. `samples/**`의 HWP 전체와 `samples/hwpx/**`의 HWPX 중
`opengov` 디렉터리를 제외한 목록입니다. full mode의 파일 후보이며,
실제 parse/format/distribution/roundtrip 제외 규칙은 기존 테스트에 따릅니다.
