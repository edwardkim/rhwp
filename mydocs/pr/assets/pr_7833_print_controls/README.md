# 최소 셀 폭·주석 소유 대조군의 재현 자료

기존에 검증하던 16개 대조군의 입력, 독립 한컴 Print PDF와 Native/fresh WASM TSV를
보존한다. [자료 목록](sources.json)에 실제 파일 경로·크기·SHA-256, 생성 조건과
한컴 Print 정보를 기록했다. 새로운 실제 문서로 검증 범위를 넓히지 않는다.

## 입력과 기준 출력

- `parent-frame` 8개는 #7833의 기존 셀 경계 복사·삭제 사례에서 파생했다. 중첩·평탄
  선택, 그림·글자처럼 취급하는 표, 삭제 전·후를 조합한다. 수동으로 이동한 문단의
  저장 조판 정보를 무효화하고, 그림 대신 만든 표의 셀 격자를 공통 상자 폭과 일치시킨
  진단 사본이다. 원래 생성기의 8개 입력과 그 Print PDF는 별도로 유지한다.
- `note-owner` 8개는 `가가🦦나끝`에 각주·미주, 삽입 위치 0·1, 같은 위치의 인라인
  그림 유무를 조합한다. 본문을 중첩 셀에 옮긴 뒤 소유 프레임이 달라진 저장 조판
  정보를 무효화했다. 파일명의 `valid-false`는 미주, `valid-true`는 각주 분기이며,
  시각 검증의 성공·실패를 뜻하지 않는다.
- 각 입력을 따로 한컴 2020 MCP의 Print 경로로 출력했다. 입력 내용을 바꾸거나
  진단 사본의 PDF를 원래 입력의 정답지로 대체하지 않았다. 인쇄 방식은
  `pdf_print_method=0`, `hancom2020_pdf_driver_one_up`이다.

이미 정식 경로에 있던 최소 물리 셀 폭 입력과 PDF는 재사용했다. 나머지 15쌍은
`tests/fixtures/pr7833_print_controls/` 및
`pdf/semanticist21-20261019/minimum-cell-controls/`에 보존했다. 각 파일의 실제 경로는
`sources.json`을 따른다. 50 MiB 이상 PDF는 없다.

## 검증 범위와 시점

`b4aca422ec2a5842e5b15182ca865059a456ab5c`의 Native273·최적화 fresh083에서
16개 조건 모두 각각 1/1쪽이며 전쪽 raw 실루엣이 90% 이상이었다(4512).
그 실행의 TSV 원문을 `native/`·`wasm/`에 바이트 그대로 보존했다.

현재 후보 `df65ef9a58`의 재실행은 4524에서 진행한다. 이 자료 보존을 새 후보의
검증 완료로 보고하지 않는다. 최종 제출 전 새 실행 결과와 증적의 source를 정렬한다.
기존 최소 폭 회귀의 독립 가로 경계와 내용·칸 여백·연결·순서 검사는
[최소 물리 셀 폭 증적](../pr_7833_minimum_cell_width/README.md)에 있다.
진단 대조군의 통과가 원본 입력의 직접 판독이나 기존 정확한 회귀를 대신하지 않는다.

실행 명령은 각 `captures`에 기록했다. 임시 output 경로를 사용한 실행도 정식 입력·PDF와
SHA가 같아야 한다. 로그·중간 JSON은 Git에 포함하지 않는다.
