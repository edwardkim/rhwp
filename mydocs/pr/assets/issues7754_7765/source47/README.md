# 독립 한컴 전 글자표의 중고딕 공급 자격 확인

이 자료는 리베이스 전 Source37 producer를 사용한 글꼴 공급 진단이며 새 head의 검증을
대체하지 않는다. SPJGT의 cmap은 893개로 `화`·`학`을 포함한 현대 한글 본문을 포함하지
않는다. 기존 독립 한컴 중고딕 글자표의 11,187개 문자를 먼저 검증하고 비어 있지 않은
11,186개 원 글리프를 같은 윤곽·전진폭으로 개인 검증용 CFF에 보존했다. 빈 U+2027은
계속 제외한다. 대상 문서의 PDF·배치·점수를 글꼴 생성의 입력으로 쓰지 않았다.

독립 `화`의 1,000 em 윤곽 범위는 `(86, -46, 960, 775)`다. 16px 글자의 윤곽 크기
13.984 × 13.136px는 대상 89쪽 Print에 관측한 크기와 부동소수점 오차 범위에서 같다.
H2GTRM의 다른 대체 윤곽은 1,024 em에서 `(64, -81, 975, 815)`다. 원래 글꼴이 없는
글자를 다른 family의 TTF로 그리는 것과 원 HFT 윤곽을 보완하는 것을 구분한다. 원 TTF와
검증된 TTC 선택은 유지하며, 미완전한 SPJGT 원 family의 결측만 CFF로 보완한다.

10쪽 대조군의 Native는 모두 100.00%를 유지했다. WASM 89쪽은 99.94%에서
100.00%로 개선됐고 71·92·96쪽도 100.00%였다. 8·17·25·44·86쪽은 99.99%,
32쪽은 99.96%로 정본 대비 미달이 남아 있어 보호 검사 완료로 판정하지 않는다.
그 미달도 실제 글꼴과 독립 Print 원 윤곽을 대조하며 계속 해소한다.

개인 글꼴 바이트는 Git 제외 경로에 0600으로 보존하며 출처·해시·재생성 명령만 이 폴더에
기록했다. RHWPIndependentHFTSourceSymbols의 역사적 파일이나 SHA를 복구했다고
주장하지 않는다. Source94의 선행 실행 오류는 자료 준비 순서의 오류이며 Source95에서
글꼴 완성 후 같은 renderer로 다시 실행했다. 90%·98%·정본 하한과 마스크는 바꾸지 않았다.
