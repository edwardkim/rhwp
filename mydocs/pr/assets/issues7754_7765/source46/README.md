# 리베이스와 완료된 구 head 증거 보존

새 base는 PR #9316 통합 `8a196ca7aea2aa3cf32d394f5b7da2bdf4520479`, 보정 후 후보는
`8f9fd0414ffcfb720fa4a601c79c4590480de0e8`이다. 두 producer worktree는 이 SHA로
고정했으며 새 빌드·회귀 결과는 별도로 수집한다. 이 폴더의 Source55·79 결과는
리베이스 전 결과이며 새 head의 통과 증거가 아니다.

리베이스 전 필수 Native 편람 383쪽은 `--handbook-gate` exit 0이었다. 시행령은 74쪽씩
base·후보, Native·fresh WASM의 네 조건에서 전쪽 최저 99.98%였다. 정본의 99.98% 쪽과
같은 값은 보호 하락이 아니며, 네 조건 모두 정본 하한 미달이 없다. 이전 119쪽 요청은
쪽수 오류였고 정정된 전체 74쪽만 여기 보존한다.

`retained-files.json`은 원 실행 경로와 보존본의 SHA-256을 연결한다. 기존 전체 PNG와
확대 판독 증거는 이전 소스 기록에 있으며, 여기에는 전쪽 TSV·manifest와 실행 기록을
추가로 보존한다. 리베이스 range-diff는 66개 패치 동일, 글꼴 공통 조회 문맥 한 개 변경이며
누락된 커밋은 없다. 정본 TSV를 바꾸지 않았다.
