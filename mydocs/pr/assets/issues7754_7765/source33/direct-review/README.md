# 소스 33 직접 판독

복학원서의 독립 한컴 Print·기준 5665 Native·후보 Native·후보 fresh WASM을 같은 96 DPI에서
영역 `(45,565)-(750,1084)`로 잘라 nearest-neighbor 2배 확대했다. 실제 전쪽 raw는
후보 Native 99.00%, WASM 98.99%다. 접수증의 본문·날짜·서명 기호와 붉은 원,
접수자 표와 워터마크의 앞뒤 관계, 후속 주의 문구의 보존을 직접 확인했다.
영문 face와 절취선의 미세 차이는 남으며 100% 일치로 판정하지 않는다. 좌표를 새로
고정하거나 이 이미지에 맞춰 기대값을 추가하지 않았다. 다른 문서의 판독은 별도다.

배포용 문서 3쪽의 예산 표는 Print·기준/후보 Native·기준/후보 WASM을 같은 영역에서
2배 확대했다. 단위 문구와 표의 줄 소속, 두 줄 항목·합계·곱셈 기호·금액,
표 뒤 안내·예산과목·붙임의 순서를 직접 대조했다. 해당 쪽은 양쪽 raw 100.00%이고
문서 전쪽 최저는 Native 99.78%, WASM 99.80%다.

143E 문서 1쪽의 오른쪽 단은 앞뒤 본문, 괄호·인용 부호·영문 용어,
9%·20%와 기자명 링크를 같은 배율로 직접 대조했다. Native 99.93%, WASM 99.94%이며
100%로 확대하지 않는다. 두 패널 JSON에 원본·PDF·실제 PNG의 SHA, 영역과 판독 내용을 기록했다.
