# 리베이스로 유입된 중첩 표 편집 기능의 Native 보존

기준 5665와 후보 소스 33의 실제 라이브러리를 각각 링크한 진단 프로그램에서 공개 편집 API로
30줄·70줄을 추가했다. 원본 HWP와 실제 한컴 재저장 HWPX 각각에 대해 편집 직후,
실제 HWP 저장 후 재열기, 실제 HWPX 저장 후 재열기를 독립적으로 실행했다.
12개 조건 42쪽에서 base/candidate의 전체 쪽수·줄1~21/22~58/59~70의 소속이 같고
PNG 84개(양쪽 42쪽)의 대응 바이트가 모두 동일하다. 실제 한컴 Print PDF에 대한
양쪽 24개 전쪽 TSV도 보존했다. candidate 각 조건의 최저는 98.07~100.00%다.

진단 소스는 `.rs.txt`이며 새 활성 회귀나 golden이 아니다. 기존 정식 회귀는
`tests/cases/nested_row_page_split.rs`에서 별도로 실행한다. WASM 라이브 편집 결과는
아직 이 Native 자료에 포함하지 않는다. 독립 PDF 경로·SHA와 실제 실행 명령은 JSON에 있다.
