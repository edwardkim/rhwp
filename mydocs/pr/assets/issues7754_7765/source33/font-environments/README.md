# 보호 글꼴 환경의 바이트 복원

영월 문서 Native의 이전 기준 설정 파일은 캐시 경로만 기록돼 있었다. 정식 보존된
명시 환경과 같은 실행의 `native_webfont_fallback.mappings`를 정본 준비 로직에 따라
합쳤다. 설정 ID를 계산한 뒤 정렬 JSON과 마지막 개행으로 직렬화한 SHA-256은
기준 기록의 `a3a6458dc372877daa22941d7d45ec46c249e1c0cff1465631170b08059abab9`와
바이트 단위로 일치한다. 원본 설정과 실행 근거의 경로·SHA는 영수증에 기록했다.

이 복원은 글꼴 프로그램 바이트 확보나 시각 검증 통과를 뜻하지 않는다. 새 생산물의
실제 결과는 별도로 측정한다. 글꼴 파일은 포함하지 않는다.
