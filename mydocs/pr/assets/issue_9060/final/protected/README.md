# 최종 전쪽 보호 검증 원본

[WASM 완료 영수증](../protected-wasm-validation.json)은 제품 소스
`43adf3f7fe412e71797456887e2be44b8ef8d14f`의 최적화된 fresh WASM으로 측정한
18개 입력·1,771쪽 전쪽 결과와 입력·PDF·실제 공급 글꼴·생산 파일의 해시를 연결한다.
공식 두 자리 raw 보호값보다 낮아진 쪽은 0쪽이다. 각 입력의 전체 TSV를 보존하며
서로 다른 실행에서 페이지별 최댓값을 모으지 않았다.

Native CLI는 WASM의 보조 메타데이터에만 사용했다. 실제 PNG는 새 WASM에서 출력했다.
세부 역할과 SHA는 영수증에 기록하며 새 Native 빌드·검증 완료로 대신하지 않는다.

현재는 WASM만 완료된 기록이다. 최종 Native 전쪽·편람 gate·필수 lint 완료 후
두 경로를 함께 수용하고 실제 정본 보호 하한의 상승분을 갱신한다.
원격 CI·통합 PR·병합 완료 기록이 아니다.
