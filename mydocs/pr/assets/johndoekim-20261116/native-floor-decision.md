## 검토한 선택지와 확정 범위

1. **기존 1행 차이 한정 예외:** 위 Native 10쪽 99.85%/99.86% 차이만 이번 source의 수용 예외로 명시한다. 보호 정본·허용치·측정 결과는 그대로 두며 예외를 숨기지 않는다. 새 회귀·다른 보호값 하락·미달·테스트 실패·미실행은 포함하지 않는다. 나머지 필수 로컬 gate를 모두 완료한 뒤 이미 승인된 원격 PR·새 head CI·self-review·merge·후속 처리를 수행한다.
2. **Native 추가 보정:** 두 기여 밖의 Native 표시 조건·실제 프로그램 소비를 메인테이너가 추가 조사·보정한다. 원인·독립 기대값을 먼저 확정하며 문서 ID·좌표·배율·획·허용치를 임의로 맞추지 않는다. 제품 source가 바뀌면 관련 직접 비교와 전체 필수 검증을 새 source에서 다시 완료한다. 보정 전에는 PR 제출을 보류한다.

두 선택 모두 원 기여 SHA·fork branch를 보존하고 #9058은 OPEN을 유지한다. 완료되지 않은 전체 회귀·보호 실행을 성공으로 기록하지 않는다.
