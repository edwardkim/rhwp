## 판독

**수정 전** — 본문이 쪽 아래 끝까지 이어져 잘리고, 쪽번호가 그려질 자리를 덮는다.
위쪽에서는 글자가 캡션과 겹친다. 이 쪽의 하단 초과 최대 **+555.8px**, `offCanvas` 17건.

**수정 후** — 본문이 제자리에서 끝나고 쪽번호 `- 151 -` 이 정상으로 나온다.
`overflow` 22건 → 0건, `offCanvas` 17건 → 0건.

## 한계 — 정본과 쪽 대응이 1:1 이 아니다

한/글 정본은 **302쪽**, rhwp 는 **304쪽**이라 이 구간에서 쪽 번호가 한 칸 어긋난다
(정본 같은 쪽의 쪽번호가 `- 150 -`/`- 151 -` 로 밀린다). 따라서 3면 비교는 **같은 쪽 번호의
내용이 아니라** 개체·본문 배치의 성격을 보는 용도다. 이 PR 은 **개체 소유 쪽 교정**만
주장하며 잔여 +2쪽과 이 쪽의 남은 하단 초과 +56.7px 는 다른 축이다.

정본: 한/글로 직접 출력(`Hancom PDF 1.3.0.534`, 302쪽). 저장소에 이 문서의 기준 PDF 가
없어 새로 만들었고, 크기가 커 이 폴더에 넣지 않았다.
