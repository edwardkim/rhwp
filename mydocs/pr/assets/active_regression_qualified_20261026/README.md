## 직접 판독과 제한

6조건의 Native/fresh review·standalone overlay 12쌍을 실제로 열었고 같은 좌표의 내용 띠를
함께 잘라 최근접 확대해 판독했다. 확대본에서 점수는 다시 계산하지 않았다. 각주/미주의 번호·
구분선·원문 순서, 큰 내부 글자, 점의 실제 공급자·기준선과 뒤 글자의 간격을 확인했다.

`charSz=50`의 겹친 glyph 윤곽·상대 배치에는 base와 같은 기존 잔차가 남는다.
이번 검토는 논리 슬롯·주석 소유·캐럿과 기존 크기 계약의 유지이며 그 잔차를 고쳤다고
주장하지 않는다. 양쪽 98% 미만인 이 대조군은 px 좌표 검사의 근거로 쓰지 않는다.
100% 역시 2px 실루엣이고 RGB 완전 일치가 아니다. 작은 글자의 가장자리·얇은 선의
농도 차이는 직접 판독과 별도로 기록했다. 정상 저장 HWP와 HWPX의 화면이 서로 같다는
주장도 하지 않으며 각 파일은 그 파일 자체의 독립 Print와 비교했다.

원 캡처·manifest를 바꾸지 않고 정본 `make_compares`, `make_overlay_page`,
`make_review_panels`로 패널만 합성했다. source가 같은 완료 캡처의 재사용이며 새 재캡처로
기록하지 않았다. 자동 점수와 사람 판독을 구분하며 전체 통합 PR의 CI·merge 완료를 뜻하지 않는다.
