# 원 PR 문서의 대체 입력 표시

원 PR에 검증용 HWP/HWPX 원본이 첨부되어 있지 않아 **유사 문서로 대체**했다.
공식 게시처에서 제목·본문·표·문제 영역의 대응을 확인했더라도 작성자 파일의 바이트 동일성을 확인한 것으로 표시하지 않는다.
이 자료는 대체 입력의 식별과 검증 범위를 밝힌다. 원 PR 실물 문서의 직접 검증 또는 전 페이지 개선 완료를 뜻하지 않는다.

## 판본 또는 원문을 확정하지 못한 PR

다음 5건도 원본 부재를 이유로 다른 문서의 이미지를 원본처럼 표시하지 않는다. 유사 문서·공개 재현 입력·단위 계약 중 실제 검증한 범위를 명시한다.

| --- | --- |

새로 찾은 문서는 전 페이지 90%로 보정할 의무가 없다는 작업지시를 적용했다. 제품 코드·회귀·baseline·Visual Sweep 정책을 변경하지 않는다.
