# 대체 문서 원본과 PDF

HWP/HWPX와 PDF를 함께 다운로드해 내용 대응을 확인할 수 있도록 보존한다.
**공식 게시처의 배포 PDF와 출력 계약을 확인한 한컴 Print PDF를 구분한다.** 배포 PDF는 원 게시처의 원문이며, Print 방식이 확인되지 않은 파일은 새 Visual Sweep 기준으로 사용하지 않는다.
원 PR에 첨부된 작성자 파일이 없어 확보한 대체 문서이며 작성자 원본과 바이트 동일성을 주장하지 않는다.
