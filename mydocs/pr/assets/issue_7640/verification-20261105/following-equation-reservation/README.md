# #7640 다음 수식이 소유하는 저장 예약 높이

17쪽 미주에서 짧은 수식 줄의 저장 LH2070은 다음 분수의 실제 높이와 같고, 저장 사다리는
TH1125와 줄 간격으로 전진한다. 수식 개체만 현재 프레임으로 재저장되었을 때 앞줄이 다음
분수의 예약 높이까지 중복 소비하던 경로를 보정했다. 기존 후속 개체 소유 질의와 저장
사다리 검증을 공유하며 문서·쪽 번호 또는 임의 감산으로 분기하지 않는다.

- 정식 소속·높이 관계 검사: 3건 중 1 FAIL → 3 PASS. 실제 후속 분수의 높이 소유를
  제거한 반례에서는 앞줄의 예약 높이를 임의로 없애지 않는다.
- 완료된 수식 문서·편집 캐시·참여 줄 간격·10월 미주 정상 대조군: 20 PASS.
- Native 전 21쪽 수집 완료, 쪽수 21/21·누락 0. 17쪽 94.69512% → 99.14958%,
  19쪽 42.58867% → 95.41891%. 전쪽 90% 미달은 3쪽에서 2쪽으로 줄었다.
- 잔여 미달은 18쪽 85.61347%, 20쪽 67.36410%다. 동일 글꼴의 고정 devel 전쪽 결과와
  대조해 0.1%p를 넘는 하락은 없지만, 잔여 미달을 제출 통과로 인정하지 않는다.
- `before/after-native-p017-{raw,review,overlay}.png`는 같은 입력·독립 한컴 Print·96DPI의
  실제 출력이다. 첫 수식 줄과 뒤 분수·다음 문제의 위치를 직접 판독했다.

이 단계의 fresh WASM·최종 전체 nextest와 편람 게이트는 미완료다. Native Skia 필수 3종은
별도 실제 실행 결과를 `validation.json`에 기록한다. 단계 증적은 #7640 전체 해결이나 PR 제출
완료를 뜻하지 않는다. 로그와 임시 진단은 ignored `output/`에만 보존한다.
