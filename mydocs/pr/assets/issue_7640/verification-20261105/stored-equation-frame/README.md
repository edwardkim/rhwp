# #7640 현재 수식과 과거 호스트 줄 높이의 분리

재저장본은 수식 상자·기준선이 이미 현재 논리 프레임인데 호스트 줄 캐시에 과거 상자의 높이가
남았다. 개체의 크기 변화 유무만으로 줄 갱신을 판단해 세 문단에서 각각 약 3px를 더 예약했고,
11쪽 마지막 수식을 다음 단으로 밀었다. 같은 수식 프레임 질의와 기준선 합집합을 측정·배치가
함께 소비하도록 보정했다. 특정 문서·쪽 번호나 임의 감산은 구현 조건에 넣지 않았다.

- 공개 렌더 트리의 원본 미주 소속 관계 검사: 보정 전 1 FAIL → 보정 후 1 PASS.
- 크기 보호·복합 수식의 별도 저장 줄 예약 대조군을 포함한 2 PASS.
- 완료된 수식 문서·편집 캐시·줄 간격 참여·인접 10월 미주 관계 검사 20 PASS/0 FAIL.
- Native 전 21쪽 수집 완료·쪽수 일치·누락 0. 미달 7쪽에서 3쪽으로 감소했다.
  11쪽 53.60031% → 99.66679%. 실제 마지막 적분식·뒤 단 시작과 그림 위치를 직접 판독했다.
- 잔여 미달: 18쪽 39.24158%, 19쪽 42.58867%, 20쪽 66.05146%.
  18쪽은 직전 후보 42.45973%보다 내려갔으므로 해결을 계속하며 제출 통과로 인정하지 않는다.
- #7375 원본 Native 50쪽은 기존 frozen 후보와 모든 PNG SHA가 같다. canonical TSV도
  다시 산출했다. Native 프로그램·줄 캐시 보정이 그 원본에 회귀하지 않았음을 확인했다.
- fresh WASM과 이 소스의 전체 nextest/lint/편람 최종 게이트는 아직 완료하지 않았다.
  부분 개선으로 #7640을 종료하거나 PR을 제출하지 않는다.
