# #7640 현재 수식의 전진폭 재측정과 줄 캐시

현재 상자 높이인 단순 수식도 검증된 글자 전진폭이 저장 폭과 다르면 같은 부분 재조판 경로가
가로 캐시를 재확인한다. 높이가 이미 현재 값이라는 이유로 폭 재측정의 증거를 버리지 않는다.
실제 배치는 저장 상자 폭을 보존하고 미지원 복합 수식·보호 프레임의 수용 범위를 넓히지 않는다.

- 18쪽 실제 소속 검사: 6건 중 1 FAIL → 비겹침 대조군을 포함한 최종 7 PASS.
  Mac 최소 글꼴 환경에서도 최종 7 PASS이며 검사 본문은 동일하다.
- 정상 수식·편집 캐시·참여 줄 간격·10월 미주 대조군 20 PASS.
- Mac 최소 글꼴 Native Skia 필수 3종: lib 4,039 PASS·12 ignored, PNG 2 PASS,
  PDF 22 PASS. 기존 Native 글꼴 집중 검사도 12 PASS다.
- 재저장본 Native 21/21쪽·누락 0·전쪽 통과, 최저 99.03802%(18쪽).
  18쪽 85.61347% → 99.03802%, 19쪽은 직전 99.47824%와 PNG SHA까지 같다.
- 원본은 PR #7600의 정확한 Print PDF로 별도 대조했다. Native 21/21쪽·최저 98.78595%,
  고정 devel 대비 페이지별 0.1%p를 넘는 하락이 없다. 기존의 다른 PDF 대조는 제출 근거로
  채택하지 않는다. 정확한 원본 Print와 재저장 Print의 전 21쪽 RGB가 같음도 확인했다.
- #7375 Native 정상 대조군 50쪽은 기존 검증 출력과 모든 PNG SHA가 같다. 전쪽 TSV를
  새로 산출했다. 원본과 재저장본의 입력·수치·기준 PDF는 구분한다.

세로 갱신만으로 가로 캐시를 무효화한 첫 후보는 19쪽의 뒤 글줄이 앞 분수의 점유를 침범했다.
해당 후보를 철회하고 직접적인 전진폭 재측정 증거를 기존 경로가 공유하게 했다. 별도 조판
모델 필드나 새 프레임 소유 경로는 남기지 않았다. 그 후보의 통과 수치는 제출 근거가 아니다.

[후속 WASM 증적과 보류 사유](fresh-wasm-e9c789b7/README.md)를 따른다. 이 단계로
#7640 해결 완료나 PR 제출 완료를 판정하지 않는다. 해시·입력·실행 근거는 `validation.json`,
