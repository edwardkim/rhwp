# 채용 공고의 중첩 표와 후속 글줄

[원본 HWP](../../../../samples/pr-1674.hwp)와 [한컴 2020 Print PDF](../../../../pdf/pr-1674-hwp-2020.pdf)를
2026-11-23에 96 DPI 보정 전 2px 실루엣으로 비교했다. 두 경로에서 독립 PDF와 같은 35쪽을 출력했다.

3쪽은 분할 표 뒤의 제목과 후속 표 순서, 4→5쪽은 원본 경력 행의 이어받기를 검사한다.
7쪽은 같은 셀에서 중첩 표 뒤 설명 두 줄이 원본 줄간격을 지키고, 8쪽은 제목 뒤
문단 간격을 포함한 저장 원점에 중첩 표를 배치한다. 23·24쪽의 후속 글줄은 첫 인라인 표
뒤의 저장 간격을 보존한다. 2쪽 “국가공무원법, 공무원임용령”의 쉼표는 앞 한글과 같은 한컴바탕을 사용한다.
독립 Print 7쪽에서 파란 글자는 유지됐고 파란 괘선은 없었다. 전체 쪽수와
본문 넘침·용지 밖·텍스트 겹침의 원장도 복원했다.
