# 글꼴 목록의 언어 그룹별 오름차순

화면 표시 이름의 첫 문자를 기준으로 한국어 → 영어(라틴 문자) → 기타 언어를 구분한다.
앞의 기호·숫자는 언어 그룹 판정을 바꾸지 않는다. 그룹 안에서는 한국어 locale의 숫자 인식
오름차순을 적용한다. 이 순서는 표시 목록에만 적용하며 조판의 글꼴 프로그램 선택 순서는 바꾸지 않는다.

도구 모음의 모든 글꼴·현재 글꼴·문서 글꼴·대표 글꼴·시스템 글꼴, 글자 모양 및 대표 글꼴
대화상자, 로컬 글꼴 목록이 공통 비교기를 사용한다.
검증 Chrome의 실제 메뉴를 열어 모든 글꼴 1,391개, 현재 1개, 문서 34개, 대표 4개,
시스템 1,364개를 조사했으며 언어 그룹 및 그룹 내 역순은 0건이었다.
