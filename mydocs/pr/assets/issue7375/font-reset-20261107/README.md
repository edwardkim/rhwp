# 로컬 글꼴 감지와 초기화 보정

2026-11-07. 기준 HEAD `9b43682f77817170b968507c0b3bded0112b85f1` 이후의 Studio 변경이다.

## 확인한 원인

실제 Mac의 `옥수수`는 `Corn-ENCORN`·`Corn-HGCORN` 두 원본 프로그램이 같은 family와
한글 이름을 공유한다. 기존 감지는 단일 face를 확정할 수 없는 이름을 미감지로 처리하여
단일 `존재만 확인` 항목을 추가했다. 이 항목을 정확한 family로 다시 선택해 실제 두 프로그램을
가렸고 표시가 대체 글꼴로 남았다. 두 원본·잘못된 probe 하나를 실제 브라우저에서 재현했다.

이름이 복수 face에 대응하는 것과 목록에서 빠진 것을 구분했다. 같은 family·style의 원본
프로그램을 함께 공급하며 서로 다른 family의 모호한 이름은 임의로 확정하지 않는다.
예전 저장 목록에 남은 중복 probe도 실제 프로그램의 별칭과 대조해 정리한다. 감지 상태
보고 역시 같은 family의 복수 프로그램을 사용 가능으로 표시한다. 특정 문서·쪽·글꼴명 예외는 없다.

## 초기화와 로드 순서

초기화 버튼은 저장된 목록·런타임 감지 결과를 삭제한다. 버튼에서 선택창을 띄우거나,
이미 허용된 브라우저 권한으로 목록을 자동 복원하지 않는다. 다음 문서 로드에서
로컬 감지 또는 대체 글꼴 사용을 다시 묻는다. 빈 문서에는 이 선택창을 띄우지 않는다.

이전 자동 보완은 snapshot이 없어도 승인된 권한으로 재감지하여 초기화를 되돌렸다.
저장 snapshot이 있을 때만 보완하고, 초기화 전에 시작한 조회의 늦은 응답은 버린다.
명시적 전체 감지로 확인한 문서 후보를 같은 갱신에서 재열거하지 않는다.
선택과 감지를 프로그램 공급·조판·첫 paint보다 먼저 완료하여 비동기 갱신과 경합하지 않는다.
브라우저 권한이나 브라우저 자체의 글꼴 목록 캐시는 변경하지 않는다.
