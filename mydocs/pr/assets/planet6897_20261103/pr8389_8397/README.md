# PR #8389·#8397의 기존 출력 보존 검증

## Native 전쪽 결과

Native는 2026-11-04~05 실행에서 제품 코드 `4b149b6cdf`·고정 base
`7fdd5441ff`로 다시 확인했다. 색상 경계 보정 전 2px 내용 실루엣을 96 DPI로 측정했다.
[원 PR 기준 2,153행 대조](native-display-comparison.tsv)는 중복을 제외하면 17문서·1,770쪽이며,
**원 PR TSV 대비 하락 0행, 누락 0쪽**이다. 전쪽 최저 94.96%, 90% 미만 0쪽이다.
문서별 전쪽 TSV는 [native](native/)에, 실제 입력·PDF·제품·TSV 해시는
[Native 출처 명세](README.md)에 보존했다. `issue7905` 6쪽도 모두 98% 이상이다.

fresh WASM도 `7bb9e66fd0` 최적화 제품(실제 제품 코드 `4b149b6cdf`와 동일)의
17문서·1,770쪽 재측정을 마쳤다. [원 PR 기준 2,153행 대조](wasm-display-comparison.tsv)는
전 행 통과·하락 0행·누락 0쪽이다. [문서별 TSV](wasm/)와
[WASM 출처 명세](README.md)에 실제 입력·PDF·package 해시를 보존했다.

위 값은 고정 base `7fdd5441ff` 당시 제품의 실제 캡처다. 최신 base `22947f6a90` 반영 뒤에는
추가된 번호 자리표·글상자 다중 그림 배치와 실제 영향 경로를 집중 검증한다.
이미 완료한 위 전쪽 측정을 새 head에서 다시 출력한 값으로 표시하지 않는다.
`sample10`에는 원 검증과 같은 외부 참조 그림 `oracle.gif`·`rdb02.gif`·`s1.jpg`를 공급했다.
[입력·PDF SHA와 Git 포함 명세](inputs.tsv)에 실측 파일과 저장소 파일의 일치를 기록했다.

기준은 각 행의 `기준_TSV`에 기록한 PR #8389·#8397의 정밀 TSV다.
`원PR_판정`과 `직전통합_기록대비`를 구분해 원 PR 기준과 후속 통합 기록의 수치를
혼용하지 않는다. 소수 둘째 자리로 표시된 현재 값이 원 PR 표시값 이상이면 통과다.

## issue7905의 직전 통합 기록 재현

`issue7905`의 현재 표시는 1~6쪽 순서로 99.97 / 98.86 / 99.99 / 99.99 / 99.99 /
99.98%다. 원 PR 기준의 99.97 / 98.86 / 99.80 / 99.99 / 99.99 / 99.98%를 유지·개선한다.
직전 통합 기록의 99.98 / 98.86 / 100.00 / 100.00 / 100.00 / 100.00%와 비교하면
5행에 0.01~0.02%p 차이가 있어 당시 제품 코드 `d536455b4e`를 직접 다시 빌드했다.

- 직전 제품 재빌드 실행 파일 SHA-256:
  `dbf11a1916d4917aed50e6fb444b88426224c355cbde6768c9bf2c82dce542a2`.
- 현재 제품 실행 파일 SHA-256:
  `24c7e929b04c14adc46fbcc80b384e74fffd5524bdd2484068ebe6e974952337`.
- 같은 현재 환경에서 직전 제품과 현재 제품의 **Native 6쪽 PNG가 모두 바이트 단위로
  일치**한다. PDF PNG 6쪽도 동일하다.
  [PNG별 SHA-256 대조](issue7905-code-reproduction-png-sha.tsv)를 보존했다.
- 두 제품의 재측정 값도 전쪽 동일하다. 직전 기록과의 차이를 이번 체리픽의 출력 회귀로
  판정하지 않는다. 직전 기록의 100.00%를 현재 raw 측정값으로 재사용하지도 않는다.
- 현재 PDF 래스터는 `pdfium_smooth_rgb_exact_dpi_v2`다. 과거 방식인 PDFium
  `page.render(scale=96/72)`를 진단용으로 실행하면 3~6쪽이 100.00%가 되지만,
  1·2쪽은 직전 기록과 같지 않다. 이 실험만으로 과거 실행 조건의 차이를 단정하지 않는다.

입력은 `mydocs/pr/assets/legal_hwpx_cellsz_host_line/input/jongbu_law.hwpx`,
독립 PDF는 같은 폴더의 `jongbu_law_hancom2018_print.pdf`다.
이 비교를 위해 제품 코드나 Visual Sweep의 임계값·비교 영역을 변경하지 않았다.
