# 기존 Print 알파·코덱 대조군의 재현 자료

기존 24개 보정 조건 중 정상 대조군 13개를 정리했다. 새로운 실제 HWP를 추가하거나 원래
Print의 미달을 다른 입력으로 대체하지 않는다. 이미 추적하던 5쌍은 기존 경로를 재사용했고,
ignored output에만 있던 8개 진단 입력과 각각의 독립 한컴 Print PDF를 정식 경로에 보존했다.

[자료 목록](sources.json)에 각 입력/PDF의 경로·크기·SHA-256과 양쪽 TSV의 SHA를 기록했다.
새 입력은 `tests/fixtures/pr8032_print_controls/`, 대응 PDF는
`pdf/semanticist21-20261019/print-controls/`에 있다. 50 MiB 이상 PDF는 없다.

## 원본과 진단 사본의 구분

원래 wide/narrow와 Print는
[공통 인쇄 격자 회귀](../pr_8032_print_alpha/README.md)에 보존돼 있다. 나머지 코덱·알파·
비율 조건은 wide의 ZIP 사본에서 그림 payload 또는 크기 정보를 바꾼 대조군이다.
각 사본을 따로 MCP의 한컴 2020 Print로 출력했다. 원본의 정답지로 승격하지 않는다.

실제 변경 ZIP entry와 포함 PNG의 모드·크기·SHA·알파 범위는 `sources.json`에 기록했다.
색인 PNG의 16/32/48 격자, RGBA, 일정 알파, 일정 RGB, 종횡비·원본 격자 밀도의 조건을
구분한다. entry의 정확한 바이트는 각 HWPX에 포함돼 있어 원본과 직접 대조할 수 있다.

## 검증 범위

런타임 `b9c1249098856f5cb1fb17c45d75ad76e855a18a`의 Native271·최적화 fresh081에서
13개 조건 모두 전쪽 90% 이상·독립 Print와 각각 1/1쪽이었다(4471/4482).
이 완료된 선행 TSV를 `native/`·`wasm/`에 바이트 그대로 보존했다.
원래 wide/narrow의 핵심 프레임·내용 순서는 기존 정식 회귀가 보호하며, 진단 사본 통과로
원래 문서의 직접 판독이나 관계 검사를 대신하지 않는다.

새 base `0bb36e6f97`와 현재 후보의 최종 검증은 기존 129개 조건과 기존 24개 보정 조건을
합친 153개 조건으로 계속한다(4506). 이 자료 보존을 새 head의 검증 완료로 보고하지 않는다.
실제 사용 경로가 output에 남아 있는 재실행도 위 정식 파일과 SHA가 같아야 한다.
임시 실행 로그와 중간 JSON은 커밋하지 않는다.
