# 춘천 인사규칙의 본문 넘침 검사 이관 보존

[하위 이슈 #7834](https://github.com/edwardkim/rhwp/issues/7834)에서 동일 원본 전15쪽의
피델리티와 본문 넘침을 개선합니다. 원본과 독립 Print PDF는 기존 경로에 유지합니다.
기존 검사 코드 전체와 이 입력의 원장 행을 자동 수집되지 않는 `.rs.txt`·`.tsv.txt`에
보존했습니다. 실제 활성 분리와 검증 상태는 `transfer-inventory.json`에서 구분합니다.
공통 helper와 다른 원본, parser·serializer·보안·쪽수 계약을 폐기하지 않습니다.

고정 devel의 Native/fresh 최저45.18405%·미달5쪽, 현재 후보45.02910%·미달7쪽입니다.
6쪽 review에서 행 소속 차이를 확인했습니다. 현재 추가 미달과 본문 넘침0→1건은
새 악화로 추적하며 이관을 해결 완료로 표시하지 않습니다.

동일 원본 전쪽 Native/fresh 각각90% 이상, 쪽수와 내용 소속·누락·중복 및 실제
표 외곽·후속 내용까지 확인한 뒤 관계 검사로 복원해야 합니다. 로그·전쪽 TSV는
ignored output에 보존하고, 최종 후보의 대표 review와 요약 증적은 별도로 연결합니다.
