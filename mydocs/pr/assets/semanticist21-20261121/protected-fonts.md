# 보호 문서 글꼴 재현 검증

11월 21일 검토한 통합 후보의 다단 각주 원본은 [원본·편집본 대조](footnotes/README.md)에 기록했다. 별도로 보호 문서 23종의 4,046개 Native·fresh WASM 측정값을 기존 정본과 대조한다.

## 독립 글머리표

별도 보관본이 없는 검증용 Hanyang·Poppy OTF의 해시는 선행 검증의 [공급 목록](../issues7733_7738_20261117/final-efe954/protected-font-conditions)에서 확인했다. 독립 HWPX 문자표의 한양중고딕 슬롯에 U+2022를 넣고 한컴 2020에서 PrintMethod 0으로 인쇄했다. 원래 글리프의 Type3 명령 SHA-256은 `2506433f6422778c6963a3dcbf11c311df80b06e75aad7a49a64e9be6c25a16a`이며 수평 전진은 1,000, 왼쪽 베어링은 316이다. 세 값이 [선행 글머리표 검증](../issues7733_7738_20261117/chemical-bullet-program-order/original-symbol-program-proof.json)과 일치했다.

독립 입력 SHA-256은 `5d11ca16005a631b110c748cbb182e2521f37868f0a516aee05ed09f77767cb1`, Print PDF는 `dff20e43f3b698161328c2378495bcacbdfb8251ec9ea512b9286de745006560`이다. 이 글리프만 담은 로컬 글꼴은 원본과 다른 이름으로 만들어 명시적으로 공급했다. 화학물질 표시 기준 72쪽에서 이 파일을 우선 공급한 첫 측정은 Native 99.91%, WASM 99.84%다. 해당 쪽의 기준은 각각 99.91%, 99.95%다.

## 실제 프로그램 대조

Native가 사용하는 식별 값은 파일 전체와 컬렉션 face index 4바이트를 연결한 SHA-256이다. 로컬 파일에서 한양중고딕·견고딕과 함초롬바탕·함초롬돋움의 식별 값이 선행 기록과 일치했다. Native가 한 번에 읽는 사용자 글꼴은 최대 256개다. 원본·독립 PDF에 쓰인 face와 선행 선택 프로그램으로 공급 목록을 좁혔다. 화학 문서 52개, 시행령 20개, 형식 사양서 18개다. 같은 조건에서 화학 문서 1쪽은 Native·WASM 모두 100.00%, 72쪽은 두 경로 모두 99.92%였다. 시행령 4·13·18·24·61쪽은 두 경로 모두 100.00%였다. 이 측정의 제품 소스는 `c6fb9159bf`다.

형식 사양서 Native 71쪽을 대조하면 기존 하한에 못 미친 쪽은 8·16·17쪽이다. 8쪽 제목의 한산뜻돋움 굵게는 Print의 사용 글리프 29개 모두 로컬 파일과 윤곽·수평 메트릭·힌팅 명령이 일치했다. 16쪽 Arial의 사용 글리프 29개는 로컬 7.05·7.07 모두 윤곽과 수평 메트릭이 일치했고, 개별 힌팅 명령 일치는 1개였다. 글꼴 파일을 전부 확보했다거나 잔여 차이가 모두 글꼴에서 비롯됐다고 판정할 근거는 없다.

HCI Poppy의 독립 한컴 2020 문자표는 글꼴 설명에 Gulim을 담은 CID TrueType으로 인쇄됐다. 이 출력은 원본 HFT 윤곽의 공급 근거에서 제외한다. 보호 정본과 허용치는 변경하지 않았다.

## 독립 문자표의 복원 범위

한컴 2020에서 현대 한글 11,172자를 44개 독립 HWPX로 나눠 인쇄했다. 각 요청의 입력·PDF 해시와 PrintMethod 0, 추출된 문자 순서를 확인했다. 결합한 PDF의 SHA-256은 `21aaa13286e52b2aaf78fb6eb68c02f8dd57218d693b53b61ef42e1dceade01d`이다. 원래 윤곽과 전진폭을 보존해 만든 로컬 한양신명조 현대 한글 글꼴의 SHA-256은 `268c743cfa90e37ff5ce2dada01f21d8d19d458734022ad31a480c02ad932317`이다. 별도로 검증한 글머리표 1종과 이 한글 음절들이 독립적으로 확인된 공급 범위다.

별도로 인쇄한 Arial 문자표는 ASCII와 문장부호 102자를 포함하며, 공백을 정규화한 PDF 본문이 입력과 일치한다. 형식 사양서 16쪽에서 사용한 29개 글자의 힌팅 명령은 그중 한 글자만 일치하고 전역 힌트 세 테이블의 내용도 다르다.

형식 사양서 10쪽의 본문 옛한글 `U+F53A`를 독립 PDF와 확대 대조했다. Native에는 해당 음절이 표시되고, 첫 WASM 공급 조건에서는 뒤의 ‘글의 문서’ 앞 한 음절이 비어 있다. 해당 글자의 실제 공급과 두 브랜치의 출력을 추가 대조한다.
