# 편집한 중첩 표의 줄 소속과 아래 괘선

원본 HWP와 한컴 2020에서 다시 저장한 HWPX에 같은 30줄 또는 70줄을 추가했다. 편집 직후, HWP 저장 재열기, HWPX 저장 재열기를 각각 같은 편집 내용의 한컴 Print와 비교했다. [84쪽별 원본과 독립 인쇄본, TSV](pages.tsv)

| 입력 | 편집 줄 | 비교한 쪽 | Native 최저 | fresh WASM 최저 |
| --- | ---: | ---: | ---: | ---: |
| HWP | 30 | 3 | 98.21581% | 98.21996% |
| HWP | 70 | 4 | 98.27731% | 98.26031% |
| 한컴 HWPX | 30 | 3 | 98.00640% | 97.86924% |
| 한컴 HWPX | 70 | 4 | 98.59903% | 98.37997% |

3쪽의 58번째 줄 아래에는 안쪽 괘선과 바깥 괘선이 순서대로 놓인다. 96 DPI로 환산한 한컴 PDF의 두 괘선 중심 간격은 3.83px다. 바깥 표가 자식 글줄의 후행 간격을 다시 빼던 경로를 보완했다. [한컴·수정 전후 Native·fresh WASM 확대](nested-last-line.png)

한컴이 다시 저장한 HWPX의 30줄·70줄 편집에 대해 HWP와 HWPX로 각각 내보낸 세로 좌표 200개를 독립 재저장본과 대조했다. 모든 줄의 편집 직후·재열기 쪽 소속도 일치했다. [독립 저장 줄 좌표](../hwpx-edited-lines.tsv) · [편집 직후와 재열기 캐럿](caret-and-reopen.tsv)

한컴 2020에서 인쇄한 PDF는 각 파일의 SHA-256으로 연결했다. 편집 직후에는 같은 내용의 HWPX 저장본을 인쇄했다. 표와 글줄의 배치를 확인한 제품 소스는 `521f69d19da9176e7947ceb318cf9838bec5ca75`다.
