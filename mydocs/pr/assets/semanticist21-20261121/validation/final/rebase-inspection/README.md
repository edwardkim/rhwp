## #9209 표의 괘선과 글자

원시 실루엣이 가장 많이 달라진 곳은 표 안에 여러 줄의 글자가 놓인 Native 20쪽과 WASM 19쪽이다. 17~23쪽을 같은 영역에서 확대해 보니 줄바꿈과 표의 왼쪽 끝은 기존과 같았다. 한컴 Print의 왼쪽 괘선은 x=96.428px, 양쪽 제품은 x=94.5px다. 원본 HWPX의 표 왼쪽 바깥 여백은 141 HWPUNIT(1.88px)이다. 이 기존 괘선 위치 차이는 재현된다.

2쪽과 20쪽의 실제 브라우저 그리기 명령에서 달라진 것은 각각 93개·97개 텍스트의 인쇄 좌표 변환이다. 독립 PDF에 기록된 텍스트 행렬 147개·252개의 단위는 가로 0.119935pt, 세로 0.119869pt다. 후보의 600DPI 장치 배율 0.999462와 0.998907을 포인트로 환산하면 두 값이 소수점 여섯째 자리까지 일치한다. 23→24쪽에서 뒤따르는 표의 셀 소속과 43~46쪽의 그림 11·8·7·6개도 보존됐다. [원본 표 속성, 실제 그리기 명령, 독립 인쇄 행렬](pr9209-print-device.json)

재조판으로 함께 들어온 대조군은 일반 페이지별 90%·devel 대비 2%p 기준과 내용 보존을 확인했다. 원시 값이 소폭 내려간 Native 48쪽과 WASM 18쪽은 잉크 차이가 가장 집중된 영역을 인쇄본·기준·후보·겹침으로 직접 판독했다. 본문과 표의 글자 순서, 누락, 선의 위치를 함께 확인했다. 23종 정본 보호 문서는 해당 문서 고유의 쪽별 하한으로 별도 판정한다.
