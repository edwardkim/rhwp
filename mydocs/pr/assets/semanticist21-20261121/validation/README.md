# 17건 통합 후보의 보호 문서 및 최신 devel 검증

2026년 11월 21일에 `devel`의 `ca231d64f4`와 제품 소스 `143f804aef`를 별도 빌드 디렉터리에서 컴파일했다. 두 Native 실행 파일과 두 최적화 WASM의 SHA-256, 각 입력·독립 인쇄본·공급 글꼴의 식별값은 [검증 조건](validation.json)에 있다. `5fceeb61c4`에서 기여자의 새 캡션 검사 커밋을 반영했고, `f40c194638`에서는 테스트의 근거 주석을 보강했다. 두 변경 후 제품 소스는 같다.

## 병합으로 들어온 조판과 CBTA 표

[#9277](https://github.com/edwardkim/rhwp/pull/9277)의 규제 문서 2종, 매개 변수 문서 2종, 연구 보고서 HWP·HWPX를 기준 브랜치와 후보에서 각각 640쪽씩 비교했다. Native 640쌍·fresh WASM 640쌍의 픽셀과 표시값이 모두 같았다. 한컴 인쇄본 대비 최저는 Native 98.58%, WASM 98.75%다. [전체 비교표](devel-pages.tsv)

CBTA 원본은 선행 검증에 공급된 글꼴 43개의 SHA-256을 하나씩 대조해 같은 글꼴로 양쪽 204쪽씩 인쇄본과 비교했다. 두 렌더러 모두 전쪽 최저는 98.22%다. 59쪽은 Native 98.88%·fresh WASM 98.90%이며 표의 합계 행·아래 캡션·뒤 문단의 간격을 확인했다. 408쌍 모두 기준 브랜치와 후보의 픽셀이 같다. 최소 글꼴 환경에서 뒤 문단의 시작은 354.0px이며 문서 전체에 본문 하단을 2px 넘은 항목은 없었다. [59쪽 확대 비교](cbta-page59.png)
