# 리베이스 후 기존 Native TSV 보존 대조

[PR #8389](https://github.com/edwardkim/rhwp/pull/8389)와 [PR #8397](https://github.com/edwardkim/rhwp/pull/8397)의 기존 기준 2,153행을 같은 입력·같은 독립 Print PDF·96 DPI에서 다시 비교했다. [대조 TSV](native-pr8389-8397-de2295.tsv)는 표시값 기준 하락 0행이며, 중복을 제외하면 1,770쪽이다. [검사 집계](native-pr8389-8397-de2295.json)에는 실행 파일과 TSV 해시가 있다.

기존 기준의 시스템 글꼴과 문서별 대체 글꼴 설정을 사용했다. 각 원본·PDF SHA-256, 50개 완료 묶음의 페이지 수, 1,770쪽 RHWP·PDF PNG의 해시를 다시 확인했다. 중단 후 문서 전용 커밋으로 HEAD가 달라져 엄격한 `--resume`이 거절된 구간은 완료된 묶음을 유지하고 미완료 쪽만 별도 실행했다. 기록된 세 HEAD 사이에서 제품 코드·의존성·측정 스크립트는 동일하며, 모든 묶음은 SHA-256 `585f455e83f3e1e7ba4fe91ce24fb313dc0347dc281a265fe8b178a49a97a9d0`의 동일한 Native 실행 파일을 사용했다.

이 결과는 이후 무효화된 문자 분할을 공통 inline 줄 계획에 포함한 후보 **이전**의 결과다. 후속 후보의 전체 Native·fresh WASM 대조나 개별 PR의 시각 판독·90% 게이트를 대신하지 않는다.
