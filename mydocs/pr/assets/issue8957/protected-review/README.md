## 하락 진단과 검증 환경 복원

초기 하락은 원 검토에서 사용한 글꼴과 연결 그림의 공급 누락으로 분리했다. 이번 보호 검토에서
제품 코드·테스트·golden은 수정하지 않았다. 기존 정본 수용 PR #8397과 후속 #8896/#8984의
글꼴 원장·실행 조건을 추적했고, 존재하는 동일 해시 프로그램을 우선 공급했다.

- 구형 수식: 승인된 공개 문자표를 한컴 2020으로 독립 출력했다. 77개 글리프는 기존 검토의
  독립 glyph hash와 같다. `%`는 이 프로그램에 없으므로 실제 HYHWPEQ.TTF도 공급했다.
  이 로컬 HYHWPEQ 버전은 과거 파일 해시와 다르며 동일 파일이라고 주장하지 않는다.
- 한컴바탕: 승인된 표준 Unicode 14,642자와 별도 11개 전용 기호 문자표로 독립 프로그램을
  복원했다. 대상 문서의 PDF에서 글꼴을 가져와 공급하지 않았다. glyf/hmtx/hint는 그대로이고,
  입력 순서와 PDF glyph ID로 기호 cmap을 복원했다. 브라우저에 필요한 OS/2·post는 같은 계열의
  로컬 메타데이터를 보완했으며 hhea 세 값 일치를 확인했다. 본문·기호의 좌표/윤곽 보정은 없다.
  독립 표준 문자표와 편람 참조의 비교 가능한 32개 글리프 윤곽은 같았다.
- 편람 U+26AB는 HCRBatang 프로그램을 공급했다. 중첩 표의 U+21E9는 원본 굴림체 슬롯에
  독립 Print가 사용하는 Haansoft Batang 대체를 명시했다.
- sample10 HWP는 원본 연결 그림 oracle.gif/rdb02.gif/s1.jpg를 WASM에도 공급했다.
  사용자 HWPX 표지의 미해결 연결 그림과 서로 다른 입력 조건이다.
- sample10 U+25B6는 독립 Type3 삼각형과 로컬 SPMJ의 윤곽·전진을 대조했다. 좌표는
  1/1000 em 이내 차이이며 byte 동일이라고 주장하지 않는다. 원본 기호 슬롯 5, fontId 2의
  `한양중고딕`에만 명조 보조 공급을 명시했다. 앞선 family 전체 대체는 본문 일부의 글꼴까지
  바꾸어 Native 7쪽·WASM 10쪽의 미세 하락을 만들었다. 이를 최종 증거로 쓰지 않고 원본 슬롯을
  분리한 환경에서 양쪽 763쪽을 다시 실행했다.

상용 글꼴 프로그램과 글꼴 복원용 PDF는 비공개 로컬 검증 자원이다. 이 PR에는 재배포하지 않고
출처·해시·독립성만 기록한다. 명령의 `<local-resource>`는 로컬 공급 자원이며 기계 경로를 뜻하지 않는다.
