## 기준과 소비 경로

39개 기능의 입력·페이지·기존 독립 근거는 기준 커밋의
`mydocs/pr/assets/planet6897_remaining39_20261111/maintainer-repair/latest-head-3575d814/claim-producers.json`
과 `claims/index.json`을 따른다. 각 PR의 표·그림·캡션·줄·HFT·Canvas paint 경로를 기존 검토와
대조했다. 추가한 딸기 family와 미해결 연결 그림 조건 외 기존 조판 경로를 변경하지 않았다.
표 경계 대조는 `mydocs/pr/assets/pr8896/latest-eb84/focus/native/*/execution.json`의 입력과
독립 PDF를 전체 페이지로 실행했다. CI·문서 전용 변경은 이번 제품 수정의 소비 경로 밖이다.

## 글꼴 환경 분리

WASM에는 Native에서 확정한 웹폰트 프로그램과 환경을 공급하고 기존 검토가 명시한 OS
Times New Roman 네 프로그램의 해시도 일치시켰다. 초기 공개 글꼴만 공급한 실행은 최종 증거에서 제외했다.
Native #8930 첫 쪽은 자동 준비 환경에 `selectedPrograms` 등이 빠져 작은 윤곽 차이가 생겼다.
기준 환경·프로그램을 명시한 재실행에서는 기준 PNG와 바이트까지 같았다. 이 재실행의 TSV를
보존했으며 허용치·PDF·제품 코드를 바꾸지 않았다. 원래 자동 실행과 제어 실행 로그는 비공개
`output/issue8957-stage2/`에 남아 있다.
