# 중첩 표 보호 문서의 WASM 전쪽 대조

교체 전 보존한 글꼴 공급 목록과 `H2GTRM.TTF`를 Visual Sweep에 명시했다. 두 실행은 같은 원본,
한컴 2020 Hancom PDF Print, 96 DPI, compat 2022와 2px raw 실루엣을 사용했다.
고정 devel과 이중선 보정 전 후보는 17쪽 전부에서 정본 보호값을 유지했으며 PNG가 페이지별로 같았다.
