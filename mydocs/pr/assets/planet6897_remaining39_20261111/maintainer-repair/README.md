# 저장 프레임 메인터너 보정 R7

코드 보정은 원 PR 39개의 통합 후보에 적용했다. 원본·독립 한컴 Print PDF·판정 기준을 변경하지 않았다. 전체 최종 검증은 별도로 진행 중이며 이 집중 결과만으로 통합 수용을 선언하지 않는다.

- 용량 컷으로 잇는 표 조각을 원본 마지막 조각의 원점으로 오인하던 경계를 고쳤다. HPV 79쪽은 마지막 31행까지 소유하고 80쪽에 짧은 추가 조각을 만들지 않는다.
- 물리 단 원점과 저장 vpos 원점을 함께 사용하여 연속 그림의 수용을 판정하고, 각 그림과 자기 재시작 본문이 같은 목표 쪽을 소비한다. HPV 158~163쪽의 그림이 한 번씩 순서대로 나오며 전체 235쪽을 보존한다.
- 빈 안내 줄이 이미 수용한 저장 표 원점에 간격을 다시 더하지 않도록 고쳤다. 결재문서 5쪽의 제출 줄을 옮기지 않고 뒤 제목 표의 위끝을 복구한다.

## 실제 회귀 재현

새 동일 검사 3건: 보정 전 0 PASS / 3 FAIL, 보정 후 3 PASS / 0 FAIL. 모두 Mac 최소 글꼴 격리 프로필에서 실행했다. 기존 관련 6개 모듈의 9건도 PASS다. 실행 명령·로그 해시·소스 해시는 [전후 실행 기록](test-before-after-state.json)에 보존했다. 로그 파일은 ignored output에만 둔다.

## 독립 Print 집중 측정

PDFium 96 DPI Print, 색상 경계 보정 전 2px raw. 원본 글꼴 Print 조건에서 결재문서 5쪽 Native 98.12%, fresh WASM 98.13%; HPV 79쪽 99.83%, 159~163쪽 99.76~99.84%다. 이는 일반 공개 글꼴 조건과 별도다. 공개 글꼴 조건의 결재문서 5쪽은 Native 96.67%, WASM 97.07%이며 두 조건을 섞지 않는다.

[집중 TSV](focus/)와 두 독립 PDF의 기하 JSON을 보존했다. `review/`에는 같은 쪽의 Native/fresh WASM review·overlay가 있으며 5·159·160쪽을 직접 열어 제목 표 원점·그림 내용·쪽 소속과 중복 여부를 판독했다. 미세한 글리프·획 차이가 남아 있으며 100% 동일로 주장하지 않는다. 새 검사의 고정 좌표는 양쪽 backend가 98% 이상인 원본 글꼴 조건의 독립 Print 위끝만 ±2px로 고정했다. 관계형 검사는 마지막 행·쪽 소속·순서·중복 방지를 확인한다.
