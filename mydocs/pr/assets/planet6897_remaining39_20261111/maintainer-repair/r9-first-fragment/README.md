# HPV 표 첫 조각 높이와 전체 행 본체 보정

원본 `samples/issue8842/1351000-201800239_hpv_cohort_final_report.hwp`와 독립 한/글 2020 Print `pdf/issue8842/1351000-201800239_hpv_cohort_final_report-2020.pdf`를 대조했다. 원 해결 #1510의 실제 보정 `1c17defd852989411fbc239644d6f1ca491cae47`은 전체 표 선언 높이에 맞추는 계약이고, #2195의 `bde419f3e927f629bb9c863cc55a448bc4175ca1`은 빈 호스트의 확대만 허용한다. 이 정상 계약은 유지한다.

문제의 구역 2·문단 47은 제목을 가진 15행 표다. 전체 행 선언 32,669HU는 개체 첫 조각 27,212HU와 다음 쪽 저장 원점 5,457HU의 합과 정확히 같다. 수정 전에는 전체를 첫 조각 높이로 압축하여 80쪽에 모두 넣고, 독립 Print의 81쪽 합계 두 행을 누락했다. 다음 원본 문단을 읽는 공통 Query에서 이 정수 단위 관계와 원본·비편집·행 측정 일치를 인증하고, 페이지 분할과 실제 paint가 같은 행 본체를 소비한다. 문서명이나 쪽 번호로 구현을 분기하지 않는다. HWPX 문단 지역 원점, 합성/편집 줄과 일반 전체 높이 fit은 바꾸지 않는다.

## 실제 완료 범위

- 전체 쪽수 235 유지, 80쪽 행 0~12와 81쪽 행 13~14의 소속 확인. 기존 79쪽 표 마지막 행도 유지.
- Native 원본 글꼴 조건 80쪽 99.90%, 81쪽 99.51%. 최소 글꼴·공개 웹폰트 조건은 각각 99.86%, 99.50%. 현재 PDFium·96 DPI·색상 경계 보정 전 2px raw 기준이며 TSV는 원문을 보존했다.
- 두 쪽의 review와 overlay 직접 판독: 표 외곽·병원 열·행 내용과 다음 본문의 위치가 Print와 대응한다. 누락했던 합계2·총합계 행을 복원했고 중복은 없다. 일부 글자·괘선의 미세 차이는 남는다.
- 최소 글꼴 `native-skia` 기존 검사 7 PASS: 앞 단계 표/그림/인라인 표 소속 3건, #5757 1건, #5879 2건, #5906 1건. 검사 제거와 기대값 변경은 없다.

## fresh WASM 및 새 회귀

최신 제품 499a50db7b의 fresh WASM 원본 글꼴 조건은 80쪽 99.90%, 81쪽 99.52%이며, 최소 글꼴·공개 웹폰트 조건은 99.86%, 99.51%다. 두 쪽의 Native/fresh WASM review·overlay를 직접 판독했다. 두 backend 모두 98% 이상인 이 두 쪽의 표 위끝만 독립 PDF ±2px로 고정하고, 첫 조각 행0~12와 이어받기 행13~14의 소속·합집합·중복 부재는 관계형으로 검사한다.

같은 컴파일된 검사와 원본 입력에서 보정 전 frozen Native(R7)는 81쪽 이어받기 부재로 실제 1 FAIL, R9는 1 PASS다. 최소 글꼴 환경에서 실행했으며, 정규 nextest 수집도 1 PASS다. 처음 누락 의존성으로 컴파일하지 못한 실행과 nextest가 CLI 환경 변수를 덮어쓴 실행은 보정 전 실패 증거로 사용하지 않는다. [검사·WASM producer와 로그 hash](regression-wasm-validation.json)를 보존한다. `.log` 원문은 ignored output에만 둔다.
