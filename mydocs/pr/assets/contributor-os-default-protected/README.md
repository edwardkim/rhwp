# 기여자용 OS 기본 글꼴 100% 보호 목록

[등록·회귀·제출 검증 정본](../../../manual/verification/visual_verification_governance.md#기여자용-os-기본-글꼴-100-보호)을 따른다.
이 목록은 메인터너·콜라보레이터의 비공개 원본 글꼴 기반 정본 전체 보호 TSV와 별개다.

## 등록된 페이지

현재 세 OS의 기본 글꼴만으로 Native/fresh WASM raw 100% 검증을 모두 마쳐 등록한 페이지는 없다.
등록 후보의 일부 환경 측정만으로 보호 등록 완료를 표시하지 않는다.
최초 등록 시 원본/PDF의 고정 해시·페이지, OS별 기본 글꼴 목록·실제 선택,
Native/fresh WASM의 정밀 raw·미대응 수·TSV·review/overlay, ±1px 회귀 함수와 독립 기대값을
여기에 연결한다. 등록 뒤에는 기여자가 제출 전 해당 페이지의 raw 100% 유지를 검증해야 한다.

## 등록 검증 중

#7733 화학물질 문서80쪽과 #7735 형식문서8쪽은 원본 글꼴 일반 환경에서 먼저 개선했다.
이 결과를 OS 기본 글꼴만 사용한 100% 등록 증거로 쓰지 않는다. 세 OS의 기본 글꼴 조건과
각 backend의 실제 결과를 확인한 뒤 등록 여부를 결정한다.
