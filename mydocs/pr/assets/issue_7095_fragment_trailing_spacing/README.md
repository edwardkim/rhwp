## 코퍼스 A/B — 첫 조각은 대상이 아니다

`samples` 1,016문서를 수정 전후로 전수 렌더해 비교했다. 처음에는 첫 조각에도 적용했는데
정본이 **반대**라는 반례 3건이 나왔다 — 한/글은 첫 조각에서 그 간격을 **그린다**.

| 문서 | 쪽 | 조각 | 정본 | 잘못 빼면 |
| --- | ---: | --- | ---: | ---: |
| `정책연구용역사업 중간진도보고서…` | 163 | `start=[] end=[3]` | 1034.19 | 1020.96 |
| `1480000-201900042-chemical-labeling-standards` | 34 | `start=[] end=[7]` | 1022.83 | 1021.47 |
| `1490000-200800034_vietnam_labor_report` | 27 | `start=[] end=[23]` | 1022.83 | 1022.25 |

같은 정책연구 문서의 161·164쪽은 **이어받은** 조각이고 정본 1010.67 로 빼야 맞는다. 첫 조각과
이어짐 조각이 정확히 갈린다. 조건을 좁힌 뒤 **악화 0 · 개선 6쪽**이다.

## 남은 차이


가로로 글자가 벌어지는 것(`ink_match` 12~18%)은 한글 전진폭 축이고 세로 조판과 독립이다.
이 변경은 세로 축만 주장한다.
