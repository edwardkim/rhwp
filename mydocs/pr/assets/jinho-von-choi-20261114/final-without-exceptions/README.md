# 예외 없는 보완의 검증 체크포인트

이 폴더는 최신 devel `e7ee272cfa33a960b0d0d924983d29e6509903e0` 통합 전의
중간 증거다. 각 영수증의 실제 producer를 보존하며 최종 제출 완료를 뜻하지 않는다.
Native 전쪽과 일부 WASM 결과의 source는 서로 다르므로 하나의 최종 검증으로 합산하지 않는다.

`90d7515dee0b1973a7bf206c3d051220a008efc3`에서 legacy Print 그림 pen의 실제
독립 경계를 복원했다. 기존 그림 fill과 외곽 획은 각각 0.480pt와 0.120pt이며
600dpi 장치 pen의 공통 소비 계약으로 설명한다. 원문 crop이나 그림 좌표는 바꾸지 않는다.

최신 base의 Print 주 프로그램·글리프 소유 보완과 보호 하한 30행 상향을 통합한 뒤
두 경로 전체 보호와 필수 검증을 다시 완료한다. 사전 결과나 과거 기준을 최종 통과로 대신하지 않는다.
