# 예외 없는 검증의 중간 경계 기록

제품 source는 `235da09ed62d23425dad71dddac2bffa9f70cdc1`, 보호 정본은
`8f073dddd67cf8f44bea7c0315c3f9950ba73641e9393747cdbc52d24b33f9a1`다.
Native 전체 보호 1,771행은 공식값 하락 0건이다. 이것을 모든 직접 시각 차이의 해결로
확대하지 않는다. WASM 초기 작은 경계의 4·11·14쪽은 각각 0.01%p 미달이었다.

굴림체의 U+21E9 결측은 독립 Print가 사용하는 Haansoft Batang으로 연결했다.
문서 전체 설정에서 두 경로의 4쪽은 100.00%이며, 11·14쪽의 0.01%p 차이는 남았다.
쪽별 글꼴 선택·좌표 보정·마스크·허용치 변경이나 기존 차이 예외는 적용하지 않았다.
최신 exact devel을 같은 환경에서 빌드해 실제 프로그램과 Print 프레임 소비를 대조 중이다.

전체 Rust 실행은 13,607건 중 13,606건 통과·신규 보안 입력 전달 1건 실패였다.
검사기는 `samples/` 상대 경로를 요구하지만 검증 스크립트가 절대 경로를 전달했다.
같은 테스트 실행 파일에 상대 경로 51개를 명시한 재실행은 통과했다. 공개 증적 위치의
추가 두 입력도 실제 CLI 세 탐지기로 검사했으며 6개 결과가 모두 clean이다.
이를 최초 전체 실행의 실패 0건으로 바꿔 기록하지 않는다. 나머지 필수 게이트는 미완료다.

PDF Gulim subset은 윤곽 대응 진단에만 메모리에서 읽었다. 출력 글꼴로 등록하거나
파일로 추출·재배포하지 않았다. ToUnicode의 네 오기를 로컬 글리프와 분리 대조했다.
사용자 제공 HBATANG은 그대로 사용하며 새 상용 프로그램을 커밋하지 않는다.
