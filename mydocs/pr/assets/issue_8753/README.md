### 직접 판독 (3쪽)

- 제목 표 「Ⅱ 구역계 변경」은 어울림 표 왼쪽 host 줄에 놓입니다.
- 「□ 사업개요」와 ㅇ 네 줄은 표 왼쪽 차선에, 「□ 추진경위」는 표 아래에 놓입니다. 줄 위치는 PDF와 같습니다.

남은 차이(수정 전부터 있던 것):
- 빈 host 어울림 표 테두리가 세로 오프셋(522HU, 약 7px)만큼 위에 그려집니다.
- 그 테두리 높이는 선언 높이(228px)로 그려지고, PDF는 행 높이(169px)입니다.
- WASM의 ㅇ줄(한컴돋움 굵게)은 굵기 합성이 Native와 다릅니다.
