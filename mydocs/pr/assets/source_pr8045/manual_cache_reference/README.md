# #8045 수동 줄 캐시의 참고 원본

이 입력은 잘못된 기존 기대값의 원인을 보존하는 참고 자료다. 활성 회귀 fixture나
출력 일치 완료 증거로 쓰지 않는다. 기존 생성기의 수동 줄 위치는 메모
`column_start=21000`, `vertical_pos=300`이지만, 같은 재현을 한컴에서 저장하면
각각 20100, 1600이 된다. 원본을 보존하고 실제 한컴 저장본과 구분한다.

| 파일 | SHA-256 |
| --- | --- |
| `nested-SQUARE.hwpx` | `439d5beeb0738484464f471978feb048a961d96e566c243c3c088c79077a37e9` |
| `nested-SQUARE-2020.pdf` | `76863df37cff4d282ddc9ca7df57056e7137578bd471c7b577dda61e748bc7c6` |

PDF는 위 원본 그대로 한컴 2020 MCP Print·1-up으로 출력한 1쪽이다.
이 원본의 Native/fresh raw는 93.69297/93.39219%지만 메모 위치가 다르다.
고정 base의 94.12874/93.85070%보다 각각 0.43577/0.45851%p 낮다. 따라서 이
참고 입력에 대해 0.1%p 무회귀나 직접 판독 통과를 선언하지 않는다. 이 차이는
이번 마지막 공통 보정 전 Native253/fresh WASM072에도 동일했다.

기존 75.58px+280px 검사를 제거하고, 독립 근거가 있는 한컴 저장본을 사용하는
새 이름의 관계·중요 원점 검사로 교체한다. 정식 입력은
`tests/fixtures/pr8045_square_wrap/square-hancom2020.hwpx`다. 해당 저장본의 통과를
이 수동 원본의 일치로 바꾸어 보고하지 않는다. 삭제된 sample16·편람 자료와는
무관하며 해당 자료의 검사·파생 참조를 복원하지 않는다.
