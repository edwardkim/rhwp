## 근거와 재사용 범위

- [전체 페이지 비교 JSON](comparison.json), [TSV](comparison.tsv).
- 각 `native/<key>/`·`wasm/<key>/`에 후보의 전쪽 TSV·실루엣 manifest를 보존했다.
- 현재 base의 실제 기록은 `mydocs/pr/assets/pr8945/protection/head-<backend>/<key>/`다.
  기록 source `e98d884fc35295c8b612ceb0ac86437fb8108fee`와 현재 base의 diff는 `mydocs/`뿐이다.
  [실제 변경 경로](../receipts/base-record-equivalence.json)와 입력/PDF·공급 글꼴·helper·연결 이미지의
  hash를 확인했다. 후보를 실제 다시 렌더하고 각 쪽의 PNG SHA-256과 raw 원래 값을 대조했다.
- sample10의 WASM은 원본이 참조한 연결 이미지 3개를 동일하게 공급해 763쪽 모두 실행했다.
- 기존 기준·글꼴 차이의 직접 비교는 [직전 정본 보호 기록](../../pr8945/protection/README.md)을
  재사용한다. 새 차이가 없음을 이번 실제 PNG 대조로 검증했으며 점수만으로 판독을 대체하지 않는다.
- 필수 HWPX Native 편람 gate는 별도로 실행해 383쪽 PASS를 확인했다. 이 필수 gate와
  과거 보호 TSV 전체의 공식 값 미재현은 별도 판정이다.

기존 #8945 예외는 그 PR 한정이었다. 작업지시자는 2026-11-11 **“예외 없이 기존 차이도 먼저 해결”**을
선택했다. 위 결과는 진단 당시 상태이며 보호 통과 판정이 아니다. 기존 911행을 보정·재검증한 뒤
제출한다. 정본 TSV·허용치·branch protection은 변경하지 않는다.

생성하거나 승인·병합하지 않는다.
