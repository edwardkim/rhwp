# Issue #7642: HWP3 저장 간격과 도형 속성 보정

- 원본 `samples/hwp3-sample16.hwp`, 기준 `pdf/issue7642-hwp3-original-print/hwp3-sample16-2020.pdf`. 한컴 2020 Print.
- 측정 source는 stage507의 `0e62c1b289 + 보존된 prototype patch`다. stage510 부분 측정에서 3쪽 90.86551%, 64쪽 97.97455%다. 전체64쪽·fresh WASM을 완료했다고 주장하지 않는다.
- 같은 원본의 정상 한컴 저장본과 대조해 새 쪽의 앞 간격, 단독 인라인 도형의 호스트 줄간격, 둥근 모서리와 점선 속성을 보존했다. Native 측정·배치 모두 같은 저장 원점을 사용한다.
- 대표 PNG는 해당 측정의 원본 raster로 새 합성했다. 3쪽은 큰 세로 이동과 도형 모양 차이가 해소됐지만 장평·영문 기울기·미세 간격 차이는 계속 직접 판독해야 한다.
- 이 증거의 프로토타입에는 나중에 폐기한 수식 줄 예약 보존도 포함되므로 새 확정 코드의 전체 재검증으로 승격하지 않는다.
- TSV·해시·명령·patch와 원본 raster는 ignored stage507/510/514에 보존한다.
