# PR #9339 보완 계획 — 한 칸 안에서 그림별 가로 기준과 겹침 판정

대상은 #9338의 공개 HWPX 두 개와 `grid2x2.hwpx`에서 그림 하나의 속성만 바꾼 대조군이다. 한컴 2024에서 네 번째 그림을 같은 위치의 오른쪽 정렬로 바꾼 원본과 대조군은 96 DPI 전쪽 픽셀이 같다. 가로 위치만 1,000 HWPUNIT 옮긴 별도의 두 인쇄본에서는 그 그림만 움직인다.

2026-11-23 작업지시자가 메인테이너의 제품 보완과 필수 로컬 검증을 승인했다. 추가로 인쇄한 중앙 정렬 대조군도 원본과 전쪽 픽셀이 같았다. 앞 그림에만 겹침을 허용한 입력은 왼쪽 열만 겹쳤고, 뒤 그림에만 허용한 입력은 오른쪽 열만 겹쳤다.

## 공통 배치 보완 범위

1. 칸 너비, 문단 들여쓰기, 가로 기준과 정렬, 부호 있는 오프셋, 바깥 여백이 만드는 그림별 물리 좌표를 기존 칸 그림 경로와 대조한다. 같은 기준 사각형과 정렬을 사용하는 경로에서 같은 계산 결과를 소비하게 한다. 네 번째 그림의 정렬 때문에 앞선 그림들의 세로 배치까지 취소되는 조건과 그림 중심이 칸 폭을 벗어날 때의 일괄 취소 조건을 수정 대상으로 삼는다.
2. `allowOverlap`을 가진 그림의 참여 범위, 선행 그림과의 수평·수직 교차, 빈 글줄이 밀리는 조건을 각각 데스크톱 인쇄와 비교한다. 입력에 기록된 `flowWithText`와 `allowOverlap`의 조합은 HWPX 저장값으로 구분하고, 편집기에서 설정할 수 있는 조합으로 일반화하지 않는다.
3. 줄 점유·그림 위치·칸의 요구 높이·실제 원점을 같은 계산 결과에서 가져오는지 확인한다. 저장 줄을 쓰는 문단, 양수 오프셋, 기존 자리차지·캡션 경로에는 각자의 기존 배치 계약을 적용한다. 새 고정값이나 문서 이름에 따른 조건을 도입하지 않는다.

## 검증과 수용

- 같은 공개 원본의 네 그림이 같은 열에서는 순서대로 놓이는지, 가로로 떨어진 그림끼리 세로로 밀리지 않는지, 한 그림의 정렬을 바꿔도 물리 위치가 같으면 전체 결과가 같은지 확인한다. 중간 셀·아래쪽 후속 문단, 네 그림의 식별자·순서·크기를 함께 대조한다.
- 공개 원본 두 개와 수정한 대조군 전체를 한컴 2024 Print, Native, 새로 빌드한 WASM Canvas에서 같은 쪽·배율로 비교하고 미달·겹침을 재확인한다. 회귀 추가는 시각 검증 선행 조건을 충족한 뒤 진행하고, 검사 첫머리의 독립 Print와 측정 정보를 갱신한다.
- 최종 후보와 최신 devel에서 관련 경로를 같은 조건으로 실행한다. 통합 전 변경 범위에 해당하는 전체 Rust 회귀·Native 공식 검사·lint와 정본 보호 전쪽 검증을 완료한다. 원 기여 커밋을 보존한다.
