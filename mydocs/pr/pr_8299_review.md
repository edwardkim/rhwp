## 주장·현재 devel 대조와 보정 방침

vpos 재계산이 저장 줄 없는 중간 문단의 물리 공간을 없애지 않게 한다.

현행 recalculate_section_vpos는 빈 line_segs를 건너간다. 공간 보존과 현재 리셋 경계의 실제 결과를 실행으로 판정한다.

원본 저장 gap과 앞 문단 이동량을 보존하고 #8290 간격 변경·쪽/단 리셋·여러 연속 무저장 문단을 함께 검사한다. 공개 구성 검사의 integration 이관은 동일 입력·assertion 보호를 확인한다.

이 절의 현재 관측은 코드·이력 대조이며 현재 base/head의 실제 재현 결과는 검증 단계에서 추가한다.
