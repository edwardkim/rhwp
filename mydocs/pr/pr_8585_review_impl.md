# PR #8585 메인터너 보정 제안

이 문서는 [검토 기록](pr_8585_review.md)의 잔여 정렬 차이에 대한 로컬 보정 범위다.
원 PR의 사진 줄바꿈 복원은 보존한다. 원 head의 Native/fresh WASM 검증 후 같은 가시성 branch에서 보정에 착수한다.

## 한 단위의 보정 범위

1. 글상자 여러 줄 그림 배치가 본문과 같은 줄 소속·정렬 폭을 소비하게 한다.
   마지막 인라인 개체 **뒤**의 말미 공백만 기존 공통 helper로 처리하고,
   개체 사이 공백·밑줄 공백·저장 줄과 fresh 조판의 계약을 보존한다.
   관측된 3.3px·13.3px를 위치 상수로 더하거나 특정 문서·공백 개수로 분기하지 않는다.
2. 동일 HWP·독립 웹한글 Print PDF로 Native/fresh optimized WASM 전 1쪽을 다시 비교하고
   대응 사진 열·줄 간격·글상자 포함과 앞뒤 본문의 보존을 직접 판독한다.
   두 경로 모두 raw 90% 이상이고 정렬 차이가 해소된 뒤 완료로 판정한다.
3. 기존 기여 테스트 안에서 6개 사진의 2열·3줄 및 대응 열 정렬 관계를 보강한다.
   절대 x 좌표를 고정하지 않는다. 첫머리에 관계형 유형·실제 측정·직전 commit 정보를 기록하고,
   기존 자동 수집 suite를 유지한다. 동일 원본의 쪽수·내용 대응을 oracle 원장에도 등록한다.
4. 보정 head에서 관련 focused·최소 글꼴 환경·새 sample 보안 검사와 필수 Rust lint 묶음,
   workspace build·release-test 전체·Native Skia 3종·fresh WASM·시각 검증을 완료한다.
   #6465의 소유 줄, #6651의 첫 줄 오프셋, #6173의 개체 사이 공백, #8122의 저장 줄 없는
   세로 정렬을 정상 대조군으로 유지하고 실제 영향을 받는 출력도 대조한다.

원 code head에 새로운 source/test/baseline 변경을 추가하므로 기존 녹색 GitHub CI를
새 head의 필수 로컬 검사 생략 근거로 사용하지 않는다. 원격 branch의 head가 바뀌면 새 기여를 먼저 확인하고,
원 기여를 rewrite하지 않은 같은 가시성 branch에서 보정한다.

## 범위와 완료 경계

그림 코덱·폰트 프로그램·표 셀의 별도 배치 문제 #8576·#8579는 이 보정의 변경 대상으로 확장하지 않는다.
현재 source의 원인인 텍스트·그림 정렬 폭 불일치를 공통 계약에서 고치는 범위다.
최신 devel의 clean merge simulation과 원 head 테스트 통과를 새 보정의 실행 증거로 대신하지 않는다.

로컬 후보와 재현 가능한 증적을 완성한 뒤 push·새 head CI·merge·첫 기여 감사 댓글의
원격 처리 범위를 별도로 확인한다. 현재 문서는 해당 원격 동작의 승인으로 해석하지 않는다.
