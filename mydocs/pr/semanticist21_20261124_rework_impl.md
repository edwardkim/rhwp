# #9281·#9286·#9325 메인테이너 보완

세 원 기여를 병합한 검토 커밋은 `327be655a1`이다. [수정 전 재현 자료](assets/semanticist21-20261124-rework/README.md)에 따라 다음 경로를 검증한다.

- #9281. 첫 문단의 구역·단 정의가 실제 문단 스트림에서도 연속하는지 판정한다. 두 정의 사이에 글자가 들어간 원본과 바로 이어지는 대조군의 용지, 쪽 번호, 본문과 저장 결과를 한컴 인쇄와 비교한다.
- #9286. 이전 rhwp가 생성한 무표지 HWPX의 채움 투명도를 사용자가 명시적으로 복구하는 경로를 제공한다. 한컴의 정수 투명도와 새 저장본을 보존하며, 채움과 윤곽선의 투명도도 각각 적용한다. v0.9.1로 생성한 파일을 다시 저장하고 두 렌더러에서 대조한다.
- #9325. Studio에서 꺾인 연결선의 가운데 손잡이가 모델의 가운데 선분을 이동하게 한다. 본문·셀 안의 이동 축, 크기, 실행 취소·다시 실행과 저장·재열기를 실제 마우스 입력으로 확인한다.

추가로 승인된 인쇄 대조군은 세 가지다. 단 정의가 없는 첫 구역은 Windows 한컴 2020에서 A4·시작 번호 1이며 바탕쪽이 사라진다. 꺾임이 하나인 곡선은 한컴 2024 PDF의 단일 ¼타원, 양 끝만 있는 곡선은 PDF에서 스트로크가 없는 것이 기준이다. 각 입력을 포함한 전체 쪽을 비교하고, 손잡이가 있는 곡선과 일반 직선을 함께 확인한다.

### #9286 파선 타원의 진행 방향

Windows 한컴 2024가 같은 타원을 인쇄한 원본 HWP와 HWPX에서 윤곽의 첫 파선은 오른쪽 끝에서 위쪽으로 이어졌다. Native SVG와 Canvas 타원은 오른쪽에서 아래쪽으로 그려 96 DPI에서 실루엣 차이 656픽셀이 모두 테두리에 모였다. 수정 전 Native 일치율은 97.04%이며 투명 채움을 복구한 HWPX와 원본 HWP의 제품 PNG는 같았다.

원본의 선 종류·굵기·색에서 반복 구간을 구하는 기존 규칙을 쓰고, HWP 타원의 윤곽 진행 방향을 공통 그리기 경로에 반영한다. 쪽 원점과 도형 프레임, 회전·대칭, 채움과 선의 투명도를 보존한다. 원본·복구본과 함께 실선, 각기 다른 장단축, 그라데이션 채움 및 묶음 도형을 대조한다.
