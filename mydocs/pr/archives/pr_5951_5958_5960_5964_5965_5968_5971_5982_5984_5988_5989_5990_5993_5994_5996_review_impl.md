## 최종 판단

통합 후보는 로컬 검증을 통과했고, source PR head도 체리픽 이후 재조회한 GitHub head와 일치한다. 통합 PR은
작업지시자의 사전 승인을 받은 뒤에만 remote push 및 PR 생성한다. PR 생성 뒤에는 최신 GitHub CI,
mergeability와 review-only 문서 경로 fast-pass 여부를 다시 확인해야 한다.
