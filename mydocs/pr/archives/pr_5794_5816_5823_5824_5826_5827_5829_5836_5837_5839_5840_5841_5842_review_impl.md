# 열린 PR 통합 검토 - #5794, #5816, #5823, #5824, #5826, #5827, #5829, #5836, #5837, #5839, #5840, #5841, #5842

## 적용 범위

최신 `upstream/devel@2afa53a549bef7320600363d86edca247549d9e1` 위에 source head 13개를 오래된 번호 순으로 누적 적용했다. source PR는 모두 non-draft, `clean`이었고, 적용 SHA와 개별 판정은 같은 디렉터리의 `pr_<번호>_review.md`에 남겼다.

## 메인터너 보정

- #5836은 #5826의 #5804 하이픈 구현을 중복 적용한 뒤 revert하는 이력을 가진다. 최종 코드 선택은 #5826과 같았지만 stale SVG golden을 함께 되돌렸다.
- 통합 full nextest에서 이 golden만 실패한 것을 확인한 뒤, #5826의 현재 출력과 byte-identical인 golden을 복구했다. 코드 의미를 새로 정한 것이 아니라 중복 충돌이 복원한 오래된 test-data를 정확히 교정한 것이다.

## 로컬 검증

- `cargo fmt --all -- --check`, `cargo clippy --locked --all-targets --target-dir target/pr-review -- -D warnings`, unit tier check, suite manifest check를 통과했다.
- `cargo nextest run --locked --cargo-profile release-test --target-dir target/pr-review --tests --test-threads 12 --no-fail-fast`: **8,109/8,109 passed**, slow 3, skipped 39, 200.820s.
- 20개 직접 회귀 계약을 추가로 실행해 모두 통과했다. CLI 14개, renderer/serializer/parser/page-gate regression을 포함한다.
- native-Skia library 3,950 passed/13 ignored, focused native-Skia 6개 통과. standard WASM은 `scripts/wasm-pack-locked.sh --target web --out-dir pkg --no-opt`로 통과했다. Docker 표준 WASM은 이 호스트에 Docker CLI가 없어 실행하지 못했다.
- IR field sweep 4/4 및 517행 dump가 baseline과 동일했고, overflow-cell baseline 1/1 및 592행 dump가 baseline과 동일했다.

## 시각 증적과 잔여사항

- HWP 2020 MCP로 생성한 기준 PDF 5개는 `pdf/pr_open_20260821/`에 보관했다. job, SHA-256, 페이지와 대표 PNG는 각 원 PR 검토 문서에 기록했다.
- #5792와 #5807, 그리고 일부 비교 문서는 표/순서의 목표 계약은 통과했으나 현재 renderer와 HWP 2020 PDF 사이 typography·page-flow 충실도 차이가 남았다. 이를 이 통합의 해결 완료라고 주장하지 않으며 대표 PNG와 수치를 asset으로 보존했다.
- #5799의 MCP 재변환은 `run_status=139`로 실패해 추적 중인 기존 PDF를 기준으로 사용했다. endpoint·token 등 비밀 정보는 기록하지 않았다.

## 후속 처리

1. rebase 직전 source head, mergeability, CI를 다시 확인한다.
2. 통합 PR에는 이 문서, 원 PR별 archive 문서, PDF/PNG 증적, 오늘할일을 함께 포함한다. 통합 PR 번호 기준 문서나 별도 docs-only PR은 만들지 않는다.
3. GitHub CI가 완료된 뒤에만 merge 및 원 PR/issue comment, branch/worktree 정리를 수행한다.
