## 구현과 과거 실제 CI

선언 높이보다 큰 실제 안 여백+글줄 점유는 측정과 행 배치 모두에서 유지한다. cell_padding_exceeding_declared_height_grows_row는 셀이 원본 PAD_TOP+line_height+PAD_BOTTOM 이상이고 글줄이 위 여백 아래에 포함되는지를 검사한다. unused padding 필드와 진짜 선언 여백을 구분하는 #6442, 기존 최소 높이 및 content-cut fit을 보호하는 #7234 경계를 함께 확인한다. RowBreak 이름을 행 경계 전용 정책으로 확대 해석하지 않는다.


통합 merge `af6bb05b26887135fb9da0fa4e54ca7205564fca`와 [Full code CI](https://github.com/edwardkim/rhwp/actions/runs/40489874571)는 완료 이력이다. 엔진·테스트·baseline은 이번 변경에서 수정하지 않았다.

## 입력·페이지·대표 증거

[개별 리뷰](pr_8065_review.md)에 실제 검증한 파일·SHA·Print·페이지·TSV와 대표 이미지를 기록했다. 대체 입력은 원 보고 실물 문서의 직접 검증으로 표현하지 않는다. 공식 배포 문서의 내용 대응 확인도 작성자의 원본 바이트 동일성을 뜻하지 않는다.
