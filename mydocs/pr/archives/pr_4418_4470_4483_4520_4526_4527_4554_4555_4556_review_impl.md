## 다음 단계와 rollback 경계

현재 branch는 local 통합 검토·보정·증적만 포함한다. 원 PR branch를 rewrite하거나 원격으로
push/merge/comment하지 않았다. 원격 통합 PR 생성, CI 대기, 원 PR close·감사 comment, branch/worktree 정리는
작업지시자 승인 뒤 `pr_review_workflow.md`의 collaborator 경로로 수행한다.

**로컬 권고: 최신 누적 head의 로컬 CI 검증은 완료됐다. #4520의 앵커 흐름 보정과 #4566의 관측 진단은
각각의 focused 회귀를 통과했다. 다만 한컴 PDF 시각 fidelity는 아직 수용 판정을 내리지 않으며, 남은
차이는 #3820에서 후속 검증한다. 통합 PR의 merge 조건은 최신 GitHub CI 통과와 작업지시자 승인이다.**
