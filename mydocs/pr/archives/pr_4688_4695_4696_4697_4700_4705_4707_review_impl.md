`issue_3915_verify_axes_both_reported`를 실행해 총 6개 test case를 다시 통과했다. 전체 nextest 결과는 추가 전 누적 code

모두 통과했다.

전체 nextest는 systemd user service의 기본 시작 제한을 피하려고 한 번 실행했으나, 작업지시자 요청에
따라 service는 자동 수거된 뒤 별도 등록 없이 제거했다. 이후 Native Skia는 foreground PTY에서 실행했다.
앞으로 이 검토 절차에서는 service wrapper를 사용하지 않는다.

## PR 생성 전 상태

이 문서는 통합 PR 번호를 갖지 않는다. 외부 원 PR별 판단은 `pr_4688_review.md`부터
`pr_4707_review.md`까지 분리했다. PR 생성 뒤 최신 `devel` merge simulation, 원 PR 최신 head 및
GitHub required check를 다시 확인하고, 작업지시자 승인 전에는 merge·close·comment를 수행하지 않는다.
