## 최종 판정 - 통합 PR 준비 완료

다섯 원 PR은 각각 **수용** 또는 **메인터너 보정 후 수용**으로 판정한다. 이 누적 head에 대한 GitHub
required CI는 통합 PR을 만든 뒤 최신 head에서 확인한다. 성공 전에는 원 PR의 close, contributor fork branch
삭제, 완료 comment를 수행하지 않는다.
