## 코드와 테스트 검토

`src/renderer/layout/paragraph_layout.rs`의 인라인 표 fallback에서 기준선 기준 계산값이 현재 줄 위로 올라가는 경우에만 `current_y + outer_margin_top`을 사용한다. 이미 저장된 outer band가 입증된 경로와 잘리지 않은 기준선 경로는 바꾸지 않는다.

원 PR이 수정한 기존 `tests/issue_3820_body_top_table_border_clip.rs` p33 기대값은 표 테두리 위 바깥여백 140 HWPUNIT 반영에 대응한다. 무관한 successor 283 HWPUNIT 계약은 유지한다. 이번 검토에서 공차나 기준선을 추가 완화하지 않았다.

- 새 집중 3개 통과: p33 잘린 인라인 표 위 여백, p35 입증된 band 경로 유지, p34 잘리지 않은 경로 유지.
- 기존 #3820 p33 회귀도 통과. 통합 집중 29개 통과.
- 전체 기본 기능 회귀 9,463개 통과·1개 실패·46개 skip. 해당 4개 계약은 실패하지 않았다.
- 원 PR의 대규모 10k/75k 무페이지수 변화 보고는 이번 독립 실행 결과가 아니다.
