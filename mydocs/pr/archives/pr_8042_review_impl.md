## 구현과 과거 실제 CI

묶기/풀기 뒤 필드 보존과 회전 자식 원점의 계약을 검토한다. 실제 자식 paint 행렬과 저장 행렬을 맞추고 변환 윤곽의 합집합을 그룹 틀로 사용한다. 본문 필드의 지역 번호와 표 셀 필드의 루트 소유 번호를 분리해 공통 삽입·도형 제거·묶기/풀기가 같은 주소 변환을 소비한다. 원 #7588의 재현 검사와 메인터너 보정의 활성 셀 주소 검사를 구분한다.


통합 merge `af6bb05b26887135fb9da0fa4e54ca7205564fca`와 [Full code CI](https://github.com/edwardkim/rhwp/actions/runs/40489874571)는 완료 이력이다. 엔진·테스트·baseline은 이번 변경에서 수정하지 않았다.

## 입력·페이지·대표 증거

[개별 리뷰](pr_8042_review.md)에 실제 검증한 파일·SHA·Print·페이지·TSV와 대표 이미지를 기록했다. 대체 입력은 원 보고 실물 문서의 직접 검증으로 표현하지 않는다. 공식 배포 문서의 내용 대응 확인도 작성자의 원본 바이트 동일성을 뜻하지 않는다.

공개 재현 계약의 검증 범위만 인정한다.
