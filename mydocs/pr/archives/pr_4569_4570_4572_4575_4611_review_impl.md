## 후속 절차

1. 이 branch를 원본 저장소의 임시 head branch로 push하고 `devel` 대상 통합 PR을 생성한다.
2. 최신 code head의 Full CI, CodeQL, Renderer 관련 required checks를 확인한다.
3. 현재 새 릴리스 준비 중이므로 CI가 녹색이어도 merge, 원 PR close, issue close, branch cleanup을 하지 않는다.
4. 릴리스 hold가 해제되고 작업지시자가 승인한 뒤에만 통합 PR merge와 `post_merge.md` 7절 후속 처리를 수행한다.
