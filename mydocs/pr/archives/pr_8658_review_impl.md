## 승인 뒤 한 단위로 수행할 범위

1. `cell_no_overlap_square_stack`의 점유 결과 → HeightMeasurer의 줄/개체 내용 높이·안 여백 → 행 최소 높이·선언 높이 수용 → 일반/partial 셀 정렬·그림 원점과 뒤 본문까지 추적한다. 실제로 요구 높이를 잃거나 덮는 소비 지점에서 공통 규칙을 고친다. 3.8px 상수·문서 ID·화면 맞춤 분기를 추가하지 않는다.
2. HU 좌표의 겹침 계획과 최종 paint의 별도 재계산이 필요한 독립 계약인지 확인한다. 같은 좌표와 규칙이면 공통 결과를 소비하게 하고, 필요한 예외라면 좌표계·적용 경계·반례와 실제 결과를 기록한다. 빈 줄 점유, 그림 유닛 소유와 물리 공간은 구분한다.
3. 원 3입력·CENTER·선언 높이 경계, 겹침 허용/가로 비충돌 정상 대조군과 해당 그림 뒤 본문을 확인한다. 분할 행은 앞뒤 컷·유닛 누락/중복·요구/예약/배치 높이·후속 내용까지 검사한다. 현재 base에 수용된 #8599·#8683 등의 영향을 받는 기능도 같은 조건에서 보존을 대조한다.
4. 관련 전쪽 Native/fresh optimized WASM이 모두 raw 90% 이상이고 직접 판독에서 결함이 없어진 뒤에만 필요한 관계형 회귀를 추가·교정한다. 기존 신규 테스트의 첫머리 측정 근거도 현행 규약에 맞춘다. 정확한 기존 테스트·baseline은 유지하고, 기대값이나 기준 PDF를 후보에 맞춰 바꾸지 않는다.
5. 보정 최종 code head에서 최소 글꼴 집중/전체 회귀, Native 공식 3종, Rust lint 묶음·manifest, fresh WASM·실제 Canvas/SVG 소비 및 변경 범위별 필수 검증과 Native 편람 383쪽 gate를 완료한다. 이미 끝난 동일 code head 검사는 canonical 재사용 조건을 실제로 만족할 때만 재사용한다. 원본/PDF·전쪽 TSV·대표 PNG를 정식 경로에 보존하고 실제 사용 파일의 commit 일치를 확인한다.

## 범위와 원격 경계

원 PR의 모든 잔여 문제나 엔진 전체를 재작성하는 계획이 아니다. 검출한 선언 높이 경계와 그 공통 소비·소유 계약을 해결하고 필요한 정상 경계를 확인한다. 범위를 넘어서는 새 결함이 나오면 원본과 근거를 구분해 작업지시자에게 보고한다.

이번 계획의 승인은 로컬 보정·필수 검증 범위다. 원 fork는 기존에 push 권한이 없는 것으로 확인된 저장소지만 이번 원격 처리 시 실제 권한을 다시 조회한다. 원격 push·새 통합 PR·공개 댓글·merge는 로컬 검증 완료 뒤 실제 후보와 경로를 제시하고 별도 승인을 받는다.
