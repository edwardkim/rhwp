## 남은 절차

통합 PR 생성은 작업지시자 사전 승인 뒤에만 remote push와 PR 생성을 진행한다. PR 생성 뒤 최신 GitHub CI와
mergeability를 확인하고, merge 승인 뒤 원 PR별 comment/close 및 branch/worktree 정리를 `post_merge.md`에
따라 처리한다.
