## 남은 처리 순서

1. 사용자의 PR 생성 승인을 받았다. 테스트 보정을 위 code commit으로 고정하고 최종 증적·리뷰·오늘할일은 별도 문서 commit으로 같은 통합 PR에 포함한다. 원시 로그와 파생 하네스는 포함하지 않는다.
2. 원격 최신 head·CI와 통합 PR gate를 확인한다. 저장소 owner를 자동 reviewer로 지정하지 않는다.
3. merge 후 실제 devel CI와 [post_merge 절차](../../manual/pr_review/post_merge.md)를 확인한 뒤 원 PR·이슈를 처리한다.

## 후속 코멘트 공통 계약

지금은 게시 계획만 작성했다. 원 PR의 직접 merge가 아니라 통합 PR의 cherry-pick 수용임을 명시한다.
실제 merge SHA, 최종 PR head CI와 devel CI URL, 메인터너 보정 여부, 검증한 페이지와 잔여 범위를 기재한다.
원 PR·연결 이슈의 기존 댓글과 종료 상태를 먼저 조회하고 중복 게시 대신 기존 댓글을 수정한다.
UTF-8 body file로 처리한 뒤 API로 body를 재조회한다. 원격 fork 브랜치는 보존한다.

이미지가 있는 PR의 댓글에서는 아래 MERGE_SHA와 경로를 실제 증적 commit으로 치환하여 직접 표시한다.
