## 원래 글자 모양 복원 후속 보정

사용자가 참고자료 감사에서 발견한 서식 복원 결함 보정과 코멘트 게시를 추가 승인했다.
혼합 글자색·밑줄을 링크 적용 전에 보존해 우클릭 해제 시 복원하며, HWP/HWPX 전용 보조
정보로 저장 재열기와 교차 형식 왕복을 지원한다. 외부 링크에 원래 정보가 없거나 외부
재저장으로 소실되면 현재 서식을 유지한다. 자세한 검증 SHA·명령·수치·화면·제한은
[최신 review 기록](pr_6984_review.md)을 따른다.

전체 검증 중 발견한 저장 무효화 가드 분류 누락을 실제 helper 위임 근거로 보완했다.
필수 lint·전체 nextest·Native Skia·WASM·Studio·실제 UI·브라우저 PDF를 통과했다.
가드 보완 이후 제품 코드는 동일하며 검증 결과를 최신 후보에 연결했다.
잠금 해제 후 새 적용본·해제본 HWP/HWPX 네 파일의 한컴 Viewer 열기·서식 표시를 확인했다.
사용자가 일회 허용을 추가 승인한 뒤 HWP와 HWPX 모두 Firefox 새 탭의
`example.com/original-format` 도착까지 확인했다. Viewer 확인은 외부 편집·재저장 시
보조 정보 보존 검증을 포함하지 않는다.

F11·편집→고치기·Enter로 링크 열기는 공통 개체 선택·키보드 편집 동작을 검증하는
별도 후속 이슈로 분리할 것을 권고했다. 이번 보정에 구현하거나 이슈를 생성하지 않았다.
현재 PR의 기존 스크린샷 6장을 보존하고 새 증거는 보정 코멘트에 추가한다.
제품·테스트 커밋 뒤 이 리뷰 문서를 별도 커밋하며, 일반 push 후 보정 코멘트를 게시하고
원문을 다시 읽어 확인한다. 최신 head CI·독립 리뷰·병합 승인은 별도 조건이다.
