## 구현과 과거 실제 CI

Unicode U+2024를 글꼴과 무관하게 벡터 원으로 바꾸는 원 검사는 독립 Print와 맞지 않아 수용하지 않았다. 현재 verified_point_glyph_supplier는 Gulim/Arial의 실제 공급자와 HCR Batang의 원 프로그램 우선을 분리하고 동일 glyph로 측정/paint한다. 세 입력의 전쪽 Native224/fresh063 raw 100%·직접 확대 판독과 독립 PDF 좌표가 선행 근거이며, 원문 기호·뒤 글자 순서 관계도 유지한다.


통합 merge `af6bb05b26887135fb9da0fa4e54ca7205564fca`와 [Full code CI](https://github.com/edwardkim/rhwp/actions/runs/40489874571)는 완료 이력이다. 엔진·테스트·baseline은 이번 변경에서 수정하지 않았다.

## 입력·페이지·대표 증거

[개별 리뷰](pr_8057_review.md)에 실제 검증한 파일·SHA·Print·페이지·TSV와 대표 이미지를 기록했다. 대체 입력은 원 보고 실물 문서의 직접 검증으로 표현하지 않는다. 공식 배포 문서의 내용 대응 확인도 작성자의 원본 바이트 동일성을 뜻하지 않는다.

위 대체 입력에서 전체 페이지 Native/fresh WASM TSV와 같은 페이지 review/overlay를 새로 산출했다. 배경 실물 문서의 검증과 구분한다.
