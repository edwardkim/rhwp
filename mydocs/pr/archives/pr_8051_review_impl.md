**증적 대응 정정 — 대체 입력의 검증 범위로 한정.**

**원 PR에 검증용 HWP/HWPX 원본이 첨부되어 있지 않아 유사 문서로 대체했다. 아래 결과는 명시한 대체 입력의 검증이며 원 PR에서 보고한 실물 문서를 직접 검증했다는 뜻이 아니다.**

## 구현과 과거 실제 CI

일반 표만 적용하던 cellzone·외곽 보충을 partial table에도 전달하되 조각의 소유 행·첫/마지막 변을 확인한다. split_table_cellzone_border는 40행 입력이 실제 두 쪽 이상으로 나뉜 후 첫 조각의 zone 색 선을 수집한다. 위/아래 선은 실제 조각 bbox와 원본 첫 행 높이로 검사하며 전체 SVG 해시를 고정하지 않는다. 반복 머리행의 별도 증거가 없는 assertion만으로 전체 반복 머리행 정확성을 주장하지 않는다.


통합 merge `af6bb05b26887135fb9da0fa4e54ca7205564fca`와 [Full code CI](https://github.com/edwardkim/rhwp/actions/runs/40489874571)는 완료 이력이다. 엔진·테스트·baseline은 이번 변경에서 수정하지 않았다.

## 입력·페이지·대표 증거

[개별 리뷰](pr_8051_review.md)에 실제 검증한 파일·SHA·Print·페이지·TSV와 대표 이미지를 기록했다. 대체 입력은 원 보고 실물 문서의 직접 검증으로 표현하지 않는다. 공식 배포 문서의 내용 대응 확인도 작성자의 원본 바이트 동일성을 뜻하지 않는다.

위 대체 입력에서 전체 페이지 Native/fresh WASM TSV와 같은 페이지 review/overlay를 새로 산출했다. 배경 실물 문서의 검증과 구분한다.
