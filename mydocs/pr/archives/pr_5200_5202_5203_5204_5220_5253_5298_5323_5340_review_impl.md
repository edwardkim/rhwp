## 누적 적용 및 범위

오래된 기능 순서와 의존 관계에 따라 최신 `upstream/devel` 위에 고유 변경을 누적했다.
PR에 포함된 devel merge commit, 반복된 CI fmt/manifest commit, `tests/generated/regression_suite_*`,
`tests/suites/manifest.json` 및 Cargo generated target은 통합하지 않았다. 추적 대상인
`tests/suites/unit-test-tiers.json`은 최종 source 줄에 맞춰 검증 단계에서 정합화했다.

통합 범위는 다음과 같다.

- HWP5 fieldEnd 위치와 ViewText 우선 판독
- 차례·숨은 설명·Hancom 기호·묶음 빈칸·짝 없는 fieldEnd의 저장 왕복
- HWPX 외부 LINK 그림 ID 분리와 다중 section `secPr` 방출
- HWPX/HWP5 `breakLatinWord` 양방향 attr 매핑
- HWPX 문단 번호 `paraHead` 속성 역산
- 각 기능의 원본 fixture·focused regression test

## 판단 및 다음 단계

차단 결함은 발견하지 못했고, 9개 PR 모두 로컬 통합 검토 기준 수용 가능하다. 각 PR별 기록은
같은 archive 디렉터리에 보존했다. 통합 PR [#5472](https://github.com/edwardkim/rhwp/pull/5472)의
head `34b980bcf2007153d507e1cb00718da6b9690529`는 `MERGEABLE`이며, CI preflight·CodeQL·Rust
CodeQL·Lint·Native Skia·Build test archive·3개 일반 shard·slow shard·prop roundtrip·Build & Test가
모두 통과했다. Frontend unit gates와 WASM Build는 변경 영향에 따른 정상 skip이다.

CI 완료 뒤 이 문서와 오늘할일의 원격 PR 상태를 trailing 문서 commit으로 갱신한다. 작업지시자의
명시 승인 전에는 merge, review comment, 원 PR close, 원격 branch 삭제를 수행하지 않는다.
