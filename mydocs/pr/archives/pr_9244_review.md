# PR #9244 검토 — 검증 원본 및 기준 PDF 인벤토리

**승인.** 작성자 postmelee의 자체 검토에서 조사 범위·집계·경로 참조를 확인했다. 대상은 devel `411a9f944cd6ff202e1f8c5b835ecccbc837486f` 위의 `25b5c38f9d9eedc04c3c9934c1e8b48ac9b80f88`이다.

[조사 보고서](../../report/task_m100_9243_report.md)의 Python 예제를 재실행해 3,800개 원본 경로와 고유 Git blob 3,651개를 확인했다. PDF 열은 별도 집계다. 이관·보류 정책 62건과 실제 테스트의 include 경로를 대조했다. 기존 gate의 입력 4개와 기준 PDF 4개는 고정 커밋의 바이트를 SHA-256으로 대조했다. 새로운 정답쌍을 확정하거나 렌더링 결과를 측정한 작업은 아니다.

후보의 변경은 조사 문서 한 파일이며 조판 구현·회귀 기대값·검증 입력을 변경하지 않는다. 문서 집계 재실행, 공백 검사와 devel 병합 시뮬레이션이 통과했다. [후보 CI](https://github.com/edwardkim/rhwp/actions/runs/44747381421)의 Build & Test가 성공했으며 영향 분류에 따라 엔진 작업은 생략됐다. 이 검토 기록을 추가한 최종 head의 필수 확인 후 병합한다.
