## 판정: 메인터너 보정 완료 · 수용 가능

## 변경 범위와 코드 검토

잘린 EMF가 Some이어도 WMF 미리보기를 준비하고 대체 렌더한다. 통합 후보에는 #6932의 흐름 높이 보정도 포함한다.

## 실행한 검증

보정 전 `ole_preview_keeps_the_declared_box`는 x=100.7, y=120.0, cell_top=109.4, 상대 y=10.6에서 실패했다. 정본 상대 11.53과 약 0.93px 차이가 ±0.5px 검사에 걸린 것이며 미리보기 복원 실패가 아니었다.

보정 후 미리보기 출력·위치/크기/경계 검사 2개가 모두 통과했다. #6926 관련 3개를 합친 focused 5개도 모두 통과했다. 최종 전체 회귀는 8 threads, `--no-fail-fast`, 9,327개 통과·실패 0·별도 skipped 46개, 316.582초, exit 0이다.

최종 메인터너 보정 후 공통 전체 회귀는 9,327개 통과·실패 0·별도 건너뜀 46개다. focused 5개, fmt, native/WASM/workspace all-targets Clippy, workspace 빌드와 manifest 검사도 통과했다. 제품 소스가 같아 기존 Native Skia·WASM package·Studio·TypeScript·Chrome·시각 결과를 재사용했으며, 이전 실패와 재실행 범위는 공통 기록에 구분했다.

## 잔여 사항과 수용 범위

현재 이미지에서는 포스터 전체가 셀 안에 보이고 이전 수백 px 밀림·잘림은 재현되지 않는다. 외부 셀 프레임 약 7.4px 및 내부 패딩 약 0.93px 차이는 별도다. 제품 렌더링은 동일하므로 기존 PNG를 유지했으며 새로 재산출했다고 기록하지 않는다.

## 보류 해소를 위해 완료한 보정

- 정본 윗여백 141HU(1.88px)와 현재 패딩 약 0.95px의 기존 차이 0.93px를 근거로 상대 위치 허용치를 0.5px에서 1px로 보정했다. #6932의 2px를 그대로 적용하지 않았다.
- 기존 x·선언 크기·용지 하단 검사를 유지하고, 개체 상단·하단이 실제 셀 경계를 벗어나지 않는 검사도 추가했다.
- `layout-anomaly` 재측정은 offCanvasCount=0이었다. 원 PR의 기존 off_canvas 기준선 1을 높이거나 검사를 skip하지 않았다.
- 별도 1쪽 Rect의 본문 경계 넘침 5.64px(overflowCount=1)는 남는다. 대상 4쪽 OLE의 셀/용지 이탈과 혼동하지 않는다.

## 원 PR·이슈 코멘트 계획

원격 통합·CI gate 완료 후 수용 댓글에 WMF 대체, #6932 배치 개선, 이번 검사 조건 보정을 구분한다. 잔여 패딩·외부 프레임 차이와 별도 1쪽 넘침을 공개하며 전체 문서 완전 일치를 주장하지 않는다.

- 지금은 원격 댓글·review·close를 수행하지 않았다.
- 모든 통합 gate와 merge 후 devel CI 완료 뒤 실제 merge SHA·PR/devel CI URL을 기록한다.
- 증적은 공통 기록의 댓글 템플릿처럼 commit 고정 raw 이미지로 본문에 직접 표시한다. `/tmp` 경로·로그 링크를 공개 증적으로 사용하지 않는다.
- 기존 수용 댓글이 있으면 본문을 수정하고 중복 등록하지 않는다. UTF-8 body-file 방식으로 게시한 뒤 API로 실제 본문을 재조회한다.
- 연결 이슈의 실제 범위가 남으면 전체 해결로 닫지 않는다. 기여자 fork 브랜치는 보존한다.
