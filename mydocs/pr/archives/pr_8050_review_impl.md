## 구현과 과거 실제 CI

칸이 외곽 변을 NONE으로 명시한 경우를 미지정/상속과 구분한다. table_outer_border_none_cells는 실제 table bbox의 왼쪽·아래·제목 왼쪽 위에는 선이 없고 제목 자신의 윗선은 남는지 검사한다. table border fill이 SOLID라는 이유로 칸의 명시적 NONE을 메우지 않는다. 고정 화면 좌표가 아니라 같은 표의 변·중앙·제목 변과의 관계이다.


통합 merge `af6bb05b26887135fb9da0fa4e54ca7205564fca`와 [Full code CI](https://github.com/edwardkim/rhwp/actions/runs/40489874571)는 완료 이력이다. 엔진·테스트·baseline은 이번 변경에서 수정하지 않았다.

## 입력·페이지·대표 증거

[개별 리뷰](pr_8050_review.md)에 실제 검증한 파일·SHA·Print·페이지·TSV와 대표 이미지를 기록했다. 대체 입력은 원 보고 실물 문서의 직접 검증으로 표현하지 않는다. 공식 배포 문서의 내용 대응 확인도 작성자의 원본 바이트 동일성을 뜻하지 않는다.
