# 자기서술 — 도구가 도구를 설명한다

> 이 장은 `tools/gen_agent_codex.py` 가 바이너리 자기서술과 실픽스처
> 실행에서 생성했다 — 수기 수정 금지. 표본의 배열은 2원소로 절단되고
> 저장소 경로는 `<repo>` 로 정규화된다.

### `capabilities` — 본 자기서술 JSON 출력

- 종류: `query` · exit 규약: 0 성공 / 1 IO / 2 사용법 / 3 판정 실패(데이터)
- 사용법: `capabilities [--mcp]`
- 플래그: `--search`
- 봉투 필드: `schemaVersion` · `schemaRegistry` · `tool` · `version` · `exitCodes` · `commands` · `batch` — 정의는 [지식지도 §2-2](../agent_knowledge_map.md)
- **출처 표지**: 문서 파생 필드 없음 (엔진·에코 값뿐)

> **계약만** — 입력 합성 비용 또는 산출 부피 때문에 표본 실행을 싣지 않는다 — 계약(플래그·봉투 필드·출처)은 아래가 전부이며 자기서술에서 생성됐다.

### `export-ir-schema` — 공개 IR 의 JSON Schema 산출 — 외부 바인딩 코드 생성의 단일 출처 (#3762)

- 종류: `export` · exit 규약: 0 성공 / 1 IO / 2 사용법
- 사용법: `export-ir-schema [--bare] [-o <파일>] [--json]`
- 플래그: `--json` · `--bare` · `-o`
- 봉투 필드: `schemaVersion` · `irSchemaVersion` · `dialect` · `definitionCount` · `schema` — 정의는 [지식지도 §2-2](../agent_knowledge_map.md)
- **출처 표지**: 문서 파생 필드 없음 (엔진·에코 값뿐)

> **계약만** — 입력 합성 비용 또는 산출 부피 때문에 표본 실행을 싣지 않는다 — 계약(플래그·봉투 필드·출처)은 아래가 전부이며 자기서술에서 생성됐다.

### `export-capabilities-schema` — capabilities 자기서술 자체의 JSON Schema 산출 — 명령 표면 코드 생성의 단일 출처 (#3776)

- 종류: `export` · exit 규약: 0 성공 / 1 IO / 2 사용법
- 사용법: `export-capabilities-schema [--bare] [-o <파일>] [--json]`
- 플래그: `--json` · `--bare` · `-o`
- 봉투 필드: `schemaVersion` · `capabilitiesSchemaVersion` · `dialect` · `definitionCount` · `schema` · `mcpSchema` — 정의는 [지식지도 §2-2](../agent_knowledge_map.md)
- **출처 표지**: 문서 파생 필드 없음 (엔진·에코 값뿐)

> **계약만** — 입력 합성 비용 또는 산출 부피 때문에 표본 실행을 싣지 않는다 — 계약(플래그·봉투 필드·출처)은 아래가 전부이며 자기서술에서 생성됐다.

### `export-ontology` — 자기서술에서 기계 유도한 JSON-LD 온톨로지 산출 — IR 클래스·속성, 명령/MCP 행위, 신뢰 술어 (#3907 O1)

- 종류: `export` · exit 규약: 0 성공 / 1 IO / 2 사용법
- 사용법: `export-ontology [--bare] [-o <파일>] [--json]`
- 플래그: `--json` · `--bare` · `-o`
- 봉투 필드: `schemaVersion` · `ontology` · `classCount` · `propertyCount` · `actionCount` — 정의는 [지식지도 §2-2](../agent_knowledge_map.md)
- **출처 표지**: 문서 파생 필드 없음 (엔진·에코 값뿐)

> **계약만** — 입력 합성 비용 또는 산출 부피 때문에 표본 실행을 싣지 않는다 — 계약(플래그·봉투 필드·출처)은 아래가 전부이며 자기서술에서 생성됐다.
