각각 `scan_legacy_grid` 결과(치수 · 창 · 셀 좌표 · 값 · 패치 주소)를 덤프해 대조했다.

  종전 통과 55개 중

  새로 열림    19

`\0\0` 경계를 요구해 `'12년 3월`·`4월`·`5월` 같은 머리 라벨 15칸을 통째로 버렸다.
