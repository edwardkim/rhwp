# 처리 결과 — 로드맵 진행률 기계 산출 (R94 P2, #4107)

## 분석

설계 문서(`mydocs/tech/autonomous_maintenance/progress_machine_readable.md`)가
필요한 실측을 이미 갖고 있었다: 현재 태그 형식은 파싱 가능하고(§2 — 100행 전부,
결번 0, 중복 0), 손집계는 실물과 갈라진다(§1 — #3907 안에서 같은 부류 오류 6건).
R94 의 착수 게이트("태그 형식 안정")는 이 문서 세트 자신이 형식의 원천이므로
통과 — 형식이 바뀌면 파서를 같은 PR 에서 고치게 된다.

범위는 설계 문서 §7 의 **P2(형식 검증만)** 로 제한했다. 이슈 본문의 증거 토큰
검증(V3~V5)은 P1(완료 정의 합의)이 선행이라 하지 않는다(§5.5 의 금지 —
등급 추천·이슈 편집·새 R 항목 — 도 그대로 지켰다).

  README 의 기계 집계 블록 재생성. 종료 코드 0/1/2.
- `mydocs/tech/agent_roadmap/README.md` — 손집계 문단을 기계 생성 블록
  (`<!-- roadmap-progress:begin/end -->`)으로 대체 + 착지 보정 문단.
- 상태 동기화 2건(#3912 누적 통합 머지가 근거):
  - **R12** `[이슈]`→`[실측]` — 산출물(실패 경로 전수·미선언 감지)이
