# #7025 — 그리드 보기 오버레이 쪽 X 정합

두 쪽 보기(zoom 0.5)에서 **2쪽에 있는 표의 세로 경계**에 같은 좌표로 마우스를 올린 결과다.
재현 문서는 비공개 코퍼스의 8쪽 중첩 표 문서(문서 ID `3190263`)를 썼다.

| 파일 | 내용 |
|---|---|
| `before_double_p2.png` | 수정 전 — 안내선이 왼쪽 쪽 위에 그려진다 |
| `after_double_p2.png` | 수정 후 — 안내선이 2쪽의 표 경계 위에 놓인다 |

같은 hover 에서 읽은 수치(마커 element 의 `style.left`):

```text
              쪽 2 의 실제 X    마커 left     편차
  수정 전          633.0          662.5     −201.4   ← 옆 쪽 위
  수정 후          633.0          863.9        0     ← 경계 위
```

두 경우 모두 커서는 `col-resize` 였다 — 적중 판정은 `#685` 에서 이미 고쳐져 정상이고
그리기 축만 어긋나 있었다.

배열별 편차(쪽폭 793.7 · 간격 10 · contentWidth 834 · zoom 1, `쓰던 식 − 실제`):

```text
  한 쪽            0 /      0 /       0
  두 쪽        +10.1 / −793.6 /   +10.1
  여러 쪽 3열   +10.1 / −793.6 / −1597.3
  맞쪽         −793.6 /  +10.1 /  −793.6
```
