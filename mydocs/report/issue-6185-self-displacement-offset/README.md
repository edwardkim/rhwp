재현물 `samples/issue6185/156570535_logo_box_self_displacement.hwpx` 1쪽
(`x 70..730`, `y 90..225`, 96dpi).

| 파일 | 내용 |

## 실측 (px @96dpi, 원본 2쪽)

| | 수정 전 | 수정 후 | 한글 2020 |
|---|---:|---:|---:|
| `담당 부서` 표 아래 괘선 | 499.5 | 499.5 | 499.0 |
| 로고 글상자 상단 | **465.5** | **514.9** | **514.7** |
| 로고 그림 | **469.3** / 479.6 | **519.1** / 529.4 | 518.5 / 527.3 |

수정 전 편차 **49.2px** 는 글상자 자신의 높이(49.81px)와 같다. 수정 후 한글과 **0.7px**
안에서 일치한다.

## 근인 — 배치 의도가 아니라 자기 변위 잔재

```
문단 pi=23  [사각형] 크기 90.7mm × 13.2mm (25698×3736 HU)
  위치: 세로=문단 오프셋 4294963560  → signed -3736 = -(높이 3736)
  배치: 자리차지, 글자처럼=false
```

세로 오프셋이 **자기 높이의 정확한 음수**다. 한글은 이 값을 무시하고 글상자를 문단
자리에 그린다. rhwp 는 그대로 적용해 상자를 자기 높이만큼 위로 올렸다.

#6110 의 `vpos == 그림 높이 → 자기 변위` 지문과 같은 축이다.

## 게이트를 정확 일치로 좁힌다

음수 오프셋 클램프는 `shape_layout.rs` 에 이미 있었지만 `clamp_negative_para_offset`
플래그가 모든 호출부에서 `false` 라 **HWP3 경로 전용으로 사실상 죽어 있었다.**

임의의 음수 오프셋까지 넓히면 실제 위치 지정을 망치므로, **오프셋 == -(자기 높이)**
정확 일치일 때만 발동하도록 새 갈래를 뒀다. 비-TAC 자리차지(vert=문단, Top/Inside)
로 함께 좁힌다.
