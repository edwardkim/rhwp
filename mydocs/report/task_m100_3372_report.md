## 1. 배경

커버리지 체크리스트(#3370)에서 **기안문(공문서) 작성이 ✕** — 공무원 1순위 산출물이
생성 범위 밖이었다. 접근은 #3372 의 2안: 편람이 권장하는 방식(§2 "표준 기안문 활용")
그대로 **누름틀 내장 표준 서식 + `edit fill-fields`** 조합. ingest 스키마 확장 없이
실물 배치 품질을 서식이 보장한다.

## 2. 제작 방법 — 정답지 대조 루프 (도그푸딩)

1. **정답지**: 편람의 별지 제1호서식(일반기안문) 페이지를 `search` 로 찾아
   `export-svg -p 61~62` 로 렌더 — 두문(행정기관명·수신·경유)/본문(제목·내용·붙임)/
   결문(발신명의·서명줄·시행/접수·주소·공개구분) 배치 확정.
2. **제작**: `build-from-ingest` 최소 스켈레톤 → header/section XML 재작성
   (charPr 3종 추가: 기관명 22pt bold·발신명의 16pt bold·결문 8.5pt / paraPr:
   중앙 정렬·제목행 하단선·회색 구분 바 / 누름틀 23곳 — field-01.hwp 의 CLICK_HERE
   패턴 준용). 결정적 재생성 스크립트 동봉.
3. **검증 루프**: 매 반복을 rhwp 자신으로 검증 — `info`(파싱) → `fields --json`
   (누름틀 23종 인식) → `export-svg`(렌더) → 정답지와 시각 대조.
4. **실전 검증**: 예시값 23필드를 `edit fill-fields`(#3345 브랜치 빌드)로 채워
   완성 기안문 렌더 — 항목체계(1.→가.나.다., 값 안의 `\n` 이 문단 내 줄바꿈),
   서명줄, 시행/주소/공개구분까지 실물 배치 확인.

제작 중 확인된 스키마 규칙: `<hh:bold/>` 는 offset 뒤·underline 앞(순서 위반 시
charPr 전체 무시), HwpUnitChar switch 등. 렌더러 결함 1건은 #3375 로 분리
(빈 누름틀 안내문의 인쇄 프로필 출력·폭 0 겹침).

## 4. 2차 커밋 — 간이기안문(별지 제2호서식) + 정답지 비교 프로토콜

- **결재란 표 돌파**: hp:tbl/tr/tc XML(cellAddr·cellSpan 병합·용지 기준 절대 앵커)로
  등록표(좌)·결재란(우) 나란히 배치. 표 셀 안 누름틀 13곳 — `fields` 인식과
  `fill-fields` 채움(13/13 재독 실반영) 모두 실측 확인.
- **정답지 나란히 비교 프로토콜 도입**(사용자 지시): 법정 서식 렌더와 완성본 렌더를
  한 장에 놓고 글자 겹침·요소·순서·정렬 대조 — 비교 시트 2장을 assets 에 동봉
  (`compare-ilban.png`·`compare-gani.png`). 감사 결과: 두 서식 모두 요소·순서·배치
  일치, 채운 상태 글자 겹침 없음. 빈 안내문 관련 잔여는 전부 #3375 범주.
- **코어 버그 발견 #3380**: 채울 값이 안내문과 동일하면 조용히 유실(성공 보고 후
  빈 값) — "주무관" 채움이 재독 대조에서 적발됨. 결정적 재현(같은 필드에 "사무관"
  ○ / "주무관" ✗)으로 이슈화. 서식 측 완화로 안내문을 실값과 충돌하지 않게 일반화.
- 용지 여백을 서식 제정 기준(상·좌·우 20㎜, 하 10㎜, 편람 실측 추출)으로 반영.
