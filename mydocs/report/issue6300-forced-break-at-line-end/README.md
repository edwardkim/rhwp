문서: `samples/issue6300/trade_report_forced_break_object.hwp` (산업통상자원부 156464313)
영역: 17쪽 `농수산식품` 문단 (원본 좌표 y 540~700px, `-p 17 --scale 1.3 --compat 2022`)

| | 줄 길이 | 병합 줄(64자↑·우단 초과) | 총 쪽수 |
| --- | --- | ---: | ---: |
| 종전 (`before.png`) | [45, 38, **0**, **69**] | 5개 | 43 |
| 수정 (`after.png`) | **[45, 38, 36, 32]** | **0개** | **40** |
| 한글 2022 | 4줄 | - | 39 |
