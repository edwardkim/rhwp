오염돼 있어, 사본에서 `PrintMethod=0` 으로 낮춰 다시 내보낸 정답지로 측정했다.

않아**(#2097 계약) 띠 자체가 그만큼 위에 놓인 결과이고, 별개 축으로 남긴다.

## 쪽수 A/B — 코퍼스 4,000문서 표본, 차이 0건

`korea_downloads` 에서 seed 6147 로 뽑은 4,000건을 수정 전/후 바이너리로 대조했다
(`같음 3978 · 다름 0 · 오류 22`, 오류는 기지 보호문서 코호트).

첫 시도에서는 회귀 1건(`156272593` 5→6쪽, 한글 COM 정답지 5쪽)이 나왔다. 근인은 그
문서의 앵커 문단이 `text=" "`(공백 한 칸)이라는 점이다 — #1147 의 조판 억제 술어가
`para.text.is_empty()` 라서 공백 한 칸이면 **애초에 억제가 걸리지 않고**, rhwp 는 이미
`PartialParagraph pi=44` 로 host 줄을 계상하고 있었다. 그 위에 꼬리를 더해 이중 계상이
된 것이라, 판정을 #1147 과 같은 축(`para.text.is_empty()`)으로 옮겨 좁혔다.
