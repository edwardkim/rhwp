## 무엇이 보이나

수정 전에는 각주 구분선이 본문 마지막 줄("…입법은")에 거의 닿고 각주 본문과도
붙어 있다. 수정 후에는 구분선이 본문에서 떨어져 제자리를 찾는다.

```text
                본문 마지막 줄 y   각주 첫 줄 y   간격
  한/글 정본           687.4          725.5      38.1
  수정 전              707.6          725.5      17.9
  수정 후              687.0          725.5      38.5
```

## 저장 바이트

`FOOTNOTE_SHAPE[0]` 을 한/글 네이티브 HWP5 정본과 맞댄 값이다.

| | 구분선 위 | 구분선 아래 | 주석 사이 |
| --- | ---: | ---: | ---: |
| 한/글 정본 | 852 | 568 | 424 |
| 수정 전 | **0** | **0** | 424 |
| 수정 후 | 852 | 568 | 424 |

`852 = 213 × 4`, `568 = 142 × 4` 로 `doc_info` 의 hunit 값과 정확히 맞는다.

## 쪽수에 대하여

이 수정으로 한/글 렌더 쪽수는 263 → 266 이 된다(정본 264). **멀어진 것처럼 보이지만
기하는 정본과 맞는다** — 종전에는 각주 밴드가 절반 크기라 쪽당 본문을 과하게 담고
있었다. 남은 +2 는 탭 채움 유실(#7170) 등 다른 축이다.

총계 지표만 보면 옳은 수정을 회귀로 오판할 수 있어, 근거는 직접 잰 밴드 기하와
저장 바이트로 삼았다.
