## 남는 ±2px — 별도 축

`3030681` 수정 후 8자는 모두 정본보다 +2.4px 로 **일정하게** 옮겨졌고 글자 피치는 정본과 같다
(8자 폭 차 −0.05px). 줄이 통째로 조금 더 오른쪽에 붙은 것이라, 정렬 폭에서 빼는 꼬리 공백 폭
추정이 실제 공백 전진보다 공백당 약 0.16px 크다고 보인다. 같은 규칙의 `1319800` 은 +0.03px 다.
그 추정은 칸 밖 정렬에도 쓰이는 공용 헬퍼라 이 수정의 범위 밖이다.
