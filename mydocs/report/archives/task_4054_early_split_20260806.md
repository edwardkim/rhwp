- **결론**: 회귀는 새 결함이 아니라 **상쇄되던 기존 결함이 드러난 것**이었다. 그 결함(각주 안전마진이

## 1. 회귀 1건의 근인

`1490000-200900057 문화예술산업-중간보고`(한글 338쪽)가 339쪽이 됐다. 진단을 넣어 값을 찍었다.

```
[OVERBUDGET] pi=2488 li=2 cum=57.6 avail=72.6 over=1.0 tailfit=false  curh=668.9 fnh=76.5
[OVERBUDGET] pi=2497 li=1..3 avail=18.1 over=26.7~84.3 tailfit=true  chain=1,2,3 -> BREAK
```

1. p259 에서 `avail = 857.9(본문) − 668.9(누적) − 76.5(각주 예약) − 40(안전마진) = 72.6px` 이라
   세 번째 줄이 **1.0px** 차이로 끊긴다. 한글은 같은 자리에서 line 4 까지 둔다(저장 좌표 바닥 800.1px)
2. 잃은 3줄(86.4px)이 p260 으로 넘어와 마지막 문단의 잔여 예산을 18.1px 로 만든다
3. 저장 좌표 신뢰(`saved_tail_vpos_fit`)가 초과 4줄을 통과시켜 **쪽수를 정답으로 되돌려 왔다**
4. #4024 의 연쇄 상한이 그 흡수를 끊자 상쇄가 풀리며 쪽수 회귀로 표면화됐다

**PI 오라클이 이 결함에 침묵하는 이유**도 확인했다 — per-PI 오라클은 문단 **시작** 쪽만 비교하므로
문단 중간의 줄 3개가 다른 쪽에 있어도 MATCH 다.

### 2.2 2차 — 올바른 단위는 줄 손실

### 2.3 3차 — 원인 분해 (판정 가능 135지점)

저장 좌표 **상단**(`ladtop`)까지 찍어 rhwp 커서와 같은 자리를 보는지 확인했다. 여기서 앞선 판정이

| 원인 | 지점 | 잃은 줄 | 문서 |
|---|---|---|---|
| **각주 안전마진 40px** | **73 (54%)** | 133 | 42 |
| 흐름 과대(rhwp 앞섬) | 33 (24%) | 108 | 17 |

**계측 함정 2종.**

## 3. 수정 — 마진을 상수에서 조건부로

각주 겹침은 물리 계약이라 상수를 내릴 수 없다. 대신 **겹침이 실측으로 배제되는 경우에만** 마진 몫의
초과를 통과시킨다(devel `e21ffecdd`, 이후 `c278b3871` 로 함수 분리·단위 테스트 보강).

```
(1) 저장 좌표가 쪽 안의 값이다            top >= 0 && top <= base_available
(2) 한글도 이 줄을 각주 영역 위에 뒀다     bottom <= base_available - footnote_height
(3) 흐름 커서가 저장 좌표보다 위에 있다    current_height <= top + 16
```

(3)이 핵심이다 — rhwp 가 그리는 위치가 한글보다 높으므로, 한글이 안 겹쳤다면 rhwp 도 안 겹친다.

## 5. 델타-PI 측정법 — 23문서만 재고 10k 지표를 확정한다

PI 판정은 **rhwp 의 PI→쪽 지도와 한글 정답지의 함수**다. 정답지는 문서마다 고정이므로, 지도가 바이트
단위로 같으면 판정도 정의상 같다. 따라서 지도가 바뀐 문서만 COM 으로 재면 된다.

```
1. 두 바이너리로 PI→쪽 지도 해시를 10k 산출   tools/pi_map_hash.py   (COM 불필요, 각 1~3분)
2. 해시가 다른 문서만 추린다                   이번 실행: 23건
3. 그 문서만 한글 COM 오라클로 재측정          verify_combined.py --list
4. 직전 판정표에 덮어써 같은 분모로 재집계
```

측정 실패·시간 초과·페이지 덤프 형식 오류는 `변경 없음`으로 취급하지 않는다. 도구는 하나라도
실패하면 기존 TSV를 교체하지 않고 실패 종료하며, TSV의 `doc`에는 동명 파일을 구분할 수 있도록
chunk에 지정한 원래 경로를 보존한다.

**결과 (10,000문서 동일 분모)**

| 지표 | r31 | **최신 devel `570fa6e4f`** |
|---|---|---|
| MATCH | 9,246 | **9,250** (+4) |
| PI_MISMATCH_CARET | 66 | 66 |
| PI_MISMATCH | 212 | 211 |
| PAGE_DELTA | 379 | **376** (−3) |
| **PI 일치율(graded 9,903)** | 94.03% | **94.07%** |

재측정 23건의 전이: `PAGE_DELTA→MATCH` 3 · `PI_MISMATCH→MATCH` 1 · `PAGE_DELTA→PI_MISMATCH` 3 ·
`PI_MISMATCH→PAGE_DELTA` 3 (13건은 지도가 바뀌어도 판정 동일).

**부수 확인**: r31 이후 devel 60커밋이 들어왔는데 PI 지도가 바뀐 문서는 이 23건뿐이었다. 그 드리프트는
조판을 건드리지 않았다는 뜻이다.
