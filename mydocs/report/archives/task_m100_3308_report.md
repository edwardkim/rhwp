## 한컴 규칙 실측 (권위 확보)

- 편집기 크기 판독 **115.13mm = 선언 폭 정확 일치** / 한컴 HWP5 재저장본도 선언 유지.
- 편집기 위치 값(단 왼쪽 21.96mm=선언 h_off)은 **조판에 쓰이지 않음** — 선언 offset
  모델 15~21px 불일치, **셀 내 가운데 모델 0.6px 정합** (작업지시자 "표 속성 값으로
  조판되지 않음" 판정).
- 보호 대상 분리: #2195 규제영향분석서 계열 스트레치 비율 0.956~0.995 vs 직인 0.679.

## 교훈

1. **편집기 대화상자 값 ≠ 조판 값** — 저장 h_offset(21.96mm)을 편집기가 표시하지만
   조판은 다른 규칙(셀 내 가운데)을 쓴다. 선언 필드의 stale 가능성을 항상 정답지
   픽셀로 교차 검증할 것.
2. 상한/하한 없는 정규화의 극단 포섭 — 오늘 #3236(1.5×)·#3308(0.9) 두 건 모두 같은
   패턴. 정규화 도입 시 보호 대상의 실측 분포로 경계를 함께 정의해야 한다.
3. red-check 두 축 독립 증명 — 복합 수정은 축별로 제거해 각각의 필요성을 증명.
