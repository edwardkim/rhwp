# #6312 자리차지 표 앵커 문단의 자기 글줄 27pt 가 사라진다

문서: `samples/issue6312/fiscal_trend_float_table_anchor.hwpx`
(기획재정부 156721992 의 **구조 보존 슬라이스** — BinData 이미지만 8x8 PNG 로 치환,
874KB → 92KB. 좌표는 원본과 동일하다.)

영역: 1쪽 (원본 좌표 y 255~400px, `-p 0 --scale 1.3 --compat 2022`)

| | 표 아래 괘선 | 문단 B 첫 줄 | 문단 오차 |
| --- | ---: | ---: | ---: |
| 종전 (`before.png`) | 230.25pt | 230.25pt | **-39.84pt** |
| 수정 (`after.png`) | 230.25pt | **260.10pt** | **-9.99pt** |
| 한글 2022 | 240.28pt | 270.09pt | - |

수정 후 **문단 오차(-9.99)가 표 오차(-10.03)와 같아진다** — 앵커 줄 축은 닫혔고,
남은 10pt 는 표 자체가 한글보다 높은 별개 축이다(이슈 본문도 그렇게 분리해 적었다).
