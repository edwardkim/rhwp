## 만든 방법

`rhwp export-svg` 산출 SVG 를 헤드리스 Chrome 으로 1587×2245 로 래스터화했다
(`pymupdf` SVG→PDF 경로는 글꼴을 대체해 없는 결함을 만든다). 정본은 `pypdfium2` 로
150dpi 래스터화했다. 수정 전/후 SVG 는 각각 devel 빌드와 이 변경 빌드에서 새로 뽑았다 —
기존 `target/release` 재사용이 아니다.
