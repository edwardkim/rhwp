# #7174 — HWP3 각주 번호의 닫는 장식이 각주 모양에 실리지 않는다

표본은 `1170000-200500003_D0150004-1-001_독일의 법령체계와 입법심사기준(최종본).hwp`
(264쪽, HWP3, 각주 230개)이다. 정본은 **한글 자신의 HWP5 변환본** — 같은 원본을
한글 2024 로 열어 `SaveAs(..., "HWP")` 로 저장한 파일이다.

## 무엇이 어긋났나

HWP3 은 각주 번호의 닫는 장식을 **두 곳**에 나눠 갖는다.

```text
  doc_info offset 110 (스펙 타입 echar)   문서 옵션 — 번호에 붙일 장식 문자
  주석 본문의 첫 글자                     같은 장식이 리터럴로 한 번 더 들어 있다
```

HWP5 는 장식을 `FOOTNOTE_SHAPE` 하나로만 표현하고, 그 값으로 **본문 참조 번호와 주석
영역 번호를 모두** 그린다. 우리는 모양에 장식을 싣지 않은 채 리터럴만 남겨, 저장본을
한글로 열면 본문 참조가 `1)` 이 아니라 `1` 이 됐다.

```text

  각주 모양만 배선   소실 없음           과잉 ')' × 230 · '\n' × 3

```

`)` 축은 닫혔다. 남은 빈 줄 3개는 이 수정의 범위가 아니다.

## 우리 렌더도 고쳐진다 — 각주 영역이 `1))` 였다

렌더 경로가 갈려 있다.

```text
  본문 참조 번호   renderer/layout/paragraph_layout.rs  <- 컨트롤의 after_decoration_letter
  주석 영역 번호   renderer/layout/picture_footnote.rs  <- 컨트롤 값 + 주석 본문 글자
```

`after_decoration_letter` 는 HWP3 경로가 이미 `)` 로 채우므로, 수정 전에는 주석 영역이
**컨트롤이 그린 `)` 와 본문에 남은 리터럴 `)` 를 겹쳐** `1))` 로 나왔다. 저장본 세 개를
같은 쪽(0-based `-p 8`)에서 `export-svg` 로 렌더해 글리프를 순서대로 이어 붙인 값이다.

```text
  한글 정본    …연방의입법사항으로서 1)  독일법의특성은추…
  수정 전      …이들사항에관하여원칙내지 1))  독일법의특성은추…
  수정 후      …이들사항에관하여원칙내지 1)  독일법의특성은추…
```

글리프 좌표까지 보면 더 분명하다(같은 쪽, `export-svg` 의 `<text>` x·y).

```text
  한글 정본   1@(121,864)  )@(128,864)  독@(153,864)
  수정 전     1@(121,864)  )@(127,864)  )@(144,864)  독@(157,864)
  수정 후     1@(121,864)  )@(127,864)  독@(151,864)
```

본문 참조는 세 경우 모두 같다 — `…이해되고있다.1)독일의법령체계는…`.

쪽 전체 렌더는 함께 둔다 — [`before-page9.png`](before-page9.png) ·
[`after-page9.png`](after-page9.png) · [`oracle-page9.png`](oracle-page9.png)
(전부 `rhwp export-png -p 8` 산출, 합성 아님).

⚠ 이 쪽의 PNG 에서는 번호 자리가 **본문 줄에 가려 판독되지 않는다.** 우리 저장본은 각주
구분선 여백이 0 이라 각주 첫 줄이 본문 마지막 줄 위에 겹쳐 그려진다 — 같은 이슈의 다른
축이며 PR #7181 이 다룬다. 그래서 이 축의 렌더 증거는 위 글리프 좌표로 제시한다.

## 범위 밖

- 구분선 여백(구분선 위/아래) — PR #7181 이 다룬다.
- 구분선 길이(정본 `-1` 자동 대 우리 고정값 `14160`) — 렌더 기하가 움직이는 별개 축.
- 미주 모양(`FOOTNOTE_SHAPE[1]`)이 통째로 0 인 축.
- 표본의 쪽수 격차(264 대 273)와 빈 줄 3개.

## 폭발반경 — 코퍼스 HWP3 38건 전수

수정 전후 바이너리로 38건을 각각 `convert` 해 저장본 레코드를 직접 비교했다(COM 불필요).

| 주석 본문의 리터럴 `)` 제거 | **1/38** — `07615` 만 `230` → `0` |
| 나머지 37건 | 자동 번호(주석) **0건** 이라 본문 글자 무변화 |

주석이 없는 문서에도 모양 값이 실리는 것은 정본과 같다 — 한글은 같은 표본에서
미주가 없는데도 `FOOTNOTE_SHAPE[1]` 에 뒤 장식 `41` · 시작 번호 `1` 을 쓴다.
