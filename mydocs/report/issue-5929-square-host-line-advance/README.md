## 근인

`#5809` 의 "빈 host 문단도 줄을 차지한다" 증언 경로가 두 겹으로 막힌다.

1. `has_square_float_before_text` 가 **다음 문단이 가시 텍스트**일 것을 요구하는데,
   이 문서는 다음(pi=9)도 빈 문단이다.
2. 이 문서의 lineseg 는 전부 합성(`tag=0x80060000`)이라 사다리 증언 함수 자체가
   합성-태그 가드에 막혀 침묵한다.

그래서 폴백 `textless_infront_para_host_requires_line_advance` 로 떨어지는데, 이 함수는
`InFrontOfText` 만 인정하므로 어울림은 **0** 을 받는다. 조판(typeset)은 같은 문단을
`h=54.1px` 로 계상한다(`dump-pages` pi=8) — 전형적인 조판↔페인트 비대칭이다.

## 수정과 게이트

사다리가 **아예 없는** 문서(합성 lineseg 뿐인 기계 생성본)에서는 조판을 따른다.
전진량은 `sb + lines + sa`(형제 빈 문단과 같은 54.1px) — 줄 부분(34.1px)만 주면
문단 앞뒤 간격 20px 이 유실돼 여전히 어긋난다(실측 확인).

게이트는 **저장 증거 부재**로 좁혔다. 사다리가 있는 문서는 `#5809` 의 증언 경로가
그대로 답하므로 그 반례(issue_2069 편집 후 stale 사다리)는 건드리지 않는다.
