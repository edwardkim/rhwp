## 공통 보정과 소비

첫 조각의 물리 상자를 받을 때 뒤에 한 저장 프레임만 남아야 한다는 조건을 제거했다.
원본 일반 셀·유효한 현재 컷·물리 경계·내용 요구·현재 예산 검증은 유지한다.
첫 컷은 같은 원본 선언을 현재 예산 안에서 수용하고, 기존 scan/emit 원장과 실제
잔여 생산자가 이미 수용한 공간을 차감한다. 잔여 생산자의 종료 프레임 계약이나
paint를 따로 변경하지 않았다. 새 분기·문서 조건·좌표 수치·clamp는 추가하지 않았다.
