# task_m100_3389 처리결과 보고서 — 정답지 페이지별 대규모 비교 하네스

- **이슈**: [#3389](https://github.com/edwardkim/rhwp/issues/3389)
- **브랜치**: `pr/task-3386-fidelity-harness` (upstream/devel 직분기)
- **범위**: `tools/fidelity_compare/`(도구+README), 증거 시트 2장
- **분류**: 검증 도구 기여 (render-diff 보완 — 한컴 정답지와의 절대 정합)

## 1. 배경

사용자 요구는 "원본(정답지)과 페이지 단위로 많이, 단계별로(10→20→…) 비교해 한계를
보라"였다. render-diff 는 자기 일관성 게이트라 **한컴이 실제로 출력한 모습**과의
정합은 별도 축이 필요했다.

## 2. 방법

한컴 공식 PDF(pypdfium2 렌더) ↔ rhwp export-svg(Chrome headless, **SVG 판형 자동
맞춤** — 고정 창은 B4 를 크롭해 가짜 diff 를 만든다)를 페이지별 나란히 시트로 만들고
픽셀 diff% 랭킹(report.tsv)을 뽑아 **최악 페이지부터 사람이 감사**한다.

## 3. 실측 (단계별)

| 단계 | 문서 | 결과 |
|---|---|---|
| 1 | 업무계획 10쪽 | 시각 감사: 거의 동일 |
| 2 | 업무계획 **35쪽 전수** | 최악 p20 감사 → **#3385 발견**(PUA 원문자 tofu) |
| 3 | 수학 기출 20쪽(수식) | diff 6~11% — 수식 정합 강함 |
| 3 | 수능 언어 15쪽(B4 2단) | 2단·지문박스·30문항 구조 재현. 잔여 = 자간/글자폭 미세 확대(폰트 폴백 의심, RHWP_FONT_PATH_DIR 재측정 예정) |

## 4. 남긴 것

- 자간/글자폭 누적 차 — 폰트 고정 재측정 후 실질이면 이슈화.
- CI 상시 게이트화(diff% 회귀 임계) 는 메인테이너 방향 결정 후.
