## 3. PDF 없는 샘플 — drift 측정으로 정합성 검증

### k-water-rfp.hwp (28p → 26p)

`RHWP_TYPESET_DRIFT=1` 출력 분포:
| diff | paragraph 수 | 의미 |
|------|--------------|------|
| **+0.0** | 301 | HWP vpos 완전 정합 |
| +0.3 | 3 | 미세 차이 (반올림) |
| +15.1 | 1 | 특이 케이스 |
| -0.0 | 1 | 0 |

**정합률 98.7%** — paragraph 누적 거의 완전 정확.

### hwpspec.hwp (177p → 172p)

| diff | paragraph 수 | 패턴 |
|------|--------------|------|
| +0.0 | 217 | 완전 정합 |
| +6.7 | 495 | sb=6.7 (spacing_before) |
| +13.3 | 109 | sb=6.7 + 추가 |
| +16.0 | 121 | sb+sa 합 |
| +20.0 | 40 | larger spacing |

`diff = fmt_total - vpos_h = spacing_before + spacing_after` (paragraph 영역 외부의 의도적 spacing).

`vpos_h = (last_vpos + last_lh) - first_vpos` 는 paragraph 영역 안의 vpos만 측정. spacing_before/after 는 별도이므로 fmt_total 에 포함되는 게 정확. **drift 가 아닌 의도적 spacing 표현**.

## 4. 페이지 수 변화 정합성 판단

| 샘플 | Before | After | 변화 |
|------|--------|-------|------|
| k-water-rfp | 28 | **26** | -2 |
| hwpspec | 177 | **172** | -5 |

paragraph 누적이 trailing_ls 만큼(9.5px) 줄어들면서 한 페이지에 더 많은 paragraph 가 들어감. 정확한 누적 결과.

### 정합성 근거

1. **drift 측정**: k-water-rfp 99% 정합, hwpspec 의도적 sb/sa 외 모두 정합
2. **다른 샘플의 한컴 일치**: exam_kor (20=20), exam_eng (8=8), 21_언어_기출 (15=15) 모두 한컴 2020 페이지 수와 일치
3. **시각 검증**: 21_언어_기출 페이지 12 PDF 와 우리 SVG 완전 일치
4. **변화 메커니즘**: paragraph 17개 누적 시 ~200px drift → 페이지 1~2개 감소가 자연스러운 결과

따라서 **k-water-rfp 26p, hwpspec 172p 가 한컴 표준에 부합**할 가능성이 매우 높음.
