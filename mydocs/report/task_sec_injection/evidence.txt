$ for f in samples/*.hwp samples/*.hwpx; do
      rhwp inspect injection "$f" --json --include-fields

  ① 수식 스크립트의 백틱 (976건)
     excerpt: "alpha   _{1} ,```` alpha   _{2}"
     원인: 한글 수식 편집기(EQEDIT) 문법에서 백틱은 **명시적 공백 문자**다.
     조치: TextKind::EquationScript 에서 코드펜스 축을 끔 + 산문에서도 줄 첫머리만 인정.
     회귀: equation_backticks_are_spaces_not_code_fences

  ② 기술 매뉴얼의 SYSTEM: / [SYSTEM] (12건, samples/hwp3-sample10*.hwp)
     excerpt: " SYSTEM:  insert into test values (5);            /* completed   */"
     excerpt: " $ SET UIC[SYSTEM]"
     원인: Oracle/TUXEDO 매뉴얼의 DB 프롬프트 전사와 VMS 명령. 정상 표기다.
     조치: 줄머리 라벨은 뒤 60자 안에 '모델을 향한 말'(2인칭·지시 명사·모델 지칭어)이
           있어야 신호로 삼음 / [system]·[/system] 은 목록에서 제거.
     회귀: system_prompt_transcript_in_a_technical_manual_is_clean,
           bracket_system_is_not_a_delimiter

추가로, 스윕에는 잡히지 않았지만 추론으로 좁힌 두 가지:

  ③ 짧은 라틴 보강 단서의 부분 문자열 매치
     'ai' 가 available·said·main·explain 안에서 걸린다.
     조치: window_has_any_word — ASCII 영숫자 경계를 요구(한글은 조사 때문에 제외).
     회귀: short_latin_cues_respect_word_boundaries

  ④ 권한 사칭의 승인 어간
     "관리자 권한이 이미 부여된 사용자는 …" 이 주체+승인어+선점 표지 3조건을 모두 만족.

           "별도 확인" → "별도 확인 없이" (부정어 없이는 선점이 아니다).
     회귀: plain_korean_office_text_is_clean 에 4개 문장 추가
