## 무엇이 보이나

수정 전에는 앞 네 항목(`桂禧悅`·`國會事務處`·`______`·`權寧星`)만 왼쪽에 붙고
`金杜炫` 부터 갑자기 깊이 들여쓰인다. 같은 목록인데 정렬이 갈린다.

수정 후에는 모든 항목이 나란히 서고 정본과 같은 모양이 된다. 줄 폭이 제자리를
찾으면서 같은 쪽에 한 항목이 더 들어간다.

렌더 x 좌표로 재면 이렇다.

```
  한/글 정본   100.7
  수정 전      157.0     (+56.3)
  수정 후      100.7     정본과 일치
```

## 계측

| | 쪽수 | 글자수 |
| --- | ---: | ---: |
| 한/글 정본 | 264 | 248,002 |
| 수정 전 | 272 | 239,744 |
| 수정 후 | **263** | **240,673** |

`SO-SUEOP` 을 한/글 자신의 HWPX 변환본과 대조하면 여백 불일치가 **17 → 0** 이고,
줄 상자는 기준선과 같은 4건(이 축과 무관한 기존 차이)으로 돌아온다.

## 상쇄되어 있던 두 번째 결함

여백만 고치면 `SO-SUEOP` 의 줄 상자 18개가 어긋난다. `hwp3_para_line_box` 가 여백에
음수 들여쓰기를 한 번 더 더하고 있었기 때문이다. 종전에는 여백이 정확히
`|들여쓰기|` 만큼 부풀어 두 오류가 상쇄됐다.

```text
  정본    여백 6000 · 들여쓰기 -2000 · 줄 상자 (3000, 39520) = 여백/2
  기준선  여백 8000 · 들여쓰기 -2000 · 줄 상자 (3000, 39520)   여백만 틀림
  여백만  여백 6000 · 들여쓰기 -2000 · 줄 상자 (2000, 40520)   상자만 틀림
  둘 다   여백 6000 · 들여쓰기 -2000 · 줄 상자 (3000, 39520)   일치
```

## 남은 격차

정본 대비 −1쪽이 남는다. 이 축이 아니라 탭 채움 유실(#7170)과 각주 모양 누락(#7174)
때문이며 각각 별도로 다룬다.
