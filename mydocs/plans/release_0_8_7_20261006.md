## 추가로 발견한 릴리스 운영 차단점

로컬 publish 계약 검사에서 현재 버전을 0.8.6으로 고정한 테스트가 실패했다. 버전 형식과 Cargo 원본 대비 모든 manifest·lockfile·현재 사용자 안내의 일치 검사를 유지하며 고정값을 제거했다. 서드파티 라이선스 기준 버전도 갱신했다.

main 대비 inventory에는 5개 workflow 정책 누락과 변경된 CodeQL init의 비고정 action ref가 있었다. CodeQL init/analyze를 GitHub v4 tag의 실제 commit `2892aa5e19bbd11bc0cff5427e3b750a04d9e3c2`로 고정했다. Nextest build/run reusable은 실제 CI의 네 archive build/worker 성공을 요구한다. issue-form-labels·refresh-nextest-duration·trusted-postmerge-ci-reuse는 새 read-only dispatch adapter에서 기존 shipped script와 API 실패 계약을 실행한다. 실제 label/metrics 쓰기 성공은 미검증이며 원격 승인 후에도 adapter는 쓰기를 하지 않는다.

여러 파일이 같은 caller run을 공유하면 collector가 마지막 파일 hash만 보존하던 결함도 재현했다. 두 source hash/mode를 같은 exact run에 연결한 신규 회귀 검사는 수정 전 `1 != 2`로 실패했고, 수정 후 각 hash·mode·verdict를 별도로 보존해 통과했다. gate의 SHA·workflow hash·actor·pagination·필수 job·artifact 요구를 완화하지 않는다.

## PR #7603 병합과 preflight 등록 경로 보정

사용자가 CI 성공 후 다음 절차 진행을 지시했다. 최종 제출 head `f9e9b3b1b8a5dce9b4927cbfb674f88c328e4e01`의 CI·CodeQL·Adapter·Proptest·Render Diff가 모두 종료되어 성공했고, required Build & Test와 CI Impact Policy도 성공했다. 정상 skipped job을 실패/미실행 필수 job과 구분했다. 최신 base/head·MERGEABLE/CLEAN·merge-tree를 재확인한 뒤 일반 merge commit으로 통합했다.

- merge SHA: `d84dce2ac9f6a7fcaf522036b8801aba76234dac`, 부모 devel `17a69fa4e`와 제출 head `f9e9b3b1b` 두 개.
- clean 기본 devel을 같은 SHA로 fast-forward했고 main ancestor·검토 기록·오늘할일 포함을 확인했다. 별도 기록 PR은 필요하지 않다. 결과는 한국어 merge 메시지에도 기록했다.
- 병합 후 [duration 갱신 run 37413415039](https://github.com/edwardkim/rhwp/actions/runs/37413415039)이 성공했다. 검증 CI를 병합 뒤 재실행하지 않았다.
- 병합 source의 promotion inventory는 executable 16개, 정책 위반 0이다. 그러나 새 `release-operations-contracts.yml` 조회 API는 404이며 Actions workflow 목록에도 없다. 등록된 CI는 active다. [GitHub의 수동 실행 규칙](https://docs.github.com/actions/managing-workflow-runs/manually-running-a-workflow)에 따라 신규 dispatch-only workflow는 이 상태에서 main 승격 전 증거를 만들 수 없다.

로컬 보정 브랜치 `release/0.8.7-preflight-registration-20261006`은 최신 devel merge SHA에서 시작했다. 새 adapter를 `workflow_call`로 바꾸고 등록된 CI가 manual dispatch에서만 같은 commit의 local reusable workflow로 호출한다.
