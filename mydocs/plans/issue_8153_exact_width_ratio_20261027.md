# #8153: 원본 장평의 항등 판정과 공통 paint 계약

두 편람의 남은 문자 차이에서 HWP5 revision 1.3의 표 33에 명시된 언어별
장평 `UINT8[7]`, 50~200%와 실제 paint를 대조했다. 원본·독립 Print PDF·
실루엣의 임계값이나 반경은 바꾸지 않는다. 글꼴 파일도 복사·수정하지 않는다.

## 선행 분석과 독립 근거

`7a9015f35732fc90df812ba070e3be195677e8ec`의 Native paint 구현에서
`(ratio - 1.0).abs() > 0.01`이 도입됐다. 이후 `e275789f23`의 파일 분리와
장평·수식 보정에서도 이 조건은 유지됐다. 99%는 Native의 f32 변환 뒤
`0.9900000095367432`가 되어 생략되지만 SVG·Canvas의 f64에서는 적용된다.
공식 정수 백분율에는 99%를 100%로 생략할 근거가 없다.

독립 대조군은 99·100·101%, 같은 KoPub돋움체 Light·400pt·한 글자 `한`의
세 쪽이다. 수동 작성한 HWPX를 한컴 2024에서 실제 HWP로 저장한 뒤 그 저장본을
PrintMethod=0으로 인쇄했다. 정규화된 실제 입력은 A4이며, 글자는 본문 안에 있다.
한컴은 99·101%를 각각 99.003128·100.996872의 `Tz`로 출력하고 100%는
항등으로 유지한다. PDF의 장치 단위 양자화와 원본 백분율은 구분한다.

| 독립 대조 쪽 | 원본 장평 | 보정 전 Native raw | 정수 미대응 |
| --- | ---: | ---: | ---: |
| 1 | 99% | 96.58386% | 2,020 |
| 2 | 100% | 100% | 0 |
| 3 | 101% | 98.63067% | 808 |

이 진단의 정규화 HWP SHA-256·PDF SHA-256·작업 ID·한컴 버전·인쇄 계약은
ignored `remaining-raw100-diagnostic/small-residuals/width-ratio-controls-v2/`
의 `independent-print-receipt.json`과 `native-before/result.json`에 있다.
기존 383쪽 기준 PDF는 재출력하지 않았다.

## 생산·소비와 보정 범위

`원본 언어별 장평 → ResolvedStyle/TextStyle.ratio → ratio_draw_params →
Native/SVG/Canvas/HTML의 가로 변환 → 실제 glyph`를 대조한다.
줄 소속·배치 전진·세로 크기·저장 LineSeg는 그대로 소비한다. 공통 TextStyle에서
정규화한 장평의 항등 여부를 결정하고 각 paint가 같은 결과를 사용하게 한다.
Native의 f32 변환 전에 항등 여부를 결정해 수치 정밀도에 따른 분기를 없앤다.
특정 페이지·글꼴·문자나 관측 점수로 분기하지 않는다.

100%의 정상 대조군, 양쪽 비항등, 유효하지 않은 장평의 기존 기본값을 검증한다.
장평을 실제 적용하는 경로에서는 기존의 단일 축 변환과 glyph 맞춤·장식의 좌표계를
함께 확인한다. 같은 런을 두 번 늘리거나 좁은 문장부호의 기존 계약을 임의로 제거하지 않는다.

## 검증과 완료 조건

먼저 독립 세 쪽과 두 편람의 59·79·101·130·141·145·232·272쪽 등 영향 영역을
Native로 대조한다. 새 하락이 있으면 원인을 확인하고 보정한다. 이후 같은 source의
표준 최적화 fresh WASM과 전쪽 TSV를 확인한다. 진단만으로 회귀 검사를 등록하거나
전쪽 완료를 주장하지 않는다. 100% 항등 대조군은 RGB 전체가 같아야 한다.

직전 행 잔여 보정 `95a1c8df17`은 Native 766조건과 정식 nextest 14건을 통과했다.
동일 source의 표준 최적화 WASM 빌드는 완료됐으며 집중·전쪽 검증은 별도로 계속된다.
그 결과와 이 변경의 검증을 섞지 않는다. #8153의 전쪽 1,532조건 raw 100%·
미대응 0, 최종 필수 검증, PR 준비까지만 수행하는 경계는 유지한다.
