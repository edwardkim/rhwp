## 2. #825 결함 분석

### 위치
- [rhwp-studio/src/command/commands/insert.ts:172-186](../../rhwp-studio/src/command/commands/insert.ts#L172-L186) — `insert:picture-props` 커맨드
- [rhwp-studio/src/engine/input-handler-picture.ts:19-107](../../rhwp-studio/src/engine/input-handler-picture.ts#L19-L107) — `getSelectedPictureRef()`
- WASM `getPictureProperties(sec, ppi, ci)` 등의 lookup API

### 본질
`getSelectedPictureRef()` 가 반환하는 `{sec, ppi, ci, type, cellIdx?, cellParaIdx?}` 구조에 **header/footer 컨텍스트 marker 부재**. WASM API 들이 `section.paragraphs` 만 lookup 하므로, 머리말/꼬리말 paragraph 의 그림은 위치 식별 실패 → dialog open 실패.

### 한컴오피스 동작 비교
한컴오피스도 머리말 영역 직접 우클릭 정상 처리는 안 하고, **머리말 안으로 진입 (헤더 편집 모드)** 후 그림 선택해야 dialog 표시. 즉 한컴은 "header edit mode 진입" 패턴.

### 해결 방향 (옵션)

| 옵션 | 내용 | 난도 | 권장 |
|---|---|---|---|
| 1 | ref 구조에 `headerFooter?: 'header'|'footer'` 추가 + WASM API 확장 | 중 | ★ (MVP) |
| 2 | 한컴식 "머리말 편집 모드" 진입 UX 구현 | 높음 | (별도 task) |

→ **옵션 1 채택**. 한컴식 모드 진입은 별도 UX task 로 분리.

## 3. #826 결함 분석

### 위치
- [src/parser/hwp3/johab.rs:65,67](../../src/parser/hwp3/johab.rs#L65-L67) — `0x301C => 0xF080F` + `0x303D => 0xF0827`
- rhwp-studio 폰트 로딩 ([rhwp-studio/src/core/font-loader.ts](../../rhwp-studio/src/core/font-loader.ts), [font-substitution.ts](../../rhwp-studio/src/core/font-substitution.ts))

### 본질
HWP3 char `0x301C` / `0x303D` 가 한컴 PUA `U+F080F` / `U+F0827` 로 매핑됨. 한컴 함초롬 폰트는 해당 PUA 에 글리프 보유 (U+F080F = "굵은 가로선"), 그러나 rhwp-studio 번들 폰트 (Pretendard / Cafe24 / Happiness Sans / Nanum 시리즈 등 오픈 라이선스만) 에는 부재.

**HWP5 변환 검증**: 한컴이 sample11.hwp 를 HWP5 로 변환한 `samples/hwp3-sample11-hwp5.hwp` 의 같은 위치 텍스트도 **U+F080F 그대로 유지**. 즉 한컴 자체의 cross-reference 정합 의도가 PUA 보존이며, 본 결함은 **rhwp-studio 폰트 레이어의 글리프 부재**가 본질.

**PR #753 후속 항목**: 본 결함은 PR #753 본문에 명시된 후속 — "PUA char (U+F080F, U+F0827) 폰트 fallback (별도 task)" — 의 직접 수행. 두 codepoint 모두 본 task 에서 처리.

### 해결 방향 (옵션)

| 옵션 | 내용 | 라이선스 | 난도 | 정합성 |
|---|---|---|---|---|
| A | 함초롬바탕 등 PUA glyph 보유 폰트 번들 | 한컴 저작물 — 번들 불가 | 낮음 | 완벽 |
| B | parser: U+F080F → 표준 Unicode 재매핑 | 라이선스 무관 | 낮음 | HWP5 cross-ref 깨짐 |
| C | renderer: PUA 범위 감지 시 SVG primitive (선/사각형) 직접 draw | 라이선스 무관 | 중 | 시각 정합 |
| D | rhwp-studio 측 render-time substitution (PUA → 표준 Unicode) — IR 보존 | 라이선스 무관 | 낮음 | 시각 정합, IR 보존 |

→ **옵션 D 채택**. 가장 단순하고 IR 정합 유지. PR #753 의 "폰트 fallback" 표현과도 부합 (parser 변경 아닌 fallback 추가).

**매핑 후보**:
- `U+F080F` (굵은 가로선) → **U+2501 ━** BOX DRAWINGS HEAVY HORIZONTAL (모든 CJK 폰트 보유)
- `U+F0827` (한컴 PUA — johab.rs 코멘트 외 상세 부재) → 한컴 함초롬 글리프 시각 확인 후 매핑 후보 결정. 1차 후보: **U+25A0 ■** BLACK SQUARE 또는 **U+2580 ▀** UPPER HALF BLOCK. 실제 함초롬 글리프 미확인 상태로 본 task 에서는 U+25A0 으로 잠정 매핑 후, 시각 검증 결과로 조정.

향후 다른 한컴 PUA 추가 발견 시 동일 substitution table 에 항목 추가만으로 확장 (PR #753 후속의 점진 확장 패턴).
