# Task #473 수행계획서

## 이슈

- 번호: #473
- 제목: 그림 crop 변환의 scale 기준 오류 — original_size_hu(표시 HU) 가 96-DPI native HU 와 일치하지 않을 때 viewBox 과대
- 마일스톤: M100
- 브랜치: `local/task473`

## 배경

`samples/21_언어_기출_편집가능본.hwp` 페이지 12 우측 단 `<보기>` 표 내부 그림이 16% 비율로 축소 표시. 분석 결과: HWP `crop` 은 96-DPI HU(75 HU/px) 관행으로 인코딩되지만, `compute_image_crop_src` 가 표시 HU(`original_size_hu`)를 scale 기준으로 사용 → 사용자가 표시 크기를 변경한 그림에서 viewBox 가 어긋남.

## 수행 범위

`src/renderer/svg.rs:2385-2404` `compute_image_crop_src` 의 scale 계산 변경.

대안 검토:
1. **scale = 75.0 고정**: 모든 케이스 정확. 다른 DPI 관행 가능성 검증 필요.
2. **crop_right / img_w_px**: 풀 crop 시 정확. 부분 crop 의 경우 cr 가 full extent 보다 작아 부정확.
3. **original_size_hu 검증 후 fallback**: orig_size_hu / img_w_px 가 75 ± 허용오차 인 경우만 사용, 아니면 75 사용.

→ **3안 채택**: 기존 동작 호환성 + 새 케이스 정정. exam_kor 헤더(orig=174000, scale=75) 는 그대로, 21_언어_기출(orig=26640, scale=12) 은 75 로 보정.

## 위험 / 부작용

메모리 `feedback_essential_fix_regression_risk` 적용:
- 그림 렌더링은 다양한 DPI(48/96/150/300/600) 의 이미지가 혼재 가능 → 광범위 샘플 검증 필수
- crop 가 있는 모든 그림 (헤더 로고, 도해, 수식 등) 영향
- 한컴 2010/2020 정답지 + 한컴독스 PDF 비교 → "어떤 환경에 align" 명시
