## 1. 목표

Q2-D의 목표는 common shaping 결과를 단순히 paint에 전달하는 것이 아니다. 다음 네 소비자가 같은
`Arc<HorizontalShapingMeasurement>`를 사용하도록 owner를 닫는 것이다.

1. line range 검증 또는 NO_LS line selection
2. 최종 TextRun bbox와 다음 run x origin
3. page-local emitted-node sidecar
4. 기존 `LayerGlyphRunPaint`의 glyph·position·advance·cluster

한 단계라도 다른 측정값을 쓰면 Q2-C 결과를 게시하지 않는다. 일반 Latin liga, RTL, variation, vertical,
display projection, control·tab·char overlap, 비영 자간·condense는 계속 닫는다.

## 2. 수정된 owner 구조

```text
ResolvedStyleSet.horizontal_shaping_context (transaction-shared Arc)
  -> compose_paragraph_with_horizontal_shaping()
       Q2-C line outcome Arc
       -> ComposedParagraph.horizontal_shaping (serde 대상 아님)
  -> paragraph_layout final emitted run range 대사
       -> bbox / next x = same measurement total advance
       -> PageRenderTree.horizontal_shaping_sidecars[NodeId]
  -> LayerBuilder reads LayerNode.source_node_id
       -> existing LayerGlyphRunPaint + TextRun fallback
```

`TextRunNode` public layout schema와 `layout_positions` 타입은 바꾸지 않는다. PageRenderTree sidecar table은
`#[serde(skip)]`이며 clone은 `Arc`만 복제한다.

## 3. 최초 applied lane

Q2-C matrix보다 제품 적용 조건을 더 좁힌다.

- full emitted run 전체가 하나의 직접 옛한글/현대 Hangul target segment다.
- 한 slot·embedded exact portable source·font size·장평·kerning flag를 사용한다.
- model text와 replay text가 같고 PUA/display projection이 없다.
- horizontal-tb, LTR, bidi level 0, variation empty다.
- synthetic bold/italic, super/sub, 자간, condense, tab, inline control, note marker, rotation,
  char overlap, border/background, underline/strike/emphasis가 없다.
- source line range가 Q2-C 결과와 같거나, NO_LS render-only transaction이 Q2-C range와 sidecar를 함께 만든다.
- LayerBuilder가 같은 embedded bytes·face index를 대사할 수 있다.

mixed non-target prefix/suffix는 Q2-C dormant fixture로 유지하지만 최초 public GlyphRun에는 열지 않는다. partial
GlyphRun variant가 TextRun 전체의 대안으로 오인되는 것을 막기 위해서다.

## 4. 구현 절편

### Q2-D0 — sidecar ABI와 bounded table

1. applied/rejected를 함께 표현하는 internal `HorizontalShapingRunDecision`을 만든다.
2. `PageRenderTree`에 `NodeId → Arc<decision>` sidecar table과 4,096 entry 상한을 추가한다.
3. duplicate node, range mismatch, stale registry generation을 typed reason으로 거부한다.
4. serialization·legacy `to_json()`·clone에서 public bytes 변화 0과 Arc 공유를 검증한다.

**종료 게이트**: 모든 sidecar가 비어 있는 기본 경로에서 render/layer JSON 변화 0. 제품 consumer는 0.

### Q2-D1 — composition owner 인계

1. `ResolvedStyleSet`에 Q2-B context의 transaction-shared `Arc`를 추가하고 W9와 같은 registry generation에서 만든다.
2. 기존 `compose_paragraph()`·`compose_section()`은 sidecar `None`의 호환 경로로 유지한다.
3. 좁은 style-aware composition entrypoint가 Q2-C transaction을 실행하고 qualified outcome `Arc`를
   `ComposedParagraph`에 보존한다.
4. exact source rebuild → context snapshot → composition 순서를 DocumentCore 파생-state 경계에서 고정한다.
5. context 없음·상한·range mismatch는 기존 composition을 그대로 반환한다.

**종료 게이트**: Q2-C line target `Arc`와 composed owner가 `Arc::ptr_eq`, 기존 151개 callsite의 출력 변화 0.

### Q2-D2 — final emitted-run mapping

1. paragraph scalar range, emitted run scalar range, UTF-8·UTF-16 range를 함께 대사한다.
2. full emitted run이 exactly one target range일 때만 같은 measurement를 채택한다.
3. `layout_positions=None`, bbox width·다음 run x를 measurement total advance로 한 번만 계산한다.
4. node 생성 뒤 same `NodeId`로 PageRenderTree sidecar를 attach한다.
5. footnote/TAC/field/display split 또는 decoration이 생기면 run 전체를 W9/K0로 rollback한다.

**종료 게이트**: line width = bbox width = next origin delta = shaped advance, partial range publication 0.

### Q2-D3 — GlyphRun lowering shadow

1. LayerBuilder가 `LayerNode.source_node_id`로 page sidecar를 찾는 별도 lowering entrypoint를 만든다.
2. embedded face digest·face index를 sidecar source handle과 대사한다.
3. Q2-B glyph px, advances와 cluster range를 기존 `LayerGlyphRunPaint`에 손실 없이 변환한다.
4. TextRun fallback은 항상 먼저 보존하고 nominal old-Hangul lowerer와 중복 생성을 금지한다.
5. rejected attempt는 page-local source node와 lowering report에 연결하되 public annotation은 아직 만들지 않는다.

**종료 게이트**: 공개 fixture의 glyph ID·position·advance·UTF-8/UTF-16 cluster가 native·WASM에서 일치하고 제품
builder는 아직 새 lowerer를 호출하지 않는다.

### Q2-D4 — 동일-boundary 원자적 activation

1. 저장 또는 현행 line range가 Q2-C 결정과 정확히 같은 문단만 activation한다.
2. paragraph layout과 LayerBuilder가 D2·D3 sidecar를 함께 소비하도록 한 commit에서 연결한다.
3. sidecar/lowering 실패 시 line range를 바꾸지 않고 기존 W9 K1/K0 TextRun만 남긴다.
4. non-target render-tree·layer-tree hash와 W9 `layout_positions` fixture를 전건 대사한다.

**종료 게이트**: 지원 old-Hangul lane에 common GlyphRun 1개, TextRun fallback 1개, nominal duplicate 0;
non-target output change 0.

### Q2-D5 — NO_LS boundary-changing activation

1. 모델 `LineSeg`를 저장하지 않는 ordinary single-interval NO_LS render-only path만 연다.
2. Q2-C가 line range와 final target `Arc`를 같은 `ComposedParagraph` transaction으로 반환한다.
3. multi-interval frame, edit reflow, stored prefix, split cell, inline control은 계속 기존 경로로 닫는다.
4. sidecar attach·lowering 준비가 완료되지 않으면 Q2-C boundary도 게시하지 않고 pristine W9/K0 composition을 쓴다.

**종료 게이트**: boundary가 바뀌는 fixture에서도 line selection·bbox·next origin·GlyphRun이 같은 Arc를 소비하고,
transaction 중 하나라도 실패하면 네 값 모두 기존 owner로 rollback한다.

## 5. 검증

- 새 integration source는 `tests/cases/` 원본만 추가한다.
- D0: sidecar serialization 음성, entry/duplicate/stale generation 상한
- D1: line → composed `Arc::ptr_eq`, context generation 변경·cache exhaustion rollback
- D2: scalar/UTF-8/UTF-16 range, bbox·next origin 일치, W9 상호 배타
- D3: old Hangul 4 glyph·2 cluster, `0..3` unsplittable range, embedded face identity
- D4: TextRun 1 + GlyphRun 1, nominal duplicate 0, non-target output hash 변화 0
- D5: NO_LS boundary delta와 전체 transaction rollback
- native·Node WASM parity, native/WASM lib clippy, K0·W9 focused regression
- PR 준비 단계에서만 review worktree generated suite·manifest와 전체 fmt/nextest를 실행한다.

성능은 D0~D3의 dormant 비용과 D4/D5 activation 비용을 분리한다. page sidecar entry 수, retained Arc bytes,
lowering wall time, GlyphRun payload bytes를 계측하고 Q2-F 기준선으로 넘긴다.

## 6. 제외·중단 조건

- 일반 edit reflow가 `LineSeg`만 남기고 Arc를 잃는 구조는 열지 않는다.
- external/native 등록 source만 있고 embedded portable face가 없으면 public GlyphRun을 만들지 않는다.
- public rejected-attempt annotation이 반드시 필요해지면 schema minor 계획을 별도 보고한다.
- one target가 emitted run 일부만 차지하면 run을 자동 분할하지 않고 후속 activation matrix로 넘긴다.
- D0~D3 결과에서 owner identity나 serialization 무변화가 증명되지 않으면 D4로 진행하지 않는다.

받는다. commit·push·PR·GitHub comment는 기존 승인 경계를 유지한다.
