# Task #519: 그림(Picture) flip / rotation 속성 SVG 렌더링 적용 — 수행계획서

## 배경

`samples/exam_eng.hwp` 4페이지 28번 안내문 박스의 종이-말림(curl) 데코레이션 그림이 PDF 에서는 박스 **왼쪽 상단** 에 표시되지만, rhwp SVG 출력에서는 원본 이미지 그대로(curl 이 우하단) 렌더링되어 표 본문과 겹쳐 사실상 보이지 않음.

## 본질

HWP 의 Picture 컨트롤은 다음 변환 속성을 가진다:

- `shape_attr.horz_flip` (좌우 대칭)
- `shape_attr.vert_flip` (상하 대칭)
- `shape_attr.rotation_angle` (회전각, HWP 스펙 1/100° 단위)

해당 그림(`bin_id=2`)의 실제 값:

```
[s0 p189 c1] flip=(h=true,v=true) rot=0
M=[-0.976,0.000,30614; 0.000,-0.881,30190]
```

수평+수직 뒤집기 (180° 회전과 동일한 효과).

`src/renderer/svg.rs:565 open_shape_transform` 은 `RenderNodeType` 의 `transform: ShapeTransform` 필드를 읽어 `<g transform="…">` 래퍼를 생성하지만, **Picture 의 ImageNode 생성 시 `transform` 필드를 채우지 않음** — `..ImageNode::new(...)` 로 `ShapeTransform::default()` (변환 없음) 가 들어감. 결과적으로 회전·뒤집기가 모두 무시됨.

같은 페이지 27번 그림(`bin_id=3`)은 flip 이 없어 정상 렌더되며, 다른 도형(Rectangle/Line/Ellipse 등)은 정상 작동 — Picture 만 누락된 결함.

## 영향 범위

- 회전·뒤집기가 적용된 모든 Picture 컨트롤이 잘못 렌더됨
- `samples/exam_eng.hwp` 4페이지 28번이 회귀 검증 케이스
- 다른 샘플에서도 같은 결함이 잠복했을 가능성 있음 (조사 필요)
