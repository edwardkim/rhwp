### 2.3 결함 원천 식별

"홀수형" 글상자는 **master 가 아닌 sec1 paragraph 0** (cover) 의 `사각형` 컨트롤 (`InFrontOfText`) 안에 있음:

```
[4] 사각형 round=10%, 선=width=56, style=0xc0000041
    글상자: paras=1
      p[0]: cc=4, text="홀수형"
```

`InFrontOfText` wrap 으로 sec1 모든 페이지에 동일 위치 자동 stamp 됨. 페이지마다 (홀수/짝수) 좌우 위치는 sec1 첫 페이지 컨트롤 좌표가 그대로 적용된 결과 — section-level decoration 으로 정상 동작.

이슈 본문의 "master[0]/master[1] cell[0] 의 도형 추정" 가설은 부정확. master 표 cells 에는 페이지번호와 "(화법과 작문)" 텍스트만 있고, 홀수형 글상자는 sec1 pi=0 의 InFrontOfText 사각형 컨트롤이 source.
