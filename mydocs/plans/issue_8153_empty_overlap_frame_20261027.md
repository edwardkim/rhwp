# #8153 빈 글자 겹침의 글줄 점유

대상은 두 편람 59쪽의 도형 다음 쉼표다. HWP의 해당 글자 겹침은 `U+3000` 한 자,
HWPX의 `composeText`는 빈 문자열이다. 원문 본문·컨트롤 순서·소유 위치와 글자모양
배열은 같다. HWPX에서만 컨트롤을 건너뛰어 쉼표가 약 13px 왼쪽에 나온다.

## 사양·원 해결과 독립 검증

HWP5 사양 표 150은 구성 문자 길이·배열, 테두리 종류·내부 크기·글자모양 배열을
정의한다. 이 표는 빈 구성 배열의 물리 폭을 0이라고 규정하지 않는다. OWPML schema의
`composeText`도 string이며, 빈 문자열의 글줄 폭이나 `U+3000` 기본값은 명시하지 않는다.
따라서 아래 참조 구현 관측을 공식 파일 형식의 숫자 규정으로 설명하지 않는다.

원 해결 커밋 `6c887fc798`과 `task_m100_1023_report.md`는 여러 구성 문자를 가진
박스 숫자를 한 편집·글줄 단위로 만들었다. `char_overlap_advance_units`의 빈 배열 0과
composer의 빈 문자열 skip은 빈 컨트롤에 대한 독립 Print 근거가 없었다.
이후 `0fec89c3cc`의 파일 분리에도 같은 판단이 남았다.

실제 한컴 2024 저장 정규화 job `1ca98352-6f0c-4365-8349-f1adb357abbf`로
동일 속성의 6조건을 대조했다. 빈 속성·속성 생략·빈 child는 각각 HWP의 `U+3000`
하나가 됐다. 명시 전각 공백·ASCII 공백·가시 글자 조건에도 앞에 `U+3000`이 붙었다.
따라서 구성 배열의 길이를 글줄 점유 단위 수와 같다고 볼 수 없다. 이를 근거로 모든
HWPX 문자열에 새 접두사를 넣거나 파일의 저장 문자를 변경하지 않는다.

원본 HWP의 이미 존재하는 한 프레임과 독립 Print의 같은 도형·쉼표 사이 빈 점유를
재사용한다. 구성 문자가 없는 HWPX도 같은 컨트롤 프레임 하나를 점유해야 한다.
소형 입력·정규화 출력 SHA는 ignored `empty-compose-controls/normalization-result.json`,
6조건의 원문/저장 배열은 `independent-normalization-audit.json`에 보존했다.
기존 두 편람과 기준 PDF는 바꾸거나 다시 인쇄하지 않았다.

동일 원본의 제안 검사에서 HWP의 기존 프레임은 통과했고 HWPX는 프레임 누락으로
실패했다. 기본 core API는 실제 호스트 글리프 공급을 하지 않으므로 이 검사에서는
소유·앞뒤 순서·별도 점유·원문 보존을 확인한다. 절대 좌표는 실제 Print producer의
PNG·독립 PDF에서 검증하며 다른 호출 경로의 수치를 해당 경로의 px 증거로 쓰지 않는다.

## 생산·측정·배치·출력 연결

- 생산: `inject_char_overlap_text`가 빈 구성에도 한 컨트롤의 표시 캐리어를 만든다.
  참조 저장본과 같은 전각 공백을 파생 run에만 사용한다. 문서 IR의 빈 배열은 보존한다.
- 측정: 공통 `char_overlap_advance_units`가 가시 구성 수와 별개인 한 프레임을 반환한다.
  저장 셀 재조판·문단 사전 측정·본문/셀 커서도 같은 계약을 소비한다.
- 배치: `paragraph_layout`의 `full_width`와 글자 겹침 분기가 이미 같은 helper의
  프레임 폭을 사용한다. 빈 run을 없애거나 뒤 좌표를 별도로 이동하지 않는다.
- 최종 출력: Native·Canvas·SVG는 기존 글자 겹침 run과 원래 소유 프레임을 소비한다.
  backend별 숫자 보정, 문서·쪽·글꼴 조건과 원문 문자 삽입을 추가하지 않는다.

기존 한 자리·여러 구성 숫자의 한 프레임은 유지한다. 실제 원본 HWPX의 수정 전 실패,
수정 후 컨트롤/쉼표 순서·프레임 점유·내용·원문 보존을 검사한다. 두 원본 59쪽의
Native/fresh WASM과 기존 정상 쪽, 전체 쪽수·전쪽 TSV를 대조한다. 해당 쪽의 Print
쉼표 위치는 ±2px 조건과 관계 검사로 보호하되, 양쪽 시각 선행 조건과 확대 판독을
마치기 전 정식 회귀로 등록하지 않는다. 최종 목표와 PR 준비만 완료 후 대기는 유지한다.
