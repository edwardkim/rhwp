# #7642 논리 기호의 표시 face와 전진폭

## 독립 근거와 원인

고정 devel `fe5725dc38`와 source `032ca53bcb`를 같은 Cairo·96DPI에서 대조했다.
11월 자료 15쪽의 Native raw는 98.98099%에서 98.80453%로 낮아졌다. 증가한
불일치는 `THEREFORE ~ q over p = 39 over 108 = 13 over 36`에 집중한다.
독립 원본 Print의 숫자·변수·등호는 HyhwpEQ인데 현재 ∴만 Latin Modern Math로
측정·표시한다. 첫 분수부터 뒤 표현식까지 약 6px 왼쪽으로 이동한다.

원본 Print의 분자/분모 기준선은 211.52/227.04이고 현재는 211.56/227.16이다.
분수 높이를 임의로 줄여 맞출 문제가 아니다. `layout_math_symbol`의 미지원
기호 fallback → 다른 face의 전진폭 → Row의 다음 자식 x → 최종 painter까지
연결되는 경로를 수정한다. 원본 수식과 저장 폭은 유지한다.

별도 48개 대조군을 로컬 XML로 작성한 뒤 한컴 2024에서 HWP로 정상 저장하고
그 저장본을 Print했다. 입력 생성 방식은 원본 한컴 저장본과 구분한다. 두 face
HancomEQN/HyhwpEQ, 6/9/12/18pt, ∴·∵·명시적 `~`·중간 기호·분수·직접 Unicode를
대조했다. Save job은 `9f6c1752-d800-4779-b075-9517002cec6a`, Print job은
`159528f2-cca1-47be-9aee-0163e1c48515`이며 PrintMethod=0, 13.0.0.3901이다.
두 face의 기호 전진은 논리 1em이고 `~`가 있을 때에만 반 em이 추가된다.
설치한 두 글꼴의 cmap/hmtx도 ∴·∵ 각각 1024/1024다. 글꼴 바이트를 포함하지 않는다.

## 수정과 검증

기존 실제 face의 GlyphRun에 ∴·∵를 연결하고 HancomEQN의 논리 1em 전진을
공유한다. 이항/관계 연산자로 재분류하지 않으며 자동 여백을 추가하지 않는다.
다른 수학 face의 기존 fallback, 원본 `~`, 분수 높이·기준선은 보존한다.

원본/PDF와 6쪽 대조군을 보존하고 Native/fresh WASM을 같은 조건으로 비교한다.
원본의 모든 관련 쪽 90% 이상·확대 판독 후 새 이름의 회귀를 추가한다.
기호 face·다음 피연산자의 상대 위치·공백의 독립 점유·본문 순서·내용 보존을
검사한다. 모든 devel 하락·기존 실패·PR 준비 완료와 이번 보정을 구분한다.
