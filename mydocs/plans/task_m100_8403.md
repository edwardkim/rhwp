## 목표와 완료 범위

`/mnt/e/tmp/black-image-01.pdf`에서 그림이 검정 단색으로 변환되는 원인을 공통 PDF 추출
경로에서 해결한다. 구현·Native/fresh WASM·Studio·저장 후 재열기·필수 회귀 검증을
**한 작업 단위**로 수행한다. 그림만 복구하고 검정 도형을 남기거나, 페이지 전체를 이미지로
바꿔 텍스트를 잃는 방식으로 완료하지 않는다.

입력은 8쪽이며 이미지 패턴은 1·3·4·5·8쪽에 총 10회 사용된다. 2·6·7쪽을 포함한
전체 문서의 내용·순서·쪽수 보존을 함께 검증한다. 현재 원인 조사에서 제품 코드는 바꾸지 않았다.

## 구현 범위

1. 공통 그래픽 상태에서 단색과 패턴 paint를 구분하고 패턴 리소스 이름·소유 문맥을 보존한다.
   `q/Q` 복원 시에도 해당 상태를 유지한다. 지원하지 못하는 paint를 이전 단색으로 성공
   처리하는 경로를 없앤다. 채움과 윤곽선의 상태를 섞지 않는다.
2. 이미지로 구성된 coloured tiling pattern (`PatternType=1`, `PaintType=1`)의 리소스와
   콘텐츠를 제한된 공통 추출 경로로 해석한다. 페이지·Form의 초기 좌표계, 패턴 Matrix,
   BBox와 반복 간격, 실제 채움 경로·현재 clip을 적용해 이미지 배치 결과를 만든다.
   기존 이미지 디코드·SMask·alpha 처리를 재사용한다.
3. 추출한 이미지가 기존 경로·텍스트와 올바른 순서로 IR에 들어가도록 한다. 패턴 채움에
   해당하는 가짜 단색 도형을 생성하지 않고, 함께 있는 실제 단색 채움·윤곽선은 보존한다.
   `패턴 상태 → 타일/clip 계산 → 이미지 핸들 → IR → Native/Canvas 출력`의 소비 위치를 기록한다.
4. 재사용되는 이미지의 디코드 캐시와 기존 요청 예산을 유지한다. 가시 영역과 교차하는 타일을
   계산하고, 타일 수·재귀 깊이·순환 리소스·출력 픽셀·연산량을 검사한다. 0인 반복 간격,
   비유한 값 등 잘못된 입력을 무한 반복·과도한 할당으로 연결하지 않는다.
5. 이번 범위 밖의 shading pattern·uncoloured pattern 등은 이미지를 지원했다고 가장하지
   않는다. 처리 불가능한 패턴은 조용한 검정 채움 대신 기존 PDF 오류 계약에 맞게 설명한다.
   문서 객체 번호·고정 좌표·파일 해시로 분기하거나 전체 패턴 렌더러를 새로 작성하지 않는다.

근거 사양은 ISO 32000-1:2008 §8.7.2와 §8.7.3이다. 패턴의 원점은 paint 순간 CTM이 아니라
리소스가 정의된 부모 콘텐츠의 초기 좌표계에 연결한다. 일반적인 행렬·반복·clip 처리는
표본의 값에 맞춘 특수 분기로 대체하지 않는다.

## 검증과 완료 조건

| 범위 | 실제 확인 사항 |
| --- | --- |
| 원본 PDF | 8쪽 전체 Native와 최적화한 fresh WASM 출력, 입력 PDF와 전쪽 TSV 및 직접 판독 |
| 핵심 그림 | 로고·그래프·나머지 패턴 이미지의 색·투명도·원점·크기·clip·누락·중복 확인 |
| 정상 대조군 | 직접 이미지 진단본, 일반 JPEG/SMask, 패턴 없는 쪽, 기존 단색 도형·텍스트 유지 |
| 공통 경계 | 패턴 재사용·여러 타일·행렬 변환·Form 리소스·q/Q·clip과 그 밖의 내용 보존 |
| 자원·실패 | 순환·깊이·잘못된 간격·예산 초과 처리 및 실패 후 정상 문서 열기 |
| 실제 사용 | CLI 변환, Studio 열기, HWP/HWPX 저장·재열기에서 그림과 기존 텍스트·순서 유지 |
| 최종 게이트 | 변경 범위에 해당하는 Rust/Native·lint·Studio 검사와 fresh WASM 브라우저 실행 |

시각 기준은 우선 원본 PDF 자체다. 변환 후 저장본의 한컴 출력 등 추가 대조가 필요한 경로는
해당 [시각 검증 절차](../manual/verification/visual_verification_governance.md)를 따른다.
전체 쪽수 일치와 Native/fresh WASM 전쪽 `silhouette_raw_match_percent` 최저 90% 이상,
변경 영역의 직접 확대 판독을 확인한다. 원인 조사의 정상 표시만으로 시각 완료를 선언하지 않는다.
폰트 환경·source SHA·빌드 산출물·TSV·대표 PNG를 기록한다.

회귀 등록은 [시각 선행 조건](../manual/pr_review/visual_fixture_evidence.md)을 충족한 뒤
기존 자동 수집 경로에 추가한다. 정상 그림이 있는 입력과 잘못된 입력을 구분하고 수정 전
실패·수정 후 통과를 확인한다. 이미지 소속·내용 순서·포함·누락·중복 관계를 검사하며
임의의 px/golden 값으로 현재 출력을 고정하지 않는다.

[로컬 사전 검증 4.3](../manual/pr_review/local_validation.md)에 따른 필수 검증을 최종 코드에서
완료한다. 승인된 범위에 필요한 실패는 보정·재검증하며, 성공한 검사를 이유 없이 반복하거나
관련 없는 엔진 개선으로 범위를 늘리지 않는다.
