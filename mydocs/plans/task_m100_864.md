## 2. 본질 진단 가설

선행 task Stage D-A 의 진단 결과:
- WMF binary: SetWindowOrg (329, 1536), SetWindowExt (4231, 1189) — top-down positive
- Placeable BoundingBox: (329, 1536) ~ (4560, 2725)
- element y: rect 1008, text 1205, image 1536 — 모두 BoundingBox top 보다 작거나 같음

### 가설 H1 — SetMapMode 처리 결함

WMF binary 가 SetMapMode (MM_ANISOTROPIC 등) record 보유. rhwp 가 미처리하여 좌표 변환 오류.

### 가설 H2 — SetViewportOrg / SetViewportExt 미처리

WMF binary 의 SetViewportOrg / SetViewportExt record 가 viewport (device coord) 정의. rhwp 가 Window 만 처리 + Viewport 미처리 → 좌표 매핑 오류.

### 가설 H3 — Logical → Device 좌표 변환 결함

WMF 의 element 좌표는 logical. SVG 의 좌표 (viewport) 로 변환 시 `(logical - window_org) * (viewport_ext / window_ext) + viewport_org` 공식 필요. rhwp 가 logical 그대로 사용.

### 가설 H4 — 한컴 의 y mirror 변환

한컴이 element y 를 `origin_y + ext_y - y - elem_h` 같은 mirror 변환 적용 (= 위/아래 flip).
