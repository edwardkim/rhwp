# Task #660: Neumann 본 작업 1 — JSON 스키마 + Rust 빌더 골격 — 수행계획서

## 목표

외부 입력 → HWPX 시험문제 변환 파이프라인의 **JSON 중간 표현 스키마**를 확정하고, Rust 측에서 그 JSON을 읽어 빈 Document IR로 변환하는 경로를 완성한다.

본 단계는 양 컴포넌트(Claude Code Skill + Rust 본체)의 **인터페이스 확립**.

전체 계획서: `~/.claude/plans/pdf-md-docx-optimized-neumann.md`  
선행: #654 spike (조건부 GO).

## 인터페이스 (`ingest_schema_v1.json`)

```jsonc
{
  "version": "1",
  "page_size": {"width_mm": 210, "height_mm": 297},
  "default_font": "함초롬바탕",
  "questions": [{
    "number": 1,
    "stem": "다음 글의 주제로 가장 적절한 것은?",
    "stem_blocks": [{"type":"text","text":"..."},
                    {"type":"image","ref":"img/q1.png","placement":"between"}],
    "choices": [{"label":"①","text":"..."}, ...],
    "media": [{"id":"img/q1.png","natural_w":1024,"natural_h":768,
               "target_w_mm":80,"placement":"between"}]
  }]
}
```

## 신규 파일

- `tools/rhwp-ingest/schema/ingest_schema_v1.json` — JSON Schema 정의
- `tools/rhwp-ingest/schema/sample_minimal.json` — 3문제 샘플
- `tools/rhwp-ingest/schema/sample_minimal/img/*.png` — placeholder 이미지
- `src/parser/ingest/mod.rs` — 모듈 진입점
- `src/parser/ingest/schema.rs` — serde 모델 + Placement enum + ingest 파일 파싱
- `src/document_core/builders/mod.rs` — 빌더 모듈 진입점
- `src/document_core/builders/exam_paper.rs` — IngestDocument → Document 변환
- `src/main.rs` 수정 — `rhwp build-from-ingest` 명령 추가

## 단계 분할 (3단계)

### 1단계: JSON 스키마 + serde 모델
- `ingest_schema_v1.json` 정의
- `src/parser/ingest/schema.rs` serde 모델 (`IngestDocument`, `Question`, `StemBlock`, `Choice`, `Media`, `Placement` enum)
- `src/parser/ingest/mod.rs` 진입점 (`pub fn parse_ingest_json(s: &str) -> Result<IngestDocument, _>`)
- Rust unit test: schema 라운드트립 (sample_minimal.json → IngestDocument → JSON → 동일)

### 2단계: 빌더 골격 + sample_minimal 변환
- `src/document_core/builders/mod.rs` 진입점
- `src/document_core/builders/exam_paper.rs` — `pub fn build_exam_paper(ingest: &IngestDocument) -> Document`
- 본 단계는 텍스트만 처리 (이미지/placement는 placeholder, 이슈 #661 본격 구현)
- sample_minimal.json → Document (3개 question = 3개 stem + 3×4=12개 choice + 빈 문단)

### 3단계: CLI + e2e
- `src/main.rs` 신규 명령 `build-from-ingest`:
  - `rhwp build-from-ingest <ingest.json> --media-dir <dir> -o <out.hwpx>`
- e2e: sample_minimal.json → HWPX → 한컴오피스/LibreOffice 정상 열림
- `cargo test` 통과, clippy 0 경고

## 검증

- `cargo test --lib parser::ingest::tests::schema_roundtrip` 통과
- `cargo run --bin rhwp -- build-from-ingest tools/rhwp-ingest/schema/sample_minimal.json --media-dir tools/rhwp-ingest/schema/sample_minimal/img -o output/sample_minimal.hwpx` 성공
- `rhwp dump output/sample_minimal.hwpx` 으로 IR 구조 확인 (3개 stem 문단 + 12개 choice 문단)
- WASM 빌드 무영향 (parser/ingest는 std::fs를 안 쓰고 byte slice만 받도록)
