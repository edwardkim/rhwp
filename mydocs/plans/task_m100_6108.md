## 목표

1. 자동·한 쪽·두 쪽·맞쪽·여러 쪽의 화면 점유 행·열을 하나의 맞춤 배율 계산 계약으로 표현한다.
2. `폭 맞춤`과 `쪽 맞춤`이 선택한 쪽 배치 전체와 내부 페이지 간격을 뷰포트에 포함하게 한다.
3. 보기 메뉴·상태 표시줄·확대/축소 대화상자·저장된 맞춤 복원이 같은 계산과 명령 경로를 사용하게 한다.
4. 화면 배율의 10~500% 범위를 단일 상수와 clamp 경로로 관리한다.
5. 실제 소비처가 없는 쪽 보기 이벤트·CanvasView 공개 wrapper와 스타일 소비처가 없는 class 토글을
   근거 확인 뒤 제거한다.

## 범위

### 포함

- 자동·한 쪽은 1×1, 두 쪽·맞쪽은 2×1, 여러 쪽은 지정한 가로×세로 블록으로 계산한다.
- `폭 맞춤`은 블록의 가로 폭을, `쪽 맞춤`은 블록의 가로·세로 전체를 뷰포트에 맞춘다.
- 여러 쪽에서는 지정 배열 전체 맞춤이 강제되는 현재 계약을 공통 calculator로 옮기고, 적용되지 않는
  비율 선택 UI는 비활성화한다.
- 명령·대화상자·문서 로드 복원에 동일한 `PageArrangement` snapshot과 page gap을 전달한다.
- 10%, 100%, 400%, 500% 경계와 모든 쪽 배치의 회귀 테스트를 추가한다.
- `page-arrangement-changed`, `CanvasView`의 단일 필드 wrapper getter/setter, `is-neutral` class 토글은
  실제 소비처를 다시 확인한 뒤 무사용 항목만 정리한다.
