# Task M100-3414 — 모달 종료 뒤 편집기 포커스 공통 복원

## 배경

GitHub Issue #3414는 모달 대화상자를 닫은 직후 `InputHandler`가 활성 상태인데 hidden textarea가
포커스를 받지 않아 Ctrl+Z가 입력 처리기에 도달하지 않는 문제를 다룬다.

기존에는 일부 표 대화상자만 `afterClose`에서 편집기 포커스를 직접 복원한다. 공통
`ModalDialog.hide()`는 오버레이만 제거하므로 나머지 모달은 동일한 키보드 공백을 남긴다.

## 구현 계획

1. `ModalDialog`가 닫힌 뒤 다른 `.modal-overlay`가 남아 있지 않을 때만 공통 종료 이벤트를
   발행한다. 중첩된 스타일 편집 등에서 자식 모달이 닫히며 부모 모달 바깥의 textarea로 포커스가
   빠지는 것을 막는다.
2. `main.ts`가 이 이벤트를 구독해, 활성 `InputHandler`가 있을 때만 공개 `focus()` API로
   hidden textarea에 포커스를 복원한다.
3. 소스 가드로 이벤트의 순서, 마지막 모달 조건, 활성 handler 조건을 고정한다.

## 범위 외

- 개체 선택 모드의 Ctrl+C/X/V/Delete 중복을 dispatcher로 이관하는 리팩터링
- 모달이 아닌 command palette·수식 편집기의 포커스 정책
- 한컴 2022의 선택/개체 undo 정합(#3416·#3351)
- GitHub comment, remote push, PR 생성과 merge
