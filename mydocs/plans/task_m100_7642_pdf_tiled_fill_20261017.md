# #7642 PDF의 인접 채우기 면 래스터 보존

## 독립 근거와 원인

배경 대조군 4개의 Native raw 미달은 새 devel 통합 후에도 재현됐다.
그림 영역은 약 98.6%지만 그라데이션 일부 영역은 약 54%다. PDF의 실제
색 명령은 원본과 같으며, Cairo 기본 antialias가 인접한 얇은 사각형을 따로
합성하면서 내부에 흰 이음매를 만든다. RHWP의 도형 위치나 입력을 바꾸어
이 래스터 오차를 모방하지 않는다.

PDF 단위로 정의한 같은 RGB의 단일 면과 빈틈없는 200개 띠를 직접 비교했다.
단일 면의 내부는 (64,128,191)인데 기본 Cairo의 띠 내부는 96 DPI에서
(120,165,210), 144 DPI에서 (111,159,207)이다. 구현과 무관한 PDF 면적·색
계약으로 원인을 재현한다. 실제 대조군의 Cairo antialias none 결과는
97.98758~100%이며, 이는 진단 결과이고 기존 판정을 소급 변경하지 않는다.

## 보정과 검증 범위

1. 공통 PDF 래스터 명령의 벡터 면 처리에서 인위적 이음매가 생기지 않게 한다.
   전체/선택 쪽에 같은 antialias 설정을 명시하고 실행 신원에 기록한다.
2. 원본 PDF·페이지·배율·raw 계산·2px 허용 거리·90% 기준은 유지한다.
   색상 보정값으로 raw 미달을 상쇄하지 않는다. 기존 래스터 캐시는 새 정책과
   섞지 않고 새 고정 base/head를 같은 정책으로 다시 비교한다.
3. 수학적으로 같은 PDF 면의 96/144 DPI 색 보존, 기존 균일 RGB·한컴 Print
   채우기·쪽 선택·raw gate 테스트를 실행한다. 문자·외곽의 antialias 변화도
   직접 판독하고 필수 전쪽 검증으로 영향 범위를 확인한다.
4. 실패한 원본의 새 Native/fresh WASM 전쪽 TSV와 직접 판독 전에 회귀 기대값을
   바꾸거나 PR 준비 완료로 판정하지 않는다.

실행 증거는 ignored stage2390~2392에 있다. 도구 결함 재현은 렌더링 fixture의
정상 출력 인증과 구분하며, 이전 Cairo 결과와 새 정책의 결과를 따로 기록한다.
