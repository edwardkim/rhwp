## 변경

GitHub [종료 공지](https://github.blog/changelog/2026-10-01-github-actions-macos-14-runner-image-retirement/)에 따라 Release Binary의 macOS 두 target을 `macos-14`에서 `macos-15`로 옮긴다. 첫 brownout은 한국시간 10월 5일 23:00~10월 6일 09:00, 종료는 11월 2일이다.

- `x86_64-apple-darwin`의 ARM64 runner 교차 빌드와 `aarch64-apple-darwin`의 native 빌드를 유지한다.
- Cargo cache에 runner label을 포함해 macOS 14의 `target/`를 새 SDK 환경으로 복원하지 않는다. key와 restore prefix를 함께 바꾸며 처음에는 각 target의 새 cache가 필요하다.
- 배포 가이드의 runner 표와 해당 설명을 갱신한다.
- target·artifact 이름, job/check 이름, trigger, release 조건, 권한, 제품 소스는 보존한다.

## 검증

1. 변경 workflow YAML 파싱 및 base 대비 matrix/step/event/permission 비교.
2. 기존 `test_release_publish_orchestration.py`, `test_release_channel_policy_workflow.py`, `test_nextest_archive_workflow.py`.
3. actionlint와 `git diff --check`, 수정 문서의 내부 링크 확인.
4. 원격 push 승인 뒤 exact head의 `Release Binary` `workflow_dispatch(tag=test)` 실행 승인을 받아 다섯 build, macOS 두 `--version`, archive architecture, Release/외부 publish skip을 확인한다.
5. PR 승인·생성 뒤 latest head CI와 정상 devel → main 승격을 확인한다. Linux 로컬 검증은 macOS build 검증의 대용이 아니다.
