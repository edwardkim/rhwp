## 목표

rhwp-studio의 현재 쪽 판정을 `첫 가시 페이지` 또는 `Y축 행`이라는 암묵적 규칙에서 분리하고,
캐럿·선택·뷰포트와 X/Y 가시 영역을 함께 고려하는 활성 페이지 계약으로 통합한다. PageUp/PageDown,
상태 표시줄, 가로·세로 눈금자, document-agent 갱신 검증이 동일한 2D 페이지 좌표를 사용하게 한다.

## 변경 범위

1. 가시 페이지와 편집 페이지를 입력으로 활성 페이지와 판정 출처를 정하는 순수 resolver를 추가한다.
2. 캐럿 rect 이벤트에 페이지 인덱스를 보존하고 CanvasView가 활성 페이지 snapshot을 소유하게 한다.
3. 가로 이동의 PageUp/PageDown을 X축 페이지 경계와 뷰포트 폭 기준으로 동작시킨다.
4. 페이지 단위 이동 결과를 X/Y delta로 표현해 캐럿을 같은 화면 위치에 보존한다.
5. 가로·세로 눈금자가 활성 페이지 한 쪽의 좌표·크기·구역 속성을 사용하게 한다.
6. document-agent 갱신 검증이 수평·수직 스크롤과 뷰포트 크기를 모두 전달하게 한다.
7. 사용되지 않는 페이지 이동 이벤트·접근자는 전체 소비처를 확인한 뒤 이번 범위에서만 정리한다.
