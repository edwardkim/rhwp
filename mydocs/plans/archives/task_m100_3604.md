# Task #3604 관련 HWP 2020 MCP client 배포·사용법 현행화 계획

Issue: #3604

## 목표

rhwp 작업자가 Hancom Office 2020 원격 변환 MCP를 사용할 때 최신 client tarball 하나와 정확한 사용법을
받도록 한다. 암호 HWP3/HWP5 HWP 및 ODF 암호 HWPX의 검증된 변환 범위도 함께 안내한다.

## 관련 이슈 경계

#3604는 rhwp 내장 MCP의 password API 부재를 다룬다. 이 작업은 외부 Hancom Office 2020 변환 client를
갱신하는 것으로, #3604의 구현 완료를 주장하거나 이슈를 닫지 않는다.

## 변경 범위

- `tools/`의 이전 HWP 2020 MCP client tarball 제거와 최신 tarball 추가
- `mydocs/manual/mcp_hwp2020Convert_usage.md`의 archive 경로, 암호 문서 지원, timeout, cleanup, 검증 안내 갱신
- 작업 계획·stage 기록과 PR 본문에 운영 변환 검증 결과를 비밀 없이 요약

## 검증 범위

- 최신 archive manifest의 client kind/source commit 확인
- `npx --package=file:<archive> -- hwp2020-mcp-convert --help` exit code 0
- Markdown archive 참조가 새 파일 하나만 가리키는지 확인
- `git diff --check`와 변경 범위 확인

## PR 경로

- base route: collaborator self-merge
- modifiers: local validation
- 시각·fixture 증적은 적용하지 않는다. rhwp renderer, layout, sample, 기준 PDF를 바꾸지 않으며, 기존 외부 MCP
  운영 검증은 client 사용법의 근거일 뿐 이번 PR의 시각 변경 주장이 아니다.
- remote branch는 `task_m100_3604`, base는 `devel`이다.
