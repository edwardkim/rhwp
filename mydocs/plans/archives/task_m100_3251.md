# 빈 문서 상태 스타일 기본값 설계

## 문제

`#style-name`은 초기 HTML에서 비어 있고 문서를 연 뒤에만 실제 스타일 목록으로
채워진다. 따라서 문서가 없을 때 비활성 스타일 콤보가 빈 값으로 보인다.

## 설계

- 초기 HTML에 기본 옵션 `바탕글`을 둔다.
- 문서 로드 후 기존 `initStyleDropdown()`이 `replaceChildren()`으로 기본 옵션을
  실제 문서 스타일 목록으로 교체한다.
- 도구 모음의 비활성 상태와 기존 시각 스타일은 변경하지 않는다.

## 검증

- 초기 HTML의 스타일 콤보가 `바탕글` 옵션을 포함하는 회귀 테스트
- 문서 로드 경로가 기존처럼 옵션을 교체하는지 소스 계약 확인
- 문서가 없는 실제 화면에서 비활성 콤보가 `바탕글`을 표시하는지 확인
