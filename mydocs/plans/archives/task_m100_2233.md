## 1. 목표

GitHub Actions의 `curl | sh` installer가 선택하는 wasm-pack 버전과 Docker의
`wasm-pack 0.15.0` pin을 하나의 명시적 정책으로 정합한다.

완료 조건은 다음과 같다.

1. 모든 GitHub Actions wasm-pack 설치 지점이 동일한 0.15.0 installer를 사용한다.
2. fresh dev WASM과 핵심 frontend consumer 계약이 통과한다.
3. release WASM과 `wasm-opt` 최적화가 통과한다.
4. Render Diff의 WASM consumer 경로가 최신 PR head CI에서 통과한다.
5. workflow trigger, required check 이름, PR cache restore-only, release artifact 정책을 바꾸지 않는다.
6. 버전 위치와 갱신 절차를 장기 기술 문서로 남긴다.
