| 항목 | 확인 결과 |

| 코퍼스 view3D 실측 (3차원원형) | `rAngAx=0, rotX=30, rotY=0, perspective=30` |

| rAngAx=0의 시각 특성 | 3차원원형: 원판 기울임 — **회전+원근 투영**. 관측 타원비 0.55 ≈ **sin(rotX=30°)=0.5 + 원근 보정** — v1의 상수 0.55가 카메라 유도값이었음을 확인 |
| 사선 격자의 정체 | 한컴 가로막대형의 "기울어진 값축 격자"는 **바닥 조그(앞 눈금→뒷벽) + 뒷벽 수직선** 폴리라인 — 방 깊이가 막대 깊이보다 깊어(gapDepth 150% 여유) 조그가 길게 보인 것. 투영 모델에서 방 깊이를 씬 전체 깊이로 잡으면 자동 재현 |
| 잔여 갭(누적가로 두께 등) | 시어·fit 배율의 캘리브레이션 문제로 귀속 — Stage 1R 시각판정에서 확정 |

## 3. 목표 (갱신)

`c:view3D` 파라미터를 파싱해 **임의 카메라에 동작하는 3D 투영 렌더**로 3D 막대
4종 + 3차원원형을 그린다. 코퍼스 정답지와의 정합은 캘리브레이션 1회로 달성하고,
비코퍼스 카메라 값에도 연속적·단조적으로 합리적인 렌더를 보장한다.
2D 출력 바이트 불변 + #1882/#1453 앵커 무회귀 유지.

## 4. 범위 재정의 (단계 재구성)

### Stage 1R — view3D 파싱 + 투영 모듈 + 3D 막대·방 재작성

1. **파서/모델**: `View3D { rot_x, rot_y, perspective, r_ang_ax, h_percent, depth_percent }`
   + `OoxmlChart.view3d: Option<View3D>` + `gapDepth` arm (bar3D 게이트).
   기본값 = ECMA 관례 (rotX 15, rotY 20, perspective 30, rAngAx=1).
2. **투영 모듈**: `project(x, y, z) -> (sx, sy)` 2모드 —
   - rAngAx=1: 시어 `(x + z·kx, y − z·ky)`, `kx = sin(rotY), ky = sin(rotX)`
   - rAngAx=0: rotY→rotX 회전 후 원근 나눗셈(카메라 거리 = perspective 유도,
     perspective=0 → 평행 투영)
   - 공통: 씬 박스 `[0,W]×[0,H]×[0,D]` 투영 bbox를 플롯 rect에 fit(스케일+평행이동).
     D = 막대 깊이 × (1 + gapDepth/100), 막대 깊이 = depthPercent 비례.
3. **3D 막대 재작성**: 막대 = 3D 박스, 투영 후 가시면 방출(front/top/side —
   기존 클래스 유지). rAngAx=1은 front가 직립 rect(기존 테스트 호환),
   rAngAx=0은 폴리곤. painter order: 시어는 기존 순서 유지, 회전은 центроид
   깊이 내림차순 정렬.
4. **방 재작성**: 뒷벽(z=D)·바닥(y=0) 면 + 값축 격자 = 바닥 조그+뒷벽 선
   폴리라인(투영 좌표) — 한컴 사선 격자 자동 재현. `hwp-bar3d-room` 그룹 유지.
5. **축 라벨**: 문자열·포맷 불변(#1882), 위치는 앞면 모서리의 투영 좌표.
6. v1~v3 오블리크 코드(`push_bar_3d` 기하·`render_value_grid_3d` 기하) 대체.
   기하 상수(0.30/2.5~9/0.4 등) 폐기 — 투영+캘리브레이션으로 일원화.

### Stage 2 — 3D 원형 (투영 기반)

타원비 = rAngAx=0 투영에서 유도(sin(rotX)+원근), 측벽 밴드는 v1 계획 유지
(하반부 클립·벽 선행 방출). 상수 0.55 → 유도값.

### Stage 3 — ofPie 보조플롯 + 팔레트 #5 (v1 계획 그대로)

ofPie는 2D — 투영 무관. `task_m100_2278_impl.md` 3단계 설계 유지.
