## 1. 배경

C2a(#2277)로 코퍼스 28종 placeholder 0건 + 2D fidelity(범례 순서·스와치 글리프·
scatter 마커·특이케이스 축)가 완결됐다. 잔여는 **형상 자체의 근사**:

- **3D 차트 5종**(3차원 묶은/누적 세로·가로막대, 3차원원형)은 C1a(#1453)의 2D 평면
  근사 그대로 — `is_3d` 플래그는 축 정책(C1c #1882)에만 쓰이고 입체 표현이 없다.
- **ofPie 2종**(원형대원형·원형대가로막대형)은 단일 원형 근사 — 보조 플롯(2차 원 /
  누적 막대)과 결합 슬라이스, 연결선이 없다.
- **팔레트 5번**(`DEFAULT_PALETTE[4]`)은 유추값(하늘 0xFF5B9BD5) — 정답지의 ofPie
  결합 슬라이스는 초록 계열로 실측 교정 대상.

선행 조건인 C2a의 범례 스와치 인프라(`SwatchKind`/`push_legend_swatch`/
`legend_items`)는 devel에 merge 완료 — 본 작업 범례는 기존 인프라를 무변경 재사용한다.

## 3. 목표

3D 차트 5종이 정답지 수준의 입체감(사선 압출 3면 음영 / 타원+측벽)으로, ofPie 2종이
주 원형+결합 슬라이스+보조 플롯+연결선 구조로 렌더되고, 팔레트 5번이 실측값으로
교정된 상태. 2D 차트 출력 바이트 불변 + #1882/#1453 앵커 무회귀.

## 4. 범위

### 포함 (3단계 예정)

1. **3D 막대 압출** — 정답지 4종 정밀 판독 → `shade(rgb, factor)`(채널별 선형 보간)
   + `push_bar_3d(svg, x, y, w, h, depth, color)` 헬퍼. 정면 원색 / 우측면 어둡게 /
   윗면 밝게, 우상 45° 압출, 깊이 `(두께*0.45).clamp(3.0, 9.0)` 고정 근사.
   우상 압출에서 보이는 면은 세로/가로 공통(top+right 평행사변형) → 단일 헬퍼로
   묶음/누적 × 세로/가로 4조합 커버. 누적은 기존 페인트 순서(아래→위/왼→오른쪽)가
   자연 은면 제거 — 캡 노출 분기 불필요, 0값 세그먼트는 조기 반환으로 캡 재도색 방지.
   rect 방출 4개소만 `is_3d` 분기, **축 계산 무접촉**(#1882). 신규 클래스
   `hwp-bar3d-top`/`hwp-bar3d-side`(front rect는 무클래스).
2. **3D 원형** — 정답지 정밀 판독 → `render_pie_3d`: 타원 슬라이스(ry≈rx×0.55) +
   하반부(θ∈(0,π), y-down) 측벽 밴드. 벽 전부 먼저, top 나중(이슈 확정 순서).
   각도 도메인 [−π/2, 3π/2] 연속이라 경계 스팬은 max/min 클립만으로 정확.
   클래스 `hwp-pie3d-wall`/`hwp-pie3d-top`. `render_pie`(2D)는 무변경.
3. **ofPie 보조플롯 + 팔레트 교정** — (a) 정답지 결합 슬라이스 픽셀 실측 →
   `DEFAULT_PALETTE[4]` 교정(강등 하늘색은 [5]로 스왑) + 핀 테스트. (b) 모델
   `OoxmlChart.of_pie: Option<OfPieInfo>`(of_pie_type/split_pos/second_pie_size/
   has_ser_lines) + 파서 arm 4개(`ofPieType`/`splitPos`/`secondPieSize`/`serLines`
   이중 게이트), **`chart_type=Pie` 유지**(#1453). (c) `render_of_pie`: 주 원형
   (앞 n−k 카테고리 + 결합 슬라이스=palette(n), 결합 슬라이스를 보조 플롯 방향
   θ=0에 정렬) + 보조(원형대원형=75% 원 / 원형대가로막대형=세로 누적 막대,
   첫 분할 카테고리 맨 위) + 연결선 2줄 `hwp-ofpie-serline`. k=splitPos 반올림
   클램프, 부재 시 2; n<3은 일반 원형 폴백. 범례 무변경(현행 Pie 분기가 요구 충족).

### 제외 (Non-goals)

- `c:view3D`/`rotX`/`rotY`/`perspective`/`gapDepth` 파싱 — 고정 근사(#1251 픽셀
  parity 비목표).
- `line3DChart` 입체 — C2a의 2D 방어 라우팅 유지.
- `splitType` 커스텀 분할(val/percent/custom) 완전 지원 — 코퍼스 부재, `splitPos`
  존중 수준.
- 콤보 차트의 3D — 코퍼스 무해당(`render_combo` 무접촉).
- 저장 경로 — 본 작업은 읽기/렌더만, OLE blob 보존 계약 무접점.

   `chart_type==Pie` 유지 재확인 + serLines barChart 비누출. 기존 `test_parse_ofpie`/
   `test_parse_bar3d_*`/`test_parse_pie3d` 무회귀.
2. **렌더러 단위**: `shade` 채널 수치·클램프·알파 보존 / 3D 막대 면 카운트(Column·Bar
   × 묶음·누적)·방출 순서·0값 스킵·깊이 클램프(3.0/9.0) / 3D 원형 타원비·하반부 벽
   카운트·경계 클립 좌표·벽 선행 방출·2D 무벽 가드 / ofPie 주·보조 슬라이스 카운트·
   결합 슬라이스 palette(4)·bar형 상하 순서·splitPos 반영·범례 정순(결합 제외)·
   n=2 폴백 / 팔레트 [4] 실측 핀.
3. **회귀 통합** (`render_page0_svg` + stem×{hwpx,hwp} 패턴, `tests/issue_2278_chart_3d_ofpie.rs`):
   3D 막대 4종 `hwp-bar3d-top`==`hwp-bar3d-side`>0 + #1882 축 라벨 문구 재확인 /
   3차원원형 wall≥1·top==4 / ofPie 2종 serline 2개·placeholder 부재·결합 슬라이스 hex.
   기존 접점 무회귀: issue_1453(7종 라우팅) / issue_1882(3D 축·범례·팔레트) /
   issue_2277 3종(stock·범례 순서·미니 축) / issue_2129 / issue_1431_scatter.
4. `cargo test` 전체 통과(≈3,191 유지) + `cargo clippy --all-targets -- -D warnings`
   무경고. 포맷은 수정 파일만.
5. `export-svg` → `output/poc/chart_c2b/` 산출(stage1: 3D막대 4종, stage2: 3차원원형,
   stage3: ofPie 2종, 각 ×{hwp,hwpx}) → `pdf/chart/` 정답지 대조 →
   **작업지시자 시각판정 통과**. 음영 계수·wall 높이·ofPie 배치 상수·serline 색은
   PDF 근사 초기값으로 시작, 시각판정에서 미세조정.
