# 수행 계획서 — Task M100-5967: 한컴 판정 자산의 재생성 계약을 바이트에서 스트림으로

- 이슈: https://github.com/edwardkim/rhwp/issues/5967
- 제목: CFB 라이터: 중첩 CFB 재포장의 디렉터리 red/black 플래그·FAT 꼬리 채움값이 #5647 판정
  자산과 달라짐 — 재생성 바이트 동일성 상실
- 작성일: 2026-08-24
- 브랜치: `task5967` (`upstream/devel` `ad2867708` 기준)

## 1. 문제 요약

`samples/issue5447/` 38건은 한컴 2022 가 실제로 열어 판정한 바이트이고, `pdf/issue5447/` 의
변환 PDF 와 `MANIFEST.json` 의 래스터 해시가 그 바이트에 묶여 있다. 현재 devel 바이너리로
#5447 스파이크 번들을 재생성하면 변종 29건이 전건 어긋난다. 차이는 `BinData/*.OLE` 중첩 CFB
**안**의 컨테이너 살림에만 있고 차트 스트림은 동일하다.

## 2. 원인 — 이슈가 열어 둔 "원인 창" 을 닫는다

**`b9eb55107` (2026-08-22, devel) — "검토: CI 완료 외부 PR 7건 통합 수용 (#5912)"**. 이 통합
커밋이 외부 PR 두 건을 cherry-pick 하며 `src/serializer/mini_cfb.rs` 를 66줄 늘렸다.

| cherry-pick | 코드 | 관측 바이트 |
|---|---|---|
| `6a0c04159` "emit valid CFB directory trees" | `DirEntry.color` 신설, `color_deepest_nodes()` 로 최심 노드만 red, `write_dir_entry` 가 `buf[67] = entry.color` | 디렉터리 엔트리 `+0x43` `01` → `00` |
| `97dbf4cef` "initialize unused CFB slots with sentinels" | FAT·MiniFAT 섹터를 FREESECT 로 선채운 뒤 실값을 덮어씀, 미할당 디렉터리 슬롯 sibling/child = NOSTREAM | FAT 꼬리 `00` → `ff` |

#5647 병합(`e555f759a`, 2026-08-20)의 이틀 뒤로, 이슈가 지목한 원인 창과 정확히 맞는다.

## 3. 되돌리지 않는다

두 변경은 MS-CFB 방향으로 옳다.

- 종전 "전 엔트리 black" 은 leaf 깊이가 갈리는 트리에서 black-height 가 어긋난다.
- FAT 미사용 슬롯의 `0x00` 은 strict 파서에서 "다음 섹터가 0번" 으로 읽힌다. 섹터 0 은 언제나
  사슬 머리이므로 후속이 될 수 없다.

같은 커밋이 [`tests/cases/mini_cfb_strict_contract.rs`](../../../tests/cases/mini_cfb_strict_contract.rs)
를 함께 넣어 red-black 불변식(스트림 1~128 전수)과 sentinel 을 이미 상시로 고정한다. 되돌리면
그 둘이 즉시 빨개지고 외부 기여 PR 2건이 무효화된다. 유효성 문제도 관측되지 않았다 — 현재 라이터
포장 상태의 산출 32건을 한글 2022 가 전건 정상 개봉·렌더했다(#5652 판정, 개봉 실패 0).

**따라서 `samples/issue5447/` 와의 바이트 동일성은 회복 불가다.**

## 4. 방향 — 자산은 동결, 계약은 스트림으로 옮긴다

자산을 다시 만들지 않는다. 재생성하면 `pdf/issue5447/` 의 한컴 PDF 와 짝이 끊어지고, 판정
자체를 다시 받아야 한다. 대신 잃어버린 "재생성 바이트 동일성" 을 두 계약으로 대체한다.

1. **재생성 스트림 동일성** — 컨테이너 살림이 바뀌어도 판정 대상 내용은 재현된다.
2. **드리프트 봉쇄** — 바이트 차이가 색 플래그와 할당표 미사용 슬롯 밖으로 새지 않는다.

`src/` 는 건드리지 않는다.

## 5. 변경 항목

### 5-1. `tests/cases/issue_5967_cfb_repack_reproducibility.rs` (신규)

커밋된 자산만으로 자기완결한다 — 생성기(`b2_variants`)에 기대지 않고 `output/` 도 쓰지 않아
CI 에서 상시로 돈다. 자산 목록·역할은 `samples/issue5447/MANIFEST.json` 에서 읽는다(파일명
하드코딩 금지 — #5447 §6-1 NFC/NFD 사고 선례).

- `judged_streams_survive_a_current_writer_repack` — 38건 전건. 중첩 CFB 를 `all_ole_streams`
  로 열거해 `build_cfb_with_root_clsid` 로 지금 라이터가 재조립 → 스트림 이름·순서·바이트와
  루트 CLSID 가 전부 보존되는가. 대조군 9건(한컴 저작 CFB)도 함께 본다.
- `writer_drift_is_confined_to_directory_color_and_fat_fill` — rhwp 라이터가 쓴 29건. 커밋본과
  재조립본의 길이가 같고, 모든 차이 바이트가 두 버킷 중 하나로 분류되며, 그 밖이 하나도 없고,
  차이가 0 도 아니다(공허한 통과 금지).

### 5-2. `samples/issue5447/MANIFEST.json`

`generator` 블록에 재현 경계를 적는다: `byte_reproducible: false`,
`byte_reproducibility_lost_at`(원인 커밋), `stream_reproducible: true`, `reproducibility_note`.
`counts`·`entries` 는 손대지 않으므로 `b2_judgment_assets_match_the_manifest` 와
`tools/hancom_chart_judgment_verify.py` 는 그대로 통과한다.

### 5-3. `samples/issue5447/README.md`

"재생성 절차" 의 `sha256sum` 직접 대조 지시를 걷어내고, 왜 어긋나는지·되돌리지 않는 이유·
올바른 대조 축(스트림 동일성, 새 테스트)을 적는다.

### 5-4. `tests/issue_4100_chart_data_edit.rs`

`generate_b2_structure_judgment_bundle` 의 doc comment 한 문단만 같은 취지로 고친다.
**코드 변경 없음.**
