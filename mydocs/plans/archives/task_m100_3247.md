# 세로 스크롤 축 고정과 줌 감도 조정 설계

## 문제

줌 앵커를 안정화하기 위해 편집 캔버스 양쪽에 수평 팬 공간을 추가한 뒤,
트랙패드로 아래로 스크롤할 때 함께 들어오는 작은 `deltaX`도 브라우저의
네이티브 수평 스크롤로 반영된다. 그 결과 문서가 좌우로 흔들려 보인다.

또한 현재 `0.00525`인 휠 줌 감도는 축소 방향에서 여전히 둔하게 느껴진다.

## 설계

- `Ctrl`/`Cmd` 없는 휠 입력이 세로 우세(`|deltaY| >= |deltaX|`)이면 이벤트의
  기본 동작을 막고, 정규화한 `deltaY`만 `scrollTop`에 적용한다.
- 가로 우세 입력은 기존 네이티브 동작을 유지하여 넓은 문서의 의도적인
  수평 팬을 보존한다.
- `Ctrl`/`Cmd` 휠 줌은 기존 포인터 앵커 경로를 그대로 사용한다.
- 줌 감도는 양방향 공통 지수 계수를 `0.00625`로 높인다. 방향별 계수를
  분리하지 않아 같은 크기의 반대 입력이 정확한 역연산이 되게 한다.

## 검증

- 세로 우세 픽셀/라인/페이지 휠 입력이 `scrollTop`만 변경하는 테스트
- 가로 우세 입력을 가로채지 않는 테스트
- `Ctrl`/`Cmd` 휠이 스크롤 축 고정 대신 줌 경로를 사용하는 회귀 테스트
- 8픽셀 줌 입력이 새 감도에 해당하는 이동량을 만들고 반대 입력으로
  원래 줌을 복원하는 테스트
- 전체 테스트, 빌드, 실제 문서의 세로 스크롤 및 줌 왕복 검증
