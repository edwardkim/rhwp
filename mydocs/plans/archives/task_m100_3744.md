## 1. 목표

`export-structure --mode clause`에서 정상 조문 `호`/`목`을 보존하면서 다음 false negative/positive를
결정적인 confidence 정책으로 함께 보정한다.

1. 오래된 `조`/`항` 앵커 뒤의 SQL·일반 번호 목록을 `호`로 승격하지 않는다.
2. 열린 조문 문맥 안의 `YYYY. M. D.` 개정연혁 날짜를 `호`로 승격하지 않는다.
3. `장`/`절` 아래의 본문 `가.`/`나.` 제목은 `목`으로 회복하되 목차형 행은 제외한다.

공개 JSON 필드·봉투·exit code와 explicit `outline`, `auto` 선택 정책은 유지한다.

## 3. 원인 경계

현재 `clause_heading_allowed()`는 `Heading`과 열린 `StructureNode` stack만 받는다.

- `호`: stack 어디든 `조|항`이 있으면 허용한다.
- `목`: stack 어디든 `호`가 있을 때만 허용한다.
- section/paragraph 거리, section 경계, 번호 연속성, 원문 날짜 형태, ParaShape, 쪽번호 tail을 보지 않는다.
- `build_structure()`의 stack은 section 루프가 바뀌어도 초기화되지 않는다.
- `has_toc_page_number_tail()`은 #3695 auto selector에만 쓰이며 explicit clause gate에는 적용되지 않는다.

따라서 단일 조건 추가가 아니라 weak marker 채택에 필요한 위치·텍스트·문단 모양 증거를 함께 전달하는
내부 context 설계가 필요하다.

## 4. Stage 2 정책 선택

### 4.1 앵커 만료 — 복합 번호 경계 채택 권고

다음의 좁은 결정 규칙을 권고한다.

1. 열린 `조|항` 아래 `호` 후보의 marker가 `.`으로 끝나고 marker 직후가 다시 숫자이면
   (`4.1`, `20.1`) 조문 `호`가 아니라 일반 문서의 복합 번호 경계로 거부한다.
2. 이 경계를 만난 현재 nearest `조|항`의 weak-`호` 허용 상태를 만료한다.
3. 경계 바로 다음 문단이 같은 section에서 경계의 앞 번호 또는 직전 정상 번호의 다음 번호로
   이어지면 정상 목록 재개로 인정한다. 그 밖의 후속 `호` 후보는 body로 보존한다.
4. 새 `조|항`이 열리면 새 상태로 시작하며, `1)1920년…`처럼 `)` 뒤 본문이 숫자로 시작하는 정상
   항목은 복합 번호로 보지 않는다.

recursive 665개에서 현행 `호` 6,219개 중 4,351개가 줄고 변경 문서는 6개다. 여섯 파일은
`hwp3-sample10` 3개 형식 변형과 `hwp3-sample11` 3개 형식 변형뿐이며 둘 다 Oracle/Unix 기술문서다.
`hwp3-sample10.hwp`는 1,228→4, 협정서는 14→14, 편람은 240→240이다.

다음 대안은 기각한다.

- section reset: 388개/12문서 감소, 편람 240→57
- 거리 32: 5,321개/41문서 감소, 편람 240→13
- 엄격 연속 번호: 5,456개/55문서 감소, 편람 240→17
- 첫 불연속에서 terminal 만료: 5,461개/41문서 감소, 편람 240→6
- 번호 `1` 재시작 허용: 편람 240→238이나 Oracle 1,228→1,146이며 SQL target을 남김

고정 거리와 blanket section/연속성은 정상 반복 목록 손실이 너무 크다. 인접 복귀 조건 없이 번호만
맞추는 설계는 Oracle sample10에서 오래된 anchor를 다시 열어 대량 오탐을 되살리므로 기각했다.
인접 조건을 둔 복합 번호 경계는 목표 SQL 앞의 `4.1`에서 만료되며, `3.5퍼센트` 뒤 `3.`/`4.`처럼
즉시 이어지는 정상 목록은 회복한다. Oracle의 경계 전 `1.`~`4.` 네 개는 잔여 false positive다.

### 4.2 날짜 negative — 달력형 lexical reject 채택 권고

- 선두 `YYYY. M. D.` 또는 마지막 점이 생략된 `YYYY. M. D`를 파싱해 월 1~12, 일 1~31인 경우
  `호` 후보를 거부한다.
- `일부개정` 같은 suffix 목록에는 의존하지 않는다.
- 날짜 거부는 현재 anchor를 만료하지 않으며 문단은 body에 보존한다.
- recursive sample의 현행 date `호`는 0개라 synthetic red가 판별 oracle이다.

### 4.3 `목` positive — 보수 ParaShape gate 채택 권고

기존 열린 `호` 아래 `목`은 그대로 허용한다. 열린 `호`가 없고 `장|절` 조상이 있는 경우에는 다음을
모두 만족할 때만 direct `목`으로 허용한다.

1. 탭+숫자 또는 dotted-leader+숫자 쪽번호 tail이 없다.
2. `ParaShape.margin_left == 0`
3. `ParaShape.indent >= -1280`
4. `ParaShape.para_level == 0`

recursive corpus의 broad 후보 304개/4문서를 111개/3문서로 좁힌다. 편람 HWP/HWPX에서 각각
발견 근거의 44개와 정확히 일치하고, 시장구조조사 실문서 23개(`가. 표준산업분류` 등)를 함께
회복한다. `issue2006` 연구보고서의 실제 제목처럼 보이는 25개와 편람의 더 깊은 하위 항목은 이번
direct-heading 범위에서 보수적으로 남기는 잔여 false negative다.

실물 broad 후보에는 TOC tail이 없었으므로 synthetic `가. 개요\t9` negative를 영구 guard로 둔다.
파일명·style ID·문단 좌표는 제품 판정에 사용하지 않는다.
