## 1. 목표

rhwp-studio에서 중첩 표 안쪽 셀의 텍스트를 드래그할 때 논리 선택뿐 아니라 Canvas 선택
하이라이트도 같은 전체 `cellPath`를 기준으로 표시되게 하고, 그 선택 텍스트를 복사해 다시
붙여넣을 수 있게 한다. 깊이 1 셀과 본문 선택·클립보드 계약은 유지한다.

## 2. 확인된 원인

- hit-test와 cursor selection은 안쪽 셀의 깊이 3 `cellPath`를 보존한다.
- `InputHandler.updateSelection()`은 선택 사각형 조회에 평면
  `(parentParaIndex, controlIndex, cellIndex)`만 전달한다.
- 평면 좌표는 바깥 셀을 가리키며, Rust의 `flat_cell_ctx_matches()`는 안전을 위해 깊이 1만
  매칭하므로 안쪽 TextRun을 찾지 못하고 빈 사각형 배열을 반환한다.
- 따라서 오류 로그 없이 `hasSelection() === true`, `.selection-highlight === 0` 상태가 된다.
- Stage 1 시각 판정 중 같은 `23,504`를 Ctrl+C 하면 기존 평면
  `copySelectionInCell(0, 7, 1, 0, 0, 0, 0, 6)`이 바깥 셀 문단을 읽어
  `{"ok":true,"text":""}`를 반환하는 후속 RED를 확인했다. 내부 클립보드가 빈 문자열이므로
  Ctrl+V 사용자 여정도 완료되지 않는다.

## 3. 변경 경계

- 전체 `cellPath`와 시작·끝 셀 문단/오프셋을 받는 Rust native/WASM 선택 사각형 API를 추가한다.
- 기존 평면 API와 깊이 1 동작은 호환성을 위해 유지한다.
- Studio는 시작·끝이 같은 중첩 셀 컨테이너인지 전체 경로로 판정하고 경로 기반 API로 라우팅한다.
- 중첩 셀 선택의 plain text 복사와 HTML export도 같은 전체 경로로 라우팅한다. 붙여넣기는 기존
  `pasteInternalInCellByPath`와 선택 삭제의 path 경로를 재사용한다.
- 표 조판 geometry, 페이지네이션, 편집 명령 및 선택 스타일은 변경하지 않는다.

## 4. 브라우저 성능 불변 계약

- 선택 이벤트마다 새 문서 전체 순회나 페이지 재조판을 추가하지 않는다.
- 기존 page hint와 page tree cache 경로를 그대로 재사용한다.
- 경로 비교는 이미 렌더 트리에 있는 `CellContext.path`와 선형 비교하며, 선택한 셀의 깊이에만
  비례한다.
- 문단별 IR resolve에 필요한 경로 복제는 해당 문단을 얻을 때 한 번만 수행하고 RenderNode별로
  할당하지 않는다.
- E2E에서 선택 API 호출 횟수, 하이라이트 수, 경고와 대표 선택 시간을 기록한다.

## 5. 래칫과 검증

1. 실제 fixture 물리 5쪽의 `23,504`를 깊이 3 경로로 선택해 사각형이 1개 이상인지 고정한다.
2. 전체 경로 일치가 마지막 셀 문단만 현재 조회 문단으로 치환해 TextRun을 정확히 찾는지 Rust
   단위 테스트로 검증한다.
3. 다른 중첩 셀 경로와 깊이 1 경로가 오매칭되지 않는지 고정한다.
4. TypeScript dispatch가 중첩 경로에는 path API와 page hint를 사용하고 평면 API로 퇴행하지
   않는지 검증한다.
5. 실제 브라우저 마우스 드래그 뒤 논리 선택과 `.selection-highlight`가 함께 존재하는 E2E를
   추가한다.
6. focused Rust·Studio 테스트, TypeScript 검사, fresh web WASM과 시각 증적을 수행한다.
7. 실제 Ctrl+C에서 내부 plain text와 `text/plain`이 `23,504`인지, 이어지는 Ctrl+V가 선택 범위를
   같은 텍스트로 복원하는지 CDP E2E로 고정한다.
8. 물리 11쪽처럼 최내곽 `cellParaIndex`가 평면 호환 필드와 다른 자식 표 셀도 실제 endpoint의
   마지막 path 문단 축으로 복사되는지 고정한다.
9. 깊이 3 자식 표를 객체 선택해 Ctrl+C 할 때는 전체 cell path의 마지막 엔트리가 가리키는 표
   control을, 그 엔트리를 제외한 소유 문단 path에서 복사하는지 고정한다.
