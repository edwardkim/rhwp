### 실패 사슬 (코드 확정)

`paragraph_layout.rs` `compose_heading` 계열: Outline 문단 → `resolve_numbering_id`
(`layout/utils.rs:84`)가 구역 `outline_numbering_id` 로 fallback → 이 문서는 **0** →
`if numbering_id == 0 { return None; }` → 번호 미생성. 정의가 있어도
`styles.numberings` 가 비어 있어 다음 줄 `.get()` 에서도 탈락한다.

**한컴은 개요 모양 정의가 없으면 내장 기본 개요 번호 모양을 적용한다** — 정답지가
증명한다(1.~4. 렌더). rhwp 에는 이 기본값이 없어 번호가 소실된다.

## 2. 수정 방향

Outline 문단이 유효한 numbering 정의에 도달하지 못할 때 **한컴 내장 기본 개요 모양을
합성해 fallback** 한다. 렌더러 층(resolve 지점) 수정이므로 HWPX·HWP5 양 포맷을 함께
커버한다.

제약 (메모리 준수): 기본 개요 모양의 **각 수준 형식은 추정 금지** — 한컴 스펙 문서·
hwp2hwpx 매핑·정답지 실측의 교차 확인으로 확정한다(#1156 규약). 이 fixture 가
행사하는 것은 level 0("1.")뿐이므로, 심층 수준은 권위 자료가 1차 근거다.
