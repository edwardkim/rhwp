# Task #3668 수행계획서 — LAYOUT_OVERFLOW_CELL 집계 표면과 게이트 편입

- Issue: [#3668](https://github.com/edwardkim/rhwp/issues/3668) (M100) — #3236 의 sub-issue,
  독립 진행 축
- 브랜치: `local/task3668` / 착수: 2026-08-01

## 1. 배경 (이슈 요지)

`LAYOUT_OVERFLOW_CELL` 진단(셀 안 줄의 윗변이 쪽 하단 밖 = 그 줄 확정 소실)은 판정
기준이 검증되어 있는데(MATCH 80건 오탐 0), **stderr 한 줄로만 나가 아무도 보지 않는다.**
#3236 에서 리포터도 내부도 7일간 이 신호를 놓쳤다. 수집·집계 표면을 만들고 회귀
게이트에 편입한다.

## 2. 현황 실측

- 진단 위치: `src/renderer/layout/paragraph_layout.rs:3275-3289` —
  `cell_ctx.is_some() && text_y > current_page_height + 0.5` 에서 `eprintln!`.
  layout 엔진(`&self`)은 이미 `Cell<f64>` 상태 패턴을 쓴다(`current_page_height`).
- CLI `export-svg --json` 봉투: `schemaVersion 1.0` + `pages[]`(page/path/bytes).
  `src/main.rs` 에 봉투 키 집합을 고정하는 테스트가 있어 필드 추가 시 함께 갱신한다.
- 래칫 전례: `tests/fixtures/ir_field_sweep_baseline.tsv` + env dump + diff 절차
  (local_validation.md 4.3.1) — 같은 패턴을 재사용한다.

## 3. 설계

### 3.1 집계 코어

layout 엔진에 `overflow_cell_lines: Cell<u32>` 카운터 추가. `eprintln!` 지점에서
증가(stderr 출력은 **유지** — 기존 소비 행태 불변). 페이지 렌더 경계에서 읽고 리셋하는
getter (`take_overflow_cell_lines()`) 노출. 페이지 단위 귀속은 렌더 호출이 페이지
단위이므로 자연 획득.

### 3.2 CLI 표면

`export-svg --json` 봉투 확장 —

```json
"pages": [{ "page": 0, "path": …, "bytes": …, "overflowCellLines": 0 }, …],
"overflowCellLines": 23        // 문서 합계 (top-level)
```

필드 추가는 하위 호환(스키마 1.0 유지, 키 추가만). 봉투 키 고정 테스트 갱신.
export-pdf 등 다른 방출 명령은 이번 범위에서 제외(이슈의 수용 기준은 "기계가 읽을 수
있는 문서별·페이지별 카운트" — export-svg 하나로 충족, 확장은 후속).

### 3.3 회귀 게이트 + 원장 동결

`tests/overflow_cell_baseline.rs` 신설 — samples 전수(hwp/hwpx, 암호 제외)를 렌더해
문서별 합계를 수집:

- **원장**: `tests/fixtures/overflow_cell_baseline.tsv` — 현재 0 이 아닌 문서만
  `상대경로\t합계` 사전순 기록 (ir_field_sweep 과 동일 규약: 0 인 문서는 행을 만들지
  않는다).
- **판정**: baseline 에 없는 문서가 0 이 아니게 되거나, 기록된 문서의 수치가 **증가**하면
  실패. 감소는 통과(개선) — diff 로 드러나면 래칫을 조인다.
- env dump(`RHWP_OVERFLOW_CELL_DUMP`)로 현재값 TSV 를 떨어뜨려 4.3.1 과 같은 수동
  대조 절차를 지원.

10k 서베이 하니스 편입은 이 이슈 범위 밖(서베이 템플릿은 r24 계보 — 원저자 축이므로
제안 코멘트만 남긴다).

## 6. 위험과 제약

- 진단 지점이 뜨거운 경로(줄 단위)라 카운터는 `Cell` 증가만 — 할당·포맷 비용 없음.
  stderr 출력은 기존과 동일 조건에서만 발생.
- samples 전수 렌더 게이트는 실행 시간이 길 수 있다 — ir_field_sweep(36s) 수준이면
  스위트 수용 가능, 초과하면 `--ignored` 승격 여부를 Stage 2 에서 작업지시자와 결정.
- wasm_api 노출(스튜디오 표면)은 이번 범위 밖 — 후속 이슈 후보로 기록만.
