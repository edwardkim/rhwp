## 목표

한글 2024의 `기본 도구 상자 접기/펴기`와 같은 빠른 전환 경로를 Studio에 제공하고, 편집 면적을
우선하는 신규 사용자는 큰 아이콘 도구 상자가 접힌 상태로 시작하게 한다.

## 작업 범위

1. #5738의 `view:toolbox-basic` 커맨드와 설정 저장·복원 경로를 단일 진입점으로 재사용한다.
2. 메뉴바 우측에 기본 도구 상자 접기/펴기 버튼을 추가한다.
3. `Ctrl+F1`과 macOS `Command+F1`을 같은 커맨드에 연결한다.
4. 신규·미설정 상태의 기본 도구 상자는 접힘으로 바꾸되, 명시적으로 저장된 값은 보존한다.
5. 메뉴와 버튼의 표시·접근성 상태, 첫 페인트 숨김을 함께 검증한다.

## 비범위

- 서식 도구 상자의 기본 표시 정책 변경
- 서식 도구 상자를 한 줄 소형 모드로 재배치하는 작업
- 기본 도구 상자 내부 아이콘 구성과 줄바꿈 정책 변경
- 렌더러, DocumentCore, HWP/HWPX 파서 변경
- 새 래스터·SVG 이미지 자산 추가

## 완료 조건

- 저장값이 없으면 기본 도구 상자는 접힘, 서식 도구 상자는 보임이다.
- 저장된 `toolbarBasic: true/false`는 값 그대로 복원된다.
- 우측 버튼, 보기 메뉴, `Ctrl+F1`이 같은 `view:toolbox-basic`을 실행한다.
- 버튼의 `aria-expanded`, 접근 가능한 이름과 툴팁이 표시 상태와 일치한다.
- 리로드 첫 페인트에서 저장된 숨김 상태가 깜빡이지 않는다.
- Studio 전체 테스트·프로덕션 빌드·헤드리스 브라우저 E2E가 실패 없이 통과한다.
- 계획 대비 실제, 절차 이탈과 잔여 위험이 최종 보고서에 기록된다.
