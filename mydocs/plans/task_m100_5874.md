## Stage 2: PDF 출력 경계 보정

SVG 기반 PDF에서 usvg가 실제로 선택한 glyph face를 기준으로 합성 필요성을 판단한다.
동일 baseline의 수평 italic text에 정규 face만 선택됐을 때 baseline 고정 shear를 적용한다.
진짜 italic/oblique face는 이중 합성하지 않고, 일반 text의 위치·advance를 유지한다.
혼합 스타일·복잡한 배치처럼 text 전체 변환이 안전하지 않은 경우에는 무음 소실 대신 경고한다.
Text IR v2의 synthetic-style authority나 layout 메트릭은 변경하지 않는다.

## 검증

- 실제 재현 문서의 수정 전후 PDF와 작성자 기준 화면을 보관한다. SVG는 로컬 임시 산출물로만 둔다.
- 정규/합성 italic/실제 italic face, fallback, 변환·baseline 및 text extraction을 검증한다.
- Rust focused regression, fmt/Clippy와 변경 범위의 PDF 계약을 확인한다.
- PDF rendering 동작과 한컴 화면의 완전한 픽셀 정합 주장을 구분한다.
- 구현·검증 결과와 오늘할일을 기록한다. 원격 PR 생성·issue close는 별도 지시로 진행한다.
- 후속 사용자 지시: raw log와 임시 PNG/SVG/JSON은 커밋하지 않는다. 실제 코멘트에 표시할
  전후 비교/작성자 기준 PNG와 원본 입력/전후 PDF만 남기고, 검증 통과 사실은 문서/PR에 기재한다.
