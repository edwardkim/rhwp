## 3. 가설

가설 후보:
1. **(A)** 컴포저 단계: pi=61 ls[0] 의 lh=2864 (인라인 표 때문) 가 후속 라인 baseline 계산에 누적되어 압축. 또는 pi=60 마지막 라인의 lh 가 pi=61 ls[0] 위치 결정에 영향.
2. **(B)** 인라인 수식 다수 paragraph 의 char_offsets / text_start 계산 결함. ls[0~2] text_start (0, 13, 60) 의 utf-16 인덱스가 사각형/수식 자리를 포함해 라인 분할이 잘못됨.
3. **(C)** sw 변경 (ls[2] sw=30562) 케이스의 다단/단일 단 처리. ls[2] 가 단 너비가 다른 라인 → wrap 처리 결함.
4. **(D)** SVG 발행 시 `text_y` 또는 `baseline` 변수 누적 결함. paragraph_layout 의 y 변수 갱신 누락.
