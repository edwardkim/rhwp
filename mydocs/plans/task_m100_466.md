## 2. 결함 위치

### 현재 헬퍼 코드 (`layout.rs:3382~3404`)

```rust
fn compute_square_wrap_tbl_x_right(
    t: &crate::model::table::Table,
    col_area: &LayoutRect,
    dpi: f64,
) -> f64 {
    use crate::model::shape::HorzAlign;
    let tbl_w = crate::renderer::hwpunit_to_px(t.common.width as i32, dpi);
    let h_offset = crate::renderer::hwpunit_to_px(t.common.horizontal_offset as i32, dpi);
    let tbl_x = match t.common.horz_align {
        HorzAlign::Right | HorzAlign::Outside =>
            col_area.x + col_area.width - tbl_w + h_offset,
        HorzAlign::Center =>
            col_area.x + (col_area.width - tbl_w) / 2.0 + h_offset,
        _ => col_area.x + h_offset,
    };
    tbl_x + tbl_w
}
```

`horz_rel_to` 무시 — 항상 col_area 기준 (Column 케이스).

## 3. 수정 방향

### 3.1 헬퍼를 LayoutEngine 메서드로 변환

`paper_width` 와 `body_area` 정보 접근을 위해 free function 을 `LayoutEngine` 의 메서드로 변환. 또는 인자로 추가.

```rust
fn compute_square_wrap_tbl_x_right(
    &self,
    t: &Table,
    col_area: &LayoutRect,
    paper_width: f64,
) -> f64 {
    // horz_rel_to 분기:
    let (ref_x, ref_w) = match t.common.horz_rel_to {
        HorzRelTo::Paper => (0.0, paper_width),
        HorzRelTo::Page => {
            let body = self.current_body_area.get();
            if body.2 > 0.0 { (body.0, body.2) } else { (col_area.x, col_area.width) }
        }
        HorzRelTo::Para => (col_area.x, col_area.width), // host_margin 미반영 (단순화)
        _ => (col_area.x, col_area.width), // Column
    };
    // 정렬 공식 (table_layout 과 동일하지만 inline_x_override 경로 가산식 사용)
    let tbl_w = hwpunit_to_px(t.common.width as i32, self.dpi);
    let h_offset = hwpunit_to_px(t.common.horizontal_offset as i32, self.dpi);
    let tbl_x = match t.common.horz_align {
        HorzAlign::Right | HorzAlign::Outside => ref_x + (ref_w - tbl_w) + h_offset,
        HorzAlign::Center => ref_x + (ref_w - tbl_w) / 2.0 + h_offset,
        _ => ref_x + h_offset,
    };
    tbl_x + tbl_w
}
```
