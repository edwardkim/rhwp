# #7642 WMF/EMF 실패 검사의 독립 Print 대조

## 범위와 근거

전체 회귀의 WMF/EMF golden 9건은 루트 크기 속성과 도형 표현이 바뀌어 실패한다.
별도의 페이지 변환 검사도 rect 속성을 문자열 전체에서 찾으므로 path로 표현된
실제 도형을 검사하지 못한다. 기존 좌표·viewport 기대값은 그대로 보존한다.
단순 문자열 변경이라는 설명만으로 기대값을 갱신하지 않는다.

기존 9건과 같은 WMF/EMF 바이트 및 논리 1000→장치 100의 페이지 변환 바이트를
HWPX에 삽입한 진단 문서를 만든다. 원본 바이트·생성 방법·hash를 보존하고
Hancom MCP Print로 실제 출력한다. 빈 header/EOF 사례는 빈 그림이라는 계약만
확인하며 도형 충족 증거로 세지 않는다. 수정/정상화가 필요하면 raw 원본과
저장 대조군을 구분하고 실패를 숨기지 않는다.

관련 전쪽 Native/fresh WASM 90%와 확대 판독 전에는 정식 회귀·golden 변경을
보류한다. 이후 원본 레코드·독립 출력으로 설명할 수 있는 표현 변화만 처리한다.
새 의미 검사는 도형의 실제 bbox/포함/흐름과 정상 대조군을 보호하며 전체 SVG
문자열이나 무근거 px 핀으로 대체하지 않는다. 실제 좌표를 고정할 때는 완료 쪽의
양쪽 raw 98%·직접 판독·±2px 조건을 따른다.
