# #8153: 글상자의 내용 프레임과 Print clip 분리

## 원 해결 PR과 반례

기존 이슈 #6174의 원 PR #6252는 `7ed637a30c99cc0e4cfce2c4a986e9e295e3c668`과
`31b697549bc66673aaf69550d15fd06c1c01916c`이며, 통합 PR #6275의
`f8a5524ab404ea80c5f2e4f1e5b3694841237a77`로 반영됐다. 본문·댓글과 코드를 확인했다.
이 수정은 안쪽 여백을 뺀 11.41px clip으로 16px 글줄을 잘라 경찰청 받침이 사라지는
문제를 고쳤지만, 모든 자손의 아래끝까지 clip을 늘리는 일반화도 함께 추가했다.

편람 161쪽의 `표 사이 간격` 글상자는 같은 일반화의 반례다. 엄격한 공통 재조판
`8164250673`에서 네 줄 구분은 독립 Print와 같지만, 마지막 `1㎜`를 온전히 드러낸다.
독립 Print의 실제 clip은 `[78.395, 384.443, 140.488, 423.679]pt`이며 도형의
물리 사각형에 대응한다. 저장 줄의 아래끝이나 안쪽 여백 사각형에 대응하지 않는다.

경찰청의 기존 독립 2020 Print도 해당 도형 주변에 실제 clip을 가진다.
`[109.261, 84.867, 169.949, 99.251]pt`이며 선언한 도형 외곽에 대응한다.
추출된 text span bbox의 아래끝이 도형보다 낮다는 것만으로 수직 clip이 없다고
판정할 수 없다. 실제 raster를 확대해 받침을 대조한다. HWP 5.0 revision 1.3의
표 90은 텍스트 안쪽 여백과 문자열 폭을 정의한다. 안쪽 배치 프레임과 출력 clip을
같은 값이라고 규정하거나, 모든 줄을 표시하도록 외곽을 늘리라고 규정하지 않는다.

## 먼저 실행한 소비자 진단

고정된 `8164250673` 라이브러리로 원본을 직접 읽고 모든 글상자의 Print clip만
소유 도형의 사각형으로 대응시켰다. 일반 경로 PNG와 실제 CLI PNG의 RGB 전체가
같음을 먼저 확인했으며, 문서 ID나 특정 좌표로 목표만 자르지 않았다.

- 편람 HWPX 161쪽: 미대응 83 → 21픽셀, raw 99.94507% → 99.98609%.
- 경찰청 원본 1쪽: 미대응 542개로 동일. raw는 99.34546596% → 99.34541063%로
  아주 조금 내려갔지만 미대응 증가가 아니라 전체 union에서 7픽셀을 제거한 분모
  변화다. 받침 확대 판독을 했고 해당 영역의 R채널 절대 오차 합은 9495 → 9029다.
  이 작은 수치 하락도 기록하며, 전체 파일의 보정 완료나 fresh WASM 통과로 간주하지 않는다.

자료는 ignored 작업 루트의 `textbox-outer-clip-8164250673/`,
`issue6174-outer-clip-8164250673/`, `p161-independent-textbox-clip-drawings.json`,
`issue6174-independent-clips.json`에 있다. 바이너리 분석은 이 문서의 근거가 아니다.

## 구현과 소비 경로

`layout_textbox_content`의 원본 도형 사각형 → 명시적인 Print clip 메타데이터 →
공통 `LayerBuilder`의 `ClipKind::TextBox` → Native/Canvas2D/CanvasKit/SVG의 기존
clip 소비로 연결한다. 레이아웃·문단 측정·글줄 원점·후속 내용 높이는 바꾸지 않는다.
내용 프레임·편집용 bbox를 Print clip으로 덮어쓰지 않는다. 기존 명시적 경로 clip과
인라인 글상자의 별도 크기 계약을 유지한다. 개별 backend에 새 예외를 넣지 않는다.

기존 #6174의 편집 화면 내용 포함 보호도 유지한다. Print의 실제 형상은 독립 PDF와
다시 비교하며, clip 때문에 글자가 빠져 보인다는 이유만으로 옛 구현의 모든 줄 노출을
독립 기대값으로 삼지 않는다. 원본 문단·문자는 모델에 보존하고 정해진 표시 영역만 소비한다.

## 검증 계획

먼저 새 Native의 편람 8·161·288·307쪽과 경찰청 원본을 직접 출력해 진단을 재현한다.
기존 원 PR의 받침과 정상 글상자를 대조하고 영향 페이지를 확대 판독한다. 이후 두 원본의
전쪽 Native/fresh WASM과 PR8148 corpus를 비교한다. 추가·변경할 정식 회귀는 각 원본의
시각 선행 조건과 독립 기대값을 확인한 뒤 등록하며, 최종 1,532개 raw 100%와 전체 페이지
중요 경계의 ±2px 검사를 부분 진단의 높은 점수로 대신하지 않는다.
