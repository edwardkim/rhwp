# #7642 재조판 행의 독립 최소 높이와 걸침 칸

Issue: #7642. 법령 43쪽은 같은 Print PDF·Native·글꼴에서 기준 devel
9415b920c8의 98.39429%가 후보 57d4adf2a0의 90.93299%로 낮아졌다.
90% 통과로 면제하지 않고 원인과 두 source의 실제 셀 상자를 대조했다.

## 원본·독립 출력·실행 증거

421문단의 31×17 표에서 12행의 일반 칸 선언 높이는 7410 HU다.
현재 정상 재조판은 본문 두 줄을 만든다. 8행에서 시작한 별도 열의
rowspan도 12행을 지난다. 독립 PDF는 두 줄을 쪽 끝의 남은 행 상자 안에
가운데 정렬한다. 기준 Native의 상자는 약70.9px, 후보는44.1px였다.
공통 글줄은 유지됐지만 주요내용·걸침 칸 라벨이 약14.3px 위로 이동했다.

RHWP_DIAG_SCAN은 12행에서 내용38.1·선언98.8·수용66.8px의 BAND_CUT을
확인했다. RHWP_DIAG_NESTED_FRAME은 최종 end_override=None과 실제
행44.1px를 확인했다. RHWP_DIAG_FOLD는 접기를 보고하지 않았다.
따라서 paint 뒤의 fold 때문이라는 가설은 배제한다.

## 원인·공통 소비 경로

row_uses_reflow_physical_frame은 일반 칸의 최소 상자와 다른 열의 걸침
장부를 구분한다. 그런데 reflow_row_physical_minimum은 prior rowspan이
있다는 이유만으로 일반 칸의 독립 최소를 없애고 있었다. 셀의 내용이 전부
소진됐다는 사실도 그 물리 최소를 지우지 못한다.

해당 배제를 제거한다. 최소 높이는 기존과 같이 일반 칸 원본 선언과 전체
내용 점유를 대조해 산출한다. 저장 줄·중첩 개체·실제 재조판 여부의 기존
수용 조건은 유지한다. scan의 owns_plain_row_frame → 실제 수용 높이
override → PageItem·paint → next_start_row_height_override가 같은
앞 상자·잔여 높이를 소비한다. 기존 straddle 장부는 다른 열의 누적 공간을
계속 소유한다. 물리 행을 줄이거나 이전 쪽에서 이미 수용한 띠를 재가산하지 않는다.

## 검증 경계

43~44쪽의 두 줄·왼쪽 걸침 라벨·다음 영향평가 행과 쪽수를 확인한다.
일반 칸과 prior rowspan이 함께 있을 때, 내용 소진 뒤 빈 꼬리, 실제 내용
이월, 저장 줄·중첩 표·prior rowspan 없는 대조군을 Native/fresh WASM으로
대조한다. 18~19쪽 종료 간격 보정과 전체102문서의90%·쪽수·직접 판독,
같은 글꼴 조건의 devel 대비0.01%p 하락 검사를 유지한다. 정상 출력의
시각 선행 조건 충족 전 신규 rendering 회귀나 baseline은 추가하지 않는다.
