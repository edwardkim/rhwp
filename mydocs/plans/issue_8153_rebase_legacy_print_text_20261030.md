# #8153 리베이스 후 기존 Print 글자 재생 보존

## 독립 근거와 범위

고정 devel `ad4bf269ffef5adf2142b33004a9981fad7ce804`과 제품 source
`80818c7e0dde36a002a81b3684de8beb4c49a032`를 같은 #7905 원본·기존 한컴 2018 Print
PDF·글꼴 환경·96dpi로 대조했다. 원본 저장 확장자와 파일명으로 Print 세대를 추측하지
않고 기존 공개 `--compat 2022|2024` 설정을 사용했다. HWP 5.0 형식 사양은 글자 크기와
좌표 단위를 명시하지만 래스터 글꼴 hinting을 규정하지 않는다. 따라서 사양에서 특정
래스터 방식을 강제한다고 주장하지 않는다.

#7905 Native 3·4·6쪽의 devel→후보 raw 표시값은 각각 38.22→37.94%,
57.57→57.33%, 42.35→42.30%다. 동일 Print 레이어에서 선과 이미지 재생을 유지하고
글자 기하 설정만 비활성화한 독립 Native 진단은 각각 38.22%, 57.57%, 42.35%다.
같은 진단에서 #8188 HWP 2022 전 64쪽은 현재 Print의 쪽별 표시값과 모두 같았다.
양 입력의 페이지 배치·그리기 순서는 변경하지 않았다. 위 90% 미달은 기존 기준의
별도 결함이며 새 하락을 면제하지 않는다.

Canvas에서 `textRendering`만 `auto`로 강제한 #7905 3·6쪽은 기존 표시값으로
복구됐다. 4쪽은 57.48→57.47%로 0.01%p가 남는다. 로고 RGB 차이는 존재하지만
추가 실루엣 미대응은 본문 왼쪽 glyph 두 픽셀이다. 해당 글줄의 clip과 2024 대조군을
검증해야 하며 글자 보정의 통과로 대체하지 않는다.

#8153 편람은 명시적 2024 호환의 독립 2024 Print를 사용한다. 2024 Print에서 이전에
확인한 소수 글자 원점과 기하 정책을 그대로 유지한다. 일반 Screen과 외부에서 직접
생성한 Print layer의 기존 동작도 유지한다. 위 2018·2022 검증이 모든 한컴 버전에서
hinting이 같다는 증거는 아니다. 기존 2022 호환 API 경로에서 devel과의 재생 계약을
보존하고 2024 opt-in 경로를 보존하는 범위다.

## 생산과 소비 경로

명시된 세대 설정 → `DocumentCore`의 Print layer 생성 → 페이지별 공통 글자 래스터
정책 → Native Skia Font/윤곽 재생과 WASM Canvas textRendering을 같은 값으로 전달한다.
실제 세대 선택은 호출자가 하며 문서 ID·글꼴명·쪽·일치율·우연한 크기로 분기하지 않는다.
페이지별 정책은 캐시 키와 외부 layer JSON의 실제 의미에도 반영한다. 벡터 출력은 현재
동작을 유지하고, Screen과 직접 구성한 layer의 기존 기본값도 확인한다.

#7905·#8188·두 편람의 같은 입력과 기존 PDF로 Native/fresh WASM을 재검증한다.
2022·2024 선택 전환과 같은 renderer 재사용 시 캐시 분리도 확인한다. 새 테스트는
정책 전달·글자 원점 및 API 전환을 합성 관계로 검증하고, 98% 미만 쪽의 절대 px를
고정하지 않는다. 4쪽 별도 미대응 보정과 최종 전쪽 결과·전체 회귀·lint·Studio는
이 계획이나 분리 진단만으로 완료한 것으로 판정하지 않는다.

## 추가 분리 대조

Print 선·이미지 설정을 유지한 Native 글자 정책 단독 진단은 #8188 HWP 2022의 전 64쪽에서
기존 표시값과 동일했다. 편람 HWP·HWPX의 239쪽은 두 방식 모두 100.00%로 표시됐지만
RGB 차이는 있으므로 2024 정책을 전역으로 바꾸지 않는다. #7905의 Canvas 4쪽 잔여 미대응은 본문의 왼쪽 glyph 두 픽셀이며
Body clip의 실제 소비 경로를 별도로 확인했다. devel의 소수 clip을 Canvas 진단에서 복원하면
4쪽은 57.47→57.48%로 devel 표시값과 같아진다. 페이지별 후킹은 진단에만 쓰며 제품에는
명시적 인쇄 세대와 공통 clip 소비 계약을 사용한다.
