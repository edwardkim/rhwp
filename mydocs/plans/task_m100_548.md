## 1. 배경

페이지 8 보기 표 셀 5 (3-col 병합 본문 셀) 의 첫 줄 [푸코] inline TAC Shape 가
cell 좌측 가장자리 (x=131.04 px) 에 렌더 — PDF (한컴 2010, x≈155.6 px) 와
24.56 px 차이.

paragraph_layout (텍스트 경로) 는 정확한 위치 (155.60) 에 텍스트 렌더 + inline_pos
등록하지만, table_layout (cell shape 경로) 는 inline_pos 무시하고 자체 계산한
`inline_x = inner_area.x = 131.04` 로 shape 렌더 → 두 경로 불일치.

## 2. 본질 가설

가설 H1 — **table_layout.rs 의 `inline_x` 초기화/리셋 시 paragraph 의
`effective_margin_left_line(line_n)` 미적용**.

- `effective_margin_left_line(line_n)` = `margin_left + line_indent(line_n)`
- line_indent(0) = +indent (positive) or 0 (negative/zero)
- line_indent(N≥1) = 0 (positive) or |indent| (negative)

가설 H2 — paragraph_layout 의 `set_inline_shape_position` 을 layout_cell_shape
이 사용하지 않음. 사용하도록 수정.

H1 이 본질 정정. H2 는 우회 (paragraph_layout 등록값을 cell 경로가 사용).

## 4. 검증 기준

- 페이지 8 보기 표 셀 5 line 1 [푸코] box 좌측 x = PDF 기대값 (≈155.6 px) ±2 px
- 텍스트 "는" 위치 (paragraph_layout) 보존 (≈185.83 px)
- 광범위 회귀 (6 샘플) 텍스트 음의 시프트 0건
- 1121 단위 테스트 무회귀
- 분기 검증:
  - positive indent (line 0 indent 적용)
  - negative indent (line 0 0, line N |indent|)
  - margin_left=0 + indent=0 (변경 없음)
