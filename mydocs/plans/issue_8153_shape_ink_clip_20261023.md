# #8153: 본문 경계 도형의 실제 획 보존

## 위반한 규칙과 독립 근거

사각형의 원 프레임은 앵커·배제 영역이며, 중심 정렬 획은 프레임 양쪽으로
원 선 굵기의 절반씩 차지한다. 편람 253쪽의 독립 한컴 Print는 위쪽 획도 보존한다.
현재 원본 Native의 사각형 프레임과 선 굵기는 맞지만 본문 clip이 위쪽 절반을 자른다.
원문 좌표를 이동하거나 고정 여백을 더하는 문제가 아니다.

- 원본 HWPX 253쪽: raw 99.14072%, 미대응 1,058픽셀.
- 독립 Print의 선 굵기: 5.634pt. 원본 전달값: 564HU = 7.52 CSS px.
- 같은 실제 Native 라이브러리의 진단 출력은 원 제품 PNG와 RGB가 전부 같다.
  이 레이어의 본문 clip만 사각형의 공통 paint 경계까지 포함하면 raw 100%, 미대응 0이다.
  이는 원인 분리 진단이며 수정 제품·fresh WASM의 검증 완료를 뜻하지 않는다.

## 기존 해결과 소비 경로

#6269의 원 PR #6278은 clip에 선 굵기를 더하는 접근이었다. 실제 통합된
#6292 → #6296 및 `9f81bbfb17`은 선의 bbox를 잉크 기준으로 통일했다.
도형 프레임은 앵커와 배제 영역이 소비하므로 그대로 두었다. 그 구분을 유지한다.
기존 선·표 조각의 bbox나 #6269의 정확한 회귀 검사는 바꾸지 않는다.

`원 사각형·타원의 프레임/선 속성 → 공통 PaintOp의 변환된 획 경계 →
본문 expand_clip → PageLayerTree의 body clip → Native/Canvas 재생`으로 연결한다.
이미 공유하는 paint 경계를 사용하며 글자용 추정 padding을 clip에 적용하지 않는다.
기존 경로 채움의 실제 극값 계산은 유지한다.

셀·글상자의 내부 clip을 해제하지 않고, 기존 expand_clip의 자손 순회 중단과
쪽 하단 경계도 유지한다. 문서 ID·쪽 번호·임의 픽셀 여백을 구현 조건에 넣지 않는다.

## 실제 검증 순서

1. 같은 원본의 중심 정렬 획 포함 관계로 수정 전 실패를 실제 실행한다.
2. 수정한 제품의 253쪽 Native/fresh WASM을 독립 Print와 비교하고 직접 판독한다.
3. 선·채움·회전·중첩 clip의 적용/비적용 경계와 기존 #6269·관련 정상 대조군을 확인한다.
4. 관련 페이지가 양쪽 raw 90% 이상인 뒤 정식 관계형 회귀를 등록한다.
5. 편람 전쪽·PR #8148 검증 문서의 변화와 필수 회귀·lint를 확인한다.

현재 진단 자료는 ignored `output/pr-review/issue8153-handbook-raw100-20261022/`에 있다.
구현 뒤의 실제 결과와 회귀 등록은 위 순서에 따라 별도로 기록하며 raw100 목표 완료로
앞당겨 판정하지 않는다.
