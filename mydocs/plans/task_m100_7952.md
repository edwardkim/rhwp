## 목표와 계약

사용자 확정 방향은 `rhwp-q-*`23개를 **`rhwp-q <기능> ...` 하나로 통합**하는 것이다.
`rhwp` 본 CLI는 변경하지 않는다. `rhwp-agent`와 `font-metric-gen`도 유지하여 루트
실행 타깃26개를4개로 줄인다. 처음 제안한 feature 선택 방식은 이번 구현에서 사용하지 않는다.
기존 옵션·JSON·종료 코드·원본 처리와 DocumentCore/Studio/WASM API를 보존한다.

개발 profile의 debug 정보는 줄·함수 정보를 유지하는 수준으로 낮춘다. 현재 존재하는
공유 target을 삭제·strip하지 않고 새 빌드 결과의 크기를 측정한다. 기존 캐시151GiB를
이번 코드 변경만으로 확보했다고 보고하지 않는다.

## 구현 근거와 범위

Cargo는 `src/bin`을 자동 발견하고 integration 검증에서 bin을 빌드한다. 기존23개의
entry를 하위 명령 adapter로 이관하고 `autobins=false`와 명시적4개 target으로 링크 수를
줄인다. dispatcher는 인자를 직접 전달한다. 전역 argv 변경·하위 프로세스 재실행은 하지 않는다.

kit/more/pack은 서로 다른 의미의 동명 명령이 있어 그룹을 유지한다. JSON의 기존 tool 식별자는
유지하고 사용법·실행 명령은 새 경로로 갱신한다. 기존22개 q 계약 파일과 호출 script를 새
실행 파일/하위 명령으로 이관하며 검사 함수와 기대 의미를 보존한다. feature 비활성화나
검사 삭제로 통과시키지 않는다. 새 바이너리 출처와 검사 수를 확인한다.

조판·렌더링 변경은 없으며 px/쪽수/golden/baseline 기대값을 수정하지 않는다.
#7001의 다른 패키지 이관·agent 의미 통합 제안은 이번 승인으로 확대하지 않는다.
