## 1. 배경

Task #544 에서 paragraph border 박스 outline 을 `col_area` 로 정정 (margin_left 미적용). 그러나 박스 안 본문 텍스트는 여전히 paragraph margin_left (≈11.36 px for ps_id=11) 를 좌측 inset 으로 적용 중.

작업지시자 보고: `[13~15] 다음 글을 읽고 물음에 답하시오.` 예제 박스에서 박스 안 좌측 여백이 PDF 보다 넓게 보임.

## 2. 본질 가설

가설 H1 — **paragraph border 가진 문단의 텍스트는 박스 outline 좌측 (col_area.x) 에서 시작 (margin_left 미적용) + border 자체 padding 만 inset 으로 사용**.

- HWP ParaShape margin_left 는 border 없는 일반 문단의 텍스트 좌측 inset.
- HWP paragraph border 는 자체 left/right/top/bottom offset (border_offset_left 등) 으로 박스 안 텍스트 padding 결정.
- PDF (한컴 2010) 가 이 룰 검증 ref.

가설 H2 — **paragraph border 가진 문단의 margin_left 는 0 (또는 border padding 으로 대체)**

가설 H3 — **margin_left 의미가 환경별 다름** (한컴 2010 vs 한컴 2020 vs 한컴독스)

H1 이 본질 후보. Stage 0 에서 본 코드 / HWP 명세 / 한컴 2010 PDF 비교로 검증.
