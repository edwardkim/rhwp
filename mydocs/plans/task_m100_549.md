## 1. 본질 진단 (Stage 0 사전 분석 결과)

### 1.1 증상

`samples/21_언어_기출_편집가능본.hwp` 14 페이지 [28~30] 박스 [A] inline TAC 표
(pi=299, cell[2] r=1 cs=2 w=1697 HU) 의 두 줄 ("[A" / "]") 이 비대칭 정렬.

| 위치 | 우리 SVG (cell-rel) | PDF 한컴 2010/2020 (cell-rel) |
|------|---------------------|-------------------------------|
| "[" line 0 | 2.32 px | 3.28 px |
| "A" line 0 | 9.29 px | (≈ 9.5 px) |
| "]" line 1 | 8.32 px | 8.88 px |
| 두 줄 중심 일치 | ✗ (2 px 어긋남) | ✓ (0.02 pt 이내) |

### 1.2 코드 경로

```
table_layout.rs:1193  resolve_cell_padding(cell, table)
  ├─ aim=false 분기 (cell[2] 의 apply_inner_margin=false)
  └─ Task #347 hack: cell.padding(510) > table.padding(0) → cell 우선
     → pad_left = pad_right = 510 HU = 6.80 px

table_layout.rs:1200  shrink_cell_padding_for_overflow
  ├─ inner_width 초안 = 22.65 - 13.6 = 9.05 px
  ├─ "[A" 자연 폭 ≈ 17~18 px > 9.05 × 1.15 = 10.4 px → shrink 발동
  └─ 좌우 균등 부분 축소 → pad 2.32 px each, inner_width = 18.01

paragraph_layout.rs:1220-1230 Center 분기 (ps_id=50 alignment=Center)
  ├─ Line 0 "[A": text > inner_width → x_start = inner_x = 607.79 (좌측 붙음)
  └─ Line 1 "]": text < inner_width → x_start = 613.79 (centered)
                                              → 두 줄 비대칭
```

### 1.3 PDF 동작 (한컴 2010/2020 정합)

```
한컴 (스펙 정합):
  aim=false → table.padding 사용 → pad = 0
  → inner_width = cell_width = 16.97 pt
  → "[A" 12.04 ≤ 16.97 fit → Center 정렬: x_start = cell_left + (16.97-12.04)/2
  → "]" 3.68 ≤ 16.97 fit → Center 정렬: x_start = cell_left + (16.97-3.68)/2
  → 두 줄 모두 cell_center 기준 → 일관 정렬 ✓
```
