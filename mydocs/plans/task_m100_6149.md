## 목표

1. 화면 픽셀 간격을 기준으로 가로·세로 눈금의 숫자와 세부 눈금 밀도를 단계화한다.
2. 마지막 편집 focus 쪽의 전체 용지 범위를 눈금자에서 식별할 수 있게 한다.
3. 페이지 간격을 배율에 따라 자연스럽게 키우되 10%에서도 페이지 경계를 구분할 하한을 보장한다.
4. 문서 용지 크기·여백·클릭 좌표·인쇄/저장 좌표는 바꾸지 않는다.

## 단계와 산출물

1. **순수 표시 계약**
   - `1·2·5 × 10ⁿ mm` 눈금 단계 계산과 페이지 간격 계산을 DOM 없는 테스트로 고정한다.
   - 완료 기록: `mydocs/working/task_m100_6149_stage1.md`
2. **눈금자 LOD와 focus 쪽 경계**
   - 가로·세로가 같은 단계 계산을 사용하게 한다.
   - 세로 눈금자를 마지막 focus 쪽 한 장에 한정하고, 가로·세로 모두 용지 시작/끝 경계를 표시한다.
   - 완료 기록: `mydocs/working/task_m100_6149_stage2.md`
3. **배치 공통 페이지 분리 표현**
   - 단일 열·자동·두 쪽·맞쪽·여러 쪽·가로 이동이 같은 동적 gap을 사용한다.
   - 페이지 루트 Canvas에만 외곽선을 적용해 overlay layer와 문서 좌표를 건드리지 않는다.
   - 완료 기록: `mydocs/working/task_m100_6149_stage3.md`
4. **회귀·시각 검증**
