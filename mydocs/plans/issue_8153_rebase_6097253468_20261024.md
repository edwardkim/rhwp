## 그림 테두리의 리베이스 후퇴와 보정 근거

`05cc98c510`의 Native 빌드와 영향 26쪽 실행은 완료했다. 새 base의 독립 그림 대조군은
99.90635%였지만 같은 입력·PDF·192DPI의 후보는 66.43217%로 후퇴했다. 직접 review를
확인하면 36pt 외곽선이 안쪽 로고를 덮는다. 중첩 그림 대조군은 양쪽 100%이며, 후보의
곡선 두 대조군과 순수 단색 채움도 각각 100%다. 이 결과를 전체 기능 보존으로 확대하지 않는다.

원인은 원본 그림 프레임을 확장한 테두리를 paint에서 그림 프레임 자체로 덮어쓴 것이다.
`picture_footnote.rs::make_picture_border_for_frame`의 원본 선폭·겹침으로 만든 바깥 여백을
`LayerBuilder::build_node`의 `image_frames` 소비 지점이 없애고 있었다. 새 base의 확장 규칙을
유지하면서, 공통 layer builder에 원본 그림 프레임과 인쇄 그림 프레임을 함께 보존한다.
테두리는 인쇄 그림 프레임으로 이동한 네 변에 원본 테두리의 상대 여백을 유지한다.
그림 크기에 맞춰 선폭·바깥 여백을 비례 확대하거나 그림 프레임으로 대체하지 않는다.
그림 크기·원점의 네 값 모두를 확인하고, master·bitmap fill·회전의 기존 적용 경계는 유지한다.

위 공통 결과를 Native와 Canvas 소비 경로에서 재실행하고, 새 base 그림 대조군과 편람 영향
쪽의 TSV·직접 판독으로 보정 여부를 확인한다. 기존 그림 소유 관계 회귀의 통과만으로
독립 Print 외곽선이 맞다고 판정하지 않는다. 실행 로그와 producer는 작업 자료의
`rebase609-candidate-05cc98c510-r2/`와 `logs/`에 보존했다.
