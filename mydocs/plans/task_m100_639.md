## 2. 본질

페이지 단위 finalize 단계에 cover-style 자동 미표시 룰을 추가한다.

**구현 위치 후보 (1순위)**: `src/renderer/pagination/engine.rs:1892` `finalize_pages` —
페이지 단위 page_hide 결정 직후. 이미 `page.page_hide` 가 PageHide 컨트롤로 설정되었거나
None 인 상태. None 인 경우에 한해 cover-style 룰 적용.

**구현 위치 후보 (2순위)**: `src/renderer/page_number::PageNumberAssigner::assign` —
쪽번호 할당 단계. 페이지 별로 page_number 가 결정되는 시점.

1순위 채택 사유:
- page_hide 와 cover-style 모두 "쪽번호 미표시" 라는 같은 의미. 동일 위치 (`page.page_hide`)
  에서 결정하는 것이 SVG 렌더링 단계 (`page_hide.page_num` 검사) 까지 일관성 유지.
- 별도 boolean 필드 신설 불필요.

## 3. 구현 룰 정형화

```rust
// finalize_pages 내부, 기존 page_hides 체크 직후
if page.page_hide.is_none() {
    // cover-style 자동 미표시 룰
    let is_cover_table_only = is_cover_style_page(page, paragraphs);
    if is_cover_table_only {
        // page_num=true 인 PageHide 자동 설정 (다른 항목은 false)
        page.page_hide = Some(PageHide {
            header: false, footer: false, master_page: false,
            border: false, fill: false, page_num: true,
        });
    }
}

fn is_cover_style_page(page: &PageContent, paragraphs: &[Paragraph]) -> bool {
    // 단일 단 + 단일 item + 완전한 Table + tac=false
    if page.column_contents.len() != 1 { return false; }
    let items = &page.column_contents[0].items;
    if items.len() != 1 { return false; }
    let PageItem::Table { para_index, control_index } = &items[0] else { return false; };
    let para = &paragraphs.get(*para_index)?;
    let Some(Control::Table(t)) = para.controls.get(*control_index) else { return false; };
    !t.common.treat_as_char  // tac=false 만 매칭
}
```

> 위 의사 코드는 구현 계획서 단계에서 정확한 시그니처/borrow 충돌 회피 형태로 다듬는다.
