## 구현 범위

1. 공통 wrap의 가용 폭·높이를 viewport에 묶고, 제목/footer는 줄이지 않으며 본문이 남은 공간에서 스크롤하게 한다. CSS flex 결과를 사용하고 JavaScript 높이 측정·resize listener를 추가하지 않는다.
2. 좁은 화면 bottom-sheet의 폭·하단 정렬·90dvh를 유지하면서 제목/버튼을 포함한 wrap 전체 스크롤을 본문 스크롤로 연결한다.
3. 독립 탭형 글자/문단 모양의 중간 flex 소유와 기존 최소 본문 높이의 소비를 점검하고 같은 공통 계약으로 보완한다. 표/셀 속성·그림 속성의 자체 패널 스크롤과 복구 목록·PDF/제품 정보의 전용 계약은 보존한다.
4. 배경 클릭 기본 비닫힘, 제품 정보의 명시 opt-in, Escape·확인·취소, 입력 값·탭·적용/Undo 동작은 유지한다. 새로운 일괄 닫힘 정책을 만들지 않는다.
5. Rust/WASM 엔진·문서 조판·저장·배포·CI workflow는 수정하지 않는다. 문서 Visual Sweep/편람/특별 보호는 UI 변경에 비해당이며 필요 검증을 축소한 것으로 쓰지 않는다.
