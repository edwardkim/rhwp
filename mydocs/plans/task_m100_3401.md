## 5. 위험과 대응

- **main↔devel 이력 분기**: v0.8.0 에서 발생했던 문제. release PR 은 **merge commit 방식**을
  쓰고 squash 를 금지한다(ancestry 소실 시 다음 릴리즈에서 동일 충돌 재발). merge 전
  `main` 트리 == `devel` 트리를 tree hash 로 확인한다.
- **dependabot 경합**: `devel` 에 수시로 커밋이 들어온다. 기준선을 고정하고, PR merge 직전
  재확인한다.
- **Actions 캐시 예산 소진**: v0.8.0 배포 로그에 경고가 있었다. 빌드 시간 증가 가능성을
  감안하되 실패 시 재실행으로 대응한다.
- **확장 zip 위생**: `.env`·개인 폰트·token·`node_modules/`·`target/`·`dist/` 불포함을
  확인한다. AMO source zip 은 200MB 제한과 제외 규칙(`samples/` `pdf-large/` 등)을 지킨다.
