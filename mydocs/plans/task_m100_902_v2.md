## 2. v2 재정의 scope — WMF renderer 근본 개선

### 2.1 식별된 fundamental 갭

| 영역 | 현재 상태 | 영향 |
|------|-----------|------|
| `META_SETVIEWPORTEXT` | **`not implemented`** | MM_ANISOTROPIC 의 Window/Viewport ratio 누락 |
| `META_SETVIEWPORTORG` | **`not implemented`** | viewport origin offset 무시 |
| `META_SETMAPPERFLAGS` | 미구현 | font mapping flag 무시 |
| `META_SETPALENTRIES` 등 | 미구현 | palette 처리 누락 |
| EXTTEXTOUT `ETO_PDY` 플래그 | 미처리 | per-glyph Y 오프셋 무시 |
| 폰트 metric | substitute 사용 | 굴림체 → Apple SD Gothic Neo 등 폴백 — glyph 너비 차이 → 시각 정합 한계 |
| Window/Viewport ratio | viewBox 자동 확장 (Task #860) | 한컴 사적 동작과 다를 가능성 |

### 2.2 진행 우선순위

1. **fix3 commit** — DX byte-aware indexing 은 실제 버그 fix, 우선 confirm
2. **SETVIEWPORTEXT/SETVIEWPORTORG 구현** — MM_ANISOTROPIC ratio 정확화
3. **EXTTEXTOUT options flags** — ETO_PDY 등
4. **미구현 records 완성** — set_mapper_flags, escape, palette 등
5. **폰트 정합** — 굴림체 substitute (오픈 한국어 폰트) 또는 임베딩
6. **회귀 검증** — 다중 sample (sample14/16/17/18/19)

### 2.3 timebox

**open-ended** (작업지시자 결정). 단계별 진행 + 매 stage 보고/승인.
