## 구현 순서와 계약

1. **공통 예산과 데이터 흐름 확인.** 선언 픽셀, 실제 소스 디코딩, 배치별 변환, PNG/IR 저장,
   Core 초기화 비용의 생산·소비 위치를 기록한다. 반복 사용 비용과 원본 해상도를 구분한다.
   기존 요청 카운터·명시한 낮은 host cap·실패 후 복구 계약을 유지한다.
2. **곡선 clip (#8413).** 현재 경로를 페이지 좌표에서 보존하고 nonzero/even-odd 채움 규칙,
   q/Q, CTM, Form, 교차 clip을 공통 이미지 alpha 합성에 전달한다. 곡선을 사각 경계로
   대체하지 않는다. 경로 저장·교차 개수·raster 작업과 마스크 할당을 유한하게 제한한다.
   기존 직사각형·볼록 다각형의 빠른 경로를 유지하며 이미지와 벡터 paint 경계를 확인한다.
3. **큰 이미지 (#8414).** 공유 source의 재사용과 동일 출력 bitmap의 저장 중복을 줄인다.
   원본 해상도 보존을 우선하며 출력 픽셀·단일/누적 예약·작업자 한도를 함께 검토한다.
   무제한 정책이나 샘플 전용 수치로 우회하지 않는다. 자동 축소로 화질을 바꾸는 결정은
   암묵적으로 추가하지 않는다. 유한한 제품 한도 변경은 실제 샘플과 경계 측정으로 정한다.
4. **명령 수 (#8416).** 선택 쪽수가 실제 content 복잡도를 대변한다는 가정을 제거하고
   요청 전체 절대 상한·명시 cap과 버퍼/decoded/path 예산으로 제한한다. 파싱 결과 공유와
   버퍼 수집 경계를 함께 확인한다. 한도가 큰 경우에도 검사 전 대규모 할당을 하지 않는다.
5. **암호화 (#8415).** bounded constructor에서 암호화 사전·인증·stream/object 복호화를
   같은 요청 예산으로 연결한다. 빈 비밀번호 인증과 실제 비밀번호가 필요한 상태를 구분한다.
   메인테이너 결정에 따라 유효한 사용자 인증 후 복사·편집 권한 플래그로 추가 차단하지 않고
   편집 가져오기를 허용한다. 소유자 비밀번호를 강제하지 않는다. 잘못된 비밀번호·미지원
   방식·손상 입력을 구분하고 CLI/WASM/Worker/Studio의 취소·재시도를 연결한다. 비밀번호는
   로그·진단·저장 설정에 남기지 않는다. 복호화된 임시 PDF 파일을 우회 입력으로 쓰지 않는다.
6. **실제 제품·안내.** 변경한 기능과 한도, 오류별 조치, 암호·권한 정책을 CLI/Studio·보안 제한·
   PDF 자원 정책 매뉴얼에 반영한다. 설정으로 해결할 수 없는 오류를 일괄적으로 “설정을 확인”으로
   안내하지 않는다. 기존 #8411 대화창의 선택 대기·키보드·취소 동작을 보존한다.

Clip은 PDF 경로·채움 규칙과 현재 좌표계, 인증은 Standard Security Handler의 버전별 계약을
근거로 구현한다. 기존 source의 사양 참조와 공식 원문을 대조한 뒤 새로운 수학적 처리나
인증 분기를 작성한다. 별도 PDF 렌더러 도입·전체 문서 raster화·일반 조판 재작성은 범위가 아니다.

## 검증·완료 조건

- 네 원본은 수정하지 않고 SHA-256으로 식별한다. 계획 승인 시 조사 재현까지 완료했고,
  후속 수정·검증 결과는 [공통 구현 기록](../working/task_m100_8413_implementation.md)에 누적한다.
- Native CLI와 최적화 fresh WASM, 실제 Studio Worker에서 네 문서를 모두 열고 전체 127쪽의
  원본 PDF와 출력 쪽수·순서·내용·이미지·텍스트를 대조한다. 저장/재열기도 같은 범위에서 확인한다.
- Native/fresh WASM 각각 전쪽 TSV를 먼저 산출하고 최저 `silhouette_raw_match_percent` 90%
  이상, 전체 쪽수 일치, 곡선 모서리·이미지 세부·문자·투명도의 직접 확대 판독을 완료한다.
  기존 정상 입력은 같은 devel/candidate 조건으로 비교하며 2%p 초과 하락을 보류한다.
- 기존 #7970/#8174/#8183/#8403의 관련 이미지·mask·직선 clip·타일·문자 획 대조군을 유지한다.
  회귀가 실패하면 원 해결 PR·현재 원본과 독립 출력부터 확인하고 기대값을 임의로 바꾸지 않는다.
- 합성 계약은 곡선·복합 경로·q/Q·Form·음수/회전 CTM, 공유 이미지·다른 mask,
  낮은 host cap·잘못된 암호·손상 암호화 사전·실패 후 정상 입력을 포함한다.
  관련 경계부터 실행하고 전체 검사는 최종 코드에서 수행한다.
- 렌더링 회귀 추가는 시각 선행 조건을 충족한 뒤 정식 자동 수집 경로에 등록한다.
  원본·fixture의 공개/커밋 가능 여부는 제출 전에 확인하고 임시 경로로 숨기지 않는다.
- 처리 시간·Native peak RSS·WASM 메모리와 실제 예산 사용량을 구분해 기록한다.
  카운터 값을 실제 메모리 상한으로 설명하지 않는다. 과도한 입력은 중단되고 다음 요청이 성공해야 한다.
- [로컬 사전 검증 4.3](../manual/pr_review/local_validation.md)에 해당하는 Rust/Native,
  WASM lint·Studio·fresh 브라우저 및 문서 검증을 완료한다.
