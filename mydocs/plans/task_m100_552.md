## 2. fix 방향

### 2.1 후보 A: paragraph border 시작 직전이면 trailing ls 제외하지 않음

```rust
} else if is_full_paragraph_end && cell_ctx.is_none()
    && !next_paragraph_starts_visible_border() {
    y += line_height;
}
```

`next_paragraph_starts_visible_border()` 산출:
- 다음 paragraph (이 paragraph 의 다음 인덱스) 의 border_fill_id 가
  current paragraph 의 border_fill_id 와 다르고 visible (any_w=true)
- 또는 현재 paragraph 의 border_fill_id 가 0 (no border) 인 상태에서 다음
  paragraph 가 visible border 를 가지면

### 2.2 후보 B: 다음 paragraph 가 어떤 border_fill_id 든 가지면 trailing ls 보존

단순화 가설.

### 2.3 후보 C: 현재 분기 자체 보존 + paragraph_border_y_correction_px 같은 별도 보정

Task #544 의 box_y 보정 메커니즘을 응용.
