# #8153: 아래아의 원본 글꼴 메트릭을 대체폭보다 우선

## 원인과 독립 근거

313쪽의 `전자문서시스템` 정의 등에서 `ㆍ`를 지날 때마다 글자 위치가 어긋난다.
두 원본의 독립 한컴 2024 Print 각각에서 U+318D 327개를 확인했다.
KoPub Batang Light/Bold, Dotum Light/Bold 모두 내장 glyph 전진이 900/1000em이다.
설치된 KoPub 6개 프로그램의 cmap/hmtx도 같은 값을 준다.
PDF 내장 폭과 실제 원 프로그램의 폭을 대조했으며 점수로 역산하지 않았다.
상세 페이지·glyph·프로그램 SHA는 ignored 작업 폴더의
`remaining-raw100-diagnostic/area-dot-independent-width-proof.json`에 보존한다.

현재 `char_width_decision_with_hft_tracking`은 원본 메트릭 조회 전에
`area_dot_fallback_width`를 호출해 KoPub에도 1em을 적용한다.
기존 주석은 메트릭이 있으면 이를 신뢰한다고 설명하지만 호출 순서가 그 계약을 깨뜨린다.
HWP 사양의 글자 모양에 따른 글꼴·장평·자간 계약과 원 프로그램의 전진을 함께 보존한다.
원본 슬롯 분류나 문자, 글꼴 family를 바꾸지 않는다.

## 원 해결과 보존 범위

#2070의 사용자 슬롯 선택과 #7080의 반각 대체폭 제거 목적을 보존한다.
기존 `issue_7080_area_dot_fullwidth.rs`는 메트릭 없는 `명조`의 전각과 정상 실물 줄을
보호하므로 삭제하지 않고 실제 재실행한다. KoPub의 0.9em은 반각 0.5em과 다르다.
확인한 KoPub Batang/Dotum의 U+318D는 기존 부분 기호 표에 기록한다.
KoPubWorld의 계약이나 다른 원본의 독립 근거를 이름만으로 변경하지 않는다.

## 생산·소비와 검증

`원본 글자 모양/슬롯 → 같은 공통 embedded 메트릭 결정 → 줄 측정·char positions →
저장 줄 배치와 paint 전진`을 추적한다. 실제 폭 hit 뒤에만 기존 전각 대체폭을 적용한다.
backend별 글자 위치 보정이나 문서 ID 분기를 추가하지 않는다.

독립 hmtx 0.9em의 공통 측정 계약을 수정 전 FAIL / 수정 후 PASS로 확인하고,
현재 원본 313쪽과 아래아가 있는 영향 페이지를 먼저 재출력한다.
독립 Print와 글줄·뒤 본문을 직접 판독하고 기존 #7080 정상 대조군을 검증한다.
이후 최종 Native/fresh WASM 전쪽 TSV와 미대응 픽셀을 다시 비교한다.
앞선 목차 기호 보정과 전체 raw100 목표를 구분하며 미완료 항목을 완료로 보고하지 않는다.
