# #8153 리베이스 기능 보존: 저장 아핀 그림의 개체 프레임

## 원본과 사양

리베이스로 포함된 #7905의 `mydocs/pr/assets/legal_hwpx_cellsz_host_line/input/jongbu_law.hwpx`는
1쪽 글 뒤 그림에 공통 개체 크기 `5668×5668 HU`, 도형 요소 현재 크기 `10202×12280 HU`와
저장 아핀 행렬을 함께 가진다. 한컴 2018 Print 기준은 같은 폴더의 기존 PDF다. PDF를 다시
생성하지 않았다. 그림의 합성 축 배율은 약 `0.555×0.461`이며 원래 요소 크기에 이 배율을
적용한 규모는 공통 개체 크기에 가깝다. 이 관측은 소수 행렬을 특정 임계값으로 비교하는
조건으로 사용하지 않는다.

[HWP 5.0 설명본](../tech/한글문서파일형식_5.0_revision1.3.md) 표 69는 공통 개체의
폭·높이, 표 83과 84는 도형 요소의 현재 크기와 별도 변환 행렬을 구분한다. 원본에 유효한
아핀 기하가 있는 독립 비인라인 그림은 변환 전 요소 크기를 개체 틀로 다시 키우지 않고
공통 크기를 측정·배치의 `picture_flow_frame_size_hu`에서 공유한다. 상대 크기 속성은 기존
`stored_picture_size_hu` 계약을 따른다. 인라인·묶음 자식·행렬 없는 경우는 기존 경로를 유지한다.
이 조건의 나머지 입력도 독립 출력과 대조해 검증해야 한다.

## 현재 검증 범위

- 고정 기준 `ad4bf269ffef5adf2142b33004a9981fad7ce804`, 이전 #7905 후보 `2ea4a0ae45ac15d2ca000088b13b5f243cb7be39`,
  변경 후보 Native 바이너리 SHA-256
  `ef4fc6d9db0c0dfc175c909a11d28023b7b35e9d8bd7ceb831cd4866d7f848ee`.
- 같은 96dpi 기준 PDF와 글꼴 경로로 측정한 #7905 1쪽 Native raw 표시값은 기준 91.44%,
  이전 후보 90.72%, 이 후보 98.90%다. 기존 후보 대비 2~6쪽 표시값은 변하지 않았다.
  기준 대비 3·4·6쪽은 각각 0.28·0.24·0.05%p 하락한 상태로 남는다. 1쪽 overlay에도
  본문 한 줄과 QR의 잔여 차이가 있어 점수만으로 시각 완료로 판정하지 않는다.
- `picture_flow_frame_` 단위 검사 5건은 통과했다. 양 편람에서 중요한 19쪽을 Native로
  확인한 결과 130쪽 99.96%, 나머지는 표시값 100.00%를 유지했다. 이는 전쪽 검증이 아니다.
- #8188의 HWPX, HWP 2024, HWP 2022는 각각 Native 64쪽 raw 표시값이 이전 후보와 모두
  같았다. fresh WASM 경로와 이 변경 이후 편람 전쪽 검증은 아직 완료하지 않았다.

3·4·6쪽의 원인과 전체 영향 범위, 해당 후보의 Native·fresh WASM 전쪽 검증, 기존 그림의
반례와 최종 회귀·lint를 확인하기 전에는 PR 준비 완료로 판정하지 않는다.
