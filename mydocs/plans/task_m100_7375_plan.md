## 선행 구현과 판정할 항목

1. HWP5 개정 1.3 사양 표 94는 사각형 곡률을 백분율로 정의한다. 직각 0·둥근 모양 20·반원 50을
   원본 바이트·HWPX ratio·model·저장·공통 RectangleNode·각 backend의 소비 경로로 대조한다.
2. 기존 model과 파서에는 `round_rate`가 있으며, `dfd9c384c6ea164c808b77b91d0e4ced51f7e205`는
   50% 반지름을 짧은 변의 절반으로 출력하도록 보정했다. 기존 구현 존재만으로 완료 판정하지 않는다.
   PR #7611은 미병합이며, 실제 반영은 PR #7832의 병합 커밋
   `bfa28a77a2714482f647ee6a7b9aa7f7876d8404`로 확인했다. 독립 출력 근거도 대조한다.
3. 원 이슈의 추가 댓글은 27·28쪽 번호 도형의 독립 hit-test·선택 주소·드래그·Ctrl+Z/Command+Z를
   별도 수용 조건으로 요구한다. #8578의 묶음 글상자 보정으로 이 조건도 해결됐다고 가정하지 않는다.

## 실행 순서와 완료 조건

- 고정 base의 원본 19·27·28·41·43쪽을 먼저 Native Visual Sweep·render tree로 확인한다.
- 실제 Studio에서 27·28쪽 번호 도형의 클릭·독립 선택·이동·되돌리기를 확인한다.

  중첩 도형·표 셀의 적용 경계를 검사한다. 관련 기존 회귀의 보호 의도는 유지한다.
- 조판 변경이 필요하면 관련 전체 Native/fresh WASM TSV·직접 raw/review/overlay, 원본과 같은 쪽수,

  이슈 종료·PR 제출·통합은 별도 원격 승인 조건과 정본 절차를 따른다.
