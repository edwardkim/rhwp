## 1. 목표

한컴 공식 단축키 계약에 맞춰 F5 셀 블록 상태의 `Ctrl/Cmd+Shift+S`는
`table:block-sum`으로 보내고, 셀 블록 밖의 같은 키는 기존 `file:save-as`로 유지한다.
수정자 없는 `S`의 `table:cell-split` 동작과 embed 프로파일의 파일 수명주기 단축키 차단도
보존한다.

## 2. 최신 devel 조사 결과

1. `shortcut-map.ts`에는 `Ctrl+Shift+S`가 `file:save-as`와 `table:block-sum`으로
   중복 등록돼 있고, `matchShortcut()`은 첫 매칭인 `file:save-as`만 반환한다.
2. 실제 F5 셀 선택 경로에서는 매처보다 앞선 수정자 무관 `S` 분기가
   `table:cell-split`을 실행한다. 따라서 이슈 본문의 UI 결과는 검증되지 않았고,
   영문 키보드에서는 셀 나누기로 빠질 수 있다.
3. #4564 embed 프로파일은 숨긴 `file:save-as`가 후순위 `table:block-sum`으로
   폴스루하지 않는 것을 기존 계약으로 둔다.
4. `table:block-sum` 구현은 현재 선택 범위가 아니라 현재 셀의 `=SUM(above)`를 실행한다.
   #4135에서는 단축키 라우팅만 바꾸며, 선택 범위 계산 의미가 공식 한컴 동작과 다르면
   실제 브라우저 관찰을 근거로 연결 이슈를 분리한다.

| embed, F5 셀 블록, `Ctrl/Cmd+Shift+S` | 파일/표 명령 모두 실행하지 않고 브라우저 기본 저장 차단 |

## 4. 구현 범위

### 포함

1. 키 이벤트와 현재 단축키 소유권을 입력으로 받는 순수 문맥 라우터를 추가한다.
2. F5 셀 블록 라우터를 IME 조기 반환과 수정자 없는 `S` 처리보다 먼저 실행한다.
3. 수정자 없는 `M`/`S` 셀 명령에 Ctrl/Meta/Alt 가드를 추가한다.
4. `file:save-as`에 물리 `KeyS` 보정을 추가해 IME 조합 상태의 셀 블록 밖 저장을 유지한다.
5. 일반 단축키 표의 도달 불가 `table:block-sum` 중복을 제거하고 충돌 회귀 테스트를 추가한다.
6. full/embed, Ctrl/Meta, 영문/한글/Process 입력의 라우팅 회귀를 추가한다.

### 제외

- `table:block-sum/avg/product`의 선택 범위 계산 알고리즘 변경
- 모든 단축키를 후보 목록으로 바꾸는 `matchShortcut` 계약 전면 개편
- embed 프로파일의 파일 수명주기 정책 변경
- Rust/WASM API 변경

## 5. 단계

### Stage 1 — RED와 실동작 기준선

현재 단축키 표와 키보드 분기 순서를 focused Node 테스트로 고정하고, 실제 브라우저에서
F5 셀 선택의 영문 `Ctrl+Shift+S` 결과와 셀 블록 밖 Save As 결과를 확인한다.

### Stage 2 — 최소 문맥 라우팅

순수 resolver와 조기 dispatch helper를 추가하고, 수정자 없는 셀 명령과 일반 Save As의
기존 동작을 보존한다. embed에서는 `file:save-as` command availability를 단축키 소유권으로
사용해 후순위 표 명령 폴스루를 차단한다.

### Stage 3 — 회귀와 브라우저 검증

focused Node 테스트, TypeScript 검사, Studio 전체 Node 테스트를 순서대로 실행한다.
실제 브라우저에서는 셀 블록/셀 편집/표 밖과 full/embed를 확인한다.

### Stage 4 — 기록과 PR 준비

단계 보고서와 최종 보고서를 작성하고 오늘할일을 완료로 갱신한다. `git diff --check`,
`cargo fmt --all`, `cargo fmt --all -- --check`를 통과시킨 뒤 로컬 커밋까지 준비한다.
원격 push와 PR 생성은 작업지시자의 별도 승인을 받기 전에는 수행하지 않는다.
