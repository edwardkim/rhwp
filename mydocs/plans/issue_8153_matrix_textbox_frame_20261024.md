# #8153: 행렬 글상자의 저장 줄 프레임 수용

## 원 해결과 독립 반례

원 PR #1681은 그룹 행렬 중복 적용과 행렬 크기에 맞지 않는 글상자를 보정했다.
원본 `7f9a10263908`·`dff4695898dc`를 `c279f7d93c`·`3500d8e64`로 체리픽했고
통합 PR #1704의 `82e2e3f1917c9c4fe1e2cbbbac096885e4165752`로 반영했다.
`mydocs/pr/archives/pr_1681_review.md`와 실제 PR 본문·댓글을 확인했다.
당시 글상자 재조판은 경험적 보정이며, `36392900` 라운드트립과 합성 AB 검사로
내부 정합성을 확인했다. 그 검증을 독립 Print 일치 증거로 확대하지 않는다.

현재 편람 HWPX 161쪽 `instid=568445309`는 원본 저장본이다. 두 문단의 저장
LineSeg는 각각 textpos 0/8이며, 폭은 모두 5932 HU다. 마지막 문단의 저장
`표 사이 간격 ` / `1㎜` 구분은 독립 한컴 2024 Print에서도 두 줄이다.
현재 실제 Native는 이를 한 줄로 합쳐 글상자 전체가 4줄에서 3줄로 바뀐다.
`934aae310d`의 실제 내용 폭은 79.0933px, 즉 96dpi에서 5932 HU다.
저장 폭과 현재 프레임이 같은데 높이·행렬 조건만으로 저장 구분을 버리는 반례다.

HWP 5.0 revision 1.3의 표 90·줄 세그먼트 정보와 프로젝트의 공통
`ParagraphBox`/`LayoutFrame` 수용 계약을 따른다. 실제 문서에 없는 개행을 추가하거나
도형 높이·글자 크기를 줄여 맞추지 않는다. 원본·PDF 해시는 #8153의 고정값을 유지한다.

## 공통 결과와 적용 범위

현재 행렬 글상자 진입 경계에서 선택된 문단을 공통 문단 프레임에 대조한다.
`ParagraphBox::content_for_style`이 문단 여백·공식 내용 폭 격자를 계산하고,
기존 composer의 `stored_rows_reproduce_frame_expectation`이 실제 줄 프레임을
구성해 저장 원점·폭과 정확히 비교한다. 텍스트 구분이 dirty이거나 구현이 생성한
줄은 원본 저장 증언으로 수용하지 않는다.

원본 저장 프레임이 수용되면 글자 구분·메트릭을 유지한다. 폭이 바뀌어 수용하지
못하면 기존 공통 `reflow_line_segs`로 엄격히 재조판한다. 지역의 3px fit 허용과
한 줄 강제 합침은 제거한다. 그룹 변환·점 좌표·도형의 선/채움 규칙을 다시 구현하지 않는다.

기존 높이·행렬 진입 경계를 이 단계에서 문서 전체의 새로운 수용 규칙으로 확대하지
않는다. 특히 세로쓰기와 Y 방향만 변한 장 표지 글상자의 기존 별도 계약을 보존한다.
공통 프레임이 재조판과 저장 구분 유지를 결정하며 backend별 예외를 두지 않는다.

## 검증 계획

- 같은 원본·독립 Print에서 실제 161쪽의 4줄, 소유·문자 순서와 확대 PNG를 대조한다.
- 폭이 같은 합성 저장 구분 유지와 폭 변경 후 재조판을 공통 frame의 양쪽 경계로 확인한다.
  합성 결과를 한컴 시각 일치로 보고하지 않는다.
- 원 PR의 실제 `36392900` 라운드트립 보호를 확인한다. 독립 Print가 없는 입력의
  내부 라운드트립 통과는 별도 계약으로 기록한다.
- 바탕쪽 Y 방향 글상자와 영향 36쪽, 원본 전쪽 Native/fresh WASM, PR #8148 corpus를
  대조한다. 프레임의 생산 → 수용 → 재조판 → 글상자 높이·문단 배치까지 함께 확인한다.
- 기존 AB 검사는 실제로 저장 폭 16856 HU와 현재 6000 HU의 불일치를 재조판하는
  사례다. 단순 높이 초과만으로 저장 줄을 합치는 계약으로 해석하지 않도록 이름·설명을 고친다.

현재는 원인·적용 계획 단계다. 새 source의 실제 Native/WASM·정식 회귀·전쪽 100%는
완료되지 않았다. 자료는 ignored 작업 루트의 `pr1681-original-20261024.json`,
`rectangle-overlap-934aae310d/p161-remaining-spacing-textbox-source.json`,
`p161-remaining-spacing-textbox-consumer.json`, `p161-remaining-title-review.png`에 둔다.
