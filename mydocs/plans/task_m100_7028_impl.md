## 1. 구현할 규칙

표 전체가 페이지 분할됐다는 이유로 셀 테두리 의미가 사라지면 안 된다.
**현재 표시 조각에 온전하게 포함된 셀은, 일반 표와 같은 셀 상자 기준으로 대각선을 그린다.**
반복 제목 셀도 이 규칙의 동일한 소비자다. 제목행 여부로만 사선을 허용하지 않는다.

1. 원본 셀 행 구간이 현재 표시 행 목록에 연속해서 모두 포함되는지 확인한다.
2. 해당 셀에 내용 cut·행 높이 override·rowspan의 페이지 경계 잘림이 적용되는지 확인한다.
   한 행의 다른 셀이 잘려 행 단위로 분할 정보가 온 경우도 이번에는 보수적으로 제외한다.
3. 온전한 셀에는 기존 `render_cell_diagonal`을 호출한다. 좌표는 현재 페이지의
   `cell_x/y/w/h`이며, 원본 페이지 y·텍스트 영역·사후 확장된 clip bbox를 사용하지 않는다.
4. 가로쓰기와 세로쓰기 모두 Cell 내용 뒤, 같은 Table의 자식으로 선을 한 번 방출한다.
5. 선 방향·종류·굵기·색·꺾은선·중심선·선 없음은 공통 생성기 판단을 그대로 사용한다.

## 2. 이번에 변경하지 않을 계약 — 승인 필요 경계

실제 잘린 셀을 조각의 대각선으로 새로 그리면 원본 선의 기울기가 바뀔 수 있다.
이번 실물은 대각선 지정이 온전한 r0c0 한 곳뿐이어서 이를 판정할 근거가 없다.
따라서 **실제 cut/height override/rowspan 경계 셀에는 대각선을 새로 방출하지 않는다.**
이는 해당 유형의 누락까지 해결했다는 뜻이 아니라 기존 출력 유지다.

분할 cell zone도 현재 렌더 경로가 없고 본 샘플의 zone 수는 0이다. 대각선/중심선이 활성인
유효 zone과 겹치는 셀에는 이번 셀 단위 방출을 적용하지 않아 zone 전체 사선을 작은 셀
사선으로 오인해 그리지 않는다. 활성 zone과 무관한 온전한 셀은 처리한다.
전체 표에 zone이 하나라도 있다는 이유로 모든 셀을 제외하는 광역 조건은 쓰지 않는다.
일반 표의 기존 zone·셀 중복 및 개별 덮어쓰기 규칙은 변경하지 않는다.

이 두 경계를 포함한 부분 범위를 명시적으로 승인받는다. 변경 범위를 실제 분할 셀·zone까지
확장하려면 정상 한컴 출력 근거와 별도 구현계획 보완이 먼저이며, 임의의 합성 문서로
기대 결과를 만들어 정답으로 삼지 않는다. 하위 이슈 자동 생성은 하지 않는다.

## 4. 검증 순서

### 4.1 실물 회귀

- 현재 원본을 파싱해 78×5, 반복 활성, leading_header_rows=[0], BF13 사선 속성을 먼저 assert한다.
- 실제 6쪽 모두에서 첫 행 5개 셀과 r0c0을 찾아, 셀 모서리를 잇는 검정 실선이 **정확히 한 번**
  있는지 RenderTree/SVG로 검사한다. 단순한 페이지 전체 Line 개수 증가는 합격 조건이 아니다.
- 첫 행 높이 약 52.4px, 첫 쪽과 후속 쪽 y, 전체 6쪽 및 셀/텍스트 기하 보존을 함께 확인한다.
- 같은 테스트를 수정 전 소스에서 실행해 대각선 assertion 실패를 확인하고, 수정 후 통과시킨다.

### 4.2 보호 반례

- 제목행 반복 끄기: 첫 페이지 사선은 유지하고 후속 페이지에 원본 첫 행을 새로 만들지 않는다.
- 사선 없음/type=0: 선을 생성하지 않는다.
- 제목 셀이 아닌 온전한 셀, 온전한 rowspan 셀, 세로쓰기: 표 분할 여부만으로 누락하지 않는다.
- 실제 cut·높이 override·rowspan 경계: 이번 변경으로 새 사선이나 페이지 밖 선이 생기지 않는다.
- 활성 cell zone 영향: 기존 분할 출력 유지, 관련 없는 셀까지 제외하지 않는다.
- 기존 #1716 제목행 4개, #2146 셀 높이, #1623/#1633 zone·중심선 테스트 재사용.

메모리상 모델 변형 테스트는 분기 계약 검사로만 사용한다. 한컴 호환 정상 샘플로 선언하거나
실물 시각 판정의 정답으로 쓰지 않는다. fixture 없으면 skip/return하지 않고 실패시킨다.

### 4.3 시각 및 최종 게이트

- 먼저 1·2·6쪽 before/after/한컴 및 프로젝트 표준 비교 자료로 사선 끝점·글자와의 겹침을 확인한다.
- 기존 제목 라벨 배치·폰트·본문 행높이 차이는 baseline 원장과 대조해 변경 영향과 분리한다.
  대각선만 추가하고 문서 전체가 한컴과 일치한다고 보고하지 않는다.
- 메인테이너 SVG 판정 후 Docker WASM/Studio 판정을 받는다.
- 최종 제출 전 영향 회귀·OVR 및 AGENTS.md/local_validation.md §4.3 Rust lint 3종·workspace
  build·suite 정합성을 실행한다. 전체 CI 성격의 긴 검증은 해당 단계 승인 후 진행한다.

## 5. 완료 판정

온전한 분할 표 셀과 반복 제목 셀에서 기존 대각선 계약이 살아나고, 보호 반례·기하·회귀가
유지되어야 한다. 실제로 잘린 셀·분할 zone 지원은 완료 목록에 넣지 않는다. 결과 보고서·PR에
이 경계를 명시하며 전체 대각선 지원 완료로 확대 해석하지 않는다.
