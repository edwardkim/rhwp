## 확인과 구현 범위

기본 CLI/MCP의 행·열 표 생성은 이미 존재한다. 현행 head로 빌드한 CLI에 `--widths`를 전달하면
`알 수 없는 옵션: --widths`와 exit 2가 나온다. 열별 너비·정렬·필드 기준 위치 옵션은 없고 코어
생성 IR의 `repeat_header`는 false다. 따라서 #5819의 추가 요구는 남아 있다.

기존 코어 생성 경로에 선택 옵션을 추가한다. 기존 코어 호출 기본값은 보존하고, CLI/MCP 생성은
반복 머리행을 기본 true, 페이지 나눔을 CELL로 지정한다. 너비는 HWPUNIT 또는 합계 100% 비율,
정렬은 열별 left/center/right를 받는다. 공통 MCP argv 배선에서 값을 받는 bool false는 전달하고
presence flag false는 계속 생략한다.

`--at-field`는 필드를 보존하고 해당 본문 문단 바로 뒤에 독립 표를 생성한다. 이름의 유일성을
확인하고 좌표 옵션과의 혼용을 거부한다. 표 셀·글상자 내부 필드는 기존 본문 표 생성 범위에
포함하지 않으며 명시적으로 거부한다. 이슈의 실제 235쪽 템플릿은 첨부되지 않아 그 파일의
전체 동작·렌더링을 검증했다고 주장하지 않는다.

## 검증 순서

1. 저장소의 HWP/HWPX 필드 fixture에서 실제 CLI 실행 및 재파싱으로 폭·정렬·필드·머리행 보존 확인.
2. invalid/dry-run의 입력·기존 출력 보존, 실제 MCP tools/call의 false 전달과 생성 확인.
3. 기존 표 생성·열 너비·MCP 옵션 계약 focused 회귀, Rust lint 묶음, 전체 release-test 회귀.
4. 문서·입력 경로와 Git commit blob의 일치를 기록한다. 원격 PR 생성·이슈 close는 별도 요청에 따른다.
