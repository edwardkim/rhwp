# #7642 자동 저장 경계 유효성의 전체 소비 경로

Issue: #7642.

0e7f112db0 Native 컴파일은 성공했으나 온새미로 원본은 47쪽이다.
실제 추적에서 138문단은 42쪽의 흐름 끝 864px로 진입한다. 문단 진입의 옛 reset은
거절했지만 `whole_fit::inspect`가 같은 저장 되감김을 다시 강제한다.
이 소비 누락을 구현 오류로 보정한다. 독립 Print는 42쪽에 138문단 첫 줄,
43쪽에 나머지 세 줄을 둔다. 기준이나 기대 쪽수를 변경하지 않는다.

같은 `stored_frame_prefix_consumed_before_page` 판단을 문단 진입, 전체 fit,
분할 진입과 자동 내부 경계 후보에 전달한다. 각각 별도 수치로 재추정하지 않는다.
명시적 page-start·쪽/단 나누기와 독립적인 표·각주 경계는 그대로 보존한다.
큰 기존 paragraph 모듈은 전체 수용 조정 함수를 자식 모듈로 옮겨 1000줄 아래로 유지한다.

새 Native/fresh WASM의 원본 두 형식·NO_LS 진단·정상 대조군과 전체 102문서,
#7969·#7970 보존 검증을 계속한다. 원래 테스트를 완화하지 않으며
전쪽 90% 이상과 확대 판독 전에는 실물 회귀를 새로 고정하지 않는다.
