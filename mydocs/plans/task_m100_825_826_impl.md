### 단계 2 — GREEN #826 (PUA substitution)

**목적**: 한컴 PUA U+F080F + U+F0827 을 표준 Unicode 로 render-time substitution.

**작업**:
1. Substitution map 정의 (Stage 1 에서 결정한 위치 — 예: `src/renderer/pua_substitution.rs` 또는 `rhwp-studio/src/core/pua-substitution.ts`):
   ```rust
   pub fn substitute_pua_for_render(text: &str) -> Cow<'_, str> {
       if !text.chars().any(|c| matches!(c as u32, 0xF080F | 0xF0827)) {
           return Cow::Borrowed(text);
       }
       Cow::Owned(text.chars().map(|c| match c as u32 {
           0xF080F => '\u{2501}',  // ━ HEAVY HORIZONTAL
           0xF0827 => '\u{25A0}',  // ■ BLACK SQUARE (잠정 — 시각 검증 후 조정)
           _ => c,
       }).collect())
   }
   ```
2. 측정 + 그리기 호출 직전에 substitution 적용
3. `cargo test issue_826` PASS 확인
4. `mydocs/working/task_m100_825_826_stage2.md` (변경 diff + 테스트 결과)
5. 커밋: `Task #826 Stage 2 (GREEN): PUA U+F080F/U+F0827 render-time substitution`

**산출물**: 신규/수정 substitution 파일, `_stage2.md`
