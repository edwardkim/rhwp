## 1. 이슈 요약

`samples/hwp3-sample10-hwp5.hwp` (한컴이 HWP3 → HWP5 변환한 파일) 의 image 가 rhwp 에서 placeholder (회색 점선 사각형) 만 표시. HWP5 변환 시 한컴이 image 를 외부 file 참조 (BinDataType::Link, `abs_path` = `C:\Users\admin\Desktop\hwp3sample\rdb02.gif` 등) 로 저장하나 rhwp HWP5 파서가 Link 타입을 적절히 처리하지 않아 `Picture.image_attr.external_path` 미설정. Task #741 의 `populate_external_images_from_dir` fallback 이 동작하지 못함.

**선행 의존**: PR #869 (Task #860 + Task #864 통합) 머지 가정. 현재 `local/task864` 에서 분기.

## 2. 결함 영역

### 결함 — HWP5 BinData Link 타입 → Picture external_path 미전달

1. **`src/parser/mod.rs:372`** — `load_bin_data_content_lenient` 가 `BinDataType::Link` 일 때 `continue` skip → BinDataContent entry 미생성
2. **`src/parser/control/shape.rs:857`** — `parse_picture` 가 `bin_data_id` 만 읽고 `external_path` 미설정
3. → `pic.image_attr.external_path = None` → `populate_external_images_from_dir` (Task #741) fallback 가 picture 의 외부 file 인식 못 함

## 3. 사전 진단 (Stage A 검증 영역)

### 가설 A — `BinDataType::Link` 의 `abs_path`/`rel_path` 가 정확히 파싱됨

`src/parser/doc_info.rs:241~244` 의 `BinDataType::Link` 분기가 `abs_path`, `rel_path` 를 정상 읽음. 검증: hwp3-sample10-hwp5.hwp 의 DocInfo BinData 의 `abs_path` 값 확인.

### 가설 B — Picture 의 `bin_data_id` 가 DocInfo BinData 의 1-based index 매칭

`pic.image_attr.bin_data_id` 가 DocInfo BinData list 의 index + 1 (1-based) 와 매칭. 검증: HWP5 spec + 실제 파일 dump 비교.

### 가설 C — `populate_external_images_from_dir` 가 HWP5 에도 자동 동작

Task #741 의 fallback 은 Document IR 의 `image_attr.external_path` 만 의존. 포맷 무관. HWP5 가 external_path 만 설정해 주면 fallback 자동 동작.
