# #8153: 가운데 정렬에서 마지막 글자 뒤의 양수 자간 제외

## 원본·독립 출력과 원인

179쪽 `발신명의`는 section5 글자 모양 68의 15pt·장평 100%·자간 50%·굵게다.
원본의 속성은 바꾸지 않는다. 독립 Print는 첫 글자 원점 235.799988pt,
기준선 550.919983pt이며 96dpi에서 각각 약 314.4px·734.56px이다.
현재 실제 paint 원점은 310.053333px·734.56px다. 기준선은 같고 가로만 어긋난다.
독립 Print의 뒤 글자 원점도 255.479996·275.040009·294.720001pt로 확인했다.

`4e13df5681`에서 공유한 `CenteredTextLineMeasure::width`는 마지막 글자의
자간 없는 폭과 실제 전진의 차이를 `max(0)`으로 더한다. 음수 자간만 처리하고,
양수 자간은 마지막 글자 뒤에도 정렬 점유로 남겨 중심을 왼쪽으로 밀어낸다.
기존 `terminal_tracking_for_alignment`는 부호를 보존하지만 가운데 정렬에서는
공통 측정 결과가 우선되므로 그 뒤의 다른 계산으로 보정되지 않는다.
확인한 생산 → 측정 → 배치 경로는 `CenteredTextLineMeasure::width` →
폭 맞춤/압축 결정 → `x_start`의 가운데 정렬 원점이다.

## 공통 처리와 검증 계획

사양의 글자 자간 속성과 독립 Print의 마지막 glyph 끝을 기준으로 처리한다.
정렬 폭에서 마지막 가시 glyph 뒤의 자간을 부호에 관계없이 제외한다.
glyph 사이 전진과 원본 문자는 그대로 유지하며 문서별 이동값을 추가하지 않는다.
음수·0 자간, 말미 공백, 장식 공백, 탭·개체의 기존 계약도 함께 확인한다.

독립 PDF 원점 ±2px와 쪽/내용/셀 포함 관계로 실제 원본의 수정 전 실패를 확인한다.
양수 자간의 공통 경계 검사를 추가하고 이전 음수 자간 경계를 실행한다.
현재 후보의 Native/fresh WASM 전쪽 검증과 구분하며 이 문서는 아직 구현 완료나
실제 출력 개선의 기록이 아니다. SO 분석과 진단 layer JSON은 ignored output에만 둔다.
