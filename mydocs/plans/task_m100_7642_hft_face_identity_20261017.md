# #7642 독립 HFT 표본의 요청 face 보존

Issue: #7642.

독립 전체 한글 표본을 engine 2020의 PrintMethod 0으로 출력했다.
7쪽·11,172자의 원 윤곽에서 복원한 기본 한양신명조 프로그램은 언어 문서
15쪽의 Type3 프로그램과 일치하지 않았다. 비슷한 이름을 근거로 그 글꼴을
HY신명조의 대체물로 공급하지 않는다. 기준 PDF·기존 출력은 보존한다.

원 문서는 HY신명조와 한양신명조를 구별한다. 기존 표본 도구는 한양신명조만
요청하고 결과 이름도 고정하므로 다른 face의 실제 프로그램을 검증할 수 없다.
표본 생성과 복원 양쪽에 명시적인 요청 face를 전달하고 provenance와 생성
글꼴의 이름에 그대로 보존한다. 전체 한글 순서·Type3 행렬·원 윤곽 보존·일반
문서 PDF 거부 조건은 유지한다. 생성 글꼴의 이름은 실제 프로그램 동일성의
증거가 아니며 독립 표본과 대상의 읽기 전용 윤곽/전진 대조가 먼저다.

기본 동작의 호환, 다른 face의 전체 표본과 provenance, 잘못된 face 거부를
단위 검사한다. HY신명조 독립 표본의 실제 한컴 Print와 원 프로그램 비교,
검증된 face만 공급한 같은 조건의 base/head Native/fresh WASM을 실행한다.
글꼴·표본 PDF는 저장소 밖 로컬에 두며 일반 Studio 공급 환경과 구분한다.
