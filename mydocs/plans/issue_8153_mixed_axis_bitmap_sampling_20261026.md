# #8153: 축별 확대·축소 그림의 공통 Print 표본 소비

## 원래 계약과 독립 근거

앞선 공통 표본 구현 `4c7d2250e6`, 확대 지원 `4319f3ff38`, 장치 영역 보정과
[기존 계획](issue_8153_print_image_coverage_20261024.md)을 먼저 대조했다.
HWP/HWPX의 영역 맞춤·전체 채움은 원본 그림 전체를 목적 사각형에 대응한다.
확대·축소 표본은 파일 사양의 조판 좌표와 구분하는 출력 계약이다. 기존 공개 PDFium
참조 구현과 독립 2024 Print를 사용하며 원본·PDF·측정 임계값을 바꾸지 않는다.

239쪽의 그림 틀은 투명하지 않은 PNG 여덟 조각과 별도의 중앙 캡처로 구성된다.
두 형식의 기존 Native는 독립 Print의 모서리 (626, 623)에 대응하는 잉크 1픽셀이
부족하다. 표준 fresh WASM은 같은 모서리와 닫힘 선을 포함해 364픽셀이 부족하다.
이 중 361픽셀은 y=886의 닫힘 선이다. 가로 띠 원본은 80×25인데 목적은 약
505.578×4.966px로, 한 축은 확대하고 다른 축은 축소한다.

고정 `7620cc75`의 실제 공개 WASM 바인딩으로 원본 여덟 조각을 공통 샘플러에
전달했다. 기존 일반 bitmap 준비는 축 하나라도 확대면 네 띠를 거절하지만, 이미 있는
Print 샘플러는 혼합 축을 지원한다. 그 결과는 독립 Print의 닫힘 선 회색 216과
모서리 회색 209에 각각 일치했다. 이것은 분리한 원본 표본의 진단이며, 실제 페이지의
수정 후 출력 통과로 확대하지 않는다.

## 원인 계층과 공통 소비

`원본 fill mode·효과·변환·전체 source 창 → print_area_sampling 판정 → 최종 장치
사각형 → 기존 공통 RGBA 표본 → Native/Canvas2D/CanvasKit`을 대조했다.
현재 판정은 일반 JPEG Picture만 허용해 PNG 영역 채움을 건너뛴다. 이후 일반 준비의
거절로 Native의 mipmap과 Canvas 필터가 서로 다른 표본을 소비한다.

같은 원본 전체를 사용하는 PNG/JPEG의 `FitToSize`/`Total`을 공통 판정에 포함하는
방향을 검증한다. 기존 `device_image::eligible`의 동일한 전체 원본 계약을 재사용한다.
일반 PNG Picture는 기존의 가시 팔레트별 재구성 계약을 유지한다. 이를 보호하는
`verified_print_bitmap_visible_palette.rs`도 정상 대조에 포함한다.
페이지·문서 ID·특정 폭·색상에 따른 분기를 만들지 않는다. 기존 공통
샘플러의 수학·장치 영역·임계값을 바꾸지 않는다. 명시적 PDF interpolation 선언,
반복·자연 크기·Zoom·crop·회전·효과는 기존 계약을 유지한다. alpha가 있는 원본은
이미 있는 샘플러의 불투명성 검사에서 거절하고 기존 출력 경로로 돌아간다.

## 실제 재현과 검증 순서

1. 고정 `89b929b8` 라이브러리에 연결한 두 실제 원본의 Native 검사는 239쪽의
   독립 모서리 (626,623) ±2px 안의 잉크 누락으로 각각 FAIL했다. 빌드 실패나
   글꼴 오류가 아니다. 같은 검사를 실제 후보에서 다시 실행하고 여덟 조각의 소유·
   누락·중복, 네 모서리·두 가로 띠·두 세로 띠의 관계도 보호한다.
2. 정식 원본은 `tests/cases/issue_8153_opaque_mixed_axis_image_sampling.rs`에 둔다.
   Native CI의 실제 수집 경로와 테스트 tier 정책을 확인한다. 소스 `cfg(test)` 모듈을
   추가하는 include 방식은 정책 검사에서 거절돼 제거했다. 현 Native CI는 제한된
   integration 사례만 선택하므로 새 feature 전용 검사의 실행 누락을 확인했다.
   최종 제출 전 CI 호출 추가 기준 5.3.1에 따라 필요한 최소 수집 경로를 마련하고
   실제 실행을 확인한다. 기본 수집에 이미 포함된 검사를 중복 호출하지 않는다.
3. 두 원본의 239쪽 및 기존 PNG 그림 경계·JPEG·그룹·crop·명시적 interpolation의
   정상 대조를 확인한다. Native/fresh WASM의 해당 페이지 TSV와 확대 PNG를 직접
   비교한다. 기준 `7620cc75`의 전쪽 최저는 Native 99.45644%, WASM 99.25584%다.
4. 실제 후보 전쪽 766조건씩을 같은 원본·독립 PDF로 검증한다. 새로운 미대응 증가를
   분석·보정하고 모든 1,532조건 raw 100%·미대응 0과 필수 테스트를 완료한다.

ignored 작업 자료는 `output/pr-review/issue8153-handbook-raw100-20261022/`의
`remaining-raw100-diagnostic/p239-*`와 `handbook-mixed-axis-image-candidate/`에 있다.
분리 원본·공개 샘플러 진단을 완성된 페이지 검증으로 세지 않는다. 사용자 지시대로
upstream/devel 동기화·원격 게시·push·PR 생성 없이 PR 준비까지만 마친 뒤 대기한다.
