## 2. 가설 (조사 후보)

순서대로 검증한다. 코드 수정 없이 dump/svg 비교로 좁힌다.

1. **셀 baseline 계산식 차이** — `paragraph_layout.rs` / `table_layout.rs` 의 cell paragraph baseline 산식이 본문 paragraph 와 차이가 있는가?
2. **CharShape 세로 시프트(vert)** — ps_id=90 / cs(글자모양) 의 vertical shift 속성이 표 셀에서 상이하게 적용되는가?
3. **valign=Top + padding 처리** — 셀 padding(283,283,283,283) + 외부 padding(510,510,141,141) 적용 순서/누락 여부.
4. **㉠/㉡ 글리프 메트릭 의존성** — HY중고딕 폰트의 U+3220/U+3221 글리프 메트릭이 일반 한글과 다르게 출력되어 baseline 위치가 위로 보이는가?
5. **본문 스케일 처리 누락** — 본문에서는 `scale(0.95,1)` (장평 95%) 트랜스폼이 적용되는데 표 셀 ㉠/㉡ 라인에는 미적용. 셀 내 글자 시프트는 그 부수효과일 가능성.

가장 유력한 후보는 **5번** (본문 vs 표 셀의 transform/scale 처리 분기 차이) 와 **1번** (table cell paragraph baseline). SVG 출력에서 본문 ㉠ 은 `transform="translate(...) scale(0.9500,1)"` 형태이지만 표 셀 ㉠ 은 단순 `text x= y=` 형태로 다르게 출력된다.
