## 목표

rhwp-studio의 배율과 쪽 배치 상태를 분리하고, 한컴오피스 한/글과 대응하는 `자동`, `한 쪽`,
`두 쪽`, `맞쪽`, `여러 쪽` 보기 설정을 제공한다. 기존 축소 다중 열 동작은 `자동`의 기본 동작으로
보존한다. Windows 한글 2024의 `쪽 이동` 계약에 맞춰 세로·가로 이동을 제공하고, 상황 선의 배율
컨트롤 순서와 진입점을 같은 사용 흐름으로 정리한다.

## 변경 범위

1. 문서 내용과 독립적인 `PageArrangement` 사용자 보기 상태를 추가한다.
2. `VirtualScroll`에 자동·고정 한 쪽·연속 두 쪽·맞쪽·사용자 지정 여러 쪽 배치를 구현한다.
3. `여러 쪽`의 1×1~8×8 입력을 검증하고 선택한 가로×세로 쪽 수가 뷰포트에 들어오는 배율을 계산한다.
4. 상태 표시줄 배율 표시와 `보기 > 화면 확대/축소`가 같은 설정 대화상자를 열도록 연결한다.
5. 모드 전환 뒤 현재 쪽, 클릭 좌표, PageUp/PageDown과 기존 자동 그리드 좌표 계약을 검증한다.
6. 보기 설정 변경이 문서 dirty 상태나 HWP/HWPX 저장 데이터에 영향을 주지 않도록 분리한다.
7. `쪽 이동`의 세로 방향을 기본값으로 두고, 가로 방향에서는 한 쪽 배치와 선택적 세로 휠→가로
   스크롤 변환을 적용한다.
8. 상황 선을 맞춤·축소·배율 슬라이더·확대·통합 배율 설정 버튼 순서로 구성하고 모든 배율 진입점의
   상태를 동기화한다.
9. 배율 가로바는 10~500% 범위와 중앙 100% 눈금을 제공하고 드래그 시 100%에 스냅한다. 확대·축소는
   macOS에서 `Command +/-`, Windows·Linux에서 `Ctrl +/-`를 사용하며 호버 안내도 플랫폼에 맞춘다.
