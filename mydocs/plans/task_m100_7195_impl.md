# #7195 구현계획 — 중첩 표 owner 너비의 유효 안 여백 반영

## 승인과 범위

2026-09-16 작업지시자가 바깥 표의 ‘모든 셀의 안 여백’ 좌우 1.80mm를
중첩 표 너비에 적용하는 방향을 확인하고 코드 구현·검증 시작을 지시했다.
앞선 stage2는 `f0d6966b6`에 커밋되어 있다. 이번 절편은 #2308의 너비 불일치를
수정하며 #2279/#3798, 원격 게시, PR, 전체 CI 게이트는 변경하지 않는다.

2026-09-16 후속 지시: 한컴 HFT 글꼴 메트릭/폭 피델리티는 이번 타스크에서 제외한다.
WASM에서 관측된 p81 마지막 줄의 p82 중복 배치는 이번 절편에서 해결한다.
분할된 두 조각의 source-line 소유권과 물리 원점을 함께 점검하고, clip으로 가리는
방식이 아니라 이미 소비된 줄의 재방출을 막는다. 다음 줄/마지막 줄 누락 방지도 검증한다.

## 위반 규칙과 근거

- 원본 `76076_regulatory_analysis.hwp` pi842의 바깥 표 padding 좌우=510HU,
  host cell `apply_inner_margin=false`. 공통 `Cell::effective_padding` 선택 규칙을 쓴다.
- 셀 폭 38245HU의 유효 내용 폭은 37225HU다. host 빈 문단의 저장 segment_width도
  37225HU다. 이 저장값은 보조 관측이며 특정 LineSeg/문자열로 분기하지 않는다.
- 현재 owner 폭 projection은 여백 차감 전 폭을 반환한다. 원점은 왼쪽 padding만큼
  이동하므로, TextLine 폭509.933px와 최종 clip503.133px가 달라 글자가 잘린다.
- 독립 참고 PDF의 p81 마지막 줄과 p82 이어짐은 stage2의 동일 입력 대조를 재사용한다.
  PDF는 Hancom2024 metadata가 있으나 정확한 출력 경로/폰트는 미확인이다.

## 구현

1. 기존 owner 폭을 선택하는 render-only projection에서 host cell의 유효 좌우
   여백을 차감한다. 셀별 명시 여백/0/표 기본의 선택은 공통 모델 함수를 사용한다.
2. 그 projection을 소비하는 측정·분할·layout 경로를 확인한다. paint 후 bbox clamp로
   증상만 숨기지 않고 줄 구성 이전의 공통 너비를 바로잡는다.
3. 일반 저장 폭 중첩 표를 새로 확대/축소하지 않는다. 기존 short-owner 적용 조건의
   추가 확대나 특수 문자 개행은 하지 않는다. 이 조건의 일반화 자체는 별도 설계 범위다.
4. 합성 계약으로 표 기본/셀별/명시0/비대칭 여백과 원본 IR 보존을 검사한다.
   실물에서는 기존 #2308 assertion을 그대로 실행하고 parent→child→TextLine 경계를 검사한다.

## 검증·완료

- 수정 전 새 회귀 계약 실패, 수정 후 성공을 확인한다.
- #2308 전체와 관련 중첩 표 집중 검증, fmt/suite 정책 검사.
- 같은 바이너리에서 실물 전체 SVG/render tree 생성. 기존 stage2 출력과 비교해
  변경 쪽을 확인하고 p34/p70 반례 및 p81/p82 PDF 비교 PNG·debug SVG를 준비한다.
- 최종 시각 판정은 작업지시자에게 요청한다. ignore 해제와 전체 PR 게이트는
  확인 결과와 별도 후속 절편에서 다루며 baseline은 갱신하지 않는다.

## 추가 승인: #2279 5쪽 continuation 높이 불일치

작업지시자가 원인 조사 후 수정 구현과 Docker WASM 빌드를 승인했다.
동일 절편에서 기존 #2308 변경을 보존하며 아래 작업을 추가한다.

- 분할 cut이 소비한 빈 문단을 실제 배치와 동일한 CellUnit 높이로 계상한다.
  시작/말미 빈 문단을 분할에서만 높이 0으로 처리하는 불일치를 제거한다.
- 일반 continuation도 실제 조각 높이와 본문 예산을 비교하여 유효한 재-cut을 선택한다.
  page-larger 단일 atom의 진행 보장은 구분하고, 출력을 clamp하거나 숨기지 않는다.
  실제 초과로 재시도할 때에는 같은 CellUnit walk에서 저장 프레임 초과 흡수를 끈다.
  이미 부족하다고 판정한 예산에 저장 경계까지 추가 수용하는 여유를 다시 적용하지 않는다.
- 원본 pi15 조각의 본문 fit 및 셀별 텍스트 보존, 합성 빈 문단·헤더/여백 계약을 검증한다.
  기존 #2308/#5301/#3128 및 RowBreak 집중 검사를 실행한다. 기존 #2279 페이지 핀은
  시각 판정 전 변경하지 않는다.
- native p4–6 PDF 비교와 최종 source 해시를 남기고 Docker WASM을 빌드한다.
  HFT 개선·#7202·#3798·전체 PR 게이트·원격 작업은 이 승인에 포함하지 않는다.

## 종료 범위 확정: 잔여 문제의 별건 분리

작업지시자는 작업 장기화를 피하기 위해 잔여 실패를 별도 이슈에서 처리하도록 지시했다.
