## #6725 한글 클립보드 HWPJSON native paste 검토

- [PR #6725](https://github.com/edwardkim/rhwp/pull/6725)의 code candidate
  `00efe0e00538aab312336b5dc20e119f0cb4f004`를 검토했다. 한글 CF_HTML의 HWPJSON을 HWPX
  조각으로 변환해 기존 외부 문서 삽입 경로를 사용하고, HTML paste 및 저장 조판 없는 문단의
  layout 회귀를 함께 정정한다.
- 기여자 head 검토에서 발견한 unsupported control/그림 원본 오류의 무음 content 유실은
  메인터너 commit `d64c94cc...`로 fail-closed 처리했다. native 변환이 실패하면 스튜디오는 종전
  HTML paste 경로로 fallback하며, 빈 XML 또는 0-byte 그림으로 성공한 것처럼 삽입하지 않는다.
- field ID 수집은 remapper와 같은 중첩 control 범위를 따르도록 보정했다. CI가 금지하는 새
  source-side `cfg(test)` module은 제거해 test-tier 기준선을 유지했으며, production 보정과
  HWPJSON integration 회귀는 남겼다.
- public sample은 `samples/hwpjson/korea-gmn-198518529-physical-ai-strategy.hwpx`다. 공개
  korea.kr 다운로드 원본의 SHA-256은
  `639c0c64030b98228046fc9562a61d7fb5d6334ad95d8a92b0058b13078e3e74`이며 provenance는
  sample README와 [검토 기록](../pr/archives/pr_6725_review.md)에 남겼다.
- exact candidate의 Full CI, Rust/Python/JavaScript CodeQL, Canvas visual diff, Adapter
  inter-diff, Proptest, CI Impact Policy가 모두 성공했다. `WASM Build`, Frontend unit,
  nextest duration refresh는 policy상 expected skip으로만 기록한다.
- 최종 판정은 **메인터너 보정 됨, 수용 가능**이다. 이 review와 오늘 기록은 PR #6725에 추가하는
  documentation-only trailing commit이며, 새 head CI와 `MERGEABLE`/`CLEAN` 확인 및 별도 merge
  승인 전에는 병합이나 issue close를 수행하지 않는다.
