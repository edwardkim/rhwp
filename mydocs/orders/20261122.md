## Windows 직접 PDF 내보내기

[#9276](https://github.com/edwardkim/rhwp/issues/9276)의 Windows 성능 회귀를 메인테이너가 맡는다. 조달청 원본 세 개와 최신 devel에서 재현한 결과, 공통 Native 렌더링과 PDF 글꼴 임베딩을 점검할 순서를 [수행 계획](../plans/task_m100_9276.md)에 기록했다.

`edwardkim`을 담당자로 지정했다. Windows에서 같은 글꼴을 다시 읽는 비용과 일부 글꼴 전체가 PDF에 들어가는 원인을 보정했다. 공고문 11쪽은 25.27초에서 3.94초로 단축됐고, 원본 3개의 19쪽 모두 수정 전후 PDF의 픽셀과 추출 텍스트가 같았다. 전체 회귀와 보호 문서 4,046행 검증을 마쳤다. [결과 보고서](../report/task_m100_9276_report.md)

[PR #9316](https://github.com/edwardkim/rhwp/pull/9316)의 제출 커밋 `131b75a8d7`에서 전체 회귀 A–E, Native Skia, 프런트엔드, CodeQL, Render Diff와 최종 CI 정책 감사가 통과했다. 셀프 리뷰에서 승인했고, 검토 기록 커밋의 필수 검사와 최신 `devel` 병합 가능 여부를 확인한 뒤 병합한다.
