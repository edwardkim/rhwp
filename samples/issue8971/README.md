# samples/issue8971 — 저장 줄 없는 그림 칸의 빈 문단 자리 줄

이 폴더는 [#8971](https://github.com/edwardkim/rhwp/issues/8971)의 정식 회귀 fixture다.

강동구 「2026 강동 환경 한마당 행사 결과보고」(HWPX, 한/글 2020 저장, 6쪽)의 축소본이다.
원본은 행사 사진 25장(시민 얼굴 포함, 24.7MB)을 담고 있어, 그림 바이너리만 같은 비율의 회색 단색
PNG 로 바꿨다. XML 은 원본과 바이트가 같고, 그림 크기는 XML(`hp:sz`·`hp:curSz`)이 정하므로
rhwp 배치 좌표는 6쪽 모두 원본과 같다(수정 전 329.2px → 수정 후 311.9px 표 높이 변화도 같다).
기준 PDF 는 원본이 아니라 **이 축소본**을 한/글로 출력한 것이다.

6쪽 「행사 사진」 표(4행 3열, TAC, 표 문단 저장 줄 높이 23393HU)의 0·2행 칸은 글자 없는 문단
하나에 위아래 배치(문단 기준) 그림 하나만 있고 저장 줄이 없다. 문단 글자 모양은 10pt·11pt 다.

| 행 | 칸 내용 | 한/글 행 높이 |
| --- | --- | --- |
| 0 | 빈 문단 + 그림(세로 오프셋 225, 높이 9637) | 141 + 225 + 9637 + 141 = 10144HU(135.25px) |
| 1 | 「환경작품 공모전 수상작 전시」 등 | 1665HU |
| 2 | 빈 문단 + 그림(오프셋 0) | 141 + 9637 + 141 = 9919HU |
| 3 | 「재활용센터 이벤트」 등 | 1665HU |

- 회귀 계약: 전체 6쪽. 6쪽 사진 표 높이 = 23393HU, 0행 칸 높이 = 10144HU(각 ±1px).
