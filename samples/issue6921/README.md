# issue 6921 — 꼬리말 정렬이 옮긴 선의 방출 좌표

## 무엇을 잠그나

`bbox` 를 옮기는 코드가 **노드가 들고 다니는 자기 좌표도 같이 옮기는지**를 잠근다.

백엔드는 노드마다 다른 것을 읽는다.

| 노드 | 그리는 근거 |
| --- | --- |
| `Rectangle` · `Ellipse` · `Image` · 글자 | `node.bbox` |
| **`Line`** | `x1/y1 – x2/y2` |
| **`Path`** | `commands` 의 절대 좌표 |

`LayoutEngine::translate_subtree_y` 는 `node.bbox.y` 만 옮겼다. 그래서 아래 둘은
**옮기기 전 자리에 그려지고 bbox 만 따로 놀았다.**

## 이 문서에서 무슨 일이 났나

꼬리말이 `vertAlign` 정렬을 받아 `dy = 23.88px` 내려간다.

```text
              bbox           SVG 방출
  수정 전   1007.92 → 1031.80   1007.92    ← 안 옮겨짐
  수정 후   1007.92 → 1031.80   1032.43    ← 따라감
```

`1007.92` 는 아직 본문 영역(바닥 `1009.2`) 안이라, 선이 본문 마지막 글줄
(`992.0 .. 1012.0`)을 가로질렀다. 600dpi 잉크 실측으로도 같은 띠에서 글자와 선이 섞였다.

```text
  수정 전  잉크 993..1011  max=636   ← 글자와 전폭 선이 한 띠
  수정 후  잉크 993..1011  max= 92   ← 글자만
           잉크 1032, 1034 max=636   ← 선은 따로
```

## 정본

`pdf/148733091-briefing-stenographic-record-2020.pdf` (engine 2020 — `lastSavedWith`
의 `product` 가 `null` 이라 규약 §3.5.1 의 2020 버킷).

```text
  12쪽  구분선 y = 1028.2 / 1029.9
```

## ⚠ 남은 차이는 이 계약 밖이다

수정 후 `1032.4` 는 정본 `1028.2` 와 **+4.2px** 다르다. 그 값은 꼬리말 **문단 자체의
세로 위치**라 다른 축이고, 이 시험은 잠그지 않는다.

이 문서의 `12·20·24·26·30·31`쪽에서 본문 마지막 줄이 본문 바닥을 넘는 것은
[#6920](https://github.com/edwardkim/rhwp/issues/6920) 의 별개 결함이고 이 수정으로
바뀌지 않는다.
