# #6712 표 셀 안 어울림 그림 재현 자료

- 공식 출처: [서울시 보육포털 게시물 3801](https://iseoul.seoul.go.kr/portal/info/boyukDataView.do?idx=3801)
- 게시물: 어린이집 영유아 방문건강관리 가정통신문(8호) 영유아 감염병 예방, 2026-07-30.
- 첨부: `한글파일_2026년 8호 가정통신문_여름철 영유아 감염병 예방.zip`.
- 2026-09-05 공식 첨부에서 아래 두 HWP만 추출했다. ZIP의 11개 HWP CRC 검사는 모두 통과했다.
  원본 바이트는 수정하지 않았다. 글꼴 파일은 포함하지 않는다.

| 파일 | SHA-256 | `lastSavedWith` |
|---|---|---|
| `한국어_2026년 8호 가정통신문_여름철 영유아 감염병 예방.hwp` | `70a6663e75fefedc001b2c249bd20f5b994596954120740252f484b1892e2097` | 한컴 2020, `11.0.0.9136` |
| `중국어_2026년 8호 가정통신문_여름철 영유아 감염병 예방.hwp` | `34a5964fa791ae662052cba8482efae682f13b45a0c0cd6ce633425566a2d5a9` | 한컴 2024, `13.0.0.3379` |

두 파일 모두 최상위 문단 1개, 셀 안 Square 그림 8개다. 한국어본의 셀[3] p[8]은
`column_start=6065`, `segment_width=40143`, 그림 크기 `5594x4906`, 오프셋 `(471,284)`로
이슈의 구조와 일치한다. 사내 문서 ID와 원본 해시의 대응표는 제공되지 않았으므로 `18981443`을
포함한 세 파일 전부를 확보했다고 해석하지 않는다.

2026-09-06 사용자가 아래 한국어 `-2020.pdf`와 중국어 `-2024.pdf` 두 파일을 검증 대상으로
확인했다. 이 두 문서로 #6712를 재현·검증하며, 세 번째 사내 ID의 별도 파일을 대기 조건으로
두지 않는다. 세 개의 독립 원본을 확인했다는 뜻은 아니다.

## 한컴 기준 PDF

[MCP 지침](../../mydocs/manual/mcp_hwp2024Convert_usage.md)에 따라 2026-09-05 한 파일씩
`start → status → download`로 변환했다. 한국어본 저장 제품은 2020이지만 변환 서버의
`engine: 2020`은 Windows HOffice120 호환 profile이라는 점을 구분한다.

변환 backend는 `hwp-managed-direct-dll-host`, 입력 전처리는 `none`이다. 서버 접속 정보와
상태 JSON은 커밋하지 않는다. `1f861362ab372f9fa26e38f9a534a89286f641c4`에서 빌드한 rhwp는
두 원본 모두 3쪽을 출력한다. 한국어본 1쪽의 제목 `1. 여름철 눈병`이 그림 아래로 밀리는 것도
기준 PDF와 visual sweep 비교로 확인했다. 아직 수정 후 통과를 뜻하지 않는다.
