# PR #8141 수학 기호 슬롯의 실제 검증 입력

`1342000_math_textbook_field_review.hwp`는 작업지시자가 제공한 PRISM 수집 자료 중
교육부의 `1342000-202300055_D0150014-1-001_(중간보고서) 초1~2 수학과 국정도서 현장적합성 검토.hwp`와
바이트가 같은 원본이다. 합성 글머리표 입력과 구분해 사용한다.

| 항목 | 값 |
| --- | --- |
| 원본 크기·SHA-256 | 393,216바이트 · `1c2d27c5f431141b81052ea308039aa43c2899488b54b48a1d1ff2f6c487047e` |
| 마지막 저장 제품 메타데이터 | Hancom Office 2018 · `10.0.0.11808` |
| 독립 기준 | [한컴 Print PDF](../../pdf/issue8141/1342000_math_textbook_field_review-hwp-2020.pdf), 49쪽 |
| PDF 크기·SHA-256 | 470,272바이트 · `956ede8003ccd245d5dd7021a0e4af4bd9264a1d95eac77dda134f698b230972` |
| 인쇄 경로 | 저장 제품에 맞춰 MCP `engine=2020`으로 원본을 Print |
| Print 작업 식별자 | `79645fe2-9bd5-425a-b084-fe3f2f7b542c` |

6쪽의 `⦁`가 한글 슬롯 대신 기호 슬롯의 함초롬바탕과 해당 전진폭을 사용하는지를
검토한다. 실제 문서의 전쪽 검증과 `samples/lang_slot/symbol_slot_bullets.hwpx`의
작은 계약 검사를 구분한다. 입력과 PDF는 검증 과정에서 내용·저장 글줄·글꼴 선언을
수정하지 않았다. 글꼴 프로그램은 이 폴더에 추가하지 않는다.
