# Issue #7620 쪽 경계 나눔 자리 차지 표 대조군

`a-rowbreak-float.hwp`는 `devel` `d9749c5a1`의 web WASM으로 `generate.mjs`를 실행해 만든 **생성 대조군**입니다. 한컴 저장본이 아닙니다. 같은 패키지로 다시 실행하면 바이트가 같습니다.

문서는 앞 문단 · 자리 차지 표 문단 · 빈 문단 · 뒤 문단입니다. 표는 2×2, 비TAC, `TopAndBottom`, 세로 문단 기준 오프셋 0, 바깥 여백 283HU이고, 쪽 경계 나눔을 RowBreak로 바꿔 저장했습니다. 표 문단 줄은 native 생성 그대로 폭 0 앵커 줄(`vpos 1600, lh 1000, ls 600, sw 0`)이고 문단 위·아래 간격은 0입니다.

기준 PDF는 `pdf/issue7620/`에 있습니다. 한컴독스 웹서비스 6.3.6(2026-09-17), 편집기 "한컴오피스 Web v2 한글" 빌드 `20260812021742`에서 파일 → 인쇄 시 서버가 만든 인쇄용 PDF(`webhwp/handler/download/…?fileExt=pdf&preview=true`, Producer cairo 1.15.12)를 브라우저 인쇄 전에 받은 것입니다. 한/글 데스크톱 Print 출력은 확인하지 않았습니다.

한컴 인쇄에서 표 괘선은 157–191px, 표 뒤 문단의 글자 잉크는 217px에서 시작합니다(96dpi). 즉 쪽 나눔 None 표와 같이 문단 윗변 + 바깥 여백 위에 표가 서고, 다음 줄은 표 아랫변 + 바깥 여백 아래에서 시작합니다. 입력과 PDF의 SHA-256은 `MANIFEST.json`에 고정했습니다. 생성 대조군의 통과를 한컴 저장본 일반의 시각 일치로 보고하지 않습니다.

## 본문 바닥 경계 대조군 (`generate-budget.mjs`)

`b-rowbreak-bottom-margin-overflow.hwp`·`c-rowbreak-table-moves-next-page.hwp`·`d-rowbreak-splits-at-row-boundary.hwp`는 `devel` `b5064fae1`의 web WASM으로 `generate-budget.mjs`를 실행해 만든 **생성 대조군**입니다. 한컴 저장본이 아니며, 같은 패키지로 다시 실행하면 바이트가 같습니다.

세 문서는 앞 문단 N개 · 표 문단 · 빈 문단 · 뒤 문단입니다. 표는 R×2, 비TAC, `TopAndBottom`, 세로 문단 기준 오프셋 0, 쪽 경계 나눔 RowBreak이고 바깥 여백 위·아래는 2835HU(1cm)입니다. b는 N=37·R=2, c는 N=39·R=2, d는 N=20·R=40입니다.

기준 PDF는 `pdf/issue7620/`에 있고, 한컴독스 웹 한글(빌드 `20261102065324`)에서 파일 → 인쇄 시 서버가 만든 인쇄용 PDF를 받은 것입니다(96dpi 관측).

- b: 표 본체(959–993px)는 1쪽 본문에 들어가지만 첫 행과 바깥 아래 여백이 함께 들어가지 않습니다. 한컴은 표를 나누지 않고 2쪽 170–204px에 두며, 「표 뒤 문단」은 1쪽 964px에 남습니다.
- c: 표 문단 줄 뒤에 표가 들어가지 않습니다. 한컴은 표를 2쪽 170–204px에, 「표 뒤 문단」을 2쪽 242px(표 아랫변 + 바깥 아래 여백)에 둡니다.
- d: 쪽 중간에서 시작한 40행 표를 행 경계에서 나눕니다. 한컴은 1쪽 596–955px, 2쪽 170–495px에 두고 1쪽 조각 아래에 바깥 아래 여백(37.8px)을 남깁니다(대조군).

생성 대조군의 통과를 한컴 저장본 일반의 시각 일치로 보고하지 않습니다. 입력과 PDF의 SHA-256은 `MANIFEST.json`에 고정했습니다.

b·c·d 세 파일에는 #8939 에서 `/RhwpLineSegTags` 표지 스트림만 더했습니다(다른 스트림 바이트 동일). rhwp 가 계산한 합성 줄의 LineSeg tag bit 31 을 한/글 저장 줄의 bit 31 과 구별하는 표지이며, 생성 직후 해시는 `MANIFEST.json`의 `generated_sha256`에 남겼습니다. 이 head 이후의 WASM으로 다시 생성하면 표지가 함께 쓰입니다.
