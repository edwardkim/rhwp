# #6793 정식 회귀 입력

[이슈 #6793](https://github.com/edwardkim/rhwp/issues/6793)에서 식별한 공개 문서
**소형항공운송사업 발전방안 연구용역 과업지시서(최종)**(국토교통부)의 원본 바이트를
등록했다. 비공개 PC 경로 또는 환경 변수가 없어 검사를 건너뛰는 방식은 사용하지 않는다.

- 파일: [1611000-201000141-small-air-transport-study.hwp](1611000-201000141-small-air-transport-study.hwp)
- SHA-256: `25cc60d379f68246875e968978c13f3273fcc3f6b04fc1fe726434e4626e447d`
- 크기: 51200바이트
- 저장 제품: **미상** — `rhwp info --json` 의 `lastSavedWith` 는
  `{product: null, version: "6.7.8.1045"}` 다. 초판 manifest 의 `9.1.1.4072` 는
  **틀렸다**(PR #6794 지적) — 정정했다.
- 기준 엔진: **`2020`** (`product` 가 `null` 이므로
  [시각·fixture 증적](../../mydocs/manual/pr_review/visual_fixture_evidence.md) §3.5.1
  에 따라 `hwp2024Convert` MCP 의 `engine: 2020`).
  ⚠⚠ **engine 2020 기준 PDF 는 아직 없다** — 이 작업 PC 에는 그 MCP 의
  `.env.local`(endpoint·token)이 없어 산출하지 못했다.
- 현재 증적은 **한/글 2024** 출력이다: **12쪽** = rhwp, 그리고 `< 차 례 >` 가
  **2쪽 첫 줄**이다.
- 회귀 계약: 앞 문단의 저장 꼬리(`vpos + lh + gap`)가 **이 쪽 예산을 넘고**, 이 문단의
  첫 **비합성** 저장 줄이 `vpos == 0` 이면 **새 쪽에서 시작한다**. `< 차 례 >` 는
  2쪽 본문 상단(y=132.3)에 놓인다. **크기 문턱이 없다.**

  ⚠ 두 번째 조건이 없으면 안 된다 — `vpos == 0` 은 새 쪽 상단인 동시에 **"앵커 없음"
  센티널**이기도 하다(`#6753`: 조각 시작 `vpos == 0` 을 무조건 쪽 경계로 읽은 선행
  시도가 242쪽을 243쪽으로 늘려 기각됐다).

⚠ **글자 수 대조는 점 리더(`···`)를 빼고 재야 한다.** 그대로 재면 결손 1,468자로
나오는데 그 대부분이 차례의 탭 채움 점이다(rhwp PDF 는 안 싣는다). 점·공백을 빼면
수정 전 결손 **4자**, 수정 후 **0자**다.

⚠ 이 문서의 text-overlap 16건은 **수정 전부터** 있던 2.07px 미세 겹침으로 이 축과
무관하다.

새 sample이 기존 코퍼스 래칫에 주는 영향은 통합 검증에서 실측한다. 알려지지 않은
회귀를 숨기려고 기존 문서 기준선을 올리거나 보안 탐지 신호를 포괄적으로 무시하지 않는다.
