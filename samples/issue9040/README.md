# samples/issue9040 — 나뉜 칸의 빈 문단 뒤 자리차지 중첩 표

이 폴더는 [#9040](https://github.com/edwardkim/rhwp/issues/9040)의 정식 회귀 fixture다.

공개 정책연구용역과제 신청서(문화체육관광부, 정책연구관리시스템 PRISM 공개, HWP, 10쪽) 원본이다.

| 항목 | 값 |
| --- | --- |
| 바깥 표 | pi=107, 5×4, 쪽나눔 RowBreak, 4행 둘째 칸 문단 44개(7~9쪽에 나뉨) |
| p40 | 빈 줄, vpos 0(쪽 되감김 — 9쪽 조각 시작), 1000+500HU |
| p41 | 빈 줄, vpos 1500, 1000+500HU |
| p42 | 글자 없는 호스트, 조직도 표 23×9(자리차지·문단 기준·오프셋 0, 26502 + 바깥 여백 141·141), 저장 줄 vpos 29784 |
| p43 | 빈 줄, vpos 31284 |

저장값은 `p41 끝 3000 + 26784 = p42 줄 29784`, `p42 줄 + 1500 = p43 줄 31284` 로 닫힌다.
한/글은 9쪽 조각에 빈 줄 두 개 → 조직도 → 호스트 줄 → 빈 줄을 차례로 두고(조각 약 435px), 전체 10쪽이다.
수정 전 rhwp 는 p41 의 전진에 표 띠(377px)를 넣고 조직도 행을 다시 세어 조각을 771px 로 그려 11쪽이 됐고,
조직도를 칸 위끝에 그렸다.

- 회귀 계약: 전체 10쪽. 9쪽 조직도는 칸 조각 안, 앞 빈 줄 아래. 9쪽은 「창의도시 정책」 행까지, 10쪽은 「Pension Policies」 행부터.
- 바이트 정본: [MANIFEST.json](MANIFEST.json)의 SHA-256과 크기
