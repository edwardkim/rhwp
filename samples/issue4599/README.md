# #4599 정책연구 보고서와 축소 대조군

`1790387_policy_progress.hwpx`는 작업지시자가 제공한 PRISM 수집 자료 중 질병관리청의
`1790387-202300151_D0150014-1-001_정책연구용역 중간진도보고서.hwpx`와 바이트가 같은 원본이다.
PR #8185의 실제 보고서 검증에 사용하며, 이 폴더의 축소 입력과 구분한다.

| 항목 | 값 |
| --- | --- |
| 원본 크기·SHA-256 | 4,743,695바이트 · `947e51913c561611397c4f7d88feaad7112da4adc658b21cbfd9471e00192411` |
| 마지막 저장 버전 메타데이터 | `9.6.1.10418` |
| 독립 기준 | [한컴 Print PDF](../../pdf/issue4599/1790387_policy_progress-hwpx-2020.pdf), 64쪽 |
| PDF 크기·SHA-256 | 1,508,356바이트 · `4c0d9d0876410766d99f4589916971f97b751a3d71901068637c7e2cc1061f95` |
| 인쇄 경로 | 저장 버전에 맞춰 MCP `engine=2020`으로 원본을 Print |
| Print 작업 식별자 | `3fe83109-2b83-4f3f-983b-7ec3d84fad61` |

검토 범위는 오프셋 표 첫 조각, 반복 머리행의 rowspan, 끝 조각 뒤 저장 줄과 Native SVG의
출력 소비다. 다음 축소 입력은 각각의 경계를 분리해 검사하며 실제 보고서 전쪽의 증거를
대신하지 않는다.

- `1790387_offset_float_split_min.hwpx`: 첫 조각과 후속 내용의 쪽 소속.
- `1790387_rowspan_header_repeat.hwpx`: 머리행에서 시작한 rowspan의 반복 범위.
- `1790387_tac_successor_after_split.hwpx`: 마지막 조각 뒤 글자처럼 취급 표의 저장 줄.

같은 기관의 다른 문서 `samples/issue2006/1790387_prep_final_report.hwpx`는 이 중간진도보고서의
대체 입력이 아니다. 원본과 독립 PDF는 내용·쪽수·저장 글줄·글꼴 선언을 바꾸지 않고 보존한다.
이 자료의 부분 개선을 #4599 전체 해결로 확대하지 않는다.
