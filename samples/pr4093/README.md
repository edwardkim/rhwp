13번이 `4.` 가 아니라 `5.` 인 것이 이번 수정의 핵심이다 — 표 셀의 `NUMBER` 문단이 4 를
가져간다. 패널 번호와 본문에 그려진 번호가 같아야 한다.

### 손으로 확인할 것

1. **계층·번호** — 위 표와 같은지. 표 셀 문단과 본문 문단은 목록에 없어야 한다.
2. **접기/펼치기** — `1. 총칙` 의 `▾` 를 눌러 하위 4개가 접히는지. 버튼에 초점을 두고
   `Enter`/`Space` 를 **연속으로** 눌러도 접힘↔펼침이 반복되는지(초점이 살아 있는지).
3. **방향키 훑기** — 항목에 초점을 두고 `↑`/`↓`·`Home`/`End` 로 훑을 때 선택만 옮겨 가고
   본문은 움직이지 않는지. `←`/`→` 는 접기/펼치기(끝이면 상위로/첫 하위로).
4. **이동** — `Enter`/`Space` 또는 클릭에서만 해당 개요로 스크롤하는지. 6번은 2쪽,
   11번부터는 3쪽으로 가야 한다.
