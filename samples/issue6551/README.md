# 원문 및 기준 PDF

기존 등록 HWPX를 원문과 대조하여 바이트 동일성을 확인했다. HWP로 재저장하거나 중복 복사하지 않았다. 원래 파일명, SHA-256, 저장 버전, 새 MCP 기준 PDF는 [MANIFEST.json](MANIFEST.json)에 기록한다.

2026-09-08 재산출 PDF는 engine 2024, 실제 한컴 13.0.0.3901, 46쪽이다. 그라데이션 방향의 검토 범위 및 글꼴 차이는 [PR #6851 검토](../../mydocs/pr/archives/pr_6851_review.md)를 따른다.
