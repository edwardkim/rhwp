# 금융위 보도자료 — 저장 LINE_SEG 없는 TAC 그림 앵커 문단 (#7062)

`layout-anomaly` 가 침묵하는 배치 결함의 정식 재현체다. 2쪽 표 셀 안에서

- `p[11]` 빈 문단 (vpos=30525)
- `p[12]` **저장 LINE_SEG 없음** · TAC 그림 1개 (`treatAsChar=1`,
  `textWrap=TOP_AND_BOTTOM`, `vertRelTo=PARA`, 44852×29997 HWPUNIT = 400.0px 높이)
- `p[13]` 1행 1열 표 (`※ 즉시 추진 가능한 …`, vpos=61874)

로 이어진다. 저장 사다리의 `p[11] → p[13]` 델타는 **31349HU = 418.0px** 로 그림 높이를
포함한다. 렌더 경로가 이 문단을 "빈 문단"으로 보고 400HU(5.3px) 고정 줄을 쓰면 뒤 표가
`553.4px` 로 올라와 그림(`548.1..948.1`) 한가운데 그려진다.

원본은 공개 보도자료이며 파일명·SHA-256·크기는 `MANIFEST.json` 을 따른다. 한컴 기준 PDF는
`pdf/tac_object_host_line_height-2020.pdf`에 보존한다. #7083의 engine 2020 재산출본이며
검토에서는 이 파일과 원본을 직접 비교한다. 초기 #6928 코멘트의 좌표는 과거 조사 기록이다.
