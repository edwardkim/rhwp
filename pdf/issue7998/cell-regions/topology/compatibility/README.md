# 추가 한컴 Print의 표 높이 차이 — B23

같은 `../edited/rowspan-merge.hwp` 바이트를 인쇄했지만 두 출력이 다르다.

- 사용자 제공 `../print/rowspan-merge-hwp-manual-2020.pdf`: 한컴 2020 11.0.0.9166,
  A4, 두 문단과 표 아래 변이 정상 높이에 있다. 사용자가 정상 HWP 열림과 시각 판정을 확인했다.
- `rowspan-merge-hwp-2020.pdf`: MCP 한컴 2020 11.0.0.9136, 원본 399×360pt,
  PrintMethod 0·one-up. 같은 내용의 세로 변이 페이지 아래까지 늘어나며 아래 변이 없다.
  이 출력 대비 Native raw는 56.38381%다. 새 HWPX Print에는 같은 현상이 없다.

빌드 차이와 용지/서비스 실행 조건이 함께 다르므로 특정 버전의 결함이나 rhwp 저장기
결함으로 아직 확정하지 않는다. 같은 파일의 native 표 구조·rowspan·셀 높이와 실제
사용자 인쇄/MCP 인쇄의 소비 조건을 분리하고, 정상 대조군의 독립 Print로 보정 방향을
확인해야 한다. XML 버전 전역 변경이나 표 높이 clamp로 화면만 맞추지 않는다.

2026-10-19 메인테이너는 **“정상 PDF 기준·추가 차이는 백로그”**로 판정했다.
stage27의 정상 출력 기준은 사용자 PDF로 유지한다. 이 진단의 90% 미달은 지우지 않고
manifest와 함께 보존하며 호환성 차이를 해결 완료로 표시하지 않는다. 서비스의 성공
상태는 출력 정확성의 증거가 아니다. 잘못된 HWP/HWPX는 30분 뒤 오류를 반환할 수
있다는 서비스 동작도 대기열·실패 분석에서 구분한다.
