# 경계 — 봉투 필드 사전은 여기 없다

## 단일 출처

봉투 필드(이름 → 타입 → 의미 · null 의 뜻 · 등장 명령)의 정본은
`mydocs/manual/agent_knowledge_map.md` **§2-2. 전수 사전** 이다.

대전은 명령 중심이다. 각 생성 장은 필드 **이름 목록**만 싣고
정의는 §2-2 로 점프한다. 이 스킬도 그 경계를 지킨다.

## 이 스킬이 하는 일 / 안 하는 일

| 한다 | 안 한다 |
|---|---|
| 장 번호로 안내 | 272개 필드 사전 복제 |
| 출처 표지 줄을 읽으라고 시킨다 | untrusted 경로를 재정의 |
| export-provenance-map 을 연다 | 지식지도를 이 폴더에 복사 |
| 절단 표본을 픽스처로 추출 | 생성 장의 JSON 을 손수정 |

## 이름이 같은 함정 (사전으로 보낼 것)

- `version` — `info` 의 문서 판본 vs `capabilities` 의 바이너리 버전
- `sections` — `info` 의 구역 수 vs `digest --sections` 의 배열
- `steps` — `run` 저널 배열 vs `replay` 의 숫자

이 스킬에 타입표를 다시 적지 않는다. §2-2 가 이미 적었다.

## 생성 장이 가리키는 문구

`- 봉투 필드: … — 정의는 [지식지도 §2-2](../agent_knowledge_map.md)`

이 한 줄이 계약이다. 스킬이 그 링크를 가로채 자체 사전을 만들지 말 것.
