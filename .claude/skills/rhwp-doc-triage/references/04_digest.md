# 04 — digest : 예산 내 발췌

초소형 모델용 매크로. info+structure+첫 장 읽기를 한 호출로 한다. excerpt 는 첫 3쪽이다.

이슈 #3633. 권위는 `cli_commands.md` 의 `digest` 절.

## 트리에서의 위치

사다리: `info → explain → export-structure → digest → search → extract-data`

이 단의 목적: 메타+상위 개요+첫 3쪽 발췌. 뒤를 대표하지 않는다

- 성공 다음: 더 필요하면 --sections 또는 --pages a..b. nextStep 을 받아 적는다
- 실패 다음: stdout 0바이트, exit 1/2

## 호출

```bash
rhwp digest <파일> --json
```

읽기 전용. 원본을 쓰지 않는다. 새 플래그를 만들지 않는다.

## 종료 코드

| 코드 | 의미 | 에이전트 행동 |
| --- | --- | --- |
| 0 | 성공. 0건 포함 | 봉투를 읽고 정지 규칙을 적용 |
| 1 | 런타임 (없음·파싱·암호 틀림) | stdout 비었는지 확인. 덤프 우회 금지 |
| 2 | 사용법 | 옵션을 고친다. 0 을 무제한으로 바꾸지 않는다 |

## 기본 모드

`outline` 최대 20개 + `excerpt`(페이지 0~2, 기본 2000자) + `truncated` + `nextStep`.
`nextStep` 은 고정 문자열이다. 고쳐 쓰지 말고 받아 적는다.
기본 nextStep: `더 읽으려면 export-text --json -p <쪽>, 찾으려면 search --json`

## --sections

절 단위 청크. `sectionsMode` 가 `outline`/`clause`/`page` 중 무엇인지 반드시 읽는다.
구조 없으면 `page` 폴백. 강등 사실을 숨기지 않는다.
절별 기본 240자, 청크 최대 50. `sectionCount` 로 총량을 본다.

## --pages a..b

0 기준, 양끝 포함, `a<=b`. 형식 오류 exit 2, 시작이 범위 밖이면 exit 1.
끝은 문서 끝으로 잘린다. `nextStep` 이 다음 창을 안내하면 그 창만 이어 읽는다.
`--sections` 와 동시 사용 금지.

## 하지 않는 것

- excerpt 로 결론을 단정
- `--pages 0..{pageCount-1}` 한 방에 전 문서 발췌
- `--max-chars` 없이 거대 문서를 기본 2000자로 안심
