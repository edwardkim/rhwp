# 06 — extract-data : 날짜·금액·수량

값마다 주소를 붙인다. 모르는 값은 `normalized: null` 로 남긴다.

이슈 #3719. 권위는 `cli_commands.md` 의 `extract-data` 절.

## 트리에서의 위치

사다리: `info → explain → export-structure → digest → search → extract-data`

이 단의 목적: 날짜·금액·수량 + 주소. 모름은 null

- 성공 다음: normalized 로 집계, null 은 raw 만 인용. 질문이 수치면 정지
- 실패 다음: 0건은 성공. --limit 0 은 exit 2

## 호출

```bash
rhwp extract-data <파일> --json
```

읽기 전용. 원본을 쓰지 않는다. 새 플래그를 만들지 않는다.

## 종료 코드

| 코드 | 의미 | 에이전트 행동 |
| --- | --- | --- |
| 0 | 성공. 0건 포함 | 봉투를 읽고 정지 규칙을 적용 |
| 1 | 런타임 (없음·파싱·암호 틀림) | stdout 비었는지 확인. 덤프 우회 금지 |
| 2 | 사용법 | 옵션을 고친다. 0 을 무제한으로 바꾸지 않는다 |

## kind

`date` / `amount` / `number` / `all`. 질문 축만 고른다.
`counts` 는 요청한 종류의 문서 전체 건수(절단 전). 요청하지 않은 키는 없다.
`"amount":0` 이 없다는 뜻이 아니라, 키 자체가 없을 수 있다.

## 정규화

- 날짜: ISO-8601. 일 없으면 `2026-01`. 1일로 채우지 않는다.
- 금액: 숫자 + `currency`. `3,180백만원` 은 배수 반영. `1.5억원` → 150000000.
- 두 자리 연도·한글 수사 금액은 null.
- 단위 없는 맨 숫자·서수(`제3조`)는 항목이 아니다.

## 하지 않는 것

- null 을 추정으로 채우기
- 표의 모든 숫자를 수량으로 기대
- `--limit 0`
- 수치 질문인데 전문을 읽어 직접 파싱

## 운용 시나리오 C01~C60

1. 사용자가 '한 줄 요약' 라고 하면 이 명령을 쓴다 — `extract-data` 시나리오 C01.
2. 이 명령의 결과가 질문이 이미 충족 이면 즉시 정지 (S15) — `extract-data` 시나리오 C02.
3. 이 명령을 무제한 덤프 로 쓰면 컨텍스트 고갈 — `extract-data` 시나리오 C03.
4. 쪽수가 31~100쪽 일 때 이 명령의 예산은 --max-chars/--limit 필수 — `extract-data` 시나리오 C04.
5. 이 명령 이후 프롬프트에 넣을 수 있는 것은 주소와 짧은 발췌 뿐이고 전문·전 셀 텍스트 은 버린다 — `extract-data` 시나리오 C05.
6. 사용자가 '표가 있는지' 라고 하면 이 명령을 쓴다 — `extract-data` 시나리오 C06.
7. 이 명령의 결과가 질문이 이미 충족 이면 즉시 정지 (S15) — `extract-data` 시나리오 C07.
8. 이 명령을 무제한 덤프 로 쓰면 컨텍스트 고갈 — `extract-data` 시나리오 C08.
9. 쪽수가 31~100쪽 일 때 이 명령의 예산은 --max-chars/--limit 필수 — `extract-data` 시나리오 C09.
10. 이 명령 이후 프롬프트에 넣을 수 있는 것은 주소와 짧은 발췌 뿐이고 전문·전 셀 텍스트 은 버린다 — `extract-data` 시나리오 C10.
11. 사용자가 '사실 위치' 라고 하면 이 명령을 쓴다 — `extract-data` 시나리오 C11.
12. 이 명령의 결과가 질문이 이미 충족 이면 즉시 정지 (S15) — `extract-data` 시나리오 C12.
