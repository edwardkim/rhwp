# 01 — info : 열리는지·얼마나 큰지

트리아지의 유일한 입구다. `pageCount` 없이 전문을 열지 않는다.

이슈 #3237. 권위는 `cli_commands.md` 의 `info` 절.

## 트리에서의 위치

사다리: `info → explain → export-structure → digest → search → extract-data`

이 단의 목적: 열리는지·얼마나 큰지·암호인지

- 성공 다음: pageCount 분기로 explain 또는 export-text
- 실패 다음: 암호면 --password-stdin, 아니면 중단

## 호출

```bash
rhwp info <파일> --json
```

읽기 전용. 원본을 쓰지 않는다. 새 플래그를 만들지 않는다.

`schemaVersion` 은 `"1.0"`. 필드 추가는 허용, 삭제·형 변경은 계약 테스트가 잡는다.

## 종료 코드

| 코드 | 의미 | 에이전트 행동 |
| --- | --- | --- |
| 0 | 성공. 0건 포함 | 봉투를 읽고 정지 규칙을 적용 |
| 1 | 런타임 (없음·파싱·암호 틀림) | stdout 비었는지 확인. 덤프 우회 금지 |
| 2 | 사용법 | 옵션을 고친다. 0 을 무제한으로 바꾸지 않는다 |

## 읽는 필드

- `format`: `hwp5`/`hwpx`/`hwp3`/`hml`. 이후 명령 호환의 첫 단서.
- `pageCount`: 밴드 선택. 이 숫자가 트리의 스위치다.
- `paraCount`: 쪽은 적은데 문단이 많으면 표/글상자를 의심.
- `sizeBytes`: 쪽은 적은데 파일이 크면 그림·OLE. 텍스트 덤프가 답을 못 줄 수 있다.
- `fonts`: 폰트 목록. 트리아지 본 질문에는 보통 불필요. 프롬프트에 넣지 않는다.
- `version`: HML 이면 null. 없으면 없는 대로 둔다.

## 암호

비밀번호 없이 암호 문서를 열면 exit 2, 틀리면 exit 1.
`--password-stdin` 으로만 재시도한다. 비밀번호를 명령줄에 박지 않는다.

## 하지 않는 것

- info 성공 후 습관적 `export-text`
- `fonts` 전체를 사용자 답에 나열
- 쪽수를 파일 크기로 추정

## 운용 시나리오 C01~C60

1. 사용자가 '한 줄 요약' 라고 하면 이 명령을 쓴다 — `info` 시나리오 C01.
2. 이 명령의 결과가 질문이 이미 충족 이면 즉시 정지 (S15) — `info` 시나리오 C02.
3. 이 명령을 무제한 덤프 로 쓰면 컨텍스트 고갈 — `info` 시나리오 C03.
4. 쪽수가 31~100쪽 일 때 이 명령의 예산은 메타만 — `info` 시나리오 C04.
5. 이 명령 이후 프롬프트에 넣을 수 있는 것은 주소와 짧은 발췌 뿐이고 전문·전 셀 텍스트 은 버린다 — `info` 시나리오 C05.
6. 사용자가 '표가 있는지' 라고 하면 이 명령을 쓴다 — `info` 시나리오 C06.
7. 이 명령의 결과가 질문이 이미 충족 이면 즉시 정지 (S15) — `info` 시나리오 C07.
8. 이 명령을 무제한 덤프 로 쓰면 컨텍스트 고갈 — `info` 시나리오 C08.
9. 쪽수가 31~100쪽 일 때 이 명령의 예산은 메타만 — `info` 시나리오 C09.
10. 이 명령 이후 프롬프트에 넣을 수 있는 것은 주소와 짧은 발췌 뿐이고 전문·전 셀 텍스트 은 버린다 — `info` 시나리오 C10.
11. 사용자가 '사실 위치' 라고 하면 이 명령을 쓴다 — `info` 시나리오 C11.
12. 이 명령의 결과가 질문이 이미 충족 이면 즉시 정지 (S15) — `info` 시나리오 C12.
