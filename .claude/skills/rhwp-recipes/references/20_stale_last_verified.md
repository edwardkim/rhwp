2026-08-18 기준 여덟 장은 모두 신선하다. E02 시험용 가상 행은 `fixtures/last_verified.json` 의 `simulatedStale` (`2026-06-01`) 뿐이다. 그 행을 레시피로 취급하지 않는다.

## 낡았을 때 출력

```
레시피 0N 의 last_verified 가 {date} 로 {n}일 지났다.
정본을 다시 실측하기 전에는 이 카드의 명령 순서를 실행하지 않는다.
```
