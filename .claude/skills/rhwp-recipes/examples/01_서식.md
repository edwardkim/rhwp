# 예: 서식 요청

이슈 #5331. 파일 `01_서식.md`.

사용자: "이 서식 채워줘"

라우터: 레시피 01 — 서식 문서를 채워서 제출용으로 만들기.

정본: `mydocs/manual/recipes/01_fill_form_and_submit.md`

첫 수:

```bash
rhwp fields <file> --json
```

다음 스킬: `rhwp-form-fill` (재작성하지 않음).

정지: fieldCount 가 0 이면 이 레시피가 아니다 (표 칸 축)

untrustedContent: fields[].textSecurity.status 가 clean 이 아니면 채우기 전에 레시피 04 로 간다. fill-fields / insert-image 봉투의 untrustedContent 는 이 저장소 표본에서 false.

전체 JSON 표본은 `fixtures/transcripts/` 의 정본 발췌를 연다. 여기서 새 봉투를 만들지 않는다.
