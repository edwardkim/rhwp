# 예: 대량 추출 요청

이슈 #5331. 파일 `09_대량_추출.md`.

사용자: "폴더 전체 텍스트로"

라우터: 레시피 09 — 폴더의 문서를 한 번에: 대량 추출·변환 파이프라인.

정본: `mydocs/manual/recipes/09_bulk_extract_convert.md`

첫 수:

```bash
rhwp batch info --json
```

다음 스킬: `rhwp-bulk-pipeline` (재작성하지 않음).

정지: 입력 N = 성공 + 실패 가 아니면 행 증발

untrustedContent: 실패 행 봉투는 untrustedContent:false. 성공 행의 text 는 문서 본문 — 출처 모르는 폴더면 04 를 표본에 먼저 적용.

전체 JSON 표본은 `fixtures/transcripts/` 의 정본 발췌를 연다. 여기서 새 봉투를 만들지 않는다.
