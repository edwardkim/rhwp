# 예: 마스킹 요청

이슈 #5331. 파일 `03_마스킹.md`.

사용자: "개인정보 마스킹"

라우터: 레시피 03 — 배포 전 개인정보 마스킹.

정본: `mydocs/manual/recipes/03_redact_before_sharing.md`

첫 수:

```bash
rhwp edit redact <file> --dry-run
```

다음 스킬: `rhwp-security-sweep` (재작성하지 않음).

정지: 산출 경로 없이 redact 하면 exit 2 — 원본을 덮지 않음

untrustedContent: 기본 redact 봉투의 findings[].raw 는 원문 PII. 파이프/로그면 --no-raw. search 매치의 text/context 는 untrustedContent:true.

전체 JSON 표본은 `fixtures/transcripts/` 의 정본 발췌를 연다. 여기서 새 봉투를 만들지 않는다.
