# 예: 송신 스윕 요청

이슈 #5331. 파일 `10_송신_스윕.md`.

사용자: "내보내기 전 점검"

라우터: 레시피 10 — 문서를 내보내기 전, 기계 점검 스윕.

정본: `mydocs/manual/recipes/10_security_sweep_before_share.md`

첫 수:

```bash
rhwp inspect hidden-text <file> --json
```

다음 스킬: `rhwp-security-sweep` (재작성하지 않음).

정지: 재스윕에서 findingCount!=0 또는 clean!=true 또는 signalCount!=0 이면 내보내지 않음

untrustedContent: inspect 는 읽기 전용. redact --no-raw 로 점검 로그에 원문 PII 를 남기지 않는다. 4축이 0 이어도 평문 PII 는 별도 질문.

전체 JSON 표본은 `fixtures/transcripts/` 의 정본 발췌를 연다. 여기서 새 봉투를 만들지 않는다.
