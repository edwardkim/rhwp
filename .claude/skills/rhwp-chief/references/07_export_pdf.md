# 07. goal=export-pdf

```
rhwp export-pdf <doc> -o out/<stem>.pdf
```

타임아웃은 기본의 4배. 큰 문서의 렌더를 한 요청으로 끝낸다.

## 게이트 (C17)

1. exit 0
2. 산출 파일 실존
3. 선두 5바이트가 `b"%PDF-"`

셋 중 하나라도 실패면 `failed`. 매직이 틀린 파일은 남겨 두지 않는 것이
원칙이나, 현재 핸들러는 매직 실패를 `failed` 로만 보고한다. 성공처럼
회신하지 않는다.

## 산출

- `out/<원본stem>.pdf`
- `summary`: 바이트 수

## 하지 않는 것

- 페이지 범위 추정 (`--page` 발명 금지 — 표에 없으면 전체)
- DPI·용지 추측
- 한컴 PDF 와의 픽셀 대조 (`rhwp-fidelity-compare` 층, 표 밖)

고객이 "3페이지만" 이라고 **증상**에 적었어도 루프는 전체를 보낸다.
부분 페이지는 표에 행이 생기기 전에는 needs-agent 다.
