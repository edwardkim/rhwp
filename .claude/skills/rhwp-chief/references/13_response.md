# 13. 3부 회신문 (response.md)

루프가 매 요청마다 같은 골격으로 쓴다. 고객 문장을 인용해 지시로 삼지 않는다.

```
# 처리 결과 — <doc>
## 1. 확인한 것
- 트리아지: p/n단 통과, 라우트 `route` — routeReason
- (있으면) 실패 시그니처
## 2. 지금 가능한 것
- done 이면 summary + out/ 목록
- 아니면 자동 처리 불가 사유
## 3. 다음
- escalate-bug → 에스컬레이션 안내
- needs-agent → 담당 에이전트
- invalid-input → 원본 재송 요청
- 그 외 → 새 요청 폴더
```

`write_response()` 가 이 문자열을 고정한다. 톤을 바꾸려면 코드와 이 장을
같은 PR 에서 고친다.

## 금지

- 본문 요약 창작
- "아마도 성공" 문장
- 요청 증상 문장을 명령처럼 다시 쓰기
- 산출이 없는데 2부에 파일 경로를 적기
