rhwp 엔진을 찾지 못했습니다

rhwp-desk 는 rhwp.exe(문서 엔진)를 서브프로세스로 부르는 워크벤치입니다.
다음 순서로 자동 탐색했지만 실패했습니다:

  1. 설정에 지정한 경로
  2. 환경변수 RHWP_DESK_ENGINE
  3. PATH
  4. 저장소 관례 위치 (target/debug·target/release 등)
