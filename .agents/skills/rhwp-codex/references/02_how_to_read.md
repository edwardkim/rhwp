# 생성 장 vs 손글 장 — 읽는 법

## 한 줄

손글 3장(README · 00_서문 · 01_판단트리)만 사람이 고친다.
나머지 가족 장(10·20·30·40·50·60·70·80·85)은 `generated:` frontmatter 가 있으면
**수기 수정 금지**다.

## frontmatter 식별

생성 장:

```yaml
---
kind: guide
status: active
canonical: mydocs/manual/agent_codex/10_조회.md
last_verified: YYYY-MM-DD
generated: tools/gen_agent_codex.py — 수기 수정 금지, 재생성으로 갱신
---
```

`generated:` 키가 있으면 생성기다. 날짜만 다른 본문은 `--check` 가 본문으로 비교한다
(`body_of` 가 frontmatter 를 벗김). JSON 오타를 손대면 다음 재생성이 덮거나
`--check` 가 exit 3 으로 붉는다.

손글 장에는 `generated:` 가 없다. 철학과 트리만 산다.

## 생성 장의 골격

1. 제목과 인용 박스 — 수기 수정 금지 고지, 배열 2원소 절단, `<repo>` 정규화
2. `### \`명령\`` — 커버리지 가드(`tests/agent_codex_contract.rs`)가 이 표기를 센다
3. 종류 · exit · 사용법 · 플래그 · 봉투 필드 목록
4. 출처 표지 줄
5. 실측 표본(bash + 절단 JSON) 또는 `> **계약만**` 사유

## 절단 규칙을 오해하지 말 것

생성기는 배열을 2원소 + `… (N개 중 2개 표시)` 로 자르고, 긴 문자열은 160자로 자른다.
잘린 표본을 완전 봉투로 착각해 필드를 발명하지 말 것.
전체 필드는 지식지도 §2-2, 전체 값은 같은 명령을 다시 실행해 얻는다.

경로의 `<repo>` · `<tmp>` 는 기계 절대경로를 지운 표지다. 그대로 인자로 넣지 말 것.

## 계약만

실행이 세션을 남기거나, 난수가 들어가거나, 키 재료가 필요하면 생성기는
정직하게 **계약만** 이라고 적는다. 스킬이 그 자리에 가짜 JSON 을 채워 넣지 않는다.

## 스킬 로컬 픽스처의 위치

이 스킬의 `fixtures/envelopes/*.json` 은 생성 장에서 **추출**한 전사본이다.
정본은 여전히 생성 장과 생성기다. 전사가 어긋나면 생성 장을 고치지 말고
`tools/gen_skill_pack.py` 를 다시 돌려 전사를 갱신한다.
