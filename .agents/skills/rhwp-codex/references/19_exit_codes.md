# 종료 코드 — 대전 항해용

정본은 서문과 CLI 계약(#2707). 스킬은 항해에 필요한 읽기만 고정한다.

| code | 이름 | 에이전트 행동 |
|---|---|---|
| 0 | 성공 | 봉투 필드 사용. dryRun 이면 파일 없음 |
| 1 | IO | 중단. 원본 불변 |
| 2 | 사용법 | 플래그 확인. 명령을 새로 만들지 말 것 |
| 3 | 판정(DATA) | identical / reproduced / lineageOk / --check stale |
| 4 | 쪽수 게이트 | 변환 계열. 고장으로 승격하지 말 것 |

`--check` 의 3 과 `--verify` 의 3 은 같은 철학이다: 도구는 정상이고 단언이 실패했다.

stdout 이 비면 판정이 아니다. stderr 를 읽고 X09.
