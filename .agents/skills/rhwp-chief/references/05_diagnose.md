# 05. goal=diagnose (기본)

goal 이 비어 있거나 명시적으로 `diagnose` 이면 루프는 **추가 rhwp 명령을
치지 않는다**. 트리아지 티켓과 3부 회신이 산출이다.

```
handle("diagnose") → {status: "done", summary: "진단 완료 — 티켓과 회신문 참조", artifacts: []}
```

`needs:info` — 바이너리가 `info` 를 광고해야 한다. 트리아지가 이미 `info` 를
썼으므로, 광고 실패면 이 핸들러까지 오기 전에 트리아지가 invalid/workaround
쪽으로 접혔을 가능성이 크다.

## 언제 쓰는가

- 상위 시스템이 문서를 넣기만 하고 목표를 모를 때
- "이 파일이 뭐지" 접수 창구
- goal 키를 실수로 뺀 요청 (추측 변환 금지)

## 하지 않는 것

- `export-text` 로 본문을 읽어 목표를 추론
- 파일 이름(`세금계산서.pdf요청.hwpx`)으로 goal 추론
- 증상 문장("PDF 로 바꿔줘")으로 goal 승격

승격은 사람 또는 상위 시스템이 `goal` 필드를 채울 때만 일어난다.

## 회신

1부: 트리아지 통과 단수와 route.
2부: "진단 완료".
3부: 추가 요청은 새 폴더로.

산출물 폴더 `out/` 은 비어 있어도 된다. diagnose 는 변환이 아니다.
