# 13 — --name-field 산출 이름

`batch fill --name-field <컬럼>` 은 산출 파일 이름을 그 컬럼 값으로
만든다. 채움 로직이 아니다.

## 규칙 (cli_commands.md 그대로)

- 생략: `0001` 부터. 최소 4자리. 행 수가 10000 이면 5자리
- 지정: 해당 데이터 필드 값
- 파일명 금지 문자 → `_`
- 동명 → `_2` 접미
- 확장자는 서식과 같음 (hwp/hwpx)
- 경로는 쓰기 전에 전부 예약. 병렬이어도 실행 순서에 좌우되지 않음

## notFound 오탐

컬럼이 누름틀 이름이 아니면 매 행 `notFound` 에 실린다. 레시피 05
실측. 게이트에서 그 문자열을 빼야 한다.

서식에 정말 `성명` 칸이 있으면 파일명과 채움이 겸해진다. 그때
notFound 에 안 뜨는 것이 정상이다.

## 동명

```
홍길동.hwp
홍길동_2.hwp
```

명령이 "중복입니다" 를 내지 않는다. 덮어쓰기 방지는 `_2` 이지,
데이터 품질 검사가 아니다. 주민번호 뒷자리 같은 유일 컬럼을
`--name-field` 로 쓰는 것은 호출자 판단. 이 스킬이 PII 파일명을
강제하지 않는다.

## 금지 문자 예

`홍길동/기획` → `홍길동_기획`. 슬래시가 하위 폴더를 만들지 않는다.
모든 산출은 `--out-dir` 바로 아래.

## dry-run

dry-run 은 파일을 쓰지 않지만 이름 예약 규칙은 실행과 같아야 뜻이
있다. `--out-dir` 를 빼지 않는다.

## 하지 말 것

- 파일명을 만든 뒤 직접 rename 하는 후처리를 스킬 기본값으로
- 동명을 막으려고 batch 구현을 고치기
- `--name-field` 를 단건 fill-fields 에 붙이기 (그 플래그는 batch 전용)
