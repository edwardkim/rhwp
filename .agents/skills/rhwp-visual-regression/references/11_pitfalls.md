# 11 — 함정

실측에서 반복되는 오독.

## P01 — STRUCT_MISMATCH 를 경로도 안 읽고 롤백

- 신호: status: STRUCT_MISMATCH, exit 1 또는 3
- 처방: 변위 노드 경로가 편집한 필드 위치와 일치하는지 읽는다

## P02 — thumbnail 을 편집 후 재렌더로 착각

- 신호: 채운 문서의 썸네일이 빈 서식과 같다
- 처방: thumbnail 은 PrvImage. 눈 검증은 export-png

## P03 — A==A 실패를 문서 회귀로 오진

- 신호: 같은 파일을 두 번 비교했는데 PASS 가 아님
- 처방: 렌더 파이프라인 비결정성. 문서보다 도구가 먼저

## P04 — --max-disp 를 키워 STRUCT 를 숨기려 함

- 신호: 임계 100px 인데도 STRUCT_MISMATCH
- 처방: 구조 불일치는 임계와 무관하게 항상 플래그

## P05 — render-diff 텍스트 모드를 --json 종료 코드로 읽음

- 신호: 차이인데 exit 1 (텍스트) vs 3 (json)
- 처방: 사람 모드는 1, --json 만 3. ir-diff 도 같은 축

## P06 — ir-diff 텍스트 모드 차이를 실패로 읽음

- 신호: 텍스트 비교는 차이가 있어도 exit 0
- 처방: 게이트는 반드시 --json. 차이 = exit 3

## P07 — 페이지를 1부터 셈

- 신호: -p 1 이 두 번째 쪽
- 처방: 0 기준. 한컴/PDF 표기(1부터)와 혼동 금지

## P08 — 배치 요약 줄만 보고 통과

- 신호: STRUCT 1건이 있는데 총 파일 수만 봄
- 처방: geom_inventory.tsv 행별 status

## P09 — 자기 라운드트립 PASS 를 한컴 충실도로 읽음

- 신호: 내부 왕복은 맞는데 한컴 PDF 와 다름
- 처방: render-diff 는 내부 회귀 방지. 한컴은 수동 검증

## P10 — 래스터 픽셀 diff 로 착각

- 신호: 색만 바뀌었는데 PASS
- 처방: render tree 노드 위치·구조 비교. 색은 export-png

## P11 — --batch 폴더 경로 오타

- 신호: 오류: 폴더 읽기 실패, exit 2
- 처방: 단건 파일 없음은 exit 1 과 구분

## P12 — 새 비교 하위명령을 만들어 쓴다

- 신호: 알 수 없는 하위명령, exit 2
- 처방: 기존 네 명령만. 별칭을 만들지 않는다

## P13 — LOAD_FAIL 을 회귀 검출(exit 3)로 접음

- 신호: 배치 --json 에서 error 키가 있는 행
- 처방: 로드 실패는 측정 실패(exit 1). 회귀가 아님

## P14 — 같은 글자 수 메일머지 행을 서로 비교하지 않음

- 신호: 특정 값에서만 레이아웃이 깨짐
- 처방: 산출물끼리도 render-diff. 글자 수 같으면 PASS 가 정상
