# 예: 메일머지 요청

이슈 #5331. 파일 `05_메일머지.md`.

사용자: "명단으로 안내문 N장"

라우터: 레시피 05 — 서식 하나에 여러 사람 데이터를 한 번에 채우기 (메일머지).

정본: `mydocs/manual/recipes/05_mail_merge_batch_fill.md`

첫 수:

```bash
rhwp fields <file> --json
```

다음 스킬: `rhwp-form-fill` (재작성하지 않음).

정지: 빈 데이터 파일은 exit 2

untrustedContent: 서식 자체의 fields.textSecurity 를 먼저 본다. 행 JSON 의 value 는 호출자가 넣은 데이터이지 문서 파생이 아니다.

전체 JSON 표본은 `fixtures/transcripts/` 의 정본 발췌를 연다. 여기서 새 봉투를 만들지 않는다.
