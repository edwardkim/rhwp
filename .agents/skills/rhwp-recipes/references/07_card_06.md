## 트리거 문구

- 편집 전후 레이아웃 숫자로
- render-diff 로 회귀
- 의도한 것만 바뀌었는지
- STRUCT_MISMATCH 가 편집 자리인가
- HWP↔HWPX 왕복 일관성
- ir 이 아니라 픽셀 변위

## 이 카드가 아닌 것

- 값이 들어갔는가 — 01 의 --verify
- 래스터 이미지 diff 가 아님
- 새 문서 내용 작성

## 첫 수

정본 레시피의 첫 실측 명령이다. 경로 자리만 치환한다.

```bash
rhwp render-diff <file> --via hwpx
```

정본 첫 bash 블록 발췌:

```bash
rhwp render-diff samples/form-01.hwp --via hwpx
```

## 사다리 (정본 순서, 발명 없음)

1. `rhwp render-diff <file> --via hwpx`
2. `rhwp render-diff <before> <after>`
3. `rhwp render-diff --batch <dir> --via hwpx -o <out>`

## 정지 조건

- STRUCT_MISMATCH 를 반사 실패로 처리하지 말 것 — 경로를 먼저 읽음
- 변위 노드가 편집과 무관하면 진짜 회귀
- 자기 자신 비교가 PASS 가 아니면 도구 비결정성
- LOAD_FAIL 은 info 로 그 파일만 따로
