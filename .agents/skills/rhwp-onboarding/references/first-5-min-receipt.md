# 첫 5분 · 작업 영수증 입구

목표 한 줄: 산출물을 넘겨야 할 때 **말이 아니라 재실행**으로 증명하는 입구를 안다.
계획 스키마와 `replay` 는 이미 존재한다. 이 문서는 새 편집 단계를 만들지 않는다.

스킬 위임: `rhwp-work-receipt`. 정본은 그 SKILL 과 `AGENTS.md` 작업 증빙 절.

## 온보딩에서 필요한 이유

에이전트가 서식을 채우거나 표를 되돌린 *다음*에 "했어"라고만 말하면 리뷰어가
재계산할 수 없다. 온보딩 5분의 마지막은 그 입구를 가리키는 것이다.

온보딩 중에는 빈 계획을 발명하지 않는다. 실제 `steps[]` 는 사용한 기존 명령으로만
채운다. 모르는 step 이름을 지어 넣지 않는다.

## 단건 영수증 (기존 명령)

```bash
rhwp replay --plan-json '{"planVersion":"1.0","input":"원본.hwp","output":"산출.hwp","steps":[]}' --json
```

읽어야 할 키(기존 계약):

| 키 | 뜻 |
|---|---|
| `inputSha256` | 입력 파일 해시 |
| `planSha256` | 계획 해시 |
| `outputSha256` | 산출 해시 |
| `toolVersion` | 사용한 rhwp 버전 |
| `mode` | `attest` (발급) |

제3자 검증:

```bash
rhwp replay --plan-json '<같은 계획>' --expect-output-sha256 <64hex> --json
```

`reproduced:true` 는 exit 0, `false` 는 exit 3. 도구 고장이 아니라 주장 기각이다.

## 캡슐

```bash
rhwp replay --plan-json '<계획>' --capsule work.capsule.json --json
rhwp replay --plan-json '<다음>' --capsule next.capsule.json --parent work.capsule.json --json
```

- 캡슐은 발급 후 불변. 에디터로 저장하면 부모 해시가 깨진다.
- `--parent` 상대 경로는 캡슐 파일 기준.
- 같은 경로를 `--capsule` 과 `--parent` 에 주면 거부.

## 아직 하지 않는 것

| 하고 싶은 일 | 어디로 |
|---|---|
| 실제 편집 실행 | `rhwp run` + 기존 스킬. 온보딩이 계획을 지어 실행하지 않는다 |
| 폴더 전수 회계 | `rhwp audit` — 캡슐이 쌓인 뒤 |
| 계보 | `rhwp lineage` — 체인이 생긴 뒤 |
| 서명·귀속 | 미착지 축. 이 스킬이 흉내 내지 않는다 |

## 온보딩 게이트

1. `replay --help` 또는 실제 호출이 사용법 오류(2)가 아닌 것을 본다.
2. 빈 `steps` 로 해시만 찍는 호출은 **시연**일 뿐이다. 실작업을 증명했다고 쓰지 않는다.
3. gym 점수나 리더보드를 영수증 대신 쓰지 않는다.

## 함정

### 01 — 산출 경로가 생긴다고 믿음

`replay` 발급은 사용자 `output` 경로를 만들지 않는다. 임시 재실행이다.
실파일이 필요하면 기존 `run`/edit 명령을 따로 실행한다.

### 02 — toolVersion 무시

버전이 다른 바이너리로 재현하면 해시가 갈라질 수 있다. 닥터의 `binary.version` 과
대조한다.

### 03 — 계획을 손으로 예쁘게 저장

공백이 바뀌면 `planSha256` 이 바뀐다. 받은 JSON 을 포맷하지 않는다.

### 04 — 해시를 줄여 쓰기

64hex 전부. 앞 8자만 적고 같다고 하지 않는다.

### 05 — exit 3 을 재시도

재현 실패는 인자가 같다. 입력·계획·산출 중 무엇이 다른지 봉투를 읽는다.

### 06 — 온보딩에서 편집 step 발명

`steps` 에 없는 명령 이름을 넣지 않는다. 모르면 이 단계를 건너뛰고
`rhwp-work-receipt` 를 연다.

### 07 — gym 팩을 계획 입력으로

이 경로의 입력이 아니다.

### 08 — 네트워크 영수증

영수증은 로컬 파일 해시. 오프라인에서 동작한다.

### 09 — 캡슐을 이슈에 붙여 수정

붙여 넣은 뒤 다시 저장하면 깨진다. 원본 파일을 첨부한다.

### 10 — parent 를 cwd 로 해석

캡슐 파일 기준이다. 같은 폴더에 두는 것이 가장 싸다.

## 성공 판정

온보딩 5분은 이 명령이 **존재하고**, 위임 스킬 경로를 알고, 빈 계획을
실작업 증명으로 과장하지 않으면 충분하다.
