# 예외 경로 — 네트워크 없음 (`no_network`)

증상: 리포트 `network.offline==true` 또는 `--offline`.
`exceptions[].kind=="no_network"`.

**이것은 임계 실패가 아니다.** 온보딩의 자가검증은 로컬 바이너리와
로컬 `samples/` 만 있으면 된다. 닥터는 외부 TCP 가 안 되어도 exit 0 이
될 수 있다 (다른 임계 검사가 통과하면).

## 프로브가 하는 일 / 안 하는 일

하는 일: `1.1.1.1:443`, `8.8.8.8:443` 에 짧은 TCP connect (기본 2초).

하지 않는 일:

- HTTP GET, crates.io 다운로드, GitHub API, 텔레메트리
- 실패 시 재시도 루프
- 온보딩 중단

`--offline` 은 프로브 자체를 생략한다. CI 나 에어갭에서 쓴다.

```bash
python tools/agent_onboarding/rhwp_doctor.py --offline --json
```

## 오프라인에서 되는 것

| 작업 | 조건 |
|---|---|
| 닥터 순수 로직·유닛 테스트 | 항상 |
| `info` / `export-text` 자가검증 | 로컬 바이너리 + 샘플 |
| `.mcp.json` 방출 | 항상 |
| 첫 5분 읽기 전용 레시피 | 로컬 바이너리 + 샘플 |
| `cargo build` | crate 캐시가 있을 때 |

## 오프라인에서 안 되는 것

| 작업 | 대안 |
|---|---|
| 첫 `cargo build` (캐시 없음) | 캐시된 머신으로 옮기거나 네트워크를 연다 |
| rustup 툴체인 설치 | 미리 설치된 툴체인 |
| `git fetch` / `gh pr` | 온보딩 자체가 아니라 기여 단계 |
| CDN 폰트 | 저장소 `assets/fonts`, `ttfs/` |

## 오해

MCP 는 로컬 stdio 다. 네트워크가 없어도 `rhwp mcp-serve` 는 뜬다.
호스트가 원격 모델 API 를 쓰는 것과 rhwp 서버는 별개다.

## 사례 01 — 회사 프록시

TCP 443 이 막혀 오프라인으로 보일 수 있다. `--offline` 으로 노이즈를 없앤다.

## 사례 02 — DNS 만 죽음

프로브는 IP 를 쓰므로 DNS 와 무관하게 연결을 본다.

## 사례 03 — IPv6 only

프로브는 IPv4 리터럴. 실패해도 로컬 온보딩은 계속.

## 사례 04 — 방화벽 팝업

Windows 가 python 의 outbound 를 물을 수 있다. `--offline`.

## 사례 05 — CI runner

외부망이 없으면 `--offline` 을 기본으로.

## 사례 06 — 크레이트 캐시 hit

오프라인 빌드 성공. 네트워크 예외는 정보일 뿐.

## 사례 07 — 크레이트 캐시 miss

빌드는 실패. 닥터 exit 3 과 별개로 cargo 로그를 본다.

## 사례 08 — 샘플이 git LFS

LFS 포인터만 있으면 불량 샘플. 네트워크가 필요할 수 있다.

## 사례 09 — 문서의 외부 링크

온보딩 레시피는 저장소 안 경로만 인용한다.

## 사례 10 — 모델 API 다운

rhwp 온보딩 실패가 아니다.

## 사례 11 — 시간 동기

TLS 검증은 프로브가 하지 않는다.

## 사례 12 — 캡티브 포털

TCP 는 성공처럼 보일 수 있다. 그래도 온보딩은 로컬.

## 사례 13 — `--offline` + 정상

exceptions 에 no_network 가 정보로 남을 수 있다. ok 는 true.

## 사례 14 — 프로브 타임아웃

2초. 매달리지 않는다.

## 사례 15 — 루프백만 허용

1.1.1.1 실패. 정상 오프라인.

## 사례 16 — 이중 해석

offline 을 exit 1 로 승격하지 않는다.

## 사례 17 — 텔레메트리 추가 유혹

넣지 않는다.

## 사례 18 — npm/pip

닥터는 표준 라이브러리만. 패키지 설치 불필요.

## 사례 19 — 폰트 다운로드 스크립트

온보딩 필수 경로가 아니다.

## 사례 20 — 기여 단계와 혼동

`gh pr create` 는 네트워크가 필요하다. 그건 온보딩 다음이다.

## 성공

오프라인이어도 `ok==true` 가 될 수 있다. 네트워크 칸은 SKIP 이다.
에이전트는 `exceptions` 를 읽고 crates.io 작업을 미룬다.
