# 예제 — 표본 1건을 계약으로 쓰지 않는다

이슈 #5324. playbook 함정 3. gym 아님. F15.

## 정답지

코퍼스 전량 N건 중 M건 + 반례 수. 한 파일의 21쌍은 가설이다.

## 명령

```bash
# 한 문서에서 패턴이 보여도
# 같은 축을 저장본 전량(또는 공개 코퍼스)에서 센다
# "N중 M, 반례 K" 가 이슈 본문에 없으면 계약 문장을 쓰지 않는다
```
