# 04 — 정답지를 여정 실행보다 먼저

playbook 2단: 한컴 출력 PDF, 법정 서식, 실제 제출 요건처럼 **원
구현과 독립된** 비교 기준을 먼저 확보한다.

"먼저"가 핵심이다. `export-svg` 를 돌려 놓고 정답지를 찾으면
에이전트가 자기 출력에 맞춰 기준을 고른다.

## 허용되는 독립 기준

1. **한컴 공식 출력 PDF** — 해당 환경에서 인쇄/PDF 저장한 것.
   보편 절대 오라클이 아니다. provenance 필수 (F03).
2. **법정 서식** — 편람 별지, 고시된 서식 이미지/PDF.
3. **실제 제출 요건** — 공고문 문구 ("검정 글씨로 작성").
4. **원본 바이트/ZIP 이름 집합** — 인터넷 배포 실물의 구조 축.
5. **기록값 자신** — 방금 쓴 칸을 `export-tables`/`fields` 로 재독.
   독립 기준이라기보다 기계 확정 축.
6. **CLI 계약** — `cli_commands.md` 종료 코드·JSON 키.

허용되지 않는 것:

- rhwp 가 방금 그린 SVG 를 정답지로 쓰기
- "그럴듯하다" 육안
- gym pack 의 reference JSON
- 콘솔에 찍힌 한글

## 확보 체크

```
[ ] 기준 종류가 위 1–6 중 하나로 이름 붙음
[ ] 원본 경로와 기준 경로가 다름 (자기 참조 아님)
[ ] 한컴 PDF 면 provenance 7키가 채워짐
[ ] 법정 서식이면 편람/고시 식별자가 있음
[ ] 제출 요건이면 문구를 인용함 (의역 금지)
[ ] 없으면 F04 한계를 먼저 기록하고 여정을 축소
```

## 정답지가 나중에 생기면

자기 일관성만 돌린 로그를 충실도 이슈로 승격하지 않는다.
정답지를 새로 기록한 뒤 **같은 명령**을 다시 돈다. 로그에
"당시 기준 없음"을 남긴다.
