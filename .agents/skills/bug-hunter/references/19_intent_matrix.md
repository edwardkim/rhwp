# 19 — 발화 → 명령

`fixtures/intent_matrix.json` (120+). 사용자 한 줄이 어느 장·정지
규칙으로 가는지.

스키마:

```
id: I001
utterance: 버그 찾아줘 실사용 기준
command: playbook 여정 하나 선택
reference: 03_journey_selection.md
stop: F01
notGym: true
```

`command` 칸에 발명 하위명령을 쓰지 않는다. 기존 CLI 이름 또는
playbook 동사(선택/확보/대조/이슈화/거부)만.
