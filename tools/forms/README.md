# 표준 서식 자산 — 공문서를 CLI 로 작성하기 (#3372)

행정 실무 문서를 CLI 만으로 작성하기 위한 **누름틀 내장 표준 서식** 모음이다.
접근은 행정업무운영 편람이 권장하는 방식(§2 "일상 반복적인 업무는 표준 기안문을
활용한다") 그대로 — **서식 + `edit fill-fields`(#3345) 조합**이며, ingest 스키마
확장 없이 실물 배치 품질을 서식이 보장한다.

## 일반기안문_서식.hwpx — 별지 제1호서식

「행정 효율과 협업 촉진에 관한 규정 시행규칙」 별지 제1호서식(일반기안문)의
두문·본문·결문 배치를 따르고, 기입 위치 **23곳이 누름틀(CLICK_HERE)** 이다:

행정기관명 / 수신자 / 경유 / 제목 / 본문 / 붙임 / 발신명의 / 수신자명단 /
기안자 / 검토자 / 결재권자 / 협조자 / 시행번호 / 시행일 / 접수번호 / 접수일 /
우편번호 / 주소 / 홈페이지 / 전화번호 / 팩스번호 / 전자우편 / 공개구분

### 사용 — 조사 → 채움 → 검증 → 산출

```bash
# ① 서식이 요구하는 필드 확인
rhwp fields tools/forms/일반기안문_서식.hwpx --json | jq -r '.fields[].name'

# ② 값 채우기 (예시값 파일 참조; 본문의 \n 은 문단 내 줄바꿈이 된다)
rhwp edit fill-fields tools/forms/일반기안문_서식.hwpx \
  --data @tools/forms/일반기안문_예시값.json -o 기안문.hwp --json

# ③ 재독 검증 — 값 반영을 기계로 대조
rhwp fields 기안문.hwp --json

# ④ 배포본
rhwp export-pdf 기안문.hwp -o 기안문.pdf
```

- 본문 항목체계(1. → 가. → 1) → 가))는 값 문자열 안에서 관례대로 들여쓰기해 넣는다
  (예시값 파일의 `본문` 참조).
- 빈 값으로 남긴 누름틀의 안내문 출력·폭 처리는 #3375 참조.

## 재생성 — build_일반기안문_서식.py

서식은 이 스크립트로 결정적으로 재생성할 수 있다(리뷰 가능성·수정 용이성):

```bash
rhwp build-from-ingest seed.json -o seed.hwpx     # 최소 스켈레톤 (스크립트 상단 참조)
python tools/forms/build_일반기안문_서식.py        # header/section XML 재작성 → 서식 hwpx
```

스크립트가 하는 일: charPr(기관명 22pt bold·발신명의 16pt bold·결문 8.5pt)·
paraPr(중앙 정렬·제목행 하단선·회색 구분 바)·borderFill 을 header 에 추가하고,
section 을 별지 제1호서식 배치로 재작성하며, 기입 위치에 누름틀을 심는다.

## 간이기안문_서식.hwpx — 별지 제2호서식 (결재란 표 포함)

내부결재문서용(보고서·계획서·검토서, 규칙 제3조제3항 — 시행문 변환 불가). 좌상단
문서등록 표(생산등록번호·등록일·결재일·공개구분), 우상단 **결재란 표**(직위 4칸·서명
공간·협조자 병합행 — colspan), 제목 박스, 점선 요약설명 박스, 작성일·작성기관으로
구성되며 기입 위치 **13곳이 누름틀**이다. 용지 여백은 서식 제정 기준(상·좌·우 20㎜,
하 10㎜)을 따른다. 사용법은 일반기안문과 동일(조사→채움→재독→PDF, 예시값
`간이기안문_예시값.json`).

주의 — 안내문과 같은 값 채움: 코어 결함 #3380(채울 값이 안내문과 동일하면 조용히
유실) 회피를 위해 본 서식의 안내문은 실값과 충돌하지 않게 일반화되어 있다("직위" 등).
새 서식을 만들 때도 안내문에 흔한 실값("주무관"·"공개")을 쓰지 않는다.
